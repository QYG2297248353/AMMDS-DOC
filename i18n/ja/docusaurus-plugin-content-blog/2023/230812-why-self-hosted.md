この記事では、萌森スタジオが製品をつくるうえで最も根本にあるこだわり、セルフホストについて語ります。それは単なるスローガンではなく、無数の取捨選択を経たうえで、なお私たちが支払う覚悟のある代償です。

## 一つにはっきりさせておきたいこと：データは誰のものか

私たちのチームのメンバーは全員、熱心なセルフホストユーザーです。ハードディスクには長年かけて蓄積した映画、漫画、小説が眠っており、命名から分類まで、すべての記録に整理した人の工夫が込められています。これらの資料をクラウドサービスに預けるのは一見楽に見えますが、それは次の三つのことを受け入れることを意味します：

- あなたの作品リスト、タグ、視聴履歴が、他人のデータになってしまいます；
- サービスがある日停止すれば、あなたが長年かけて整理した成果が一晩でアクセスできなくなる可能性があります；
- ツールを乗り換えようとしても、エクスポートされるデータが不完全なことがほとんどです。

私たちはユーザーの資料を誰かの資産にしたくありません。だからこそ、最初の一行のコードから AMMDS の位置づけは明確でした：**あなた自身の機器に置く映画の資料棚**です。資料はローカルに保存され、クラウドアカウントの登録は不要で、リモートのスイッチ一つであなたに代わってデータの行き先を決められるようなものもありません。

## セルフホストは閉ざされることを意味しない

セルフホストとはインターネット接続を拒むことだ、という誤解があります。実際はそうではありません。

プログラム自体はオフラインで起動できますが、「資料の自動補完」「リソース探し」「通知のプッシュ」といった機能は、確かに外部サイトへのアクセスを必要とします。私たちが下した判断は次のとおりです：

> ネットワーク接続機能は既定でオフで、あなたが項目ごとに有効化します。有効化した後も、プログラムはあなたが設定した宛先にのみアクセスします。

言い換えれば、ネットワーク接続はユーザーが自ら与える権限であり、製品がこっそり奪い取る権利ではありません。完全にオフラインの環境でローカルファイルの整理に使うことも、情報サイトを有効にした後に自動スクレイピングの便利さを享受することもできます——決定権は常にあなたの手にあります。

## 代償：私たちが手放したもの

セルフホストを選ぶことは、「起動すればすぐ使える」という利便性の一部を手放すことを意味します：

- **公式ホスティングなし**：自分で機器を用意し、データがどのディレクトリに置かれるのかを理解する必要があります。
- **初回設定には手作業が必要**：インストール方法を選び、ログインし、ファイルの置き場所をプログラムに伝える——この何ステップかは省けません。
- **アップグレードは自分で開始**：バックグラウンドでこっそりデータ形式が置き換えられることはありません。

こうした敷居が一部のユーザーを敬遠させることは承知しています。しかし、引き換えに別のユーザーがデータの制御を失うのであれば、私たちはむしろ敷居を残す方を選びます。

## 一貫した設計原則

この選択はその後、AMMDS のすべての機能に共通する指針となりました：

| 場面 | 私たちの対応 |
| :--- | :--- |
| 資料の保存 | すべてローカルに置き、アップロードしない |
| 外部サイトへのアクセス | 既定でオフ、項目ごとに有効化 |
| メディアサーバーとの同期 | あなたが自ら接続を設定 |
| バックアップと移行 | 標準のバックアップパッケージにエクスポートし、いつでも持ち出し可能 |

今日あなたが目にする多くの設計——ローカルデータベース、標準バックアップパッケージ、エクスポート可能な資料フィールド——の原点は、このブログに書かれた判断です。
