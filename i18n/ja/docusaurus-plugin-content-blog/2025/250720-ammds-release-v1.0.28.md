# AMMDS v1.0.28 をリリース — 欧米映画・ドラマのスクレイピングに対応

AMMDS v1.0.28 が正式にリリースされました！今回のアップデートで最も重要な突破口は、欧米映画・ドラマのスクレイピング機能の追加です。これは AMMDS が日本の映画・ドラマのスクレイピングに対応した後、スクレイピング能力を欧米の映画・ドラマ分野へ初めて拡張したものです。

{/* truncate */}

## 欧米映画・ドラマのスクレイピング

v1.0.28 以前、AMMDS の映画・ドラマのスクレイピング能力は主に日本の映像コンテンツ（Jav）分野に集中していました。今回のアップデートで、スクレイピングの対象範囲が欧米の映画・ドラマ作品へ正式に拡張されました。具体的には次のとおりです。

- **複数データソースへの対応**：複数の欧米映画・ドラマのデータソースに接続し、メタデータの豊富さと正確性を確保します
- **タイトルと別名の識別**：作品のオリジナルタイトル、英語タイトル、および各地域の別名を自動的に識別します
- **出演者情報のスクレイピング**：欧米の出演者情報の自動取得に対応し、出演者の写真や個人プロフィールなどを含みます
- **制作会社と製作者**：制作会社や配給元といった製作関連情報をスクレイピングします
- **レーティングとタグ**：コンテンツのレーティング（R 指定や PG-13 など）およびカテゴリタグを自動的に取得します

## スクレイピングエンジンの最適化

欧米の映画・ドラマコンテンツのスクレイピングをより良くサポートするため、スクレイピングエンジンに根本的な最適化を行いました。

- データソースのアダプター層を強化し、より多くの種類のメタデータ形式に対応しました
- 知覚ハッシュ（Perceptual Hash/pHash）アルゴリズムを最適化し、画像照合の正確性を向上させました
- 失敗時のリトライ機構を改善し、スクレイピングに失敗したタスクに対して上限付きの自動再試行を行います

## 不具合の修正

- 一部のシナリオでスクレイピングタスクが停止する問題を修正
- メタデータキャッシュの期限切れ判定が不正確でデータの不整合を招く問題を修正
- 多言語タイトルの表示が異常になる問題を修正
- 特定のエンコード形式のファイル名によりスクレイピングが失敗する問題を修正

## 展望

欧米映画・ドラマのスクレイピングの登場により、AMMDS の欧米コンテンツ管理分野における空白が埋まりました。今後もスクレイピングの品質を継続的に改善し、欧米映画・ドラマ向けの特有の機能をさらに追加していく予定です。
