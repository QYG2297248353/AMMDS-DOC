# AMMDS v1.0.25 をリリース — 内蔵翻訳とネタバレモード

AMMDS v1.0.25 では、二つの実用的な新機能である内蔵翻訳エンジンとネタバレモードを追加しました。あわせてコミュニティから報告された複数の重要な問題を修正し、全体の安定性を向上させました。

{/* truncate */}

## 内蔵翻訳エンジン

v1.0.25 において、AMMDS はローカルで動作する翻訳機能を統合しました。ユーザーは外部の翻訳サービスに依存することなく、メタデータの多言語処理を完了できます。

- **Baidu 翻訳との連携**：Baidu 翻訳 API を通じて中国語と英語をはじめとする多言語間の相互翻訳を実現し、映画・ドラマのタイトルやあらすじを一括で翻訳したいシナリオに適しています
- **Microsoft 翻訳との連携**：Azure Translator サービスにも対応し、ユーザーに選択肢を増やします。ネットワーク環境や個人の好みに応じて柔軟に切り替えられます
- **翻訳キャッシュ**：翻訳済みのコンテンツはローカルにキャッシュされ、重複リクエストを回避して API 呼び出しの割り当てを節約します

これら二つの翻訳エンジンは主に Metatube のスクレイピングフローで使用され、スクレイピングした外国語のメタデータをユーザーが使い慣れた言語へ自動的に変換します。

## ネタバレモード

新しい**ネタバレモード**が追加され、初期状態で有効になっています。この機能を使用すると、映画・ドラマのコンテンツにネタバレ印を付けることができます。

- 映画・ドラマの詳細ページでは、ネタバレ印が付いたコンテンツがぼかし処理されます
- ユーザーが手動でクリックして初めて具体的な内容を展開して確認できます
- これは新作や人気ドラマを整理するユーザーに非常に便利で、意図せず物語の重要な情報を見てしまうことを効果的に防ぎます

## 不具合の修正

- **Metatube 翻訳問題の修正**：Metatube のスクレイピング時に翻訳エンジンの呼び出しが失敗してメタデータが欠落する問題を解決しました
- **映画・ドラマ購読失敗問題の修正**：一部のユーザーから報告された、ネットワークの揺れやサイトの応答異常によって映画・ドラマの購読タスクが中断される問題を修正しました
- **スクレイピングログの最適化**：スクレイピングログの出力形式を再構築し、構造化フィールドを追加しました。これによりスクレイピング失敗の原因を追いやすくなりました
- **出演者スクレイピングロジックの最適化**：出演者情報のスクレイピング手順を最適化し、重複リクエストを削減して、スクレイピングの効率と正確性を向上させました

## その他の改善

- 翻訳エンジンの並行制御を最適化し、リクエストが速すぎることによるレート制限を回避しました
- ネタバレモードと既存の UI コンポーネントの互換性を向上させました
- 設定ページの操作体験を改善しました
