# AMMDS v1.0.23 をリリース — 漫画スクレイピングが登場

AMMDS v1.0.23 が正式にリリースされました！今回のアップデートでは、待ち望まれていた漫画スクレイピング機能が追加され、マルチメディアコンテンツ管理の分野における AMMDS のもう一つの重要な拡張を意味します。

{/* truncate */}

## 漫画スクレイピング — ゼロから一への突破口

v1.0.23 の最も中核となる目玉は、**漫画スクレイピング機能の初登場**です。これは AMMDS が漫画コンテンツの管理を初めてサポートするもので、ユーザーは Jellyfin の Bookshelf プラグインを通じて漫画のスクレイピングを実現できます。具体的には次のとおりです。

- **Jellyfin Bookshelf との連携**：Jellyfin の Bookshelf コンポーネントに接続することで、AMMDS が漫画リソースを自動的に識別・整理し、メタデータ情報を抽出します。
- **メタデータの自動入力**：スクレイピングの過程で、漫画のタイトル、著者、出版社、ISBN、発売日、カテゴリタグといった主要情報を自動取得し、手作業による整理の負担を大幅に削減します。
- **表紙とサムネイルへの対応**：漫画の表紙を自動的にダウンロードして関連付けることで、メディアライブラリに直感的で美しい表示効果をもたらします。

## 不具合の修正

新機能に加え、本バージョンではコミュニティから報告された複数の問題も修正しました。

- 一部のシナリオでメタデータのキャッシュが異常になり、重複してスクレイピングされる問題を修正
- 特殊文字を含むパスでファイル認識に失敗する問題を修正
- ログ出力を最適化し、不要な警告情報を削減
- スクレイピングタスクキューの安定性を向上させ、高負荷時のタスク消失を回避

## 今後の計画

漫画スクレイピングの登場は第一歩にすぎません。今後のバージョンでは、漫画スクレイピングの正確性と対応範囲を継続的に改善し、より多くの漫画ソースへの対応を順次追加していく予定です。使用感をコミュニティでぜひご共有ください。より良いものづくりに役立てます！
