# AMMDS v1.0.30 をリリース — プラグインアシスタントと分割整理

AMMDS v1.0.30 では、プラグインアシスタントプロジェクト、キー管理機能、そして映画・ドラマの分割整理機能が追加され、あわせて番号（ID）の識別ロジックが最適化されました。

{/* truncate */}

## プラグインアシスタント

本バージョンでは、**AMMDS プラグインアシスタント**プロジェクトが新たに追加されました。これは独立した補助ツールであり、プラグインの開発、テスト、配布の手順を簡素化することを目的としています。

- **プラグインの足場（Scaffold）**：プラグインプロジェクトのテンプレートを素早く生成し、開発者がゼロから構築する必要をなくします
- **ローカルテスト環境**：プラグインのローカルでの実行とデバッグを可能にし、開発のイテレーションを加速します
- **パッケージングと公開**：ワンクリックでプラグインをパッケージ化し、AMMDS プラグインマーケットへ公開できます
- **依存関係の管理**：プラグイン間の依存関係を自動的に検出し処理します

## キー管理

集中式の**キー管理機能**が追加されました。

- すべてのサードパーティサービスに対する API キーやトークンなどの機密情報を一元管理します
- 暗号化して保存し、認証情報の安全を確保します
- キーの追加・削除・変更・検索に対応します
- 各機能モジュールとシームレスに連携し、一か所の設定が全体に反映されます

## 映画・ドラマの分割整理

**映画・ドラマの分割整理機能**が完成し、複数ファイルから成る映像リソースの管理における課題を解決します。

- 同一作品に属する複数の動画ファイル（CD1、CD2 や Part1、Part2 など）を自動的に識別します
- 分割ファイルを単一のエントリとしてまとめて表示し、メディアライブラリを整然と保ちます
- カスタムの分割命名規則に対応し、異なるソースの命名習慣に適応します

## 番号識別の最適化

番号（ID）の識別ロジックに対して重要な最適化を行いました。

- **手動で識別コードを変更した後に一致しなくなる問題を修正**：以前はユーザーが識別コードを手動で調整した後、システムがメタデータを正しく再照合できませんでしたが、これを修正しました
- **特殊タグの処理を最適化**：番号に含まれる `-C` や `-AI` といった特殊なサフィックスタグの処理ロジックを最適化し、これらのバリエーションが正しく識別・照合されるようにしました。これによりタグ形式に起因するスクレイピングの失敗を削減します

## 不具合の修正

- 一部のシナリオで分割ファイルの並び順が混乱する問題を修正
- キー更新後にキャッシュが更新されない問題を修正
- プラグインアシスタントが生成したプロジェクトテンプレート内の依存バージョンが互換性を持たない問題を修正
