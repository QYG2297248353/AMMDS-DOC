# AMMDS v1.6.34 をリリース — Metatube サービスを内蔵

AMMDS v1.6.34 では、プラットフォーム対応が大幅に拡張され、FnOS アプリストアからのオフラインインストールと Windows 10/11 インストールパッケージへの対応が追加されました。あわせて Metatube スクレイピングサービスが内蔵されています。

{/* truncate */}

## FnOS アプリストアへの対応

今回のアップデートでは、**FnOS アプリストアからのオフラインインストール対応**が追加されました。FnOS ユーザーはアプリストアから直接 AMMDS をインストールできるようになり、導入の手順が大幅に簡素化されます。

- **オフラインインストールパッケージ**：FnOS 向けのオフラインインストールパッケージを提供し、ネットワークに接続せずにインストールを完了できます
- **アプリストアとの連携**：AMMDS は FnOS アプリストアに掲載され、ユーザーはワンクリックでインストールとアップデートができます
- **自動更新**：今後のバージョンでは、アプリストアのチャネルを通じて自動的に更新が配信されます

## Windows インストールパッケージへの対応

v1.6.34 では **Windows 10/11 インストールパッケージ**が正式にリリースされ、より多くのユーザーがデスクトップ環境で手軽に AMMDS を利用できるようになりました。

- グラフィカルなインストールウィザードを提供し、ユーザーをインストールと設定へと案内します
- Windows サービスモードに対応し、起動時の自動実行が可能です
- 管理パネルへのショートカットを統合し、日々の操作を容易にします

## サイト認証の緩和

コミュニティからのフィードバックに基づき、サイト認証のポリシーを調整しました。**サイト検索機能のみが認証を必要とする**ようになりました。これは次のことを意味します。

- ユーザーは認証なしで大部分の基本機能を利用できます
- リソース検索に関わるモジュールのみでサイト認証の完了が必要です
- 新規ユーザーの参入障壁が下がり、使用感が向上しました

## Metatube サービスの内蔵

**Metatube サービスが AMMDS に内蔵されました**。ユーザーは設定ページで自由に有効化できます。

- 内蔵サービスにより、Metatube を個別に導入する手間が省けます
- ユーザーは有効化と無効化を自由に選べ、システムリソースの消費を柔軟に制御できます
- AMMDS のスクレイピングエンジンと深く連携し、より滑らかなメタデータ取得体験を提供します

## 不具合の修正

- Windows インストールパッケージが一部のシステムバージョンで互換性を持たない問題を修正
- FnOS オフラインインストールパッケージの依存関係のチェックが不完全な問題を修正
- Metatube 内蔵サービスとプロキシ設定が競合する問題を修正
