## はじめに

AMMDS v1.1.0 は 2025 年にリリースされました。これは 3 月の v1.0.0 パブリックベータ以来、初となる重大な機能アップデートです。本記事では実際の利用という観点から v1.1.0 の新機能を深掘りして体験し、リアルな設定のアドバイスと使用感を共有します。

## 一、AMMDS アシスタント管理ページ

### 機能の概要

v1.1.0 で最も目を引く新機能は、**AMMDS アシスタント**（AMMDS Assistant）の管理ページです。これは AMMDS が管理者向けに提供するシステムレベルの管理パネルであり、複数の運用機能を統合しています。

### 中核となる能力

**システムのヘルスチェック**：アシスタントページにはヘルスチェック機能が組み込まれており、以下の項目の状態をワンクリックで検出できます。

- データベースの接続状態（SQLite）
- 各スクレイピングプラグインの API 接続性
- 認証済みサイトへの到達性
- ディスク容量の使用率
- システムの稼働時間

**稼働状況の概要**：

```
システム状態
├── サービス稼働時間：15 日 7 時間 32 分
├── データベース：✅ 正常（37.2 MB）
├── TMDB プラグイン：✅ 接続済み
├── JavBus プラグイン：✅ 接続済み
├── M-Team サイト：✅ 認証済み
├── KamePT サイト：✅ 認証済み
├── Rousi サイト：⚠️ Cookie がまもなく期限切れ
└── ディスク使用率：42%（残り 128 GB）
```

### 実際に使ってみた感想

アシスタントページの設計思想は非常に実用的です。もともと異なるメニュー項目に散らばっていたシステム情報を一か所にまとめて表示するため、管理者はシステム全体の状態を一目で把握できます。特に Rousi サイトの Cookie 有効期限切れの通知機能は、実に心配りが行き届いています。PT サイトの Cookie の有効期間は通常 30 日程度しかなく、速やかに更新しないと認証が失効します。この通知機能は多くの手間を省いてくれます。

**改善提案**：今後のバージョンでは、ヘルスチェックの間隔や通知のしきい値をカスタマイズできるようにし、さらに多くのシステム指標（CPU 負荷やメモリ使用率など）の監視に対応してほしいです。

## 二、3D Logo ログインページ

### ビジュアルのアップグレード

v1.1.0 ではログインページに大幅なビジュアル改造が施され、**3D Logo アニメーション効果**が導入されました。それまでの AMMDS のログインページは標準的な平面の Logo を使用しており、簡潔ではあるものの識別度に欠けていました。新しい 3D Logo はページ読み込み時に回転アニメーションを表示し、ダイナミックな背景の光効果と相まって、全体の印象を現代的な SaaS 製品に引けを取らないものにしています。

### フロントエンド技術

観察したところ、3D Logo は Three.js または CSS 3D Transforms を用いて実装されており（バージョンにより異なります）、GPU のハードウェアアクセラレーションを活用しています。主流のブラウザではスムーズに動作し、目立つ性能オーバーヘッドはありません。ログインページの読み込み速度も、前バージョンと比べて顕著な低下は見られません。

### ユーザーのフィードバック

実際に体験してみると、3D Logo の視覚効果は確かに印象的で、特に導入後に初めてログインページを開いたときにその効果を実感できます。これは「プロフェッショナルで現代的」な製品という印象を伝え、ユーザーの AMMDS に対するブランド認知の向上に役立ちます。

**注意点**：サーバーリソースが逼迫している環境（低スペックの NAS など）では、3D アニメーションによって CPU 負荷が増加する可能性があります。さまざまな性能のハードウェア環境に対応するため、システム設定に「3D アニメーションを無効化」するオプションを残しておくことをお勧めします。

## 三、JavBus サイト対応のスクレイピング効果

### 背景

JavBus は中国国内の映像愛好家が常用する日本の映画・ドラマのリソースデータベースであり、豊富なメタデータ情報を提供しています。v1.1.0 において、AMMDS は JavBus をスクレイピングのデータソースとして正式に統合しました。

### スクレイピング効果の実測

典型的なリソースファイルを使って JavBus のスクレイピング効果をテストしました。

**テストファイル**：`FC2-PPV-1234567.mp4`

**スクレイピング結果**：
- 映画タイトル：✅ 日本語と中国語のタイトルを正確に認識
- 表紙ポスター：✅ 高解像度のポスターをダウンロード
- 出演者情報：✅ 完全な出演者リストとアバター
- 発売日：✅ 日付単位まで正確
- 作品番号（ID）：✅ 自動的に認識して関連付け
- あらすじ：✅ 日本語のあらすじ＋中国語翻訳
- シリーズ情報：✅ シリーズ名とシリーズ内の番号

### 複数ソースの集約の様子

AMMDS のインテリジェントマッチングアルゴリズムは、JavBus とその他の利用可能なデータソースから同時に情報を取得し、それらを集約します。例えば、JavBus が出演者情報を提供し、TMDB が評価データを提供する場合、AMMDS は両者を自動的にマージして、最も完全なメタデータレコードを生成します。

### 設定の詳細

JavBus プラグインの設定は非常に簡単です。

1. プラグイン管理ページで JavBus プラグインを有効にします
2. 追加の API キーは不要です（JavBus は公開データソースです）
3. リクエスト間隔を設定します（アンチスクレイピング機構の発動を避けるため、1～2 秒を推奨）
4. 優先度を設定します（欧米コンテンツでは TMDB が優先して照合されるよう、中程度に設定することを推奨）

## 四、オンラインストアへの対応

### 機能の意義

AMMDS は**オンラインストア**（store.lifebus.top）を導入しました。これにより、AMMDS の開発を支援したいユーザーにより便利な購入チャネルが提供されます。

### 利用方法

[足跡ストア](https://store.lifebus.top/)にアクセスすると、関連製品やサービスを購入でき、AMMDS の継続的な発展を支援できます。

### コミュニティへの影響

オープンソースの精神と商業的な持続可能性は決して両立しないわけではありません。プライベートデータプラットフォームとして、AMMDS の継続的な開発と保守にはリソースが必要です。オンラインストアの導入は、プロジェクトを支援したいユーザーに直接のチャネルを提供すると同時に、プロジェクトの商用化の探求における第一歩でもあります。

## 五、実際の使用体験のまとめ

### 導入とアップグレード

v1.0.x から v1.1.0 へのアップグレードは非常にスムーズでした。

```bash
docker compose pull
docker compose up -d
```

アップグレード後はデータベースの移行が自動的に完了し、既存の設定（サイト認証、プラグイン設定、ユーザーアカウント）はすべてそのまま保持され、互換性の問題は発生しませんでした。

### 性能の様子

DS920+（J4125、8 GB RAM）で 1 週間稼働させたデータは次のとおりです。

| 指標 | v1.0.x | v1.1.0 |
|:----|:------:|:------:|
| メモリ使用量 | ~180 MB | ~210 MB |
| CPU アイドル時の使用量 | < 1% | < 2% |
| スクレイピング速度（単一ファイル） | ~8 秒 | ~7 秒 |
| ページ読み込み時間 | ~1.2 秒 | ~1.5 秒 |

新機能によるシステムリソースの消費は妥当な範囲内であり、全体的な性能の様子は満足できるものです。

### 推奨設定

実際のテストを通じて、異なる利用シナリオ向けの設定提案をまとめました。

**ライトユーザー**（家庭での映像鑑賞、2～3 人）：
- Docker のパラメータ：特別な調整は不要
- 有効にするプラグイン：TMDB + JavBus
- 認証するサイト：1～2 か所

**上級ユーザー**（複数サイトの管理、大量のリソース）：
- Docker のパラメータ：`AMMDS__MaxConcurrentScrapes=3` を追加
- 有効にするプラグイン：TMDB + JavBus + FANZA DMM
- 認証するサイト：3～5 か所
- Telegram 通知の有効化を推奨

## 六、展望

v1.1.0 は AMMDS の将来の発展に向けた良好な基盤を築きました。このアップデートから、プロジェクトチームが三つの分野で明確な計画を持っていることがうかがえます。

1. **運用のツール化**：アシスタントページによって運用の複雑さを軽減する
2. **ビジュアルのブランド化**：3D Logo などのデザインで製品の上質感を高める
3. **エコシステムの多様化**：スクレイピングのデータソースとサイト対応を継続的に拡充する

今後のバージョンでより多くの革新的な機能が見られることを楽しみにしています。また、より多くのユーザーが AMMDS コミュニティに参加し、より良いプライベートデータプラットフォームを共に築いていくことを歓迎します。
