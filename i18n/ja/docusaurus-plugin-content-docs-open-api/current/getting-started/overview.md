# オープンプラットフォームでできること

AMMDS でライブラリを整理したあと、**ほかのプログラムにもそのデータを読ませたい**ときに使うのが「オープンプラットフォーム」です。スマホのクライアント、漫画リーダー、自作のバックアップスクリプト、ちょっとした集計ツールなどがこれに当たります。

このページでは「どんな選択肢があって、それぞれ誰向きか」だけを説明します。鍵の作り方と最初の呼び出しは次の二つのページです。

## まず言葉を整理します

> **インターフェース / API**：AMMDS が外向けに開いている扉です。ほかのプログラムが決まった形で問い、AMMDS が決まった形で答えます。住所一つがインターフェース一つで、その集まりを API と呼びます。

> **リクエスト**：ほかのプログラムが AMMDS に送る「これが欲しい」という問いかけです。

> **レスポンス**：AMMDS が返してくる答えの中身です。

> **JSON**：その答えの書式です。`{"code": 200, "data": true}` のような形で、人にもプログラムにも読めます。

> **認証**：入る前に「この人は見てよい人だ」と身分を示すことです。

## どんな人が使いますか

| やりたいこと | 使うもの |
| --- | --- |
| スマホのクライアントで作品ライブラリを見る | オープン API |
| AMMDS の漫画を漫画リーダーで読む | 漫画リーダー |
| データを定期的にファイルへバックアップする | バックアップパッケージ |
| 「何本保存したか」を数える小さなツールを自作する | オープン API |
| 二つの AMMDS の間でデータを移す | バックアップパッケージ |

見たり整理したりするだけでよければ、管理機能のページだけで十分です。ここは読み飛ばしてかまいません。

## 三つの選択肢

| 選択肢 | 住所 | 入り方 | 向いている用途 |
| --- | --- | --- | --- |
| オープン API | `/api/v1/**` | ヘッダーに `x-api-key` | スクリプト・自動化ツール・外部アプリからの作品データ取得と翻訳 |
| 漫画リーダー | `/api/mihon/**` | ヘッダーに `Authorization: Bearer <認証コード>` | Mihon、Tachiyomi などのリーダー |
| バックアップパッケージ | ネットワークの住所はなく、ファイルそのもの | ネットワーク不要 | データを書庫に書き出して別の場所へ取り込む |

ほかにも外部システムとつながる機能が二つありますが、設定は画面側で行い、ここには含まれません。

- **通知の送信**：AMMDS が指定した住所へ向けて知らせを送ります。連携アプリで設定します。
- **AMMDS 同士の連携**：お互いを連絡先に追加し、検索を共有します。管理機能 → メッセージセンターで設定します。

## オープン API で何ができますか

| できること | 住所 |
| --- | --- |
| サービスが動いているか確かめる（鍵は不要） | `/api/v1/health` |
| 作品の取り込み・詳細・件数・ローカル照合・複数ソース検索 | `/api/v1/movie` |
| 文章の言語を判定し、別の言語に翻訳する | `/api/v1/translate` |

:::note[鍵とログインは別物です]
オープン API は鍵だけを見ます。ブラウザのログイン状態は見ません。逆に管理側のインターフェースはログインだけを見て、鍵は受け付けません。両者が交じることはなく、鍵で管理権限を得ることはできません。
:::

## 本体に備わっている一覧

AMMDS にはブラウザで眺められる一覧が用意されています。

| 住所 | 中身 |
| --- | --- |
| `/swagger/swagger-ui.html` | クリックして試せるウェブ版の一覧 |
| `/swagger/swagger-api` | プログラム向けの一覧ファイル |

対象はオープン API・公開サイト・クライアント向けで、管理側のインターフェースは含まれません。

## 設定項目

始める前に決めておくことは三つです。

| 設定項目 | 何を入れるか | 入れない / 間違えた場合 |
| --- | --- | --- |
| インスタンスの住所 | AMMDS が動く機器を `http://<住所>:<ポート>` の形で。ポートは既定値 `8080` | 間違えると何もつながらず、毎回タイムアウトします |
| オープン API のスイッチ | システム → システム設定で ON にします（設定キー `GLOBAL_OPEN_API`） | OFF のままだと、正しい鍵でも入れてもらえません |
| 鍵 | システム → 鍵管理で作成します。種別は X-API-KEY | 未作成、または種別違いだとすべて拒否されます |

## うまくいかないときは

- **つながらない**：ブラウザで `http://<あなたの住所>:8080/api/v1/health/check` を開いてみてください。開ければ住所とポートは合っています。開かなければ、AMMDS が動いているか、ポートが変更されていないかを確認します。
- **毎回権限がないと言われる**：システム → システム設定でオープン API のスイッチが ON かを確認し、次に鍵の種別が X-API-KEY かを確認します。
- **同じ機器ではつながるが、ほかの機器からつながらない**：同じ機器なら `127.0.0.1` を使います。別の機器からは AMMDS 側の LAN 住所を指定します。`127.0.0.1` は使えません。
- **自分のバージョンに何があるか分からない**：上の二つの Swagger の住所を開いてください。動かしているバージョンに実際にあるものが一覧されます。
