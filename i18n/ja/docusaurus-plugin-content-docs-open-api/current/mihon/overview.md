# 漫画リーダーで漫画を読む

AMMDS に漫画を入れておけば、パソコンの前に座らなくても、スマホのリーダーからそのまま読めます。このページでは、どのアプリを入れるか、何を入力するか、うまくいかないときに何が出るかを説明します。

コードを書く必要はありません。手順は「AMMDS で認証コードを発行する」→「アプリに住所と認証コードを入れる」の二つだけです。

## まず言葉を整理します

> **Mihon**：Android 向けの漫画リーダーです。Tachiyomi はその前身で、使い方はほぼ同じです。以下ではまとめて「リーダー」と呼びます。

> **認証コード**：文字の羅列で、そのアプリに発行する入館カードのようなものです。アプリは漫画を取りに来るたびにこれを添えます。

> **認証**：入る前に身分を示すことです。リーダーの場合は、リクエストに認証コードを入れて送ることです。

> **インターフェース / API**：AMMDS が外向けに開いている扉です。リーダーが決まった形で問い、AMMDS が決まった形で答えます。

## どのアプリを入れるか

| やること | 方法 |
| --- | --- |
| リーダーを入れる | スマホに Mihon（または Tachiyomi 系の同等アプリ）をインストールします |
| AMMDS につなげる | AMMDS が配布している Mihon 拡張をインストールします。カスタムサーバーに対応した代替手段を使う場合は、その手段の接続方法に従ってください |

:::note[二種類の証明書は混ぜられません]
リーダーが使うのは**認証コード**で、「まず鍵を手に入れる」にある作品ライブラリ用の鍵とは別物です。リーダー用のコードは漫画を読むためだけのもので、逆も同じです。
:::

## 手順 1：AMMDS で認証コードを発行する

1. AMMDS の管理画面にログインし、**システム → 鍵管理** を開きます。
2. 鍵の作成を選びます。
3. 種別は **Mihon 拡張**（`secret_mihon`）を選びます。
4. 保存したらすぐに認証コードをコピーし、リーダーに貼ります。

この認証コードは、住所が `/api/mihon` で始まるインターフェースでしか使えません。ほかでは使えません。

:::note[アカウントとパスワードでも入れます]
リーダーは AMMDS のアカウントとパスワードでのログインにも対応しています。ただし発行される証明書の有効期限は **2 時間**で、切れたら再度ログインが必要です。普段使いなら認証コードのほうが楽で、単独で無効にもできます。
:::

## 手順 2：アプリに住所を入れる

1. リーダー側で AMMDS 拡張の設定画面を開きます。
2. サーバーの住所に `http://<あなたの住所>:8080` を入れます。
3. 認証コードに、前の手順でコピーした文字列を貼ります。
4. 保存したら、一度漫画ライブラリを更新して一覧が取れるか確認します。

## 設定項目

| 設定項目 | 何を入れるか | 入れない / 間違えた場合 |
| --- | --- | --- |
| サーバーの住所 | AMMDS が動く機器を `http://<住所>:<ポート>` の形で。ポートは既定値 `8080` | 間違えるとつながらず、一覧が出ません |
| 認証コード | システム → 鍵管理で作成。種別は必ず **Mihon 拡張** | 種別違い、または削除済みだと「権限がありません」と出ます |
| 鍵の種別 | 作成時に **Mihon 拡張**（`secret_mihon`）を選ぶ | X-API-KEY にするとリーダーからは毎回拒否されます |
| アカウントとパスワード（任意） | AMMDS のアカウントとパスワード | 2 時間だけ有効な証明書に交換されます。切れたら再ログイン |

:::warning[スマホとパソコンが同じネットワークにいないとつながりません]
AMMDS が家庭内のネットワークで動いている場合、スマホは同じ Wi-Fi につないでください。住所にはパソコンの LAN 住所を書きます。`127.0.0.1` はスマホ自身を指すので使えません。
:::

## つながると何ができますか

| アプリでの操作 | 裏で取っているもの |
| --- | --- |
| 漫画ライブラリを開く | 漫画の一覧。1 ページずつ。更新時刻・題名・ページ数で並べ替えできます |
| 検索 | 題名・作者・シリーズ・分類・タグでの一致 |
| 一冊を開く | 漫画の詳細。作者・あらすじ・ページ数・話数 |
| 話を開く | 話の一覧。番号は昇順に並ぶので飛びません |
| ページをめくる | 各ページの画像 |
| 表紙を見る | 表紙画像。表紙が外部リンクの場合は、アプリがその住所を直接読み込みます |

## 表示と原因の対応表

| 出ている表示 | ありがちな原因 | 対処 |
| --- | --- | --- |
| 権限がありません | 認証コードの種別が「Mihon 拡張」でない、または削除済み | Mihon 拡張の認証コードを作り直します |
| 一覧が空 | 漫画ライブラリにアルバムがない、または話が未取り込み | 先に AMMDS の管理画面で漫画を取り込みます |
| 表紙が出ない | その漫画の表紙が外部リンクで、サーバー側に画像がない | 正常な動作です。アプリが外部リンクを直接読み込みます |
| 画像が開かない | 話のページファイルがデータディレクトリにない | AMMDS のデータディレクトリ内の漫画ファイルがそろっているか確認します |
| つながらない / 時間切れ | 住所やポートが違う、またはスマホと AMMDS が同じネットワークにいない | まずブラウザで `http://<あなたの住所>:8080/api/mihon/health` を開きます。開ければ住所は合っています |

## うまくいかないときは

- **まず住所だけを確かめる**：スマホのブラウザで `http://<あなたの住所>:8080/api/mihon/health` を開いてください。認証コードは不要です。開ければネットワークと住所は問題なく、残るは認証コードだけです。
- **何度も権限がないと言われる**：古い認証コードを削除して作り直してください。種別を「Mihon 拡張」にし、コピー時に文字を落とさないよう注意します。
- **一覧が空だが、ライブラリには確かにある**：AMMDS の管理画面で漫画の取り込みが完了しているか、話まで入っているかを確認してください。
- **しばらくすると再ログインになる**：アカウントとパスワードの方式を使っています。有効期限は 2 時間です。認証コードに替えれば、何度も求められなくなります。
