# このバージョンの変更点（v1.6.84）

v1.6.84 で増えたこと・直ったことを、専門用語なしでまとめました。**これは古いバージョンの保存用ドキュメントです。** 最新版をお使いの場合は、画面右上のバージョン切替で「最新版」を選んでください。

## 増えたこと

### 作品情報を調べられるサイトがひとつ増えました（TMDB）

TMDB は映画・ドラマの情報がまとまっている公開サイトです。接続すると、AMMDS が作品番号からタイトル・あらすじ・出演者・ポスターを調べ、自動でライブラリに登録します。

「連携 → TMDB」でスイッチをオンにし、サイトで発行された認証コードを貼り付けて「テスト」を押せば、設定が合っているか確認できます。

> **認証コード**：「本人が照会している」と示すための長い文字列です。TMDB に登録すれば取得できます。専門知識は不要です。

### 整理済みのライブラリは、足りない分だけ補えます

これまでの整理タスクはファイルを並べ直していましたが、このバージョンでは「足りない分を補う」モードが加わりました。

- フォルダ名・ファイル名は**一切変更しません**。
- 足りない表紙・背景画像・スチル写真と、作品情報を書いた小さなファイルだけを追加します。
- すでにある画像は、明らかに良い画像が見つかったときだけ差し替えます。
- すでにある情報ファイルは足りない項目だけ補い、手で直した内容は残します。

> **情報ファイル（NFO）**：動画と同じ場所に置く小さなテキストファイルです。Emby や Jellyfin などのプレイヤーが、タイトル・出演者・あらすじを表示するために読みます。自分で開く必要はありません。

### 他のプログラム向けの窓口が増えました

タグ・出演者・お知らせ・小説・オンライン検索・システム診断などの外部向け窓口が追加されました。ウェブ画面やスマホアプリだけを使う場合は、読み飛ばして構いません。

## 直ったこと

- Java をインストールせずに動く単体ファイル版（Windows / Linux）で、一部の画面が空になったり `{}` だけ表示されたりする問題を修正しました。
- 使われていない古いファイルを整理し、プログラムを軽くしました。

## アップグレード前の確認

- **データ形式の変更はありません。** いつもどおりプログラムを差し替えるだけで、ライブラリ・アカウント・設定はそのまま残ります。
- 更新後は「システム → システム診断」を一度開いて、状態を確認してください。
- 画面が古いままに見える場合は、ブラウザで `Ctrl` + `F5` を押して再読み込みしてください。
