# 判別を助ける小さな道具

この分類は作品情報を直接提供するわけでも、ダウンロードを担うわけでもありません。しかし前の工程を滑らかにします。判別が正確になり、検索が速くなり、動画を変換でき、字幕を自動で作れます。

> **エンコード（変換）**：動画を別の形式や別の画質に作り直すことです。より多くの機器で再生できるようにします。

> **プロキシ**：まず別のサーバーにつなぎ、そのサーバーから目的のサイトへ行ってもらう仕組みです。手元から直接届かないときに使います。

> **索引（インデックス）**：検索専用に作った一覧です。先に内容を整理しておくことで、検索が速くなります。

> **オブジェクトストレージ**：「入れ物 + ファイル名」でファイルを置くネット上の場所です。各種のネットワークディスクや法人向け保管服務が当てはまります。

## どれが何をするか

| 道具 | 解決すること | 自分で用意が要るか | 既定状態 |
| --- | --- | --- | --- |
| 高徳地図 | 作業台に現在の都市と天気を表示 | 不要。キーを入れるだけ（入れなくても動きます） | 既定オフ |
| クラウドストレージ | 設定を暗号化してバックアップ。S3 なら画像も置ける | 要：WebDAV または S3 の住所とアカウント | 既定オフ |
| DeepSeek | AI 翻訳、判別の補助、Telegram での対話 | 要：住所とキー | 既定オフ |
| FFmpeg | エンコード、形式変換、画面キャプチャ、表紙、再生時間の取得 | 不要。無ければ自動でダウンロード | 既定**オン** |
| FlareSolverr | 一部サイトの「人間か確認」ページを通過する | 要：自分で用意 | 既定オフ |
| MeiliSearch | 上部の検索窓で作品・出演者・漫画などを素早く探せるようにする | 要：自分で用意 | 既定オフ |
| 翻訳サービス | 取得した外国語の題名やあらすじを中国語にする | 経路によってはキーが必要。内蔵の無料経路は不要 | 既定オフ |
| VibeVoice | 動画の台詞を字幕ファイルにする | 任意：本体で運用（模型の取得が必要）か外部サービス | 既定オフ |

## 高徳地図

作業台の天気カードに、現在の都市と天気を出します。出口となるネットワークから都市を推定しますが、都市を固定することもできます。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフなら入力したキーを使いません |
| サービス住所 | 既定 `https://restapi.amap.com`。プロキシやミラーを使うなら変更 | 間違えると天気の読み込みが失敗します |
| API キー | 高徳オープンプラットフォームで申請。**服務プラットフォームは「Web 服務」を選ぶ** | 空なら内蔵の枠に戻ります。天気は出ますが、精度と残量は内蔵枠次第です |
| 都市コード | 都市の数字コード。例：北京 `110000`、上海 `310000` | 空なら出口のネットワークで推定。書式は 3〜6 桁の数字で、外れれば未設定とみなします |

:::tip[都市を固定すると安定]
サーバーがプロキシや VPN の内側にあると、推定が機械室のある場所になることがあります。都市コードを入れれば、天気はいつでも気になる都市のものになります。
:::

「接続テスト」はサービス住所に対する健康診断だけで、キーは確認しませんし、天気も返りません。

## クラウドストレージ

「クラウドストレージ」は WebDAV と S3 という独立した二つのプラグインからなり、「暗号化バックアップ + 単位ごとの復元」という同じ考え方を共有します。

| 能力 | WebDAV | S3 互換オブジェクトストレージ |
| --- | --- | --- |
| 設定の暗号化バックアップ | 対応 | 対応 |
| 設定の復元 | 対応 | 対応 |
| 画像などの資源を置く | **非対応** | 対応（別のスイッチが必要） |
| 暗号化の合言葉 | 独立 | 独立。WebDAV とは影響し合いません |

:::warning[WebDAV の位置づけ]
WebDAV は枠が限られがちで、大量の画像には向きません。画像などを遠くに置きたいなら S3 を使ってください。
:::

### バックアップの範囲

バックアップには**設定類**だけが入ります。作品の項目、画像、メタデータといった大きな中身は入りません。

| 単位 | 中身 |
| --- | --- |
| システム設定 | ドメインの紐づけ、システムモード、ディスク監視、広告のスイッチなど |
| 連携プラグインの設定 | 各プラグインの設定 |
| 外観とテーマ設定 | テーマ、背景、追悼モード、着地ページ |
| 個人とホーム設定 | 愛称、メール、電話番号、公開ホームのテーマ（肖像は含みません） |
| 口の鍵 | 公開口の利用鍵と有効期限 |
| 処理とスキャン規則 | スキャンの定義、実行種類、予定規則 |
| 購読規則 | 購読キーワード、一致規則、自動ダウンロードの方針 |
| 管理画面の設定 | 管理メニュー、タブ、テーマ色など |

既定で選ばれている単位は `system,plugin,user,secret,task,subscribe` です。

### 設定項目の説明（WebDAV）

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフならバックアップしません |
| サービス住所 | プロトコルを付ける。例：`https://dav.example.com` | 空だと接続テストが失敗します |
| 保存ディレクトリ | 既定 `ammds-backup`。空ならサービスの根 | 無いときは接続テストが自動で作ります |
| アカウント | 空なら匿名 | 認証が要るのに空だとつながりません |
| パスワード | ログインパスワード。口は平文を返しません | 同上 |
| 自己署名証明書を許可 | 既定オフ。自前なら オン | オフだと自己署名の証明書が失敗します |
| バックアップ暗号化 | 既定**オン**。AES-256-GCM で暗号化 | オフなら平文のバックアップになります |
| 暗号化の合言葉 | 鍵を導き出すために使用 | **失うと復元できません** |
| 復元方針 | 既定「統合更新」。他に「手元優先」「遠隔優先」 | 選び間違いで、復元後の値が望みと違います |
| バックアップ単位 | コンマ区切りの単位コード。既定 `system,plugin,user,secret,task,subscribe` | 選んでいない単位は入りません |
| 保持数 | 既定 `5`。超えた古い分を自動で掃除。`0` は無制限 | 小さすぎると古いバックアップが消えます |

### 設定項目の説明（S3）

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | バックアップも資源の保存もこれに依存 |
| S3 サービス住所 | 例：`https://s3.us-east-1.amazonaws.com` や自前の MinIO 住所 | 空だとつながりません |
| S3 地域 | 既定 `us-east-1` | 合わないと署名が失敗します |
| S3 バケット | 先にサービス側で作っておく | 無いと接続テストが失敗します |
| S3 接頭辞 | 既定 `ammds-backup`。バックアップの書き先のディレクトリ | 合わないと一覧が空になります |
| S3 アクセスキー / シークレットキー | 鍵の組。口は平文を返しません | 間違えると署名が失敗します |
| S3 パス形式アドレス指定 | 既定**オン**。MinIO など自前では概ね必要、大手クラウドではオフ推奨 | 合わないとつながりません |
| 自己署名証明書を許可 | 既定オフ | 自前で自己署名ならオン |
| 資源を S3 へ保存 | 既定オフ。オンで新しく上げた画像を S3 へ。手元にも控えを残す | オフなら移りません。オンにする前にあった手元の資源は自動では移りません |
| 資源アクセスの接頭辞 | 空なら本システム経由で読みます。入れると直接連結でき、配信網にも接続可 | 間違えると画像が開きません |
| 手元の控え | 既定**オン**。S3 から読んだ資源の写しを残す | オフなら毎回 S3 まで取りに行き、通信が増えます |
| 暗号化 / 合言葉 / 復元方針 / 単位 / 保持数 | 意味は WebDAV と同じ。合言葉は別 | 同上 |

### バックアップと復元の手順

1. 「設定情報」で接続、暗号化、復元方針を入力して保存します。
2. 「単位バックアップ管理」で残したい単位を選び、「単位を保存」を押します。
3. 「バックアップと復元」で任意のメモを入れ、「今すぐバックアップ」を押します。
4. 終わると一覧が更新され、ファイル名、生成時刻、大きさ、暗号化の有無が見られます。
5. 戻したいときは「復元」を押し、方針を選んで合言葉を入れ、確認して書き込みます。

| 復元方針 | 動作 |
| --- | --- |
| 統合更新 | 足りないものと差分だけを埋めます |
| 手元優先 | 手元に無い設定だけを足し、手元の値を残します |
| 遠隔優先 | バックアップの中身で手元の設定を上書きします |

:::warning[合言葉を失うと復元できない]
合言葉は手元で鍵を導くためだけに使われ、サーバーは平文を保存しません。別の場所に控えてください。また、復元のときに WebDAV や S3 自身の接続設定と合言葉は上書きされません。復元後にまたバックアップできるようにするためです。
:::

## DeepSeek

DeepSeek は大きな言語模型を AMMDS につなぎます。AI 翻訳、判別の補助、Telegram での対話に使います。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと残高と模型のカードが出ず、裏での呼び出しも未使用扱い |
| サービス住所 | 既定 `https://api.deepseek.com`。中継や自前プロキシなら変更 | 空だと「先に接続住所を設定してください」が出て要求しません |
| API キー | 呼び出しの証明 | 無いと残高も模型も対話も使えません |
| 推論模型 | 既定 `deepseek-v4-pro`。直接入力も、模型一覧の「採用」でも可 | 古い名は置き換えられます：`deepseek-chat` → `deepseek-v4-pro`、`deepseek-reasoner` → `deepseek-v4-flash` |
| 模型の温度 | 既定 `0.7`。大きいほどゆらぎ、小さいほど安定 | 通常は変更不要 |
| 文脈長 / 出力長 | 既定 `1M` / `384K`。**能力の表示だけで、要求には使われません** | 変えても実際の要求には影響しません |

### 画面でできること

| 区域 | 中身 |
| --- | --- |
| アプリ情報 | 名称、ロゴ、公式サイト、文書、連携版、紹介 |
| 設定情報 | 上の表の各項目。「設定を再読込」「設定を保存」 |
| 残高 | 有効化後に出現。通貨別に総額、進呈分、入金分を表示。使えるときは緑の「アカウント利用可」、不足は赤の「残高不足」 |
| 模型一覧 | 有効化後に出現。模型 ID、帰属、作成時刻。「採用」で設定に書き戻し、使用中は「使用中」 |
| 接続テスト | 現在のサービス住所で健康診断 |

:::note[同時実行と失敗]
模型ごとに制限があります。`deepseek-v4-pro` は 500、`deepseek-v4-flash` は 2500 まで。枠が取れなければ最大 30 秒待ち、だめなら「同時リクエストが満杯」を返します。429 は失敗として扱われ、プラグイン側では自動再試行しません。
:::

## FFmpeg

FFmpeg は音と動画の処理の土台です。エンコード、形式変換、画面キャプチャ、表紙の切り取り、縮小画像、そして再生時間と解像度の取得を担います。**既定で有効**です。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | 既定**オン** | オフで新しいエンコード / 変換処理が作れなくなります（既存の処理には影響しません） |
| 処理数 | 既定 `2`。1〜5。種類ごとに数えます | 大きすぎると処理装置を占領します |
| エンコード出力方式 | 既定「接尾辞を付ける」（他に「統一ディレクトリ」） | 「統一」なのにディレクトリが空だと失敗 |
| エンコード統一出力ディレクトリ | 出力方式が「統一」のときに使用 | 同上 |
| エンコード既定の接尾辞 | 既定 `transcode`。ファイル名の後ろに付く | 通常は変更不要 |
| 形式変換の出力方式 | 既定「元ディレクトリに同名出力」（他に「統一」） | 同上 |
| 形式変換の統一出力ディレクトリ | 出力方式が「統一」のときに使用 | 同上 |
| エンコード既定の動画符号化 | 既定 `libx264`。他に `libx265` | 部品が無いと「符号化器が無い」と出ます |
| エンコード既定の事前設定 | 既定 `veryfast`。`ultrafast` から `veryslow` まで | 遅いほど小さくなりますが時間がかかります |
| エンコード既定の品質 (CRF) | 既定 `23`。18〜28 が目安。小さいほど高画質で大きい | 目安を外れると大きさや画質が大きく変わります |
| 並び待ち | 既定**オン**。処理数を超えた分は順番待ち | オフだと超えた分が即失敗 |
| 処理の再開 | 既定**オン**。再起動後に未完了の処理を自動で再開 | オフだと未完了が失敗になり、手で再試行が必要 |

### 部品の管理

- 部品は手元の `data/ffmpeg` に入り、OS と処理装置に合うものが選ばれます。
- 起動後に確認し、**無ければ自動で非同期ダウンロードして毎分再試行**します。32 ビットには対応しません。
- 「資源ダウンロード」カードでファイル名、状態、進み具合、場所が見られ、**不足部品のダウンロード**、**状態を更新**、**削除**ができます。

:::note[ダウンロードが途中で止まったら]
状態は未開始、ダウンロード中、完了、失敗などです。止まった部品は削除して取り直せばよく、もう一方には影響しません。
:::

エンコードの入口は**ツールボックス → 動画エンコード**、形式変換は**ツールボックス → 形式変換**です。

## FlareSolverr

一部のサイトは本文の前に「ブラウザを確認しています」のようなページを出し、普通の要求ではそのページしか取れません。FlareSolverr はこの種のページを処理する専門のサービスで、AMMDS は取得を任せられます。

> **確認ページ / 人間か確認**：サイトが「プログラムではなく本物のブラウザか」を確かめるための間のページです。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフなら使わず、要求は元の道筋で出ます |
| サービス住所 | 既定 `http://127.0.0.1:8191`。動いている FlareSolverr を指す。プロトコルとポートが必要 | 空なら「先に接続住所を設定してください」。別の機械なら実際の住所に |
| プロキシ設定を同期 | 既定**オン**。システムのネットワークプロキシを渡す | コンテナ内では `127.0.0.1` は自分。その機械が直接外に出られるなら同期をオフに |
| 時間切れ | 既定 `60` 秒。二段階の確認が遅いサイトなら 90〜120 秒に | 大きすぎると失敗した要求が長く接続を占めます |

:::note[独立したサービス]
AMMDS はダウンロードも、預かりも、起動もしません。自分でコンテナか実行ファイルとして動かしてください。プラグインは住所を保存して呼ぶだけです。
:::

### オンにすべきとき、そうでないとき

| 場面 | 向くか |
| --- | --- |
| 相手が「ブラウザを確認しています」のようなページを出す | 向く |
| 普通の静的なサイト、公開された口 | 不要。オンだと毎回ひと手間増えます |
| ログインや支払いが必要、または相手があなたの住所を拒否 | 不向き。アカウントや権限の代わりにはなりません |
| 401 / 403 が返るが確認ページは無い | 不向き。まずキーとアカウントの状態を確認 |

「接続テスト」は AMMDS が FlareSolverr に届くかだけを確認し、相手サイトが確認を通れることは保証しません。

## MeiliSearch

MeiliSearch は全文検索の仕組みです。設定すると作品、ドラマ、出演者、漫画、小説、資訊が索引に書き込まれ、公開サイトと上部の検索窓がその索引を参照します。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと索引作りも検索も行わず、公開の検索口は空を返します |
| サービス住所 | 既定 `http://192.168.10.24:7700` は**例示の住所**です。必ず自分の住所に変更。プロトコルとポートが必要 | そのままなら必ずつながりません |
| API キー | 索引と検索の認証キー。再構築には**書き込める**キーが必要 | 権限不足で再構築が失敗します |
| 自動索引 | 既定**オン**。定期的に全種類を全量で作り直します | オフだと手動のみで、新しい作品が索引に入りません |

### 索引の管理と再構築

「索引管理」は種類ごとに再構築し、毎回**全量**です。

| 選択 | 中身 |
| --- | --- |
| 全部 | 全種類を順に作り直します（作品、ドラマ、出演者、漫画、小説、資訊） |
| 作品 | 作品の題名、作品番号など |
| 出演者 | 出演者の姓名、別名など |
| 漫画 | 漫画の題名、作者など |
| 小説 | 小説の題名、作者、シリーズなど |
| 資訊 | 資訊の項目 |

「索引を再構築」を押すと、種類ごとに書き込んだ件数が表示されます。例：`movie=1024, actor=356`。再構築は「その種類を空にしてから分割して書き込む」方式なので、その間は検索結果が一時的に空になったり不足したりします。

:::tip[初回は手で一度作り直す]
新しく入れたときや、データが大きく変わったあとは、まず手で「全部」を一度作り直し、その後は自動索引に任せるのがおすすめです。自動索引がオンでサービスが使えれば、起動から約 5 分後に初回の全量を作り、以後は一時間ごとです。
:::

「検索テスト」は索引を読むだけで、データは変えません。見つからないときは、その種類が再構築済みかを確認してください。

## 翻訳サービス

翻訳サービスは、取得した外国語の題名・あらすじ・タグを中国語にします。道筋は二つで、AMMDS 内蔵の翻訳か、MetaTube に任せるかです。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態（画面では「翻訳を有効化」） | スイッチをオン | オフだと翻訳の要求が「翻訳サービスが未使用」を返します |
| AI 優先 | 既定オフ。オンで先に AI 翻訳を試し、全滅なら機械翻訳を順に試す | オフなら内蔵の順序で進みます |
| 既定の翻訳方式 | 既定 `ammds`（内蔵）。他は `metatube` | `metatube` なのに MetaTube 側で翻訳がオフなら結果が出ません |
| 題名 / 説明 / タグ / 既定の翻訳プロンプト | 内蔵の英語雛形。自分で書けます。変数 `{source_lang}`、`{target_lang}`、`{content}` が使えます | 書き間違いはエラーではなく、訳の質に出ます |

:::note[簡体字中国語のみ]
情報取得の流れでは、外国語を簡体字中国語に固定で訳します。元の言語は自動判定で、この画面に対象言語の設定はありません。また、情報取得設定の「項目翻訳」は既定でオフなので、オンにしないと翻訳されません。
:::

### 内蔵翻訳の提供者

内蔵翻訳は使えない提供者を除き、優先度順に試して最初の成功を返します。

| 分類 | 提供者 | 入力が必要なもの |
| --- | --- | --- |
| 機械翻訳 | DeepL | サービス住所、端点、認証コード |
| 機械翻訳 | DeepLX | サービス住所、端点、認証コード |
| 機械翻訳 | 谷歌翻訳Free | 不要 |
| 機械翻訳 | 微軟翻訳Free | 不要 |
| 機械翻訳 | 百度翻訳 | サービス住所、端点、アプリ ID、キー |
| 機械翻訳 | 小牛翻訳 | サービス住所、端点、アプリ ID、アプリキー |
| 機械翻訳 | 彩雲翻訳 | サービス住所、端点、トークン |
| 機械翻訳 | 騰訊翻訳 | サービス住所、地域、プロジェクト ID、SecretId、SecretKey |
| AI 翻訳 | OpenAI 互換 | サービス住所、端点、キー、模型、温度、指示文 |
| AI 翻訳 | Gemini 互換 | サービス住所、端点、キー、模型、温度、指示文 |
| AI 翻訳 | Anthropic 互換 | サービス住所、端点、キー、模型、温度、指示文 |

提供者はカードで表示され、オンライン / オフライン状態と優先度が見られ、有効スイッチ、**テスト**、編集、削除ができます。

:::tip[AI 優先の実際]
「AI 優先」は AI を前に並べるだけではありません。道筋が AI の提供者を機械翻訳より前にまとめて並べ、AI が全滅しても機械翻訳を続けて試します。手で保険をかける必要はありません。
:::

`metatube` を選ぶと、翻訳の要求は MetaTube に回り、その画面で維持している引擎とキー（Google、OpenAI、DeepL、Baidu など。選んだもののキーが必要）を使います。

### 翻訳テスト

| 項目 | 内容 |
| --- | --- |
| テスト内容 | 翻訳したい文 |
| 翻訳結果 | 読み取り専用の出力 |
| 内容の種類 | 現在は「汎用」のみ |
| 翻訳方式 | 機械翻訳 / AI 翻訳 / 自動 |
| 元の言語、対象の言語 | 言語表から選択 |

使える言語コード：`auto`（元の言語のみ、自動判定）、`zh`、`cht`、`en`、`ja`、`ko`、`ru`、`cs`。提供者が対応しない言語は飛ばされます。

## VibeVoice

VibeVoice は動画の台詞を字幕ファイル（`.srt`）にします。手元で運用することも、外のサービスにつなぐこともできます。

> **音声認識**：動画の中の話し言葉をプログラムに聞き取らせ、文字に書き出させることです。

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 接続方式 | 既定 `local`（手元で運用）。他は `remote`（外部サービス） | local では住所、キー、模型名が表示されません |
| 有効状態 | スイッチをオン | オフだと字幕処理が作れず、ツールボックスの入口に未使用と出ます |
| サービス住所 | 既定 `http://127.0.0.1:8000`。ローカルは自動写入、リモートは手入力 | リモートで間違うと検出が失敗 |
| API キー | 任意。サービス側が認証をしていなければ空 | 認証が要るのに空だとつながりません |
| 認識模型名 | 既定 `vibevoice-asr`。サービスが読み込んだ模型と一致させる | 不一致だと認識が失敗 |
| 最大同時処理数 | 既定 `1`。1〜5 | 手元の推論は記憶を多く使うため、順番実行がおすすめ |
| 処理あたりの最大スレッド | 既定 `4`。サービスへの助言として転送 | 通常は変更不要 |
| 1 区間の最大分数 | 既定 `3`。上限 60 | 長すぎると手元の推論が落ち、字幕の後半が欠けます |
| 模型の倉庫 | 既定 `microsoft/VibeVoice-ASR-BitNet`。模型ダウンロードで使用 | 通常は変更不要 |
| 模型ファイル名 | ダウンロード完了時に自動写入。空は未取得 | 空なら模型が未準備 |
| 起動器の優先 | 既定 `asr_infer` | 下を参照 |
| 字幕の生成場所 | 既定 `video_dir`（動画と同じ場所）。他は `unified`（統一ディレクトリ） | 「統一」なら `data/subtitles/vibevoice/` に処理 ID 名で書かれます |

| 起動器 | 働き | 向き |
| --- | --- | --- |
| `asr_infer`（推奨） | 区間ごとに独立した工程で一度だけ推論 | 既定。常駐の記憶が不要で速い |
| `asr_stream_server` | 常駐して流し込みで応える。約 2.5 GB 常駐 | 区間ごとの再読み込みを避けたいときだけ |

### ローカル方式の準備

1. プラグイン画面で接続方式に「ローカル」を選びます。
2. 「内蔵サービス → 起動器ダウンロード」で推論プログラムを取得し、準備完了になるまで待ちます。
3. 「模型ダウンロード」で倉庫が公式のものかを確認し、「模型をダウンロード」を押して二つのファイル（合計 約 1.5 GB）を待ちます。
4. 「サービスを起動」を押し、状態が「動作中」になりポートが表示されるのを確認します。
5. 「サービス検出」で「サービスを検出」を押し、接続済みで読み込まれた模型に `vibevoice-asr` が含まれるかを確認します。

### 字幕を作る

入口は**ツールボックス → 字幕生成**です。プラグインが未使用なら先に有効化するよう出ます。

1. 「字幕処理を新規」を押し、単一の動画かディレクトリを選びます。
2. 認識言語を選びます（既定は自動判定）。二か国語にしたければ「二言語字幕」をオンにして対象言語を選びます。
3. 送信すると処理が並びに入り、一覧に動画、長さ、言語、二言語、状態、進み具合、作成時刻が出ます。

| 状態 | できる操作 |
| --- | --- |
| 実行中 / 並び待ち / 翻訳中 | 中止 |
| 失敗 / 中止済み | 再試行 |
| 完了 | 詳細、閲覧、編集、ダウンロード、翻訳 |

完了した処理は、その字幕をもとに「翻訳処理」をもう一本作れます。音声認識を飛ばして直接翻訳し、言語の接尾辞が付いた新しい字幕ができます。

## 困ったときは

- **天気がずっと読み込み失敗**：サーバーが `restapi.amap.com` に届いていません。接続テストで確認し、外への出入りとプロキシを見ます。
- **都市の推定が違う**：出口が機械室やプロキシのものです。都市コードを手で入れてください。
- **バックアップ一覧が空**：接続の設定が違う、またはそのディレクトリ / 接頭辞にバックアップが無い。先に接続テストを。
- **復元で合言葉が違うと言われる**：バックアップ時のものと違います。失ったら復元できません。
- **S3 は住所に届くのに接続できない**：地域、住所の指定方式、署名の不一致。自前ならパス形式をオンに試してください。
- **DeepSeek の残高や模型一覧が空**：先に接続テストで住所を確認し、キーを見直します。模型一覧の権限が無いなら模型名を直接入力してください。
- **「同時リクエストが満杯」**：同じ模型が上限です。少し待つか `deepseek-v4-flash` に替えます。
- **「符号化器が無い」と出る**：部品が無いか壊れています。資源ダウンロードで削除して取り直します。
- **エンコードが全部失敗**：並び待ちがオフで同時実行が満杯です。並び待ちをオンにして再試行。
- **FlareSolverr が拒否または時間切れ**：サービスが動いていない、ポートが違う、または防火壁で塞がれています。8191 番が待ち受けているか確認。
- **FlareSolverr をオンにしても取得が失敗**：確認ページではなくログインや拒否です。アカウント、キー、または出口のネットワークを見直します。
- **MeiliSearch につながらない**：住所が例示のまま、ポートが開いていない、またはキーの権限不足です。
- **検索で見つからない**：その種類がまだ再構築されていません。一度作り直して再試行。
- **「翻訳サービスが未使用」**：翻訳プラグインの「有効状態」をオンに。情報取得後も中国語が無ければ、情報取得設定の「項目翻訳」を確認。
- **VibeVoice のサービス検出が失敗**：ローカルなら先に「サービスを起動」。リモートなら住所とキーを確認。
- **字幕の後半が欠ける**：区間が長すぎて推論が落ちました。「1 区間の最大分数」を下げるか `asr_infer` に替えます。
