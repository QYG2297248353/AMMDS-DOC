# 外部サービスをつなぐ、たった三つの手順

AMMDS は作品の情報を自分で作り出すわけではありませんし、ファイルを代わりにダウンロードすることもありません。表紙を自動で補ったり、資源を探したり、通知を送ったりするには、「連携アプリ」で外部サービスを一つずつつなぐ必要があります。

どのサービスでも手順は同じです。**有効化 → 情報を入力 → テスト** の三つです。個別の入力内容は、この章のほかのページをご覧ください。

## まずは連携アプリとは何か

> **連携アプリ**：AMMDS が外部サービスをまとめて管理する場所です。ここに住所（アドレス）とアカウント情報を入力すると、AMMDS はその設定に従ってサービスを利用します。

> **外部サービス**：AMMDS 本体の機能ではなく、別のサイトや別の機械で動いているプログラムのことです。情報サイト、ダウンロードソフト、プレイヤーなどが当てはまります。場所と利用者情報を AMMDS に教えることで、両者がつながります。

> **設定項目**：設定ページで入力する欄や、オンにするスイッチのことです。どれも該当ページの表で説明しています。

## 六つの分類、それぞれの役割

サイドバーは用途別に六つに分かれています。

| 分類 | 担当 | 含まれるもの |
| --- | --- | --- |
| メタデータ | 作品・ドラマ・出演者の表紙、あらすじ、出演者一覧 | MetaTube、TMDB、TheTVDB、Bangumi、ThePornDB、TheJavDB、R18.dev、FANZA DMM、麻豆 |
| サイト資源 | どのサイトで資源を探すか | M-Team、NexusPHP、Rousi、FSM、Prowlarr、BitMagnet |
| ダウンローダー | 見つけた資源を何がダウンロードするか | qBittorrent、Transmission、IYUU |
| メディアサーバー | 整理した情報をどのプレイヤーに渡すか | Jellyfin、Emby |
| 通知 | 処理が終わったら誰に知らせるか | Bark、Telegram、Webhook |
| 補助ツール | 判別を助ける小さな道具 | FFmpeg、翻訳、DeepSeek、VibeVoice、MeiliSearch、FlareSolverr、高徳地図、クラウドストレージ |

:::note[もう一つの分類]
サイドバーには「クラウド同期」という分類もあります。設定をネットワークストレージへバックアップするためのもので、作品情報の取得には関わりません。
:::

## 必須のものと後回しにできるもの

| やりたいこと | 必須 | いまは不要なもの |
| --- | --- | --- |
| 作品名を判別し、表紙やあらすじを補う | メタデータ源を一つ以上、加えて情報取得の実行 | 源を増やすと命中率は上がりますが、一つでも動きます |
| 資源を探して自動ダウンロード | サイト資源を一つ以上 + qBittorrent | Prowlarr、BitMagnet は控えなので後からで十分です |
| テレビで整ったポスター一覧を見る | Jellyfin か Emby のどちらか | 両方でも構いません。再生統計は合算されます |
| スマートフォンに通知を受け取る | 通知経路をどれか一つ、加えて通知のマスタースイッチ | Telegram はボタン操作にも対応しますが必須ではありません |
| ファイルをスキャン・変換できるようにする | FFmpeg（既定で有効） | 変換しないなら触らなくて大丈夫です |
| 上部の検索窓で見つけられるようにする | MeiliSearch | 一覧の絞り込みは使えますが、全体検索は空になります |

:::tip[一つずつ足す]
一度に全部オンにしないでください。まずメタデータ源を一つ動かし、それから次を足すほうが、問題の場所がすぐ分かります。
:::

## 手順

1. **開く**：連携アプリを開き、左側の分類を展開して目的の項目をクリックします。
2. **「有効状態」をオンにする**。入力だけしてこのスイッチをオンにしないと、何も動きません。
3. **情報を入力**：サービスアドレス、キーやトークン、アカウントとパスワードなどです。入力したら右上の**設定を保存**を押します。保存成功の表示が出て初めて書き込まれます。
4. **子スイッチをオンにする**：「作品検索」「ドラマ検索」「ランキング収集」「メタデータ検索」など、項目ごとの細かなスイッチがあります。用途に合わせてオンにして保存します。
5. **「接続テスト」を押し**てアドレスに届くか確認し、続けて「検索テスト」で実際にデータが取れるか確認します。

:::warning[「届く」と「使える」は別]
多くの接続テストは、相手が何か一言でも返せば成功と判定します。「権限がありません」と返ってきても成功です。したがってテストが通るのに検索結果が空なら、ネットワークではなく、キー・残量・子スイッチ・キーワードを確認してください。
:::

## 設定項目の説明

どの設定ページも、同じ種類の部品でできています。

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オンにしない限り、あとに何を書いても反映されません |
| サービスアドレス | 相手のサービス住所。`http://` か `https://` を付けます | 空欄や間違いで接続テストが失敗します。コンテナ内で `127.0.0.1` を書くと自分自身を指します |
| キー / トークン / API キー | サイトから発行される文字列。鍵のようなもので、持っている人があなたとして利用できます | 空欄や間違いは「つながるのに結果が空」「401 / 403 が返る」として現れます |
| アカウント / パスワード | ダウンローダーやメディアサーバーのログイン情報 | 間違いは「接続テストは通るのに情報取得が失敗する」として現れます |
| 子スイッチ（作品検索、ドラマ検索、ランキング収集、メタデータ検索） | 用途に合わせてオン | オフだとその処理に参加しません。例：ドラマがずっと見つからない |
| リクエスト間隔 | 二つのリクエストの間に空ける最小ミリ秒 | 小さすぎるとサイトの速度制限に当たり、頻繁なタイムアウトや 429 が返ります |
| 言語 | 取得したい文字の言語。例：`zh-CN` | 間違えてもエラーにはならず、翻訳が取れず原文のままになります |

設定カードの右上には、もう二つボタンがあります。

| ボタン | 働き |
| --- | --- |
| 設定を再読込 | 保存していない変更を捨て、保存済みの値を読み直します |
| 設定を保存 | ページ内のすべてを送信し、すべて成功したときだけ「保存成功」と表示されます |

:::note[保存は過去にさかのぼりません]
保存した設定は**これ以降**の処理にだけ効きます。すでに終わったスキャンや情報取得をやり直してはくれません。優先度・言語・画像アドレスを変えたら、情報取得をもう一度実行して結果を確認してください。
:::

## 鍵は大切に

次のものは資格情報です。漏れると、残量を他人に使われたり、あなたとしてサイトを利用されたりします。

- MetaTube のトークンと各翻訳サービスのキー
- TMDB の認証コード
- TheTVDB のキーと購読 PIN
- Bangumi の認証トークン
- ThePornDB のキーと Stash クライアントのキー
- M-Team のパスキー、アクセストークン、臨時認証コード
- 各サイトのサイトトークン、パスキー、API トークン
- IYUU、Telegram、Bark のトークン

大切な点をいくつか：

- 資格情報は自分のデータベースに保存され、設定ページには現在の値が表示されます。管理アカウントとデータベースへのアクセス権を絞り、バックアップファイルも厳重に保管してください。
- 管理画面のアドレスをそのままインターネットに公開しないでください。
- **スクリーンショット、質問投稿、グループチャット、ログにキーをそのまま貼らないでください**。漏れた疑いがあれば、まず該当サイトで無効化し、新しいものを発行して貼り直します。
- 使わない項目はオフにして、キーも消しておくことをおすすめします。
- TMDB の認証後、画面に戻るのはアカウント ID とトークン末尾 4 桁だけで、完全なトークンは表示されません。Bangumi のトークンは認証の戻り先で自動的に書き込まれるため、手で写す必要はありません。

## 困ったときは

- **保存したのに動かない**：「有効状態」と関連する子スイッチが、両方オンになって保存されているか確認してください。二つ同時に必要な項目もあります。
- **接続テストが失敗する**：アドレスのプロトコルとポートの書き間違いを確認します。Docker で動かしている場合は `127.0.0.1` を使わないこと。そのうえで、その機械が外に出られるかを確認します。
- **テストは通るのに検索が空**：たいていはキーが無効、残量切れ、子スイッチがオフ、またはキーワードがその源の判別できる書式でないかのいずれかです。
- **401 か 403 が返る**：トークンの期限切れか権限不足です。サイト側で作り直してください。
- **429 が返る、またはよく時間切れになる**：速度制限に当たっています。リクエスト間隔を大きくします。
- **画像が表示されない**：画像アドレスが遮られているか、サイトが直リンクを禁止しています。
