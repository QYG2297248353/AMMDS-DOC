# 作品情報はどこから来るか

表紙・あらすじ・出演者・タグといった情報は、AMMDS が自分で作っているわけではなく、外部の情報サイトから取ってきたものです。このページでは全ての情報源を並べて、それぞれ何が得られるか、何が必要か、どう有効化するか、そして複数を同時に使ったときにどの結果が採用されるかを説明します。

> **メタデータ源**：作品情報を提供する外部サイトです。AMMDS がファイル名の番号を渡して問い合わせると、表紙・あらすじ・出演者などが返ってきます。

> **スクレイピング（情報取得）**：AMMDS が情報サイトで作品を調べ、その結果を自分のライブラリに書き込む一連の流れです。

> **作品番号**：ファイル名に含まれる識別番号です。例：`SSIS-001`。AMMDS は主にこれで作品を判別します。

## まずは一つ選ぶ

:::tip[全部は要りません]
十の情報源を全部オンにする必要はありません。まず届くものを一つ選んで動かし、それから二つ目を検討してください。増やすほど命中率は上がりますが、設定と管理の手間も増えます。
:::

| 情報源 | 得られるもの | 準備するもの | 既定状態 |
| --- | --- | --- | --- |
| MetaTube | 番号系作品の題名、あらすじ、発売日、収録時間、評価、出演者、監督、メーカー、レーベル、シリーズ、ジャンル、劇場写真。出演者のプロフィール | 任意：内蔵サービスを使うか、リモートの住所とトークンを入力 | 既定オフ |
| TMDB | 映画・ドラマ・出演者の題名、あらすじ、劇場写真、スタッフ | 認証コード（ボタンの認証で自動写入も可）。アカウント ID は任意 | 既定オフ |
| TheTVDB | ドラマのシーズンとエピソード構成。映画も検索可 | API キー（必須）。キーの種類によっては購読 PIN | 既定オフ |
| Bangumi | アニメ作品の題名、あらすじ、各話、キャラクターと声優、スタッフ | 検索だけなら不要。アカウント系機能は認証が必要 | 既定オフ |
| ThePornDB | 作品と出演者の情報。自前または公開の Stash-Box にも接続可 | API キー。Stash クライアントは別にエンドポイントとキー | 既定オフ |
| TheJavDB | 番号から題名、発売情報、出演者、分類、見本画像 | 不要。住所に届けば使えます | 既定オフ |
| R18.dev | オンラインの番号検索、または公式データパックを取り込んでのオフライン検索 | オンラインは住所が必要。オフラインはデータパックが必要 | 既定オフ |
| FANZA DMM | 作品検索とランキング（本日の新作、近日公開） | 不要。アカウントもキーも要りません | 既定オフ |
| 麻豆 | 作品と出演者をまとめて同期 | サービス住所。ページ上部にサービス終了の告知あり | 既定オフ |
| M-Team DMM | M-Team の DMM 経由で作品情報を検索し、そのまま取り込めます | M-Team のアクセストークン（サイト資源と同じ設定ページ） | 既定オフ |

## 共通の三手順

どれを設定するときも流れは同じです。詳しくは[外部サービスをつなぐ、たった三つの手順](./overview.md)をご覧ください。

1. **「有効状態」をオン**にし、必要な子スイッチ（作品検索、ドラマ検索など）も一緒にオンにします。
2. 住所やキーを入力し、**設定を保存**を押します。
3. **「接続テスト」**で住所に届くかを確認し、**「検索テスト」**で本当にデータが取れるかを確認します。

:::warning[スイッチは二つとも]
多くの情報源には「作品検索」「ドラマ検索」「メタデータ検索」といった子スイッチがあります。元のスイッチだけでは検索に参加しませんし、ランキングも集めません。
:::

## MetaTube

MetaTube は複数の作品サイトと出演者サイトをまとめたサービスです。一度の設定で多くのサイトをカバーでき、ついでに題名やあらすじを中国語に翻訳することもできます。AMMDS は本体に内蔵されたプロセスを使うことも、自分で用意したリモートサービスを使うこともできます。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → MetaTube |
| 内蔵サービス | 「内蔵サービスを優先」がオンで、本体のプロセスが動いているときに使用。既定の待ち受けは 18080 番ポート |
| リモートサービス | そのスイッチをオフにしたとき、または内蔵プロセスが動いていないときに使用 |
| 得られるもの | 題名、作品番号、発売日、収録時間、評価、出演者、監督、メーカー、レーベル、シリーズ、ジャンル、あらすじ、劇場写真。出演者の誕生日・国籍・身長・スリーサイズ・血液型 |
| 準備するもの | リモートなら住所とトークン。内蔵ならプログラムが無ければ自動でダウンロードされます |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと情報取得に参加しません |
| 内蔵サービスを優先 | 既定オン。リモートを使うならオフ | 内蔵プロセスが動いていないとリモート住所に戻り、別の実体につながることがあります |
| リモートサービス住所 | 既定 `https://metatube.lifebus.fun`。`http(s)://` で始まり、末尾に `/` は付けない | 書式が違うと接続テストが失敗します |
| 認証を有効化 | リモート側にトークンがあるときだけオン | オンなのにトークンが空だとリモートに拒否されます |
| トークン | リモートサービスのトークンと一致させる | 間違いは「つながるのに結果が空」として現れます |
| 優先度 | 情報源を試す順番。前にあるほど優先。既定は `Caribbeancom,AVBASE,Pcolle,DUGA,MYWIFE,1Pondo,JAV321,FC2,TOKYO-HOT,JavBus,Getchu,fc2hub,Gcolle,HeyDouga,FALENO,FANZA,H0930,DAHLIA,H4610,HEYZO,SOD,10musume,KIN8,ThePornDBScene,C0930,AVE,PACOPACOMAMA,MGS,ThePornDBMovie,JAVFREE,CaribbeancomPR,MURAMURA`。複数値はコンマ区切り | 目当てのサイトが後ろすぎると、順番が回ってきません |
| 翻訳を有効化 | 既定オフ。オンにすると情報取得時に題名やあらすじを翻訳 | オフなら原文のまま |
| 翻訳サービス | 候補 `GoogleFree,Google,OpenAI,DeepL,Baidu,Microsoft`。保存したものが実際に使われ、初回は `GoogleFree` | キーが必要な引擎を選んでキーが空だと翻訳されません |
| Google / DeepL / OpenAI のキーと住所 | 該当引擎を選んだらキーは必須。住所は空なら既定住所 | キー不足は翻訳失敗。ログに残るだけで登録自体は成功します |
| OpenAI モデル / プロンプト | モデル名と翻訳用の指示文 | 空ならサービス側の判断 |
| Baidu アプリ ID / キー | Baidu を選んだら必須 | 無いと翻訳されません |

設定カード右上のボタン：**内蔵サービスを起動**、**内蔵サービスを停止**、**内蔵サービスを再起動**、**設定を再読込**、**設定を保存**。「資源ダウンロード」カードは MetaTube 本体のためのもので、無ければ起動後に自動でダウンロードされます。

:::note[接続テストはリモート住所を見る]
「接続テスト」が見るのは「リモートサービス住所」であり、内蔵プロセスではありません。内蔵サービスの状態は「内蔵アプリ情報」で確認します。取得失敗と出たら、プログラムがダウンロード済みかを確認し、**内蔵サービスを起動**を押してください。
:::

## TMDB

TMDB（The Movie Database）は映画とドラマの総合データベースです。接続すると作品・出演者・ドラマの検索に参加します。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → TMDB |
| 得られるもの | 作品の詳細、劇場写真、スタッフ。出演者プロフィール。ドラマのシーズンとエピソード |
| 準備するもの | TMDB 開発者サイトでアプリを作って得る認証コード。または「認証を取得」で自動写入 |
| 画面 | 「設定情報」「接続テスト」「資源検索」の三つのカード |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと一切検索しません |
| サービス住所 | 既定 `https://api.themoviedb.org`。通常は変更不要 | 間違えるとつながりません |
| 認証コード | TMDB の API Read Access Token | 空欄や間違いでキー確認が 401 を返します |
| アカウント ID | 「アカウント情報を取得」で使用。認証成功時に自動写入 | 空だとアカウント情報の取得が失敗します |
| 作品検索 | 既定オン | オフだと作品検索に参加しません |
| ドラマ検索 | 既定**オフ** | オフだと「関連するドラマが見つかりません」と固定で返ります |
| 出演者検索 | 既定オン | オフだと出演者検索に参加しません |
| 画像住所 | 既定 `https://image.tmdb.org/t/p/`。空なら自動取得 | 住所が遮られていると画像が出ません |
| 画像サイズ | 既定 `original`。画像住所の後ろに連結 | 間違えると画像が 404 になります |
| 検索言語 | 既定 `zh-CN` | 間違えてもエラーではなく、その翻訳が取れないだけです |

### ボタンと検索

| ボタン | 内容 |
| --- | --- |
| 認証を取得 | TMDB の認証ページを開き、同意すると当サイトの戻り先に跳び、認証コードとアカウント ID を自動写入します |
| 接続テスト | サービスに届くかを判定 |
| キーを確認 | 認証コードが有効かを判定 |
| アカウント情報を取得 | アイコンとアカウント情報を表示。アカウント ID が必要 |

検索は三つのタブがあります。TMDB 作品（結果をクリックすると詳細とスタッフが表示され、「取込」で作品ライブラリに写入）、TMDB 出演者（「取込」で出演者ライブラリへ）、TMDB ドラマ（先に「取込プレビュー」を見てから「全シーズンを取込」または「今シーズンを取込」）。シーズン番号 `0` は特別編です。プレビューは下書きを作るだけで、書き込みはしません。

## TheTVDB

TheTVDB はドラマのシーズンとエピソードの構成が本領です。同じ検索口で映画も調べられます。v4 はすべて先にキーでログインする必要があるため、キーは必須です。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → TheTVDB |
| 得られるもの | ドラマの基本情報、キャラクターとスタッフ、シーズン一覧、エピソード一覧。映画のポスター、説明、ジャンル、製作会社、あらすじ |
| 準備するもの | API キー（必須）。「ユーザー支援型」キーは購読 PIN も |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと情報取得に参加しません |
| サービス住所 | 既定 `https://api4.thetvdb.com`。`/v4` の有無はどちらでも動作 | 間違えるとつながりません |
| API キー | 必須 | 無いとプラグインは利用不可と見なされます |
| 購読 PIN | 「ユーザー支援型」キーのみ。その他は空欄 | 必要なのに空だとログイン失敗 |
| 言語 | 三文字コード。既定 `zho`（簡体字中国語）。`eng` 英語、`jpn` 日本語 | 間違えてもエラーではなく原文に戻ります |
| ドラマ検索 | 既定オフ。ドラマ検索に参加するかを制御 | オフだとドラマが見つかりません（映画に個別スイッチはありません） |
| リクエスト間隔 | 既定 `1000` ミリ秒。同一プロセスから TheTVDB への全リクエストで共用 | 小さすぎると速度制限に当たります |

検索では種類（ドラマまたは映画）を選び、キーワード、初回放送年、取得件数（既定 10、1 ページ上限 50）を入れて「検索」を押します。「詳細を見る」で拡張情報を読み込み、「取込」で登録します。シーズン番号を空にすると全シーズン取り込みです。

:::note[接続テストとキー確認は別物]
「接続テスト」はネットワークが TheTVDB に届くかの判定です。キーが無効ならログインは失敗します。両方通って初めて設定完了です。
:::

## Bangumi

Bangumi（bgm.tv）はアニメのデータベースで、各話・キャラクター・声優・スタッフが得意分野です。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → Bangumi |
| 得られるもの | 作品の題名、あらすじ、各話、キャラクターと声優、スタッフ、関連作品 |
| 準備するもの | 検索と閲覧にトークンは不要。アカウント系機能は「認証を取得」 |
| 特徴 | アプリの資格情報は内蔵済みで、クライアント ID、キー、戻り先住所、User-Agent は画面に出ません |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと検索しません |
| 認証住所 | 既定 `https://bgm.tv` | 間違えると認証ページが開きません |
| API 住所 | 既定 `https://api.bgm.tv` | 間違えると検索が失敗します |
| アクセストークン / リフレッシュトークン | 認証成功時に自動写入 | 未認証でも接続テストは通りますが、トークン確認は失敗します |
| リフレッシュ有効期間 | 既定 `604800` 秒（7 日） | 通常は変更不要 |
| ドラマ検索 | 既定オフ。ドラマ・アニメ検索に参加するかを制御 | オフだとアニメが見つかりません |
| リクエスト間隔 | 既定 `1000` ミリ秒 | 小さすぎると速度制限に当たります |
| 言語 | 既定 `zh-CN` | 返ってくる文章の言語設定 |
| 認証有効期限 | トークンの期限時刻。既定 `0` は不明を意味します | 手入力は不要 |

検索はキーワード入力のほか、「ID で検索」に Bangumi の作品 ID を直接入れる方法もあります。詳細の下部でシーズン番号（`0` は特別編）を選び、「ドラマライブラリに取込」を押します。先に「マッピングプレビュー」で整形結果を確認できます。

:::warning[アカウント変更は上書きのみ]
取り消しやトークン削除の口はありません。アカウントを替えるときは「認証を取得」をもう一度押してください。新しいトークンが上書きします。
:::

## ThePornDB / StashBox

ThePornDB は作品と出演者の情報を提供します。公式 API のほか、自前または公開の Stash-Box にも接続でき、両方を同じ画面で管理します。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → ThePornDB |
| 得られるもの | 作品（シーン / 映画を切り替え可）と出演者の情報。Stash クライアント内の同様のデータ |
| 準備するもの | ThePornDB アカウントで発行した API トークン。Stash クライアントは名称、エンドポイント（`http://ホスト:9999/graphql` の形）、キー |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと検索しません |
| サービス住所 | 既定 `https://api.theporndb.net` | 間違えるとつながりません |
| キー | ThePornDB のユーザー設定で発行した API トークン | 空だと「ユーザー情報を取得」が失敗します |
| パーセプチュアルハッシュ計算 | 既定オフ。オンで画像のハッシュを計算し類似比較に使います。VideoHashes プログラムが必要 | プログラムが無ければ使えません |
| あいまい一致 | 既定オフ。オンで題名のあいまい一致を許可 | オフなら厳密な条件のみ |
| ランキング収集 | 既定オフ。オンで「最近の更新」ランキングを定期収集 | ランキングだけに影響し、検索には影響しません |

:::warning[二つのキーを混ぜない]
主設定のキーは公式 API 専用です。Stash クライアントのキーはクライアント側に保存され、主設定に書いても効きません。
:::

検索は四つのタブ：ThePornDB 作品、ThePornDB 出演者、Stash 作品、Stash 出演者。ヒットしたら「作品ライブラリに取込」または「出演者ライブラリに取込」を押します。使えるクライアントが無いときは、Stash クライアント設定を確認するよう案内が出ます。

## TheJavDB

TheJavDB は番号を入口に作品情報を返します。番号系作品の補助源として向いています。キーの申請は不要です。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → TheJavDB |
| 得られるもの | 表紙、作品番号、発売日、収録時間、分類タグ、製作会社、タグ、シリーズ、監督、出演者、出典リンク、あらすじ、見本画像 |
| 準備するもの | 住所に届けば十分。自前やミラーを使うなら住所を変更 |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと検索しません |
| サービス住所 | 既定 `https://api.thejavdb.net`。`http(s)://` を付け、余分なパスは付けない | 間違えるとつながりません |
| 作品検索 | 既定オフ。オンで自動情報取得に参加 | オフでも画面の番号検索は使えますが、自動取得では使われません |

:::note[画面の検索と自動取得は別の道]
画面の「番号検索」は情報源を直接呼ぶもので、住所とデータの確認用です。「作品検索」スイッチの制限は受けません。自動情報取得に参加させるには、そのスイッチをオンにして保存してください。この画面に取込ボタンはなく、登録は情報取得タスクの中で行われます。
:::

## R18.dev

R18.dev にはオンラインの口と、ダウンロードしてオフラインで使えるデータパックがあります。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → R18.dev |
| 得られるもの | 表紙、作品番号、発売日、収録時間、女優、男優、監督、分類、メーカー、タグ、シリーズ、作者、予告編、あらすじ、見本画像 |
| 準備するもの | オンラインは住所に届くこと。オフラインは公式データパックの取込（`.sql`、`.sql.gz`、`.sql.zip`） |
| 画面 | 「設定情報」「データ統計」「データ取込」「番号検索」「接続テスト」 |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと検索しません |
| サービス住所 | 既定 `https://r18.dev` | 完全オフライン運用なら届かなくてもローカル検索は動きます |
| 作品検索 | 既定オフ。オンで自動情報取得に参加 | オフなら自動では使われません |
| オンライン検索 | 既定オフ。オンは情報取得時にオンラインを優先、オフはローカルのみ | オフでデータ未取込なら何も見つかりません |

データパックの取込手順：「ダウンロードページ」または「最新データパックを取得」で公式ページへ → ファイルをアップロード領域にドラッグ、またはクリックして選択 → 「取込開始」を押す（アップロード中は「アップロードを中止」可）→ 「ファイルのアップロードに成功しました。バックグラウンドで取り込んでいます...」と表示されます。

:::warning[取込は負荷が大きい]
解凍と書き込みは CPU、ディスク、データベース接続を多く使います。空いている時間に行い、同じファイルを二重にアップロードしないでください。
:::

「データ統計」カードは各表の件数と増分を示し、「更新」で再集計します。「番号検索」はオンラインとオフラインを選べます。オンラインは先にオンラインを問い合わせ、外れたらローカルを検索。オフラインはローカルだけを検索し、外部へは要求を出しません。

## FANZA DMM

FANZA（DMM）は作品検索とランキングを提供します。アカウントもキーも不要です。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → メタデータ → FANZA DMM |
| 得られるもの | キーワード / 番号検索、日付検索、オンライン統合検索、ランキング（本日の新作と今後 3 日の近日公開） |
| 準備するもの | なし。接続先は本体側で固定（既定 `https://api.video.dmm.co.jp/graphql`）で、画面では変更できません |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフなら何もしません |
| ランキング収集 | 既定オフ。ランキング処理にだけ影響 | 元スイッチだけではランキングを集めません |
| 作品検索 | 既定オフ。オンで作品検索と自動情報取得に参加 | オフなら元スイッチがあっても検索しません |

:::note[三つのスイッチは別々の役割]
元スイッチは「このプラグインを使うか」。ランキング収集はランキング処理。作品検索はキーワード / 番号の検索と情報取得です。
:::

ランキング処理は 1 日 1 回で十分です。その日に集めた分は再要求しませんし、「近日公開」は無い日だけを補います。「接続テスト」は `https://api.video.dmm.co.jp` に届くかを判定するだけで、資格情報の確認もしませんし、データの口が使えることも保証しません。

## 麻豆

麻豆は公式の口から作品と出演者をページごと取得し、ローカルに書き込みます。画面にキーワード検索は無く、「同期」でまとめて集める形です。

:::warning[サービス告知]
画面上部に「2026年4月3日より、また会う日まで🪁」と表示されており、この情報源は外部への提供を終了しています。設定と同期の入口は残っていますが、口がデータを返さない可能性があります。有効にするかはご自身で判断してください。
:::

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと収集しません |
| サービス住所 | 既定 `https://api.modelmediaasia.com` | 間違えるとつながりません |
| 作品収集 | 既定オフ。「作品を同期」の前提条件 | オフだと同期を押しても拒否され、先に対応する収集機能を有効にするよう出ます |
| 出演者収集 | 既定オフ。「出演者を同期」の前提条件 | 同上 |

「接続テスト」カードの右上に三つのボタン：**作品を同期**（ページごとに非同期で取得し、公開順に登録）、**出演者を同期**（出演者情報を非同期で取得）、**接続テスト**（画面内の住所で健康診断）。送信するとすぐ「同期タスクを送信しました」が返り、実際の収集は裏で進みます。同じ種類の同期が走っているときに再押しすると拒否され、「同期中です。頻繁な操作は避けてください」と出ます。

:::tip[先に保存してからテスト]
「接続テスト」が使うのは画面に今入っている住所です。住所を変えたら先に「設定を保存」し、それからテストと同期をしてください。テスト値と実際に動く値がずれないようにするためです。
:::

## M-Team DMM

M-Team の DMM 情報機能は「サイト資源 → M-Team」の画面にあり、「メタデータ」分類ではありませんが、同様に作品検索と取込に参加します。

| 項目 | 内容 |
| --- | --- |
| 入口 | 連携アプリ → サイト資源 → M-Team（画面下部が「検索テスト」） |
| 得られるもの | DMM の作品情報（作品ライブラリに取込可）、女優 / 企画、合集、キーワード |
| 準備するもの | M-Team のアクセストークン（サイト資源と同じ設定を共用） |

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだと検索もアカウント保護確認も行いません |
| サービス住所 | 既定 `https://api.m-team.io/api` | 間違えるとつながりません |
| キー（パスキー） | ダウンロードリンクの組み立てに使用 | 無いと検索はできますがダウンロードが失敗します |
| アクセストークン | サイトの管理画面「実験室」で取得。一度だけ表示 | 空だと結果が出ません |
| 臨時認証コード | ヘッダ `Authorization` の値として送信 | 必要なときだけ |
| アカウント保護通知 | 既定オフ。ログイン状態を定期確認して通知 | 長期未ログインのアカウントはサイト側で凍結・削除されます |
| メタデータ検索 | 既定オフ。オンで DMM の口が検索に参加 | オフだと検索テストが「先に M-Team 連携設定で「メタデータ検索」を有効にしてください」と返します |

検索テストは四種類：DMM メタデータ（番号や題名のキーワード。そのまま取込可）、女優 / 企画、合集、キーワード。結果は「表紙、ID、題名、作品番号、情報、操作」を表で示し、ヒット件数と所要時間も出ます。行をクリックすると詳細の引き出しが開きます。

:::tip[取込ボタンが出る条件]
行内の「取込」は、検索種類が「DMM メタデータ」で、その行に作品番号があるときだけ出ます。それ以外は詳細を開き、種一覧から番号で取り込んでください。
:::

## 複数を同時に使ったときの決まり

- **優先度**：MetaTube の内部では「優先度」に並んだ順に情報源を試します。別々の情報源の間では、情報取得と判別の規則がどの結果を採用するか決めます。
- **子スイッチが範囲を決める**：作品検索、ドラマ検索、メタデータ検索は、それぞれその情報源が対応する種類の検索に参加するかを制御します。
- **自動的な埋め戻しは無い**：優先度、言語、画像住所、スイッチを変えても、**これ以降**の処理にだけ効きます。登録済みの作品に新しい設定を反映させるには、情報取得タスクをもう一度実行してください。
- **翻訳は補助**：題名とあらすじの中国語は翻訳の経路が補います。失敗してもログに残るだけで、既に一致した情報には影響しません。

> **埋め戻し**：新しい設定を、すでに整理済みの作品に適用し直すことです。AMMDS は自動では行いません。情報取得をもう一度実行してください。

## 鍵は大切に

TMDB の認証コード、TheTVDB のキーと購読 PIN、Bangumi のトークン、ThePornDB と Stash のキー、MetaTube のトークン、M-Team のパスキーとトークンは、すべて資格情報です。

- スクリーンショット、質問投稿、グループチャット、ログにキーをそのまま貼らないでください。
- 漏れた疑いがあれば、まず該当サイトで無効化し、新しいものを発行して貼り直します。
- 長く使わない情報源はオフにして、キーも空にしておくことをおすすめします。

## 困ったときは

- **保存したのに情報取得に参加しない**：「有効状態」と「作品検索 / ドラマ検索 / メタデータ検索」が、すべてオンになって保存されているか確認します。
- **接続テストが失敗する**：サービス住所のプロトコルとポートを確認。コンテナなら `127.0.0.1` を使わないこと。そのうえで外に出られるかを確認します。
- **テストは通るのに検索が空**：キーが有効か、残量が残っているか、子スイッチがオンか、そしてキーワードがその源の判別できる書式かを確認します。
- **401 または 403**：トークンの期限切れか権限不足です。サイト側で作り直してください。
- **429 または頻繁な時間切れ**：速度制限です。リクエスト間隔を大きくします。
- **画像が出ない**：画像住所が遮られているか、サイトが直リンクを禁止しています。
- **麻豆など、ある源がずっと空**：相手のサービスがまだ存在するかを確認してください（麻豆の画面上部に終了の告知があります）。
