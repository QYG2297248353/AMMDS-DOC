# テレビで見られるように同期する

AMMDS は再生機ではなく、情報を整理するだけです。テレビで整ったポスター一覧を見たければ、Jellyfin か Emby をつないで、整理した情報を渡します。

> **メディアサーバー / プレイヤー**：テレビ、箱、またはパソコンで動く再生ソフトです。Jellyfin や Emby などが当てはまります。動画を再生し、ポスター一覧を表示します。

> **API キー**：プレイヤーが発行する文字列で、専用の鍵のようなものです。持っている人は、そのソフトの権限で情報の読み書きができます。

> **紐づけ**：手元の作品とプレイヤー内の作品を対応させることです。紐づけて初めて両者の同期ができます。

## まず一つ選ぶ

Jellyfin と Emby は同じ流れをくむため、設定項目と能力はよく似ています。**二つを同時に有効にもできます**。再生統計はそれぞれに紐づけた利用者ごとに取得したうえで合算されます。一つでも十分です。

| 比較 | Jellyfin | Emby |
| --- | --- | --- |
| 入口 | 連携アプリ → メディアサーバー → Jellyfin | 連携アプリ → メディアサーバー → Emby |
| 通信 | プレイヤーの口 + API キー | プレイヤーの口 + API キー |
| 既定のサービス住所 | `http://127.0.0.1:8096` | `http://127.0.0.1:8096` |
| キーの取得場所 | 管理コンソール → API キー（一部版では「詳細」の下） | 設定 → 詳細 → API キー |
| 管理入口 | ツールボックス → メディアサーバー → ライブラリ管理 / 作品ライブラリ / 出演者ライブラリ | 同上 |

## 共通の三手順

1. プレイヤーで API キーを発行します（名は `AMMDS` にしておくと、後で単独で無効化できます）。
2. AMMDS のプラグイン画面に戻り、サービス住所とキーを入力して**保存**します。
3. 画面を更新して利用者一覧を読み込み、「紐づけ利用者」を選んで保存し、「接続テスト」を押します。

:::tip[専用のキーを作る]
管理者が普段使っているキーを流用しないでください。別に作れば、問題が起きたときにそれだけを無効化できます。
:::

## Jellyfin

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだとメディアサーバーの口がすべて「先に JellyFin プラグインを有効にしてください」を返します |
| サービス住所 | 既定 `http://127.0.0.1:8096`。コンテナならホストの住所かサービス名 | コンテナで `127.0.0.1` を書くと AMMDS 自身につながります |
| API キー | Jellyfin の管理コンソールで発行。有効化後は診断上の必須項目 | 空または無効で「正しいプラグイン設定を入力してください」と出ます |
| ユーザー名 | ログイン名。**任意** | 通常は同期に影響しません |
| パスワード | ログインパスワード。**任意** | 同上 |
| 紐づけ利用者 | 再生記録をどの Jellyfin 利用者に帰属させるか。複数はコンマ区切り | 未紐づけでも再生記録の同期は動きますが、その利用者の集計が出ません |
| 自動補完 | 既定オフ。オンで定期処理が出演者情報を非同期で補完 | 手元の出演者ライブラリに無い情報は補えません |

### 紐づけの順番

1. 先にサービス住所と API キーを入力して**保存**します。
2. 設定画面を更新し、Jellyfin の利用者一覧を読み込みます。
3. 「紐づけ利用者」でアカウントを選び（管理者は赤い札、一般は青い札）、保存します。

### 同期できる内容

| 内容 | 向き | 説明 |
| --- | --- | --- |
| ライブラリの項目 | プレイヤー → AMMDS | ライブラリ内の作品や出演者を取得し、紐づけと表示に使います |
| ライブラリ同期 | 双方向 | 手元の作品情報と表紙をプレイヤーへ書き込み、紐づけを作ります |
| 再生記録 | プレイヤー → AMMDS | 紐づけ利用者ごとに再生記録を取得し、再生統計に使います |
| 出演者補完 | 双方向 | プレイヤー側の出演者情報を補完。逆にプレイヤー側で取得した出演者を手元に書き込むこともできます |
| 画像 | AMMDS → プレイヤー | ライブラリや項目の主画像をアップロードし、既存の画像を上書きします |
| ライブラリ走査 | AMMDS → プレイヤー | 単一または全ライブラリの走査を実行します |

対応する操作は**ツールボックス → メディアサーバー → ライブラリ管理**にあります。「全ライブラリを走査」「出演者情報を補完」「ライブラリを同期」「再生記録を同期」「更新」。

## Emby

### 設定項目の説明

| 設定項目 | 何を入力するか | 空欄・間違いのとき |
| --- | --- | --- |
| 有効状態 | スイッチをオン | オフだとメディアサーバーの口がすべて「先に Emby プラグインを有効にしてください」を返します |
| サービス住所 | 既定 `http://127.0.0.1:8096`。コンテナならホストの住所かサービス名 | `127.0.0.1` を書くと AMMDS 自身につながります |
| API キー | Emby の管理コンソールで発行。有効化後は診断上の必須項目 | 空または権限不足で利用者一覧の取得が失敗します |
| ユーザー名 | ログイン名。**任意** | 通常は同期に影響しません |
| パスワード | ログインパスワード。**任意** | 同上 |
| 紐づけ利用者 | 再生記録をどの Emby 利用者に帰属させるか。複数はコンマ区切り | 未紐づけでも同期は動きますが、その利用者の集計が出ません |
| 自動補完 | 既定オフ。オンで定期処理が出演者情報を非同期で補完 | 手元の出演者ライブラリに無い出演者は補えません |

:::warning[キーにはライブラリ管理の権限を]
キーを発行したアカウントにライブラリ管理の権限が無いと、利用者一覧の取得が失敗します。
:::

### 紐づけの順番

1. サービス住所と API キーを入力して保存します。
2. 設定画面を更新し、Emby の利用者一覧が読み込まれるのを待ちます。
3. 「紐づけ利用者」でアカウントを選び（管理者は赤い札、一般は青い札）、保存します。

### 同期できる内容

| 内容 | 向き | 説明 |
| --- | --- | --- |
| ライブラリの項目 | プレイヤー → AMMDS | ライブラリの作品や出演者を取得します |
| ライブラリ同期 | 双方向 | 手元の作品情報と表紙を書き込み、作品の紐づけを作ります |
| 再生記録 | プレイヤー → AMMDS | 紐づけ利用者ごとに再生記録を取得し、再生統計に使います |
| 出演者補完 | 双方向 | 出演者情報を補完。プレイヤー側で取得した出演者を手元に書き込むこともできます |
| 画像 | AMMDS → プレイヤー | ライブラリや項目の主画像をアップロードします |
| ライブラリ走査 | AMMDS → プレイヤー | 単一または全ライブラリの走査を実行します |

## 両方に共通する制限

- **すべて非同期**：同期と補完は裏で実行され、口はすぐ「同期中…後ほどログを確認してください」を返します。進み具合は実行ログでしか確認できません。
- **紐づけは書き込みを伴う**：作品や出演者を紐づけるとき、手元の情報と画像をプレイヤーへ書き戻します。最善努力であり、書き戻しの失敗は紐づけの成立には影響しません。
- **ファイルは消さない**：同期が書くのは情報と画像だけで、プレイヤー上の動画ファイルは削除しません。
- **紐づけ解除は関係だけ**：解除で消えるのは手元の紐づけ記録だけで、プレイヤー側のデータには影響しません。
- **自動補完には前提がある**：手元の出演者ライブラリにある情報や肖像に依存します。手元に無いものは補えません。
- **住所に 127.0.0.1 を書かない**：コンテナでは `127.0.0.1` は AMMDS コンテナ自身を指します。

## 困ったときは

- **「正しいプラグイン設定を入力してください」**：サービス住所の間違い、API キーが無効、またはプレイヤーが起動していません。まず「接続テスト」で見当をつけます。
- **「先に XX プラグインを有効にしてください」**：プラグインの「有効状態」をオンにして保存します。
- **利用者一覧が空**：設定がまだ保存されていません。保存してから画面を更新してください。
- **再生記録にデータが無い**：利用者が未紐づけ、またはその利用者の最近の再生がありません。紐づけてから再同期します。
- **同期の進み具合が見えない**：処理は裏で動いています。実行ログを見てください。
- **表紙が更新されない**：書き戻しの失敗か、元画像が固定されています。プレイヤー側で画像の固定状態を確認して再実行します。
- **Emby に書き込んだのに画面が変わらない**：プレイヤーの保存領域が更新されていません。ライブラリ走査か情報の更新を一度実行します。
