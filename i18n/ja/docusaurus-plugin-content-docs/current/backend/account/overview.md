# プロフィール、公式ストア、ログインの安全

このページは三つを扱います。**自分のアカウント**（アイコン、情報、公開ページ、パスワード）、**公式ストア**、そして**サイト認証**（PT サイトの認証情報を AMMDS に渡すこと）です。三つは独立しているので、必要な節だけお読みください。

## 1. プロフィール

右上のアイコン → **ユーザーセンター** を開きます。ページは上から順に、ヘッダー画像エリア、ページ設定、ユーザー情報、ライセンスです。変更はすぐ反映され、再起動は不要です。

### ヘッダー画像エリア

| 項目 | 変更方法 |
| --- | --- |
| アイコン | アイコンをクリックして画像を選ぶと、アップロード完了後に差し替わります |
| バナー | 右上のアップロードボタンで画像を選びます。すでにある場合は削除して既定の背景に戻せます |
| ニックネーム | 現在のニックネームを表示 |
| ロールの印 | 管理者またはユーザー |
| ライセンスの印 | ライセンスの状態（有効 / 無効）と連動 |
| 会員の印 | 会員の印があるときだけ表示 |
| パスワード変更 | クリックすると変更ダイアログが開きます |

バナーを設定していないときは、内蔵の背景画像が使われます。

### ページ設定

ここは**他の人が公開ページを見たときの見え方**を決めます。

| エリア | 内容 |
| --- | --- |
| 公開ページの背景 | アップロードまたは削除。未設定ならプレースホルダー |
| 公開ページのバナー | アップロードまたは削除。ヘッダーのバナーとは別物です |
| 公開ページのテーマ | 複数のテーマカード。クリックで切り替わって保存されます。テーマごとにデザインと配置が異なります |

背景とバナーは公開ページの全テーマに適用され、使い方や切り抜き比率はテーマごとに決まります。

### ユーザー情報

情報カードには、ユーザー ID、ニックネーム、メールアドレス、電話番号、ロール、状態、登録日時、最終ログインが表示されます。右上に二つの入口があります。「情報を編集」でダイアログを開き、「公開ページ」で別タブに開きます。

> **ユーザー ID**：自分で決めるアカウント名で、そのまま公開ページのアドレス（`/u/あなたのID` の形）になります。変更すると古いリンクは使えなくなるので、すでに共有している場合は一緒に更新してください。

> **マスク表示**：一部だけを表示し、途中を記号で隠すことです。電話番号なら最初と最後の数桁だけ見えます。

### 設定項目：編集できる項目

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| ユーザー ID | 必須。英数字、アンダースコア、ハイフンのみ。4 文字以上、数字だけは不可、`admin`、`root`、`ammds` などの予約名も不可 | 保存できず、公開ページも開けません |
| ニックネーム | 必須。最大 32 文字 | 保存できません |
| メールアドレス | 必須。メールの形式であること | 保存できず、インスタンス連携も有効にできません |
| 電話番号 | 任意。公開ページではマスク表示 | 空のままで構いません |
| 公開ページの表示項目 | 複数選択：ユーザー ID、ニックネーム、アイコン、メール、電話番号（マスク）、登録日時、最終ログイン、状態 | 一度も設定していなければ電話番号以外すべて表示。すべて外すと何も表示されません |

### パスワードを変更する

ヘッダーの「パスワード変更」を押し、三つを入力します。現在のパスワード、新しいパスワード、新しいパスワードの再入力です。

パスワードの規則（ログイン、変更、リセットで共通）：**6〜22 文字、英大文字と小文字を含み、数字または記号を少なくとも一つ**含むこと。二回の入力は一致している必要があります。

送信時にパスワードは暗号化されます。変更に成功すると「まもなくログアウトします」と表示され、約 5 秒後に自動的にログアウトします。新しいパスワードで再ログインしてください。変更には現在のパスワードが必要です。まったくログインできない場合は、システム管理の回復キーでリセットします。

アイコン、バナー、背景はデータディレクトリの容量を使います。ニックネーム、メールアドレス、電話番号はインスタンス連携の前提でもあり、欠けていると有効にできません。

## 2. 公式ストア

> **公式ストア**：AMMDS に内蔵されたショップです。商品、価格、在庫、決済、発送は公式ショップ側が管理し、こちらは表示と注文だけを行います。会員やサービスの購入は、開発を支える最も直接的な方法です。

### 買い物の流れ

1. **閲覧**：商品一覧を開きます。匿名で閲覧、検索、詳細の確認ができます（「販売停止中」の表示がある商品はカートに入れられません）。
2. **カートに入れる**：詳細ページで規格と数量を選び、「カートに入れる」を押します（ここでログインが必要です）。カートでは数量の変更や削除ができます。
3. **購入**：「購入手続き」を押し、下のブロックを入力して支払い方法を選び、注文を送信します。

カートはまとめて精算され、行ごとのチェックはありません。通貨は最初のカート投入時に選択地域で決まります。通貨を変えるにはカートを放棄してやり直す必要があります（確認ダイアログが出ますが、注文は作られず請求もされません）。送信後は注文結果ページに移り、そのリンクは自分で保管しても安全です。

### 購入手続きの入力項目

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| 連絡先 | メールアドレスは必須。電話番号、姓、名は任意 | メールが空だと送信できません |
| 登録済み住所 | ログイン後、保存済みの住所を選ぶと下のフォームに反映されます | 毎回手入力です |
| 配送先住所 | 住所、都市、国は必須。郵便番号、州は任意 | 必須項目が空だと送信できません |
| 配送方法 | 「配送方法を取得」を押すと、地域で使える方法と送料が出ます | そのまま注文しても自動で取得されます |
| 支払い方法 | ストアが提示する方法から選びます | 選ばないと注文できません |

### 注文の確認

注文一覧と詳細は公開サイトで確認します。管理画面の **公式ストア** メニューには四つのページがあります。

| ページ | 用途 |
| --- | --- |
| 状態 | ショップ情報、商品数、カテゴリ数、カート数、注文数、最終同期時刻、接続状態。手動で同期できます |
| 注文 | 全アカウントの注文と明細を確認。キーワードと支払い状態で絞り込み可 |
| カート | 各アカウントのカートを確認し、項目の削除やクリアができます |
| 登録済み住所 | 自分の配送先を管理し、既定を設定できます |

同期には「商品（差分）」「情報」「注文」「全体照合」があり、すべて裏で実行されます。画面には進捗、成功・失敗の件数、エラーの要約が出ます。全体照合の実行中は二重に開始できません。

### 住所の項目

**公式ストア → 登録済み住所** で追加、編集、削除、既定設定ができます。項目はメール、電話番号、姓、名、国、州、都市、郵便番号、住所です。**メール、電話番号、国、都市は必須**です。購入手続きでは既定の住所が自動で選ばれてフォームに反映されます。

## 3. サイト認証

> **サイト認証**：PT サイトの認証情報（ユーザー ID と個人キー）を AMMDS に渡し、そのアカウントでデータを読めるようにすることです。氏名や身分証などの実名情報は扱いません。

> **PassKey**：サイトが発行する個人キーで、そのサイトのログイン情報と同じ働きをします。画面の共有は避け、複数のサイトで同じキーを使い回さないでください。

右上のアイコン → **サイト認証** を開きます。設定済みのサイトはカード表示で 1 行 3 枚です。何もない場合は「認証サイトがありません」と出ます。

### 認証の手順

1. カードの「UID」を押し、そのサイトのユーザー ID を入力して送信します（保存されます）。
2. 「PassKey」を押し、サイトから受け取ったキーを入力して送信します。
3. カードのスイッチが有効になっているか確認します。
4. 「今すぐ認証」を押します。

サイトによって必要なものが違います。ユーザー ID と個人キーの両方が必要なサイトが多いですが、個人キーだけのサイトもあります。ほかにも三つの前提があります。サイトが有効であること、サイト自体が認証に対応していること、認証情報が保存済みであることです。一つでも欠けると画面が知らせ、リクエストは送られません。

認証は裏で実行されるので、ページに留まる必要はありません。一覧は 10 秒ごとに自動更新され、別のタブに移ると止まります。

### 認証の状態

| 状態 | 意味 |
| --- | --- |
| 認証済み | 直近の認証が成功し、有効期限内 |
| 未認証 | 未実施、失敗、または有効期限切れ |

認証結果の有効期限は **6 時間**です。過ぎると自動的に未認証へ戻りますが、最後の認証日時と失敗理由は残り、原因の調査に使えます。内蔵の定期タスクが定期的に再認証するので、通常は手動での更新は不要です。成功時はサイトが返したユーザー名とメールアドレスを記録し、「サイト認証に成功しました」という通知を送ります。

## 困ったときは

- **「サイトが有効ではありません」と出る**：カードのスイッチをオンにしてやり直してください。
- **「先に UID と PassKey を設定してください」と出る**：それぞれ一度入力します。保存済みのボタンは強調表示されます。
- **「このサイトは認証に対応していません」と出る**：その種のサイトはプラグイン経由で接続します。統合アプリで設定してください。
- **理由が表示されずに失敗する**：ユーザー ID と個人キーが合っていないか、サイト側でキーが再発行されています。サイトで両方を確認してください。
- **認証済みが未認証に戻る**：6 時間の有効期限が切れ、定期タスクがまだ実行されていません。一度「今すぐ認証」を押してください。
- **商品一覧が空**：ストアがまだ同期されていません。管理者が「状態」ページで同期してください。
- **パスワード変更後にログアウトされる**：想定された動作です。新しいパスワードで再ログインしてください。
