# スキャン：AMMDS にファイルを覚えさせる

動画がたくさん入ったフォルダを AMMDS に渡す最初の一歩は「スキャン」です。どんなファイルがあるかを読み取って登録し、その後に情報を補ったり整理したりできます。タスクの作り方、対象ファイルの絞り方、置き場所、自動実行、結果の確認場所を説明します。

## はじめに

> **スキャン**：指定したフォルダを巡回し、条件に合う動画ファイルを一つずつ登録することです。ファイルを登録するだけで、作品情報はまだ調べません。

> **スクレイピング**：情報サイトから作品の表紙・あらすじ・出演者を調べて自動で埋めることです。スキャンの後に行います。

> **作品番号 / 識別コード**：ファイル名に含まれる識別番号です。検索欄では「番号（作品番号）」、詳細・編集画面では「识别码（識別コード）」と呼ばれますが、同じものです。

> **メタデータ**：作品の表紙・あらすじ・出演者・タグなどの説明情報です。

> **NFO**：動画と同じ場所に置く小さな説明ファイルで、題名や出演者などが書かれています。プレイヤーが読み、AMMDS もここから情報を復元できます。

> **Cron**：「いつ実行するか」を数字と記号で書いた短い文字列です。毎日の時刻や何時間ごとかを指定します。

> **許可リスト**：「これだけを認める」一覧です。載っていないものはすべて除外されます。

> **並列処理**：複数のことを同時に進めることです。

> **プレースホルダー**：書式文字列の中で `{}` で囲まれた目印で、使うときに題名・作品番号・出演者名などの実際の内容に置き換わります。

:::tip[スキャンとスクレイピングは別の作業です]
スキャンはファイル名とメディア情報だけを登録し、**作品番号の判定も情報の補完も行いません**。表紙・あらすじ・出演者まで埋めたい場合は[スクレイピング：作品情報を自動で補う](./scrape.md)へ進んでください。
:::

## 順に進める

### 1. スキャンタスクを作る

任务管理 → 任务配置（タスク管理 → タスク設定）を開きます。既定は「任务列表（タスク一覧）」タブです。「点击创建扫描任务（スキャンタスクを作成）」カードを押すと作成ダイアログが開きます。既存のカードでは「编辑（編集）」「记录（記録）」「删除（削除）」と主ボタンが使えます。

作成時の項目：

| 項目 | 内容 |
| --- | --- |
| 任务名称（タスク名） | 必須。一覧やログで見分けるための名前です |
| 分类（分類） | 影视（映像）/ 剧集（ドラマ）。ドラマは専用の判定・スクレイピング経路を通ります |
| 媒体类型（メディア種別） | 映像のときだけ。産地区分を選びます（日本 AV、欧米、国産、FC2 PPV など） |
| 剧集分区（ドラマ区分） | ドラマのとき「媒体类型」の代わりに表示。全部、番剧（アニメ）、日剧（日本ドラマ）など |
| 整理模式（整理モード） | ファイルをどう動かすか。次節参照 |
| 扫描目录（スキャンフォルダ） | 必須。サーバーのファイルツリーから選びます。選べるのはフォルダだけで、単一ファイルは不可 |
| 整理目录（整理先フォルダ） | 「原地整理（その場で整理）」「查漏补缺（不足補完）」以外は必須。その場系はスキャンフォルダに自動で追従します |
| 重命名规则（名前付け規則） | 原文件名（元のファイル名）/ 标准化文件名（標準ファイル名） |
| 重复文件处理规则（重複時の規則） | 整理先に同名があるとき、どちらを残すか |
| 目录监控（フォルダ監視） | 新規作成時だけ設定可。ファイルの変化でスキャンを起動します |
| 加入收藏（お気に入りに追加） | スキャンとスクレイピング後にお気に入りへ。映像タスクだけ有効 |
| 计划任务（スケジュール） | フォルダ監視がオフのときだけ表示。6 項目の Cron 式を書きます |

:::note[フォルダ選択前に権限を確認]
扫描目录 と 整理目录 はどちらもサーバーのファイルツリーから選び、フォルダを展開したときに中身を読み込みます。AMMDS を動かすアカウントにスキャンフォルダの読み取り権限、整理先フォルダの書き込み権限があるか先に確認してください。ないと後で整理に失敗します。
:::

タスクカードにはタスク名（横にシステム種別とタスク種別のタグ：影视 / 剧集 / 未知）、媒体类型 または 剧集分区、扫描目录 と 整理目录、整理模式、命名と重複の規則、计划任务（未使用なら「未启用（未使用）」）が並びます。

### 2. ファイルの動かし方を選ぶ（整理モード）

| モード | 行うこと |
| --- | --- |
| 原地整理（その場で整理） | ファイルは動かさず、スクレイピング結果で改名・情報補完だけ |
| 标准化整理（移动）（標準・移動） | 整理先へ移し、フォルダ書式とファイル名書式に従って配置 |
| 标准化整理（复制）（標準・複製） | 整理先へ複製し、元ファイルは残す |
| 标准化整理（软连接）（標準・シンボリックリンク） | 整理先に元を指すショートカットを作り、容量を余分に使わない |
| 标准化整理（硬连接）（標準・ハードリンク） | 同じデータに別名を付ける。元と先が同じファイルシステムである必要があります |
| 查漏补缺（不足補完） | フォルダ構成もファイル名も変えず、不足している画像と NFO だけ補う |

> **シンボリックリンク / ハードリンク**：どちらも元ファイルを動かさずに整理先へ「リンク」を増やす方法です。シンボリックリンクはショートカットのようなもので元を消すと切れ、ハードリンクは同じデータの別名で、同じディスク上である必要があります。

「原地整理」と「查漏补缺」は整理先を別に選ぶ必要がなく、この二つに切り替えると整理先がスキャンフォルダで自動入力されます。

### 3. 名前付けと重複の規則

二つだけです。

- **原文件名（元のファイル名）**：スキャンで見つけた名前をそのまま使います。
- **标准化文件名（標準ファイル名）**：「影视刮削规则 → 整理文件名格式（映像スクレイピング規則 → ファイル名書式）」で新しい名前を作ります。

重複規則は、整理先に同名があるときどちらを残すかを決めます。

| 規則 | 残すもの |
| --- | --- |
| 保留（そのまま残す） | 元のファイル。容量・日付・解像度で選び直しません |
| 大文件 / 小文件（大きい / 小さい） | 容量が大きい方、または小さい方 |
| 新文件 / 旧文件（新しい / 古い） | 日付が新しい方、または古い方 |
| 高分辨率 / 低分辨率（高 / 低解像度） | 解像度が高い方、または低い方 |

### 4. 対象ファイルを絞る

スキャンは「任务配置 → 扫描规则配置（タスク設定 → スキャン規則）」の全体規則を読みます。映像とドラマは同じタブを共有しますが、ドラマは `tv` 接頭辞の付いた項目を読みます。

| 規則 | 映像 | ドラマ |
| --- | --- | --- |
| 動画形式の制限 | `scanning_video_format` | 同じ項目を共用 |
| 無視フォルダ | `scanning_ignore_dir` | `scanning_tv_ignore_dir` |
| 無視ファイル | `scanning_ignore_file` | `scanning_tv_ignore_file` |
| 最小動画サイズ（MB） | `scanning_min_size` | `scanning_tv_min_size` |
| 分割マーカー | `scanning_video_segmentation` | 不使用 |
| 字幕形式 | `scanning_subtitle_format` | 同じ項目を共用 |
| ローカル NFO の読み取り | `scanning_read_nfo` | `scanning_tv_read_nfo` |

ドラマには「特别篇关键词（特別編キーワード）」「集号缺失默认季（話数欠落時の既定シーズン）」「绝对编号识别（絶対番号の判定）」の三つが追加され、ファイル名をシーズンと話数に分解します。**規則を変えてもその後のスキャンにだけ効き、登録済みの記録は書き換えません。**

実際のスキャンはこの順です。

1. スキャンフォルダから再帰的にファイルを集め、動画拡張子の許可リストで絞ります。
2. 「無視フォルダ」に当たるサブツリー全体と、名前に「無視ファイル」キーワードを含むファイルを飛ばします。
3. 全件スキャンでは最小サイズで絞ります。フォルダ監視による単一ファイルのスキャンではサイズ絞りをしません。
4. ファイル情報とメディア情報（種別、解像度、サイズ、映像・音声コーデック、ビットレートなど）を読みます。
5. 同じフォルダに同名の字幕があるか調べ、字幕の種類を記録します。
6. 分割マーカーで `cd1`、`part2` のような複数構成か判定します。
7. 「读取本地 NFO」がオンで隣に NFO があれば、解析して手順記録に書き込みます。
8. 同じパスが登録済みなら新規作成せず、記録を今回のタスクに結び直すだけです。

### 5. 自動で動かす

| 方式 | 出る場面 | 内容 |
| --- | --- | --- |
| 立即扫描（今すぐスキャン） | フォルダ監視オフのタスク | カードの主ボタン。押すと投入され、バックグラウンドで実行 |
| 初始化（初期化） | 監視オン、状態が「创建（作成）」 | まず全件スキャンし、フォルダ監視を登録 |
| 监控中（監視中） | 監視オン・初期化済み | ボタンはスキャンを起動せず、監視中であることだけ示す |
| 定时扫描（定時スキャン） | 監視オフで Cron を記入 | スケジューラが式に従って起動。[定時実行・タスク履歴・失敗時の再実行](./automation.md)参照 |

:::warning[フォルダ監視と手動スキャンはどちらか一方です]
監視をオンにすると手動スキャンは使えず、まず初期化が必要です。監視と Cron も二択で、監視中は Cron が保存されず、監視をオフにしたときだけ Cron で定時タスクが登録されます。一つのタスクに両方入れても意味がありません。
:::

フォルダ監視はファイルシステムのイベントを使い、定期的な巡回ではありません。

- スキャンフォルダとその下の全サブフォルダを登録し、新しいサブフォルダは再帰的に追加登録します。
- **新しい動画ファイル**ができたときだけ起動し、拡張子が形式の許可リスト内である必要があります。
- そのイベントに対応するファイルだけを扱い、フォルダ全体の再スキャンはしません。
- フォルダが削除されると監視を解除します。アプリ再起動後はタスク設定から再登録します。

:::warning[階層が深いと資源を消費します]
フォルダ監視はシステムのファイル監視枠を使います。階層が深い・更新が頻繁なほど負荷が大きく、Linux では inotify の枠を使い切ると監視サービスが起動できません。監視フォルダを減らすかシステム上限を上げてください。
:::

カードの「记录（記録）」はスキャンログへ、そのタスクで絞った状態で飛びます。「编辑（編集）」は編集ダイアログを開きますが、**目录监控（フォルダ監視）のスイッチは編集時には変更できません**。「删除（削除）」は二段階確認で、スキャン中のタスクは削除できません。

### 6. 結果の見場所

| 場所 | 見られるもの |
| --- | --- |
| 任务管理 → 扫描日志（タスク管理 → スキャンログ） | 実行種別、開始時刻、所要時間、状態、判定 / 追加 / 更新件数。実行中は取り消せます |
| 任务管理 → 刮削入库 → 影视刮削（タスク管理 → 登録 → 映像スクレイピング） | 登録済み動画、識別番号、メディア情報、スクレイピング / 整理の状態。紐付け・解除・削除・番号の手修正ができます |
| 任务管理 → 刮削入库 → 剧集刮削（タスク管理 → 登録 → ドラマスクレイピング） | 作品名ごとにまとめた確認待ちグループ。統合・分割・無視・確定ができます |

スキャンが終わっても**自動ではスクレイピングしません**。ただし「自动刮削（自動スクレイピング）」がオン、またはモードが「查漏补缺（不足補完）」のときは除きます。

## 作品番号はいつ判明するか

スキャン段階ではファイル名とメディア情報だけで、一覧の「识别番号（識別番号）」はスクレイピングで照合された後に値が入ります。実際の判定はスクレイピング側の「识别码规则（識別コード規則）」と「番号补全规则（番号補完規則）」が行います。

例外はローカル NFO です。「读取本地 NFO」をオンにすると、スキャンが NFO からメタデータと識別コードを直接復元できます。判定失敗や誤りは **任务管理 → 刮削入库 → 影视刮削（タスク管理 → 登録 → 映像スクレイピング）** で識別番号タグを押して手修正します。

## 規則パネルには他に何があるか

「任务配置（タスク設定）」の下半分はタブ別の規則パネルです。タスクが「どのフォルダを掃くか」を決め、規則が「どう判定・スクレイピング・整理するか」を決めます。

| タブ | おおよそ管轄すること |
| --- | --- |
| 扫描规则配置（スキャン規則） | 形式、無視フォルダ / ファイル、最小サイズ、分割マーカー、字幕、NFO 読み取り、ドラマ専用項目 |
| 影视刮削规则（映像スクレイピング規則） | データ源、フォルダ / ファイル名書式、NFO 項目、画像、タグ、翻訳、スレッド数など。[スクレイピング：作品情報を自動で補う](./scrape.md)参照 |
| 剧集刮削规则（ドラマスクレイピング規則） | ドラマ用スクレイパー、一致しきい値と重み、フォルダ / ファイル名書式、シーズンポスター命名、NFO 項目など。[スクレイピング：作品情報を自動で補う](./scrape.md)参照 |
| 番号补全规则（番号補完規則） | ファイル名から不完全な番号を補う |
| 识别码规则（識別コード規則） | ファイル名から識別コードを取り出す |
| CID 转换规则（CID 変換規則） | 識別コードを別の番号形式に変える |
| 订阅规则配置（購読規則） | 中文字幕優先、検索順序、ダウンロード先 |
| 漫画整理配置（漫画整理設定） | 形式、フォルダ、命名、章ごと生成、表紙 / 裏表紙 / 目次キーワード |
| 小说整理配置（小説整理設定） | 形式、フォルダ、命名、章ごと生成の有無 |

> **スクレイパー**：作品情報を調べに行ける情報源です。情報サイトや手元の既存データなどを指します。スクレイピング時に複数選ぶと、それらへ同時に問い合わせます。

> **スレッド**：まとまった作業をいくつかに分けて同時に進める「作業員」の数です。多いほど速いですが、増やしすぎると機械や相手サイトに負担がかかります。

> **正規表現**：どんな文字に一致させるかを記号で書いた規則で、ファイル名から番号を取り出すのに使います。

規則パネルで入力欄・数字欄・スイッチ・新規選択肢を作れるドロップダウンのどれになるかは画面が決めます。変更後は「保存配置（設定を保存）」で項目ごとに送信し、「刷新配置（設定を再読込）」は未保存の変更を捨てて読み直します。

### 番号補完規則

各規則に必要なのは：备注（備考、規則の見分け用）、规则类型（規則種別、一致文字列の解釈方法）、匹配规则（一致規則、ファイル名のどこを拾うか）、模板（テンプレート、番号の組み立て）、番号长度（番号の長さ。`0` は自動補完、0 より大きいとその桁数まで補う）、自动补全（自動補完、自動適用するか）、启用状态（有効 / 無効）です。

### 識別コード規則と CID 変換

「识别码规则（識別コード規則）」はファイル名やパスから識別コードを取り出します。一致方法は正規表現・接頭辞・包含・接尾辞の四つで、出力テンプレート（`{num}`、`{match}`、`{group1}` など）、作品種別、有无码（モザイクの有無）、需包含前缀（必要な接頭辞）、有効状態、備考を設定できます。パネルには「识别测试（判定テスト）」があり、ファイル名か完全なパスを入れると識別コード・命中の有無・命中規則・補完後の番号が返ります。

「CID 转换规则（CID 変換規則）」は識別コードが正しいことを前提に、それを CID に変えます。一致方法は同じで、出力テンプレートは `{brand}`、`{num}`、`{num2}` 〜 `{num8}`（ゼロ埋め）、`{match}`、`{group1}` などに対応し、変換テストもあります。

:::tip[まず判定、それから変換]
CID 変換は正しい識別コードに依存します。結果がおかしいときは「识别测试（判定テスト）」で識別コード自体を確認し、それから CID テンプレートを直します。
:::

識別コード規則と CID 変換規則はどちらもドラッグで並べ替えでき、**上にあるほど優先度が高くなります**。番号補完規則と同じく、追加・編集・削除・有効 / 無効に対応します。

### 購読・漫画・小説の整理規則

この三つは映像スキャンタスクとは混ぜず、それぞれのタブで設定します。

| タブ | 入力すること |
| --- | --- |
| 订阅规则配置（購読規則） | 中字优先（中文字幕優先。現バージョンでは好みを保存するだけで自動ダウンロードの並びには影響しません）、搜索顺序（検索順序。サイトのキーワード一覧でどこを先に試すかを決め、まとめ系の情報源は常に最後）、下载目录（ダウンロード先。空ならダウンローダの既定パス） |
| 漫画整理配置（漫画整理設定） | 形式（フォルダ、CBZ、CBR、CB7、PDF、EPUB）、既定の整理先、フォルダ / ファイル命名、章ごと生成の有無、表紙 / 裏表紙 / 目次のキーワード |
| 小说整理配置（小説整理設定） | 形式（EPUB、TXT）、既定の整理先、フォルダ / ファイル命名、章ごと生成の有無 |

漫画・小説の命名規則は `${title}`、`${author}`、`${chapter}`、`${index}` などのプレースホルダーに対応します。詳細はパネルの説明に従ってください。

規則は全体設定です。変更はその後作られる / 実行されるタスクに効き、登録済みのメタデータは書き換えません。タスク単位の項目（フォルダ、整理モード、Cron、フォルダ監視）はタスクカードで管理し、規則パネルにはありません。

## 設定項目の説明

### タスク作成時

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| 任务名称（タスク名） | 見分けやすい名前 | 必須。ないとタスクを作れません |
| 分类（分類） | 影视（映像）か 剧集（ドラマ） | 誤ると判定経路が違い、ドラマは別系統になります |
| 媒体类型 / 剧集分区（メディア種別 / ドラマ区分） | 映像は産地区分、ドラマは区分（全部、番剧、日剧 など） | 分類に対応する方だけ表示され、もう一方は隠れます |
| 整理模式（整理モード） | 六つの動かし方から一つ | 必須。「原地整理」「查漏补缺」なら整理先はスキャンフォルダと同じになります |
| 扫描目录（スキャンフォルダ） | サーバーのファイルツリーから選ぶフォルダ | 必須。フォルダのみでファイルは不可。読み取り権限がないと見つかりません |
| 整理目录（整理先フォルダ） | その場系以外は必須、書き込み権限も必要 | 必須。権限がないと整理に失敗します |
| 重命名规则（名前付け規則） | 原文件名 か 标准化文件名 | 標準を選ぶとスクレイピング規則のファイル名書式で改名します |
| 重复文件处理规则（重複時の規則） | 保留 / 大文件 / 小文件 / 新文件 / 旧文件 / 高分辨率 / 低分辨率 | 「保留」なら容量・日付・解像度で選び直しません |
| 目录监控（フォルダ監視） | 新規作成時のオン / オフ | 編集時は変更不可。オンだと手動スキャン不可で Cron も保存されません |
| 加入收藏（お気に入りに追加） | オン / オフ、映像タスクだけ有効 | オフなら追加しません。ドラマタスクでは効果がありません |
| 计划任务（スケジュール） | 6 項目の Cron 式。監視オフのときだけ表示 | 空なら手動のみ。書き間違いやタイムゾーン違いで発火しません |

### スキャン規則の全体項目

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| 動画形式の制限 `scanning_video_format` | 許可する動画の拡張子 | 一覧にない形式はスキャンされません。監視も一覧内の新規ファイルだけ認めます |
| 無視フォルダ `scanning_ignore_dir` / `scanning_tv_ignore_dir` | 丸ごと飛ばすフォルダ | 命中するとサブツリー全体を飛ばします |
| 無視ファイル `scanning_ignore_file` / `scanning_tv_ignore_file` | 名前に含むと飛ばすキーワード | 広すぎると本編まで飛ばします |
| 最小動画サイズ `scanning_min_size` / `scanning_tv_min_size`（MB） | 何 MB 未満を動画としないか | 全件スキャンだけが絞り、監視による単一ファイルは絞りません |
| 分割マーカー `scanning_video_segmentation` | `cd1`、`part2` などの複数構成マーカー | ドラマは不使用。誤ると一本を複数に分けます |
| 字幕形式 `scanning_subtitle_format` | 同フォルダで字幕と見なす拡張子 | 映像とドラマで共用します |
| ローカル NFO の読み取り `scanning_read_nfo` / `scanning_tv_read_nfo` | 隣の NFO を読むか | オンにしないと NFO からメタデータと識別コードを復元できません |
| 特别篇关键词 / 集号缺失默认季 / 绝对编号识别 | ドラマ専用。ファイル名をシーズンと話数へ | ドラマタスクだけが読み、空なら既定の解析になります |

### 番号補完・識別コードとその他

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| 番号補完の一致規則 / テンプレート | ファイル名のどこを拾い、どんなテンプレートで番号にするか | 規則が誤ると誤った番号ができ、スクレイピングが別作品に一致します |
| 番号长度（番号の長さ） | `0` で自動補完、0 より大きいとその桁数まで | 桁数が違うと余分なゼロが付く、または足りなくなります |
| 識別コード規則の一致方法とテンプレート | 正規表現 / 接頭辞 / 包含 / 接尾辞、`{num}`、`{match}`、`{group1}` などの出力テンプレート | 識別コードが取れないとスクレイピングで照合できません。まず「识别测试」で確認を |
| CID 変換の出力テンプレート | `{brand}`、`{num}`、`{num2}` 〜 `{num8}`、`{match}`、`{group1}` など | 識別コード自体が誤っていると変換も必ず誤ります。先に識別コードを直します |
| 启用状态 / 並び順 | 規則のオンオフとドラッグ並べ替え | オフの規則は判定に参加しません。並び順が優先度です |
| 搜索顺序（購読規則の検索順序） | カンマ区切りのサイトキーワード | 誤ったキーワードはそのサイトを常に後回しにします |
| 下载目录（購読規則の保存先） | 購読ダウンロードの保存パス | 空ならダウンローダの既定パスを使います |
| 保存配置 / 刷新配置 | 変更後「保存配置」で項目ごとに送信 | 保存しないと反映されません。「刷新配置」は未保存の変更を捨てます |

## 困ったときは

- **ファイルが一つも見つからない**：扫描目录 が正しいか、AMMDS のアカウントに読み取り権限があるかを確認し、次に形式の許可リストと「忽略目录 / 忽略文件」で弾かれていないか見ます。
- **一つのファイルが複数作品・複数部分に分かれる**：分割マーカーと識別コード規則を確認し、まずファイル名を「识别测试（判定テスト）」で試します。
- **監視をオンにしても動かない**：タスクが初期化済みか確認します。「监控中（監視中）」のボタンは元々スキャンを起動しません。階層が深い・監視枠不足なら監視フォルダを減らすか上限を上げます。
- **定時に動かない**：Cron の書き方とアプリのタイムゾーンを確認し、さらに全体のスケジューラスイッチがオフでないか見ます。[定時実行・タスク履歴・失敗時の再実行](./automation.md)参照。
- **整理に失敗する**：多くは整理先の書き込み権限不足か、「硬连接（ハードリンク）」を選んだのに元と先が別ディスクであるためです。
- **規則を変えたのに古い記録が変わらない**：規則はその後のスキャンにだけ効き、登録済み記録は書き換えません。再スキャンか再スクレイピングが必要です。
