# スクレイピング：作品情報を自動で補う

スキャンはファイルを登録するだけですが、スクレイピングは AMMDS が「どの作品か」を判別し、表紙・あらすじ・出演者・タグを補い、説明ファイルや画像を作って、指定した書式どおりに配置するところまで行います。始め方、情報の出どころ、増えるファイル、詰まったときの対処、そして不足補完と各設定を説明します。

## はじめに

> **スクレイピング**：情報サイトから作品の表紙・あらすじ・出演者を調べて自動で埋めることです。

> **メタデータ**：作品の表紙・あらすじ・出演者・タグなどの説明情報です。

> **作品番号 / 識別コード**：ファイル名に含まれる識別番号で、AMMDS はこれで作品を判別します。

> **NFO**：動画と同じ場所に置く小さな説明ファイルで、題名や出演者などが書かれています。プレイヤーも読みます。

> **スクレイパー**：作品情報を調べに行ける情報源です。情報サイトや手元の既存データなどを指し、複数選ぶとまとめて問い合わせます。

> **並列処理**：複数のことを同時に進めることです。スクレイパーは同時に問い合わせるため、一つが止まっても他は進みます。

> **プレースホルダー**：書式文字列の中で `{}` で囲まれた目印で、出演者名・作品番号・題名などの実際の内容に置き換わります。

## 順に進める

### 1. 始める前に揃える

1. 情報源のプラグインを一つ以上有効にし、「任务管理 → 任务配置 → 影视刮削规则 → 刮削器（タスク管理 → タスク設定 → 映像スクレイピング規則 → スクレイパー）」でチェックを入れます。
2. スキャンで対象ファイルが「刮削入库（取り込み）」に登録済みで、そのパスにまだアクセスできることを確認します。[スキャン：AMMDS にファイルを覚えさせる](./scan.md)参照。
3. 自動で整理したいなら、整理先フォルダが存在し書き込めることを先に確認します。
4. NFO と画像を生成したいなら、対応するスイッチと項目が設定済みか確認します。

スクレイピングは**ダウンローダに依存しません**。ダウンローダが影響するのは購読と手動送信だけで、情報の照合には関係しません。

:::note[同時に動くのは一つだけ]
同時に実行できるスクレイピングタスクは一つです。実行中に再度投入すると拒否され、「重复执行 - 刮削任务运行中（重複実行・スクレイピング実行中）」と表示されます。
:::

### 2. 起動方法を選ぶ

任务管理 → 刮削入库 → 影视刮削（タスク管理 → 取り込み → 映像スクレイピング）を開きます（ドラマは「剧集刮削（ドラマスクレイピング）」）。次の中から選べます。

| 入口 | 範囲 | 内容 |
| --- | --- | --- |
| 刮削整理（スクレイピング＋整理） | 未処理の全映像 | スクレイピングとファイル整理をまとめて実行 |
| 仅刮削（スクレイピングのみ） | 未処理の全映像 | 情報の照合と NFO・画像の生成だけで、動画は移動も改名もしません |
| 选择整理（選択して整理） | チェックした媒体 | 一括処理。1 回につき最大 120 件 |
| 自动刮削（自動スクレイピング） | 設定した間隔 | 映像とドラマにそれぞれスイッチと間隔があり、オンにすると既定で 3 分ごとに未処理を確認します |
| 查漏补缺（不足補完） | 指定タスクの元フォルダ | スキャン後に不足している画像と NFO だけを補い、フォルダ構成は変えません。下の専用の節を参照 |

### 3. 情報はどこから来るか

「刮削器（スクレイパー）」は複数選択のリストです。既定では `本地(默认)`（ローカル）、`MetaTube(插件)`、`ThePornDB(插件)`、`Stash(插件)`、`FANZA_DMM(插件)`、`M-Team_DMM(插件)`、`TheJavDB(插件)`、`R18Dev(插件)`、`TMDB(插件)` が並びます。

実際の動きはこうです。

1. チェックしたスクレイパーへ**並列に**検索をかけます。一つが失敗・タイムアウトしても他は止まりません。
2. 各情報源が見つけた作品をローカルの映画ライブラリへ書き込み、システムがローカルの照合結果を読み直します。
3. 読み直す際、TMDB が有効でチェックされていればその結果を優先し、そうでなければ JAV の番号は MetaTube、欧米の番号は ThePornDB へ回します。
4. Stash、FANZA_DMM、M-Team_DMM、TheJavDB、R18Dev は補助的な情報源で、命中すると同じくローカルに入り、作品番号やファイルの指紋で記録が見つけられます。
5. 番号系がどれも命中せず TMDB が使える場合は、「題名 + 年」で一般の映画としてもう一度照合します。

:::tip[整理済みのライブラリには「ローカルデータ優先」]
「本地数据优先（ローカルデータ優先）」をオンにすると、すでに紐付きがあり、その作品が残っている媒体はネットに接続せずそのまま再利用します。紐付けが切れたときだけ再検索します。欠けている項目だけ補いたいときに向きます。
:::

:::warning[情報源にも得手不得手があります]
MetaTube は欧米の番号に対応しません。欧米作品には ThePornDB か TMDB を有効にしてください。使えるかどうかは、プラグインの有効状態・サイトアカウントの有効性・ネットワークの到達性にも左右されます。
:::

### 4. 何が補われるか

照合に成功すると、情報源が返した項目が作品記録へ書き込まれ、設定に従って派生情報も補われます。

| 区分 | 内容 |
| --- | --- |
| 基本項目 | 題名、原題、あらすじ、公開日、上映時間、評価、監督、制作会社、シリーズ |
| 出演者 | 出演者名、別名、肖像、作品との関連。「演员刮削（出演者スクレイピング）」をオフにすれば飛ばせます |
| タグ / 分類 | 「自动标签（自動タグ）」「自动分类标签（自動分類タグ）」の設定に従い、解像度・制作会社・識別コード・発行日・出演者・モザイク・中文字幕・解除済みなどを追加 |
| 画像 | ポスター、背景、サムネイル、スチール。高精細表紙も選べます |
| 翻訳 | 「字段翻译（項目翻訳）」をオンにすると、システムの翻訳設定で題名やあらすじなどを翻訳します |
| 作品番号 | 識別コードと補完後の番号を混ぜて出力でき、サイトごとの命名の違いに対応できます |

「NFO 字段（NFO 項目）」は NFO を生成するときにどのタグを書くかを決めます。既定では識別コード `num` を含むほとんどの項目が入ります。不要なタグは設定から外せます。

### 5. 整理後のフォルダとファイル名

どこに置くか、何と呼ぶかは「影视刮削规则（映像スクレイピング規則）」の二つの書式文字列で決まります。

| 設定項目 | 既定値 | 内容 |
| --- | --- | --- |
| 整理目录格式（フォルダ書式） | `${actor}/${number}` | `/` 一つが一段のフォルダになります |
| 整理文件名格式（ファイル名書式） | `${number}` | 名前の本体だけで、拡張子は含めません |

使えるプレースホルダーは出演者、作品番号、題名、日付、年、月、日、モザイク、解像度、監督、制作会社などです。末尾が `_safe` の種類はパスの区切りを空白に置き換えます。書き方はパネル上部の「帮助（ヘルプ）」で確認できます。

:::warning[名前が長いと切られます]
ファイル名が 200 バイトを超えると切り詰められ、整理後の相対パスが 3600 バイトを超えると整理が中止されます。書式にプレースホルダーを詰め込みすぎると起こりやすいです。
:::

### 6. どんなファイルが増えるか

スクレイピング後、整理先には次のファイルが増えることがあります。

| ファイル | 内容 |
| --- | --- |
| `<ファイル名>.nfo` | NFO 項目の設定に従って生成され、動画と同じ名前 |
| `<ファイル名>-poster.jpg` | 表紙。モザイクあり作品は縦長 2:3 をなるべく保ちます |
| `<ファイル名>-fanart.jpg` | 背景。モザイクあり作品は横長をなるべく保ちます |
| `<ファイル名>-thumb.jpg` | サムネイル。モザイクあり作品は横長をなるべく保ちます |
| `<ファイル名>.srt` | 外付け字幕。先に同じ名前があれば上書きしません |
| `extrafanart/fanart1.jpg` … | 「刮削剧照（スチール取得）」をオンにしたときに書き込みます。フォルダ名は設定可能 |

画像のダウンロード失敗で整理を止めるかは「允许图片下载失败（画像取得失敗を許す）」で決まります。高精細表紙をオンにすると高精細画像を優先します。モザイクあり作品で表紙と背景の向きが逆になった場合、システムが二つのファイルを入れ替えて揃えようとし、それでも合わなければツールボックスの「海报裁剪（ポスター切り抜き）」で手作業にしてかまいません。

### 7. どこまで進んだかを見る

「刮削入库（取り込み）」一覧の「查看步骤（手順を見る）」を開くと、タイムラインに各回の手順・状態・所要時間・エラーが並びます。主な手順は `文件校验`（ファイル検証）、`番号识别`（番号判定）、`数据源检索`（情報源の検索）、`元数据匹配`（メタデータ照合）、`演员刮削`（出演者取得）、`文件移动`（ファイル移動）で、整理段階には `海报下载`（ポスター）、`背景图下载`（背景）、`缩略图下载`（サムネイル）、`NFO生成`（NFO 生成）があります。ほかに `读取本地 NFO`（ローカル NFO 読み取り）、`手工绑定`（手動紐付け）、`查漏补缺`（不足補完）といった特殊な手順もあります。

順番はタイムラインが基準です。同じ作品に複数回の記録がある場合、引き出し上部で過去の回を切り替えられ、既定では最新の回を表示します。

## 不足補完：足りないものだけ補い、動画は動かさない

「查漏补缺（不足補完）」は、情報がほぼ揃っていて画像か NFO が数点欠けているだけのときに使います。**フォルダ構成もファイル名も変えず、動画ファイルも移動せず**、欠けている画像と NFO だけを補います。

よくある二つの場面：

- スキャンタスクの「整理模式（整理モード）」を「查漏补缺（不足補完）」にした場合：スキャン直後にこのモードで補います。[スキャン：AMMDS にファイルを覚えさせる](./scan.md)参照。
- すでにスクレイピング済みの作品で画像や NFO が欠けた場合：「刮削入库（取り込み）」でタスクに「查漏补缺（不足補完）」を使うと、付属ファイルだけ追加されます。

スクレイピングに失敗した作品は「待刮削（処理待ち）」のままになり、自動的に完了にはなりません。不足を補んだあと、必要なものは改めて再実行してください。

## スクレイピングの設定項目を順に

規則パネルは **任务管理 → 任务配置（タスク管理 → タスク設定）** にあり、「影视刮削规则（映像スクレイピング規則）」と「剧集刮削规则（ドラマスクレイピング規則）」の二つのタブに分かれます。変更後は「保存配置（設定を保存）」で項目ごとに送信し、「刷新配置（設定を再読込）」は未保存の変更を捨てて読み直します。入力欄・数字欄・スイッチ・ドロップダウンのどれになるかは画面が決めます。

### 映像スクレイピング規則

| グループ | 設定項目 |
| --- | --- |
| 情報源 | スクレイパー、ローカルデータ優先、ブランド接頭辞の絞り込み |
| 整理 | フォルダ書式、ファイル名書式 |
| メタデータ | 自動タグ、自動分類タグ、項目翻訳、番号の混合、出演者スクレイピング |
| NFO | NFO 項目（NFO に書くタグを決める） |
| 画像 | 高精細表紙、スチール取得、スチールフォルダ、画像取得失敗を許す |
| 字幕 | 外付け字幕の検索 |
| 性能 | マルチスレッド実行、最大スクレイピングスレッド数 |

### ドラマスクレイピング規則

ドラマの設定は同じタブにまとまっています。ドラマ用スクレイパー（ローカル、TMDB、Bangumi、TheTVDB）、自動スクレイピング間隔、一致しきい値と重み、シーズン対応の自動発見、各シーズンの話数、フォルダ / ファイル名書式、シーズンポスターの命名、NFO 項目、出演者スクレイピング、項目翻訳、リクエスト間隔とスレッド数です。

## ドラマのスクレイピングは何が違うか

ドラマは番号で照合せず、題名・年・シーズンと話数の構成で TMDB、Bangumi、TheTVDB などに照合します。スキャン後、まず「剧集刮削（ドラマスクレイピング）」ページでグループを確定し（統合・分割・無視ができます）、境界が決まってからドラマのメタデータを生成します。初回はグループの境界を先に確定し、それから一致しきい値を調整するのがおすすめです。ドラマのフォルダ書式・ファイル名書式・シーズンポスターと NFO の命名規則は「剧集刮削规则（ドラマスクレイピング規則）」にあります。

## 設定項目の説明

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| 刮削器（複数選択） | 有効な情報源を一つ以上チェック | 一つもないと情報が一切見つかりません。プラグイン無効・アカウント失効・不通でも同じです |
| 本地数据优先（ローカルデータ優先） | オン / オフ | オフだと紐付きがあっても改めてオンラインで取得します |
| 品牌前缀过滤（ブランド接頭辞の絞り込み） | 必要に応じて絞る接頭辞 | 誤ると正常な番号まで弾かれ、照合できなくなります |
| 整理目录格式（フォルダ書式） | 既定 `${actor}/${number}`。プレースホルダーで組み立てます | 空や誤りだと意図しないフォルダ構成になります |
| 整理文件名格式（ファイル名書式） | 既定 `${number}`。名前の本体だけ | 誤るとファイル名がおかしくなります。200 バイト超で切詰め、相対パス 3600 バイト超で整理中止 |
| 自动标签 / 自动分类标签 | 解像度・制作会社・識別コードなどを自動追加するか | オフならこれらの派生タグは付きません |
| 字段翻译（項目翻訳） | オン / オフ。システムの翻訳設定に従います | オフなら翻訳しません。翻訳が未設定だとオンでも訳文が出ません |
| 番号混合 | オン / オフ | オフなら番号の表記は一種類だけになります |
| 演员刮削（出演者スクレイピング） | オン / オフ | オフなら出演者名・別名・肖像を取得しません |
| NFO 字段（NFO 項目） | NFO に書き込むタグ | 外したタグは NFO から消えます。既定では識別コード `num` を含みます |
| 高清封面 / 刮削剧照 / 剧照目录 | 画像のスイッチとスチールのフォルダ名 | 高精細表紙オフなら通常画像、スチール取得オフなら `extrafanart` は作られません |
| 允许图片下载失败（画像取得失敗を許す） | 画像が取れないときも整理を続けるか | オフだと一枚の失敗で整理全体が止まることがあります |
| 外挂字幕搜索（外付け字幕の検索） | 外付け字幕を探すか | オフなら `<ファイル名>.srt` は書かれません。同名ファイルがあるときは上書きしません |
| 多线程执行 / 最大刮削线程数 | スレッドを使うか、同時に何本走らせるか | 多すぎると機械や相手サイトに負担、少なすぎると遅くなります |
| 自动刮削（映像 / ドラマ別のスイッチと間隔） | オンにして間隔を設定。既定は 3 分ごとに未処理を確認 | オフなら手動のみ。間隔が短すぎると頻繁に走ります |
| 选择整理（選択して整理） | 処理する媒体にチェック | 1 回最大 120 件。超えるなら分割します |
| 一致しきい値と重み（ドラマ） | 「同じ作品か」の判定の厳しさと情報源ごとの重み | 厳しすぎると不一致、緩すぎると誤一致。先にグループ境界を確定してから調整を |
| 季映射自动发现 / 每季集数（ドラマ） | 対応を自動発見するか、各シーズンの話数 | 自動発見オフなら手動紐付け。話数が違うとシーズン構成が崩れます |
| 保存配置 / 刷新配置 | 変更後「保存配置」を押す | 保存しないと反映されません。「刷新配置」は未保存の変更を捨てます |

## 困ったときは

- **「重复执行 - 刮削任务运行中（重複実行・実行中）」と出る**：すでに一つ動いています。終わるのを待つか取り消してから再投入します。
- **まったく情報が入らない**：スクレイパーのチェック、プラグインの有効状態、サイトアカウントを確認し、さらにホーム画面のネットワーク診断で情報サイトに届くか確かめます。
- **欧米作品が見つからない**：MetaTube は欧米の番号に非対応です。ThePornDB か TMDB を有効にしてください。
- **作品番号を誤認した**：「刮削入库（取り込み）」で識別番号タグを押して直し、再度スクレイピングします。
- **照合できない、画像や NFO が欠けている**：まず「绑定（紐付け）」でライブラリを検索して手動に紐付け、それからスクレイピングします。画像や NFO だけの欠けなら「查漏补缺（不足補完）」を使えば動画は動きません。
- **整理が途中で止まる / 名前が切れる**：200 バイト超で切詰め、相対パス 3600 バイト超で中止です。書式のプレースホルダーを減らします。
- **どの手順で失敗したか知りたい**：「查看步骤（手順を見る）」で、ファイル検証・番号判定・情報源検索・画像や NFO 生成のどこかを特定します。手順のエラーは通常、バッチログより具体的です。

実行後の状態・ログ・再実行については[定時実行・タスク履歴・失敗時の再実行](./automation.md)をご覧ください。
