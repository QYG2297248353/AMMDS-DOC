# ネットにつながらない？まずここを

天気が出ない、作品情報が補われない、通知が届かない——多くは外部サイトにつながっていないためです。ホーム画面の「网络信息（ネットワーク情報）」には、プログラムが使うサイトを一つずつ検査するツールが備わっています。開き方、結果の読み方、結果ごとの対処を説明します。

## はじめに

> **スクレイピング**：情報サイトから作品の表紙・あらすじ・出演者を調べて自動で埋めることです。

> **プロキシ**：目的のサイトに直接つながず、別の機器に代わりにリクエストを転送してもらうことです。

> **キャッシュ**：調べた結果を一時保存し、しばらくの間は再接続せずに使い回すことです。ここでは 5 分間です。

> **並列処理**：複数のことを同時に進めることです。ここの検査は一つずつ行い、帯域を奪い合いません。

> **DNS**：URL を機械が読めるアドレスに翻訳する仕組みです。これが不通だとサイトを開けません。

> **HTTP レスポンス**：相手のサイトが返してくるひと言です。「権限なし」「見つからない」でも、回線が通っている証拠になります。

## 順に進める

### 1. 検査画面を開く

仪表盘 → 工作台（ダッシュボード → ホーム画面）で「网络信息（ネットワーク情報）」カードのどこかをクリックします。ポップアップの上部にはスイッチが一つだけあり、三つの選択肢が同じ領域を共有します。

| 選択肢 | 見られるもの |
| --- | --- |
| 当前网页（このブラウザ） | いま使っているブラウザから見た公衆アドレス・地理位置・プロキシの状態 |
| 后台服务（バックエンド） | AMMDS を動かしているサーバーから見た同じ情報 |
| 连通性（接続性） | プログラムが使う公共サイトの一覧を、一つずつ検査した結果 |

「连通性（接続性）」を選ぶと右上のボタンが「重新测试（再テスト）」に変わり、前の二つでは「刷新（更新）」になります。

### 2. ネットワークの詳細を見る

「当前网页（このブラウザ）」と「后台服务（バックエンド）」を切り替えると、どちらの機器の出口アドレスを見るかが変わります。

| 参照元 | データの取り方 | 表すもの |
| --- | --- | --- |
| このブラウザ | ブラウザが `ip.sb` へ直接問い合わせます | いま使っている機器がネットに出るときのアドレス |
| バックエンド | バックエンドが問い合わせを代わりに転送します | サーバーがネットに出るときのアドレス |

二つが違う場合、多くはサーバーがプロキシを通っているか、ブラウザとサーバーがそもそも別のネットワークにいるためです。

表示される項目：

| 項目 | 内容 |
| --- | --- |
| IPv4 / IPv6 | 二種類のアドレス形式を別々に調べ、つながらない方は「暂不支持（現在非対応）」と表示します |
| ネットワーク優先度 | 両方使えるとき、現在の接続が実際に使っている方を示します |
| 地理位置 | 国 / 地域、都市、ネット事業者、事業者番号、タイムゾーン、緯度経度 |
| プロキシの状態 | システムで設定したプロキシのオンオフ、プロトコル、アドレス、ログインユーザー名。パスワードは表示されません |

:::tip[結果は 5 分間保存されます]
同じ参照元の詳細は 5 分間キャッシュされ、参照元を切り替えるか「刷新（更新）」を押すと再取得します。「网络信息（ネットワーク情報）」カード自体も 5 分間キャッシュされるため、ホーム画面を開くたびに再調査はしません。
:::

### 3. 接続性検査を実行する

「连通性（接続性）」に切り替えると、まず検査対象のサイトをすべて一覧にします（状態はすべて「待测试（テスト待ち）」）。その後**表の上の行から順に一行ずつ**検査し、終わった行からすぐ結果を表示します。全部終わると、上部に総数・アクセス可の数・アクセス不可の数・合計時間が出ます。

判定は二つだけです。

- **可访问（アクセス可）**：バックエンドが相手から何らかの HTTP レスポンスを受け取った場合です。「権限なし」「見つからない」といった返答も含みます。回線が通っており、認証が必要なことやパスが無いことは判定に影響しません。
- **不可访问（アクセス不可）**：名前解決の失敗、接続のタイムアウト、接続のリセット、暗号化接続が成立しない場合などです。

:::warning[アクセス可でも機能が使えるとは限りません]
たとえば TMDB がアクセス可でもスクレイピングが失敗するときは、たいてい API Key の設定違いか当日の無料回数を使い切ったためで、ネットワークの問題ではありません。
:::

表の三列：

| 項目 | 内容 |
| --- | --- |
| 测试对象（対象） | サイトのアイコンとドメインで、下の行に名称とグループ |
| 连通性（接続性） | テスト待ち / テスト中 / アクセス可 / アクセス不可。マウスを重ねるとステータスコードや失敗理由が見られます |
| 耗时（所要時間） | リクエストを送ってから相手の最初の返答までの時間 |

気をつけたい点：

- 途中でポップアップを閉じると、残りの検査はすぐ中止されます。
- 一覧は一度読み込むと使い回され、三つの選択肢を行き来しても再取得しません。
- 右上の「重新测试（再テスト）」は全行をリセットし、最初から順に実行し直します。

### 4. どのサイトを検査しているか

一覧はグループごとに管理され、バックエンドが実際にアクセスする公共サイトを網羅します。

| グループ | 含まれるもの |
| --- | --- |
| メタデータ源 | DMM、FANZA、DMM 画像、R18.dev、TMDB、TMDB 画像、TheTVDB、Bangumi、ThePornDB、TheJavDB、MGS、JavBus、JAV321、AV-Legue、Madou、MetaTube |
| サイト索引 | M-Team、M-Team API、Rousi、FSM、IYUU、KamePT |
| 通知サービス | Telegram、Bark、高徳地図 |
| AI と翻訳 | DeepSeek、Gemini、Baidu 翻訳、DeepL、Xinyi、Caiyun、Google 翻訳、Microsoft 翻訳、Tencent 翻訳 |
| 基盤 | GitHub、GitHub 加速、HuggingFace、HF ミラー、公式リソース、公式 S3、ライセンスサービス、公式ショップ、統計サービス |
| DNS と基本 | Cloudflare DoH、Google DoH、DNSPod DoH、IP 照会（ip-api / ipw.cn）、時刻照合（Suning / Taobao） |

:::note[一覧は自動的に増えます]
一覧はバックエンドが一括管理しており、サイトを一つ追加すれば画面を改めずともここに現れます。自分で建てたサービス（Jellyfin、qBittorrent、ローカルの MetaTube など）はこの一覧に入らず、それぞれのプラグイン設定ページで接続を確認します。
:::

## 設定項目の説明

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| ネットワークプロキシ | 系统配置 → 网络代理（システム設定 → ネットワークプロキシ）でプロキシをオンにし、プロトコル・アドレス・ログインユーザー名を入力します。パスワードは表示されません | オフだと境外のサイトだけ不通になります。アドレスが誤ると「后台服务（バックエンド）」もデータを取得できません |
| 三択スイッチ | ポップアップ上部で「当前网页（このブラウザ）」「后台服务（バックエンド）」「连通性（接続性）」を選びます | 選び間違えても別の機器の情報が見えるだけです。「连通性（接続性）」を選ばないとサイト検査は走りません |
| 刷新（更新） | 前の二つを表示中に押します | 押さないと最大 5 分前のキャッシュ結果のままです |
| 重新测试（再テスト） | 「连通性（接続性）」を選んだ後に右上で押します | 押さないと前回の結果のままです。押すと全行を消して再検査します |

## 困ったときは

| 現象 | 考えられる原因 | 対処 |
| --- | --- | --- |
| 大半がアクセス不可で、所要時間がどれも約 4 秒 | サーバーがそもそも外に出られない | ホストの DNS・ファイアウォール・上流ネットワークを確認します |
| 境外のサイトだけアクセス不可 | 国境を越える回線が制限されている | 系统配置 → 网络代理（システム設定 → ネットワークプロキシ）でプロキシを有効にして再検査します |
| どのサイトもアクセス可なのにスクレイピングが失敗 | API Key・無料回数・サイト側の制限 | プラグイン設定とサイトアカウントの状態を確認します。ネットワークの問題ではありません |
| DNS グループ全体が失敗 | 暗号化された名前解決の経路が遮断されている | ネットワーク方針による制限で、通常は他の機能に影響しません |

- より詳しい診断（データベース・ディスク・依存プログラム・プラグイン設定）は「系统管理 → 系统检查（システム管理 → システム診断）」へ。このページは接続の可否だけを扱います。
- 天気カードが出ないときは、まずホーム画面で「天气信息加载失败（天気情報の読み込みに失敗）」と出ていないか確認し、上記の順で検査します。[ホーム画面：開いてすぐ見えるもの](./overview.md)もご覧ください。
- 結果がどうも腑に落ちないときは、ポップアップを開け閉めせず、右上の「重新测试（再テスト）」を一度押してやり直します。
