# メディアサーバー：ライブラリとカバー

ツールボックスの「メディアサーバー」は、プレイヤー側のメディアライブラリを直接操作するためのものです。各ライブラリにどれだけ項目があるか、どのディレクトリにあるかを確認し、メタデータや画像を整理し直したり、より見栄えのするカバーに差し替えたり、ライブラリの中に入って階層ごとに整理したりできます。

入口は **ツールボックス → メディアサーバー → ライブラリ管理** です。

:::warning[カバーの書き戻しには利用可能なメディアサーバーが必要です]
カバーの変更、更新、削除はいずれもプレイヤーのメディアライブラリへの書き込みです。あらかじめ「連携アプリ」で Jellyfin または Emby を設定・有効化してください。そうでないと、これらの操作は完了しません。
:::

## ページ上部

上部に「すべてのメディアライブラリをスキャン」ボタンがあり、Jellyfin と Emby のスキャンタスクをまとめて投入します。両方のプラグインが無効な場合、このボタンは灰色になります。

以下は Jellyfin と Emby に分かれた二つのブロックです。各ブロックの一番上に、その側の統計が表示されます：

| 統計 | 説明 |
| --- | --- |
| 映画 | 映画の項目数 |
| ドラマ | ドラマの項目数 |
| 各話 | 各話の項目数 |
| コレクション | コレクションの項目数 |

統計の取得に失敗した場合、行全体が表示されなくなりますが、下のライブラリカードには影響しません。

各ブロックの右上には、俳優情報の補完、メディアライブラリの同期、再生履歴の同期、更新の四つのボタンがあります。役割はそれぞれ、俳優データの補完、ローカルのデータをプレイヤーへ書き込む、再生履歴を取得する、ライブラリ一覧を再取得する、です。これらのタスクはすべてバックグラウンドで実行され、クリックすると「タスクを投入しました」と表示されるだけです。

## ライブラリカード

メディアライブラリごとに一枚のカードがあり、上から順に次の内容です：

| 箇所 | 内容 |
| --- | --- |
| カバー | プレイヤー内のそのライブラリのメイン画像。読み込めない場合はプレースホルダーアイコンが表示されます |
| 名前 | メディアライブラリ名。長すぎると切り詰められ、マウスを合わせると全文が表示されます |
| 種別 | 映画、番組、音楽、コレクション、書籍、その他 |
| 項目数 | 「· 128 項目」のような形式。プレイヤーが返さない場合は `-` と表示されます |
| 物理パス | ライブラリに対応するディスクディレクトリ。複数ある場合はセミコロンで区切られ、長すぎると切り詰められます |
| 操作 | 四つのボタン。後述の表をご覧ください |

| ボタン | 役割 | 説明 |
| --- | --- | --- |
| ライブラリに入る | このライブラリを開き、中のフォルダーや作品を階層ごとに閲覧 | カードのカバーや名前をクリックするのと同じ |
| カバーを変更 | カバー生成ダイアログを開く | 後述 |
| 今すぐスキャン | プレイヤーにこのライブラリをスキャンさせる | タスクを投入するだけで、その場では完了しません |
| その他 | メタデータを更新、画像を更新、カバーを削除 | 後述 |

### 「その他」の三項目

| メニュー項目 | 動作 | 注意点 |
| --- | --- | --- |
| メタデータを更新 | プレイヤーにこのライブラリのメタデータを再読み込みさせる | バックグラウンドで実行。既存のカバーは上書きしません |
| 画像を更新 | プレイヤーに画像を再取得させる | 同様に既存のカバーは上書きしません |
| カバーを削除 | メディアライブラリのメイン画像を削除 | 確認ダイアログが表示されます。削除されるのはプレイヤー上の画像で、動画ファイルは変更しません |

## カバーの変更

「カバーを変更」をクリックするとダイアログが開き、**テキストカバー** と **画像カバー** の二つのタブがあります。どちらのタブも右側に 16:9・1280×720 のリアルタイムプレビューが表示され、左側を変更すると右側に即座に反映されます。確定後「カバーを置き換える」をクリックすると、画像がメディアサーバーに直接書き込まれ、元のメイン画像が上書きされます。

### テキストカバー

設定だけで生成され、ライブラリ内の作品画像には依存しません。最も単純な形は、ライブラリ名 + 黒背景 + 中央に白文字です。

| 設定項目 | 入力方法 |
| --- | --- |
| カバー文言 | 最大 60 文字。空欄の場合はメディアライブラリ名が既定値 |
| サブタイトル | 任意、最大 60 文字。例：`Movies / TV Shows` |
| 背景色 | カラーピッカーで背景色を選択 |
| 文字色 | カラーピッカーで文字色を選択 |
| 文字サイズ | 24〜140、刻み 2 |
| 配置 | 左揃え、中央揃え、右揃え |
| 太字 | スイッチ |

### 画像カバー

このライブラリ内の作品画像を素材として、一枚のカバーを組み立てます。

| 設定項目 | 入力方法 |
| --- | --- |
| カバー文言 | 最大 60 文字。空欄の場合はメディアライブラリ名が既定値 |
| サブタイトル | 任意、最大 60 文字。例：`今月の人気作品` |
| レイアウト | グリッドのコラージュ、またはメイン画像 + タイトルバー |
| 作品数 | グリッドのコラージュの場合のみ。4 枚、6 枚、9 枚から選択 |
| マスクの不透明度 | 0〜0.85、刻み 0.05。大きいほど文字が見やすくなります |
| タイトル文字サイズ | 28〜120、刻み 2 |
| 文字色 | カラーピッカーで文字色を選択 |
| 作品素材 | 「別の一批にする」をクリックするとライブラリ内の作品画像を再びランダムに取得します。隣に「N 枚の作品画像を取得しました」と表示されます |

素材がまだ取得されていない、あるいは一枚も取得できていない場合、「カバーを置き換える」は灰色になります。

毎回手動でクリックしたくない場合は、ライブラリごとに「自動カバー変更」を有効にすると、新しいコンテンツが追加されたときに自動で変更されます。次のセクションをご覧ください。

## 自動カバー変更

ライブラリカードの操作エリアには時計アイコンのボタンがあり、ホバーすると「自動カバー変更」と表示されます。クリックすると「自動カバー変更設定」ダイアログが開きます。**既定はオフで、スイッチをオンにしたライブラリにだけ適用されます**。他のライブラリには影響しません。

### 設定できる項目

| 設定項目 | 入力方法 |
| --- | --- |
| 自動交換を有効化 | スイッチ。既定はオフ、このライブラリのみに適用 |
| カバーの種類 | テキストカバー、または画像カバー |
| カバー文言 / サブタイトル | 最大 60 文字。プレースホルダー `{library}`（ライブラリ名）、`{count}`（項目数）、`{date}`（当日の日付）に対応。波括弧ごと記述します。例：`{library} · 全 {count} 作品` |
| テキストカバー | 背景色、文字色、文字サイズ 24〜140、左揃え / 中央揃え / 右揃え、太字 |
| 画像カバー | レイアウト（グリッドのコラージュ / メイン画像 + タイトルバー）、作品数 4 / 6 / 9 枚（グリッドのみ）、マスクの不透明度 0〜0.95、タイトル文字サイズ 24〜140、文字色 |
| 最小交換間隔 | 10〜10080 分、既定 720 分。同じライブラリで二回の自動交換の間の最短間隔 |

カバーはサーバー側で合成され、1280×720・PNG に固定されます。各設定項目の意味は手動変更のダイアログと同じで、設定可能な範囲はこちらを基準とします。

### いつ変更されるか

システム起動後 25 分で最初のチェックを行い、その後は 30 分ごとにポーリングします。スイッチをオンにしたライブラリだけが対象となり、一つもオンでない場合はメディアサーバーへの要求を行いません。

オンにした各ライブラリについて、次の三つの条件をすべて満たした場合にのみ変更します：

1. ライブラリの項目数が前回の記録より増えている
2. 前回の実行からこのライブラリの最小間隔を超えている
3. メディアサーバーに正常に接続できる。画像カバーを選んだ場合は作品素材も取得できる

有効化直後の最初のチェックでは、現在の項目数をベースラインとして記録するだけで、すぐにカバーは変更されません。その後、新しい項目が追加されて初めて上記の判定が行われます。

### カバーが変更されないケース

| ケース | 結果 |
| --- | --- |
| 項目数が増えていない | スキップ。項目の減少（削除、別ライブラリへ移動）でも変更せず、記録のみ更新 |
| 前回の交換から最小間隔に達していない | スキップし、次のラウンドまで待つ |
| 新しく生成した画像が前回と完全に同じ | スキップし、再書き込みしない。無駄なキャッシュ更新を避けるため |
| カバーを手動で変更した | 自動ポーリングではスキップし、変更したカバーを保持。再び自動変更に委ねるには「今すぐ一度実行」をクリックし、確認ダイアログで上書きの続行を選択 |
| 素材不足、生成失敗、サーバーに到達不能 | 元のカバーをそのまま保持し、失敗理由を記録 |
| ライブラリが空、または項目数を取得できない | 変更しない |

### 結果の確認先

- 有効化後、ライブラリカードに「自動カバー変更 · 時刻 · 成功 / 失敗 / スキップ」の行が追加されます。まだ実行されていない場合は「自動カバー変更 · ポーリング待ち」と表示されます。
- 時計ボタンをクリックして設定を開くと、下部の「最近の自動交換」に結果ラベル、実行時刻、詳細な説明が表示され、失敗理由もここで確認できます。
- より詳細なエラーはバックエンドのログに記録されます。

### 今すぐ一度実行

設定ダイアログの下部に「今すぐ一度実行」があります。項目数の増加や最小間隔は確認せず、その場でカバーを生成します。

ただし、サーバー上の現在のカバーが前回自動書き込みしたものと異なる（手動で変更されたことを示す）場合、直接上書きせず、まず確認ダイアログを表示します：

> カバーが手動で変更されたことを検出しました
> 続行すると自動生成のカバーで上書きされ、現在の手動変更したカバーは失われます。続けますか？

「上書きを続行」をクリックして初めて書き戻され、「キャンセル」をクリックすると元のカバーが保持されます。定時ポーリングは手動のカバーを上書きしません。手動で一度実行して確認した後で、そのライブラリが再び自動変更の対象になります。

設定したばかりで今すぐ結果を確認したい場合も、これで一度実行します。

このボタンはライブラリに現在接続できることを前提とし、メディアサーバーに接続できない場合は実行失敗を表示し、元のカバーを保持します。

:::warning[書き戻しはメディアサーバーに依存します]
自動変更も手動変更と同様に、Jellyfin または Emby が設定・有効化されていることが前提です。サーバーが利用不可の場合は失敗を記録するだけで、カバーを破損させることはありません。
:::

## ライブラリに入って階層ごとに閲覧する

「ライブラリに入る」をクリックすると、一覧エリアが閲覧画面に置き換わり、上部が「戻る」とパンくずリストになります。パンくずはライブラリから現在のディレクトリまでのパスを示し、前の階層をクリックするとそこへ直接戻れます。

- **検索**：既定では現在のディレクトリのみを検索し、自動的には下の階層へ進みません
- **更新**：現在のディレクトリを再取得します
- **フォルダー**：カードで表示され、名前、種別、「N 項目」が表示されます。各フォルダーカードの右下に「カバーを変更」があります
- **項目**：テーブルで表示され、列はカバー、名前、種別、年、時間、操作です。1 ページ 24 件で、下部にページ送りがあります
- **戻る**：ルートでない場合は一つ上の階層へ、ルートの場合はメディアライブラリ一覧へ戻ります
- 現在のディレクトリに何もない場合は「現在のディレクトリは空です」と表示されます

フォルダーや作品のカバーを変更する場合も、同じカバー生成ダイアログを使用します。書き込み先がそのフォルダー / 作品になるだけです。書き込みに成功すると現在のディレクトリが再読み込みされ、画像がすぐに更新されます。

## 前提と制限

- **設定済みで利用可能な Jellyfin または Emby が必要**：カバーの書き戻し、更新、削除はすべてプレイヤーのインターフェースを通るため、プラグインが未設定または無効では実行できません。
- **動画は削除しない**：カバーの更新と削除はメタデータと画像のみを扱い、ライブラリ内の動画ファイルには触れません。
- **更新はバックグラウンドタスク**：クリックしてもすぐには結果が見えず、プレイヤーの処理完了を待ってからページを更新する必要があります。
- **素材はライブラリ内の作品画像**：画像カバーはプレイヤー内の既存作品のメイン画像を使用するため、ライブラリに画像がなければ生成できません。
- **自動カバー変更は既定でオフ**：ライブラリごとに個別に有効化し、新しい項目が増えて最小間隔を超えた場合にのみ変更。有効化後の最初のチェックはベースラインの確立のみで、すぐにはカバーを変更しません。
- **自動タスクは手動変更を上書きしない**：カバーが手動で変更されたことを検出すると自動上書きを停止します。再度引き継ぐには「今すぐ一度実行」をクリックし、確認ダイアログで上書きを続行する必要があります。

## よくある質問

| 現象 | 説明 |
| --- | --- |
| ライブラリカードがずっとプレースホルダーのまま | プレイヤーがメイン画像を返していない、または画像アドレスにアクセスできない。まず「画像を更新」をクリックして再度お試しください |
| 項目数が `-` と表示される | プレイヤーが項目数を返していません。AMMDS が集計していないわけではありません |
| 物理パスが空 | このライブラリがプレイヤーでディレクトリ未設定か、インターフェースが返していない |
| 「すべてのメディアライブラリをスキャン」がクリックできない | Jellyfin と Emby の両方が無効 |
| 「カバーを置き換える」が灰色 | 画像カバーの素材がまだ取得されていない、または送信中 |
| 自動カバー変更を有効にしたがカバーが変わらない | 有効化後の最初はベースライン記録のみ。その後は項目数が増えていない、または最小間隔に達していないためスキップされます。カードの実行時刻と結果をご確認ください |
| 自動カバー変更に「カバーが手動で変更されました」と表示される | プレイヤーまたは手動ダイアログでカバーを変更したため、自動タスクは上書きしません。「今すぐ一度実行」をクリックし、確認ダイアログで上書きを続行すると再び引き継ぎます |
| 自動カバー変更が失敗し続ける | メディアサーバーに到達できるか、ライブラリ内に作品画像があるかを確認してください。失敗理由は設定ダイアログの「最近の自動交換」とバックエンドログにあります |
| 「別の一批にする」をクリックしても変わらない | ライブラリ内の作品画像が少なく、同じものがランダムに選ばれています |
| 書き戻し後もプレイヤーで古い画像が表示される | プレイヤーのキャッシュが更新されていません。ライブラリのスキャンまたはメタデータの更新を一度実行してください |
