# システム設定項目の一覧と説明

システム設定には、サイト全体の動作に関する項目が集まっています。どのドメインでアクセスされるか、サイトの名前、通信を中継するか、通知を送るか、画面の配色、ログインの厳しさ、裏のリクエストの待ち時間です。このページでは七つのセクションを項目ごとに説明します。

## まず確認

**システム管理 → システム設定** を開きます。上部に七つのタブがあり、同時に表示されるのは一つです。タブごとに入力中の内容は保持され、再読み込みすると最後に見ていたセクションに戻ります。

| タブ | 扱う内容 |
| --- | --- |
| 基本設定 | ドメインの紐付け、インスタンス連携、API 公開、システムモード、ディスク監視、広告 |
| 外観 | ランディングページ、テーマ、背景と配色、追悼モード |
| 通知設定 | 通知の総スイッチ、メッセージ種別、夜間のサイレント |
| ネットワーク設定 | 中継のスイッチ、方式、ホストとポート、認証、対象外リスト |
| 管理画面設定 | 管理画面のタイムアウト（ブラウザに保存） |
| セキュリティ設定 | パスキー、二段階認証、シングルサインオン |
| サイト設定 | サイト情報、届出番号、フッターのリンク、検索と共有の表示 |

変更は設定テーブルに直接書き込まれ、ファイルの編集は不要です。システムモードを除けば、保存後すぐに反映されます。

## 1. 基本設定

### ドメインの紐付け（三つの手順、順番は変えない）

紐付け前は「未連携」、紐付け後は「連携済み」と表示されます。

| 手順 | ボタン | 動作 |
| --- | --- | --- |
| 1 | テスト | そのドメインがこのサーバーを指しているか確認します。紐付けは書き込みません |
| 2 | 検証トークンを生成 | サーバーがトークンを発行し、追加すべきテキストレコード（ホスト名はドメイン、値はトークン）を画面に出します |
| 3 | 検証して紐付け | サーバーがテキストレコードを確認し、通った場合だけドメインを書き込みます |

> **テキストレコード**：ドメインの設定に書く文字列の一種で、「このドメインは自分のものです」と示すためによく使います。ドメインを買った業者の管理画面で追加します。

> **DNS**：ドメインをサーバーの住所に変換する仕組みです。レコードを追加してから、世界中で引けるようになるまで少し時間がかかります。

:::warning[紐付けたいドメインで先に開く]
紐付けの前に、これから紐付けるドメインで AMMDS を開いてください。画面は入力されたドメインと、いま開いているドメインを比べます（通信方式、パス、ポート、大文字小文字は無視）。一致しないと拒否されます。レコードの確認ができないためです。
:::

### 設定項目：基本設定

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| ドメインの紐付け | どのドメインでアクセスされるか。上記の三手順で設定 | 不要。検証が通った時点で書き込まれます | `IP:ポート` でしかアクセスできず、ドメインが必要な機能（パスキー、インスタンス連携）は有効にできません |
| インスタンス連携 | 他の AMMDS とデータを共有するか。有効には、ドメインの紐付けと、ニックネーム・メール・電話番号の登録が必要 | 不要 | 既定はオフで共有しません。条件を満たさないとスイッチは戻り、理由が表示されます |
| API を公開 | 外部向けの API を開くか。オフにすると、鍵を持つプログラムも呼べません | 不要 | 既定はオフで、外部からは使えません |
| システムモード | 三種類：全体モード（公開サイトと管理画面）、管理画面のみ、API のみ | **再起動が必要** | 既定は全体モードです |
| サービスアドレス | 外部に公開する自分のアドレス。ドキュメントや検出に使われ、ログイン時に現在のアドレスで上書きされます | 不要 | 内蔵のアドレスを使います |
| ディスク監視 | オンにすると空き容量を定期的に確認し、不足時に通知します | 不要 | 既定はオフで、空き不足を知らせません |
| 広告を表示 | ページに広告を出すか | 不要 | 既定はオン。非課金ユーザーがオフにすると拒否され、「有料ユーザー以外は無効にできません」と出ます |

## 2. サイト設定

このセクションには「基本設定」と「検索と共有の表示」の二つの子タブがあります。

### サイト情報と届出番号

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| サイト名 | 公開ページのタイトルや共有の要約に出る名前 | 不要 | タイトルにサイト名が出ません |
| サブタイトル | 名前の下の小さな行 | 不要 | 表示されません |
| サイトの説明 | サイトを一言で紹介する文 | 不要 | 共有時の要約が空になります |
| 会社名 | フッターなどに出る運営者名 | 不要 | 表示されません |
| ICP 届出番号と照会リンク | 番号と、クリックした先の照会先 | 不要 | 番号が空なら表示されません |
| 公安届出番号と照会リンク | 同上。公安への届出です | 不要 | 番号が空なら表示されません |
| 営業許可の届出番号と照会リンク | 同上。営業許可証です | 不要 | 番号が空なら表示されません |
| 著作権の文言 | フッターの著作権表示 | 画面に編集入口はありません | 固定の内容です |
| フッターのクイックリンク | 「名前 + アドレス」を 1 行ずつ。上下に移動して順序を変更可。最大 20 件 | 不要 | リンクなし。保存時に名前かアドレスが空の行は捨てられます |

### 検索と共有の表示

> **SEO**：検索エンジンに見つけてもらいやすく、きれいに表示してもらうための設定です。

> **OG**：ソーシャルが読む記述のことで、リンクを共有したときのカードのタイトル・画像・要約を決めます。

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| 検索タイトル | 検索結果に出る大きな見出し | 不要 | サイト名で代用されます |
| 検索キーワード | カンマ区切りの語の並び | 不要 | 検索エンジンにキーワードが渡りません |
| 検索の説明 | 検索結果の下に出る説明文 | 不要 | 説明が空になります |
| 共有タイトル | ソーシャル共有時のカードの見出し | 不要 | 検索タイトルに戻ります |
| 共有の説明 | カードの本文 | 不要 | カードに説明が出ません |
| 共有画像 | カードの画像 | 不要 | カードに画像が出ません |
| カードの形式 | 小さな画像のカードか、大きな画像のカードか | 不要 | 既定の形式です |
| クローラーの規則 | 四つの既定から選択、または自分で記述 | 不要 | クローラーを制限しません |
| 正規アドレス | どのアドレスが本物か検索エンジンに伝え、重複登録を防ぎます | 不要 | 現在のアクセス先が使われます |

保存すると公開 API にはすぐ反映され、ページのタイトル類は次に開いたときか再読み込み時に更新されます。

## 3. ネットワーク設定

> **中継（プロキシ）**：プログラムが一旦別のサーバーにつなぎ、そこから外部へ出る仕組みです。直接つながらない環境で使います。

> **CIDR**：住所の範囲を短く書く方法です。一行でまとまり全体を表せます。

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| 中継のスイッチ | 中継を使うか | 不要。保存後ただちに通信部品が作り直されます | 既定はオフで直接接続です |
| 中継の方式 | HTTP、SOCKS4、SOCKS5 の三つ。提供元に確認してください | 不要 | 方式が違うとつながりません |
| 中継のホスト | 中継サーバーのアドレス | 不要 | スイッチがオンなのにホストが空だと、システム診断で異常になります |
| 中継のポート | 数値。1〜65535 | 不要 | 同上。範囲外の値も異常になります |
| 中継のユーザー名 | 中継が認証を要求するときに入力 | 不要 | 認証が必要な中継はつながりません |
| 中継のパスワード | 同上 | 不要 | 同上 |
| 対象外リスト | 中継を通さない宛先。ドメイン、アドレス、範囲、`*.cn` のようなワイルドカードが使えます。「ローカル」「プライベート住所」「特定ドメイン」の三つの既定から選んでも登録できます | 不要 | 既定で、自分のマシン、プライベート帯域、時刻確認用の幾つかのドメインが入っています |

ホストとポートはスイッチをオンにしてから編集できます。対象外リストから時刻確認用のドメインを消さないでください。時刻の確認が失敗する可能性があります。

:::tip[中継の変更は即時反映]
中継の設定を保存すると、通信部品が作り直され、内蔵のメタデータサービスも再起動します。アプリ全体の再起動は不要です。到達可否は、ダッシュボードのネットワーク診断で宛先ごとに確認できます。
:::

## 4. 通知設定

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| 通知の総スイッチ | 通知を送るかどうか | 不要 | 既定はオフで何も送られず、システム診断は「未使用」と記録します |
| メッセージ種別 | 送る種類にチェック：システム、購読、ダウンロード、取り込み、認証、会員、作品の情報取得、出演者の情報取得 | 不要 | チェックのない種類は送られません |
| 夜間のサイレント | オンにすると 22:00〜08:00 は送りません | 不要 | 既定はオフで、夜間も届きます |

各通知経路の鍵は統合アプリで設定します。総スイッチがオンなのに経路が一つも設定されていない場合、システム診断は警告を出します。

## 5. 外観

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| ランディングページを優先 | サイトを開いたとき、管理画面ではなく公開ページを先に出す | 不要 | 既定は管理画面です |
| テーマ | 画面のテーマ。クリックで切り替え | 不要 | 既定のテーマです |
| 背景と配色 | 背景画像と基調色 | 不要 | 既定の背景と配色です |
| 追悼モード | 開始と終了を設定すると、その間は白黒表示になります | 不要 | 使われません |

このセクションは配色と背景だけを変え、画面の配置は変えません。

## 6. セキュリティ設定

> **パスキー**：指紋、顔、端末の暗証番号でパスワードなしにログインする仕組みです。ドメインでの暗号化アクセスと、対応ブラウザが必要です。

> **二段階認証**：パスワードに加えて、スマートフォンの 6 桁の数字を入力します。パスワードが漏れても入られません。

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| パスキー | 指紋・顔・端末の暗証番号でのログインを許可するか | 不要 | 既定はオフ。条件を満たさないとボタンが押せません |
| 二段階認証 | 有効にすると四つの手順：説明を読む → QR を読み取る（手入力も可）→ 6 桁を入力 → 完了。最後に 8 個の一回限りの回復コードが発行されます | 不要 | 既定はオフで、パスワードのみです |
| シングルサインオン | 外部アカウントでのログイン。表示されたコールバック URL を相手側の許可リストに登録し、アプリを作成（名前、アイコン、ボタン文言、クライアント ID と秘密、対応づけ項目） | 不要 | 既定ではボタンが出ません |

二点注意があります。パスキーと外部アカウントのログインでは追加の数字入力は**不要**で、パスワードのときだけ求められます。外部アプリを削除すると、その入口はすぐに使えなくなります。

## 7. 管理画面設定

| 設定項目 | 何を決めるか / 入力方法 | 再起動 | 未設定の場合 |
| --- | --- | --- | --- |
| 資源検索のタイムアウト | 検索を最大何秒待つか。最小 12 | 不要。現在のブラウザだけに効きます | 既定値が使われます。小さすぎると検索完了前に打ち切られます |

ブラウザに保存されるため、サーバーには書き込まれず、別の端末やブラウザには引き継がれません。

## 画面で変更できない設定

次は導入時の環境変数または起動引数で決まり、画面に編集入口はなく、変更後は再起動が必要です。サービスポート、待ち受けアドレス、1 ファイルあたりのアップロード上限、1 リクエストあたりの上限、データベース接続、ログのレベル、スケジュールタスクの総スイッチ、ディレクトリ監視、ディスク警告のしきい値、そして未ログインの公開 API への制限（既定は毎分 100 回）です。

| 変更内容 | 反映のされ方 |
| --- | --- |
| 中継の設定 | 即時。通信部品が作り直され、内蔵のメタデータサービスが再起動します |
| プラグインの有効・無効、内蔵サービスの優先切替 | 内蔵のメタデータサービスが即時に再起動します |
| サイト購読の設定 | 対応する購読のスケジュールが即時に作り直されます |
| システムモード | 再起動が必要です |
| サイト情報と検索・共有の表示 | API には即時、ページは再読み込み後に更新 |
| 環境変数 | 再起動が必要です（コンテナなら作り直し） |

## 困ったときは

- **保存しても変わらない**：再起動が必要な項目（システムモード、環境変数）ではないか確認してください。サイト情報などは再読み込みが必要です。
- **ドメインが紐付かない**：そのドメインで開いているか、レコードが追加され引ける状態かを確認し、「テスト → トークン生成 → 検証して紐付け」をやり直してください。
- **中継を入れたら遅い、またはつながらない**：方式、ホスト、ポートを確認し、国内サイトを対象外リストに追加してください。
- **通知がまったく来ない**：総スイッチとメッセージ種別を確認し、統合アプリで経路の鍵が入っているかも確認してください。
- **パスキーのボタンが押せない**：ドメインでの暗号化アクセスか、ブラウザが新しいか、総スイッチがオンかを確認してください。
- **反映されたか確かめたい**：[システム診断、ログ、ストレージ、ライセンスとユーザー](./maintenance.md)で全体診断を実行すると、問題が一覧で出ます。
