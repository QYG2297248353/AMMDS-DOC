# シリーズ・メーカー・タグ

この三つのページはどれも映画そのものを保管するのではなく、映画を「分類」します。シリーズは複数の作品を一つにまとめて閲覧できる形にし、メーカーは発行元ごとに作品を集め、タグライブラリはサイト全体で共用する言葉の出所です。このページでは「やりたいこと」に沿って、作り方、作品の入れ方、そしてどの変更が登録済みの映画に効くか（効かないか）を説明します。

## はじめに

> **作品番号 / 識別コード**：ファイル名に入っている作品の識別番号です。シリーズライブラリもメーカーライブラリも、これで作品を逆引きします。

> **メタデータ**：作品の表紙、あらすじ、出演者、タグといった説明情報です。メーカー名、シリーズ名、タグはすべてここに書き込まれます。

> **NFO**：動画と同じ場所に置く小さな説明ファイルで、作品のメタデータが書かれています。メディアサーバーも読みます。

> **スクレイピング**：資料サイトから作品の表紙、あらすじ、出演者を調べて自動で埋めてくれることです。

> **別名**：同じものの別の書き方です。メーカーは資料源によって名前が違うことがあり、別名でその差を吸収します。

> **複数値入力**：一つの欄にいくつも値を入れられ、入力ごとに Enter で追加します。別名やタグなどがそうです。

> **名前による緩やかな関連**：両者は「名前が一致する」だけで結びついており、強く固定されているわけではありません。そのため書き方が変わると、集計にその作品が出てこなくなることがあります。

> **正規表現**：「ある書き方に合う文字列」を記号で表す規則で、識別コードをまとめて照合するのに使います。慣れない場合は他の二つの規則タイプを先に使ってください。

> **重み / 引用**：タグライブラリで、そのタグがどれだけ使われているかを示す数値です。よく使うタグを前に並べるためのもので、作品数の正確な値ではありません。

## シリーズ：複数の作品を一つのまとまりにする

### シリーズを探して作る

媒体管理 → 系列库（メディア管理 → シリーズライブラリ）に進みます：

| 場所 | 内容 |
| --- | --- |
| シリーズ検索 | キーワード（シリーズ名 / 説明）、作品の識別コード |
| クイック操作 | 「新建系列（シリーズを新規作成）」、行にチェックを入れると「删除（削除）」が出現 |
| データ表 | シリーズ、操作 |

「系列（シリーズ）」列が情報の本体です。左に表紙、右にシリーズ名（押すと詳細へ）、説明と「N 部作品（N 作品）」ラベルが並びます。「操作」列には**详情（詳細）、分享（共有）、编辑（編集）、删除（削除）**があります。検索欄の「作品识别码（作品の識別コード）」はシリーズの逆引き用です。番号を一つ入れると、その作品を含むシリーズが見つかります。

新規作成と編集は同じダイアログで、項目は三つだけです：

| 項目 | 説明 |
| --- | --- |
| 表紙 | クリックまたはドラッグで画像をアップロード。削除して再アップロードも可 |
| シリーズ名 | 必須 |
| シリーズの説明 | 任意 |

:::note[表紙の規格]
表紙のアップロードは画像のみ、上限 10 MB です。アップロード後は縦長のサムネイルで表示されます。
:::

### シリーズに作品を入れる

一覧の行で「详情（詳細）」を押すかシリーズ名を押すと詳細ページに進みます。上部にシリーズ名と「N 部作品（N 作品）」、右に**編集**と**共有**、左に表紙と説明、右に作品エリアのツールバーと作品表——**添加作品（作品を追加）**、**批量导入（一括取り込み）**、チェック後に現れる**移出系列（シリーズから外す）**、そして「按作品名称筛选（作品名で絞り込む）」検索欄があります。表の各行は連番、作品（表紙 + タイトル + 識別コード + 発行日）、操作（表示、外す）で、「查看（表示）」はその映画の詳細編集ページに飛びます。

**添加作品（作品を追加）**（すでにある映画ライブラリから選ぶ）：

1. 「添加作品（作品を追加）」でダイアログを開きます。
2. 「搜索媒体库作品（ライブラリの作品を検索）」欄でタイトルから映画ライブラリを検索します。
3. 作品を一つ以上チェックし、「添加选中（N）（選択した N 件を追加）」を押します。
4. 完了すると、追加できた作品数のメッセージが出ます。

**批量导入（一括取り込み）**（識別コードでシリーズ全体を一度に整理）：

1. テキスト欄に識別コードを貼り付けます。カンマ、改行、スペース、セミコロンで区切れます。例：

   ```
   SSIS-001, IPX-002
   MIDE-003
   ABP-004
   ```

2. 「开始导入（取り込み開始）」を押します。
3. ライブラリにある作品はそのままシリーズに追加され、無い作品はオンライン検索での取り込みを試みます。
4. 結果には成功数が示され、失敗したものは「识别码（識別コード）」と「失败原因（失敗理由）」が出ます。

:::warning[オンライン取り込みが依存するもの]
一括取り込みの「ライブラリに無ければオンライン検索」の段階は、有効な資料源に依存します。資料源が未設定か到達できないとき、その識別コードは失敗理由として返ってきます。先に連携アプリで資料源を設定してください。
:::

**移出系列（シリーズから外す）**：1 件なら行内の削除ボタン、まとめてならチェック後の「移出系列（シリーズから外す）」を使い、どちらも確認が出ます。外すのは作品とシリーズの関連だけで、映画の項目そのものは削除しません。

### 映画の「シリーズ」項目と混同しない

映画の詳細編集ページにも「系列信息（シリーズ情報）」というグループがあり、その作品が属するシリーズ名とシリーズ内での説明を記録します。これは**映画のメタデータ**に属し、シリーズライブラリのシリーズとは別のデータです：

| データ | 管理する場所 | 用途 |
| --- | --- | --- |
| 映画のシリーズ項目 | 映画ライブラリ → 詳細編集 → シリーズ情報 | その 1 件の映画のメタデータと NFO に書き込む |
| シリーズ実体 | シリーズライブラリ → シリーズ詳細 | 作品をまとめ、シリーズページやシリーズ共有を作る |

そのため作品をシリーズライブラリに入れるには、明示的に「添加作品（作品を追加）」か「批量导入（一括取り込み）」が必要です。映画のメタデータにシリーズ名を書いただけでは自動的に所属しません。

## メーカー：作品を発行元ごとに自動で集める

### メーカーを探して作る

媒体管理 → 厂牌库（メディア管理 → メーカーライブラリ）に進みます：

| 場所 | 内容 |
| --- | --- |
| 操作バー | 左に「创建厂牌（メーカーを作成）」「识别码归属测试（識別コードの归属テスト）」、右に「搜索厂牌名称或别名（メーカー名または別名で検索）」 |
| カード | メーカーごとに 1 枚、押すと詳細を開く |

検索欄は入力した瞬間に絞り込み、空にすると全件に戻ります。一覧は作品総数の降順で、作品の多いメーカーが前に並びます。

カードの情報：

| 要素 | 説明 |
| --- | --- |
| 画像 | マウスを重ねると「更换图像（画像を変更）」が出て、押すとすぐ差し替え |
| 名前 | メーカー名。右の星は「重点关注（重点フォロー）」の印 |
| 種類ラベル | 制作会社 / 発行会社 / 芸能事務所 / その他 |
| タグ | 先頭の 2 つまで表示、残りは「+N」にまとめられる |
| 集計 | 「N 部影视 · N 部剧集（映画 N 件 · ドラマ N 件）」、規則があれば「N 条规则（規則 N 件）」を追加 |
| 削除 | カード上の削除ボタン |

「创建厂牌（メーカーを作成）」で次を入力します：

| 項目 | 説明 |
| --- | --- |
| メーカー名 | 必須。映画のメタデータの制作会社名と一致させること。最長 100 文字 |
| メーカー種類 | 制作会社 / 発行会社 / 芸能事務所 / その他 |
| 設立年 | 1800–2200 の整数 |
| 国 / 地域 | 例「日本」 |
| 公式サイト | `https://` で始めること。詳細ページから開けます |
| 別名 | 複数値、入力後 Enter |
| タグ | 複数値、入力後 Enter |
| 説明 | メーカーの紹介、最長 500 文字 |
| メーカー画像 | ダイアログ右側でアップロード、押して差し替え可 |

:::tip[名前はメタデータと一致させる]
メーカーと作品は名前で緩やかに関連づくため、「厂牌名称（メーカー名）」は映画のメタデータの制作会社名と完全に一致させないと、集計にその作品が出てきません。資料源によって書き方が違うときは「别名（別名）」で差を吸収します。
:::

:::warning[メーカーを削除した影響]
削除するとそのメーカーの規則と除外項目も一緒に消えますが、**映画やドラマのメタデータは一切変更しません**。すでに作品に書き込まれたメーカー名は残ります。
:::

### 識別コードの規則で作品を自動的に取り込む

メーカーの作品の入り口は二つ、**手動追加**と**識別コードの規則による自動収納**です。別名は照合用、規則は归属の自動判定用です。

メーカー詳細 →「识别码规则（識別コード規則）」タブで管理します：

| 項目 | 説明 |
| --- | --- |
| 規則タイプ | 識別コードの接頭辞 / 識別コード完全一致 / 正規表現 |
| 照合式 | 選んだタイプに合わせて入力。最長 200 文字 |
| 命中後に書き込む先 | 制作会社 / 発行会社 / 制作 + 発行 |
| 優先度 | -9999～9999。複数の規則が同時に命中したときの並びに使う |
| 有効 | オフにするとその規則は判定に参加しない |
| 説明 | 規則の根拠のメモ。例「このメーカーは SSIS シリーズの発行権を持つ」 |
| 保存後 | 「立即按规则收纳作品到影视元数据（規則ですぐに作品を映画メタデータへ収納）」にチェック可 |

「预览命中数量（命中数のプレビュー）」は、保存せずにその規則が何件に命中するかを先に確認できます。保存するか決める前に使ってください。

归属の判定と収納の流れ：

1. 映画の項目を保存するとき、**有効な**規則に従ってメーカーを制作会社 / 発行会社へ自動で書き込みます。
2. メーカー詳細の「立即收纳作品（すぐに作品を収納）」（規則タブでは「立即收纳（すぐ収納）」）から手動で一度実行もできます。
3. 規則に命中して収納された作品は、カードに命中した規則名が表示され、どの規則で入ったか遡れます。
4. 作品を外すと、システムが**除外項目**を 1 件記録し、次回の自動収納でまた引き戻されるのを防ぎます。

:::note[規則を削除しても巻き戻らない]
識別コード規則の削除はその後の判定にだけ影響し、すでに映画のメタデータへ書き込まれたメーカー名は巻き戻りません。
:::

上部の「识别码归属测试（識別コードの归属テスト）」は規則タブ内のテスト欄と同じです。識別コード（例 `SSIS-001`）を入れると命中したメーカーと対応する式を返し、命中しないときは「未命中任何厂牌规则（どのメーカー規則にも命中しませんでした）」と表示されます。規則を調整するときは先にこれで確認すると、保存してから結果を見るより速いです。

### メーカー詳細で他に何を変えられるか

カードを押すと詳細のドロワーが開きます。ヘッダーは画像、名前、種類、重点フォローの星、国、設立年、公式サイト、説明、タグ、別名、そして三つの集計——**映画数、ドラマ数、識別コード規則数**です。下に三つのタブがあります：

- **作品**：上部のラジオ「全部 / 影视 / 剧集（すべて / 映画 / ドラマ）」でメディア種類を切り替え、右で「标题或识别码（タイトルまたは識別コード）」検索できます。「添加作品（作品を追加）」ダイアログではタイトルか識別コードで映画を検索し、すでにメーカーにある項目は「已在厂牌（メーカー登録済み）」と表示され追加できません。作品カードは種類の角印、タイトル、識別コード、年、命中元、命中規則を表示し、操作は「查看（表示）」（対応する映画・ドラマの編集ページへ）と「移出（外す）」。下部にページ送りがあります。
- **识别码规则（識別コード規則）**：式と説明、有効スイッチ、編集・削除を並べた表です。上に「添加规则（規則を追加）」「立即收纳（すぐ収納）」、右上で識別コードの归属テストができます。
- **资料（資料）**：メーカー種類、設立年、国 / 地域、公式サイト、別名、タグ、説明、「重点关注（重点フォロー）」スイッチを変更できます。保存するとカードと集計も更新されます。

:::tip[重点フォロー]
「重点关注（重点フォロー）」は印にすぎず、カードに星を表示するためだけのものです。作品の収納ロジックは変わりません。
:::

## タグ：サイト全体で共用する言葉の出所

### 三層構造

タグライブラリは、映画・ドラマ・俳優・漫画・小説の五種類の編集ページで選べる候補の唯一の出所です。

| 階層 | 意味 | 数 |
| --- | --- | --- |
| メディア種類 | 内容の大きな分類。五つに固定 | 5 |
| 分類 | 各メディア種類の下にあるタグの組。システム既定 + ユーザー作成 | 5 + N |
| タグ | 具体的な語。別名・色・重みを持つ | 無制限 |

五つのシステム既定分類：

| カード名 | メディア種類 | タグタイプ |
| --- | --- | --- |
| 影视标签（映画タグ） | 映画 | `tag_movie` |
| 剧集标签（ドラマタグ） | ドラマ | `tag_tv` |
| 演员标签（俳優タグ） | 俳優 | `tag_actor` |
| 漫画标签（漫画タグ） | 漫画 | `tag_comic` |
| 小说标签（小説タグ） | 小説 | `tag_novel` |

ユーザー作成の分類はいずれかのメディア種類の下に置く必要があるため、システム分類と同じメディア種類の絞り込みを共有します。

### ページとカード

媒体管理 → 标签库（メディア管理 → タグライブラリ）に進みます：

| 場所 | 内容 |
| --- | --- |
| 操作バー | 左に「创建分类（分類を作成）」、右に種類の絞り込みプルダウンと「搜索标签或别名（タグまたは別名で検索）」 |
| カード | 1 枚が 1 分類、1 行に最大 4 つ |

上部の種類の絞り込みを切り替えると、そのメディア種類のカードだけ残ります。検索欄はタグ名か別名で絞り込みます。

カードのタイトルは分類名で、システム分類は「メディア種類 + 标签（タグ）」で命名されます（例「影视标签（映画タグ）」）。タイトル横のバッジに「系统（システム）」か「用户（ユーザー）」が表示されます。右上に「共 N 个（合計 N 件）」、つまりその分類のタグ数が出ます。ユーザー作成の分類は削除でき、削除すると分類の下のタグは**システム既定の分類へ戻り**、タグは失われません。カード内はタグの表で、タグ名（設定した色で着色）、「引用（参照）」値、編集 / 削除の二つの操作があります。

### 分類の作成、タグの追加と編集

「创建分类（分類を作成）」で名前（最長 30 文字）を入れ、メディア種類を一つ選ぶだけです。分類はタグを整理するためだけのもので、内容の検索ロジックには参加しません。

カードのツールバー右の「添加（追加）」か、タグ行の編集アイコンを押します：

| 項目 | 説明 |
| --- | --- |
| 名前 | 必須、最長 50 文字。整理時に**主名称**として NFO に書き込まれます |
| 別名 | 複数値、入力後 Enter、いくつでも可 |
| 色 | パレットの 10 色から選ぶか、HEX 値を直接入力（既定 `#165dff`） |

:::note[別名の役割]
資料源が同じ概念を違う書き方で返すことがあります（日中英、簡体字 / 繁体字、略称など）。その差を「别名（別名）」に入れると照合時に別名でも認識され、NFO に書き込むときは主名称が使われます。
:::

:::warning[タグ削除の境界]
タグの削除はタグライブラリから語を取り除くだけで、**保存済みのメタデータには影響しません**。映画や俳優などの項目にすでに書き込まれた種類やタグの文字は残り、以後は候補から選べなくなるだけです。
:::

### 重みと「引用」

各タグには重みがあり、カードの表では「引用（参照）」列に表示されます：

- タグが 1 回命中するごとに重みが 1 増えます；
- システムは定期的に減衰させ、1 回あたり最大 10%（切り捨て）、**1 を下回ることはありません**；
- つまり人気の指標で、「参照されたおおよその回数」であり、正確な作品数ではありません。

並び替えと表示はこれを使ってよく使うタグを前に出し、編集ページで素早く選べるようにします。

### 日々どこで使うか

タグライブラリ自体には二つの検索があります。メディア種類でカードを絞り込む、タグ名か別名で探す、の二つです。より普段使う入り口は、各内容の編集ページにあるタグのプルダウンです：

| 編集ページ | 検索するタグタイプ |
| --- | --- |
| 映画の詳細編集 → 種類 / タグ | 映画タグ |
| ドラマ編集 → 種類 / タグ | ドラマタグ |
| 俳優詳細 → タグ / スタイル / 特徴 | 俳優タグ |
| 漫画・小説の編集 | それぞれのタグタイプ |

これらのプルダウンはすべてタグライブラリを検索し（システム分類 + ユーザー作成分類の両方が見えます）、新しい語の直接入力にも対応します。ライブラリに無い値は新しいタグとして一緒に送信されます。

:::tip[一括管理の利点]
どこかの編集ページで作ったタグはタグライブラリの対応する分類に戻るので、次はどの項目でも選べます。同義語をまとめて整理したいときは、ここの別名を 1 回直せばすべての参照元に反映されます。
:::

## 設定項目の説明

| 設定項目 | 何を入れるか | 空 / 間違えた場合 |
| --- | --- | --- |
| シリーズ名 | 必須 | 空だとシリーズを作れません |
| シリーズの表紙 | 画像、上限 10 MB | 画像以外やサイズ超過はアップロードできません。縦長のサムネイルで表示されます |
| 作品の識別コード（シリーズ検索） | 番号を一つ | その作品を含むシリーズの逆引きに使います |
| 一括取り込みの識別コード | 複数を貼り付け、カンマ・改行・スペース・セミコロンで区切る | ライブラリに無く資料源も無い場合、「失败原因（失敗理由）」として返ります |
| メーカー名 | 必須、最長 100 文字、映画メタデータの制作会社名と完全に一致 | 書き方が違うと集計に出ません。「别名（別名）」で差を吸収します |
| メーカー種類 | 制作会社 / 発行会社 / 芸能事務所 / その他 | 分類ラベルにすぎません |
| 設立年 | 1800–2200 の整数 | 範囲外は受け付けられません |
| 公式サイト | `https://` で始める | これ以外だと詳細ページのリンクが開きません |
| 別名 / タグ（メーカー） | 複数値、入力ごとに Enter | Enter を押さないと追加されません |
| 説明（メーカー） | メーカーの紹介、最長 500 文字 | 文字数超過は受け付けられません |
| 規則タイプ | 識別コードの接頭辞 / 完全一致 / 正規表現 | 種類を誤ると命中しない、または当たりすぎます |
| 照合式 | 選んだタイプに合わせて入力、最長 200 文字 | 誤ると作品に命中しません。先に「预览命中数量（命中数のプレビュー）」か「识别码归属测试（归属テスト）」で確認を |
| 命中後に書き込む先 | 制作会社 / 発行会社 / 制作 + 発行 | 誤ると違う項目に書き込まれます |
| 優先度 | -9999～9999 | 複数規則が同時命中したときの並び。誤ると違うメーカーが選ばれます |
| 有効（規則） | スイッチ | オフだと判定に参加しません |
| 識別コードの归属テスト | 識別コードを一つ、例 `SSIS-001` | 命中しないと「未命中任何厂牌规则（どのメーカー規則にも命中しませんでした）」と出ます |
| 分類名 | 最長 30 文字、メディア種類を一つ | 分類はタグの整理だけで、検索ロジックには参加しません |
| タグ名 | 必須、最長 50 文字、主名称として NFO に書き込む | 空だとタグを作れません。主名称が NFO の文字を決めます |
| タグの別名 | 複数値、入力ごとに Enter | 空だと主名称だけが照合され、同じ概念の別の書き方を認識できません |
| タグの色 | 10 色、または HEX 値（既定 `#165dff`） | カード上の着色にだけ影響します |
| 種類 / タグのプルダウン入力 | 候補から選ぶか、新しい語を直接入力 | ライブラリに無い値は新しいタグとして一緒に送信されます |

## 困ったときは

- **シリーズライブラリに入れた作品がシリーズページに出ない**：映画のメタデータにシリーズ名を書いても自動では所属しません。「添加作品（作品を追加）」か「批量导入（一括取り込み）」を明示的に使ってください。
- **一括取り込みで失敗が多い**：まず「失败原因（失敗理由）」を見てください。多くは資料源が無効か到達できないためです。連携アプリで資料源を設定してから再実行します。
- **メーカーの集計に一部の作品が出ない**：メーカーは名前で緩やかに関連づくため、「厂牌名称（メーカー名）」を映画メタデータの制作会社名と完全に一致させてください。書き方が違う場合は「别名（別名）」に追加します。
- **収納した作品を外せない / また戻ってくる**：外すと除外項目が記録され、次回の自動収納で引き戻されなくなります。規則の削除はその後の判定にだけ効き、すでにメタデータにあるメーカー名は巻き戻りません。
- **規則がうまく当たらない**：先に「预览命中数量（命中数のプレビュー）」で何件命中するか見るか、「识别码归属测试（归属テスト）」で識別コードを一つ入れて結果を確認し、それから保存するか決めてください。
- **タグ / 分類 / メーカーを消してデータが消えないか心配**：タグの削除は語だけ、ユーザー分類の削除はタグがシステム既定へ戻る、メーカーの削除は映画・ドラマのメタデータを一切変更しません。書き込まれた文字は残り、候補から選べなくなるだけです。
- **「引用（参照）」が作品数と合わない**：減衰する人気の指標で、正確な数ではありません。よく使うタグが前に並ぶのは編集ページで選びやすくするためです。
