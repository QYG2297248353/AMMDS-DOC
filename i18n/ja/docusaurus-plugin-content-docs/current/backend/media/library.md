# 映像・ドラマ・俳優

スキャンとスクレイピングで項目が入ったあとの日々の手入れは、この三つのページで行います。映画ライブラリは単独の作品、ドラマライブラリは一作品のシーズンと各話、俳優ライブラリは人物と作品の関連を管理します。「何をしたいか」順に、探す・補う・直す・消す方法と、元に戻せない操作を説明します。

## はじめに

> **作品番号 / 識別コード**：ファイル名に含まれる識別番号です。検索欄では「番号」、詳細・編集画面では「识别码」と呼ばれますが同じもので、一作品に複数持てます。

> **メタデータ**：作品の表紙・あらすじ・出演者・タグなどの説明情報です。

> **スクレイピング**：情報サイトから作品の表紙・あらすじ・出演者を調べて自動で埋めることです。

> **サイト ID**：TMDB、Bangumi、IMDb などの情報サイトがドラマに付ける番号で、サイトをまたいで同じ作品を合わせるのに使います。

> **紐付け**：ライブラリの記録と、ディスク上の動画ファイル（または別の既存記録）を結びつけ、「このファイル / この作品のことだ」と分からせることです。

> **複数値入力**：一つの枠にいくつもの値を入れられ、入力ごとに Enter で追加します。タグ、类型（区分）、別名などがそうです。

## 記録を探して読む

三つのライブラリはどれも 媒体管理（メディア管理）配下で、作りは似ています。上が検索条件、中央がショートカット、下が表またはカードです。

### 映画ライブラリ

媒体管理 → 影视库（メディア管理 → 映画ライブラリ）へ進みます。

| 領域 | 内容 |
| --- | --- |
| 検索条件 | 标题（題名）、番号、演员（出演者）、类型（区分）、标签（タグ）、系列（シリーズ）の六つ。右に「搜索（検索）」「重置（リセット）」 |
| ショートカット | 左に「添加媒体（媒体を追加）」「搜索影视（作品を検索）」。行にチェックを入れると「合并媒体（媒体を統合）」「删除媒体（媒体を削除）」が出現。右に「来源（出典）」ドロップダウン |
| データ表 | 番号、表紙、情報、タグ、出演者、操作。下部にページ送りと 1 ページ件数 |

| 検索項目 | 一致の方法 |
| --- | --- |
| 标题 | 原題と中国語題名をあいまい一致 |
| 番号 | 識別コードで一致 |
| 演员 | 出演者名で一致 |
| 类型 | 複数値、いずれかが命中すれば可（入力後 Enter） |
| 标签 | 複数値、いずれかが命中すれば可 |
| 系列 | シリーズ名で一致 |

「信息（情報）」列には識別コード、中国語題名（無ければ原題に戻る）を出し、その下に**公開日、上映時間、レーティング、評価**をラベルで並べ、宣伝文があればもう一行使います。「标签」「演员」の二列はその記録のタグと出演者名をそのまま出します。

:::tip[二つの検索方法は別です]
右上の「来源（出典）」ドロップダウンは切り替えると即座に再検索します。「搜索条件」の変更は「搜索（検索）」を押して初めて送信され、「重置（リセット）」はフォームを空にするだけで再検索しません。
:::

### ドラマライブラリ

媒体管理 → 剧集库（メディア管理 → ドラマライブラリ）へ進みます。

| 領域 | 内容 |
| --- | --- |
| 検索条件 | 題名、識別コード、出演者、类型（区分）、标签、状态（状態）。右に「搜索」「重置」 |
| ショートカット | 「新建剧集（ドラマを新規作成）」「搜索剧集（ドラマを検索）」。チェックを入れると「删除（削除）」が出現。右に「来源（出典）」ドロップダウン |
| データ表 | 番号、表紙、ドラマ情報、分区（区分）、出典、季 / 話、更新日時、操作 |

| 検索項目 | 一致の方法 |
| --- | --- |
| 标题 | ドラマ名、原名、中国語名に一致 |
| 识别码 | TMDB / Bangumi / IMDb などのサイト ID |
| 演员 | 出演者名で一致 |
| 类型 | 分区（区分）。値はアプリが配信します |
| 标签 | 複数値、入力後 Enter |
| 状态 | 连载中（連載中）/ 已完结（完結） |
| 来源 | データ源。「全部」を選ぶと絞り込みなし |

「季 / 集」列は「N 季」「N 話」の二行です。各行の右に**分享（共有）、详情（詳細）、编辑（編集）、删除（削除）**が並びます。検索項目の「类型（ジャンル）」は実際には「分区（区分）」を指します。「来源（出典）」の選択肢はアプリが配信するもので、固定ではありません。

:::note[再生は管理画面にありません]
ドラマのファイル紐付け、利用可否の検証、季映射（シーズン対応）は管理画面でだけ見られ、操作できます。公開側のドラマ詳細はメタデータと季・話の構成だけを出し、ファイル一覧もプレイヤーもありません。視聴には外部プレイヤーかメディアサーバーをお使いください。
:::

### 俳優ライブラリ

媒体管理 → 演员库（メディア管理 → 俳優ライブラリ）へ進みます。

| 領域 | 内容 |
| --- | --- |
| 検索条件 | 姓名（名前）、性别（性別）、退役、已故（物故）、标签、风格（スタイル）、特征（特徴）、年齢スライダー |
| ショートカット | 「新增演员（俳優を追加）」「搜索演员（俳優を検索）」。チェックを入れると「合并演员（俳優を統合）」「删除演员（俳優を削除）」が出現。右に「来源（出典）」ドロップダウン |
| データ表 | 番号、名前、事務所、デビュー日、国籍、操作 |

| 検索項目 | 内容 |
| --- | --- |
| 姓名 | 俳優名をあいまい一致 |
| 性别 | 男性 / 女性 / 人妖（その他） |
| 退役 | 引退済み / 現役 / 全部 |
| 已故 | 物故 / 存命 / 全部 |
| 标签 / 风格 / 特征 | 三つの独立したタグ軸で、それぞれ複数値入力 |
| 年龄 | スライダーの段階：全部、20 歳、20–30、30–40、40 歳 |

「姓名」列が主体です。左に大写真、右に名前とラベル（性別、年齢、特徴、スリーサイズ、引退 / 物故の状態）。残る列は事務所、デビュー日、国籍で、最後の列は**分享、详情、删除**です。映画ライブラリと同じく、「来源」は切り替えで即再検索、フォームの条件は「搜索」で送信、「重置」はフォームを空にするだけです。

## 作品を判別しているもの

一作品に複数の識別コードを持て、画面では二つの呼び方があります。

| 場所 | 内容 |
| --- | --- |
| 検索条件 → 番号 | 識別コードで検索 |
| 一覧 → 信息 | 題名の前にその記録の最初の識別コードを表示 |
| 詳細引き出し → 识别码 | すべての識別コード。複数ならカンマ区切り |
| 高级编辑 → 识别码 | 複数値入力。追加・削除・自由入力ができます |

識別コードはスキャン時に認識規則でファイル名から取り出して正規化したものです。そのため同じ作品の表記違いは一つの記録に収束します。規則はタスク管理欄で設定します。手作業で作品を追加するときは識別コードを自分で書けて、購読はそれを頼りに後続の資源を追います。

## 新しい記録を追加する

### 映画：搜索影视（作品を検索）

「搜索影视（作品を検索）」を押してオンライン検索のダイアログを開き、番号か題名を入れて Enter を押します。

1. 検索履歴は最大 20 件、ブラウザ内に保存され、クリックで再利用できます。
2. 結果カードには番号、公開日、データ源、題名が出て、右上に三つのボタンがあります。

| ボタン | 動作 |
| --- | --- |
| 导入（取り込み） | 映画ライブラリへ書き込み、一覧を更新してダイアログを閉じます |
| 收藏（お気に入り） | まず取り込み、それからお気に入りへ追加 |
| 订阅（購読） | まず取り込み、番号で購読を作り、購読タスクに後続の資源を追わせます |

3. 結果が無いときは履歴検索エリアを出し、初期状態では「搜索一下，试试看吧（検索してみましょう）」と表示します。

お気に入りと購読はユーザー単位の印です。「暂停 / 恢复 / 退订（一時停止 / 復元 / 解除）」といった後続の状態は購読管理が担当し、このページでは扱いません。

### ドラマ：搜索剧集（ドラマを検索）

「搜索剧集（ドラマを検索）」は単独のドラマを手で補録するためのものです。

1. ドラマ名のキーワード（例 `葬送のフリーレン`）を入れて Enter。キーワードはローカルの検索履歴に最大 20 件残ります。
2. 候補カードには縦長ポスター、年、データ源、**一致スコア**（小数第三位まで）が出ます。
3. 「导入（取り込み）」を押すと季番号の入力枠が出ます。空ならそのデータ源の全季、`0` は特別編、`1`～`99` はその季だけを取り込みます。
4. 成功すると「导入成功，可在剧集详情中完善元数据与季集（取り込み成功。ドラマ詳細でメタデータと季・話を整えられます）」と出ます。

:::note[取り込みはまず統合します]
データ源に同じサイト ID が既にある場合は、重複して新規作成せず**既存のドラマに合流**します。取り込みは登録だけで、その後の季・話とファイルは詳細ページでの手入れが必要です。
:::

### 俳優：追加と検索

「新增演员（俳優を追加）」は編集ページで手入力、「搜索演员（俳優を検索）」はオンライン検索してから取り込みます。入力を減らす順序は、まず「搜索演员」で取り込み、次に編集ページで名前と別名を確認、最後に「在线搜索补充元数据（オンラインでメタデータを補う）」で現在の俳優に足りない項目を埋める、です。

## 詳細を見て項目を直す

### 映画の詳細引き出し

一覧の題名をクリックすると「媒体详情（媒体の詳細）」引き出しが開きます。

| ブロック | 内容 |
| --- | --- |
| 左側 | 表紙、下に上映時間・レーティング・評価のラベル |
| 説明項目 | 題名、識別コード、公開日、上映時間、評価、レーティング、監督、出演者、制作会社。空の値は行を取りません |
| あらすじ | 大筋と詳細の二段 |
| 类型 / 标签 | 二組の色付きラベル |
| スタッフ・出演者 | 監督と出演者。出演者は「饰 役名」を付けられます |
| 画像 | 背景、サムネイル、スチールの三組のカルーセル |

画像内の高精細画像は先頭に繰り上げられます。画像をクリックすると全画面プレビューになり、左右キーで循環、`Esc` で閉じます。引き出し下部に四つのボタン：**编辑元数据（メタデータ編集）、在线搜索补充（オンラインで補完）、高级编辑（詳細編集）、关闭（閉じる）**。

「编辑元数据」はよく使う項目だけを触り、保存すると一覧と引き出しの両方が更新されます。

1. 題名（中国語）、原題、評価（0–10、刻み 0.1）。
2. 公開日、上映時間（分）、レーティング、言語、国。
3. 宣伝文、类型、标签、制作会社、監督。
4. 大筋と詳細、二つの長文。
5. 「绑定演员（出演者を紐付ける）」では複数行を追加でき、俳優名 + 役名を入れます。役名は空でもよく、名前が空の行は送信されません。

ダイアログは開くときに完全な詳細を取ってから埋め戻し、保存時はオブジェクト全体を送るため、**ダイアログに出ていない項目が空になることはありません**。

一つの記録で項目が足りないときは「在线搜索补充」を使います。番号か題名で検索 → 結果カードの「补充到当前影视（現在の作品に補完）」を押す → まず候補を登録し、現在の項目と**統合**して、一覧と引き出しを更新します。

:::note[統合と補完は別物です]
「合并媒体（媒体を統合）」は既存の二記録を手で一つにすること。「补充（補完）」は候補を取り込んでから自動統合することで、一記録の項目埋めに向きます。
:::

### ドラマの詳細と編集

一覧の行で「详情（詳細）」を押すとドラマ詳細ページへ。上部に**重新刮削（再スクレイピング）**と**编辑元数据（メタデータ編集）**の二つがあり、本文は上から順に次です。

| ブロック | 内容 |
| --- | --- |
| ヘッダー | ポスター、題名と原題、ラベルで年、初回放送日、状態、評価、評価人数、順位、1 話の長さ、レーティング、言語、区分、出典 |
| 概要 | 类型、标签、制作会社、国 / 地域、監督、脚本、サイト ID、あらすじ |
| 出演者 | 名前と役名の二列 |
| 季一覧 | 季番号（特別編は別表示）、季名、初回放送日、当季の話数（登録済み / 総数） |
| 話一覧 | `SxxExx`、題名、放送日、長さ、評価、类型、および「再生可能ファイル」列 |
| シーズン対応 | ローカル季番号、データ源、データ源項目 ID、紐付け方式、話番号オフセット、データ源の話数、備考 |

「重新刮削」にはデータ源、データ源項目 ID、季番号（`0`～`99`）が必要です。更新は**このドラマに合流**し、二つ目のドラマは作られません。

一覧の「编辑」と詳細の「编辑元数据」はどちらもドラマ編集ページを開き、次を管理できます。

- **基本情報**：題名、原題、中国語題名、並べ替え用題名、表示題名、状態、評価、初回放送日、年、1 話の長さ、レーティング、言語、国 / 地域、区分、宣伝文、大筋、あらすじ、中国語あらすじ。
- **分類情報**：类型、标签（ドラマ用タグライブラリから）。
- **制作情報**：制作会社、国 / 地域、監督、脚本、および TMDB / Bangumi / TVDB / IMDb の四種のサイト ID。
- **出演者**：名前と役名を追加・削除。
- **シリーズと季・話**：シリーズ所属、および季（季番号、当季話数、季名、初回放送日、季の説明）と話（話番号、絶対話番号、題名、放送日、長さ、类型、評価など）。
- **画像**：表紙と背景。アップロード・削除・並べ替えに対応。

保存するとドラマ一覧へ戻ります。

### 俳優の項目

「新增演员」と行内の「详情」はどちらも俳優の詳細・編集ページを開き、六つのグループに分かれます。

| グループ | 項目 |
| --- | --- |
| 基本情報 | 名前（必須）、性別（男性 / 女性 / 人妖）、別名、生年月日、年齢、国籍 |
| 体型情報 | 身長、体重、血液型、バスト、ウエスト、ヒップ。女性はカップサイズ、男性は長さを表示 |
| 経歴情報 | デビュー日、評価（0–10）、事務所、引退の有無、物故の有無 |
| ソーシャルリンク | プラットフォーム + リンク、行の追加・削除可 |
| 特徴タグ | 标签、风格、特征 の三項。いずれも俳優タグライブラリから |
| 紹介と拡張 | 紹介の長文、任意のキーと値の拡張項目 |

右の画像エリアに二種類：大写真（2:3、1 枚、再アップロード・削除・クリックでプレビュー）とポスターウォール（3:4、複数、一括アップロードと削除）。性別は体型項目の表示に影響し、女性なら「カップサイズ」、男性なら「長さ」が出て、切り替えて初めて対応項目が現れます。

引き出しの左側には大写真、基礎情報、体型、タグ、スタイル、紹介が並び、下部に**在线搜索补充元数据（オンラインでメタデータを補う）、编辑演员（俳優を編集）、关闭（閉じる）**の三つです。

## 画像を管理する

### 映画の詳細編集

画像操作は「高级编辑（詳細編集）」ページに集まっています（「添加媒体」と詳細の「高级编辑」は同じページを開きます）。

| 画像 | 推奨比率 | できること |
| --- | --- | --- |
| 表紙 | 2:3 | クリックまたはドラッグでアップロード、切り抜き、削除、上下に動かして並べ替え |
| 背景 | 16:9 | アップロード、削除、並べ替え |
| サムネイル | 16:9 | アップロード、削除、並べ替え |
| スチール | 16:9 | アップロード、削除、並べ替え |

並び順がそのまま表示順で、一覧と詳細は既定で最初の表紙を使います（高精細表紙があれば優先）。切り抜きボタンは専用のダイアログを開き、確定するとそのままアップロードして差し替えます。

詳細編集ページにはほかに基本情報、分類情報、制作情報（識別コードとモザイクを含む）、シリーズ情報、出演者情報、元リンク、拡張項目、紐付け一覧、そして「媒体绑定列表（媒体紐付け一覧）」があります。サーバーのファイルツリーから動画ファイルをこの記録に紐付けたり解除したりでき、一覧には「可用 / 失效（利用可 / 無効）」と断片の題名が付きます。

:::tip[保存前に確認枠が出ます]
詳細編集で「保存」を押すと、まず「数据共享计划（データ共有プラン）」の確認枠が出ます。**收藏（お気に入り）**、**订阅（購読）**するか、データ共有に参加するかを選べます。チェックすると対応する記録が追加され、チェックしなくても既存の状態は取り消されません。
:::

## 統合・削除と、その効く範囲

| 操作 | 使い方 | 結果 |
| --- | --- | --- |
| 合并媒体（媒体を統合・映画） | 表で**ちょうど二行**にチェックを入れて押す | 一件目を残し、二件目は取り込まれて削除。それ以外の件数では警告が出ます |
| 合并演员（俳優を統合） | **ちょうど二件**にチェックを入れて押す | 一件目を残し、二件目は取り込まれて削除。件数が違えば警告が出ます |
| 删除媒体（媒体を削除・映画） | チェックして押すと一件ずつ送信 | 「删除任务已提交（削除タスクを投入しました）」と出て、数秒後に一覧が更新されます |
| 删除演员（俳優を削除） | 行内「删除」、またはチェック後の一括削除 | どちらも二段階確認です |
| 删除剧集（ドラマを削除） | 行の右の「删除」 | そのドラマの季、話、ファイル紐付け、シーズン対応も同時に消えます |

:::warning[削除は動画を残しますが、関係は消します]
- 映画の削除はメタデータと紐付けだけを消し、**ディスク上の動画は消しません**。ただしメタデータ、お気に入り、購読の関係は復元できません。作業前にバックアップを。
- ドラマの削除も動画ファイルは消しませんが、季・話・ファイル紐付け・シーズン対応は一緒に消えます。一括削除前にチェック範囲を確認してください。
- 統合は取り消せません。関連データを移して統合された側の記録を消します。同じ人物 / 同じ作品かを先に確かめ、必要ならバックアップを。
:::

## ドラマだけ：季・話・ファイル・シーズン対応

> **シーズン対応（季映射）**：一季が一項目になっているデータ源（Bangumi など）と連携するためのものです。ローカルの第 N 季をそのサイトの特定項目に結び、必要なら話番号をオフセットで換算します。

**季と話**：季一覧の「查看集（話を見る）」は下の話一覧をその季へ切り替えます。話一覧の上には「全部季（全季）」と `S1`、`S2` …… のショートカットが並びます。話は `S{季}E{話}` の形で表示され、季ボタンで絞り込めます。「本季集数（当季話数）」は「登録済み / 総数」で、二つが違えばまだ登録されていない話があります。

**ある話にファイルを紐付ける**：「再生可能ファイル」列で操作します。

1. 「添加文件（ファイルを追加）」を押すと「按路径添加文件（パスで追加）」ダイアログが開き、上部に対象の「第 N 季 第 N 話」が出ます。
2. **ファイルの絶対パス**を入力（必須。例 `D:\Media\作品名\Season 1\S01E01.mkv`）。
3. 分割ファイルなら分割番号を入れます。`CD1` は `1`、`CD2` は `2`。
4. 紐付けに成功するとファイルが一覧に現れ、「可用 / 不可用（利用可 / 不可）」と出典が付きます。
5. 「解绑（紐付け解除）」は関係を消すだけで、ディスクのファイルは消しません。

:::tip[利用可 / 不可はどこから来るか]
この印は直近の検証結果です。ファイルを移したり改名しても、再検証して初めて「不可」になります。紐付け解除と再紐付けもこの状態を更新します。
:::

**シーズン対応を紐付ける**：「绑定季映射（シーズン対応を紐付ける）」フォームにローカル季番号、データ源、データ源項目 ID を入れます（ID は `400602` のような数字でも、項目リンクをそのまま貼っても可）。「绑定方式（紐付け方式）」は `AUTO`（自動発見）か `MANUAL`（手指定）で、`MANUAL` の行は自動発見に上書きされません。「集号偏移（話番号オフセット）」の換算は **データ源の話番号 = ローカル話番号 + オフセット** です。「自动发现（自動発見）」を押すとデータ源から対応を再発見して更新し、追加 / 更新件数を知らせます。

:::note[自動発見に結果が無いとき]
「自动发现未返回任何季映射（自動発見はシーズン対応を返しませんでした）」と出る原因はたいてい二つです。データ源が関連項目に対応していない、またはタスク設定の `tv_season_auto_discover` がオフになっている、です。

このページが扱うのは**登録済み**のドラマだけです。スキャン段階でできた「確認待ちドラマ / 統合 / 境界の確定」はタスク管理欄の「刮削入库 → 剧集入库（取り込み → ドラマ登録）」で処理します。

## 俳優だけ：別名・作品・お気に入り・購読

**別名**は複数値入力で、Enter で追加します。同じ俳優の別表記を残し、検索やデータ源との照合に役立てます。送信前に前後の空白が除かれ、空の値は書き込まれません。**別名は「出演影视（出演作品）」の一致には使われず、作品の関連は名前だけで見ます**。

**作品との関連**：一覧の行で「详情」を押すと俳優の詳細引き出しが開き、右側が作品エリアです。題名は「出演影视（N）（出演作品 N 件）」で、N は一致した映画の総数。表はページごとに表紙、題名、識別コード、公開日、評価、类型を出し、各行の「详情 / 编辑（詳細 / 編集）」はその映画の詳細編集へ直接飛びます。作品一覧は映画ライブラリを**俳優名**で絞るため、映画側に書かれた出演者名は俳優ライブラリの名前と完全に一致していなければなりません。表記が違うとその作品はここに出ません。

**お気に入りと購読**：俳優ライブラリの一覧には「お気に入りだけ」絞り込みがありません。公開側の俳優一覧には「收藏库（お気に入りライブラリ）」モードがあり、別の画面なので矛盾ではありません。作られる入口は二つです。

1. 「搜索演员（俳優を検索）」の結果カード：取り込み、お気に入り、購読の三つのアイコンが順に並び、いずれもまず登録してから動作します。
2. 俳優の編集ページで保存するときの「数据共享计划（データ共有プラン）」確認枠：收藏（お気に入り）・订阅（購読）にチェックすると対応する記録が追加されます。

購読はその俳優を追うという意味で、後の新作を購読タスクが自動で拾えます。一時停止と解除は購読管理が担当し、このページでは扱いません。

## 設定項目の説明

| 設定項目 | 入力するもの | 未入力 / 間違えた場合 |
| --- | --- | --- |
| 検索条件（六項目） | 題名、番号、出演者、类型、标签、系列 | 「搜索」を押さないと反映されません。「重置」はフォームを空にするだけ |
| 「来源」ドロップダウン | データ源を一つ、または全部 | 切り替えると即再検索で、「搜索」は不要です |
| 类型 / 标签 / 別名などの複数値入力 | 一つ入れるごとに Enter | Enter を押さないと追加されません。別名は前後の空白を除き、空値は書き込みません |
| 识别码（詳細編集） | 複数値、追加・削除・自由入力 | ファイル名と表記が違うと別作品と誤認します。購読はこれで後続資源を追います |
| 評価 | 映画は 0–10・刻み 0.1、俳優は 0–10 | 範囲外は入力できません |
| 绑定演员（メタデータ編集） | 各行「名前 + 役名」、役名は空可 | 名前が空の行は送信されません |
| 取り込み時の季番号 | 空 = 全季、`0` = 特別編、`1`～`99` = その季だけ | 誤ると違う季を取り込みます。同じサイト ID なら新規ではなく合流します |
| 重新刮削（再スクレイピング） | データ源、データ源項目 ID、季番号（`0`～`99`） | このドラマに合流し、二つ目のドラマはできません |
| ファイルの絶対パス | 必須。例 `D:\Media\作品名\Season 1\S01E01.mkv` | 空だと紐付けできません。パス違いなら「不可用（利用不可）」になります |
| 分割番号 | 分割ファイルで `CD1` → `1`、`CD2` → `2` | 空だと分割ファイルが揃わないことがあります |
| シーズン対応の項目 ID | `400602` のような数字、または項目リンク | 誤ると別項目を指し、話数が合いません |
| 绑定方式（紐付け方式） | `AUTO`（自動発見）/ `MANUAL`（手指定） | `MANUAL` の行は自動発見に上書きされません |
| 集号偏移（話番号オフセット） | データ源の話番号 = ローカル話番号 + オフセット | オフセット違いで話番号が全体にずれます |
| 画像の比率 | 表紙 / 大写真 2:3、背景 / サムネイル / スチール 16:9、ポスターウォール 3:4 | 比率違いは切り抜かれます。並び順が表示順です |
| 統合操作 | ちょうど二行にチェック | それ以外の件数では警告が出て実行できません |
| 数据共享计划（データ共有プラン）の確認枠 | お気に入り・購読・データ共有に参加するか | チェックしなくても既存状態は取り消されません。チェックすると記録が追加されます |

## 困ったときは

- **目的の記録が見つからない**：検索条件を変えた後に「搜索」を押したか、「来源」で絞られていないか、番号 / 識別コードの表記が合っているかを確認します。
- **俳優の出演作品が何本か欠ける**：作品の関連は**名前**だけを見ます。映画側の出演者名は俳優ライブラリと完全に一致させてください。別名は一致に使われません。
- **ドラマの取り込みで重複ができた**：同じサイト ID なら本来は既存ドラマに合流します。本当に重複したら統合で対処しますが、ちょうど二件必要です。
- **シーズン対応の自動発見に結果が無い**：データ源が関連項目に非対応、またはタスク設定の `tv_season_auto_discover` がオフです。
- **ドラマのファイルが「不可用（利用不可）」になった**：ファイルが移動・改名されています。再検証を一度。紐付け解除や再紐付けでも状態は更新されます。
- **記録を誤って消した**：削除は動画を残しますが、メタデータ・お気に入り・購読は復元できません。再スクレイピングか再取り込みしかないので、事前のバックアップを。
- **項目を直したのに保存されない**：「编辑元数据（メタデータ編集）」も詳細編集も保存ボタンが必要です。詳細編集では保存前に「数据共享计划（データ共有プラン）」の確認枠も出るので、そこを飛ばさないでください。
