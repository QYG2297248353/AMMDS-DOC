# 漫画と小説

漫画ライブラリは漫画とアルバム、小説ライブラリは小説を収めます。どちらも「一冊の本 + いくつかの章」という形で、違いは漫画の章が画像の集まり、小説の章が文字の本文だという点です。このページでは「やりたいこと」に沿って、本を作る、中身を入れる、順番を整える、ファイルに書き出す、読書の進捗がどこに残るかを説明します。二つのライブラリは見た目がよく似ているので一緒に扱い、違うところだけ指摘します。

## はじめに

> **メタデータ**：本や章の説明情報です。タイトル、作者、章の並びなどが含まれます。漫画では `ComicInfo.xml` という決まった名前のファイルに一緒に保存します。

> **プレースホルダー**：命名書式の中の `${title}` のような印です。整理するとき実際の内容に置き換わり、`${title}` は本の名前に、`${chapter}` は章の名前になります。

> **書源（しょげん）**：小説の本文を取ってくるサイトのことです。目次と本文の取得だけを担当し、どの書源を使うか、その設定は連携アプリで管理します。

> **整理**：決めたフォルダー名やファイル名の規則に従って、ライブラリの中身をフォルダーや一つのファイルに書き出すことです。

> **EPUB / PDF**：よくある電子書籍の形式です。EPUB はリーダーアプリで読みやすく、PDF はページごとの文書です。

> **CBZ / CBR / CB7 / アーカイブ**：一章分の画像を一つのファイルにまとめる形式で、違いは圧縮の方式だけです。CBR は生成にサーバー側の追加ツールが必要です。

## 本を作る

二つのライブラリはどちらも 媒体管理（メディア管理）の下にあり、左が作成、右が並べ替えと検索、中央がカードという構成です。

### 漫画ライブラリ

媒体管理 → 漫画库（メディア管理 → 漫画ライブラリ）に進みます：

| 場所 | 内容 |
| --- | --- |
| 左 | 「创建漫画（漫画を作成）」 |
| 右 | 並べ替えのプルダウン、「搜索我的漫画（自分の漫画を検索）」 |
| カード | 1 行に最大 4 枚、下部にページ送り |

並べ替えは**新しく作成した順、古く作成した順、タイトル昇順、タイトル降順**の四つで、切り替えると 1 ページ目に戻って再検索します。

カードには表紙、分類ラベル、タイトル、シリーズ、作者、タグ、説明が表示されます。タイトルの右の副題は二種類で、「全章节（全章モード）」をオンにすると「全集（全巻）」、オフなら「第 N 季（第 N シーズン）」と表示されます。

カードの右上にマウスを重ねると三つの操作が出ます。**编辑（編集）**（編集ページへ）、**分享（共有）**、**删除（削除）**（確認後に削除）。カード本体（右上のボタンではない方）を押すと章の管理ページに進み、「全章モード」の設定も一緒に引き継がれます。

### 小説ライブラリ

媒体管理 → 小说库（メディア管理 → 小説ライブラリ）に進みます：

| 場所 | 内容 |
| --- | --- |
| 左 | 「创建小说（小説を作成）」「搜索小说（小説を検索）」「导入 EPUB（EPUB を取り込む）」 |
| 右 | 並べ替えのプルダウン、「搜索我的小说（自分の小説を検索）」 |
| カード | 1 行に最大 4 枚、下部にページ送り |

並べ替えは同じく**新しく作成した順、古く作成した順、タイトル昇順、タイトル降順**です。1 ページは既定で 12 件、4 列の並びに合うようになっています。

カードの左が表紙、右上に**状態**ラベルが固定で付きます（完结 / 连载 / 草稿 / 待续 / 创作中 ＝ 完結 / 連載 / 下書き / 続き待ち / 執筆中）。右には種類、タイトル、作者、シリーズ、出典、タグが並び、説明は最大 3 行です。

カードの右上にマウスを重ねると操作アイコンが出ます：

| アイコン | 動作 | 説明 |
| --- | --- | --- |
| ダウンロード | 未取得の章の本文を取ってくる | 書源由来の本だけに表示 |
| 編集 | 編集ページへ | |
| 共有 | 共有リンクを作る | |
| 削除 | 確認後に小説一冊を丸ごと削除 | |

:::tip[章の管理ページに入る]
カード本体を押すと章の管理ページに進みます。漫画も小説も同じ入り口で、右上のボタンとは別です。
:::

### 作成時に入力すること

漫画は「创建漫画（漫画を作成）」、小説は「创建小说（小説を作成）」から入力します。それぞれ次のとおりです。

漫画：

| 項目 | 説明 |
| --- | --- |
| タイトル | 必須 |
| 作者 | 必須 |
| シリーズ | 所属するシリーズ名 |
| 種類 | 漫画 / アルバム |
| 説明 | 複数行のテキスト |
| 全章节（全章モード） | スイッチ。オンにすると章に分けず、本全体を一つとして表示 |
| 季数 | `1`～`999` の整数。プルダウンでも直接入力でも可。「全章モード」がオンのときは無効 |
| 表紙 | クリックまたはドラッグでアップロード。推奨比率 9:16、画像のみ、10 MB まで |

季数に不正な値を入れると警告が出て、直前の正しい値に戻ります。

小説：

| 項目 | 説明 |
| --- | --- |
| タイトル | 必須 |
| 作者 | |
| 種類 | 候補に 玄幻、都市、科幻、悬疑、武侠、言情、历史、游戏、轻小说 など。独自の種類を直接入力も可 |
| シリーズ | 所属するシリーズ名 |
| 状態 | 完結 / 連載 / 下書き / 続き待ち / 執筆中 |
| 説明 | 複数行のテキスト |
| 表紙 | クリックまたはドラッグでアップロード。推奨比率 2:3 |

## 中身を入れる

### 漫画：パソコンまたはサーバーから取り込む

章のページ中央に三つの取り込み口があります：

1. **画像**：クリックまたはドラッグでアップロード。JPG、PNG、BMP、GIF に対応。ディレクトリごと一度に放り込め、名前順に自動で並びます。
2. **PDF / EPUB**：クリックまたはドラッグでアップロード。PDF と EPUB に対応し、一つずつ進捗を表示しながら取り込みます。
3. **CBZ / メタデータ**：CBZ の入口で `.cbz` ファイルを選べますが、現行版では「暂未支持 CBZ 文件上传（CBZ のアップロードは未対応）」と表示され、形式とサイズの確認だけでスキップされます。メタデータの入口は `ComicInfo.xml` だけを受け付け、章のメタデータを書き込むために使います。

ほかに「漫画导入（漫画を取り込む）」はサーバーのディレクトリを使います。ダイアログで漫画画像のあるディレクトリを選ぶと、ファイル名の自然順で取り込み、表紙 / 裏表紙を表すキーワードの画像を自動で先頭と末尾に置きます。

:::warning[アーカイブ取り込みの現状]
アップロード側で実際に保存されるのは PDF / EPUB だけで、CBZ は入口が用意されているだけです。アーカイブ関連の機能は**書き出し側**にあり、「手动整理（手動で整理）」で章を CBZ、CBR、CB7 にできます。
:::

### 小説：EPUB と書源

- **EPUB の取り込み**：「导入 EPUB（EPUB を取り込む）」で `.epub` ファイルを選ぶと、目次と章を解析して登録します。取り込み中は読み込み中表示が出ます。手元の電子書籍をライブラリに移す最も速い方法です。
- **書源からの取り込み**：「搜索小说（小説を検索）」で書源の検索ダイアログを開きます。タイトルのキーワードを入れ、有効な書源から検索 → 結果から本を選んで取り込みます。取り込んだ本はカードに出典が表示され、章のページに「来源书源: 书源名（出典書源: 書源名）」ラベルが出ます。書源は目次と本文の取得だけを担当し、書源自体の有効化や規則は連携アプリで管理します。

## 章の管理と並び順

カードから進むと「章节管理 · 书名（章の管理 · 本の名前）」というタイトルのページになり、上部の操作は左右に分かれます。

漫画：

| 位置 | 操作 | 説明 |
| --- | --- | --- |
| 左 | 章のプルダウン | 現在の章を切り替え |
| 左 | 章を新規作成 | 章のタイトルと説明を入れて作成。全章モードでは無効 |
| 左 | 漫画导入 | サーバーのディレクトリから画像を取り込む。章が未選択のときは無効 |
| 右 | 編集 | 漫画の編集ページに戻る |
| 右 | 立即整理 | タスク設定のまま整理タスクを実行 |
| 右 | 手动整理 | 整理先ディレクトリ、ディレクトリ書式、ファイル形式を指定してから実行 |
| 右 | 章を削除 | 全章モードでは無効 |

小説：

| 位置 | 操作 | 説明 |
| --- | --- | --- |
| 左 | 章のプルダウン | 連番 + タイトルで全章を一覧 |
| 左 | 章を新規作成 | 章のタイトルだけ入力 |
| 左 | 出典書源ラベル | 書源から取り込んだ本だけに表示 |
| 左 | 未取得の本文 N 章 | 本文が未取得の章があると赤いラベルで表示 |
| 右 | 本文を更新 | 書源由来の本で、章を選択しているときだけ表示 |
| 右 | 全冊ダウンロード | 書源由来の本だけに表示。バックグラウンドのタスクで実行 |
| 右 | 編集 / 立即整理 / 手动整理 | 整理タスクを実行 |
| 右 | 章を削除 | 章を選択しておく必要あり |

**漫画の章の画像**：章を選ぶと画像がグリッドで並び、各画像の右上に三つの操作があります。**前へ / 後ろへ**（並び順を変更。先頭は前へ動かせず、末尾は後ろへ動かせません）、**削除**（画像を外します）。画像を押すと大きいプレビューでページをめくれます。下部のページ送りは 1 ページの枚数を切り替えられます（12、24、48、60、120、240、480、1000）。

**小説の本文編集**：章を選ぶと編集欄に進みます：

- 上部に**章のタイトル**の入力欄と「保存正文（本文を保存）」ボタンがあります。
- 本文はプレーンテキストの複数行入力欄で、空行が段落の区切りです。HTML タグはそのまま文字として表示され、描画されません。
- 書源から取り込んだ章は開いたときに本文を自動取得します。取得中は編集欄に読み込み表示がかぶさり、途中の内容が見えないようになっています。
- 「保存正文（本文を保存）」を押すまで、変更はブラウザー内にしか残りません。

**全冊ダウンロード**（書源由来の小説のみ）は取得をバックグラウンドに任せます：

1. 実行するとページ上部に「正在后台下载全本（バックグラウンドで全冊をダウンロード中）」の進捗バーが出ます。
2. 進捗はタスクログから来て、現在の段階の説明が添えられます。
3. 「查看任务日志（タスクログを見る）」でログページに飛び、失敗の原因を調べられます。

## ファイルにまとめて書き出す

「立即整理（すぐ整理）」はタスク設定のディレクトリと書式を使い、実行後に「提交整理任务成功（整理タスクを送信しました）」と表示されます。「手动整理（手動で整理）」は今回のタスクに限って設定を上書きできます。

漫画の手動整理：

| 項目 | 説明 |
| --- | --- |
| 整理先ディレクトリ | 必須。サーバーのディレクトリ一覧から選択 |
| ディレクトリ書式 | `${title}` `${author}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` などのタグに対応。空ならタスク設定を使用 |
| ファイル形式 | フォルダー整理、CBZ、CBR、CB7、PDF、EPUB |

フォルダー / PDF / EPUB はそのまま生成され、CBZ と CB7 は組み込みで生成されます。CBR（RAR）はサーバーに `rar` ツールを入れるか、`AMMDS_RAR_TOOL` で実行ファイルを指定する必要があります。

小説の手動整理（「立即整理」は「小说整理配置（小説の整理設定）」に従って実行）：

| 項目 | 説明 |
| --- | --- |
| 整理先ディレクトリ | 空なら「小说整理配置」のディレクトリを使用 |
| ディレクトリ命名規則 | `${title}` `${author}` `${category}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` などのタグに対応 |
| ファイル命名規則 | 本全体を書き出すとき `${chapter}` は小説名、章ごとに書き出すときは章名を使用 |
| 整理形式 | **EPUB**（既定）または **TXT** |
| 章ごとに生成 | オンなら章ごとに一ファイル、オフなら本全体で一ファイル（EPUB に全章を含む） |

EPUB は章の順番どおりに目次を作るので、そのままリーダーアプリに渡せます。

二つの既定設定はタスク管理欄の「任务配置（タスク設定）」にあり、名前で探します。**漫画整理配置（漫画の整理設定）**は整理形式、既定の整理先ディレクトリ、ディレクトリ / ファイルの命名規則、章ごとに生成するか、表紙 / 裏表紙 / 目次の判別キーワードを扱います。**小说整理配置（小説の整理設定）**は整理形式、既定の整理先ディレクトリ、ディレクトリ / ファイルの命名規則、章ごとに生成するかを扱います。この二つは漫画と小説の取り込みだけに使われ、映画のスキャンタスクとは混ざりません。変更はそれ以降に作った・実行したタスクにだけ効き、すでに登録済みの内容は書き換わりません。

## 読書の進捗はどこに残るか

章の管理ページは中身の保守だけで、**読書の進捗はここに表示されません**。進捗はフロントのリーダーが記録します：

- 漫画は「章 + ページ」で保存し、画面を離れたりバックグラウンドに回したりした時点ですぐ書き出します。同じ漫画を開き直すと「已恢复到上次阅读位置 第 N 页（前回の位置、N ページに復帰しました）」と表示されます。フロントの詳細ページはこれに合わせて「继续阅读（続きから読む）」と「从头阅读（最初から読む）」を用意します。
- 小説は「章 + 位置」で記録します。進捗があるとフロントの詳細ページの主ボタンが「继续阅读（続きから読む）」になり、何章まで読んだかが出ます。リーダーは章の目次、めくり / スクロールの二方式、テーマと文字サイズの調整を備えます。進捗がない場合や、進捗が指す章が削除された場合は「从头阅读（最初から読む）」に戻ります。

## 設定項目の説明

| 設定項目 | 何を入れるか | 空 / 間違えた場合 |
| --- | --- | --- |
| タイトル | 漫画・小説ともに必須 | 空だと本を作れません |
| 作者 | 漫画は必須、小説は空でも可 | 漫画は空だと本を作れません |
| 種類 | 漫画は「漫画 / アルバム」、小説は候補から選ぶか独自入力 | 分類表示にだけ影響し、取り込みには影響しません |
| 全章モード（漫画） | スイッチ。オンなら本全体を章に分けない | オンにすると季数、章の新規作成、章の削除がすべて無効 |
| 季数（漫画） | `1`～`999` の整数。プルダウンまたは直接入力 | 不正な値は警告が出て直前の正しい値に戻ります |
| 表紙 | クリックまたはドラッグでアップロード。漫画 9:16、小説 2:3。漫画は画像のみ 10 MB まで | 形式やサイズが違うとアップロードできません |
| 状態（小説） | 完結 / 連載 / 下書き / 続き待ち / 執筆中 | カード右上の印にだけ使われます |
| 章のプルダウン | 取り込み前に章を一つ選ぶ | 未選択だと「漫画导入」が無効 |
| 画像のアップロード | JPG、PNG、BMP、GIF。ディレクトリごと一度に投入可 | 名前順に自動で並びます。順番が違うときは前へ / 後ろへで手直し |
| `ComicInfo.xml` | メタデータの入口はこのファイル名だけ受け付け | 別の名前では章のメタデータを書き込めません |
| CBZ のアップロード | `.cbz` ファイルを選ぶ | 現行版では「暂未支持 CBZ 文件上传（CBZ のアップロードは未対応）」と表示され、確認だけでスキップ。アップロード側で保存されるのは PDF / EPUB だけ |
| 本文を保存 | 本文を直したら「保存正文（本文を保存）」を押す | 押さないと変更はブラウザー内だけで、閉じると消えます |
| 整理先ディレクトリ（手動整理） | 漫画は必須、サーバーのディレクトリ一覧から選択。小説は空なら「小说整理配置」のディレクトリ | 漫画は選ばないと実行できません |
| ディレクトリ書式 / 命名規則 | `${title}` `${author}` `${chapter}` `${index}` などのタグ | 空ならタスク設定を使用。タグを誤ると誤ったディレクトリ名になります |
| ファイル形式 / 整理形式 | 漫画はフォルダー / CBZ / CBR / CB7 / PDF / EPUB、小説は EPUB（既定）または TXT | CBR はサーバーの `rar` か `AMMDS_RAR_TOOL` が必要で、無いと生成できません |
| 章ごとに生成（小説） | オンなら章ごとに一ファイル、オフなら本全体で一ファイル | オフでは一つの EPUB に全章が入ります |
| ファイル命名規則（小説） | 本全体の書き出しでは `${chapter}` に小説名、章ごとでは章名 | 誤るとファイル名と中身が合いません |

## 困ったときは

- **取り込んだ章の順番が乱れた**：画像はファイル名順に並び、「漫画导入」では表紙 / 裏表紙の画像を先頭と末尾に置きます。それでも違うときは各画像の前へ / 後ろへで直します。先頭は前へ、末尾は後ろへ動かせません。
- **CBZ を取り込めない**：現行版のアップロード側は `.cbz` に非対応で、形式とサイズの確認だけでスキップされ、「暂未支持 CBZ 文件上传（CBZ のアップロードは未対応）」と出ます。アーカイブを使いたいときは「手动整理（手動で整理）」で章を CBZ / CBR / CB7 に書き出してください。
- **CBR が生成できない**：CBR はサーバーに `rar` ツールを入れるか、`AMMDS_RAR_TOOL` で実行ファイルを指定する必要があります。無ければ CBZ か CB7 を使ってください。
- **小説の本文を直したのに保存されない**：本文は「保存正文（本文を保存）」で初めて保存されます。書源由来の章は開いたとき自動取得され、その間は読み込み表示がかぶさるので、終わってから直してください。
- **全冊ダウンロードが止まる / 失敗する**：進捗はタスクログから来ます。「查看任务日志（タスクログを見る）」でどの段階で止まったか確認してください。全冊ダウンロードは書源由来の本にだけあります。
- **整理が想定どおりに生成されない**：「立即整理（すぐ整理）」はタスク管理欄「任务配置（タスク設定）」の既定ディレクトリと書式を使います。今回だけ変えたいなら「手动整理（手動で整理）」で上書きし、既定を変えたいならタスク設定を編集してください。
- **「続きから読む」が見当たらない**：読書の進捗はフロントのリーダーにあり、章の管理ページには表示されません。進捗が指す章が削除されると最初から読むに戻ります。
