# 情報ライブラリ

情報ライブラリは、すべての情報コンテンツを一元管理します。ソースは二種類だけです：

- **購読ソース**：RSS 購読により自動取得され、削除のみ可能で、変更はできません
- **手動作成**：管理画面で自分で執筆し、新規作成・編集・削除ができます

## 入口

管理画面左側の「メディア管理」→ メニューの最後の項目「情報ライブラリ」。

## 一覧の見方

上部が絞り込みエリア、下部が情報のテーブルです。

| 絞り込み | 説明 |
| --- | --- |
| キーワード | タイトル、概要、本文に一致します。入力後 Enter を押しても検索できます |
| ソース | すべて、購読ソース、手動作成 |
| 分類 | すべて、記事、画像、動画、リソース、その他 |

条件を変更したら「検索」をクリックします。「リセット」をクリックすると条件がクリアされ、一覧が再取得されます。

テーブルの列と内容：

| 列 | 説明 |
| --- | --- |
| 情報 | カバーのサムネイル、タイトル、二行の概要。タイトルをクリックすると詳細ダイアログが開きます |
| 分類 | 記事、画像、動画、リソース、その他 |
| 著者 | 複数の著者は読点で区切られます。未入力の場合は「著者未記載」と表示されます |
| ソース | 「購読ソース」または「手動作成」。購読ソースにマウスを合わせると、具体的な購読元名が表示されます |
| 公開日時 | `2026-11-15 10:00:00` の形式。ない場合は `-` と表示されます |
| 状態 | 未読または既読 |
| 操作 | 表示、編集、削除 |

一覧は公開日時の新しい順に並びます。下部のページ送りは既定で 1 ページ 20 件で、10、20、50、100 件に切り替えられます。

## 新規作成と一括削除

- **記事を作成**：常に左上にあり、クリックすると作成ページに進みます
- **一括削除**：チェックを入れると表示され、ボタンに選択件数が付きます。例：「一括削除 (3)」

## 購読ソースの記事が変更できない理由

購読記事は取得した原文であり、変更すると次回の取得時に一致しなくなるため、システムは読み取り専用として扱います：

- 行の操作に「編集」はなく、「表示」と「削除」だけがあります
- バックエンドも変更を拒否し、「購読ソースの記事は編集できません。削除のみ可能です」と表示します

内容を調整したい場合は、削除してから手動作成で新しく書き直してください。

## 一括削除

1. 一条または複数の記事にチェックを入れます。
2. 「一括削除」をクリックします。
3. 確認後、削除されます。

購読ソースと手動作成のどちらも削除できますが、削除後は復元できません。単一削除は行の操作にあり、同じく確認ダイアログが表示されます。

## 手動記事を書く

「記事を作成」をクリックすると、左側にタイトルと本文、右側に基本情報を入力します。

| 項目 | 説明 |
| --- | --- |
| タイトル | 必須、最大 200 文字 |
| 本文 | 必須、Markdown で記述。後述 |
| カバー | 任意。クリック、または画像を破線枠にドラッグしてアップロード。アップロード後に変更・削除可能。画像のみ受け付け、1 枚あたり 10MB 以下 |
| 著者 | 任意、最大 100 文字 |
| 分類 | 任意、記事、画像、動画、リソース、その他 |
| 原文リンク | 任意、元の記事のアドレスを入力。例：`https://example.com/article` |
| 公開日時 | 任意、時分秒まで指定可能、既定は現在時刻 |

既存の手動記事を編集する場合も、フォームの内容は同じです。購読ソースの記事は編集ページに入れず、警告が表示されて一覧に戻されます。

### 本文エディター

本文は Markdown で記述します。エディターには **編集**、**分割表示**、**プレビュー** の三つの表示モードがあります。分割表示では、左側で執筆しながら右側でリアルタイムに結果を確認できます。

ツールバーには左から順に、太字、斜体、見出し、引用、コード、リスト、区切り線、リンクの挿入、画像の挿入があります。

画像の挿入には二つの方法があります：

- 画像のアドレス（URL）を入力する
- ローカルの画像をアップロードする

リンクを挿入する場合は、リンク先のアドレスとリンク文字を入力します。保存すると、Markdown とともに変換済みの Web コンテンツも保存され、一覧とフロントエンドでの表示には変換後の結果が使われます。

## 公開後の確認先

- フロントエンド上部ナビゲーションの最後の項目「情報」。アドレスは `/home/information` です
- 情報一覧はログインせずに閲覧できます
- 詳細ページに入るにはログインが必要です

## よくある質問

| 現象 | 説明 |
| --- | --- |
| 「編集」ボタンが見つからない | 購読ソースの記事は読み取り専用で、削除のみ可能です |
| タイトルが保存できない | タイトルは必須で、最大 200 文字です |
| 本文が保存できない | 本文は必須です |
| 本文内の画像が表示されない | 画像アドレスに直接アクセスできるか確認するか、アップロードに切り替えてください |
| フロントエンドで新しい記事が見えない | 公開日時が未来に設定されていないか確認してください。フロントエンドは公開日時順に表示します |
