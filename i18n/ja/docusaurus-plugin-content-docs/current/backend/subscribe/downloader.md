# ダウンロードと取り込み

このページでは、**資源が検索画面を離れたあと**のことを扱います。どのソフトがダウンロードするのか、ファイルがどこに置かれるのか、進捗をどこで見るのか、そしてライブラリに反映させるために何が必要かを説明します。

## まず言葉の確認

> **ダウンローダ**：実際にダウンロードするソフト（ここでは qBittorrent）です。AMMDS はタスクを渡すだけで、ダウンロード本体はダウンローダが行います。

> **分類 / タグ**：ダウンローダがタスクに付ける印です。これがあると、多数のタスクの中から AMMDS が送ったものをすぐ見分けられます。

> **シード**：ダウンロード完了後もファイルを共有し続けることです。共有中にファイルを消すとシードが途切れます。

> **追加シード**：同じファイルを別のサイトにも登録することです。もう一度ダウンロードする必要はありません。

## 手順

### 接続を確認する

**ツールボックス → ダウンローダ → プラグイン情報** を開くと、ダウンローダのアドレス、アカウント、既定の保存先、バージョン、現在のタスク数が分かります。プラグインが無効のときは「プラグインが無効です」と表示されるだけで、接続しません。

### タスクを送る

三つの経路はすべて同じタスク一覧に集まります。

| 経路 | 場所 | 書き込まれる印 |
| --- | --- | --- |
| サイト検索から送信 | 検索結果のダウンローダボタン | 分類 `AMMDS` |
| 磁力検索から送信 | 検索結果のダウンローダボタン | 分類 `AMMDS` |
| 購読の自動ダウンロード | 購読が資源を見つけたとき自動送信 | タグ `AMMDS订阅` と `subscribe-<購読ID>`、保存先は購読ルールの指定 |

手動で追加もできます。「新規タスク」を押し、ダイアログ上部で二つのモードを切り替えます。

| モード | 入力するもの |
| --- | --- |
| 磁力ダウンロード | 磁力リンクを貼り付けます。複数ある場合は改行で区切ります |
| 種ファイル | `.torrent` ファイルを一つ以上アップロードします |

### 進捗を見る

**ツールボックス → ダウンローダ → タスク管理** を開きます。一覧は 5 秒ごとに自動更新されます（タブが非表示のときは停止します）。

| 列 | 意味 |
| --- | --- |
| ファイル名 | 種の名前。2 行目に保存先 |
| 状態 | ダウンローダの状態を日本語にしたもの。ダウンロード中、アップロード中、メタデータ取得中、待機中、一時停止、検証中、ファイル移動中、ファイル不足、エラーなど |
| 速度 | ダウンロード速度とアップロード速度 |
| サイズ | タスク全体のサイズ |
| 分類 / タグ | 送信時に書き込まれた印 |
| 進捗 | 進捗バー。完了で 100% |

### まとめて操作する

一覧でタスクにチェックを入れてから、上部のボタンを使います。

| ボタン | 動作 |
| --- | --- |
| ダウンロード開始 | 選択したタスクを再開します |
| ダウンロード一時停止 | 選択したタスクを止めます |
| タスク削除 | 確認ダイアログが出て、「元ファイルも削除」か「タスクのみ削除」を選びます |

:::warning[ファイルの削除は元に戻せません]
削除ダイアログでは、確定ボタンが「元ファイルも削除」、キャンセルボタンが「タスクのみ削除」です。確定すると、ダウンロード済みのデータも一緒に消えます。シード中や追加シード待ちのタスクは、関連する流れが止まっているか確認してから削除してください。
:::

### ダウンロード後に必要なこと

ダウンローダはファイルをディスクに置くだけで、**ライブラリには自動登録しません**。AMMDS に新しいファイルを認識させるには、スキャンタスク（タスク管理のセクション）を一度実行するか、監視が有効なディレクトリにファイルを置いてください。

## 設定項目

手動でタスクを追加するときに指定できる三つです。すべて省略できます。

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| 分類 | ダウンローダに表示される分類名 | 分類なしになり、既定の分類に入ります |
| タグ | 入力して Enter で確定。複数はカンマ区切りになります | タグなし |
| 保存先 | ファイルを置くディレクトリ | ダウンローダの既定の保存先 |

## 追加シードとの関係

ダウンローダのタスクと追加シードのタスクは別の記録です。混同しないでください。

- **ダウンローダのタスク**は、ダウンロードとシードの進捗を表します。
- **追加シード**は **ツールボックス → PT 追加シード** が他のサイトを通じて行うもので、専用の計画・サイト設定・記録を持ちます。追加シードの計画では別のクライアントも選べ、検索画面の送信先とは別の設定です。
- ダウンロード後もファイルはダウンローダがシードし続け、追加シードは同じファイルを指す新しいタスクを他のサイトに作ります。ファイルを削除する前に、両方のタスクが止まっているか確認してください。

## 困ったときは

- **送信が失敗する**：ダウンローダが無効、またはアドレスやアカウントが間違っています。プラグインのページで接続をテストしてください。
- **送信は成功したが一覧に出ない**：1 ページ目に戻して絞り込みを消すか、ダウンローダ本体で確認してください。
- **「メタデータ取得中」で止まる**：磁力にシードがいません。種ファイルで試してください。
- **「ファイル不足」と出る**：保存先が移動されたか、ファイルが消えています。戻して再検証するか、タスクを削除して取り直してください。
- **購読が完了にならない**：タスクがダウンローダから消えたか、進捗を読み戻せていません。購読管理から再送信してください。

検索や購読の設定を変えたいときは、[資源を探して購読する](./search.md)をご覧ください。
