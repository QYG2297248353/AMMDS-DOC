# 資源を探して購読する

このページでは二つのことを扱います。**一度だけ資源を探す**ことと、**作品番号を追跡して新しい資源を自動で取り込む**ことです。単発の検索は「サイト検索」または「磁力検索」、長期的な追跡は「購読管理」を使います。三つとも **サブスクリプション検索** メニューにあります。

## まず言葉の確認

> **作品番号**：ファイル名によく入っている識別番号です。AMMDS はこれで作品を判別します。

> **磁力リンク**：`magnet:` で始まる一行のテキストです。ダウンロードソフトはこれを使って、ファイルを共有している人を探します。種ファイルを先に用意する必要はありません。

> **シード数 / リーチ数**：そのファイルを共有している人数と、ダウンロード中の人数です。シードが多いほど速く落ちる傾向があります。

> **プロモーション**：サイトが種に付ける割引の印です。無料ダウンロード、50% ダウンロード、2 倍アップロードなどがあり、通信量の計算にだけ影響します。

> **API キー**：サイトが発行する文字列です。ソフトはパスワードを知らなくても、これを提示して「このアカウントです」と証明できます。

## 一度だけ探す

1. **サブスクリプション検索 → サイト検索**（または **磁力検索**）を開きます。
2. 作品番号、作品名、出演者名のいずれかを入力して Enter を押します。
3. 結果を待ちます。サイト検索の待ち時間は最大 60 秒です。時間内に返ってこないサイトは「結果なし」として扱われ、残りはそのまま表示されます。
4. 結果の上のツールバーで絞り込みます。並び替え項目（公開日時、ファイルサイズ、シード数、リーチ数）、並び順、メディア、映像コーデック、音声コーデック、解像度、プロモーションです。
5. 最初から選び直すときは「リセット」を押します。絞り込みがすべて解除され、並び替えは「公開日時 / 降順」に戻ります。

検索履歴はブラウザに最大 20 件保存されます。結果がないときは検索ボックスの下に履歴が出るので、クリックすれば再検索できます。

「N 件見つかりました」は絞り込み後の件数であり、サイトが返した総数ではありません。

## 見つけたあと：ダウンロードか送信か

| ボタン | 動作 | 向いている場面 |
| --- | --- | --- |
| 種をダウンロード | `[AMMDS]タイトル.torrent` という名前の種ファイルを保存します | ダウンロードソフトを自分で選びたいとき |
| ダウンロードへ送信 | 有効なダウンローダへ直接渡します。分類は `AMMDS` になります | すでにダウンローダを使っているとき |

磁力検索には、磁力リンクをコピーするボタンと、タイトルを開いてパソコン側のソフトに任せる操作が追加されます。

## 長く追跡する

1. 作品のオンライン検索結果、ダッシュボードのランキング、作品編集画面などで「購読」を押します。
2. AMMDS は作品番号で作品情報を照合し、設定した順序で各サイトを探します。見つかった時点で自動的に送信されます。
3. 状態は **サブスクリプション検索 → 購読管理** で確認します。一覧は 10 秒ごとに自動更新されます。
4. すぐに再実行したいときは、「購読中」または「すべて」タブのカードで「今すぐ検索」を押します。
5. 追跡をやめるときは「購読をキャンセル」です。あとから「キャンセル済み」タブで復元できます。

同じ作品番号（大文字小文字を区別しない）の購読は一つだけです。二重に押しても増えません。

## 二つの検索の違い

| | サイト検索 | 磁力検索 |
| --- | --- | --- |
| データの出どころ | 有効にしたサイトとインデクサー | 磁力インデックスのサービス |
| 項目 | プロモーション、シード数、解像度などサイトの項目 | ソース、ファイル数、ファイル一覧 |
| ページ送り | すべて一度に返り、画面ではページ送りなし | サーバ側でページ送り、1 ページ 20 件 |
| 並び替え | 画面内で並べ替え | サーバ側で並べ替え。変更すると 1 ページ目に戻ります |
| ダウンロード形式 | 種ファイルまたは直接リンク | 磁力リンク |
| 前提条件 | サイト系インデックスを一つ以上有効化 | 磁力インデックスが有効で到達できること |

二つは独立しています。あるサイトがタイムアウトしても、そのサイトだけが空になるだけで、検索全体は止まりません。磁力検索の「ソース」絞り込みは現在のページだけに効き、総数は変わりません。

## 購読の六つの状態

| タブ | 意味 | カードのボタン |
| --- | --- | --- |
| すべて | 状態で絞り込まない | 今すぐ検索、キャンセル、削除 |
| 購読中 | 購読中。照合待ち、または次の検索待ち | 今すぐ検索、キャンセル |
| 一時停止 | 照合失敗が続いたため自動で停止 | キャンセル |
| キャンセル済み | 自分で停止。記録は残ります | 復元、削除 |
| ダウンロード中 | ダウンローダへ渡済み | 削除 |
| 完了 | ダウンローダが完了を報告 | 削除 |

「削除」は完全に消す操作で元に戻せません。「キャンセル」は停止するだけなので、いつでも復元できます。

カードには作品番号、タイトル（未照合なら「識別中」）、公開日、購読日時、ポスターが出ます。作品番号のない記録はカードになりません。

## 「購読中」のまま、または「一時停止」になる理由

- 検索は成功したが、どのサイトもダウンロード先を返さなかった場合、状態は「購読中」のままで「資源がまだありません」という通知が入り、次の回で自動的に再試行します。
- 作品情報の照合が 10 回続けて失敗すると、無駄なアクセスを防ぐために自動で「一時停止」になります。
- 未照合の購読はバックグラウンドで処理されます。起動 10 分後に初回、その後は 300 分ごとです。
- 「購読中」の記録は 20 分ごとに処理され、1 回につき最大 10 件、購読日時の新しい順です。

## 設定項目

購読の全体設定は **タスク管理 → タスク設定 → 購読ルール** にあります。

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| 中国語字幕を優先 | 中国語字幕付きの資源を優先したいときにオンにします | 現バージョンでは好みを保存するだけで、自動ダウンロードの並びには影響しません |
| 検索順序 | カンマ区切りのサイト名。既定値は `M-Team,NexusPHP,Rousi,Prowlarr` です。同じ作品番号でどのサイトを先に試すかを決めます | 上記の既定順になります。キーワードが間違っていると、そのサイトは常に後回しです |
| ダウンロード先ディレクトリ | ダウンロードしたファイルの保存先 | 空ならダウンローダの既定の保存先を使います |

再起動は不要で、次の購読処理から新しい値が使われます。まとめ系のソースは検索順序に関係なく常に最後になります。

磁力検索に画面設定はありません。入力できるのはキーワードと並び替えだけです。

## 困ったときは

- **まったく結果が出ない**：サイトや磁力インデックスが有効か、アカウントが切れていないかを確認し、キーワードを短くするか作品番号に変えてください。
- **一部のサイトしか返ってこない**：単一サイトのタイムアウトは正常な縮退です。少し待ってから再実行してください。
- **結果はあるのに落とせない**：まず「ダウンロードへ送信」を試し、それでも駄目ならダウンローダのアドレスとアカウントを確認してください。
- **カードが「識別中」のまま**：作品情報と照合できていません。ライブラリで手動に紐付けてから「今すぐ検索」を押してください。
- **「一時停止」になった**：照合が 10 回続けて失敗しています。作品番号や情報を直してから復元してください。
- **送信したのにタスクが見えない**：ダウンローダ側で確認するか、[ダウンロードと取り込み](./downloader.md)の手順で一覧を確認してください。
