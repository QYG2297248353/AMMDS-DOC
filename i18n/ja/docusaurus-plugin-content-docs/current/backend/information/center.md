# メッセージ、フィード、共有と連携

**インフォメーションセンター** は四つを扱います。システムが残したメッセージ、外部のフィード、項目を他の人に共有すること、そして別の AMMDS サイトとの連携です。四つは独立しているので、必要な節だけお読みください。

## 1. メッセージを読む

メッセージ画面には、AMMDS の動作中に発生した通知が集まります。バックグラウンドタスクの結果、サイト認証の状態、共有申請と取り込みの進捗、そして公式のお知らせです。

> **通知の種類**：三種類あります。システム通知はアプリ自身が出します（購読の結果、サイト認証、整理の進捗など）。公式通知は公式アカウントのお知らせ、共有通知は共有に関する申請と取り込みの結果です。

### 絞り込みと閲覧

上部に二つの絞り込みがあります。通知種別（すべて / システム / 公式 / 共有）と閲覧状態（すべて / 既読 / 未読）です。変更したら「検索」を押します。一覧は 1 ページ 10 件で、件数は切り替えられます。

各メッセージには種類、レベル、タイトル、本文の要約、時刻、操作が表示されます。レベルは四段階です。

| レベル | 色 | 意味 |
| --- | --- | --- |
| 情報 | 青 | 一般的なお知らせ。対応不要です |
| 成功 | 緑 | 操作が正常に完了しました |
| 警告 | 橙 | 問題の可能性がありますが、使用は続けられます |
| エラー | 赤 | 失敗または異常。対応が必要です |

### 既読と削除

- 操作列のチェックボタンで既読になります。既読になるとボタンは無効になり、二重送信されません。
- 削除ボタンでメッセージを消します。消すと一覧に戻りません。
- 現バージョンでは一件ずつの操作のみで、「すべて既読」や一括削除はありません。

この画面はアプリ内のメッセージだけを扱います。スマートフォンへの通知は、統合アプリで通知サービスを設定してください。

## 2. 外部フィードを購読する

> **RSS**：多くのサイトが公開している更新リストの形式です。アドレスを登録すると、AMMDS が定期的に取りに行き、新しい記事をアプリ内で読めるようにします。

フィードには六つのタブがあります。

| タブ | 用途 |
| --- | --- |
| ダッシュボード | 購読数と記事数、分類の内訳、直近 14 日の傾向、最近のタスク |
| 購読管理 | 追加、編集、取得、アーカイブ、削除 |
| オフラインキャッシュ | 使用量と進捗の確認、キャッシュの削除 |
| 人気購読 | オンラインの人気リストから選んでワンクリックで購読・解除 |
| リンクプレビュー | アドレスを解析して中身を確認してから購読 |
| 設定 | 全体の既定値 |

### 購読を追加する

1. 「購読管理」で追加を押し、下の項目を入力します。
2. 保存後、その行の「取得」を押すとすぐ実行され、追加された件数が表示されます。
3. まとめて取得するには「すべて取得」を使います。バックグラウンドタスクなので、ページを離れても構いません。

アドレスが使えるか不安なときは、先に「リンクプレビュー」をお試しください。アドレスを入れて「解析プレビュー」を押すと、件数、分類、言語、記事のプレビューが確認できます。内容を確認してから「このソースを購読」を押します。

### 設定項目：購読に入力できる項目

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| 有効状態 | オフにすると取得の対象から外れます | 既定は有効です |
| 購読アドレス | RSS または Atom のアドレス | アドレスがないと取得できません |
| 名称 | アプリ内で表示する名前 | 一覧で見分けにくくなります |
| 説明 | 任意のメモ | 表示されません |
| 内容分類 | 記事 / 画像 / 動画 / 資源 / その他 | 「その他」になり、公開タブには出ません |
| アイコンのリンク | 任意。一覧の小さなアイコン | 既定のアイコンになります |
| 詳細解析 | 取得後に詳細ページを開き、本文とメディアを補完します | リストの要約だけになります |
| オフラインキャッシュ | 本文や画像をローカルに保存します | 配信元が消すと、内容も読めなくなります |

サイトのプラグインが持ち込む「統合ソース」は、名称・説明・アイコンだけ変更でき、アドレスは読み取り専用です。

### オフラインキャッシュ

> **オフラインキャッシュ**：記事の本文や画像などの資源を自分のディスクに保存することです。配信元が不安定なときや古い記事を消すときに役立ちます。

キャッシュ画面では、購読ごとに「総件数 / キャッシュ済み / 未処理」、キャッシュの使用量、進捗率が確認できます。「キャッシュを更新」はバックグラウンドタスクを登録し、「キャッシュを削除」はすべてのファイルを消します。削除したあとは、再度キャッシュしないとオフラインで読めません。アーカイブ済みの購読は取得もキャッシュもされません。

### 人気購読

人気リストはオンラインのカタログから取得し、名称、説明、分類、種類、配信元ドメインを表示します。配信元には三つの印があります。オンライン同期（今しがた取得）、ローカルキャッシュ（オンラインが使えず保存分を利用）、内蔵フォールバック（初回導入でオンラインも不可）です。「今すぐ同期」もでき、未購読のものはそのまま購読できます。購読解除すると、取得済みの記事も一緒に削除されます。システムは定期的にこれらのソースが応答するかを確認し、応答しないものに印を付けます。

### フィード全体の設定

これらは**新規購読の既定値**であり、変更しても既存の購読には影響しません。個々の購読のスイッチが優先されます。

| 設定項目 | 何を決めるか / 入力方法 | 未設定・誤設定の場合 |
| --- | --- | --- |
| 自動アーカイブ | 毎日、保持日数より古い購読をまとめてアーカイブします | 既定はオフで、アーカイブは手動です |
| 自動アーカイブの保持日数 | 数値。既定 30 | 0 以下は自動アーカイブ無効と同じです |
| 既定の詳細解析 | 新規購読で「詳細解析」を最初からオンにするか | 既定はオフです |
| 既定のオフラインキャッシュ | 新規購読で「オフラインキャッシュ」を最初からオンにするか | 既定はオフです |
| 1 記事あたりの画像上限 | 数値。既定 20 | 画像が多い記事は一部だけ保存されます |
| 1 記事あたりの動画上限 | 数値。既定 0 | 既定では動画本体は保存しません |
| 1 回あたりの処理件数上限 | 数値。既定 200 | 残りは次の回に回ります |
| キャッシュ要求のタイムアウト（秒） | 数値。既定 30 | 遅い資源は失敗し、再実行が必要です |
| 人気リストのキャッシュ時間（分） | 数値。既定 360 | 短いほど新しいが取得頻度が増え、長いほど古い可能性があります |
| 人気ソースの可用性チェック | リスト内のソースが応答するか定期確認するか | 既定はオン。オフにすると使えないアドレスを勧める可能性があります |
| リンクプレビューのタイムアウト（秒） | 数値。既定 20 | 遅いサイトは解析に失敗します |

:::warning[購読の削除は記事も消します]
購読を削除すると、その購読で取得した記事もすべて削除されます。元に戻せません。
:::

## 3. 項目を共有する

共有リンクは、作品・出演者・シリーズ・漫画・小説・ドラマを公開アドレスにします。相手はログインなしで開けますが、見られるのは項目の情報だけで、メディアファイルは渡りません。

### 共有を作る

1. 「新規共有」を押し、種類を選びます。
2. 共有したい項目を検索して選びます。
3. 有効期限を選びます。無期限、または任意の期限です。
4. 「他人の取り込みを許可するか」を決めます。オフにすると相手は閲覧のみで、取り込みには申請が必要です。
5. 必要ならアクセスパスワードを設定します。空ならパスワードなしです。
6. 「作成」を押します。結果画面に QR コードと完全なリンクが表示され、リンクは一度自動でコピーされます。

> **アクセスパスワード**：いわゆる抽出コードです。相手にはリンクとパスワードを両方渡してください。パスワードはリンクに含まれません。

一覧は種類で絞り込み、短縮コードやタイトルで検索できます。各行には種類、タイトル、短縮コード、完全なリンク、パスワードの有無、有効期限、状態、取り込み可否、作成日時が表示されます。

| 状態 | いつそうなるか | 相手に見えるもの |
| --- | --- | --- |
| 正常 | 期限切れでも停止中でもない | 閲覧可。取り込み可否は設定次第です |
| 停止中 | 自分で停止した | 共有が停止されていると表示されます |
| 期限切れ | 設定した期限を過ぎた | 共有の期限が切れたと表示されます |

停止はいつでも再開できます。削除は元に戻せず、リンクは即座に無効になります。

### 取り込み申請の処理

誰かがあなたの共有を取り込みたいとき、申請は「受信トレイ」に入ります。対象の共有、申請者（ニックネームとアカウント ID）、メールアドレス、理由、状態、日時が表示されます。「保留中」だけが承認・却下できます。

結果は共有通知になります。ただし、**承認はその申請の状態を変えるだけ**で、共有そのものが取り込み可能かは、作成時の設定のままです。

## 4. 他人の共有を取り込む

取り込みは **システム管理 → バックアップと復元 → 共有取り込み** にあります。

| 設定項目 | 何を決めるか / 入力方法 | 未設定の場合 |
| --- | --- | --- |
| 共有リンクまたは短縮コード | 相手から受け取った公開アドレス、または末尾の短縮コード | プレビューできません |
| アクセスパスワード | 相手が設定しているときだけ入力 | パスワードを求められ、取り込みできません |
| 取り込み方法 | 既存をスキップ / 上書き更新 / マージ更新 | 既定は「既存をスキップ」です |

入力したら「共有をプレビュー」で種類・タイトル・件数を確認し、「共有を取り込み」を押します。取り込みが許可されていない場合は「この共有は取り込みできません」と表示されるので、理由を書いて申請できます（事前にユーザー ID、ニックネーム、メールアドレスを登録しておく必要があります）。

同じページの下では「リンク記録」（成功、権限なし、リンク無効、期限切れ、失敗）と「申請記録」（対象、理由、状態。保留中は取消可）を切り替えられます。記録を消しても、取り込み済みのデータには影響しません。

## 5. 別の AMMDS と連携する

> **インスタンス連携**：二つの AMMDS を友達にすることです。連携すると、メッセージのやり取り、相手のライブラリの検索、漫画や小説の情報の取り込みができます。サイトのトークンを使うため、パスワードを相手に渡す必要はありません。

> **トークン**：期限付きの証明書で、一時的な通行証のようなものです。切れたら取り直せばよいだけです。

### 前提条件

1. 両方が **システム設定** で「連携」をオンにします（既定はオフです）。
2. 相互にネットワークから到達できること。ドメインを使うなら暗号化アクセスが推奨されます。
3. 相手のサイトアドレス（プロトコル付き、または `IP:ポート`）を知っていること。

スイッチがオフのままでは、友達申請も検索も成功しません。

### 友達追加と申請の送受信

1. 「友達を追加」を押し、相手のアドレスを入力します。
2. 「解析」を押すと、相手の連携サービスを探して友達 ID とニックネームを自動入力します。
3. 必要ならサイト名とメモを入力し、申請理由（必須）を書いて「申請」を押します。
4. 相手が受信トレイで承認すると関係が成立します。長く放置されたら「送信済み申請」から再送し、拒否されたら新しく申請します。

友達一覧には名前、状態（オンライン / 接続中 / 長期オフライン / オフライン）、アドレス、メモ、そして更新・情報・メッセージ・編集・削除が表示されます。アドレスの横の「チェック」で状態を更新できます。

- **更新**：トークンを取り直します。期限切れや相手側のリセット後に使います。
- **情報**：相手のニックネーム、サイト名、メモを変更します。アドレスは読み取り専用です。
- **編集**：メモだけ変更します。
- **削除**：友達関係を消します。メッセージと申請の記録は残ります。

### 友達検索とメッセージ

「友達検索」はすべての友達サイトへ同時に問い合わせ、結果をまとめます。種類は作品、出演者、漫画、小説で、キーワードは必須です。「取り込み」ボタンがあるのは漫画と小説だけで、作品と出演者は閲覧のみです。同名の衝突や相手側の詳細欠落があると、取り込みは失敗して理由が表示されます。

友達の行で「メッセージ」を押すと会話画面が開きます。時系列に並び、自分の発言は右、相手は左です。メッセージはそれぞれのデータベースにだけ保存され、中央のサーバーを経由しません。

連携では相手のメディアファイルをコピーしません。本文やポスターは各自のサイトが管理します。

## 困ったときは

- **メッセージが見つからない**：絞り込みが「未読」や特定の種類で止まっていないか確認し、解除してから再検索してください。
- **フィードが取得できない**：「リンクプレビュー」でアドレスが解析できるか確認してください。使えなくなっていたら差し替えるか、人気購読から同種のものを選びます。
- **共有が開けない**：期限切れか停止中です。延長または作り直しを依頼してください。パスワードを求められたら相手に聞いてください。
- **取り込みボタンが押せない**：相手が「閲覧のみ」にしています。申請を出して承認を待ってください。
- **相手サイトの解析に失敗する**：アドレスと連携スイッチを確認し、まずブラウザで相手サイトを開いてみてください。
- **友達が長期オフライン**：「チェック」で確認し、「更新」を試してください。駄目なら相手サイトとネットワークを確認します。
