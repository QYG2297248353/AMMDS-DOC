# ライフアーカイブ

ライフアーカイブは自分用の記録帳で、管理画面の左側メニューにあり、**記念日**、**体型記録**、**フィットネス記録**、**プライベートライフ**の四つのページに分かれています。各ページは独立しており互いに影響しません。記録したい種類のページに進んでください。

この機能は管理画面にログインした人だけが利用でき、フロントエンドのサイトには入口がありません。記録は自分の AMMDS 内にのみ保存され、外部サービスへ同期されることはありません。

## 入口と共通点

管理画面にログイン後、左側メニューの「ライフアーカイブ」を見つけて展開すると、四つのサブページが表示されます。

四つのページの使い方は基本的に同じです：

- 右上またはページ上部に「新規追加」ボタンがあり、入力して保存するだけです。
- 各レコードは編集・削除できます。削除前には確認ダイアログが表示され、**削除後は復元できません**。
- 一覧は既定で 1 ページ 10 件表示され、表示件数を変更したりページを切り替えたりできます。
- 上部の統計とグラフは、保存・編集・削除後に自動で更新されます。

## 一、記念日

記念日は、誕生日、結婚記念日、祝日、仕事上の重要な節目などを記録するためのものです。ページ上部には四つの統計カードがあります：

| 統計カード | 集計内容 |
| --- | --- |
| 記念日 | すべての記念日の数 |
| 間近 | 次回の発生日が今後 7 日以内（今日を含む）の数 |
| 今月の記念日 | 月が今月と同じものの数 |
| 今日の記念日 | 月と日が今日と同じものの数 |

これら四つのカードは**すべてのレコード**を集計対象とし、下の検索や絞り込みには連動しません。

### 記念日を新規追加する

「記念日を追加」をクリックし、次の表に従って入力します：

| 設定項目 | 入力方法 | 説明 / 制限 |
| --- | --- | --- |
| イベント名 | 必須 | 2〜30 文字。例：「結婚記念日」 |
| 日付の種類 | 新暦または旧暦、既定は「新暦」 | 「旧暦」を選んでも記録に目印を付けるだけで、日付が旧暦に換算されることはありません |
| 日付 | 必須 | 出来事が起きた日付を選択します。新規追加時に未来の日付を選ぶこともできます |
| イベント種別 | 必須、既定は「記念日」 | 誕生日、記念日、祝日、仕事、個人、その他。一覧では色分けされたラベルで区別されます |
| 繰り返し | 必須、既定は「毎年」 | 毎年、毎月、一度きり |
| 通知タイミング | 既定は「1 日前」 | 当日、1 日前、3 日前、7 日前、通知なし。保存後、一覧に「通知」マークが付きます |
| 備考 | 任意 | 最大 200 文字 |

:::note[繰り返しとカウントダウンについて]
繰り返しの設定は、現在のところ記録情報として保存されるだけです。一覧のカウントダウンと上部の統計はいずれも「毎年同じ月日」を基準に計算され、「毎月」や「一度きり」を選んでも変化しません。
:::

### 一覧と絞り込み

- 検索ボックスでは記念日の名前と備考を検索できます。
- 「絞り込み」をクリックすると、イベント種別と日付範囲で絞り込めます。選択後「絞り込みを適用」をクリックします。
- 絞り込み項目には誕生日、記念日、祝日、仕事、その他があり、**「個人」はありません**。新規追加時は「個人」を選べますが、現時点ではそれで絞り込むことはできません。
- カウントダウンは「今日」「明日」「明後日」または「N 日後」と表示され、日付の月日を基準に計算され、年は関係しません。
- 複数のレコードにチェックを入れると、一括削除できます。

## 二、体型記録

体型記録は、身長、体重、各部分の周囲の変化を追跡するためのものです。ページ上部には四つの統計カードがあります：

| 統計カード | 集計内容 |
| --- | --- |
| 記録総数 | すべての体型記録の数 |
| 平均身長 | すべての記録の平均値 |
| 平均体重 | すべての記録の平均値 |
| 平均 BMI | すべての記録の平均値 |

統計カードはすべての記録を対象に計算されます。下の「体重と BMI の推移」グラフは現在の絞り込み条件に連動し、絞り込み後に描画されます。

### 体型記録を新規追加する

「記録を追加」をクリックし、次の表に従って入力します：

| 設定項目 | 入力方法 | 説明 / 制限 |
| --- | --- | --- |
| 記録日時 | 必須 | 今日以前の日付のみ選べ、未来は選択できません |
| 身長 | 必須 | 100〜250 cm、小数第 1 位まで |
| 体重 | 必須 | 30〜200 kg、小数第 1 位まで |
| BMI | 自動計算、入力不要 | 身長と体重から算出され、小数第 1 位まで保持されます。身長または体重を変更すると連動して変わります |
| 胸囲 / ウエスト / ヒップ | 任意 | それぞれ 40〜200 cm、小数第 1 位まで |
| 上腕囲 | 任意 | 15〜60 cm、小数第 1 位まで |
| 大腿囲 | 任意 | 30〜100 cm、小数第 1 位まで |
| ふくらはぎ囲 | 任意 | 20〜60 cm、小数第 1 位まで |
| 備考 | 任意 | 最大 200 文字 |

BMI の区分はページ上のラベルと一致します：

| BMI | ラベル |
| --- | --- |
| 16 未満 | 著しく低い |
| 16 以上 18.5 未満 | やせている |
| 18.5 以上 24 未満 | 健康 |
| 24 以上 28 未満 | 過体重 |
| 28 以上 32 未満 | 肥満 |
| 32 以上 | 高度の肥満 |

### 一覧と絞り込み

- 検索ボックスでは備考を検索できるほか、身長や体重の数値を直接入力することもできます。
- 「絞り込み」をクリックすると、記録日の範囲と体重の範囲で絞り込めます。
- 開始日は終了日より後に設定できません。また、最小体重は最大体重より大きくできません。違反すると画面に警告が表示されます。
- 一覧は 1 ページあたり 10、20、50 件から選べます。
- 編集、単一削除、チェック後の一括削除に対応しています。
- 推移グラフにデータがない場合は「現在の絞り込み範囲内に推移データはありません」と表示されます。

## 三、フィットネス記録

フィットネス記録は、毎回の運動を記録するためのものです。ページ上部には記録総数、総運動時間、平均時間、消費カロリーの四つの統計カードがあり、いずれもすべての記録を対象に計算されます。

下には二つのグラフがあります：

| グラフ | 内容 |
| --- | --- |
| 直近 30 日の運動推移 | 直近 30 日の各日の総時間と総カロリー。運動しなかった日は 0 として計算されます |
| 運動種別の割合 | 各運動種別の割合。すべての記録の総時間で並べ替えられます |

これら二つのグラフは固定の集計基準で、一覧の絞り込みには影響されません。

### フィットネス記録を新規追加する

「記録を追加」をクリックし、次の表に従って入力します：

| 設定項目 | 入力方法 | 説明 / 制限 |
| --- | --- | --- |
| 記録日時 | 必須 | 日付のみを選択し、具体的な時刻は記録しません |
| 運動種別 | 必須 | 有酸素運動、筋力トレーニング、ヨガ、水泳、ランニング、サイクリング、その他 |
| 具体的な種目 | 必須 | 最大 128 文字。例：「ジョギング」「ベンチプレス」 |
| 運動強度 | 必須 | 低、中、高 |
| 体調 | 必須 | 快適、普通、疲労、非常に疲労 |
| 継続時間 | 必須 | 0〜1440 分、整数のみ |
| 消費カロリー | 必須 | 0〜20000 kcal、整数のみ。種別、強度、時間を入力すると自動で推定されます |
| 運動場所 | 任意 | 最大 128 文字 |
| 心拍数 | 任意 | 0〜300。平均心拍数を入力します。整数のみ |
| 体重 | 任意 | 0〜500 kg、小数第 1 位まで |
| 肩幅 | 任意 | 0〜300 cm、小数第 1 位まで |
| 上腕囲 | 任意 | 0〜300 cm、小数第 1 位まで |
| 前腕囲 | 任意 | 0〜300 cm、小数第 1 位まで |
| 胸囲 | 任意 | 0〜300 cm、小数第 1 位まで |
| ウエスト | 任意 | 0〜300 cm、小数第 1 位まで |
| ヒップ | 任意 | 0〜300 cm、小数第 1 位まで |
| 大腿囲 | 任意 | 0〜300 cm、小数第 1 位まで |
| ふくらはぎ囲 | 任意 | 0〜300 cm、小数第 1 位まで |
| 備考 | 任意 | 最大 1000 文字 |

:::note[カロリーは推定値です]
自動計算されるカロリーは、運動種別、強度、時間に基づく一般的な参考値であり、正確な測定値ではありません。この数値は直接変更できます。また、「電卓」をクリックして体重、運動種別、強度、時間を入力すると、体重に基づいて再推定し、その結果を記録に反映できます。
:::

### 一覧と絞り込み

- 検索ボックスでは運動種別または場所を検索できます。
- 「絞り込み」をクリックすると、運動種別、強度、記録日の範囲で絞り込めます。
- 表見出しをクリックすると、記録日時、時間、カロリーで並べ替えられます。
- 編集、単一削除、チェック後の一括削除に対応しています。
- 一覧には概要項目のみ表示されます。心拍数、周囲、備考などは編集ダイアログを開かないと全文を確認できません。

## 四、プライベートライフ

プライベートライフは、個人的なデータを記録するためのものです。ページ上部には四つの統計カードがあります：

| 統計カード | 集計内容 |
| --- | --- |
| 記録総数 | すべての記録の数 |
| 絶頂の回数 | 記録で「絶頂」が「はい」の件数 |
| 平均時間 | すべての記録の平均継続時間 |
| パートナー数 | 記録に登場した異なるパートナー名の数 |

下の「直近 12 か月の頻度」グラフは月ごとの記録件数を集計し、現在の月を含みます。記録のない月は 0 と表示されます。統計とグラフはいずれもすべての記録を対象に計算されます。

:::note[一覧には概要のみ表示されます]
一覧には日付、種別、パートナー、場所、時間、保護措置、気分のみが表示されます。備考などの詳細は一覧に表示されず、「編集」をクリックしたときにだけ確認できます。
:::

### プライベート記録を新規追加する

「記録を追加」をクリックし、次の表に従って入力します：

| 設定項目 | 入力方法 | 説明 / 制限 |
| --- | --- | --- |
| 記録日時 | 必須 | 日付のみを選択します |
| 記録種別 | 必須 | 自慰、パートナー、同性、複数人 |
| パートナー | 「自慰」以外は必須 | 過去の記録にある名前から選ぶか、新しい名前を直接入力できます。「複数人」を選んだ場合は複数入力できます |
| 場所 | 必須 | 最大 128 文字 |
| 継続時間 | 必須 | 0〜1440 分、整数のみ |
| 保護措置 | 任意 | コンドーム、女性用コンドーム、避妊薬、IUD（避妊リング）、避妊手術、無防備 |
| 体位 | 任意 | 最大 64 文字 |
| ランジェリー | 任意 | はい / いいえ、既定は「いいえ」 |
| 絶頂 | 任意 | はい / いいえ、既定は「いいえ」 |
| パートナーの絶頂 | 「自慰」以外で表示 | はい / いいえ、既定は「いいえ」 |
| 射精部位 | 「自慰」以外で表示 | 体内、体外、顔、胸部、口腔、肛門 |
| 潮吹き | 任意 | はい / いいえ、既定は「いいえ」 |
| 道具 | 任意 | 最大 255 文字 |
| 気分 | 任意 | 快感、興奮、穏やか、疲労 |
| 備考 | 任意 | 最大 1000 文字 |

:::note[「自慰」を選ぶと項目が変わります]
記録種別で「自慰」を選ぶと、「パートナー」「パートナーの絶頂」「射精部位」が自動的に非表示になり、パートナーの入力も不要になります。「パートナー」「同性」「複数人」に切り替えると、これらの項目が再表示されます。
:::

### 一覧と絞り込み

- 検索ボックスではパートナーまたは場所を検索できます。
- 表見出しをクリックすると、記録日時、パートナー、継続時間で並べ替えられます。
- このページには検索のみがあり、日付や種別の絞り込みはありません。
- 編集、単一削除、チェック後の一括削除に対応しています。

## データとプライバシー

- ライフアーカイブは管理画面にログインした人だけが利用でき、フロントエンドのサイトには入口がなく、共有リンクも提供されません。
- 記録は自分の AMMDS 内にのみ保存され、外部サービスへアップロードされることはありません。
- 削除は完全削除であり、削除後は復元できません。一括削除も同様に復元できません。
- 上部の統計はすべての記録を対象に計算され、検索や絞り込みの影響を受けません。体型の推移グラフは絞り込みに連動し、フィットネスとプライベートのグラフは固定の集計基準です。

## よくある質問

| 現象 | 説明 |
| --- | --- |
| 左側メニューにライフアーカイブが見つからない | まず管理画面にログインする必要があります。ライフアーカイブはフロントエンドのサイトのメニューにはありません |
| 絞り込み後も上部の統計が変わらない | 正常です。統計はすべての記録を対象に計算されます。体型の「体重と BMI の推移」グラフは絞り込みに連動します |
| 記念日で「毎月」を選んでもカウントダウンが年単位のまま | カウントダウンと統計は「毎年同じ月日」を基準に固定計算されます。繰り返し設定は記録用です |
| 旧暦の日付が自動換算されない | 「旧暦」を選んでも目印を付けるだけで、日付は選択した日がそのまま保存されます。旧暦に合わせて自分で入力する必要があります |
| BMI を手動で変更できない | BMI は身長と体重から自動計算されるため、いずれかの値を変更すると更新されます |
| 自動計算のカロリーが正確でない | 参考値にすぎません。直接変更できるほか、電卓で体重から再推定することもできます |
| 「自慰」を選ぶとパートナー項目が消えた | 仕様です。パートナー関連の項目は自動的に非表示になります。別の種別に戻すと再表示されます |
| プライベートライフの一覧で備考が見えない | 一覧には概要のみ表示されます。備考は「編集」で確認してください |
| 削除した記録は取り戻せるか | できません。削除は復元不可です |
