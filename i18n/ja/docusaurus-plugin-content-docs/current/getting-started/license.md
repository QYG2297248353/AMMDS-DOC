# ライセンス

このページでは、**直接使用できるライセンスキー**をまとめて掲載します。いずれかをコピーしてユーザーセンターで有効化すれば、**透かしはすぐに消え、すべての機能がそのまま使えます**。キーは管理者が随時更新します。「有効化枠がいっぱい」と出たり使えない場合は、次のキーをお試しください。

> **ライセンス**：この導入が正しく認可されていることを示す記録です。有効な認可がないと全画面に透かしが出ますが、ログイン、システム設定、サイト認証、データのバックアップなどはすべて影響を受けません。
>
> **キー**：`AMMDS-XXXX-XXXX-XXXX-XXXX` の形をした文字列で、この導入の認可証にあたります。

透かし・お試し・オフライン有効化といった概念だけを知りたい場合は、[用語集](../glossary.md)と[よくある質問：ライセンスと透かし](../faq.md#ライセンスと透かし)をご覧ください。有効化・更新・無効化の流れを詳しく見たい場合は、[システム保守：ライセンスと透かし](../backend/system/maintenance.md#4-ライセンスと透かし)を参照してください。

## 有効化の手順

**管理者**アカウントでログインし、次の3つの手順で操作します。他のログインアカウントは状態と特典を閲覧できますが、有効化はできません。

1. 右上のアバター → **ユーザーセンター** を開き、ページ下部の「ライセンス」カードまでスクロールします。
2. 「有効化」をクリック（すでに有効な場合は「ライセンスを変更」を押して展開）し、キーを貼り付けます。
3. 確定します。成功すると透かしが消え、カードにプランと有効期限が表示されます。

状態の各項目、オフライン有効化、お試しの規則については、[システム保守：ライセンスと透かし](../backend/system/maintenance.md#4-ライセンスと透かし)を参照してください。サーバーが認可サービスに接続できない場合は「オフライン有効化」を使います。画面の案内に従ってインスタンスIDとコマンドを取得し、別の接続済みデバイスで実行して、返されたJSONをファイル（64 KiB以内）に保存してアップロードしてください。

## いくつかの規則

| 項目 | 規則 |
| --- | --- |
| 有効化枠 | 1つの導入が1枠を使用し、ログインユーザー数とは無関係。枠が埋まったら古いデバイスを解放する |
| ライセンスの変更 | 現在の認可を置き換えます。お試し中に有効化成功すると、お試しは即座に終了します |
| オンライン更新 | 一度だけ検証します。サービスが一時的に使えない場合はキャッシュの状態を返します |
| オンライン認可の無効化 | リモート側の解放が確認されてからローカルのデータを消去します |
| ローカルの認可だけ消去 | ローカルのキーとトークンのみ削除。リモートの枠は解放せず、お試し記録も消しません |
| 会員とライセンス | 会員はアカウント上の識別、ライセンスはこの導入の認可で、両者は独立しています |

無効化と消去には確認が必要で、取り消せません。プラン名・価格・特典の範囲は購入ページとライセンスページの表示に従ってください。

## キーが使えないとき

- **「有効化枠がいっぱい」と出る**：そのキーの枠が使用済みです。次のキーをお試しください。自分のキーならライセンスポータルで古いデバイスを解放するか、古いインスタンスでオンラインライセンスを無効化してください。
- **「認可が利用できない」/ 検証失敗**：期限切れ・取り消し・一時停止の可能性があります。別のキーを試し、キーが完全にコピーされ余分な空白がないか確認してください。
- **透かしが消えない**：有効化成功後は消えるはずです。消えない場合はユーザーセンターのライセンス状態と通知バーを確認し、[よくある質問：ライセンスと透かし](../faq.md#ライセンスと透かし)から該当項目を探してください。機能には影響しないので、そのまま使い続けられます。
- **認可サービスに接続できない**：有効済みのインスタンスはキャッシュした有効な認可でしばらく動作を続け、オフラインの猶予期間があります。ネットワークが戻ったら更新してください。猶予が切れても透かしが戻るだけで、機能には影響しません。
- **それでも解決しない**：バージョン、時刻、ログの抜粋を添えてGitHubにIssueを立ててください：https://github.com/QYG2297248353/AMMDS-Docker/issues/new
