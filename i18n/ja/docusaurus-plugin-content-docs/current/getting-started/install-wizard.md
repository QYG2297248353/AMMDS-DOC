# 初期設定ウィザード：初回の設定

プログラムのインストール後、初めて起動したときにシステム内に管理者アカウントがまだない場合、自動的に初期設定ウィザードが起動します（アドレスは `/setup`）。四つの手順を入力し終えると、作成したばかりのアカウントでログインできるようになります。

:::note[ウィザードが表示されるタイミング]
初期設定が完了していない場合にのみ表示されます。すでに初期設定済みで `/setup` にアクセスすると、自動的にホームへ戻ります。もう一度実行したい場合は、空のデータベースに切り替える必要があります。
:::

## 始める前に

- プロフィールとアバターの同期に使うメールアドレスを用意します（メールアドレスの実在確認は行いません）
- 管理者のユーザー名とパスワードを決めておきます（ルールは後述）
- 一連の流れは二分〜三分で、途中で「戻る」をクリックして修正できます

## 第一步：規約への同意

ページには「概要」「利用規約」「プライバシーポリシー」の三つのタブがあります。概要では、プログラムが何をするか、初回起動時にどのファイルが書き込まれるか、データがどこに保存されるかをわかりやすい言葉で説明します。完全な条文はページ上のリンクから開けます。

読み終えたら「内容を確認し、同意します」にチェックを入れると、「次へ」をクリックできるようになります。

:::warning[チェック必須]
チェックを入れずに「次へ」をクリックすると、規約への同意が必要であると表示され、手順は進みません。
:::

## 第二步：管理者の作成

| 項目 | 入力方法 | ルール |
| --- | --- | --- |
| ユーザー名 | 今後のログインに使う名前 | 3〜32 文字。英字、数字、アンダースコア、ハイフンのみ使用可能 |
| メールアドレス | 連絡用メールアドレス | 必須、形式が正しいこと。後のアバター同期で使用します |
| パスワード | ログイン用パスワード | 6〜22 文字。大文字と小文字の両方を含み、さらに数字または特殊文字を含む必要があります |
| パスワード（確認） | もう一度入力 | 直前の項目と完全に一致している必要があります |

> 起動時に環境変数 `ADMIN_USER` / `ADMIN_PASS` で管理者がすでに作成されている場合、この手順は「完了済み」と表示され、メールアドレスのみ入力すればよく、残りの三項目は入力不要です。

## 第三步：サイト情報

| 項目 | 入力方法 | 未入力の場合 |
| --- | --- | --- |
| サイト名 | ブラウザーのタイトルとフッターに表示される名前 | 必須 |
| ランディングページ | 「管理画面を優先」または「フロントエンドを優先」 | 既定は管理画面優先。フロントエンドを選ぶと、以降はルートアドレスを開いたときにまずフロントエンドのホームが表示されます |
| 备案号（届出番号） | 必要な場合のみ入力、任意 | 未入力の場合はフッターに届出情報が表示されません |

## 第四步：プロフィールの補完

この手順で、フロントエンドに表示されるあなたの身分が決まります。

| 項目 | 説明 |
| --- | --- |
| アバター | メールアドレスに基づいて Gravatar（メールアドレスからアバターを探す公共サービス）に自動でアバターを取得し、取得できない場合は頭文字付きの画像を生成します。自分でアップロードすることもでき、PNG / JPEG / GIF / WebP / BMP に対応し、2 MB 以下である必要があります |
| ユーザー ID | 4〜32 文字の英字、数字、アンダースコア、ハイフン。`admin`、`root`、`ammds` のような予約語（システムに占有されている名前）は使用できず、数字のみも不可です |
| ニックネーム | フロントエンドに表示される名前。最大 32 文字 |
| 電話番号 | 任意 |
| ソーシャルリンク | 任意、最大 20 件。アドレスは `https://` で始まる必要があります |

「プロフィールを同期」をクリックすると、メールアドレスに基づいてアバターとニックネームを再取得できます。すでに手動で変更した内容は上書きされません。

## 送信後

「初期設定を完了」をクリックすると、成功後に自動的にログインページへ移動するので、第二步で作成したアカウントでログインしてください。

:::tip[アカウント情報は忘れずに]
ウィザードで入力したユーザー名は、後から画面上で変更できません。パスワードはユーザーセンターでいつでも変更できます。回復キーは別のもので、プログラムの初回起動時に自動生成され、ここでのパスワードとは関係ありません。
:::

## よくある質問

| 現象 | 原因と対応 |
| --- | --- |
| どのアドレスを開いても `/setup` に飛ぶ | 初期設定が完了していません。ウィザードを最後まで進めてください |
| `/setup` にアクセスするとホームへ戻る | 初期設定済みです。そのままログインしてください |
| ユーザー ID が使用済みと表示される | 別の ID に変更してください。予約語と数字のみも拒否されます |
| ソーシャルリンクが送信できない | アドレスが `https://` で始まっているか確認してください |
| アバターのアップロードに失敗する | 画像が 2 MB 以下で、対応形式であることを確認してください |
| 送信後にログインできない | 第二步で入力したユーザー名とパスワードを使っているか確認してください。パスワードを忘れた場合は回復キーで再設定できます |
