# 作品・ドラマ・出演者・漫画・小説を眺める

作品、ドラマ、出演者、漫画、小説の五つのライブラリは形がよく似ています。左にカード、右に絞り込みです。このページではまず共通点を説明し、そのうえでそれぞれ何が見られて何ができるかを説明します。

> **作品番号**：作品の識別番号で、ふつうファイル名に含まれます。例：`SSIS-001`。カードでは紫色の小さな札で出ます。

> **シーズン / エピソード**：ドラマの階層です。一つの作品がいくつかのシーズンに分かれ、その下に話があります。

> **マグネット**：ダウンロードソフトにそのまま渡せる一行の文字です。トレントファイルと同じ働きをします。

## 五つに共通すること

### 一覧の形

| 区域 | 内容 |
| --- | --- |
| 左の内容 | カードの並びとページ移動 |
| 右の絞り込み | 検索、中国語優先、モード、検索履歴、人気のタグ、この棚の紹介 |

広い画面では一列 6 枚、狭くなるほど 4、3、2、1 と減ります。幅が 1024px 以下になると右の絞り込みは隠れます（漫画と小説では一覧の上へ移ります）。

### 絞り込みの部品

| 部品 | 働き | そのままのとき |
| --- | --- | --- |
| 検索窓 | 言葉を入れて改行、または検索のボタン | 空ならすべて |
| 中国語優先 | 題名の表示だけに影響。オンで中国語題名、オフで原題 | 結果は変わらず、見える名前だけ変わります |
| モード | 「全体」か「お気に入り」。切り替えるとすぐ再検索 | 既定は全体 |
| 検索履歴 | 最大 15 件。ブラウザに残り、押すと再利用 | 今の言葉をもう一度押すと検索の取り消し |
| タグ | 人気のタグ（最大 20）。押すとそのタグで絞る | もう一度押すと解除。タグを選ぶと言葉は消えます |

:::warning[言葉とタグは同時に使えません]
言葉を入れると選んだタグが消え、タグを選ぶと言葉が消えます。「両方を満たす」条件にはなりません。
:::

### ページ移動と記憶

- 1 ページは 20 件（小説は 16 件）。移動の部品は総数だけを出し、件数の選択はありません。
- 検索の言葉、モード、中国語優先はブラウザに残り、更新すると戻ります。
- 作品とドラマは詳細に入るときページを住所欄に書き込むため、戻ると同じページに戻れます。
- 未ログインの訪問者は 1 ページ最大 30 件で、ページはサーバーが無作為に選びます。そのため更新すると中身が変わることがあります。まとめ取りを防ぐ設計です。

## 作品

一覧は誰でも見られますが、**詳細はログインが必要**です。未ログインなら ログイン画面へ跳び、入ると自動で戻ります。

### カードにあるもの

- **表紙**：高精細な表紙を優先。無い、または失敗で「画像の読み込みに失敗」。
- **重ね札**：発売日、評価（10 点満点）、そして裏で付いた「再生可」の印。値があるものだけ出ます。
- **題名**：中国語優先に従います。作品一覧には中国語題名が無いときの代わりが無く、題名が空になることがあります。
- **作品番号**：紫色の小さな札。複数あることも。
- **出演者**：青の札。役どころの文字に「男 / 女」が含まれるかで札の絵が変わり、判断できないときは人型の疑問符。

### 詳細

上部に大きな題名と中国語題名（「訳」の札付き）、主な絵は高精細な背景を優先します。

| 項目 | 内容 |
| --- | --- |
| 作品番号 | すべての番号を札で表示 |
| 発売日 | もとの日付の文字 |
| 収録時間 | 分 |
| 監督 / 製作会社 / 発売元 | 複数の値を札で |
| 出演者 | 名前の札。出演者ライブラリに居れば出演者詳細へ跳べます |

情報の区域の右に三つのボタン：**購読**、**お気に入り**、**共有**。購読とお気に入りは今の状態で絵と色が変わり、共有は未ログインで ログインを求めます。

その下：

| 区域 | 内容 |
| --- | --- |
| 評価 | 10 点満点を星 5 個に換算。半星も可。点で色が変わります（8 以上は緑、4 以上は琥珀、他は赤） |
| マグネット送信 | マグネットの経路を入れて「送信」。空なら「マグネットを入力してください」 |
| 拡張情報 | 三つのタブ：分類、タグ、拡張情報の表 |
| 出演者 | 肖像 + 名前 + 役どころ。横に流れます |
| 表紙 / 背景 / 縮小 / 劇場写真 | 画像の壁。高精細が上。押すと全画面 |
| 資源の共有 | マグネット一覧：名前、大きさ、共有日、操作 |
| コメント | 手元だけの仮の実装。文末の注記を参照 |

:::warning[詳細に再生機はありません]
作品の詳細が出すのは情報、画像、資源だけで、**再生機も「再生」のボタンもありません**。カードの「再生可」は記録の印にすぎません。動画を見るには外の再生機を使ってください。
:::

「資源の共有」の各行に三つの操作：**ダウンロードを送信**（現行版では「お楽しみに」と出るだけ）、**マグネットを複写**、**資源を通報**（同じく「お楽しみに」）。表が空なら「共有された資源はありません」。

## ドラマ

ドラマは連続劇、アニメ、バラエティを「一つの作品」としてまとめ、詳細では全シーズンと全話を同じ画面に広げます。

### カードにあるもの

- **表紙**：縦長。無い、または失敗で「画像の読み込みに失敗」。
- **重ね札**：初回放送年、評価。
- **題名**：中国語優先に従います。
- **分区**：口が返す分区名を優先し、無ければ内蔵の対応表でアニメ、日本劇、韓国劇、中国劇、欧米劇、記録、バラエティ、その他。
- **連載の状態**：`Continuing` は「連載中」、`Ended` は「完結済み」。
- **シーズンと話の数**：「3 シーズン · 24 話」の形。
- **ジャンル**：先頭の三つを「 / 」で結ぶ。

### 詳細

| 項目 | 内容 |
| --- | --- |
| 初回放送 | 無ければ `-` |
| 収録時間 | 分 |
| 分区 | 中国語の分区名。未知のコードはそのまま |
| 情報源 | 情報源のコード。無ければ `-` |
| シーズン数 / 話数 | 情報源の宣言を優先し、次に実際に登録された数 |
| 状態 | 連載中 / 完結済み / 元の値 |
| ジャンル / 製作会社 | 複数の値を札で |

同じく**購読、お気に入り、共有**の三つがあります。評価は作品と同じ。マグネットの送信窓は送るだけで、送信後に窓を空にし、**一覧は表示しません**。

### シーズンと話

「シーズン一覧」は全シーズンを一度に折りたたみ可能な板として描きます。

1. 板の題はシーズン名、または「第 N シーズン」。番号が 0、または特別編の印があれば「特別編」。
2. 板の右に「このシーズンは全 N 話」。
3. 板の中にシーズンの表紙、初回放送日、あらすじ。
4. 話は番号、題名、放送日、収録時間、評価、縮小絵の表。題名は中国語を優先し、無ければ原題。
5. 既定では「話がある」最初のシーズンが開きます。シーズンが無ければ「シーズンの情報はありません」。

:::warning[話の一覧は再生のリストではありません]
一覧が出すのは番号、題名、放送日、収録時間、評価、縮小絵だけです。話にファイルの情報は無く、画面に再生機もありません。ファイルの紐づけは管理画面で行います。
:::

画像の区域は表紙、背景、縮小絵、ロゴ、横断幕です。ドラマには「劇場写真」の項目が無いため、そのブロックはありません。

## 出演者

出演者ライブラリは、出演者の記録と出演作品を結びつけます。

### カードにあるもの

- **肖像**：縦長。無い、または失敗で「画像の読み込みに失敗」。
- **重ね札**：デビュー日、身長（cm）、体重（kg）。
- **名前**：中国語優先に従います。
- **基本の札**：性別、年齢、国籍、引退、故人、カップなど。値があるものだけ。一覧の性別は `female`（「女」）とその他（「男」）の二通りです。

### 詳細

上部の大きな題名は出演者の名前で、別名があれば下に「別名：A / B」。主なカードの左が肖像で、右に次が並びます。

| 項目 | 出方 |
| --- | --- |
| 性別 | 男 / 女 / シーメール / 不明 |
| 年齢 | 「N 歳」 |
| 引退 / 故人 | 橙 / 赤の札 |
| 身長 / 体重 | 「N cm」「N kg」 |
| 血液型 / 誕生日 / 国籍 | 札 |
| スリーサイズ | 「胸-腰-尻」。カップなども追記 |
| デビュー日 / 所属 | 日付の文字と札の並び |
| 評価 | 星 5 個 + 10 点満点 |
| 交流への経路 | よくある交流サイトはドメインで見分け、他は汎用の絵 |

同じく**購読、お気に入り、共有**の三つがあります。

| 区域 | 内容 |
| --- | --- |
| 拡張情報 | 五つのタブ：紹介、傾向、特徴、タグ、拡張情報の表 |
| 肖像の並び | 出演者の画像集。拡大可。無ければ「肖像はありません」 |
| 作品 | 最近の 20 作品。発売が新しい順。画面では 10 件ごと。題名で作品詳細へ |
| 資訊 | 出演者名で検索し最大 10 件 |

:::tip[件数の上限]
作品は最近 20 件、資訊は 10 件までで、どちらにも「もっと読む」はありません。もっと見たいときは作品一覧か資訊で検索してください。
:::

:::note[「おすすめの出演者」は今は空]
そのカードにはまだ情報源が無く、いつも「おすすめの出演者はいません」と出ます。手の形の矢印は出ますが跳び先は無いので、入口と思わないでください。
:::

## 漫画

漫画は「表紙の一覧 → 詳細と各話 → 全画面の閲覧機能」の三段です。

### カードと絞り込み

カードには表紙、分類（全集でなく季号が 0 より大きければ「第 N 季」、全集なら「全集」）、題名、作者、シリーズ、タグ（最大 3 個）。検索窓は題名、説明、備考、作者、作画、出版情報、シリーズを対象にします。

### 詳細

左が表紙、右にまず札の列（分類、全集 / 第 N 季、年齢区分、ページ数「全 N ページ」＝ 無ければ 0）、次に「札 - 値」の表（作者、シリーズ、出版社、印刷、出版日、言語、形式、色、読み向き、年齢区分、評価、備考、経路。空は行を作りません）、そしてタグ、登場人物、団体、場所、説明、最後に評価です。

右に縦に四つのボタン：

1. **続きを読む**：その利用者の進み具合が残っており、かつその話が話一覧に残っているときだけ出ます。
2. **読む / 最初から読む**：進みが無ければ「読む」、あれば「最初から読む」。どちらも第一章を開きます。
3. **お気に入り / 登録済み**：未ログインで ログインの確認。
4. **共有**：同じく未ログインで 確認。

話の一覧は 1 ページ 20 話。各話に題名、「第 N 話 · X ページ」、任意の説明。読みかけの話には「N ページまで読了」の札。進みがあれば、カードの右上に「N ページから続きを読む」の近道が出ます。

### 閲覧機能

全画面で、上の帯、読む領域、下の帯、そして常に出る進みの線でできています。上の帯には戻る、題名、話の選択、前後の話、めくる向き、全画面。下の帯にはめくり、ページ入力、拡大、ページ一覧、設定。

- **めくり**：単ページ / 見開き（見開きは幅が 720px 以上必要。足りなければ単ページ）。左の三分の一で前へ、右の三分の一で次へ、真ん中で帯の出し入れ。今の話の最後でさらにめくると次の話へ。
- **流し読み**：全画像を縦に並べ、画面の上から 35% を基準にページを同期。
- **拡大**：0.5〜5 倍。ボタンは 0.25 刻み。百分率を押すと戻る。二度押しで 1 倍と 2 倍を行き来。
- **鍵**：左右でめくり、空白で次、PageUp / PageDown でめくり、Home / End で最初と最後、`+` / `-` で拡大、`0` で戻す、`F` で全画面、`Esc` で全画面を抜ける、または帯の出し入れ。

### 閲覧の設定項目

右下の「設定」の引き出し：

| 設定項目 | 選べるもの | そのままのとき |
| --- | --- | --- |
| 読み方 | めくり / 流し | 既定はめくり。流しにすると縦長の並び |
| 画像の合わせ方 | 幅 / 高さ / 元の大きさ | 違うと画面からはみ出すか小さすぎる |
| 画像の間 | 0〜40px | 変わりません |
| めくる向き | 左から右 / 右から左 | 逆向きだと押す場所が入れ替わる |
| 単ページ / 見開き | 単 / 見開き | 幅が足りなければ単ページに強制 |
| 背景のテーマ | 黒 / 濃灰 / 生成り / 目に優しい / 白 | 見た目だけ |
| 先読み | 0〜10 ページ | 多いほど滑らかだが通信が増える |
| 車輪で拡大 | オン / オフ | オフなら車輪はめくりに使われる |
| 左右を押してめくる | オン / オフ | オフなら押すと帯の出し入れだけ |
| タッチ画面で帯を自動的に隠す | オン / オフ | オンなら携帯で軽く触れると帯が出る |

設定は今のブラウザにだけ残り、**別の機器には付いてきません**。「既定に戻す」で全部が戻ります。

:::tip[設定と進みは別物]
進み具合はアカウントごとにサーバーに残るため、別の機器でも続きから読めます。設定はこのブラウザだけです。
:::

進みは「漫画 + 話 + ページ」で記録し、ページか話が変わってから約 800 ミリ秒後に保存。話の切り替え、戻る、画面が隠れる、去るときはすぐ保存します。サーバーが失敗しても手元の控えは残るため、次も続きから読めます。

## 小説

小説も「一覧 → 詳細と目次 → 閲覧機能」の三段です。

### 一覧

1 ページ 16 冊。カードには表紙、左上の青い種類の札、題名（「中国語を優先」なら中国語題名）、作者（空なら「作者不詳」）、「全 12 章 · 連載」のような章数と状態（完結 / 連載 / 下書き / 続編待ち / 執筆中）。

### 詳細

| 区域 | 内容 |
| --- | --- |
| 題名の区域 | 書名と「作者：xxx」 |
| 札の列 | 種類、状態、言語、「全 N 章」。空は出ない |
| 説明の表 | 作者、シリーズ、出版社、出版年、ISBN、章数、ページ数。値があるものだけ |
| タグ / 紹介 | 青い小さな札と長い文 |
| 評価 | 10 点満点を星 5 個に換算、右に「N 点」 |
| すばやい操作 | 続きを読む（進みがあるとき）、最初から / 読む（つねに第一章）、「前回は 第 N 章 · 題名」、お気に入り / 登録済み、共有 |
| 目次 | 「番号 + 題名 + 字数」の行と右の「読む」。1 ページ 20 章。前回読んだ章に橙の「前回読了」の札が付き、詳細を開くとそのページが開く |

お気に入りは未ログインで「操作に失敗しました。ログインをご確認ください」。共有は画面を開き、作ると共有の経路が得られます。

### 閲覧機能

画面いっぱいに広がり、上下の帯は既定で隠れていて、中央を押すと出て、4 秒操作が無いと引っ込みます。

| 場所 | 要素 |
| --- | --- |
| 上 | 戻る、書名、目次、全画面 / 解除、設定 |
| 本文 | 章の題名、段落、章末の「—— 本章 終 ——」 |
| 章末 | 次があれば「次の章：題名」で押せます。最後は「最後の章です」 |
| 下 | 前の章、前のページ、状態の文字、次のページ、次の章 |
| 下の状態 | めくりでは「第 x/y 章 · 第 a/b ページ · 全体の百分率」、流しでは「第 x/y 章 · 流しの百分率 · この章の字数」 |

目次は覆いかぶさる引き出しで、「目次 · 全 N 章」、今の章が強調され、開くと今の章へ自動で流れます。章を替えても本文は消えず、上に細い進みの線が出るだけです。

### 閲覧の設定項目

設定の中身はすぐ効き、ブラウザに残ります。別の機器には同期しません。

| 設定項目 | 選べるもの | そのままのとき |
| --- | --- | --- |
| 読み方 | めくり / 流し | 前回の選択 |
| テーマ | 白、生成り、目に優しい、暗夜 | 配色だけ |
| 文字の大きさ | A- と A+ で 2px ずつ。12〜34px。中央の数字で 18px に戻る | 前回の値 |
| 行の高さ | 1.4 / 1.6 / 1.8 / 2.0 / 2.4 | 前回の値 |
| 書体 | 既定、宋体、楷体、黒体 | 前回の値 |
| 版心の幅 | 狭 / 中 / 広（620 / 760 / 900px） | 前回の値 |
| 余白 | 狭 / 中 / 広。狭い画面では比率で縮小 | 前回の値 |
| めくりの動き | オン / オフ | オフで滑る動きが無くなる |
| 最初の行の字下げ | オン / オフ | オフで段落の字下げが無くなる |
| 両端を押してめくる | オン / オフ | オフなら押すと帯の出し入れだけ |
| 車輪でめくる | オン / オフ。めくり専用 | 流しではつねにスクロールに従います |
| 章末で自動で次へ | オン / オフ | オフなら「この章の終わりです」と出るだけ |
| 進みの線を出す | オン / オフ | オフなら下の線が出ない |

文字の大きさ、行の高さ、書体、字下げ、版心、余白を変えると組み直され、今のページの最初の段落を基準に位置が保たれます。

### 操作

| 操作 | 結果 |
| --- | --- |
| 画面の左 約三分の一を押す | 前のページ。章の最初なら前の章の終わりへ |

## まだ途中の場所

自分のせいだと思わないよう、ありのまま書きます。

- 作品の**「同じシリーズの作品」**はいつも「同じシリーズの作品はありません」——この区域に入れる中身がまだありません。
- ドラマの**「同じシリーズ」**もずっと空——ドラマのシリーズの模型がまだありません。
- **コメント**は手元だけの仮の実装です。既定で「AMMDS 公式 / お楽しみに」の一通。送っても今の画面に差し込まれるだけで、更新すると消えます。高評価と返信も裏側につながっていません。交流の場としては使えません。
- 作品の**「ダウンロードを送信」「資源を通報」**は今のところ「お楽しみに」と出るだけです。
- 作品の詳細には言語、国 / 地域、区分、シリーズが出ません。これらは管理画面のライブラリで確認してください。

## 困ったときは

- **カードを押すとログインへ跳ぶ**：詳細は要ログインです。入ると自動で元の画面へ戻ります。
- **一覧がずっと空**：管理画面でまだ取り込みが済んでいない、または絞り込みが狭すぎます（言葉とタグは重ねられません。どちらかが消えていないか確認）。
- **更新すると一覧が変わる**：訪問者なら 1 ページの件数が制限され、ページも無作為です。普通の動作です。ログインすれば戻ります。
- **カードの題名が空**：作品一覧には中国語題名が無いときの代わりがありません。「中国語優先」をオフにすれば原題が出ます。
- **「この出演者の詳細はありません」と出る**：その出演者は作品の出演者対応の中にだけ居て、出演者ライブラリには入っていません。
- **漫画の「続きを読む」が消えた**：その利用者の進みがサーバーに無い、または進みの話が話一覧から消えています。
- **進みは付いてきたのに設定が無い**：進みはアカウントごとにサーバー、設定は以前のブラウザだけ。想定どおりです。
- **小説で「指定がありません」と出る**：詳細の目次か「読む / 続きを読む」から入ってください。
