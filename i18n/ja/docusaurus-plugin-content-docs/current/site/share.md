# 共有、商店と個人ページ

このページは人と関わる三つの事を扱います。**共有**（項目をログイン不要の公開住所に変える）、**商店**（サイトの中に小さな店を開く）、**個人ページ**（他人から見える自分と、自分で資料を整える場所）です。

> **短コード**: 共有リンクの末尾にある無作為の文字列。例： `ABC123`。その共有だけの印です。

> **Passkey**: 暗証の代わりに端末の生体や端末に結び付いた鍵で入る方法です。管理画面で対応する能力が有効なときだけ、ログイン画面にこの選択が現れます。

> **回復鍵**: 設置のときに作られる非常時の鍵です。暗証を忘れたときにこれで戻します。なくしたら導入文書の初期化の流れに従うしかありません。大事に保管してください。

## 共有ページ

共有リンクは動画、俳優、シリーズ、漫画、小説、ドラマを短コード付きの公開住所に変えます。相手はログインせずに開けます。共有ページは見せるだけです。取込めるかどうかは作った人が決め、取込そのものは受け取る側の自分の仕組みの中で行われます。

### 住所のかたち

```
https://あなたの域名/share/短コード
```

| 項目 | 説明 |
| --- | --- |
| 経路 | `/share/:code`。`code` は作成時に出た短コード |
| ログイン | 不要。訪問者が直接開ける |
| 体裁 | 公共の体裁。サイトの上の帯は無く、どの帯にも現れない |
| 幅 | 中身は最大約 1040px。机の上では中央、携帯では 1 列 |

短コードだけが印で、住所には**暗証番号は入っていません**。暗証を付けた場合は、別の手段で相手に伝えてください。

### 画面のしくみ

| 場所 | 中身 |
| --- | --- |
| 上の礼 | 「共有リンクから」の礼、種類の礼（動画 / シリーズ / 俳優 / 漫画 / 小説 / ドラマ、種類ごとに色違い）、取込不可のとき「見るだけ」の礼 |
| 題名 | 共有された項目の題名。長ければ折り返す |
| 有効期限 | 永久なら「永久に有効」、それ以外は「有効期限 YYYY-MM-DD HH:mm」 |
| 中身 | 種類ごとに描かれる項目の詳細。次の節へ |
| 足 | 決まり文句「© AMMDS 提供技术支持」 |

「見るだけ」の礼は作った人が「他人の取込を許す」を切ったときだけ出ます。礼が無ければ相手は直接取込めます。

### 暗証番号

暗証を付けた共有は、中身の前にまず暗証の板を出します。

1. 板の題は「この共有には暗証番号が必要」、下に共有された項目の題名が付き、どの共有か確かめられます。
2. 「暗証番号を入力してください」の枠に入れ、Enter か「解錠」で送ります。
3. 空欄ならその場で「暗証番号を入力してください」と出て、問い合わせは行われません。
4. 間違いなら枠の下に「暗証番号が違います。もう一度お試しください」と出て、続けて試せます。
5. 通ると、返ってきた中身全部で板をそのまま置き換えます。読み込み直しは要りません。

暗証の確認はこの画面のうちだけ有効で、読み込み直すと入れ直しです。暗証は住所欄にも端末の控えにも書き残されません。

### 共有の中身の種類

一つの共有は一つの種類だけに属し、画面は種類に合った部品を読み込みます。下の区画は資料があるときだけ現れます。

| 種類 | 見えるもの |
| --- | --- |
| 動画 | 頭（ポスター、評価、札、識別番号 / 初演 / 長さ / 制作 / 等級 / 言語 / 解像度 / 容量 / 符号 / 字幕などの資料）、あらすじ、俳優、劇中写真、属するシリーズ |
| シリーズ | 頭と資料、シリーズの紹介、作品数、作品一覧。無ければ「このシリーズには作品がまだありません」 |
| 俳優 | 頭（顔、別名、性別、年齢、身長、体重、誕生日、国籍、血液型、三囲、デビュー日、所属、状態）、経歴、写真 |
| 漫画 | 頭（作者、シリーズ、分類、種類、季、頁数、年齢制限、評価、言語、出版情報、読む向きなど）、紹介、覚書、作り手、登場人物、班、場所、話の一覧（各話に頁数付き） |
| 小説 | 頭（副題、分野、状態、出版社、出版年、言語、頁数、話数、属するシリーズ、ISBN）、中身の紹介 |
| ドラマ | 頭（種類、制作、年、初放送、評価、長さ、状態、区分）、あらすじ、俳優、季と話（特別編が最初、各季は話番号 / 題 / 初放送の 3 列）、種類と制作 |

小説の共有は話の総数だけを持ち**話の一覧は見せません**。漫画の共有には話の一覧が付きます。共有ページに映像や本文のダウンロード口はありません。

### 切れたときと失敗の知らせ

状態に応じて、中途半端な中身ではなく板全体で知らせます。

| 状態 | 題 | 文面 |
| --- | --- | --- |
| 読み込み失敗か短コード不明 | 共有が見つからないか読み込めません | 中身を取れませんでした。住所が有効か確かめるか、後でお試しください。板の中に「再読み込み」あり |
| 作った人が一時停止 | 共有は停止されています | 作った人がこの共有を一時停止したため、今は開けません |
| 有効期限超過 | 共有は期限切れです | この共有リンクは有効期限を過ぎたため開けません |
| 種類に対応する部品が無い | 見せられる中身がありません | この共有の種類はまだ見せられません。後でお試しください |

読み込み中は骨組みの画面で、空の画面がちらつくことはありません。削除された共有の短コードは消え、開いても「共有が見つからないか読み込めません」に落ちます。

:::warning[有効期限は作った人の物]
共有ページで期限を延ばしたり、暗証を変えたり、停止を自分で解いたりはできません。必要なら作った人に頼み、その人の管理画面の共有一覧で直してもらってください。
:::

### 共有を自分の棚に取込む

共有ページに**取込のボタンはありません**。取込は受け手の管理画面で行われ、公開ページは「見るだけ」の礼で可否を伝えるだけです。

**取込める場合：そのまま取込む**

1. 受け手の仕組みで **システム管理 → バックアップと復元 → 共有取込** を開きます。
2. 共有リンクか短コードを入れ、暗証付きなら暗証も入れます。
3. 「共有をプレビューする」で題名、種類、項目一覧を確かめます。
4. 取込の方案を選びます：既にある物は飛ばす、上書きで更新、併せて更新。
5. 「共有を取込む」を押すと成功と失敗の数が出ます。失敗の詳細は最初の 50 件まで。

**取込めない場合：まず申請する**

1. 同じく「共有取込」で住所を入れて「共有をプレビューする」を押します。
2. その共有が「見るだけ」のため「共有を取込む」は使えず、「この共有は取込できません」と出ます。
3. 「共有を申請」で窓を開きます。対象の共有は読み取り専用で、「申請理由」は必須、最大 200 字です。
4. 「申請を送る」を押すと、共有の持ち主が **情報管理 → 共有 → 受信箱** で受け取ります。
5. 持ち主は受信箱で「通す」か「断る」を押します。この二つは「審査待ち」の申請にだけ現れます。
6. 結果は持ち主の側のサイト内通知（システムメッセージ）に記録が残り、状態は「通りました」か「断られました」になります。

取込が済むと、受け手は同じ画面の「リンク記録」でこの結果を確かめられます。申請の記録もここで、まだ処理されていないものを取り消せます。

:::note[申請と取込は別の物]
承認は申請の状態を変えて通知を出すだけで、資料が受け手の仕組みに自動で移るわけではありません。本当の取込は引き受け手が「共有取込」で行い、方案も受け手が選びます。
:::

## 商店

上の帯の「商店」から入ります。商品一覧か分類を見て、商品の詳細で規格を選び買い物かごに入れ、ログインしてから注文を確定し、その後は「私の注文」で進みを見たり、取消や返品を申し込めます。

### 入り口と画面の一覧

- 商店は管理画面で有効にした後でだけ上の帯に「商店」が現れます。無効なら帯から隠れますが、住所を直接打てば開けます。商店が未開なら、商品一覧と店の情報の画面はどちらも「商店はまだ開いていません。また後でお越しください」と出します。
- 商品一覧、分類の画面、店の情報は名前なしで見られます。買い物かご、注文の確定、注文一覧と注文詳細はログインが必要で、していなければログイン画面へ移されます。

| 画面 | 住所 | ログイン |
| --- | --- | --- |
| 商品一覧 | `/home/store` | 名前なし可 |
| 商品の分類 | `/home/store/category/{handle}` | 名前なし可 |
| 商品の詳細 | `/home/store/product/{handle}` | 名前なし可。かご入れはログイン必要 |
| 買い物かご | `/home/store/cart` | 必要 |
| 注文の確定 | `/home/store/checkout` | 必要 |
| 注文の結果 | `/home/store/order/{token}` | 必要 |
| 注文一覧 | `/home/store/orders` | 必要 |
| 注文の詳細 | `/home/store/orders/{注文ID}` | 必要 |
| 店の情報 | `/home/store/info` | 名前なし可 |

### 商品一覧

画面の幅に合わせた格子で、机の上では 1 行 4 枚、板端末 3 枚、携帯 1 枚。1 頁に 12 点です。

| 要素 | 説明 |
| --- | --- |
| 表紙 | 1:1 の四角。失敗時は「画像の読み込みに失敗しました」の置き絵。売れない品は表紙に「現在販売できません」 |
| 題名と金額 | 題名は 1 行で切り詰め、副題は空なら隠す。規格で金額が違えば幅で、同じなら単独で。金額と通貨は画面のその都度の表示に従う |
| 頁送り | 資料があれば頁送りと総数。空なら「商品はまだありません」 |

カードを押すと商品の詳細に入ります。分類の画面 `/home/store/category/{handle}` は同じ側欄とカードを使い、分類名、説明、下位分類の札を加えて出します。説明が空なら「この分類の販売中の商品すべて」という既定の文です。

#### 検索と側欄

机の上では右に商店の側欄、狭い画面では検索と分類が一覧の上に移ります。

| 区画 | 中身 |
| --- | --- |
| 案内と通貨 | 商品の先頭頁、私の注文、店の情報、かごの 4 つのボタン。下に今の決済通貨と地域名があり、押すと店の情報へ移って切り替えられる |
| 検索 | 枠で Enter か検索ボタン。言葉は住所欄の `q` の変数に入り、そのまま共有できる |
| 分類 | 札の雲。「全部」と各段の分類。押すと絞り込み、先頭の頁へ戻る |
| 系列 | 系列の資料があるとき現れる。「全部の系列」と各系列の札 |
| かご | ログアウト中は「ログインすると買い物かごの確認と注文ができます。」とログインのボタン。ログイン中は最初の 3 行の商品、数、合計と「かごを見る」 |
| 店 | 店名、説明、類型（公式直営）、通貨、問い合わせの郵便、決まった商店の紹介文 |

### 商品の詳細

| 場所 | 中身 |
| --- | --- |
| 操作の行と主絵 | 商店へ戻る、かご、私の注文、店の情報。絵が複数なら回し絵（自動では回らない）。無ければ置き絵 |
| 販売の状態 | 売れるなら「在庫あり」、売れないなら「この商品は現在販売できません」 |
| 規格の選び | 選択肢を持つ商品は選択肢ごとに分けてボタンを描く。選択肢は無く規格が複数なら規格のボタンをそのまま並べる。売れない規格は薄くする |
| 数と属性 | 数の入力は 1〜99。属性の区には品番、規格（規格名の全部）、在庫の状態（売れるなら「販売可（在庫は注文確定時に確認）」） |
| 操作のボタン | 「買い物かごに入れる」と「今すぐ購入」。売れないときは両方とも使えない |
| 詳細と絵と文 | 名前、副名、番号、分類、通貨、販売の状態、規格の表（規格、SKU、金額、販売の状態）。下の紹介が空なら「紹介文はまだありません」、その後に決まった免責の文 |

> **SKU**: 在庫の単位です。同じ商品でも規格ごとに番号が別で、注文確定時はこれに従って在庫を減らします。

ログアウト中に「買い物かごに入れる」を押すと「ログインすると買い物かごの確認と注文ができます。」と出てログイン画面へ行き（ログイン後にこの商品へ戻る）、ログイン中なら「かごに入れました」。「今すぐ購入」はかごに入れてすぐ注文の画面へ行きます。品が無いか販売を終えていると画面全体で「商品が存在しないか販売を終えました」と「商店へ戻る」を出します。

### 買い物かご

かごは今のアカウントと決済の地域に結び付いていて、アカウントや地域を変えると別のかごになります。

| 要素 | 説明 |
| --- | --- |
| 商品の行 | 表紙、題名、規格名、単価、数（1〜99、直ちに反映）、行の合計 |
| 除く | 行ごとの「除く」のボタン。成功すると「商品を除きました」。空のかごは「かごは空です」と「選び続ける」 |
| 注文の要約 | 決済通貨、小計、送料、税、割引（負の数）、合計。下に注文画面へ入る「注文へ進む」 |
| 割引コード | 「割引コードを入力」に入れて「使う」。成功すると「割引コードを適用しました」 |
| かごを捨てる | 「今のかごを捨てますか？」の再確認。消すと「現在のかごを捨てました」 |

行ごとの選び印はなく、かごの中身は全部一緒に注文します。

### 注文の確定

画面は左が帳面、右が注文の要約。かごが空なら空の知らせと「選び続ける」だけです。

| 区画 | 項目と動き |
| --- | --- |
| よく使う住所 | ログイン後のみ。保存した住所の選び（かごの地域と両立する物だけ）。選ぶと自動で埋まる。入ったときは既定の住所が選ばれている |
| 連絡先と住所 | 郵便（必須、`@` を含む）、電話、名、姓。番地、市、国 / 地域（3 点とも必須）。郵便番号と都道県は任意。国の選択肢はかごの地域内に限られる |
| 届け方 | 「届け方を取得」を押すと先に連絡先と住所を保存し、それから選べる届け方と金額を読む。使える物が無ければ案内の文が出る |
| 払い方 | 店が返す払い方の一覧から一つ選ぶ。飛び越しで済む通路には「飛び越しでの支払いが必要」の追記。使える物が無ければ「現在の地域では利用できる支払い方法がありません」 |
| 注文の要約 | 商品の行、決済通貨、小計、送料、税、割引、合計と「注文を確定する」「かごを捨てる」 |

確定時には順に確かめます。郵便が空か `@` を欠けば「有効なメールアドレスを入力してください」。番地、市、国のどれかが空なら「完全なお届け先住所を入力してください」。払い方が選ばれなければ「支払い方法を選択してください」。届けが必要な品なのに届け方が取れなければ「現在の地域では利用できる配送方法がありません」。

飛び越しの払い方はこのサイトを離れて支払いの頁へ行き、済むと `payReturn=1` を伴って戻ります。読み取る絵の類は「読み取り支払い」の窓が出て、「支払いが完了しました」を押してから注文の確認に進みます。確認が済むと注文の結果の画面へ移り、注文 ID が返れば直接注文の詳細に入ります。

注文の確定には重複を防ぐ印が付き、同じ注文で「注文を確定する」を繰り返し押しても二つにはなりません。「注文を確認しています。重複して送らないでください」と出たら何度も試さず、少し後に注文一覧で結果を確かめてください。

### 注文の結果

`/home/store/order/{token}` は注文後の受け取りの頁です。住所には無作為の token を使い、当ての付く注文 ID ではありません。画面が開いている間は一時的に `no-referrer` となり、token が参照元から漏れないようにします。

| 場所 | 中身 |
| --- | --- |
| 結果の区 | 「注文が完了しました」、注文番号、「選び続ける」「私の注文」「注文の詳細」の 3 つのボタン |
| 注文の情報と内訳 | 注文の日時、注文の状態、支払いの状態、届けの状態、連絡の郵便（隠した表示）、金額。内訳は表紙、題名、規格、数、行の金額 |

注文が無いか token が切れていれば「注文が存在しないかリンクの期限が切れました」。

### 注文一覧

1 頁に 10 件。上に「更新」と「選び続ける」があります。

| 要素 | 説明 |
| --- | --- |
| 注文の頭 | 注文番号、注文の日時、注文の状態の札、支払いの状態の札 |
| 商品の行 | 表紙、題名、規格、数、行の金額。下は注文の合計。注文が無ければ「注文はまだありません」 |
| 操作 | 払えるなら「支払う」、それ以外は「詳細を見る」。取消できるなら「注文を取消す」、返品できるなら「返品・返金」 |
| 取消 | 再確認が必要。送ると「取消の申請を送りました。販売者の対応をお待ちください」と出て、状態は「取消申請中」になります |

### 注文の詳細

| 場所 | 中物 |
| --- | --- |
| 知らせの帯と状態 | 注文に説明があれば帯で示し、取消の申請があればさらに知らせ。続いて注文の状態、支払いの状態、届けの状態の 3 つの札と注文の日時 |
| 情報の表 | 注文番号、連絡の郵便、注文の日時、金額、支払いの状態、届けの状態 |
| 届けの情報 | 届けの記録があれば、届けの状態、運ぶ者、発送 / 到着の日時と追跡番号。番号が無ければ「販売者はまだ追跡番号を記入していません」。注文の品がすべて届け不要なら仮想商品として別途に示される |
| 返品の記録 | それぞれの記録に状態、申請の日時、商品の行、理由と説明 |
| 操作の区 | 注文が取消を許せば取消の札。返品を許せば返品の帳面で、返せる数、理由、行ごとの覚書と説明を書け、送ると「返品・返金の申請を送りました」 |

操作の区画は注文の今の状態が許すときだけ描かれるため、注文によって見える区画は違います。

### 店の情報

店の情報の画面は店の公開資料と決済の決まりをまとめ、決済通貨の切り替え口でもあります。

| 区画 | 中身 |
| --- | --- |
| 店の資料 | 店名、説明、類型（公式直営）、問い合わせの郵便、注文の受け付けの状態（開いている / 開いていない） |
| 決済通貨 | 地域から一つ選ぶ一覧。各項に通貨の符号、地域名、記号。切り替えると直ちに効き、金額は新しい地域の通貨で取り直される |
| 払い方 | 今の地域で使える支払い方法の札と、届け方と決済の説明文 |
| 地域と届けの範囲 | 地域ごとに 1 行で通貨と含まれる国 / 地域。今の地域には「現在」の印。地域が無ければ「利用できる地域はまだありません」 |
| 販売後の説明 | 決まった販売後の文と「私の注文を見る」「選び続ける」 |

:::note[金額と通路は画面の通りに]
商品の金額、送料、税、割引、支払いの通路はすべて店の側から返り、その都度変わります。ここでは画面の項目と操作だけを述べ、具体的な金額や通路には触れません。
:::

## 個人ページ

サイトには「人」に関する画面が二種類あります。誰でも開ける**公開ページ**と、ログイン後に自分を整える**個人センター**です。前者は資料で公開にした項目だけを見せ、後者がその項目、顔、横断幕、頁全体の主題を決めます。

### ログインと口

#### 上の帯

ログアウト中、上の帯の右には「ログイン」のボタンだけがあり、押すとログイン画面へ行きます。ログイン後は顔の下の選びの帯に変わります。

| 項目 | 動き |
| --- | --- |
| 個人センター | `/admin/user/info` を開く |
| 管理画面 | 管理の作業台を開く |
| ねたばれを見せる / 隠す | 一覧と詳細のねたばれの内容の切り替え |
| ログアウト | ログインの状態を消してログイン画面へ戻る |

上の帯には他に言語の切り替え、明るさの切り替え、全画面のボタンと素早い検索があり、これらはログインの状態を問いません。

#### ログイン画面

| 要素 | 説明 |
| --- | --- |
| アカウント / 暗証 | 枠の文は「管理者のアカウント」「管理者の暗証」。管理画面で RSA 公開鍵が設定されている場合は送る前に暗号化されます。鍵が未設定または形式が不正な場合は、そのまま（平文で）送信されます。 |
| 隠約の取り決めと暗証忘れ | 隠約の取り決めに同意しないと入れず、未同意なら「先に隠約の取り決めを読んで同意してください」。暗証忘れは回復鍵で戻す窓を開く |
| 他の入り方 | 奥の仕組みが対応する能力を開いたときだけ「Passkey でログイン」と「統合ログイン」が現れる。統合ログインは窓で応用を選び、新しい窓で第三者の認証を済ませる |
| 二段階の確認 | 開いたアカウントは、暗証が通った後に確認番号の段階へ進み、6 桁の番号か回復コードで済ませる |

> **RSA の公開鍵での符号化**: 暗証は送る前に一度かけてから出され、途中で拾った物からは暗証をそのまま取り戻せません。

:::warning[自分で登録はできません]
ログイン画面の下の「アカウントを登録」のボタンは今は**使えない状態**で、表の側に登録の口は開いていません。アカウントは設置時の初期化（既定の管理者 `ammds`）による物で、ここで新しく作ることはできません。
:::

ログインに成功すると住所欄の `redirect` の変数に従って元の画面へ戻ります。無ければ、システム設定 → 主題と見た目 → 着地頁 の「優先して開く」に従い、表の側か管理の側へ入ります。

### 公開ページ

#### 二つの住所

`/user/{ユーザーID}` が正式なかたちで、`/u/{ユーザーID}` は短い別名です。二つとも同じ画面を描きます。

どちらもログインが要らず、公共の体裁（サイトの上の帯は無し）です。画面の下は「先頭 | © AMMDS 提供技术支持」に決まっています。「先頭」はサイトの表の先頭頁へ戻ります。個人センターの「公開ページ」のボタンが開くのは `/u/{ユーザーID}` です。ユーザー ID を変えると古い住所は直ちに効かなくなります。

#### 画面の中身

| 要素 | 説明 |
| --- | --- |
| 顔とあだ名 | 顔が未設定なら既定の使用者の絵、あだ名が未設定なら「AMMDS 用户」 |
| 印 | `@ユーザーID` のかたち |
| 札 | アカウントの状態があれば緑の札。ほかに決まった「AMMDS 認証ユーザー」の札 |
| 横断幕と背景 | 頭の横断幕が未設定なら主題の段々の背景、頁全体の底が未設定なら仕組みの背景 |
| 基本の情報 | 公開にした項目だけを描く。空の項目は現れない |
| 無いときの文 | 公開の項目がすべて空なら「このユーザーには公開情報がまだありません」 |

読み込み中は読み込み中の表示。ユーザーが存在しないか公開ページが閉じていれば「ユーザーが存在しないか開けません」と「再読み込み」を出します。

:::note[何が見えるかは本人が決める]
郵便、電話、登録の日時、最終ログインの日時、アカウントの状態はすべて選べる公開項目です。電話は公開しても隠した表示だけです。すべての印を外すと、公開ページには顔、あだ名、主題の見た目だけが残ります。
:::

#### 主題

公開ページには 12 の主題があり、それぞれ頁の組み立てと組版が独立しています。単なる色替えではありません。

| 主題 | 説明 |
| --- | --- |
| 经典卡片（古典の札） | 中央の横断幕の札 + 2 列の情報の格子。既定の主題 |
| 极简线框（簡素な枠） | 白黒のスイス組版、左の大きな顔 + 情報の表 |
| 清雅海洋（涼やかな海） | 全幅の波の頭 + 浮かぶ数の角 + 横への情報の流れ |
| 日落暖橙（夕日の暖橙） | 左が狭く右が広い分かれ。粒子と暖色の縁 |
| 暗夜霓虹（闇夜のネオン） | 暗い底にネオンの線。くっつく側欄 + 光る情報の札 |
| 纸质书卷（紙の書物） | 雑誌の体裁。最初の文字の沈み + 2 列の本文 + 下の版権欄 |
| 玻璃拟态（硝子） | 浮かぶ硝子の札体、上下のかみ合い + 柔らかい光 |
| 艺术画框（絵の縁） | 画布の非対称の組み立て、傾いた縁 + 番号の札 |
| 时尚杂志（流行の雑誌） | 大きな絵の表紙、余白のない人像 + 下に重なる題 |
| 赛博终端（電子の端末） | 端末の窓の動き、タイプの行番号 + 走る線の監視の面 |
| 樱花物语（桜の物語） | 桜色の輪の顔、散る花びら + 柔らかい札 |
| 新粗野（新しい野太さ） | 彩度の高い色面の硬い影、貼る絵の札 + 硬い端の札 |

主題はアカウントに保存され、訪問者が開くときはアカウントの設定どおりに描かれます。値が正しくなければ「经典卡片」に戻ります。背景の絵と横断幕は全部の主題に当てはまり、切り取り方は主題ごとに任されます。

### 個人センター

上の帯の顔から「個人センター」を選んで入ります。上から、頭の姿の区、頁の設定、ユーザーの情報、免許の 4 つの区画です。

#### 頭の姿の区

| 要素 | 操作 |
| --- | --- |
| 顔 | 顔を押して絵を選ぶ。上げると直ちに置き換わる |
| 横断幕 | 右上の上げるボタンで絵を選ぶ。すでにある場合は消せて、既定の背景に戻る |
| あだ名 | 今のあだ名を示す |
| 役割と免許の札 | 役割は管理者かユーザー。免許の札は免許の状態と同じ（有効 / 無効）。会員の印があれば VIP の札が別に付く |
| 暗証の変更 | 窓を開き、今の暗証と新しい暗証を入れる |

#### 頁の設定

この区画は、他の人が見る公開ページの姿を決めます。

| 場所 | 説明 |
| --- | --- |
| 頁の背景の絵 | 上げるか消す。未設定なら「背景図は未設定」の置き絵 |
| 頁の横断幕 | 上げるか消す。未設定なら「横断幕は未設定」の置き絵 |
| 公開頁の主題 | 12 の主題の札。縮んだ絵と一行の説明付き。押すと切り替わり保存される |

背景の絵と横断幕は独立した二つの項目で、頭の姿の区の横断幕には影響しません。

#### ユーザーの情報

情報の札はユーザー ID、あだ名、郵便、電話、役割、状態、登録の日時、最終ログインの日時を示し、右上に二つの口があります。

- **情報を編集**：編集の窓を開く。
- **公開ページ**：新しい札で `/u/{ユーザーID}` を開く。ユーザー ID が未設定なら使えず、札は「未設定（編集後に公開ページが作られます）」と出す。

#### 情報を編集する項目

| 項目 | 決まり | 空欄や間違いの場合 |
| --- | --- | --- |
| ユーザー ID | 必須。公開ページの住所の中の一段 | 変えると古い繋がりは切れる |
| あだ名 | 必須、最大 32 文字 | 長すぎると保存できない |
| 郵便 | 必須、郵便のかたちに合うこと | かたちが違うと保存できない |
| 電話 | 任意。公開ページは隠した表示だけ | 空欄でも支障なし |
| 公開ページに出す項目 | 複数選び：ユーザー ID、あだ名、顔、郵便、電話（隠し表示）、登録の日時、最終ログインの日時、状態 | すべて外すと公開ページには何も出ない |

出す項目には決まりが一つあります。**一度も設定したことがなければ**、電話を除く全部の項目が出ます。

### お気に入りと読み位置

| 能力 | 口 | 説明 |
| --- | --- | --- |
| お気に入りと棚 | 各媒体の詳細のお気に入りのボタン。一覧の側欄の「様式」の切り替え | 小説の詳細は「お気に入り / お気に入り済み」を示し、ログアウト中は「操作に失敗しました。ログインを確認してください」。お気に入りの様式にすると一覧はお気に入りの項目だけを返す |

## 問題が起きたとき

**共有について**

- **住所が開かず「共有が見つからないか読み込めません」**：短コードの書き損ないか、共有が削除されたかです。期限切れや停止の板かどうかも確かめてください。板には理由が書いてあります。
- **暗証がどうしても通らない**：枠の下に「暗証番号が違います。もう一度お試しください」と出ます。作った人がくれたのが暗証番号そのものか確かめてください。
- **読み込み直すとまた暗証を求められる**：確認はこの画面のうちだけ有効です。決まりどおりです。
- **期限を延ばしたい、停止を解きたい**：共有ページではできません。作った人に頼み、その人の管理画面で直してもらってください。

**商店について**

- **上の帯に「商店」がない**：管理画面で商店がまだ有効になっていません。有効でも未開なら「商店はまだ開いていません。また後でお越しください」と出ます。
- **かごに入れようとしたらログイン画面へ行った**：かご、注文、注文の確認はすべてログインが必要です。後に同じ商品へ戻ります。
- **「注文を確認しています。重複して送らないでください」と出た**：押し続けないでください。少し後に「私の注文」で結果を確かめてください。重複を防ぐ仕組みがあるので二つにはなりません。
- **金額が前と違う**：金額、送料、税は今の決済地域の通貨でその都度取られます。店の情報の画面で地域が切り替わっていないか確かめてください。

**アカウントと頁について**

- **「アカウントを登録」が押せない**：表の側に登録の口はありません。アカウントは設置時の初期化（既定の管理者 `ammds`）による物です。
- **以前の公開ページの繋がりが切れた**：ユーザー ID が変えられています。新しい住所（個人センターの「公開ページ」のボタン）を使ってください。
- **暗証を忘れた**：ログイン画面の「暗証を忘れた」で窓を開き、回復鍵で戻してください。
- **あなたの頁を「何もない」と言われる**：公開の項目がすべて外れている可能性があります（顔、あだ名、主題の見た目だけが残る）。「情報を編集」で付け直してください。
