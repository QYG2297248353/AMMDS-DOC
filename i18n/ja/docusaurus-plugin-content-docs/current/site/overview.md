# 訪問者が見る画面

自分のライブラリを他の人にも見せるときに使うのが**公開サイト**です。このページでは、それがどの画面でできているか、訪問者と利用者で何が違うか、そして資訊の閲覧と検索のしかたを説明します。

> **公開サイト**：訪問者と閲覧する人のための画面です。見たり探したりするのはここです。

> **管理画面**：管理者のための画面です。ファイルの取り込み、情報の補完、設定の変更はそちらで行います。

> **訪問者（ゲスト）**：ログインせずに眺めに来た人のことです。

## 公開サイトと管理画面の分担

両者は同じアカウントとデータを共有しますが、入口と役割が違います。

| 比較 | 公開サイト | 管理画面 |
| --- | --- | --- |
| 対象 | 訪問者とログイン済みの閲覧者 | 管理者と情報を整える人 |
| ログイン | 一覧は公開、詳細と操作は要ログイン | 全体が要ログイン |
| できること | 閲覧、検索、お気に入り、購読、共有、読書 | 取り込み、情報補完、編集、処理実行、設定変更 |
| 情報の管理 | 直接は変えない | ここだけが情報を変えられる |

## 画面の一覧

| メニュー | 中身 | 未ログインで見られるか |
| --- | --- | --- |
| 作品 | 一覧と詳細 | 一覧は可、詳細は要ログイン |
| ドラマ | 一覧と詳細 | 一覧は可、詳細は要ログイン |
| 出演者 | 一覧と詳細 | 一覧は可、詳細は要ログイン |
| 漫画 | 一覧と閲覧機能 | 一覧は可、詳細は要ログイン |
| 小説 | 一覧と閲覧機能 | 一覧は可、詳細は要ログイン |
| 資訊 | 購読で取ってきた項目 | 一覧は可、詳細は要ログイン |
| 商城 | 公式の店 | 管理画面で有効にしたときだけ出る |

:::note[サイトの入口がどこへ飛ぶか]
サイトの根の住所は直接中身を出さず、管理画面の「優先して開く先」の設定に従って跳びます。公開を選べば作品一覧、管理を選べばログイン済みは作業台、未ログインは ログイン画面へ。既定は管理です。
:::

## 画面の形

どの画面も同じ外枠です。

1. **上部の帯**：左にサイトの印と一列のメニュー、右に検索、言語切替、明暗テーマ、全画面、ログインの入口。幅が狭いと一列メニューは畳まれ、右の操作だけが残ります。
2. **内容の領域**：一覧は「左のカード並び + 右の絞り込み」の二段組み、詳細は一列です。幅が狭いと絞り込みは一覧の上へ移ります。
3. **脚部**：管理画面で設定した短い経路、届出の情報、決まった著作権の文。

## 上部の検索の使い方

上部の帯の虫眼鏡を押すと検索窓が開きます。

1. 言葉を入れると自動で探しますが、実際に問い合わせるのは入力が止まってから約 300 ミリ秒後です。
2. 対象は作品、ドラマ、出演者、漫画、小説、資訊の六種。それぞれ最大 8 件で、種類ごとにまとめて出ます。
3. 結果を押すと対応する詳細へ跳びます。
4. 見つからないときは「一致なし（完全な名前でお試しください）」と出ます。

:::tip[見つからないときは索引を確認]
上部の検索は MeiliSearch の索引（連携アプリの補助ツールで設定）に依存します。索引が作られていなければ空のままです。
:::

## ログインとアカウント

未ログインのとき、上部の帯の右は「ログイン」のボタンです。ログイン画面には次があります。

- アカウントとパスワード。パスワードはブラウザの中で暗号にしてから送ります。
- 個人情報の方針への同意。外せば送信できません。
- 二段階の確認。パスワードのあとに 6 桁の番号か復旧コードを入れます。
- 「パスワードを忘れた」は、サーバー側に置いた復旧鍵で再設定します。

:::warning[自分では登録できません]
ログイン画面の「アカウントを登録」は無効です。公開サイトに登録の入口はありません。アカウントは導入時の初期化で作られます。
:::

ログインすると、ボタンはアイコンのメニューに変わり、**個人センター**、**管理画面**、**ネタバレを開く / 閉じる**、**ログアウト** の四つが並びます。

## 訪問者と利用者の違い

| 能力 | 訪問者 | 利用者 |
| --- | --- | --- |
| 各ライブラリの一覧 | 見られる | 見られる |
| 詳細を開く | 遮られ、ログイン画面へ。入ると元の画面に戻る | 見られる |
| 作品 / 出演者の件数 | 1 ページ最大 30 件、ページはサーバーが無作為に選ぶ | 普通にページ移動 |
| お気に入り / 購読 / 共有 | 先にログイン | できる |
| 漫画と小説の続き読み | 閲覧の入口が要ログイン | アカウントごとに保存され、続きから読める |

:::note[訪問者の見える中身は変わります]
作品・出演者・資訊の訪問者向け一覧は、意図的に制限されています。求められたページは無視され、無作為に一ページが選ばれ、件数は 30 に切られます。そのため更新すると違うものが出ることがあります。まとめ取りを防ぐ設計であり、データの異常ではありません。
:::

## 外観とテーマ

- **共通の装い**：テーマ色、背景、角の丸み、動き、追悼モードは管理画面のシステム設定から配られ、訪問者は皆同じものを見ます。
- **手元の好み**：明暗テーマ、言語、全画面は訪問者が上部の帯で切り替え、自分のブラウザにだけ残ります。
- **ネタバレ設定**：ログイン後にアイコンメニューで切り替え。オンのとき、一覧と詳細の中身はサイトの設定に従って扱われます。

## 資訊：購読で取ってきた中身

上部メニューの「資訊」は、購読で取れた項目の一覧です。ここに並ぶものは管理画面で設定した購読元から来ており、公開サイトは表示だけを担います。

### 一覧のカード

カードは横長の表紙で並びます。机上は一列 4 枚、平板 3 枚、携帯 1 枚です。

| 要素 | 内容 |
| --- | --- |
| 表紙 | 無い、または読み込み失敗で「画像の読み込みに失敗」と出る |
| 分類の札 | 左上。文章は青、画像は緑、動画は橙、資源は紫、他は灰 |
| 題名 | 一列。長ければ省略。空なら `--` |
| 要約 | 最大二列。空なら `--` |
| 出典 | 左下に購読元の名前。空なら `--` |
| 公開時刻 | 右下 |
| すばやい操作 | 「配信元へ」は新しいタブで元の経路を開く。トレント / マグネット / トレントファイルがあれば「原文を見る」か「資源をダウンロード」も出る |

一覧が空なら「資訊はありません」と出ます。カードを押すと**新しいタブ**で詳細が開き、一覧の閲覧を邪魔しません。

> **RSS**：サイトが新しい中身を決まった書式で並べた一覧で、他のプログラムが定期的に読みに来ます。この資訊はそうやって取れてきます。

### 分類と検索

側の欄（幅が狭いと一覧の上へ移る）に、検索、分類、検索の履歴があります。

- **分類**は五つ固定：すべて、文章、画像、動画、資源。ボタンに重ねると「分類名 · 全 N 件」。実際に中身がある分類だけ出ます。
- 分類を押すと一ページ目から引き直します。「すべて」は分類の条件を付けません。
- **検索**は題名と要約を対象にし、ボタンを押すか改行して初めて問い合わせます。入力中は問いません。
- **検索の履歴**は最大 15 件。重なりを除いて上に寄せます。札を押すと再検索、**同じ札をもう一度押すと検索の取り消し**になります。
- 分類、言葉、ページはブラウザに残り、更新すると前の状態に戻ります。

一覧に**購読元で絞る**操作はありません。範囲を狭めたいときは「分類 + 言葉」を組み合わせてください。

### ページ移動

既定は 1 ページ 20 件で、件数は切り替えられます。件数を変えると一ページ目へ戻ります。移動の部品は総数が 0 より大きいときだけ出ます。訪問者が見る総数とページは実際の量を表しません（上の「訪問者と利用者の違い」を参照）。

### 詳細

| 区域 | 中身 |
| --- | --- |
| 上部 | 「一覧へ戻る」のボタン |
| 題名の区域 | 題名、その下に分類の札、出典の札、公開時刻の札（空は出ない） |
| 動画の区域 | 動画の添付があるとき出現。埋め込みの再生機で再生し、下に「配信元へ」 |
| 画像の一覧 | 画像の添付があるとき出現。小さな絵を押すと拡大 |
| 本文 | 富表現で描画 |
| 資源 | 画像と動画以外の添付を列挙。住所、種類、大きさを表示し、右の「資源をダウンロード」は新しいタブで開く |
| 側の情報 | 出典、公開時刻、分類、作者 |
| 側の操作 | 「原文を見る」は新しいタブで元の経路、「一覧へ戻る」 |

資訊が無い、または消されているときは「資訊が存在しないか削除済みです」と全面に出ます。区域は中身があるときだけ描かれるため、分類によって見える区域の数が違います。

:::tip[中で再生するか元へ飛ぶか]
動画の区域が再生するのは、添付に記録された住所です。管理画面で手元に控えを作っていれば手元を、そうでなければ配信元を指します。再生機が使えない、または元のページが見たいときは「配信元へ」を使ってください。
:::

外部の経路はすべて新しいタブで開き、今の画面の情報を相手に渡しません。

## 運転モードが公開サイトに与える影響

| モード | 訪問者が見るもの |
| --- | --- |
| 通常 | 一覧と検索が使える。ログインすれば詳細と操作も |
| 管理のみ | 公開の住所は「サイトは閉じています」の画面に書き換えられる |
| 口だけ | 管理を含むすべての画面が「サイトは閉じています」へ跳ぶ |

:::note[一時的な異常で全停止はしない]
運転モードの判定に失敗しても移動は遮りません。公開サイトは開いたままです。
:::

## 困ったときは

- **詳細を押しても動かずログインへ飛ばされる**：詳細は要ログインです。入ると自動で元の画面へ戻ります。
- **検索で何も出ない**：MeiliSearch が設定され、索引が作られているかを確認してください（連携アプリの補助ツール）。
- **一覧がずっと空**：管理画面でまだ取り込みが済んでいない、または絞り込みが狭すぎます。
- **訪問者は見えるものが毎回違う**：意図した設計です。ログインすれば普通のページ移動に戻ります。
- **資訊の表紙が壊れる / 動画が再生できない**：添付が配信元を指しており、その機械から届きません。「配信元へ」を使うか、管理画面で手元に控えを作ってください。
- **資訊がずっと「ありません」**：購読元が未登録、またはまだ取れていません。
