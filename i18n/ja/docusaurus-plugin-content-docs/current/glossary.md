# わからない言葉はここで

AMMDS のドキュメントや画面には、少し分かりにくい言葉がいくつか出てきます。このページでは六つの分野に分けて、それぞれをやさしい言葉で説明し、どこで出会うかもお伝えします。自分で入力する項目については、間違えたときに何が起こるかも書いています。

わからない言葉はまずこのページで `Ctrl` + `F` で検索してみてください。見つからないときは、症状から探せる[よくある質問](./faq.md)をご覧ください。

## 一、インストールと実行

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| Docker | ソフトを、必要な環境ごとまとめて動かす仕組みです。Docker を一度入れれば、パッケージを取ってくるだけで動きます。依存を一つずつ入れる必要はありません。Docker が使えない機器では別の方法を選んでください。 | インストール方法の比較、Docker でインストールする |
| イメージ | ソフトのパッケージファイルで、「インストールディスク」のようなものです。`qyg2297248353/ammds:latest` のように書き、コロンの後ろがバージョンのタグです。**間違えると**：タグを間違えると別のバージョンを取ってきたり、存在しないためにコンテナが起動しません。 | イメージの取得、バージョンアップ |
| コンテナ | イメージを実際に動かしている本体です。コンテナを消しても、外にマウントしたディレクトリのデータは残ります。 | 起動コマンド、ディレクトリの一覧 |
| マウント | 機器上の実際のディレクトリをコンテナ内の場所につないで、読み書きできるようにすることです。「ホスト側:コンテナ側」と書きます。**間違えると**：つなぎ忘れや書き間違いでファイルが見つからず、データがコンテナの中に入って消えることもあります。 | Docker コマンドの `-v`、ディレクトリの一覧 |
| バイナリープログラム | 実行ファイルとも呼ばれ、AMMDS の配布パッケージに入っている、そのまま動かせるプログラムのファイルです。Windows では `.exe` で終わり、Linux では拡張子がありません。**間違えると**：ほかの機器向けのものを入手すると実行できないと表示されます。Windows と Linux では共用できません。 | Windows / Linux で直接動かす、バージョンアップ |
| GraalVM Native Image | プログラムをあらかじめ単独で動く実行ファイルに変換しておく技術です。動かすときに Java を入れなくてよく、JAR / WAR といったファイルも無く、ダブルクリックやコマンドでそのまま起動でき、立ち上がりも速くなります。仕組みを知る必要はなく、「Java は要らない」と覚えておけば十分です。 | インストール方法の比較、トラブル対応 |
| JAR / WAR | Java のプログラムでよく使われる二つの梱包形式です。**AMMDS の配布パッケージにこの類のファイルはありません**。Java の実行環境も要りません。インターネットで見かける `java -jar` の手順は、自分でソースを組み立てるときのもので、AMMDS の導入には当てはまりません。 | 古い案内、開発者向けの資料 |
| NAS | ファイルを置くためのネットワーク機器です（FnOS や QNAP など）。アプリパッケージも Docker も動かせます。 | NAS にインストールする、ディレクトリの計画 |
| 環境変数 | 起動前にプログラムへ渡す設定のことで、ポートやアップロード容量などです。Docker では `environment` の欄に、直接動かすときは実行ファイルの起動コマンドの前に書きます。**間違えると**：名前を間違えると設定されず既定値のままになります。値を間違えると画面が開かない、アップロードが拒否されるなどの原因になります。変更後は必ず再起動が必要です。 | 設定項目の表、起動コマンド |
| ポート | 一台の機器の中でサービスを分けるための番号です。`http://ホストIP:8080` の 8080 がポートです。**間違えると**：変えた番号で開かないとつながらず、他のプログラムが使っている番号だと起動に失敗します。 | アクセス先、ポートの一覧 |
| パス | ファイルやディレクトリがディスクのどこにあるかを示す文字列です（例：`/mnt/media`、`C:\AMMDS`）。**間違えると**：読み込めずスキャンできなかったり、別の場所にデータが作られて「消えた」ように見えます。 | メディアディレクトリ、データディレクトリ |
| プロキシ | インターネットへのアクセスを、別のサーバーを経由して行う仕組みです。海外サイトが不安定なときに使います。HTTP と SOCKS が選べます。**間違えると**：住所やポートを間違えると広くつながらなくなります。除外リストを外すと NAS やプレイヤーなど身内の機器につながらなくなります。SOCKS はユーザー名とパスワードに対応していません。 | システム設定 → ネットワーク設定 |

## 二、ファイルとディレクトリ

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| スキャン | 指定したディレクトリを一通り見て、どの作品があるかを調べさせることです。 | スキャンタスク、10 分の手順 |
| タスク | スキャンや情報取得など、一回ぶんの作業の記録です。進み具合や結果、失敗の理由を確認できます。 | タスク画面、タスクログ |
| 定時タスク | 設定した時刻に自動で動くタスクです（毎日のスキャンなど）。**間違えると**：時刻を間違えてもエラーにはならず、動くタイミングがずれるだけです。定時タスクの元スイッチを切ると、手動での実行も拒否されます。 | 定時タスク、スケジュールのスイッチ |
| NFO | 作品のそばに置く小さなテキストファイルで、その作品の情報を記録します。プレイヤーがそのまま読めます。 | スキャンの整理モード、不足分の補完 |
| 表紙 | 一覧に出る小さな画像です。作品を見分けるのに使います。 | 作品一覧、ライブラリ |
| ポスター | 縦長の大きな画像です。ポスター一覧に並ぶものです。 | 詳細ページ、ポスター一覧 |
| 劇中の写真 | 作品から切り出した画像です。ふつう何枚かあります。 | 詳細ページの画像一覧 |

## 三、作品の情報

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| 情報取得（スクレイピング） | 情報サイトから表紙・あらすじ・出演者・タグを調べて自動で埋めることです。インターネット接続が必要です。 | 情報取得タスク、10 分の手順 |
| 作品番号 | 作品を見分けるための識別番号で、ふつうファイル名に含まれます。これが読めないと情報は埋まりません。 | スキャン結果、情報取得の結果 |
| ライブラリ | 整理が終わったあとに、眺めたり検索したりできる作品の一覧です。 | 管理画面の作品メニュー、公開サイト |
| 出演者 | その作品に関わる演者やスタッフの情報で、情報取得といっしょに取得されます。 | 詳細ページ、出演者一覧 |
| タグ | 作品につけるキーワードです。絞り込みに便利です。 | 詳細ページ、整理ページ |
| シリーズ | 同じシリーズの複数の作品をまとめたものです。 | 作品詳細、整理ページ |
| レーベル | 制作元やレーベルのことです。シリーズやタグと同じく、まとめ方のひとつです。 | 作品詳細、整理ページ |
| 情報源 | 作品の情報を提供してくれるサイトやサービス、つまり「どこを調べに行くか」です。**間違えると**：住所や認証コードが違うとつながらず、情報取得がずっと失敗します。プラグイン設定ページで接続テストをしてください。 | 連携アプリ、プラグイン設定 |
| 読んだ位置 | 漫画や小説をどこまで読んだかの記録です。別の機器から続きを読めます。 | 漫画と小説の閲覧機能 |

## 四、資源を探して取り込む

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| 購読 | 作品番号や出演者を指定して、合う資源が出てこないか見張り続けてもらうことです。 | 購読ページ、自動化タスク |
| マグネット | `magnet:` で始まる文字列です。ダウンローダーはこれを手がかりにファイルを探して取得します。 | 検索結果、ダウンロード |
| torrent | 中身を説明する小さなファイルです。ダウンローダーはこれを開いてダウンロードを始めます。 | 検索結果、ダウンローダー |
| ダウンローダー | 実際にダウンロードするプログラムです（qBittorrent や Transmission など）。**間違えると**：住所やアカウントが違うと、送っても何も起きず購読が止まったままになります。 | ダウンローダー設定、購読設定 |
| 追加の種（クロスシード） | 他サイトにある同じファイルを利用して、ダウンロードや種の維持を速く進めることです。 | 補助ツール、ダウンロード関連ページ |
| RSS | サイトが定期的に出している「更新の一覧」です。購読しておくと新着が自動で分かります。 | メッセージ、購読設定 |

## 五、アカウントと設定

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| 認証コード | 外部サービスへ接続するときに身分を示す文字列です。**間違えると**：相手に拒否され、接続テストが失敗して情報が取れません。 | プラグイン設定、連携アプリ |
| API キー | 認証コードと同じもので、サービスによってこの名前で呼ばれます。間違えたときの結果も同じです。 | プラグイン設定、オープンプラットフォーム |
| キー | 認証や暗号に使う秘密の文字列の総称です。AMMDS にはキーの管理機能もあり、外部プログラム向けに種類を選んで発行できます。種類を間違えると相手は「未認証」のままです。 | キーの管理、個人情報 |
| ライセンス | この導入が正しく認可されていることを示す記録です。有効化していなくても表示の印が出るだけで、機能は止まりません。お試しは保存データごとに一度だけです。 | 個人情報 → ライセンス |
| 透かし | 未認可のときに画面に出る印です。見た目だけで、機能には影響しません。 | すべてのページ |
| システム診断 | アバターメニューから実行できるまとめて点検する機能です。データベース、ディスク、ポート、時刻、依存プログラム、プロキシ、プラグイン設定を分野別に表示します。 | アバターメニュー、初期設定の最後 |
| バックアップ | データをファイルとして書き出すこと（画像を一緒に出すか選べます）、または `db/` と `data/` をそのまま写すことです。 | システム管理 → バックアップと復元 |
| 復元 | バックアップを読み込んで戻すことです。**間違えると**：構造が合わないと「検証に失敗」と表示されます。ひとつのパッケージに入れられる種類はひとつだけです。 | システム管理 → バックアップと復元 |
| ログ | プログラムが何をしたかの記録で、不調のときの最初の手がかりです。ファイルは `data/logs/` の下にあります。 | 実行ログ、タスクログ |

## 六、他のプログラムとつなぐ

| 言葉 | やさしい説明 | どこに出てくるか |
| --- | --- | --- |
| Webhook | 何かが起きたときに AMMDS がメッセージを送る先の住所です。スマホへの通知などに使います。**間違えると**：届かないだけで、画面にはエラーが出ません。 | 通知設定 |
| 共有リンク | 作品を他の人に見せるためのリンクです。 | 共有ページ、公開サイト |
| 取り出しコード | 共有リンクを開くときに入力する合言葉です。**間違えると**：リンクが開けません。 | 共有設定、訪問者が開くページ |

## 困ったときは

- **このページに載っていない言葉**：まずバージョンを確認してください（ワークベンチの「システム情報」で見られます）。古い版本では言い方が変わっていることがあります。
- **説明どおりに入力しても直らない**：設定を元に戻して再起動し、直ったことを確かめてから、一度にひとつだけ変えてみてください。
- **言葉の意味を勘違いしていそう**：[よくある質問](./faq.md)で、いま起きている症状から探してみてください。
- **それでも解決しない**：バージョン、起きた時刻、ログの該当部分を添えて GitHub へご連絡ください：https://github.com/QYG2297248353/AMMDS-Docker/issues/new
