# プロジェクト概要

AMMDS は、**自分の機器に置く作品データ棚**です。名前がバラバラな動画ファイルが入ったハードディスクを読み取り、どの作品かを判別して、表紙・あらすじ・出演者・タグを補い、眺めたり検索したりできるライブラリに整理します。

データはすべて自分の機器の中に保存されます。クラウドのアカウント登録は不要です。

:::warning[ご利用の前に]
本ソフトはオフライン製品で、データはご自身で登録・管理します。お住まいの地域の法令を守ってください。中国国内での本製品の宣伝は行わないでください。会話では略称 `AMMDS` をお使いください。
:::

:::note[インターネットについて]
画面そのものはオフラインで開けますが、作品情報の自動取得・資源の検索・通知の送信にはインターネットが必要です。外部サービスを有効にすると、設定に従ってそのサイトへアクセスすることに同意したものとみなされます。
:::

## どんな困りごとを解決しますか

| 困りごと | AMMDS の対応 |
| --- | --- |
| ファイル名が乱れていて、同じ作品が何通りも書かれている | 番号で判別し、同じ作品にまとめます |
| 表紙を探したり、あらすじを写したりするのが面倒 | 表紙・あらすじ・出演者・タグを自動で補います |
| テレビで整ったポスター一覧が見たい | 整理した情報を Jellyfin や Emby に渡します |
| 検索・ダウンロード・登録が別々のアプリに分かれている | 検索 → 購読 → ダウンロード依頼 → 登録を一本につなぎます |
| 漫画や小説も一緒に管理したい | 閲覧機能があり、読書の進み具合も記録します |
| 長く動かしていて不調の原因が分からない | タスク履歴・ログ・システム診断・ネットワーク診断を確認できます |

## やらないこと

できることより、境界をはっきりさせておきます。

- **動画ファイル自体は用意しません**。ファイルはご自身でディスクに置き、AMMDS は判別と整理だけを行います。
- **再生プレイヤーではありません**。テレビで見るには Jellyfin や Emby などが別に必要です。
- **ファイルを他人のサーバーにアップロードしません**。データは手元に残ります。有効にした外部サービスにだけ、設定に従ってアクセスします。
- **ドキュメントは実装済みの機能だけを書いています**。書かれているボタンが見当たらないときは、まずバージョンを確認してください。

## 向いている人

**向いている**：動画や漫画のファイルがすでにあり、長く整理したい方。最初の十数分の設定を厭わない方。

**あまり向いていない**：ファイルをクリックしてすぐ見たいだけの方、設定を一切したくない方。初回はインストール方法の選択・ログイン・ファイルの場所指定が必要です。

## 三つのステップで始める

1. **入れる**：[インストール方法を選ぶ](./getting-started/overview.md)で、お使いの機器に合う方法を選びます。
2. **初めて開く**：[初回起動：ログインと基本設定](./getting-started/first-login.md)に沿って設定します。
3. **最初の一批を整理**：[10 分で最初の作品を整理する](./getting-started/first-library.md)を一通り試します。

知らない言葉は[わからない言葉はここで](./glossary.md)に、困ったときは[よくある質問](./faq.md)にまとめています。

## ドキュメントの読み方

| やりたいこと | 読む場所 |
| --- | --- |
| まだ入れていない | クイックスタート |
| 管理画面のメニューを知りたい | 管理画面 |
| 情報サイト・ダウンローダー・プレイヤーをつなぎたい | 連携アプリ |
| 家族にもライブラリを見せたい | 公開サイト |
| 他のプログラムからデータを読みたい | オープンプラットフォーム |
| ポートやアップロード容量など起動設定を変えたい | クイックスタート → 環境変数 |
| 古いバージョンからアップグレードしたい | アップグレードガイド |
| 用語の意味を調べたい | 用語集 |
| 様子がおかしい | よくある質問 |

管理画面と連携アプリは画面のメニュー順に並んでいるため、アプリで見る名前がそのまま章名になっています。

## よく出てくる言葉

> **スクレイピング（情報取得）**：情報サイトから表紙・あらすじ・出演者を調べて自動で埋めることです。

> **作品番号**：ファイル名に含まれる識別番号です。AMMDS はこれで作品を判別します。

> **ライブラリ**：整理後に眺めたり検索したりできる作品の一覧です。

> **設定項目**：画面で入力したりオンにしたりするものです。必ず説明が付いています。

全一覧は[わからない言葉はここで](./glossary.md)にあります。入力が必要なページには、かならず設定項目の表も付けています。
