# Release AMMDS v1.0.24 — Site Authentication and Resource Search Open

AMMDS v1.0.24 is a major update! Site authentication is now officially open to users, along with core capabilities such as resource search and torrent downloads. This is a milestone in AMMDS's support for the PT site ecosystem.

{/* truncate */}

## Site Authentication Opens

The biggest feature of this release is the official launch of the **site authentication system**. The following sites have been successfully integrated so far:

- **M-Team (Mantou)**: as one of the largest PT sites in China, integrating M-Team means users can complete site authentication directly in AMMDS, without manually maintaining complex cookies or passkeys.
- **KamePT**: a well-known general-purpose PT site offering users a wider range of resources.

Site authentication uses a secure credential management scheme: users' login information is stored encrypted to ensure privacy.

## Resource Search and Torrent Downloads

Building on authentication, AMMDS v1.0.24 opens up resource search capabilities:

- **Sites supported for search**: M-Team (Mantou), FSM (Fujisan)
- **Full-text search**: search resources by title, category, release group and other dimensions
- **Torrent downloads**: once you find the resource you want, you can trigger a torrent download task directly for a seamless download workflow
- **Search result display**: clearly shows key information such as resource size, release date, seed count and download count, helping users quickly judge resource quality

## Subscription Management Page

A new **subscription management page** has been added, where users can centrally view and manage all subscription tasks:

- Unified display of the running status of film and TV subscriptions and resource subscriptions
- Support for manually triggering subscription checks
- Provides subscription history lookup

## Runtime Log Cleanup

An automatic log cleanup feature has been added to prevent log files generated by long-term running from taking up too much disk space. Users can configure a retention period in days, and the system automatically clears expired logs.

## Comic Scraping Improvements

Several improvements have been made to the comic scraping feature introduced in v1.0.23:

- Improved the scraping success rate, especially in unstable network environments
- Added a perceptual hash (Perceptual Hash/pHash) collection mechanism for scraping and matching Western comics
- Improved the metadata deduplication logic to reduce duplicate entries

## Bug Fixes

- Fixed site authentication timeouts on some sites
- Fixed abnormal pagination of search results
- Fixed out-of-sync status of torrent download tasks
