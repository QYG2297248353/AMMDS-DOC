# Release AMMDS v1.1.0 — All-New Assistant and 3D Login Experience

AMMDS v1.1.0 is officially released! This is AMMDS's first minor version upgrade, marking the project's entry into a more mature iteration stage. This update brings several heavyweight new features and platform support.

{/* truncate */}

## Online Store Support

To better support the project's continued development, AMMDS has integrated an **online store**. Users can now purchase related products and services through the [Footprint Store](https://store.lifebus.top/) to provide financial support for the project. This not only makes it easier for the community to show support, but also secures the project's ongoing development.

## AMMDS Assistant Management Page

A brand-new **AMMDS Assistant** management page is now live, a comprehensive upgrade of the previous plugin assistant:

- **Health check**: one-click detection of the running status of AMMDS service components, including database connections, the scraping engine and site authentication
- **Visual dashboard**: displays system running data in charts, such as scraping task volume, success rate and resource search counts
- **Assistant configuration**: centrally manages parameter settings for each assistant module, reducing operational complexity

## 3D Logo Login Page

The login page receives a major visual upgrade with a new **3D Logo animation effect**:

- The AMMDS logo on the login page is rendered in 3D, supporting rotation and lighting effects
- The animation is smooth and natural, enhancing users' first impression and brand recognition
- Adapts automatically to light and dark themes, performing well in both modes

## JavBus Site Support

Added support for the **JavBus** site, further expanding the search and scraping data sources for Japanese film and TV resources.

## Bug Fixes

- **Fixed assistant import failures**: resolved cases where a failed plugin assistant import made features unavailable
- Fixed stuttering of the 3D Logo on some low-performance devices
- Fixed a bug where site authentication status was displayed inaccurately

## Future Plans

In v1.1.0, we clearly disclosed the development roadmap for upcoming versions:

- **NexusPHP framework site resource search**: support for more PT sites built on the NexusPHP framework
- **Film and TV subscriptions**: smarter subscription features with keyword filtering and automatic downloads
- **Comic previews**: online preview capability for comic content
- **Novel management**: new support for managing novels as a type of multimedia content

Please stay tuned for our upcoming version updates!
