# Release AMMDS v1.0.30 — Plugin Assistant and Multi-Part Organization

AMMDS v1.0.30 brings the plugin assistant project, secret key management and multi-part organization for film and TV, along with improvements to video ID recognition.

{/* truncate */}

## Plugin Assistant

This release adds the **AMMDS Plugin Assistant** project, a standalone helper tool designed to simplify the plugin development, testing and deployment workflow:

- **Plugin scaffolding**: quickly generate plugin project templates so developers don't have to start from scratch
- **Local test environment**: provides local running and debugging of plugins to speed up development iterations
- **Packaging and publishing**: package a plugin and publish it to the AMMDS plugin marketplace with one click
- **Dependency management**: automatically detects and handles dependencies between plugins

## Secret Key Management

A centralized **secret key management feature** has been added:

- Unified management of sensitive information such as API keys and tokens for all third-party services
- Encrypted storage to keep credentials safe
- Support for creating, reading, updating and deleting keys
- Seamless integration with all feature modules — configure once, effective globally

## Multi-Part Film and TV Organization

The **multi-part film and TV organization feature** is complete, solving the pain point of managing multi-file film and TV resources:

- Automatically identifies multiple video files belonging to the same work (such as CD1, CD2 or Part1, Part2)
- Merges the parts into a single entry for display, keeping the media library tidy
- Supports custom part-naming rules to accommodate naming conventions from different sources

## Video ID Recognition Improvements

Important improvements have been made to the video ID recognition logic:

- **Fixed the issue where manually changed recognition codes could not be matched**: previously, after users manually adjusted a recognition code, the system could not correctly re-match the metadata; this has now been fixed
- **Improved handling of special tags**: optimized the logic for handling special suffix tags such as `-C` and `-AI` in IDs, ensuring these variants are correctly recognized and matched and reducing scraping failures caused by tag formats

## Bug Fixes

- Fixed disordered sorting of part files in some scenarios
- Fixed the cache not refreshing after a key was updated
- Fixed incompatible dependency versions in project templates generated by the plugin assistant
