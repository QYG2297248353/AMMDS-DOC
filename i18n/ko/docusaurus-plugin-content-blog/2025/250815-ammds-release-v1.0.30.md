# AMMDS v1.0.30 출시 — 플러그인 도우미 및 분할 정리

AMMDS v1.0.30에는 플러그인 도우미 프로젝트, 키 관리 기능, 영상 분할 정리 기능이 추가되었고, 번호(ID) 식별 로직도 최적화되었습니다.

{/* truncate */}

## 플러그인 도우미

이번 버전에는 **AMMDS 플러그인 도우미** 프로젝트가 새로 추가되었습니다. 플러그인 개발, 테스트, 배포 흐름을 간소화하기 위한 독립 보조 도구입니다:

- **플러그인 스캐폴딩**: 플러그인 프로젝트 템플릿을 빠르게 생성해 개발자가 처음부터 구조를 잡을 필요가 없습니다
- **로컬 테스트 환경**: 플러그인을 로컬에서 실행하고 디버깅할 수 있어 개발 반복이 빨라집니다
- **패키징 및 배포**: 한 번의 클릭으로 플러그인을 패키징해 AMMDS 플러그인 마켓에 게시합니다
- **의존성 관리**: 플러그인 간 의존 관계를 자동으로 감지하고 처리합니다

## 키 관리

중앙집중식 **키 관리 기능**이 추가되었습니다:

- 모든 서드파티 서비스의 API 키, 토큰 등 민감한 정보를 통합 관리합니다
- 암호화되어 저장되어 자격 증명이 안전하게 보호됩니다
- 키에 대한 생성·조회·수정·삭제를 지원합니다
- 각 기능 모듈과 매끄럽게 연동되어 한 곳에서 설정하면 전체에 적용됩니다

## 영상 분할 정리

**영상 분할 정리 기능**을 구현해 여러 파일로 나뉜 영상 리소스 관리의 불편을 해소했습니다:

- 한 작품에 속한 여러 동영상 파일(예: CD1, CD2 또는 Part1, Part2)을 자동으로 식별합니다
- 분할된 파일을 하나의 항목으로 합쳐 표시해 미디어 라이브러리를 깔끔하게 유지합니다
- 서로 다른 소스의 명명 습관에 맞도록 사용자 지정 분할 명명 규칙을 지원합니다

## 번호 식별 최적화

번호(ID) 식별 로직에 중요한 개선을 진행했습니다:

- **수동으로 식별 코드를 수정한 뒤 매칭되지 않던 문제 수정**: 이전에는 사용자가 식별 코드를 직접 조정하면 시스템이 메타데이터를 올바르게 다시 매칭하지 못했는데, 지금은 수정되었습니다
- **특수 태그 처리 최적화**: 번호에 붙는 `-C`, `-AI` 같은 특수 접미 태그 처리 로직을 개선해 이러한 변형이 올바르게 식별·매칭되도록 했고, 태그 형식 문제로 스크래핑이 실패하는 경우를 줄였습니다

## 문제 수정

- 특정 상황에서 분할 파일 정렬이 뒤섞이던 문제를 수정했습니다
- 키를 갱신한 뒤 캐시가 새로고침되지 않던 문제를 수정했습니다
- 플러그인 도우미가 생성한 프로젝트 템플릿의 의존성 버전이 호환되지 않던 문제를 수정했습니다
