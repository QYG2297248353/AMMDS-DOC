# AMMDS v1.6.36 출시 — Jav/서양 멀티미디어 검색

AMMDS v1.6.36에는 Jav 및 서양 멀티미디어 검색 기능이 추가되고 다중 배우 공동 검색을 지원해 리소스 발견의 편의성이 크게 향상되었습니다.

{/* truncate */}

## Jav/서양 멀티미디어 검색

v1.6.36의 가장 큰 업그레이드는 **멀티미디어 검색 기능**의 도입입니다:

- **통합 검색 창**: 하나의 검색창에서 일본 영상물(Jav)과 서양 영화·드라마 콘텐츠를 동시에 검색할 수 있어 검색 모드를 전환할 필요가 없습니다
- **교차 카테고리 매칭**: 시스템이 검색어의 카테고리를 자동으로 판단해 해당 데이터 소스와 스마트하게 매칭합니다
- **검색 결과 통합**: 서로 다른 데이터 소스의 결과를 모아 보여 주고 중복을 제거해 정렬함으로써 통합된 탐색 경험을 제공합니다
- **고급 필터**: 카테고리, 연도, 프로듀서 등 기준으로 검색 결과를 다시 필터링할 수 있습니다

## 다중 배우 검색

사용자들이 자주 하는 다중 배우 질의에 대응하기 위해 **다중 배우 검색** 지원이 추가되었습니다:

- 여러 배우 이름을 동시에 입력해 해당 배우들이 함께 출연한 작품을 찾을 수 있습니다
- 배우 이름은 퍼지 매칭과 별칭 식별을 지원해 일부만 입력해도 결과를 찾을 수 있습니다
- 검색 결과에 매칭된 배우가 표시되어 확인이 쉽습니다

## 일반 문제 수정

- 데이터 소스 시간 초과로 검색 결과가 불완전하게 로드되던 문제를 수정했습니다
- 여러 페이지에 걸친 검색에서 필터 조건이 유실되던 문제를 수정했습니다
- 일부 특수 문자 검색어로 검색 오류가 발생하던 문제를 수정했습니다
- 검색 응답 속도를 최적화해 평균 조회 시간을 줄였습니다
