# AMMDS v1.6.34 출시 — Metatube 서비스 내장

AMMDS v1.6.34에는 플랫폼 지원의 큰 확장이 포함되어 FnOS 앱 스토어 오프라인 설치와 Windows 10/11 설치 패키지 지원이 추가되었으며, Metatube 스크래핑 서비스가 내장되었습니다.

{/* truncate */}

## FnOS 앱 스토어 지원

이번 업데이트에서는 **FnOS 앱 스토어 오프라인 설치 지원**이 새로 추가되었습니다. FnOS 사용자는 이제 앱 스토어에서 직접 AMMDS를 설치할 수 있어 배포 과정이 크게 간소화됩니다:

- **오프라인 설치 패키지**: FnOS용 오프라인 설치 패키지를 제공해 인터넷 연결 없이 설치할 수 있습니다
- **앱 스토어 연동**: AMMDS가 FnOS 앱 스토어에 등록되어 한 번의 클릭으로 설치하고 업데이트할 수 있습니다
- **자동 업데이트**: 향후 버전은 앱 스토어 채널을 통해 자동으로 배포됩니다

## Windows 설치 패키지 지원

v1.6.34에서 **Windows 10/11 설치 패키지**를 정식 출시해 더 많은 사용자가 데스크톱 환경에서 편리하게 AMMDS를 사용할 수 있게 되었습니다:

- 그래픽 설치 마법사를 제공해 설치와 설정 과정을 안내합니다
- Windows 서비스 모드를 지원해 부팅 시 자동 실행할 수 있습니다
- 관리 패널 바로가기를 통합해 일상적인 조작이 편리합니다

## 사이트 인증 완화

커뮤니티 의견을 반영해 사이트 인증 정책을 조정했습니다. **사이트 검색 기능에만 인증이 필요합니다**. 이는 다음을 의미합니다:

- 사용자는 인증 없이 대부분의 기본 기능을 이용할 수 있습니다
- 리소스 검색과 관련된 모듈만 사이트 인증이 필요합니다
- 신규 사용자의 진입 장벽을 낮추고 사용 경험을 개선했습니다

## Metatube 서비스 내장

**Metatube 서비스가 이제 AMMDS에 내장되었습니다.** 사용자는 설정 페이지에서 직접 켤 수 있습니다:

- 내장 서비스로 Metatube를 별도로 배포해야 하는 번거로움이 사라졌습니다
- 사용자가 자유롭게 켜고 끌 수 있어 시스템 자원 사용을 유연하게 제어할 수 있습니다
- AMMDS의 스크래핑 엔진과 긴밀히 연동되어 더 매끄러운 메타데이터 획득 경험을 제공합니다

## 문제 수정

- 일부 시스템 버전에서 Windows 설치 패키지의 호환성 문제를 수정했습니다
- FnOS 오프라인 설치 패키지의 의존성 검사가 불완전하던 문제를 수정했습니다
- Metatube 내장 서비스와 프록시 설정이 충돌하던 문제를 수정했습니다
