# AMMDS v1.0.24 출시 — 사이트 인증 및 리소스 검색 개방

AMMDS v1.0.24는 대규모 업데이트입니다! 사이트 인증 기능이 사용자에게 정식 개방되고, 리소스 검색과 토렌트 다운로드 같은 핵심 능력이 함께 추가되었습니다. 이는 AMMDS가 PT 사이트 생태계 지원에서 이룬 이정표적인 진전입니다.

{/* truncate */}

## 사이트 인증 기능 개방

이번 버전의 가장 큰 기능은 **사이트 인증 시스템**의 정식 출시입니다. 현재 다음 사이트를 성공적으로 연동했습니다:

- **M-Team(만터우)**: 중국 최대 PT 사이트 중 하나로, M-Team 연동을 통해 사용자가 AMMDS에서 직접 사이트 인증을 마칠 수 있어 복잡한 쿠키나 패스키를 수동으로 관리할 필요가 없습니다.
- **KamePT**: 잘 알려진 종합 PT 사이트로, 사용자에게 더 다양한 리소스 선택지를 제공합니다.

사이트 인증은 안전한 자격 증명 관리 방식을 사용하며, 사용자의 로그인 정보는 암호화되어 저장되어 프라이버시가 안전하게 보호됩니다.

## 리소스 검색과 토렌트 다운로드

인증 기능을 기반으로 AMMDS v1.0.24는 리소스 검색 능력을 개방했습니다:

- **검색 지원 사이트**: M-Team(만터우), FSM(후지산)
- **전문 검색**: 제목, 분류, 업로드 그룹 등 다양한 기준으로 리소스를 검색할 수 있습니다
- **토렌트 다운로드**: 원하는 리소스를 검색한 뒤 바로 토렌트 다운로드 작업을 실행할 수 있어 다운로드 흐름이 매끄럽게 이어집니다
- **검색 결과 표시**: 리소스 크기, 게시 시간, 시딩 수, 다운로드 수 등 핵심 정보를 명확히 표시해 사용자가 리소스 품질을 빠르게 판단하도록 돕습니다

## 구독 관리 페이지

**구독 관리 페이지**가 새로 추가되어, 사용자가 모든 구독 작업을 한곳에서 확인하고 관리할 수 있습니다:

- 영상 구독과 리소스 구독의 실행 상태를 통합 표시
- 수동으로 구독 확인을 실행할 수 있음
- 구독 기록 조회 기능 제공

## 실행 로그 정리

로그 자동 정리 기능이 추가되어, 장시간 실행으로 인해 로그 파일이 디스크 공간을 너무 많이 차지하는 것을 방지합니다. 사용자가 보관 기간을 설정하면 시스템이 오래된 로그를 자동으로 정리합니다.

## 만화 스크래핑 최적화

v1.0.23에서 도입된 만화 스크래핑 기능에 대해 여러 가지 개선을 진행했습니다:

- 스크래핑 성공률을 높였습니다. 특히 네트워크가 불안정한 환경에서 효과가 큽니다
- 서양 만화의 스크래핑 매칭에 사용할 퍼셉추얼 해시(Perceptual Hash/pHash) 수집 메커니즘을 추가했습니다
- 메타데이터 중복 제거 로직을 개선해 중복 항목을 줄였습니다

## 문제 수정

- 일부 사이트 인증이 시간 초과되던 문제를 수정했습니다
- 검색 결과 페이지 처리가 비정상이던 문제를 수정했습니다
- 토렌트 다운로드 작업 상태가 동기화되지 않던 문제를 수정했습니다
