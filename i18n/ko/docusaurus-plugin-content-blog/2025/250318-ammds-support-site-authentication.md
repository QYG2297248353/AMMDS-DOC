# 1차 PT 사이트 인증 지원: M-Team, Rousi Pro, Kamept

AMMDS가 1차 PT 사이트 인증을 공식 지원합니다. 인증을 마치면 AMMDS에서 바로 해당 사이트의 인기 랭킹을 보고 사이트 내 리소스를 검색할 수 있어, 웹페이지를 열어 오갈 필요가 없습니다.

{/* truncate */}

## 세 사이트 소개

| 사이트 | 통용 명칭 | 설명 |
| --- | --- | --- |
| M-Team | 만터우 | AMMDS가 처음 연동한 PT 사이트 |
| Rousi Pro | 러쓰 | 신규 아키텍처 사이트로, 인기 랭킹과 다차원 검색을 지원 |
| Kamept | 거북이 사이트 | 생태계 리소스 사이트로, 랭킹과 리소스 검색을 지원 |

## 인증은 무엇을 하는 기능인가

> **인증**: 사이트가 "접속자가 바로 본인 계정임"을 확인하도록 하는 것입니다. 웹사이트에 로그인하는 것과 같은 원리이며, AMMDS가 대신 처리해 주므로 이후 랭킹 조회나 리소스 검색 때 다시 수동으로 로그인할 필요가 없습니다.

인증 정보는 여러분 자신의 서버에만 저장되며, AMMDS는 이를 허가된 사이트 데이터에 접근하는 데에만 사용합니다.

## 시작하는 방법

1. 관리자 페이지의 '개인 정보'에서 사이트 인증 진입점을 엽니다;
2. 화면 안내에 따라 해당 사이트의 인증을 완료합니다;
3. 이후 구독 검색에서 해당 사이트의 랭킹과 검색을 바로 사용할 수 있습니다.

자세한 설정 방법은 문서의 '통합 애플리케이션 → 리소스는 어디에서 찾나요' 장을 참고하세요.

## 문제가 생기면

- 인증 실패 안내가 나오면: 먼저 브라우저에서 해당 사이트 계정이 정상적으로 로그인되는지 확인하세요;
- 랭킹이나 검색 결과가 비어 있으면: 사이트 자체에 접근 제한이 있거나 점검 중일 수 있으니 다른 시간에 다시 시도하세요;
- 그 밖의 경우에는 커뮤니티에 의견을 남겨 주세요.
