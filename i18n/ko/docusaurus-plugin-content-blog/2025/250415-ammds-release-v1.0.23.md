# AMMDS v1.0.23 출시 — 만화 스크래핑 도입

AMMDS v1.0.23이 공식 출시되었습니다! 이번 업데이트에서는 많은 분이 기다리셨던 만화 스크래핑 기능을 선사하며, AMMDS가 멀티미디어 콘텐츠 관리 분야에서 한 걸음 더 확장되었음을 알립니다.

## 만화 스크래핑 — 0에서 1로의 도약

v1.0.23의 가장 큰 특징은 **만화 스크래핑 기능의 첫 선**입니다. AMMDS가 만화 콘텐츠 관리를 지원한 것은 이번이 처음이며, 사용자는 Jellyfin의 Bookshelf 플러그인을 통해 만화를 스크래핑할 수 있습니다. 구체적으로:

- **Jellyfin Bookshelf 연동**: Jellyfin의 Bookshelf 구성 요소와 연결해 AMMDS가 만화 리소스를 자동으로 식별·정리하고 메타데이터 정보를 추출합니다.
- **메타데이터 자동 입력**: 스크래핑 과정에서 만화의 제목, 작가, 출판사, ISBN, 발행일, 분류 태그 등 핵심 정보를 자동으로 가져와 수동 정리 작업을 크게 줄입니다.
- **표지 및 썸네일 지원**: 만화 표지를 자동으로 내려받고 연결해 미디어 라이브러리에서 직관적이고 보기 좋은 형태로 표시됩니다.

## 문제 수정

새 기능 외에도 이번 버전에서는 커뮤니티에서 보고된 여러 문제를 수정했습니다:

- 특정 상황에서 메타데이터 캐시 이상으로 중복 스크래핑이 발생하던 문제
- 특수 문자가 포함된 경로에서 파일 식별이 실패하던 문제
- 로그 출력을 최적화해 불필요한 경고 정보를 줄였습니다
- 스크래핑 작업 큐의 안정성을 높여 동시 요청이 많을 때 작업이 유실되는 것을 방지했습니다

## 향후 계획

만화 스크래핑의 도입은 첫걸음일 뿐입니다. 이후 버전에서 만화 스크래핑의 정확도와 범위를 계속 개선하고, 더 많은 만화 소스에 대한 지원을 단계적으로 추가할 계획입니다. 사용 경험을 커뮤니티에 공유해 더 나은 서비스를 만들어 주세요!
