# AMMDS v1.6.38 출시 — ThePornDB 랭킹 및 Stash 검색

AMMDS v1.6.38에는 ThePornDB 랭킹 연동, 미디어 라이브러리 Stash 검색 기능, 이미지 프록시 지원이 추가되어 서양 영화·드라마 생태계의 도구 사슬이 더욱 풍부해졌습니다.

{/* truncate */}

## ThePornDB 랭킹

**ThePornDB 랭킹** 연동이 새로 추가되어 서양 영화·드라마 콘텐츠의 순위 정보를 제공합니다:

- **인기 트렌드**: 현재 인기 있는 서양 영화·드라마 콘텐츠 순위를 표시합니다
- **카테고리별 랭킹**: 카테고리별로 세분화된 랭킹을 제공해 특정 유형의 콘텐츠를 발견하도록 돕습니다
- **정기 업데이트**: ThePornDB의 최신 순위 데이터를 자동으로 동기화합니다
- **랭킹 상세**: 랭킹 항목을 클릭하면 해당 작품의 상세 페이지로 이동해 전체 메타데이터를 볼 수 있습니다

## Stash 검색

**Stash** 미디어 라이브러리와 연동한 검색을 지원해 AMMDS와 Stash 사이의 데이터 통로를 열었습니다:

- **Stash 영상 검색**: Stash 미디어 라이브러리의 영상 리소스를 직접 검색합니다
- **Stash 배우 검색**: 배우 이름으로 Stash에서 관련 작품을 검색할 수 있습니다
- **교차 라이브러리 통합**: Stash 검색 결과와 AMMDS 자체 데이터 소스 결과를 합쳐 표시해 한 번에 검색하는 경험을 제공합니다

## 이미지 프록시

**이미지 프록시** 지원이 추가되었습니다:

- 일부 사이트의 이미지 도용 방지로 인한 표시 문제를 해결합니다
- 사용자 지정 이미지 프록시 주소를 설정할 수 있습니다
- 이미지 로딩에 실패하면 자동으로 대체 이미지로 낮춰 페이지 레이아웃이 어긋나는 것을 방지합니다
- 미디어 라이브러리 표지와 썸네일 로딩 안정성을 높입니다

## 문제 수정

- 특정 시간대에서 ThePornDB 랭킹 데이터가 늦게 업데이트되던 문제를 수정했습니다
- Stash 검색 결과 일부가 올바르게 표시되지 않던 문제를 수정했습니다
- 이미지 프록시 설정이 적용되지 않던 문제를 수정했습니다
- 일반적인 안정성 개선과 성능 최적화
