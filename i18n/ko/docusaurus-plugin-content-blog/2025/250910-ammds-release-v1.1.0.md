# AMMDS v1.1.0 출시 — 새롭게 선보이는 도우미와 3D 로그인 경험

AMMDS v1.1.0이 공식 출시되었습니다! AMMDS의 첫 마이너 버전 업그레이드로, 프로젝트가 더 성숙한 단계에 접어들었음을 의미합니다. 이번 업데이트에서는 여러 중요한 신기능과 플랫폼 지원이 추가되었습니다.

{/* truncate */}

## 온라인 스토어 지원

프로젝트의 지속적인 발전을 더 잘 지원하기 위해 AMMDS가 **온라인 스토어**를 연동했습니다. 이제 [발자국 스토어](https://store.lifebus.top/)에서 관련 제품과 서비스를 구매해 프로젝트를 후원할 수 있습니다. 이는 커뮤니티의 참여를 편리하게 할 뿐 아니라 프로젝트의 지속적인 발전을 보장합니다.

## AMMDS 도우미 관리 페이지

새로운 **AMMDS 도우미** 관리 페이지가 공개되었습니다. 이전 플러그인 도우미의 전면적인 업그레이드입니다:

- **상태 점검**: 한 번의 클릭으로 데이터베이스 연결, 스크래핑 엔진, 사이트 인증 등을 포함한 AMMDS 각 서비스 구성 요소의 실행 상태를 확인합니다
- **시각화 대시보드**: 스크래핑 작업량, 성공률, 리소스 검색 횟수 등 시스템 운영 데이터를 차트로 표시합니다
- **도우미 설정**: 도우미 각 모듈의 매개변수를 중앙에서 관리해 운영 복잡도를 낮춥니다

## 3D 로고 로그인 페이지

로그인 페이지에 큰 시각적 변화가 생기며 **3D 로고 애니메이션 효과**가 추가되었습니다:

- 로그인 페이지의 AMMDS 로고가 3D로 렌더링되어 회전과 조명 효과를 지원합니다
- 애니메이션이 자연스럽고 매끄러워 첫인상과 브랜드 인지도를 높입니다
- 밝은 테마와 어두운 테마에 모두 자동으로 맞춰져 어떤 모드에서도 좋은 모습을 보여 줍니다

## JavBus 사이트 지원

**JavBus** 사이트 연동 지원이 새로 추가되어 일본 영상 리소스의 검색과 스크래핑 데이터 소스가 더욱 확장되었습니다.

## 문제 수정

- **도우미 가져오기 실패 문제 수정**: 특정 상황에서 플러그인 도우미를 가져오지 못해 기능을 사용할 수 없던 문제를 해결했습니다
- 일부 저사양 기기에서 3D 로고가 끊기던 문제를 수정했습니다
- 사이트 인증 상태가 정확하게 표시되지 않던 버그를 수정했습니다

## 향후 계획

v1.1.0에서 저희는 후속 버전의 개발 로드맵을 명확히 공개했습니다:

- **NexusPHP 프레임워크 사이트 리소스 검색**: NexusPHP 프레임워크로 구축된 더 많은 PT 사이트를 지원합니다
- **영상 구독**: 키워드 필터링과 자동 다운로드를 지원하는 더 스마트한 영상 구독 기능
- **만화 미리보기**: 만화 콘텐츠를 온라인으로 미리 볼 수 있는 기능
- **소설 관리**: 소설류 멀티미디어 콘텐츠 관리 지원 추가

앞으로도 후속 버전 업데이트에 많은 관심을 부탁드립니다!
