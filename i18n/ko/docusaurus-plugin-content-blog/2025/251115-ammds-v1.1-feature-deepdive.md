## 서론

AMMDS v1.1.0은 2025년에 출시되었으며, 3월 v1.0.0 퍼블릭 베타 이후 첫 번째 대규모 기능 업데이트입니다. 이 글에서는 실제 사용 관점에서 v1.1.0의 새로운 기능을 심층적으로 살펴보고, 실제 설정 조언과 사용 경험을 공유합니다.

## 1. AMMDS 도우미 관리 페이지

### 기능 개요

v1.1.0에서 가장 주목할 만한 새 기능은 **AMMDS 도우미**(AMMDS Assistant) 관리 페이지입니다. AMMDS가 관리자에게 제공하는 시스템 수준 관리 패널로, 여러 운영 기능을 통합했습니다.

### 핵심 기능

**시스템 상태 점검**: 도우미 페이지에는 상태 점검 기능이 내장되어 있어 한 번의 클릭으로 다음 항목의 상태를 확인할 수 있습니다:

- 데이터베이스 연결 상태(SQLite)
- 각 스크래핑 플러그인의 API 연결 상태
- 인증된 사이트의 접근 가능 여부
- 디스크 공간 사용률
- 시스템 가동 시간

**실행 상태 개요**:

```
시스템 상태
├── 서비스 가동 시간: 15일 7시간 32분
├── 데이터베이스: ✅ 정상(37.2 MB)
├── TMDB 플러그인: ✅ 연결됨
├── JavBus 플러그인: ✅ 연결됨
├── M-Team 사이트: ✅ 인증됨
├── KamePT 사이트: ✅ 인증됨
├── Rousi 사이트: ⚠️ 쿠키 만료 예정
└── 디스크 사용률: 42%(128 GB 남음)
```

### 실제 사용 느낌

도우미 페이지의 설계 철학은 매우 실용적입니다. 여러 메뉴에 흩어져 있던 시스템 정보를 한곳에 모아 관리자가 한눈에 전체 상태를 파악할 수 있게 했습니다. 특히 Rousi 사이트의 쿠키 만료 알림 기능은 세심합니다. PT 사이트의 쿠키 유효 기간은 보통 30일에 불과해 제때 갱신하지 않으면 인증이 만료되는데, 이 알림 기능이 많은 번거로움을 덜어 줍니다.

**개선 제안**: 향후 버전에서 상태 점검 주기와 알림 임계값을 직접 설정할 수 있고, CPU 부하나 메모리 사용률 같은 더 다양한 시스템 지표를 모니터링할 수 있으면 좋겠습니다.

## 2. 3D 로고 로그인 페이지

### 시각적 업그레이드

v1.1.0은 로그인 페이지를 대대적으로 개선하며 **3D 로고 애니메이션 효과**를 도입했습니다. 이전 AMMDS 로그인 페이지는 표준 평면 로고를 사용해 깔끔하지만 개성이 부족했습니다. 새로운 3D 로고는 페이지가 로드될 때 회전 애니메이션을 보여 주고 역동적인 배경 조명 효과가 더해져, 전체적인 인상이 최신 SaaS 제품에 버금갑니다.

### 프론트엔드 기술

관찰에 따르면 3D 로고는 Three.js 또는 CSS 3D Transforms 기술(버전에 따라 다름)로 구현되었으며, GPU 하드웨어 가속을 활용해 주류 브라우저에서 원활하게 실행되고 눈에 띄는 성능 저하도 없습니다. 로그인 페이지의 로딩 속도도 이전 버전에 비해 크게 느려지지 않았습니다.

### 사용자 피드백

실제 사용에서 3D 로고의 시각적 효과는 확실히 인상적이며, 특히 배포 후 처음 로그인 페이지를 열었을 때 그렇습니다. 이는 "전문적이고 현대적인" 제품 이미지를 전달해 AMMDS에 대한 사용자의 브랜드 인식을 높이는 데 도움이 됩니다.

**주의할 점**: 서버 자원이 부족한 환경(예: 저사양 NAS)에서는 3D 애니메이션이 CPU 부하를 늘릴 수 있습니다. 다양한 성능의 하드웨어 환경에 맞도록 시스템 설정에 "3D 애니메이션 비활성화" 옵션을 남겨 두는 것을 권장합니다.

## 3. JavBus 사이트 지원의 스크래핑 효과

### 배경

JavBus는 영상 애호가들이 자주 사용하는 일본 영상 리소스 데이터베이스로, 풍부한 메타데이터 정보를 제공합니다. v1.1.0에서 AMMDS는 JavBus를 스크래핑 데이터 소스로 정식 통합했습니다.

### 스크래핑 효과 실측

대표적인 리소스 파일로 JavBus 스크래핑 효과를 테스트했습니다:

**테스트 파일**: `FC2-PPV-1234567.mp4`

**스크래핑 결과**:
- 영화 제목: ✅ 일본어 및 중국어 제목 정확히 식별
- 표지 포스터: ✅ 고해상도 포스터 다운로드
- 배우 정보: ✅ 전체 출연진 목록 및 프로필 사진
- 발매일: ✅ 일 단위까지 정확히 식별
- 영화 번호: ✅ 자동 식별 및 연결
- 줄거리: ✅ 일본어 줄거리 + 중국어 번역
- 시리즈 정보: ✅ 시리즈명과 시리즈 내 순번

### 다중 소스 통합 성능

AMMDS의 스마트 매칭 알고리즘은 JavBus와 다른 사용 가능한 데이터 소스에서 동시에 정보를 가져온 뒤 데이터를 통합합니다. 예를 들어 JavBus가 배우 정보를 제공하고 TMDB가 평점 데이터를 제공하면, AMMDS가 두 데이터를 자동으로 병합해 가장 완전한 메타데이터 레코드를 생성합니다.

### 설정 세부 사항

JavBus 플러그인 설정은 매우 간단합니다:
1. 플러그인 관리 페이지에서 JavBus 플러그인을 활성화합니다
2. 별도의 API 키가 필요하지 않습니다(JavBus는 공개 데이터 소스입니다)
3. 요청 간격을 설정합니다(안티 스크래핑 메커니즘 발동을 피하려면 1~2초 권장)
4. 우선순위를 설정합니다(TMDB가 서양 콘텐츠를 먼저 매칭하도록 중간으로 설정 권장)

## 4. 온라인 스토어 지원

### 기능의 의미

AMMDS가 **온라인 스토어**(store.lifebus.top)를 연동해, AMMDS 개발을 후원하려는 사용자에게 더 편리한 구매 경로를 제공합니다.

### 사용 방법

[발자국 스토어](https://store.lifebus.top/)에 방문해 관련 제품과 서비스를 구매하면 AMMDS의 지속적인 발전을 지원할 수 있습니다.

### 커뮤니티에 미치는 영향

오픈소스 정신과 사업적 지속 가능성은 서로 모순되지 않습니다. AMMDS는 개인 데이터 플랫폼으로서 지속적인 개발과 유지보수에 자원이 필요합니다. 온라인 스토어 연동은 프로젝트를 후원하려는 사용자에게 직접적인 경로를 제공하는 동시에, 프로젝트의 사업화 탐색에 첫걸음을 내딛게 합니다.

## 5. 실제 사용 경험 요약

### 배포와 업그레이드

v1.0.x에서 v1.1.0으로 업그레이드하는 과정은 매우 매끄러웠습니다:

```bash
docker compose pull
docker compose up -d
```

업그레이드 후 데이터베이스 마이그레이션이 자동으로 완료되었고, 사이트 인증, 플러그인 설정, 사용자 계정 등 기존 설정이 모두 온전히 유지되어 호환성 문제가 없었습니다.

### 성능

DS920+(J4125, RAM 8GB)에서 일주일간 측정한 데이터:

| 지표 | v1.0.x | v1.1.0 |
|:----|:------:|:------:|
| 메모리 사용량 | ~180 MB | ~210 MB |
| CPU 유휴 사용량 | < 1% | < 2% |
| 스크래핑 속도(단일 파일) | ~8초 | ~7초 |
| 페이지 로딩 시간 | ~1.2초 | ~1.5초 |

새 기능이 차지하는 시스템 자원은 합리적인 범위에 있으며 전반적인 성능은 만족스럽습니다.

### 권장 설정

실제 테스트를 바탕으로 사용 시나리오별 설정을 제안합니다:

**라이트 사용자**(가정용 영상 감상, 2~3명):
- Docker 매개변수: 특별한 조정 불필요
- 활성화 플러그인: TMDB + JavBus
- 인증 사이트: 1~2개

**고급 사용자**(다중 사이트 관리, 대량 리소스):
- Docker 매개변수: `AMMDS__MaxConcurrentScrapes=3` 추가
- 활성화 플러그인: TMDB + JavBus + FANZA DMM
- 인증 사이트: 3~5개
- Telegram 알림 활성화 권장

## 6. 전망

v1.1.0은 AMMDS의 미래 발전에 탄탄한 기반을 마련했습니다. 이번 업데이트를 통해 프로젝트 팀이 세 가지 측면에서 명확한 계획을 가지고 있음을 알 수 있습니다:

1. **운영 도구화**: 도우미 페이지로 운영 복잡도를 낮춥니다
2. **시각적 브랜드화**: 3D 로고 같은 디자인으로 제품 완성도를 높입니다
3. **생태계 다양화**: 스크래핑 데이터 소스와 사이트 지원을 지속적으로 확대합니다

후속 버전에서 더 많은 혁신적인 기능이 나오기를 기대하며, 더 많은 사용자가 AMMDS 커뮤니티에 참여해 더 나은 개인 데이터 플랫폼을 함께 만들어 가기를 바랍니다.
