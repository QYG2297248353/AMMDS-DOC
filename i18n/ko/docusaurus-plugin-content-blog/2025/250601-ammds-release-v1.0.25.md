# AMMDS v1.0.25 출시 — 내장 번역 및 스포일러 모드

AMMDS v1.0.25에는 실용적인 새 기능 두 가지인 내장 번역 엔진과 스포일러 모드가 추가되었습니다. 또한 커뮤니티에서 보고된 여러 핵심 문제를 수정해 전반적인 안정성을 높였습니다.

{/* truncate */}

## 내장 번역 엔진

v1.0.25에서 AMMDS는 로컬 번역 기능을 통합했습니다. 외부 번역 서비스에 의존하지 않고 메타데이터를 여러 언어로 처리할 수 있습니다:

- **바이두 번역 연동**: 바이두 번역 API로 중국어·영어 등 여러 언어 간 상호 번역을 구현했습니다. 영화·드라마 제목과 줄거리를 대량으로 번역해야 하는 상황에 적합합니다.
- **마이크로소프트 번역 연동**: Azure Translator 서비스도 지원해 선택지를 넓혔으며, 네트워크 환경과 개인 선호에 따라 유연하게 전환할 수 있습니다.
- **번역 캐시**: 번역된 콘텐츠는 로컬에 캐시되어 중복 요청을 피하고 API 호출 할당량을 절약합니다.

이 두 번역 엔진은 주로 Metatube 스크래핑 흐름에 적용되어, 스크래핑한 외국어 메타데이터가 자동으로 사용자가 익숙한 언어로 변환되도록 합니다.

## 스포일러 모드

**스포일러 모드**가 새로 추가되었으며 기본값은 켜져 있습니다. 이 기능으로 사용자는 영상 콘텐츠에 스포일러 표시를 추가할 수 있습니다:

- 영화·드라마 상세 페이지에서 스포일러 표시가 붙은 콘텐츠는 흐리게 처리됩니다
- 사용자가 직접 클릭해야 구체적인 내용을 볼 수 있습니다
- 새로 개봉한 영화나 인기 드라마를 정리하는 사용자에게 특히 유용하며, 줄거리의 핵심 정보를 무심코 보는 것을 효과적으로 막아 줍니다

## 문제 수정

- **Metatube 번역 문제 수정**: Metatube 스크래핑 중 번역 엔진 호출 실패로 메타데이터가 누락되던 문제를 해결했습니다
- **영상 구독 실패 문제 수정**: 일부 사용자가 보고한 영상 구독 작업이 네트워크 변동이나 사이트 응답 이상으로 중단되던 문제를 수정했습니다
- **스크래핑 로그 최적화**: 스크래핑 로그 출력 형식을 재구성하고 구조화된 필드를 추가해 스크래핑 실패 원인을 파악하기 쉽게 했습니다
- **배우 스크래핑 로직 최적화**: 배우 정보 스크래핑 흐름을 개선해 중복 요청을 줄이고 스크래핑 효율과 정확도를 높였습니다

## 기타 개선 사항

- 번역 엔진의 동시성 제어를 최적화해 요청이 너무 빨라 속도 제한에 걸리는 것을 방지했습니다
- 스포일러 모드와 기존 UI 구성 요소의 호환성을 높였습니다
- 설정 페이지의 인터랙션 경험을 개선했습니다
