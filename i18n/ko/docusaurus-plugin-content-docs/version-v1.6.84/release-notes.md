# 이 버전의 변경 사항 (v1.6.84)

v1.6.84에서 새로 생긴 것과 고쳐진 것을 쉬운 말로 정리했습니다. **이 문서는 이전 버전 보관용입니다.** 최신 버전을 쓰고 계시다면 오른쪽 위 버전 메뉴에서 '최신판'을 선택해 주세요.

## 새로 생긴 것

### 작품 정보를 찾을 수 있는 곳이 하나 늘었습니다 (TMDB)

TMDB는 영화·드라마 정보가 모여 있는 공개 사이트입니다. 연결하면 AMMDS가 작품 번호로 제목, 줄거리, 출연진, 포스터를 찾아 자동으로 라이브러리에 채워 넣습니다.

**연동 → TMDB**에서 스위치를 켜고, 사이트에서 받은 인증 코드를 붙여 넣은 뒤 **테스트**를 누르면 설정이 맞는지 바로 확인할 수 있습니다.

> **인증 코드**: '본인이 조회하고 있다'를 증명하는 긴 문자열입니다. TMDB에 가입하면 받을 수 있으며, 기술 지식은 필요하지 않습니다.

### 이미 정리한 라이브러리는 부족한 부분만 채울 수 있습니다

이전에는 정리 작업을 하면 파일 배치를 다시 했습니다. 이 버전에는 **'부족한 부분만 채우기'** 모드가 추가되었습니다.

- 폴더 이름과 파일 이름은 **전혀 바꾸지 않습니다**.
- 없는 표지, 배경 이미지, 스틸 사진, 작품 정보를 적은 작은 파일만 추가합니다.
- 이미 있는 이미지는 더 좋은 이미지가 있을 때만 교체합니다.
- 이미 있는 정보 파일은 빠진 항목만 채우고, 직접 고친 내용은 그대로 둡니다.

> **정보 파일(NFO)**: 영상 옆에 두는 작은 텍스트 파일입니다. Emby, Jellyfin 같은 플레이어가 제목·출연진·줄거리를 표시할 때 읽습니다. 직접 열어볼 필요는 없습니다.

### 다른 프로그램을 위한 창구가 늘었습니다

태그, 배우, 소식, 소설, 온라인 검색, 시스템 점검 등의 외부용 창구가 추가되었습니다. 웹 화면이나 모바일 앱만 쓰신다면 넘어가셔도 됩니다.

## 고쳐진 것

- Java 설치가 필요 없는 단일 파일 버전(Windows / Linux)에서 일부 화면이 비어 있거나 `{}`만 나오던 문제를 수정했습니다.
- 쓰지 않는 오래된 파일을 정리해 프로그램을 가볍게 했습니다.

## 어디서 받을 수 있나요

| 기기 | 방법 |
| --- | --- |
| 飞牛 FnOS | 앱 스토어 오프라인 패키지 |
| Windows 10 / 11 | Windows 오프라인 설치 프로그램(AMMDS Launcher) |
| QNAP | App Center 오프라인 패키지 |
| Docker | 평소처럼 이미지 업데이트 |

## 업그레이드 전 확인

- **데이터 형식 변경이 없습니다.** 평소처럼 프로그램만 교체하면 라이브러리, 계정, 설정이 그대로 유지됩니다.
- 업데이트 후 **시스템 → 시스템 점검**을 한 번 열어 상태를 확인해 주세요.
- 화면이 예전 모습이라면 브라우저에서 `Ctrl` + `F5`로 새로 고침하세요.
