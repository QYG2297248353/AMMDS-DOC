# 프로젝트 소개

AMMDS는 **내 기기에 두는 작품 자료 정리함**입니다. 이름이 제각각인 동영상 파일이 잔뜩 든 하드디스크를 읽어 어떤 작품인지 알아내고, 표지·줄거리·출연진·태그를 채워 넣어 훑어보고 검색할 수 있는 라이브러리로 정리해 줍니다.

모든 자료는 내 기기에 저장됩니다. 클라우드 계정 가입은 필요하지 않습니다.

:::warning[사용 전에]
이 소프트웨어는 오프라인 제품이며, 자료는 사용자가 직접 입력하고 관리합니다. 거주 지역의 법령을 지켜 주세요. 중국 내에서 본 제품을 홍보하지 마시고, 대화할 때는 약칭 `AMMDS`를 사용해 주세요.
:::

:::note[인터넷 연결에 대해]
화면 자체는 오프라인에서도 열리지만, 작품 정보 자동 보충·자료 검색·알림 보내기에는 인터넷이 필요합니다. 외부 서비스를 켜면 설정에 따라 해당 사이트에 접속하는 것에 동의한 것으로 봅니다.
:::

## 어떤 불편을 해결하나요

| 불편한 점 | AMMDS의 처리 |
| --- | --- |
| 파일명이 엉망이고 같은 작품이 여러 가지로 적혀 있음 | 번호로 알아보고 하나의 기록으로 합칩니다 |
| 표지를 찾고 줄거리를 옮겨 적는 일이 번거로움 | 표지·줄거리·출연진·태그를 자동으로 채웁니다 |
| TV에서 깔끔한 포스터 목록을 보고 싶음 | 정리한 정보를 Jellyfin, Emby 등에 전달합니다 |
| 검색·다운로드·정리가 서로 다른 앱에 흩어져 있음 | 검색 → 구독 → 다운로드 요청 → 등록을 한 흐름으로 잇습니다 |
| 만화·소설도 함께 관리하고 싶음 | 읽기 기능이 있고 읽은 위치도 기록합니다 |
| 오래 쓰다 보니 어디가 잘못됐는지 모름 | 작업 기록·로그·시스템 점검·네트워크 점검을 볼 수 있습니다 |

## 하지 않는 일

잘하는 것보다 경계를 분명히 하는 편이 도움이 됩니다.

- **영상 파일 자체를 마련해 주지 않습니다.** 파일은 직접 디스크에 두고, AMMDS는 알아보고 정리만 합니다.
- **재생기가 아닙니다.** TV에서 보려면 Jellyfin, Emby 같은 플레이어가 따로 필요합니다.
- **파일을 남의 서버에 올리지 않습니다.** 자료는 내 기기에 남고, 켠 외부 서비스에만 설정대로 접속합니다.
- **문서에는 이미 만들어진 기능만 적습니다.** 설명된 버튼이 보이지 않으면 먼저 버전을 확인해 주세요.

## 누구에게 맞나요

**잘 맞는 경우**: 이미 영상이나 만화 파일이 있고 오래 정리하고 싶은 분. 처음 십몇 분 정도 설정할 의향이 있는 분.

**잘 맞지 않는 경우**: 파일을 눌러 바로 보고 싶기만 한 분, 설정을 전혀 하고 싶지 않은 분. 처음에는 설치 방법 선택, 로그인, 파일 위치 지정이 꼭 필요합니다.

## 세 단계로 시작하기

1. **설치**: [설치 방법 고르기](./getting-started/overview.md)에서 내 기기에 맞는 방법을 고릅니다.
2. **처음 열기**: [처음 열기: 로그인과 기본 설정](./getting-started/first-login.md)대로 설정합니다.
3. **첫 묶음 정리**: [10분에 첫 작품 정리하기](./getting-started/first-library.md)를 한 번 따라 해 봅니다.

모르는 단어는 [모르는 단어 모아보기](./glossary.md)에, 문제가 생기면 [자주 묻는 질문](./faq.md)에 정리해 두었습니다.

## 문서 읽는 법

| 하고 싶은 일 | 볼 곳 |
| --- | --- |
| 아직 설치하지 않음 | 빠른 시작 |
| 관리 화면의 메뉴를 알고 싶음 | 관리자 |
| 자료 사이트·다운로더·플레이어 연결 | 연동 앱 |
| 가족에게 라이브러리를 보여주고 싶음 | 공개 사이트 |
| 다른 프로그램이 내 자료를 읽게 하고 싶음 | 오픈 플랫폼 |
| 포트, 업로드 크기 등 시작 설정 변경 | 빠른 시작 → 환경 변수 |
| 이전 버전에서 업그레이드 | 업그레이드 안내 |
| 용어 의미를 찾아보기 | 용어 설명 |
| 뭔가 이상함 | 자주 묻는 질문 |

관리자와 연동 앱은 화면의 메뉴 순서대로 되어 있어, 앱에서 보는 이름이 곧 문서의 장 이름입니다.

## 자주 나오는 단어

> **정보 긁어오기(스크레이핑)**: 자료 사이트에서 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다.

> **작품 번호**: 파일명에 들어 있는 식별 번호입니다. AMMDS는 이것으로 작품을 알아봅니다.

> **라이브러리**: 정리가 끝난 뒤 훑어보고 검색할 수 있는 작품 목록입니다.

> **설정 항목**: 화면에서 입력하거나 켜는 것들입니다. 항상 설명이 함께 붙습니다.

전체 목록은 [모르는 단어 모아보기](./glossary.md)에 있고, 입력을 요구하는 페이지에는 설정 항목 표도 반드시 들어갑니다.
