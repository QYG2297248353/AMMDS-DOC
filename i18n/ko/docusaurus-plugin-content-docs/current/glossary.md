# 모르는 단어 모아보기

AMMDS 문서와 화면에는 낯선 단어가 더러 나옵니다. 이 페이지는 여섯 분야로 나누어 각 단어를 쉬운 말로 풀이하고, 어디에서 만나게 되는지 알려 줍니다. 직접 입력하는 항목은 잘못 적었을 때 어떤 일이 생기는지도 적어 두었습니다.

모르는 단어가 나오면 먼저 이 페이지에서 `Ctrl` + `F`로 찾아 보세요. 없다면 증상으로 찾는 [자주 묻는 질문](./faq.md)을 확인해 주세요.

## 1. 설치와 실행

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| Docker | 프로그램을 필요한 환경까지 한꺼번에 담아 실행하는 방식입니다. Docker를 한 번 설치하면 묶음을 받아 바로 실행할 수 있고, 필요한 것을 하나씩 설치하지 않아도 됩니다. Docker를 쓸 수 없는 기기라면 다른 방법을 고르세요. | 설치 방법 비교, Docker로 설치하기 |
| 이미지 | 프로그램 묶음 파일로, '설치용 디스크' 같은 것입니다. `qyg2297248353/ammds:latest`처럼 적고 콜론 뒤가 버전 태그입니다. **잘못 적으면**: 태그가 틀리면 다른 버전을 받거나 아예 받지 못해 컨테이너가 뜨지 않습니다. | 이미지 받기, 버전 올리기 |
| 컨테이너 | 이미지를 실제로 실행하고 있는 덩어리입니다. 컨테이너를 지워도 밖으로 연결해 둔 디렉터리의 자료는 남습니다. | 실행 명령, 디렉터리 목록 |
| 마운트 | 기기에 있는 실제 디렉터리를 컨테이너 안의 자리에 이어 주어 읽고 쓸 수 있게 하는 것입니다. '기기 쪽:컨테이너 쪽'으로 적습니다. **잘못 적으면**: 연결을 빠뜨리거나 잘못 적으면 파일을 찾지 못하고, 자료가 컨테이너 안에 들어가 함께 사라질 수 있습니다. | Docker 명령의 `-v`, 디렉터리 목록 |
| 바이너리 프로그램 | 실행 파일이라고도 부르며, AMMDS 배포판에 들어 있는 바로 실행할 수 있는 프로그램 파일입니다. Windows에서는 `.exe`로 끝나고 Linux에는 확장자가 없습니다. **잘못 고르면**: 다른 시스템용 배포판을 받으면 실행할 수 없다고 나오며, Windows와 Linux는 서로 통하지 않습니다. | Windows / Linux에서 직접 실행하기, 버전 올리기 |
| GraalVM Native Image | 프로그램을 미리 하나의 독립 실행 파일로 컴파일해 두는 기술입니다. 덕분에 실행할 때 Java를 설치할 필요가 없고 JAR / WAR 같은 파일도 없으며, 두 번 누르거나 명령줄로 바로 실행되고 시작도 더 빠릅니다. 원리는 몰라도 되고 'Java를 설치하지 않아도 된다'는 점만 기억하면 됩니다. | 설치 방법 비교, 문제 해결 |
| JAR / WAR | Java 프로그램에서 흔히 쓰는 두 가지 묶음 형식입니다. **AMMDS 배포판에는 이런 파일이 없고** Java 실행 환경도 필요하지 않습니다. 인터넷에서 보는 `java -jar` 안내는 소스를 직접 컴파일할 때 쓰는 것으로, AMMDS 설치에는 해당하지 않습니다. | 오래된 안내 문서, 개발자 자료 |
| NAS | 파일을 담아 두는 네트워크 기기입니다(FnOS, QNAP 등). 앱 패키지도 Docker도 실행할 수 있습니다. | NAS에 설치하기, 디렉터리 계획 |
| 환경 변수 | 실행 전에 프로그램에 건네주는 설정으로, 포트나 업로드 용량 같은 것입니다. Docker에서는 설정 파일의 `environment` 항목에, 직접 실행할 때는 실행 파일의 실행 명령 앞에 적습니다. **잘못 적으면**: 이름이 틀리면 설정되지 않고 기본값으로 동작합니다. 값이 틀리면 화면이 열리지 않거나 업로드가 거절될 수 있습니다. 바꾼 뒤에는 반드시 다시 실행해야 합니다. | 설정 항목 표, 실행 명령 |
| 포트 | 한 기기 안에서 서비스를 구분하는 번호입니다. `http://기기주소:8080`의 8080이 포트입니다. **잘못 적으면**: 바꾼 번호로 열어야 하고, 다른 프로그램이 쓰고 있는 번호면 실행에 실패합니다. | 접속 주소, 포트 목록 |
| 경로 | 파일이나 디렉터리가 디스크 어디에 있는지 나타내는 값입니다(예: `/mnt/media`, `C:\AMMDS`). **잘못 적으면**: 아무것도 읽히지 않고, 자료가 엉뚱한 곳에 만들어져 '사라진 것'처럼 보입니다. | 미디어 디렉터리, 자료 디렉터리 |
| 프록시 | 인터넷 요청을 다른 서버를 거쳐 보내는 방식입니다. 해외 사이트가 불안정할 때 씁니다. HTTP와 SOCKS를 고를 수 있습니다. **잘못 적으면**: 주소나 포트가 틀리면 대부분의 사이트에 닿지 못합니다. 예외 목록을 비우면 NAS나 플레이어 같은 내부 기기에 닿지 못합니다. SOCKS는 아이디와 비밀번호를 지원하지 않습니다. | 시스템 설정 → 네트워크 설정 |

## 2. 파일과 디렉터리

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| 스캔 | 지정한 디렉터리를 훑어 어떤 작품이 있는지 알아내게 하는 것입니다. | 스캔 작업, 10분 따라하기 |
| 작업 | 스캔이나 정보 가져오기처럼 한 번 실행한 기록입니다. 진행 상황과 결과, 실패 이유를 볼 수 있습니다. | 작업 화면, 작업 기록 |
| 예약 작업 | 정해 둔 시각에 스스로 실행되는 작업입니다(매일 스캔 등). **잘못 적으면**: 시각이 틀려도 오류는 나지 않고 실행 시각만 어긋납니다. 예약 작업의 전체 스위치를 끄면 직접 실행도 거절됩니다. | 예약 작업, 스케줄 스위치 |
| NFO | 작품 옆에 두는 작은 글 파일로, 그 작품의 정보를 담습니다. 플레이어가 바로 읽어 갑니다. | 스캔 정리 모드, 빠진 부분 채우기 |
| 표지 | 목록에 나오는 작은 그림입니다. 작품을 알아보는 데 쓰입니다. | 작품 목록, 라이브러리 |
| 포스터 | 세로로 긴 큰 그림입니다. 포스터 벽에 놓이는 것입니다. | 상세 화면, 포스터 벽 |
| 장면 사진 | 작품에서 잘라 낸 그림으로, 보통 여러 장입니다. | 상세 화면의 사진 모음 |

## 3. 작품 정보

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| 정보 가져오기(스크레이핑) | 정보 사이트에서 표지·줄거리·출연진·태그를 찾아 자동으로 채워 넣는 것입니다. 인터넷 연결이 필요합니다. | 정보 가져오기 작업, 10분 따라하기 |
| 작품 번호 | 작품을 구분하는 식별 번호로, 보통 파일 이름에 들어 있습니다. 이것을 읽지 못하면 정보가 채워지지 않습니다. | 스캔 결과, 정보 가져오기 결과 |
| 라이브러리 | 정리가 끝난 뒤 훑어보고 검색할 수 있는 작품 목록입니다. | 관리 화면의 미디어 메뉴, 공개 사이트 |
| 출연진 | 그 작품에 관련된 배우와 제작진 정보로, 정보를 가져올 때 함께 딸려 옵니다. | 상세 화면, 출연진 목록 |
| 태그 | 작품에 붙이는 키워드입니다. 걸러 보기에 편합니다. | 상세 화면, 정리 화면 |
| 시리즈 | 같은 시리즈의 여러 작품을 묶은 것입니다. | 작품 상세, 정리 화면 |
| 제작사 | 제작한 곳이나 레이블입니다. 시리즈나 태그처럼 묶는 방식의 하나입니다. | 작품 상세, 정리 화면 |
| 정보 출처 | 작품 정보를 제공하는 사이트나 서비스, 즉 '어디를 찾아보는가'입니다. **잘못 적으면**: 주소나 인증 코드가 틀리면 연결되지 않고 정보 가져오기가 계속 실패합니다. 플러그인 설정에서 연결 확인을 해 주세요. | 연동 앱, 플러그인 설정 |
| 읽은 위치 | 만화나 소설을 어디까지 읽었는지 기록한 값입니다. 다른 기기에서 이어서 볼 수 있습니다. | 만화와 소설 보기 |

## 4. 자료 찾기와 내려받기

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| 구독 | 작품 번호나 출연진을 정해 두고, 맞는 자료가 나오는지 계속 지켜보게 하는 것입니다. | 구독 화면, 자동화 작업 |
| 마그넷 | `magnet:`로 시작하는 문자열입니다. 다운로더가 이것을 단서로 파일을 찾아 받습니다. | 검색 결과, 내려받기 |
| 토렌트 | 내용을 설명하는 작은 파일입니다. 다운로더가 이것을 열어 내려받기를 시작합니다. | 검색 결과, 다운로더 |
| 다운로더 | 실제로 내려받는 프로그램입니다(qBittorrent, Transmission 등). **잘못 적으면**: 주소나 계정이 틀리면 보내도 아무 일이 없고 구독이 멈춘 채로 남습니다. | 다운로더 설정, 구독 설정 |
| 추가 시드 | 다른 사이트에 이미 있는 같은 파일을 활용해 내려받기나 시드 유지를 빠르게 하는 것입니다. | 보조 도구, 내려받기 관련 화면 |
| RSS | 사이트가 정기적으로 내놓는 '새 소식 목록'입니다. 구독해 두면 새 자료가 저절로 보입니다. | 알림, 구독 설정 |

## 5. 계정과 설정

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| 인증 코드 | 외부 서비스에 접속할 때 신분을 증명하는 문자열입니다. **잘못 적으면**: 상대가 거절하고 연결 확인이 실패하며 정보를 가져오지 못합니다. | 플러그인 설정, 연동 앱 |
| API 키 | 인증 코드와 같은 것이며, 서비스에 따라 이 이름으로 불립니다. 잘못 적었을 때 결과도 같습니다. | 플러그인 설정, 오픈 플랫폼 |
| 키 | 인증이나 암호화에 쓰는 비밀 문자열을 통틀어 이르는 말입니다. AMMDS에는 키 관리도 있어 외부 프로그램에 쓸 키를 종류별로 만들 수 있습니다. 종류를 잘못 고르면 상대는 계속 '인증되지 않음'이라고 합니다. | 키 관리, 내 정보 |
| 라이선스 | 이 설치가 정당하게 인가되었다는 기록입니다. 적용하지 않아도 표시만 생기며 기능이 잠기지 않습니다. 체험은 저장 자료마다 한 번만 쓸 수 있습니다. | 내 정보 → 라이선스 |
| 워터마크 | 인가되지 않았을 때 화면에 나타나는 표시입니다. 보기만 그러하며 기능에는 영향이 없습니다. | 모든 화면 |
| 시스템 점검 | 아바타 메뉴에서 한 번에 상태를 살피는 기능입니다. 데이터베이스, 디스크, 포트, 기기 시각, 부속 프로그램, 프록시, 플러그인 설정을 분야별로 보여 줍니다. | 아바타 메뉴, 초기 설정 마무리 |
| 백업 | 자료를 파일로 내보내는 것(그림을 함께 내보낼지 고를 수 있습니다)이거나 `db/`와 `data/`를 그대로 복사하는 것입니다. | 시스템 관리 → 백업과 복원 |
| 복원 | 백업을 도로 불러오는 것입니다. **잘못하면**: 구조가 맞지 않으면 '검증을 통과하지 못함'이 뜹니다. 하나의 묶음에는 한 종류만 담을 수 있습니다. | 시스템 관리 → 백업과 복원 |
| 로그 | 프로그램이 무엇을 했는지 적은 기록으로, 문제가 생겼을 때 첫 단서입니다. 파일은 `data/logs/` 아래에 있습니다. | 실행 기록, 작업 기록 |

## 6. 다른 프로그램과 이어 쓰기

| 단어 | 쉬운 풀이 | 어디에서 보이나요 |
| --- | --- | --- |
| 웹훅 | 무슨 일이 생겼을 때 AMMDS가 메시지를 보내는 주소입니다. 휴대폰 알림 같은 데 씁니다. **잘못 적으면**: 그냥 전달되지 않으며 화면에 오류도 뜨지 않습니다. | 알림 설정 |
| 공유 링크 | 작품 하나를 다른 사람에게 보여 주는 링크입니다. | 공유 화면, 공개 사이트 |
| 열람 코드 | 공유 링크를 열 때 넣는 암호입니다. **잘못 적으면**: 링크가 열리지 않습니다. | 공유 설정, 방문자가 여는 화면 |

## 문제가 생기면

- **이 페이지에 없는 단어**: 먼저 버전을 확인해 주세요(워크벤치의 '시스템 정보'에서 볼 수 있습니다). 오래된 판에서는 부르는 이름이 다를 수 있습니다.
- **설명대로 넣었는데도 고쳐지지 않음**: 설정을 원래대로 돌리고 다시 실행해 문제가 사라졌는지 확인한 뒤, 한 번에 하나씩만 바꿔 보세요.

- **그래도 해결되지 않음**: 버전, 일어난 시각, 해당하는 로그를 함께 적어 GitHub로 알려 주세요: https://github.com/QYG2297248353/AMMDS-Docker/issues/new
