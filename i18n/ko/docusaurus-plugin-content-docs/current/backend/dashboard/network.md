# 인터넷이 안 되나요? 먼저 여기를

날씨가 안 뜨고, 작품 정보가 채워지지 않고, 알림이 오지 않는다면 대부분 외부 사이트에 접속하지 못하는 탓입니다. 홈 화면의 「网络信息（네트워크 정보）」에는 프로그램이 쓰는 사이트를 하나씩 검사하는 도구가 있습니다. 여는 법, 결과 읽는 법, 결과별 조치를 알려 줍니다.

## 먼저 알아 두기

> **정보 긁어오기(스크레이핑)**: 자료 사이트에서 작품의 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다.

> **프록시**: 대상 사이트에 바로 접속하지 않고 다른 기기가 대신 요청을 전달하게 하는 것입니다.

> **캐시**: 막 조회한 결과를 잠시 저장해 두고, 얼마 동안은 다시 접속하지 않고 재사용하는 것입니다. 여기서는 5분입니다.

> **동시 처리**: 여러 일을 한꺼번에 진행하는 것입니다. 이 점검은 하나씩 순서대로 돌기 때문에 대역폭을 다투지 않습니다.

> **DNS**: 웹 주소를 기계가 읽을 수 있는 주소로 바꿔 주는 서비스입니다. 이것이 막히면 사이트가 열리지 않습니다.

> **HTTP 응답**: 상대 사이트가 돌려주는 한 마디입니다. 「권한 없음」「찾을 수 없음」이어도 회선이 통한다는 증거입니다.

## 순서대로 해 보기

### 1. 점검 창 열기

仪表盘 → 工作台（대시보드 → 홈 화면）에서 「网络信息（네트워크 정보）」카드 아무 곳이나 누릅니다. 팝업 맨 위에는 스위치 하나만 있고, 세 선택지가 같은 영역을 씁니다.

| 선택지 | 보이는 것 |
| --- | --- |
| 当前网页（이 브라우저） | 지금 쓰는 브라우저 기준 공인 주소, 위치, 프록시 상태 |
| 后台服务（백엔드） | AMMDS를 돌리는 서버 기준 같은 정보 |
| 连通性（연결성） | 프로그램이 쓰는 공개 사이트 목록을 하나씩 검사한 결과 |

「连通性（연결성）」을 고르면 오른쪽 위 버튼이 「重新测试（다시 검사）」로 바뀌고, 앞의 두 개에서는 「刷新（새로 고침）」입니다.

### 2. 네트워크 상세 보기

「当前网页（이 브라우저）」와 「后台服务（백엔드）」를 오가면 어느 기기가 외부로 나갈 때 쓰는 주소를 볼지가 바뀝니다.

| 출처 | 데이터를 가져오는 법 | 뜻 |
| --- | --- | --- |
| 이 브라우저 | 브라우저가 `ip.sb`에 직접 조회합니다 | 지금 쓰는 기기가 인터넷에 나갈 때 쓰는 주소 |
| 백엔드 | 백엔드가 조회를 대신 전달합니다 | 서버가 인터넷에 나갈 때 쓰는 주소 |

둘이 다르면 보통 서버가 프록시를 거치거나, 브라우저와 서버가 아예 다른 네트워크에 있는 경우입니다.

표시 항목:

| 항목 | 내용 |
| --- | --- |
| IPv4 / IPv6 | 두 가지 주소 형식을 따로 확인하며, 안 되는 쪽은 「暂不支持（아직 지원 안 함）」로 표시합니다 |
| 네트워크 우선순위 | 둘 다 될 때 현재 연결이 실제로 쓰는 쪽을 표시합니다 |
| 위치 | 국가 / 지역, 도시, 통신사, 통신사 번호, 시간대, 위도·경도 |
| 프록시 상태 | 시스템에 설정된 프록시 온오프, 프로토콜, 주소, 로그인 사용자 이름. 비밀번호는 보이지 않습니다 |

:::tip[결과는 5분간 저장됩니다]
같은 출처의 상세는 5분간 캐시되고, 출처를 바꾸거나 「刷新（새로 고침）」을 누를 때만 다시 가져옵니다. 「网络信息（네트워크 정보）」카드 자체도 5분간 캐시되므로 홈 화면을 열 때마다 다시 조사하지 않습니다.
:::

### 3. 연결성 검사 실행

「连通性（연결성）」으로 바꾸면 먼저 검사할 사이트를 모두 나열하고(상태는 전부 「待测试（검사 대기）」), 그다음 **표 위쪽 줄부터 한 줄씩 차례로** 검사해 끝난 줄부터 바로 결과를 보여 줍니다. 모두 끝나면 위에 총수, 접근 가능 수, 접근 불가 수, 총 소요 시간이 나옵니다.

판정은 두 가지뿐입니다.

- **可访问（접근 가능）**: 백엔드가 상대로부터 어떤 HTTP 응답이든 받은 경우입니다. 「권한 없음」「찾을 수 없음」같은 답도 포함합니다. 회선이 통하며, 신원 확인이 필요하거나 경로가 없어도 판정은 달라지지 않습니다.
- **不可访问（접근 불가）**: 도메인 조회 실패, 연결 시간 초과, 연결 재설정, 암호화 연결이 성립하지 않은 경우 등입니다.

:::warning[접근 가능이라고 기능이 되는 건 아닙니다]
예를 들어 TMDB는 접근 가능인데 스크레이핑이 계속 실패하면, 보통 API Key가 틀렸거나 그날 무료 횟수를 다 쓴 탓이지 네트워크 문제가 아닙니다.
:::

표의 세 열:

| 항목 | 내용 |
| --- | --- |
| 测试对象（대상） | 사이트 아이콘과 도메인, 아래 줄에 이름과 그룹 |
| 连通性（연결성） | 검사 대기 / 검사 중 / 접근 가능 / 접근 불가. 마우스를 올리면 상태 코드나 실패 이유가 보입니다 |
| 耗时（소요 시간） | 요청을 보낸 뒤 상대의 첫 답을 받기까지의 시간 |

주의할 점:

- 도중에 팝업을 닫으면 남은 검사가 즉시 중단됩니다.
- 목록은 한 번 불러오면 재사용되어, 세 선택지를 오가도 다시 가져오지 않습니다.
- 오른쪽 위 「重新测试（다시 검사）」는 모든 줄을 지우고 처음부터 순서대로 다시 검사합니다.

### 4. 어떤 사이트를 검사하나

목록은 그룹별로 관리되며 백엔드가 실제로 접속하는 공개 사이트를 망라합니다.

| 그룹 | 포함 |
| --- | --- |
| 메타데이터 출처 | DMM, FANZA, DMM 이미지, R18.dev, TMDB, TMDB 이미지, TheTVDB, Bangumi, ThePornDB, TheJavDB, MGS, JavBus, JAV321, AV-Legue, Madou, MetaTube |
| 사이트 색인 | M-Team, M-Team API, Rousi, FSM, IYUU, KamePT |
| 알림 서비스 | Telegram, Bark, 가오더 지도 |
| AI·번역 | DeepSeek, Gemini, Baidu 번역, DeepL, Xinyi, Caiyun, Google 번역, Microsoft 번역, Tencent 번역 |
| 기반 시설 | GitHub, GitHub 가속, HuggingFace, HF 미러, 공식 리소스, 공식 S3, 라이선스 서비스, 공식 상점, 통계 서비스 |
| DNS·기본 | Cloudflare DoH, Google DoH, DNSPod DoH, IP 조회(ip-api / ipw.cn), 시각 확인(Suning / Taobao) |

:::note[목록은 저절로 늘어납니다]
목록은 백엔드가 일괄 관리해서 사이트를 하나 추가하면 화면을 고치지 않아도 여기에 나타납니다. 직접 올린 서비스(Jellyfin, qBittorrent, 로컬 MetaTube 등)는 이 목록에 없고, 각각의 플러그인 설정 페이지에서 연결을 확인합니다.
:::

## 설정 항목 설명

| 설정 항목 | 입력할 것 | 비우거나 틀리면 |
| --- | --- | --- |
| 네트워크 프록시 | 系统配置 → 网络代理（시스템 설정 → 네트워크 프록시）에서 프록시를 켜고 프로토콜·주소·로그인 사용자 이름을 채웁니다. 비밀번호는 보이지 않습니다 | 꺼두면 해외 사이트만 접근 불가가 됩니다. 주소가 틀리면 「后台服务（백엔드）」도 데이터를 못 가져옵니다 |
| 세 선택지 스위치 | 팝업 위에서 「当前网页（이 브라우저）」「后台服务（백엔드）」「连通性（연결성）」을 고릅니다 | 잘못 골라도 다른 기기 정보가 보일 뿐입니다. 「连通性（연결성）」을 고르지 않으면 사이트 검사가 안 돌아갑니다 |
| 刷新（새로 고침） | 앞의 두 개를 보고 있을 때 누릅니다 | 누르지 않으면 최대 5분 전 캐시 결과가 그대로입니다 |
| 重新测试（다시 검사） | 「连通性（연결성）」을 고른 뒤 오른쪽 위에서 누릅니다 | 누르지 않으면 이전 결과가 그대로입니다. 누르면 모든 줄을 지우고 다시 검사합니다 |

## 문제가 생기면

| 증상 | 예상 원인 | 조치 |
| --- | --- | --- |
| 대부분 접근 불가이고 소요 시간이 모두 약 4초 | 서버가 아예 외부로 나가지 못함 | 호스트의 DNS, 방화벽, 상위 네트워크를 확인합니다 |
| 해외 사이트만 접근 불가 | 국경을 넘는 회선이 제한됨 | 系统配置 → 网络代理（시스템 설정 → 네트워크 프록시）에서 프록시를 켜고 다시 검사합니다 |
| 사이트는 모두 접근 가능한데 스크레이핑 실패 | API Key, 무료 횟수, 사이트 제한 | 플러그인 설정과 사이트 계정 상태를 확인합니다. 네트워크 문제가 아닙니다 |
| DNS 그룹 전체 실패 | 암호화된 도메인 조회 경로가 막힘 | 네트워크 정책 제한이며 보통 다른 기능에는 영향이 없습니다 |

- 더 자세한 점검(데이터베이스, 디스크, 의존 프로그램, 플러그인 설정)은 「系统管理 → 系统检查（시스템 관리 → 시스템 점검）」으로. 이 페이지는 연결 가능 여부만 다룹니다.
- 날씨 카드가 안 뜰 때는 먼저 홈 화면에서 「天气信息加载失败（날씨 정보를 불러오지 못했습니다）」가 떠 있는지 보고, 위 순서대로 검사해 보세요. [홈 화면: 처음 열면 보이는 것들](./overview.md)도 참고하세요.
- 결과가 계속 이상하면 팝업을 여닫지 말고 오른쪽 위 「重新测试（다시 검사）」를 한 번 눌러 다시 돌립니다.
