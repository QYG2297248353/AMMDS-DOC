# 라이프 아카이브

라이프 아카이브는 나 자신을 위한 기록장으로, 관리자 왼쪽 메뉴에 있으며 네 개의 페이지로 나뉩니다: **기념일**, **신체 기록**, **운동 기록**, **친밀한 생활**. 각 페이지는 서로 독립적이어서 영향을 주지 않으며, 기록하고 싶은 종류에 맞춰 들어가면 됩니다.

이 영역은 관리자에 로그인한 사람에게만 공개되며, 프런트 사이트에는 진입점이 없습니다. 기록은 당신의 AMMDS 안에만 저장되고 외부 서비스로 동기화되지 않습니다.

## 진입점과 공통 사항

관리자에 로그인한 뒤 왼쪽 메뉴에서 '라이프 아카이브'를 찾아 펼치면 네 개의 하위 페이지가 나옵니다.

네 페이지의 사용법은 기본적으로 같습니다:

- 오른쪽 위 또는 페이지 위쪽에 '추가' 버튼이 있어, 작성 후 저장하면 됩니다.
- 각 기록 행은 편집과 삭제가 가능하며, 삭제 전에는 한 번 더 확인합니다. **삭제한 뒤에는 복구할 수 없습니다.**
- 목록은 기본적으로 페이지당 10건이며, 페이지당 건수를 조정하거나 페이지를 넘길 수 있습니다.
- 위쪽의 통계와 차트는 저장·편집·삭제 후에 자동으로 갱신됩니다.

## 1. 기념일

기념일은 생일, 결혼 기념일, 명절, 중요한 업무 일정 등을 기록하는 데 씁니다. 페이지 위쪽에 네 장의 통계 카드가 있습니다.

| 통계 카드 | 계산 기준 |
| --- | --- |
| 기념일 | 전체 기념일의 수 |
| 다가오는 기념일 | 다음 발생일이 앞으로 7일 이내(오늘 포함)인 항목의 수 |
| 이번 달 기념일 | 월이 이번 달과 같은 항목의 수 |
| 오늘의 기념일 | 월과 일이 오늘과 같은 항목의 수 |

이 네 카드는 모두 **전체 기록**을 기준으로 집계하며, 아래의 검색이나 필터에 따라 달라지지 않습니다.

### 기념일 추가하기

'기념일 추가'를 누르고 아래 표에 따라 작성하세요.

| 설정 항목 | 작성 방법 | 설명 / 제한 |
| --- | --- | --- |
| 이벤트 이름 | 필수 | 2~30자. 예: '결혼 기념일' |
| 날짜 종류 | 양력 또는 음력, 기본값은 '양력' | '음력'을 선택해도 기록에 표시만 할 뿐, 날짜를 음력으로 변환하지는 않습니다 |
| 날짜 | 필수 | 이 일이 발생한 날짜를 선택합니다. 새로 추가할 때 미래 날짜도 선택할 수 있습니다 |
| 이벤트 종류 | 필수, 기본값은 '기념일' | 생일, 기념일, 명절, 업무, 개인, 기타. 목록에서 색이 다른 태그로 구분합니다 |
| 반복 종류 | 필수, 기본값은 '매년' | 매년, 매월, 1회성 |
| 알림 시각 | 기본값은 '1일 전' | 당일, 1일 전, 3일 전, 7일 전, 알림 없음. 저장하면 목록에 '알림' 표시가 붙습니다 |
| 비고 | 선택 | 최대 200자 |

:::note[반복 종류와 디데이에 대하여]
반복 종류는 현재 기록 정보로만 저장됩니다. 목록의 디데이와 위쪽 통계는 '매년 같은 달 같은 날'을 기준으로 계산하며, '매월'이나 '1회성'을 선택해도 달라지지 않습니다.
:::

### 목록과 필터

- 검색창으로 기념일 이름과 비고를 검색할 수 있습니다.
- '필터'를 누르면 이벤트 종류와 날짜 범위로 필터링할 수 있고, 선택 후 '필터 적용'을 누릅니다.
- 필터 항목에는 생일, 기념일, 명절, 업무, 기타가 있고, **'개인'은 없습니다**. 추가할 때 '개인'을 선택할 수는 있지만, 아직 이 항목으로 필터링할 수는 없습니다.
- 디데이는 '오늘', '내일', '모레' 또는 'N일 후'로 표시되며, 날짜의 월과 일을 기준으로 계산하고 연도와는 무관합니다.
- 여러 기록을 체크하면 일괄 삭제할 수 있습니다.

## 2. 신체 기록

신체 기록은 키, 몸무게, 둘레의 변화를 추적하는 데 씁니다. 페이지 위쪽에 네 장의 통계 카드가 있습니다.

| 통계 카드 | 계산 기준 |
| --- | --- |
| 전체 기록 수 | 전체 신체 기록의 수 |
| 평균 키 | 전체 기록의 평균값 |
| 평균 몸무게 | 전체 기록의 평균값 |
| 평균 BMI | 전체 기록의 평균값 |

통계 카드는 전체 기록을 기준으로 계산합니다. 아래의 '몸무게 및 BMI 추이' 차트는 현재 필터 조건을 따라가므로, 필터링한 뒤에 그려집니다.

### 신체 기록 추가하기

'기록 추가'를 누르고 아래 표에 따라 작성하세요.

| 설정 항목 | 작성 방법 | 설명 / 제한 |
| --- | --- | --- |
| 기록 시각 | 필수 | 오늘 또는 그 이전 날짜만 선택할 수 있고, 미래는 선택할 수 없습니다 |
| 키 | 필수 | 100~250cm, 소수점 첫째 자리까지 |
| 몸무게 | 필수 | 30~200kg, 소수점 첫째 자리까지 |
| BMI | 자동 계산, 입력 불필요 | 키와 몸무게로 계산되며 소수점 첫째 자리까지 표시합니다. 키나 몸무게를 바꾸면 함께 변경됩니다 |
| 가슴둘레 / 허리둘레 / 엉덩이둘레 | 선택 | 각각 40~200cm, 소수점 첫째 자리까지 |
| 위팔둘레 | 선택 | 15~60cm, 소수점 첫째 자리까지 |
| 허벅지둘레 | 선택 | 30~100cm, 소수점 첫째 자리까지 |
| 종아리둘레 | 선택 | 20~60cm, 소수점 첫째 자리까지 |
| 비고 | 선택 | 최대 200자 |

BMI 구간은 페이지의 태그와 같습니다.

| BMI | 태그 |
| --- | --- |
| 16 미만 | 심각한 저체중 |
| 16 이상 18.5 미만 | 저체중 |
| 18.5 이상 24 미만 | 건강 |
| 24 이상 28 미만 | 과체중 |
| 28 이상 32 미만 | 비만 |
| 32 이상 | 고도 비만 |

### 목록과 필터

- 검색창으로 비고를 검색하거나 키나 몸무게 숫자를 바로 입력할 수 있습니다.
- '필터'를 누르면 기록 시각 범위와 몸무게 범위로 필터링할 수 있습니다.
- 시작 날짜는 종료 날짜보다 늦을 수 없고, 최소 몸무게는 최대 몸무게보다 클 수 없습니다. 어길 경우 페이지에서 안내합니다.
- 목록은 페이지당 10, 20, 50건 중에서 선택할 수 있습니다.
- 편집, 단건 삭제, 체크 후 일괄 삭제를 지원합니다.
- 차트에 데이터가 없으면 '현재 필터 범위에 추이 데이터가 없습니다'라고 표시됩니다.

## 3. 운동 기록

운동 기록은 매번의 운동을 기록하는 데 씁니다. 페이지 위쪽에 네 장의 통계 카드가 있고, 전체 기록 수, 총 운동 시간, 평균 시간, 소모 칼로리가 모두 전체 기록을 기준으로 계산됩니다.

아래에 두 개의 차트가 있습니다.

| 차트 | 무엇을 보나요 |
| --- | --- |
| 최근 30일 운동 추이 | 최근 30일 동안 하루별 총 시간과 총 칼로리. 운동하지 않은 날은 0으로 계산합니다 |
| 운동 종류 분포 | 각 운동 종류의 비율로, 전체 기록의 총 시간을 기준으로 정렬합니다 |

이 두 차트는 고정된 기준을 사용하며 목록 필터의 영향을 받지 않습니다.

### 운동 기록 추가하기

'기록 추가'를 누르고 아래 표에 따라 작성하세요.

| 설정 항목 | 작성 방법 | 설명 / 제한 |
| --- | --- | --- |
| 기록 시각 | 필수 | 날짜만 선택하며, 구체적인 시각은 기록하지 않습니다 |
| 운동 종류 | 필수 | 유산소, 근력 운동, 요가, 수영, 달리기, 자전거 타기, 기타 |
| 구체적인 종목 | 필수 | 최대 128자. 예: '조깅', '벤치프레스' |
| 운동 강도 | 필수 | 낮음, 보통, 높음 |
| 느낌 | 필수 | 편함, 보통, 피로, 매우 피로 |
| 지속 시간 | 필수 | 0~1440분, 정수만 입력 |
| 소모 칼로리 | 필수 | 0~20000kcal, 정수만 입력. 종류, 강도, 시간을 입력하면 자동으로 추정됩니다 |
| 운동 장소 | 선택 | 최대 128자 |
| 심박수 | 선택 | 0~300. 평균 심박수를 입력하며 정수만 가능합니다 |
| 몸무게 | 선택 | 0~500kg, 소수점 첫째 자리까지 |
| 어깨너비 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 위팔둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 아래팔둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 가슴둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 허리둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 엉덩이둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 허벅지둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 종아리둘레 | 선택 | 0~300cm, 소수점 첫째 자리까지 |
| 비고 | 선택 | 최대 1000자 |

:::note[칼로리는 추정값일 뿐입니다]
자동으로 계산된 칼로리는 운동 종류, 강도, 시간에 따른 일반적인 참고값일 뿐 정밀한 측정값이 아닙니다. 이 숫자를 직접 수정할 수 있고, '계산기'를 눌러 몸무게·운동 종류·강도·시간을 입력해 몸무게 기준으로 다시 추정한 뒤 결과를 기록에 넣을 수도 있습니다.
:::

### 목록과 필터

- 검색창으로 운동 종류나 장소를 검색할 수 있습니다.
- '필터'를 누르면 운동 종류, 강도, 기록 시각 범위로 필터링할 수 있습니다.
- 표 머리를 누르면 기록 시각, 시간, 칼로리 순으로 정렬할 수 있습니다.
- 편집, 단건 삭제, 체크 후 일괄 삭제를 지원합니다.
- 목록에는 요약 필드만 표시되며, 심박수·둘레·비고 등은 편집 창에 들어가야 전체 내용을 볼 수 있습니다.

## 4. 친밀한 생활

친밀한 생활은 개인적인 데이터를 기록하는 데 씁니다. 페이지 위쪽에 네 장의 통계 카드가 있습니다.

| 통계 카드 | 계산 기준 |
| --- | --- |
| 전체 기록 수 | 전체 기록의 수 |
| 절정 횟수 | 기록에서 '절정'이 '예'인 항목의 수 |
| 평균 시간 | 전체 기록의 평균 지속 시간 |
| 파트너 수 | 기록에 등장한 서로 다른 파트너 이름의 수 |

아래의 '최근 12개월 빈도' 차트는 월별 기록 건수를 집계하며 현재 달을 포함합니다. 기록이 없는 달은 0으로 표시됩니다. 통계와 차트 모두 전체 기록을 기준으로 계산합니다.

:::note[목록에는 요약만 표시됩니다]
목록에는 날짜, 종류, 파트너, 장소, 시간, 보호 조치, 기분만 표시됩니다. 비고 같은 개인적인 세부 사항은 목록에 나타나지 않으며, '편집'을 눌러야 볼 수 있습니다.
:::

### 친밀 기록 추가하기

'기록 추가'를 누르고 아래 표에 따라 작성하세요.

| 설정 항목 | 작성 방법 | 설명 / 제한 |
| --- | --- | --- |
| 기록 시각 | 필수 | 날짜만 선택 |
| 기록 종류 | 필수 | 자위, 파트너, 동성, 다인 |
| 파트너 | '자위' 외에는 필수 | 이전 기록의 이름 중에서 선택하거나 새 이름을 바로 입력할 수 있고, '다인'을 선택하면 여러 명을 입력할 수 있습니다 |
| 장소 | 필수 | 최대 128자 |
| 지속 시간 | 필수 | 0~1440분, 정수만 입력 |
| 보호 조치 | 선택 | 콘돔, 여성용 콘돔, 피임약, 자궁 내 장치, 불임 수술, 무보호 |
| 자세 | 선택 | 최대 64자 |
| 란제리 | 선택 | 예 또는 아니오, 기본값은 '아니오' |
| 절정 | 선택 | 예 또는 아니오, 기본값은 '아니오' |
| 파트너 절정 | '자위' 외에 표시 | 예 또는 아니오, 기본값은 '아니오' |
| 사정 부위 | '자위' 외에 표시 | 질 내, 질 외, 얼굴, 가슴, 입, 항문 |
| 오르가슴 분출 | 선택 | 예 또는 아니오, 기본값은 '아니오' |
| 도구 | 선택 | 최대 255자 |
| 기분 | 선택 | 즐거움, 흥분, 차분함, 피로 |
| 비고 | 선택 | 최대 1000자 |

:::note[필드가 바뀌는 경우]
기록 종류에서 '자위'를 선택하면 '파트너'가 필수 항목이 아니게 되고, '파트너 절정'과 '사정 부위'는 자동으로 숨겨집니다. 다시 파트너·동성·다인으로 바꾸면 이 필드들이 다시 나타납니다.
:::

### 목록과 필터

- 검색창으로 파트너나 장소를 검색할 수 있습니다.
- 표 머리를 누르면 기록 시각, 파트너 또는 지속 시간 순으로 정렬할 수 있습니다.
- 이 페이지에는 검색만 있고 날짜나 종류 필터는 없습니다.
- 편집, 단건 삭제, 체크 후 일괄 삭제를 지원합니다.

## 데이터와 개인정보

- 라이프 아카이브는 관리자에 로그인한 사람에게만 공개되며, 프런트 사이트 메뉴에 없고 공유 링크도 제공하지 않습니다.
- 기록은 당신의 AMMDS에만 저장되며 외부 서비스로 업로드되지 않습니다.
- 삭제는 영구적이며, 삭제한 뒤에는 복구할 수 없습니다. 일괄 삭제도 마찬가지로 복구할 수 없습니다.
- 위쪽 통계는 전체 기록을 기준으로 계산해 검색과 필터의 영향을 받지 않으며, 신체 추이 차트는 필터를 따라갑니다. 운동·친밀 차트는 고정된 기준을 사용합니다.

## 자주 묻는 질문

| 현상 | 설명 |
| --- | --- |
| 왼쪽 메뉴에서 라이프 아카이브를 찾을 수 없음 | 먼저 관리자에 로그인해야 합니다. 라이프 아카이브는 프런트 사이트 메뉴에 없습니다 |
| 필터링했는데 위쪽 통계가 그대로임 | 정상입니다. 통계는 전체 기록을 기준으로 계산하며, 신체의 몸무게 및 BMI 추이 차트만 필터에 따라 달라집니다 |
| 기념일에 '매월'을 선택했는데 디데이가 여전히 연도 기준임 | 디데이와 통계는 고정적으로 '매년 같은 달 같은 날'을 기준으로 계산하고, 반복 종류는 기록용으로만 쓰입니다 |
| 음력 날짜가 자동으로 변환되지 않음 | '음력' 선택은 표시용이며, 날짜는 선택한 그날로 저장됩니다. 음력 날짜는 직접 확인해 입력해야 합니다 |
| BMI를 직접 수정할 수 없음 | BMI는 키와 몸무게로 자동 계산되며, 두 값을 바꾸면 갱신됩니다 |
| 자동 계산된 칼로리가 정확하지 않음 | 참고값일 뿐이므로 직접 수정할 수 있고, 계산기로 몸무게 기준 다시 추정할 수도 있습니다 |
| '자위'를 선택했는데 파트너 항목이 사라짐 | 설계된 동작으로, 파트너 관련 필드가 자동으로 숨겨집니다. 다른 종류로 바꾸면 다시 나타납니다 |
| 친밀한 생활 목록에 비고가 보이지 않음 | 목록에는 요약만 표시되며, 비고는 '편집'에서 확인할 수 있습니다 |
| 삭제한 기록을 되찾을 수 있나요 | 할 수 없습니다. 삭제는 복구되지 않습니다 |
