# 메시지, 피드, 공유와 연동

**정보 센터**는 네 가지를 맡습니다. 시스템이 남긴 메시지, 외부 피드, 항목을 남과 공유하기, 그리고 다른 AMMDS 사이트와 연동하기입니다. 네 가지는 서로 독립이라 필요한 부분만 보면 됩니다.

## 1. 시스템 메시지 읽기

메시지 화면에는 AMMDS가 돌면서 만든 알림이 모입니다. 백그라운드 작업 결과, 사이트 인증 상태, 공유 신청과 가져오기 진행, 그리고 공식 공지입니다.

> **알림 종류**: 세 가지입니다. 시스템 알림은 앱이 스스로 만듭니다(구독 결과, 사이트 인증, 정리 진행 등). 공식 알림은 공식 계정의 공지이고, 공유 알림은 공유 신청과 가져오기 결과입니다.

### 걸러내기와 읽기

위쪽에 두 가지 걸르개가 있습니다. 알림 종류(전체 / 시스템 / 공식 / 공유)와 읽음 상태(전체 / 읽음 / 안 읽음)입니다. 바꾼 뒤 「조회」를 누릅니다. 목록은 한 페이지에 10개이며 개수를 바꿀 수 있습니다.

각 메시지에는 종류, 등급, 제목, 내용 요약, 시각, 동작이 나옵니다. 등급은 네 가지입니다.

| 등급 | 색 | 뜻 |
| --- | --- | --- |
| 정보 | 파랑 | 그냥 알림. 할 일 없음 |
| 성공 | 초록 | 동작이 잘 끝남 |
| 경고 | 주황 | 문제가 있을 수 있지만 계속 쓸 수 있음 |
| 오류 | 빨강 | 실패나 이상. 손봐야 함 |

### 읽음 처리와 삭제

- 동작 칸의 체크 버튼을 누르면 읽음이 됩니다. 읽음이 되면 버튼이 잠겨 두 번 보내지 않습니다.
- 삭제 버튼으로 메시지를 지웁니다. 지우면 목록에 다시 나오지 않습니다.
- 이번 버전은 한 개씩만 다룰 수 있고, "모두 읽음"이나 여러 개 삭제는 없습니다.

이 화면은 앱 안의 메시지만 다룹니다. 휴대폰으로 알림을 받으려면 통합 앱에서 알림 서비스를 설정하세요.

## 2. 외부 피드 구독하기

> **RSS**: 많은 사이트가 내놓는 정해진 형식의 새 글 목록입니다. 주소를 등록하면 AMMDS가 주기적으로 가져와 앱 안에서 읽게 해 줍니다.

피드에는 여섯 개의 탭이 있습니다.

| 탭 | 쓰임 |
| --- | --- |
| 대시보드 | 구독 수와 글 수, 분류 비율, 최근 14일 흐름, 최근 작업 |
| 구독 관리 | 추가, 편집, 가져오기, 보관, 삭제 |
| 오프라인 캐시 | 사용량과 진행 확인, 캐시 비우기 |
| 인기 구독 | 온라인 인기 목록에서 골라 한 번에 구독하거나 해지 |
| 링크 미리보기 | 주소를 먼저 풀어 보고 구독할지 정하기 |
| 설정 | 전체 기본값 |

### 구독 추가하기

1. 「구독 관리」에서 추가를 누르고 아래 항목을 채웁니다.
2. 저장한 뒤 그 줄의 「가져오기」를 누르면 바로 실행되고, 늘어난 개수가 알림으로 나옵니다.
3. 모두 가져오려면 「전체 가져오기」를 씁니다. 백그라운드 작업이라 페이지를 떠나도 됩니다.

주소가 될지 확신이 없으면 먼저 「링크 미리보기」를 써 보세요. 주소를 넣고 「미리보기」를 누르면 개수, 분류, 언어, 글 몇 개를 볼 수 있습니다. 내용이 맞으면 「이 소스 구독」을 누릅니다.

### 설정 항목: 구독에 넣을 것

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 사용 여부 | 끄면 가져오기 대상에서 빠집니다 | 기본은 사용입니다 |
| 구독 주소 | RSS 또는 Atom 주소 | 주소가 없으면 가져올 수 없습니다 |
| 이름 | 앱에 보이는 이름 | 목록에서 구분이 어렵습니다 |
| 설명 | 있어도 되고 없어도 되는 메모 | 보이지 않습니다 |
| 내용 분류 | 글 / 이미지 / 영상 / 자료 / 기타 | "기타"로 묶이고 공개 탭에는 나오지 않습니다 |
| 아이콘 주소 | 있어도 되는 목록 아이콘 | 기본 아이콘이 쓰입니다 |
| 자세히 읽기 | 가져온 뒤 상세 페이지를 열어 본문과 미디어를 채웁니다 | 목록의 요약만 남습니다 |
| 오프라인 캐시 | 본문과 그림을 내 기기에 저장합니다 | 원본 사이트가 지우면 내용도 볼 수 없습니다 |

사이트 플러그인이 가져온 「통합 소스」는 이름·설명·아이콘만 고칠 수 있고 주소는 읽기 전용입니다.

### 오프라인 캐시

> **오프라인 캐시**: 글 본문과 그림 같은 자료를 내 디스크에 저장해 두는 일입니다. 원본 사이트가 불안정하거나 옛 글을 지우는 곳이라면 유용합니다.

캐시 화면에는 구독별로 "전체 / 저장됨 / 남음", 캐시 사용량, 완성 비율이 나옵니다. 「캐시 새로 고침」은 백그라운드 작업을 등록하고, 「캐시 비우기」는 모든 파일을 지웁니다. 비운 뒤에는 다시 저장해야 오프라인에서 볼 수 있습니다. 보관된 구독은 가져오기도 캐시도 하지 않습니다.

### 인기 구독

인기 목록은 온라인 목록에서 가져오며 이름, 설명, 분류, 종류, 원본 도메인을 보여 줍니다. 출처에는 세 가지 표시가 있습니다. 온라인 동기화(방금 가져옴), 로컬 캐시(온라인이 안 되어 저장된 목록 사용), 내장 대체(처음 설치인데 온라인도 안 될 때)입니다. 「지금 동기화」도 되고, 구독하지 않은 것은 바로 구독할 수 있습니다. 구독을 해지하면 가져온 글도 함께 지워집니다. 시스템은 이 소스들이 응답하는지 주기적으로 확인하고, 안 되는 곳에 표시를 붙입니다.

### 피드 전체 설정

아래는 **새 구독의 기본값**이며, 바꿔도 이미 있는 구독은 변하지 않습니다. 개별 구독의 스위치가 우선합니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비우거나 잘못 넣으면 |
| --- | --- | --- |
| 자동 보관 | 매일, 보관 기간보다 오래된 구독을 통째로 보관합니다 | 기본은 꺼짐이고 보관은 손으로 합니다 |
| 자동 보관 기간(일) | 숫자. 기본 30 | 0 이하면 자동 보관을 쓰지 않는 것과 같습니다 |
| 기본 자세히 읽기 | 새 구독에서 "자세히 읽기"를 처음부터 켤지 | 기본은 꺼짐 |
| 기본 오프라인 캐시 | 새 구독에서 "오프라인 캐시"를 처음부터 켤지 | 기본은 꺼짐 |
| 글 하나당 그림 한도 | 숫자. 기본 20 | 그림이 많은 글은 일부만 저장됩니다 |
| 글 하나당 영상 한도 | 숫자. 기본 0 | 기본은 영상 자체를 저장하지 않습니다 |
| 한 차례 글 한도 | 숫자. 기본 200 | 나머지는 다음 차례로 넘어갑니다 |
| 캐시 요청 제한 시간(초) | 숫자. 기본 30 | 느린 자료는 실패하고 다시 돌려야 합니다 |
| 인기 목록 캐시 시간(분) | 숫자. 기본 360 | 짧으면 자주 가져오고, 길면 낡은 목록일 수 있습니다 |
| 인기 소스 확인 | 목록의 소스가 응답하는지 주기적으로 볼지 | 기본은 켜짐. 끄면 죽은 주소를 추천할 수 있습니다 |
| 링크 미리보기 제한 시간(초) | 숫자. 기본 20 | 느린 사이트는 풀지 못합니다 |

:::warning[구독을 지우면 글도 지워집니다]
구독을 지우면 그 구독으로 가져온 글도 모두 지워집니다. 되돌릴 수 없습니다.
:::

## 3. 항목을 남과 공유하기

공유 링크는 작품, 출연자, 시리즈, 만화, 소설, 드라마를 공개 주소로 만듭니다. 상대는 로그인 없이 열 수 있지만, 보이는 것은 항목 정보뿐이고 영상 파일은 주지 않습니다.

### 공유 만들기

1. 「새 공유」를 누르고 종류를 고릅니다.
2. 공유할 항목을 찾아 고릅니다.
3. 유효 기간을 고릅니다. 영구 또는 직접 정한 만료 시각입니다.
4. "남이 가져가는 것을 허용할지"를 정합니다. 끄면 상대는 보기만 하고, 가져가려면 신청해야 합니다.
5. 필요하면 접근 비밀번호를 정합니다. 비우면 비밀번호가 없습니다.
6. 「만들기」를 누릅니다. 결과에 QR 코드와 전체 링크가 나오고, 링크는 한 번 자동으로 복사됩니다.

> **접근 비밀번호**: 흔히 말하는 추출 코드입니다. 남에게 줄 때는 링크와 비밀번호를 함께 주세요. 비밀번호는 링크에 들어 있지 않습니다.

목록은 종류로 걸러내고, 짧은 코드나 제목으로 찾을 수 있습니다. 각 줄에는 종류, 제목, 짧은 코드, 전체 링크, 비밀번호 있음 여부, 유효 기간, 상태, 가져오기 허용 여부, 만든 시각이 나옵니다.

| 상태 | 언제 그렇게 되는지 | 상대에게 보이는 것 |
| --- | --- | --- |
| 정상 | 만료되지도 멈추지도 않음 | 볼 수 있음. 가져오기는 설정에 따라 다름 |
| 일시 정지 | 내가 멈춤 | 공유가 멈췄다고 나옵니다 |
| 만료 | 정한 시각을 지남 | 공유가 만료됐다고 나옵니다 |

멈춘 것은 언제든 다시 시작할 수 있습니다. 삭제는 되돌릴 수 없고 링크가 바로 죽습니다.

### 가져오기 신청 처리하기

남이 내 공유를 가져가려 하면 신청이 「받은 편지함」에 들어옵니다. 대상 공유, 신청자(별명과 계정 ID), 메일, 이유, 상태, 시각이 나옵니다. 「대기 중」만 승인이나 거절을 할 수 있습니다.

결과는 공유 알림이 됩니다. 다만 **승인은 그 신청의 상태만 바꿀 뿐**이고, 공유 자체를 가져갈 수 있는지는 만들 때 정한 설정 그대로입니다.

## 4. 남의 공유 가져오기

가져오기는 **시스템 관리 → 백업과 복원 → 공유 가져오기**에 있습니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 공유 링크 또는 짧은 코드 | 남에게 받은 공개 주소, 또는 끝부분의 짧은 코드 | 미리 볼 수 없습니다 |
| 접근 비밀번호 | 상대가 정했을 때만 넣습니다 | 비밀번호를 요구받고 가져올 수 없습니다 |
| 가져오기 방식 | 이미 있는 것 건너뛰기 / 덮어쓰기 / 합치기 | 기본은 "건너뛰기"입니다 |

넣고 「공유 미리보기」로 종류·제목·개수를 확인한 뒤 「공유 가져오기」를 누릅니다. 가져오기가 허용되지 않았으면 "이 공유는 가져올 수 없습니다"라고 나오니, 이유를 적어 신청할 수 있습니다(먼저 사용자 ID, 별명, 메일을 채워야 합니다).

같은 페이지 아래에서 「링크 기록」(성공, 권한 없음, 링크 무효, 만료, 실패)과 「신청 기록」(대상, 이유, 상태. 대기 중은 취소 가능)을 오갈 수 있습니다. 기록을 지워도 이미 가져온 자료에는 영향이 없습니다.

## 5. 다른 AMMDS와 연동하기

> **인스턴스 연동**: 두 AMMDS를 서로 친구로 만드는 일입니다. 맺으면 메시지를 주고받고, 상대 보관함을 찾고, 상대의 만화나 소설 정보를 내 쪽으로 가져올 수 있습니다. 사이트 토큰을 쓰므로 비밀번호를 넘길 필요가 없습니다.

> **토큰**: 기한이 있는 증표로, 임시 통행증 같은 것입니다. 만료되면 다시 받으면 됩니다.

### 준비물

1. 양쪽이 모두 **시스템 설정**에서 「연동」을 켭니다(기본은 꺼짐).
2. 서로 네트워크에서 닿을 수 있어야 합니다. 도메인을 쓴다면 암호화 접속을 권합니다.
3. 상대의 사이트 주소(프로토콜 포함, 또는 `IP:포트`)를 알고 있어야 합니다.

스위치가 꺼져 있으면 친구 신청도 검색도 되지 않습니다.

### 친구 추가와 신청 주고받기

1. 「친구 추가」를 누르고 상대 주소를 넣습니다.
2. 「해석」을 누르면 상대의 연동 서비스를 찾아 친구 ID와 별명을 자동으로 채웁니다.
3. 원하면 사이트 이름과 메모를 넣고, 신청 이유(필수)를 적어 「신청」을 누릅니다.
4. 상대가 받은 편지함에서 승인하면 관계가 맺힙니다. 오래 방치되면 「보낸 신청」에서 다시 보내고, 거절당하면 새로 신청합니다.

친구 목록에는 이름, 상태(온라인 / 연결 중 / 오래 오프라인 / 오프라인), 주소, 메모, 그리고 갱신·정보·메시지·수정·삭제가 나옵니다. 주소 옆의 「확인」으로 상태를 새로 고칠 수 있습니다.

- **갱신**: 토큰을 새로 받습니다. 만료됐거나 상대가 초기화했을 때 씁니다.
- **정보**: 상대의 별명, 사이트 이름, 메모를 바꿉니다. 주소는 읽기 전용입니다.
- **수정**: 메모만 바꿉니다.
- **삭제**: 친구 관계를 지웁니다. 메시지와 신청 기록은 남습니다.

### 친구 검색과 메시지

「친구 검색」은 모든 친구 사이트에 동시에 물어보고 결과를 모읍니다. 종류는 작품, 출연자, 만화, 소설이고 키워드는 필수입니다. 「가져오기」버튼은 만화와 소설에만 있고, 작품과 출연자는 보기만 됩니다. 같은 이름이 있거나 상대의 상세 정보가 없으면 실패하면서 이유가 나옵니다.

친구 줄에서 「메시지」를 누르면 대화창이 열립니다. 시간 순으로 늘어서고 내가 보낸 것은 오른쪽, 상대 것은 왼쪽입니다. 메시지는 양쪽 데이터베이스에만 저장되고 중앙 서버를 거치지 않습니다.

연동은 상대의 영상 파일을 복사하지 않습니다. 본문과 포스터는 각자의 사이트가 관리합니다.

## 문제가 생기면

- **메시지가 안 보인다**: 걸러내기가 "안 읽음"이나 한 종류에 머물지 않았는지 보고, 지운 뒤 다시 조회하세요.
- **피드를 못 가져온다**: 「링크 미리보기」로 주소가 풀리는지 확인하세요. 죽었으면 바꾸거나 인기 구독에서 비슷한 것을 고르세요.
- **공유가 안 열린다**: 대개 만료됐거나 멈춘 것입니다. 연장하거나 새로 만들어 달라고 하세요. 비밀번호를 요구하면 상대에게 물어보세요.
- **가져오기 버튼이 안 눌린다**: 상대가 "보기만"으로 정했습니다. 신청을 내고 기다리세요.
- **상대 사이트 해석이 실패한다**: 주소와 연동 스위치를 확인하고, 먼저 브라우저로 상대 사이트를 열어 보세요.
- **친구가 오래 오프라인이다**: 「확인」으로 보고, 「갱신」을 시도하세요. 그래도 안 되면 상대 사이트와 네트워크를 확인합니다.
