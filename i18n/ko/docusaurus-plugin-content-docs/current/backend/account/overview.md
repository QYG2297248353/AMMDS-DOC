# 내 정보, 공식 상점, 로그인 안전

이 페이지는 세 곳을 다룹니다. **내 계정**(아바타, 정보, 공개 페이지, 비밀번호), **공식 상점**, 그리고 **사이트 인증**(사이트 인증 값을 AMMDS에 넘기는 일)입니다. 서로 독립이라 필요한 부분만 보면 됩니다.

## 1. 내 정보

오른쪽 위 아바타 → **사용자 센터**를 엽니다. 페이지는 위에서 아래로 머리 그림 영역, 페이지 설정, 사용자 정보, 라이선스입니다. 바꾸면 바로 반영되고 다시 시작할 필요가 없습니다.

### 머리 그림 영역

| 항목 | 고치는 법 |
| --- | --- |
| 아바타 | 아바타를 눌러 그림을 고르면 올리기가 끝나는 대로 바뀝니다 |
| 배너 | 오른쪽 위 올리기 버튼으로 그림을 고릅니다. 이미 있으면 지워서 기본 배경으로 돌릴 수 있습니다 |
| 별명 | 지금 별명이 보입니다 |
| 역할 표시 | 관리자 또는 사용자 |
| 라이선스 표시 | 라이선스 상태(유효 / 무효)와 같습니다 |
| 회원 표시 | 계정에 회원 표시가 있을 때만 보입니다 |
| 비밀번호 변경 | 누르면 변경 창이 열립니다 |

배너를 올리지 않았으면 기본 배경 그림이 쓰입니다.

### 페이지 설정

여기는 **남이 내 공개 페이지에 들어왔을 때 보이는 모습**을 정합니다.

| 영역 | 내용 |
| --- | --- |
| 공개 페이지 배경 | 올리거나 지우기. 없으면 빈 자리 표시 |
| 공개 페이지 배너 | 올리거나 지우기. 머리 쪽 배너와는 따로입니다 |
| 공개 페이지 테마 | 여러 테마 카드. 누르면 바뀌고 저장됩니다. 테마마다 화면 구성과 배치가 다릅니다 |

배경과 배너는 공개 페이지의 모든 테마에 쓰이고, 어떻게 쓰고 얼마나 자를지는 테마가 정합니다.

### 사용자 정보

정보 카드에는 사용자 ID, 별명, 메일, 휴대폰, 역할, 상태, 가입 시각, 마지막 로그인이 나옵니다. 오른쪽 위에 두 입구가 있습니다. 「정보 편집」은 편집 창을 열고, 「공개 페이지」는 새 탭에서 엽니다.

> **사용자 ID**: 내가 정한 계정 이름이며, 그대로 공개 페이지 주소(`/u/내ID` 모양)가 됩니다. 바꾸면 옛 링크가 죽으니 이미 나눠 준 것이 있다면 함께 고치세요.

> **가림 표시**: 일부만 보여 주고 가운데를 기호로 가리는 것입니다. 휴대폰이라면 앞뒤 몇 자리만 보입니다.

### 설정 항목: 편집할 것

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 사용자 ID | 필수. 영문, 숫자, 밑줄, 붙임표만. 4자 이상, 숫자만은 안 되고 `admin`, `root`, `ammds` 같은 예약 이름도 안 됩니다 | 저장할 수 없고 공개 페이지도 안 열립니다 |
| 별명 | 필수. 최대 32자 | 저장할 수 없습니다 |
| 메일 | 필수. 메일 모양이어야 합니다 | 저장할 수 없고 인스턴스 연동도 켤 수 없습니다 |
| 휴대폰 | 있어도 되고 없어도 됨. 공개 페이지에서는 가림 표시 | 비워 둬도 됩니다 |
| 공개 페이지에 보여 줄 항목 | 여러 개 고르기: 사용자 ID, 별명, 아바타, 메일, 휴대폰(가림), 가입 시각, 마지막 로그인, 상태 | 한 번도 정하지 않았다면 휴대폰을 뺀 모두를 보여 줍니다. 다 끄면 아무것도 보이지 않습니다 |

### 비밀번호 바꾸기

머리 쪽 「비밀번호 변경」을 누르고 세 가지를 넣습니다. 지금 비밀번호, 새 비밀번호, 새 비밀번호 다시입니다.

비밀번호 규칙(로그인, 변경, 초기화 모두 같음): **6~22자, 영문 대문자와 소문자를 모두 포함, 그리고 숫자나 기호를 하나 이상** 넣어야 합니다. 두 번 넣은 것이 같아야 합니다.

보낼 때 비밀번호는 암호화됩니다. 성공하면 "곧 로그아웃됩니다"라고 나오고 약 5초 뒤에 자동으로 나가집니다. 새 비밀번호로 다시 들어오세요. 바꾸려면 지금 비밀번호가 필요합니다. 아예 들어갈 수 없다면 시스템 관리의 복구 키로 초기화하세요.

아바타, 배너, 배경은 모두 데이터 폴더의 공간을 씁니다. 별명, 메일, 휴대폰은 인스턴스 연동의 준비물이기도 하며 없으면 켤 수 없습니다.

## 2. 공식 상점

> **공식 상점**: AMMDS에 들어 있는 가게입니다. 물건, 값, 재고, 결제, 배송은 공식 가게가 맡고, 이쪽은 보여 주고 주문만 합니다. 회원이나 서비스를 사는 것은 개발을 가장 직접적으로 돕는 길입니다.

### 사는 흐름

1. **둘러보기**: 물건 목록을 엽니다. 로그인 없이 보고, 찾고, 자세히 볼 수 있습니다("지금은 팔지 않음" 표시가 있는 물건은 담을 수 없습니다).
2. **담기**: 자세히 보기에서 규격과 수량을 고르고 「장바구니에 담기」를 누릅니다(여기서 로그인이 필요합니다). 장바구니에서 수량을 바꾸거나 뺄 수 있습니다.
3. **결제**: 「결제하기」를 누르고 아래 칸을 채운 뒤 결제 수단을 골라 주문을 보냅니다.

장바구니는 한꺼번에 결제되고 줄마다 고르는 칸은 없습니다. 통화는 처음 담을 때 고른 지역으로 정해집니다. 통화를 바꾸려면 장바구니를 버리고 다시 담아야 합니다(물어보는 창이 뜨지만 주문이 생기거나 돈이 빠지지 않습니다). 보내면 주문 결과 페이지로 가고, 그 링크는 내가 간직해도 안전합니다.

### 결제 화면에서 채울 것

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 연락처 | 메일은 필수. 휴대폰, 성, 이름은 선택 | 메일이 비면 보낼 수 없습니다 |
| 자주 쓰는 주소 | 로그인 후 저장한 주소를 고르면 아래 칸에 채워집니다 | 매번 손으로 씁니다 |
| 받는 주소 | 주소, 도시, 나라는 필수. 우편번호, 주/도는 선택 | 필수가 비면 보낼 수 없습니다 |
| 배송 방법 | 「배송 방법 가져오기」를 누르면 그 지역에서 되는 방법과 값이 나옵니다 | 그냥 주문해도 자동으로 가져옵니다 |
| 결제 수단 | 상점이 준 목록에서 고릅니다 | 고르지 않으면 주문이 안 됩니다 |

### 주문 확인

주문 목록과 자세히 보기는 공개 사이트에서 봅니다. 관리 화면의 **공식 상점** 메뉴에는 네 페이지가 있습니다.

| 페이지 | 쓰임 |
| --- | --- |
| 상태 | 가게 정보, 물건·분류·장바구니·주문 수, 최근 동기화 시각, 연결 상태. 손으로 동기화할 수 있습니다 |
| 주문 | 모든 계정의 주문과 자세한 내용. 키워드와 결제 상태로 걸러낼 수 있습니다 |
| 장바구니 | 계정별 장바구니를 보고 항목을 빼거나 비울 수 있습니다 |
| 자주 쓰는 주소 | 내 배송 주소를 관리하고 기본값을 정합니다 |

동기화에는 "물건(바뀐 것만)", "정보", "주문", "전체 맞춤"이 있고 모두 뒤에서 돕니다. 화면에는 진행, 성공·실패 개수, 오류 요약이 나옵니다. 전체 맞춤이 도는 중에는 다시 시작할 수 없습니다.

### 주소 항목

**공식 상점 → 자주 쓰는 주소**에서 추가, 편집, 삭제, 기본 설정을 합니다. 항목은 메일, 휴대폰, 성, 이름, 나라, 주/도, 도시, 우편번호, 자세한 주소이며 **메일, 휴대폰, 나라, 도시는 필수**입니다. 결제 화면에서는 기본 주소가 저절로 골려 칸에 채워집니다.

## 3. 사이트 인증

> **사이트 인증**: 사이트 인증 값(사용자 ID와 개인 키)을 AMMDS에 넘겨, 그 계정으로 데이터를 읽게 하는 일입니다. 이름이나 신분증 같은 실명 정보는 다루지 않습니다.

> **PassKey**: 사이트가 발급하는 개인 키로, 그 사이트의 로그인 값과 같은 구실을 합니다. 화면을 캡처해 나누지 말고, 여러 사이트에서 같은 키를 쓰지 마세요.

오른쪽 위 아바타 → **사이트 인증**을 엽니다. 등록된 사이트는 카드로 보이며 한 줄에 세 개입니다. 없으면 "인증 사이트가 없습니다"라고 나옵니다.

### 인증하는 법

1. 카드의 「UID」를 누르고 그 사이트의 사용자 ID를 넣어 보냅니다(저장됩니다).
2. 「PassKey」를 누르고 사이트에서 받은 키를 넣어 보냅니다.
3. 카드의 스위치가 켜져 있는지 확인합니다.
4. 「지금 인증」을 누릅니다.

사이트마다 필요한 것이 다릅니다. 사용자 ID와 개인 키를 모두 요구하는 곳이 많지만, 개인 키만 필요한 곳도 있습니다. 또 세 가지가 더 필요합니다. 사이트가 켜져 있을 것, 사이트가 인증을 받아줄 것, 인증 값이 저장되어 있을 것입니다. 하나라도 없으면 화면이 알려 주고 요청을 보내지 않습니다.

인증은 뒤에서 이루어지니 페이지에 머물 필요가 없습니다. 목록은 10초마다 새로 고쳐지고, 다른 탭으로 가면 멈춥니다.

### 인증 상태

| 상태 | 뜻 |
| --- | --- |
| 인증됨 | 최근 인증이 성공하고 유효 기간 안에 있음 |
| 인증 안 됨 | 한 번도 안 했거나, 실패했거나, 유효 기간이 지남 |

인증 결과의 유효 기간은 **6시간**입니다. 지나면 저절로 인증 안 됨으로 돌아가지만, 마지막 인증 시각과 실패 이유는 남아 원인을 찾는 데 쓰입니다. 안에 있는 정기 작업이 주기적으로 다시 인증하므로 보통은 손으로 갱신할 필요가 없습니다. 성공하면 사이트가 돌려준 사용자 이름과 메일을 기록하고 "사이트 인증에 성공했습니다"라는 알림을 보냅니다.

## 문제가 생기면

- **"사이트가 활성 상태가 아닙니다"가 뜬다**: 카드의 스위치를 켜고 다시 해 보세요.
- **"먼저 UID와 PassKey를 설정하세요"가 뜬다**: 각각 한 번 넣습니다. 저장된 버튼은 강조되어 보입니다.
- **"이 사이트는 인증을 지원하지 않습니다"가 뜬다**: 그런 사이트는 플러그인으로만 붙입니다. 통합 앱에서 설정하세요.
- **이유 없이 실패한다**: 사용자 ID와 개인 키가 맞지 않거나, 사이트에서 키를 다시 발급했을 수 있습니다. 사이트에서 둘을 확인하세요.
- **인증됨이 다시 인증 안 됨으로 돌아간다**: 6시간이 지나고 정기 작업이 아직 안 돌았습니다. 「지금 인증」을 한 번 누르세요.
- **물건 목록이 비어 있다**: 상점이 아직 동기화되지 않았습니다. 관리자가 「상태」에서 동기화하세요.
- **비밀번호를 바꾸니 로그아웃된다**: 원래 그런 동작입니다. 새 비밀번호로 다시 들어오세요.
