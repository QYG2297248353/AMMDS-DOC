# 시스템 점검, 로그, 저장소, 라이선스와 사용자

"먼저 여기를 보라"는 페이지입니다. 전체 점검을 돌리고 로그와 공간을 보고, 그 김에 라이선스와 계정 안전, 뒤의 작업도 살펴봅니다. 각 절은 따로 읽을 수 있습니다.

## 1. 시스템 점검: 먼저 한 번 돌리기

> **시스템 점검**: 안에 든 진찰 도구입니다. 설정과 상태만 읽고, 바꾸거나 저절로 고치지 않습니다.

오른쪽 위 아바타 → **시스템 점검**을 엽니다. 먼저 읽기만 하는 요약이 나옵니다. 판, 운영 체제, 메모리, 디스크 남은 공간, 포트, 데이터베이스, 켜 있는 시간, 데이터 폴더, 서버 시각, 시간대입니다.

「점검 시작」을 누르면 서버에서 돌고, 끝나면 위에 정상·경고·이상·사용 안 함이 각각 몇 개인지와 걸린 시간이 나옵니다.

### 무엇을 보는가

| 묶음 | 보는 점 |
| --- | --- |
| 기본 정보 | 판, 운영 체제, 메모리, 디스크, 시스템 시각, 바깥 연결 |
| 프로그램 설정 | 도움 프로그램이 준비됐는지, 중계 설정이 모자라지 않은지, 각 통합이 답하는지 |
| 시스템 설정 | 포트, 데이터베이스 연결, 도메인 연결, 알림 갈래, 라이선스 |
| 돌아가는 상태 | 로그의 오류 수, CPU와 메모리 부담, 디스크 부담 |

자주 나오는 기준입니다.

- **메모리**: 사용률이 90%를 넘거나 시스템의 빈 메모리가 10%보다 적으면 경고.
- **디스크**: 데이터 폴더에 1GB보다 적게 남았거나 사용률이 90%를 넘으면 경고.
- **시스템 시각**: 인터넷 시각과 5분 넘게 다르면 경고. 라이선스 확인, 정기 작업, 시각 판단이 흔들립니다.
- **네트워크 연결**: 여러 곳을 한꺼번에 두드려 보고, 모두 닿으면 정상, 일부만 닿으면 경고, 모두 실패면 이상.
- **도움 프로그램**: 없으면 경고가 나고 무슨 기능이 막히는지도 알려 줍니다(영상 처리 프로그램이 없으면 영상 처리, 화면 갈무리, 포스터 자르기, 작은 그림 만들기가 막힙니다).
- **중계**: 안 쓰면 "사용 안 함"으로 적습니다. 쓰는데 호스트나 포트가 비었거나 포트가 1~65535 밖이면 이상입니다.
- **통합 서비스**: 안 켰으면 문제가 아닙니다. 켰는데 필수 설정이 비었으면 경고, 주소는 있는데 못 붙으면 이상입니다.

### 결과 읽는 법

| 상태 | 뜻 | 손댈 일인가 |
| --- | --- | --- |
| 정상 | 기대한 대로 | 아니오 |
| 경고 | 쓸 수는 있지만 불안. 기능이 제한될 수 있음 | 알림대로 처리 |
| 이상 | 이미 못 쓰거나 설정이 뚜렷이 틀림 | 예, 고쳐야 함 |
| 사용 안 함 | 그 대상 자체가 꺼져 있음 | 아니오(필요하면 별개) |

일부 항목에는 꼬리표가 붙습니다. "설정이 필요"는 그 설정 화면으로 보내고, "다시 시작 필요"는 다시 켜야 먹는다는 뜻이며, "영향받는 기능"은 그 문제가 미치는 곳입니다.

## 2. 로그: 세 가지가 제각각

**시스템 관리 → 로그 감사**에 세 페이지가 있습니다.

| 페이지 | 보는 것 | 찾기 좋은 것 |
| --- | --- | --- |
| 로그인 로그 | 누가 언제 들어왔는지. 성공과 실패 모두 | 비밀번호 틀림, 막힌 계정, 낯선 곳에서의 접속 |
| 동작 로그 | 서버에서 방금 무슨 일이 있었는지 | 화면 오류, 서비스 이상 |
| 작업 로그 | 뒤의 작업이 어디까지 갔고 왜 실패했는지 | 검사, 정보 긁어오기, 정리, 동기화, 내보내기·가져오기 실패 |

### 로그인 로그

항목은 순서대로 사용자 이름, 온 곳, 장소, 시각, 기기 정보(운영 체제 / 기기 / 브라우저), 상태, 이유입니다. 키워드와 상태로 걸러내고 한 페이지에 10개, 최신이 먼저입니다. 실패 이유는 확인 단계에서 온 것으로 "사용자가 없습니다", "계정이 막혔습니다", "비밀번호가 다릅니다" 같은 것이 있고, 성공은 "로그인 성공"입니다.

### 동작 로그

항목은 시각, 갈래, 등급, 남긴 곳, 메시지입니다. 등급은 네 가지로 오류(빨강), 경고(주황), 정보(파랑), 디버그나 보통입니다. 화면은 최근 것(기본 300개)을 읽고 8초마다 새로 고쳐집니다.

오른쪽 위에서 "최근 1일 / 7일 / 30일"을 골라 내보낼 수 있습니다. 서버가 주된 로그와 날짜별로 갈린 로그를 날짜 순으로 한 글 파일로 이으며, 모두 합쳐 100MB가 넘으면 오래된 쪽을 잘라 냅니다. 로그는 데이터 폴더에 있고, 주된 파일은 날짜로 갈리며 오류는 따로 모입니다.

### 작업 로그

도구 모음에 도는 작업 수가 나오고 이름, 종류, 상태로 걸러낼 수 있으며 자동 새로 고침도 켤 수 있습니다. 열은 작업, 종류, 상태, 진행, 끝낸 수 / 전체, 걸린 시간입니다. 「자세히」를 누르면 실패 이유, 시작과 끝 시각, 그리고 **실행 내역**(시각, 등급, 메시지가 줄줄이)이 보입니다. 왜 실패했는지 가장 빨리 알 수 있는 자료입니다.

할 수 있는 일은 다음과 같습니다. 자세히(언제든), 취소(도는 중이고 받아들이는 작업만), 삭제(도는 중이 아닐 때), 끝난 것 비우기(끝난 것 모두 지우고 도는 것은 남습니다).

### 권하는 순서

1. 먼저 **작업 로그**에서 실패한 그 회를 찾아 실행 내역의 첫 오류를 읽습니다.
2. 시각을 기억하고 **동작 로그**에서 같은 무렵의 앞뒤를 봅니다.
3. 서비스 주소, 값, 네트워크가 걸렸다면 **시스템 점검**으로 확인합니다.
4. 로그인이나 권한이 의심되면 **로그인 로그**를 봅니다.

## 3. 저장소: 공간을 누가 쓰고 있나

**시스템 관리 → 저장소 관리**를 열면 네 숫자가 나옵니다. 디스크 전체, 쓴 것, 남은 것, 데이터 폴더 사용량입니다. "쓴 것"과 "데이터 폴더 사용량"의 차이는 대개 영상 원본, 운영 체제, 다른 프로그램입니다.

집계는 뒤에서 이루어집니다(켤 때 한 번, 그다음 5분마다). 화면은 30초마다 새로 고쳐집니다. 데이터 폴더는 첫 단계 폴더마다 크기와 파일 수가 갈리고, 그림은 두 번째 단계까지 더 잘게 나옵니다. 흔한 갈래는 그림, 캐시, 영상 처리 프로그램, 자막, 자료 서비스, 값, 로그, 임시입니다. 등록되지 않은 폴더는 "그 밖의 자료"로 묶입니다.

:::warning[폴더를 손으로 지우지 마세요]
데이터 폴더의 값 폴더와 데이터베이스 폴더에는 증표와 모든 자료가 들어 있습니다. 돌고 있는 중에 옮기거나 지우면 깨질 수 있습니다. 정리는 아래의 자리에서 하세요.
:::

이 화면은 보기만 하는 곳이고, 정리 자리는 따로 있습니다.

| 무엇을 치울까 | 어디서 |
| --- | --- |
| 작업 로그 | 로그 감사 → 작업 로그 → 끝난 것 비우기 |
| 내보낸 백업 | 백업과 복원 → 자료 내보내기 → 내보내기 기록 → 삭제 |
| 피드 오프라인 캐시 | 정보 센터 → 피드 → 캐시 칸 → 캐시 비우기 |
| 쓸모없는 파일과 임시 파일 | 도구함 → 파일 탐색기 → 삭제 |
| 서비스가 내려받은 자료 | 그 서비스 화면의 자료 카드 |

공간이 모자라면 어떻게 될까: 시스템 점검의 디스크 항목은 1GB보다 적게 남았거나 90%를 넘으면 경고합니다. 「시스템 설정 → 기본 설정」의 디스크 감시를 켜 두면 모자랄 때 알림이 옵니다. 정보 긁어오기, 내려받기, 변환은 모두 임시 공간을 쓰므로, 공간이 바닥나면 실패하고 작업 로그에 적힙니다.

## 4. 라이선스와 워터마크

> **워터마크**: 페이지 위에 겹쳐 보이는 반투명한 글자입니다. 유효한 라이선스가 없으면 온 사이트에 보이지만, **기능은 모두 그대로 씁니다**. 로그인, 시스템 설정, 사이트 인증, 백업도 영향이 없습니다.

> **값(키)**: 여기서는 이 설치의 라이선스를 보여 주는 문자열입니다.

오른쪽 위 아바타 → **사용자 센터**를 열고 맨 아래 「라이선스」카드가 이 절입니다. 상태와 권리는 누구나 볼 수 있지만, **켜기, 새로 고침, 써 보기, 멈추기, 지우기는 관리자만** 할 수 있습니다.

### 상태 읽는 법

화면에는 라이선스 상태(유효 / 무효), 켠 방식, 요금제, 유효 기간, 값(일부 가림), 최근 확인 성공 시각, 써 보기 상태, 이 설치의 이름표가 나옵니다. 위쪽 띠가 지금 처지를 설명합니다.

| 띠 | 뜻 | 할 일 |
| --- | --- | --- |
| 써 보는 중(남은 시간) | 7일 써 보기 안. 끝나면 워터마크가 돌아옵니다 | 끝나기 전에 켜기 |
| 써 보기 끝, 다시는 안 됨 | 자료 하나에 한 번뿐 | 라이선스를 켜기 |
| 라이선스 서비스에 못 붙어, 확인된 라이선스로 도는 중(오프라인 여유 기한) | 오프라인이지만 여유 안 | 네트워크를 살리고 새로 고침 |
| 서비스에 못 붙고 여유도 지남 | 네트워크가 필요 | 살리고 새로 고침 |
| 라이선스를 지금 쓸 수 없음 | 만료, 취소, 멈춤, 안 켬 등 | 라이선스 관리 화면에서 확인 |
| 요금제에 기본 권리가 없음 | 요금제 설정 문제 | 관리자에게 문의 |

### 켜는 세 가지 길

| 길 | 하는 일 |
| --- | --- |
| 온라인으로 켜기 | `AMMDS-XXXX-XXXX-XXXX-XXXX` 모양의 값을 넣고 「켜기」를 누릅니다. 서버가 바로 처리하고 워터마크가 사라집니다 |
| 오프라인으로 켜기 | 서버가 라이선스 서비스에 닿지 못할 때 씁니다. 「오프라인 켜기」를 누르면 제품 ID, 설치 이름표, 그대로 쓸 수 있는 명령이 나옵니다. 인터넷이 되는 다른 기기에서 돌리고 돌아온 JSON을 파일(64 KiB까지)로 올립니다 |
| 7일 써 보기 | 값이 필요 없습니다. 누르면 곧 이어지는 셈이 시작되고, 꺼 둔 동안에도 흐릅니다 |

켜진 설치는 「라이선스 바꾸기」를 누르기 전까지 켜는 칸을 숨깁니다. 바꾸면 지금 것을 갈아치우고, 써 보는 중에 켜면 써 보기가 곧 끝납니다.

### 몇 가지 규칙

| 동작 | 규칙 |
| --- | --- |
| 7일 써 보기 시작 | 설치 자료 하나에 한 번뿐. 온전한 라이선스가 있거나 이미 썼으면 버튼이 잿빛 |
| 온라인 새로 고침 | 한 번 확인합니다. 서비스가 안 될 때는 저장된 상태를 돌려줍니다 |
| 온라인 라이선스 멈추기 | 먼 곳이 자리를 돌려준다고 확인한 뒤에 내 자료를 지웁니다 |
| 내 것만 지우기 | 이 기기의 값과 표만 지웁니다. 먼 곳의 자리는 돌려주지 않고 써 본 기록도 남습니다 |

멈추기와 지우기는 모두 물어보고 되돌릴 수 없습니다. 회원은 계정의 표시이고 라이선스는 이 설치의 권리라 서로 다릅니다. 요금제 이름, 값, 권리 범위는 사는 화면과 라이선스 화면에 나오는 대로입니다.

## 5. 사용자와 로그인 안전

AMMDS는 내가 돌리는 관리자 한 명 앱입니다. 설치에 관리자가 하나뿐이니, 요점은 **그 하나뿐인 문을 지키는 것**입니다.

| 역할 | 뜻 |
| --- | --- |
| 관리자 | 설치의 라이선스를 바꾸고 조심스러운 동작을 할 수 있는 유일한 계정 |
| 사용자 | 들어와서 기능은 쓰지만 설치 단위 권리는 못 바꿈 |
| 손님 | 로그인 없이 공개 페이지를 봄. 공개 API 횟수 제한을 받음 |

처음 관리자는 첫 실행 때 만들어지고 이름은 정해져 있으며, 첫 비밀번호는 설치 때의 환경 값(기본은 널리 알려진 값)입니다.**설치를 마치면 제일 먼저 비밀번호를 바꾸세요.**

### 로그인이 어떻게 확인되는가

비밀번호는 보내기 전에 암호화되어, 글자 그대로는 브라우저를 나가지 않습니다. 사용자 이름, 비밀번호, 계정 상태를 보고, 2단계 인증이 켜졌으면 숫자도 봅니다.

> **로그인 표**: 들어온 뒤 받는 통행증입니다. 그다음 동작은 이것만 붙이면 되어 비밀번호를 다시 넣지 않아도 됩니다. 접근용은 120분, 새로 고치는 것은 30일입니다.

시도는 성공이든 실패든 로그인 로그에 남습니다.

비밀번호 규칙(로그인, 변경, 초기화 모두 같음): **6~22자, 영문 대문자와 소문자를 모두 담고, 숫자나 기호를 하나 이상** 넣습니다.

### 안전 살피기 네 걸음

1. **로그인 로그**를 열고 상태 "실패"로 줄줄이 시도가 있는지, 온 곳이나 장소로 낯선 로그인이 있는지 봅니다.
2. 이상하면 먼저 비밀번호를 바꾸고, 그다음 2단계 인증이나 패스키를 켭니다.
3. 막힌 계정은 아예 들어올 수 없고 이유가 적힙니다.
4. 비밀번호를 잊었으면 아래의 복구 값으로 초기화합니다.

### 2단계 인증

> **2단계 인증**: 비밀번호에 더해 휴대폰의 6자리 숫자를 넣습니다. 비밀번호가 새어도 들어올 수 없습니다.

**시스템 설정 → 보안 설정 → 2단계 인증**에 있습니다.

1. 큰 스위치를 켭니다.
2. 「켜기」를 누르고 네 걸음을 갑니다. 설명 읽기 → 코드 찍기(손으로 넣어도 됨)→ 인증 앱의 6자리 넣기 → 끝.
3. 끝나면 **8개의 한 번 쓰는 복구 코드**가 나옵니다. 복사하거나 파일로 받아 두고, 각각 한 번씩만 씁니다.
4. 끌 때도 확인이 필요합니다. 인증 앱의 지금 6자리, 또는 아직 안 쓴 복구 코드를 넣습니다.

복구 코드를 다 썼으면 한 번 끄고 다시 켜면 8개가 새로 나옵니다. 숫자가 통하지 않으면 기기 시각을 맞추세요. 이 방식은 시각이 맞는 것을 전제로 합니다.

### 패스키

**시스템 설정 → 보안 설정 → 패스키**에 있습니다. 지문, 얼굴, 기기 비밀번호로 들어옵니다. 켜려면 세 조건이 모두 맞아야 합니다.

| 조건 | 맞지 않을 때 |
| --- | --- |
| 도메인으로 들어옴(주소와 포트가 아니고, 내 컴퓨터도 아님) | 도메인을 연결하고 도메인으로 들어오라고 알립니다 |
| 암호화된 접속(주소가 암호화 방식으로 시작) | 브라우저가 인증을 주지 않는다고 알립니다 |
| 브라우저가 이 인증을 받아줌 | 더 새로운 브라우저로 바꾸라고 알립니다 |

조건이 맞으면 「만들기」를 누르고 기기의 인증(운영 체제의 생체 인식, 휴대폰 등)을 확인하면 목록에 남습니다. 이름(고칠 수 있음), 만든 시각, 마지막으로 쓴 때가 보이고 고치기와 삭제가 있습니다. 지우면 그 기기는 이 길로 들어올 수 없습니다. 패스키와 남의 계정 로그인은 **추가 숫자를 요구하지 않습니다**.

### 한 번에 로그인

**시스템 설정 → 보안 설정 → 한 번에 로그인**에서 남의 계정으로 들어오기를 정합니다.

1. 화면에 나온 되돌아올 주소를 복사해 상대의 허용 목록에 넣습니다.
2. 「앱 만들기」를 누르고 이름, 아이콘, 버튼 글, 클라이언트 ID와 비밀, 잇는 항목(기본은 그 사람을 가리키는 값)을 넣습니다.
3. 저장하면 내 남의 계정을 연결할 수 있고, 언제든 풀거나 멈출 수 있습니다.
4. 로그인 화면에 그 버튼이 생깁니다.

클라이언트 비밀은 내 데이터베이스에만 저장되고 화면에 다시 보여 주지 않습니다. 앱을 지우면 그 입구가 바로 죽습니다.

### 보안 설정 항목

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 패스키 큰 스위치 | 지문이나 얼굴로 들어오는 것을 허용할지 | 기본은 꺼짐 |
| 2단계 인증 큰 스위치 | 추가 숫자를 물을지 | 기본은 꺼짐이고 비밀번호만 |
| 손님 횟수 제한 | 로그인하지 않은 이의 공개 API 횟수 상한(분당, 기본 100) | 시스템이 직접 읽고 화면에는 자리가 없습니다 |

## 6. 값과 비밀번호 되찾기

**시스템 관리 → 값 관리**에서 다루는 것은 **남의 프로그램이 쓸 값**입니다.

| 열 | 뜻 |
| --- | --- |
| 이름 | 만들 때 적은 쓰임. 옆에 "정상" 또는 "만료" |
| 값 | 꼬리표를 누르면 전체가 복사됩니다 |
| 종류 | 브라우저 확장 / API 부름 / 만화 읽기 앱 |
| 만료 시각 | 그때 저절로 못 쓰게 되고 꼬리표가 빨개집니다 |
| 동작 | 삭제(다시 물어보고 되돌릴 수 없음) |

> **API 키**: 남의 프로그램에 주는 문자열입니다. 이것을 붙여 부르면 "허락된 부름"임을 증명할 수 있어 계정 비밀번호가 필요 없습니다.

만들 때 넣는 것은 이름(필수), 종류(필수), 만료 시각(비우면 오래 감. 넣는다면 지금보다 10분 이상 뒤)입니다.

:::warning[종류는 섞어 쓸 수 없습니다]
세 종류는 제각기 자기 자리에서만 먹습니다. API 값은 공개 API에서만 통하고 관리 화면을 열어 주지 않으며, 만화 읽기 값은 그 자리만 맡습니다. 잘못 쓰면 "허락되지 않음"을 받습니다. 공개 API는 [시스템 설정 항목 하나씩 보기](./config.md)에서 "API 공개"도 켜야 합니다.
:::

**관리자 비밀번호 되찾기**는 다른 길이며, 한 번 쓰는 복구 값을 씁니다. 데이터 폴더의 파일로만 존재하고 화면에도 로그에도 나오지 않습니다. 로그인 화면의 「비밀번호를 잊었어요」에서 복구 값과 새 비밀번호를 넣어 보내면, 성공할 때 파일이 지워져 한 번만 쓰입니다. 파일이 없다면 다시 켜면 새로 만들어집니다.

새 비밀번호도 같은 힘의 규칙을 따릅니다. 자주 나오는 알림은 이렇습니다. "복구 값이 없습니다"는 이미 썼거나 아직 없는 것, "복구 값이 다릅니다"는 내용이 안 맞는 것, "비밀번호가 너무 단순합니다"는 규칙 미달, "관리자 계정이 이상합니다"는 관리자가 한 명이 아닌 상태입니다.

평소 바꾸기는 사용자 센터(지금 비밀번호가 필요)에서 합니다. 「비밀번호를 잊었어요」와는 다른 길입니다.

## 7. 뒤에서 도는 정기 작업

**시스템 관리 → 예약 작업**을 열면 시스템에 들어 있는 정기 작업을 모두 볼 수 있습니다. 얼마나 자주 도는지, 지난번이 잘 됐는지, 지금 도는지가 보이고, 한 번만 손으로 돌릴 수도 있습니다.

목록에는 작업 이름(아래에 소속이 나옴), 실행 간격(사람 말. 원래 식은 마우스를 올리면 보임), 돌아가는 상태, 지난 실행 시각, 그리고 「실행」이 있습니다. 「실행」을 누르면 바로 돌아오고 뒤에서 시작합니다. 도는 중에는 같은 작업을 두 번 시작할 수 없습니다.

> **Cron**: "언제 돌릴까"를 한 줄로 적은 식입니다. "매일 04:45", "5분마다"처럼 씁니다. 화면은 사람 말로 옮기고, 모르면 그대로 보여 줍니다.

이 페이지는 각 작업의 **가장 최근 한 번**의 시각과 결과만 간직하고, 지난 목록은 주지 않습니다. 전체 흐름을 보려면 **작업 로그**에서 종류나 상태로 걸러내고 「자세히」로 줄줄이 내역을 보세요.

:::warning[큰 스위치를 꺼도 다 멈추지는 않습니다]
큰 스위치(설치 때의 환경 값, 기본은 켜짐)를 끄면 화면에 "예약 작업이 꺼졌습니다"라고 나오고 손으로 돌리는 것도 거절되며, 설정으로 등록된 주기 작업(추가 시드 자동 실행 같은 것)은 등록되지 않습니다. 다만 프로그램 안에 직접 적힌 작업은 그대로 돕니다. 어떤 자동을 아예 멈추려면 그 기능의 스위치도 함께 꺼야 합니다.
:::

## 문제가 생기면

- **경고가 잔뜩 나왔다**: 먼저 "이상"을 고치고, 그다음 "설정이 필요" 꼬리표가 붙은 것을 처리한 뒤 「다시 점검」으로 확인하세요.
- **시스템 시각이 크게 어긋났다**: 컴퓨터 시각을 맞추고 다시 켜고, 중계에서 빼놓은 목록에 시각 확인용 도메인이 남아 있는지도 보세요.
- **작업이 "도는 중"에서 안 움직인다**: 작업 로그에서 같은 진행에 멈췄는지 보고, 필요하면 취소하고 다시 돌리세요.
- **디스크 경고가 떴다**: 3절의 자리에서 치우세요. 데이터 폴더의 파일을 손으로 지우지 마세요.
- **워터마크가 사라지지 않는다**: 라이선스 상태와 띠를 보고 그대로 하세요. 기능이 막히지 않으니 그냥 써도 됩니다.
- **들어올 수 없다**: 로그인 로그에서 이유를 보세요. 관리자 비밀번호를 잊었다면 복구 값으로 초기화합니다.
