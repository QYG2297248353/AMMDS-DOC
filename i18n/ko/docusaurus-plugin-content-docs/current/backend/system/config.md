# 시스템 설정 항목 하나씩 보기

시스템 설정에는 사이트 전체의 동작 갈래가 모여 있습니다. 어느 도메인으로 들어오는지, 사이트 이름이 무엇인지, 통신을 중계할지, 알림을 보낼지, 화면이 어떤 색인지, 로그인을 얼마나 엄격히 할지, 뒤의 요청을 얼마나 기다릴지입니다. 이 페이지에서는 일곱 영역을 항목마다 풀어 씁니다.

## 먼저 확인

**시스템 관리 → 시스템 설정**을 엽니다. 위쪽에 일곱 탭이 있고 한 번에 하나만 보입니다. 탭마다 입력한 내용을 지키고 있으며, 다시 읽으면 마지막에 보던 영역으로 돌아옵니다.

| 탭 | 다루는 것 |
| --- | --- |
| 기본 설정 | 도메인 연결, 인스턴스 연동, API 공개, 시스템 모드, 디스크 감시, 광고 |
| 겉모습 | 첫 화면, 테마, 배경과 색, 추모 모드 |
| 알림 설정 | 알림 큰 스위치, 메시지 종류, 밤에는 조용히 |
| 네트워크 설정 | 중계 스위치, 방식, 호스트와 포트, 인증, 빼놓을 목록 |
| 관리 화면 설정 | 관리 화면 요청 제한 시간(브라우저에 저장) |
| 보안 설정 | 패스키, 2단계 인증, 한 번에 로그인 |
| 사이트 설정 | 사이트 정보, 등록 번호, 바닥글 바로 가기, 검색과 공유 보이기 |

바꾼 것은 설정 표에 바로 적히고, 파일을 고칠 일은 없습니다. 시스템 모드를 빼고는 저장하면 곧바로 반영됩니다.

## 1. 기본 설정

### 도메인 연결(세 단계, 순서를 바꾸지 마세요)

연결 전에는 "연결 안 됨", 연결 후에는 "연결됨"으로 나옵니다.

| 단계 | 버튼 | 하는 일 |
| --- | --- | --- |
| 1 | 시험 | 그 도메인이 이 서버를 가리키는지 확인합니다. 연결은 적지 않습니다 |
| 2 | 확인용 값 만들기 | 서버가 값을 내려 주고, 넣어야 할 글자 기록(이름은 도메인, 값은 그 값)을 화면에 보여 줍니다 |
| 3 | 확인하고 연결 | 서버가 그 글자 기록을 맞춰 보고, 통과해야 도메인을 적습니다 |

> **글자 기록**: 도메인 설정에 적는 글자로, "이 도메인은 내 것입니다"라고 증명할 때 흔히 씁니다. 도메인을 산 곳의 관리 화면에서 넣습니다.

> **DNS**: 도메인을 서버 주소로 바꿔 주는 물음 서비스입니다. 기록을 넣고 나면 온 세상에서 찾을 수 있게 되기까지 조금 걸립니다.

:::warning[연결할 도메인으로 먼저 열기]
연결하기 전에, 연결하려는 도메인으로 AMMDS를 먼저 여세요. 화면은 넣은 도메인과 지금 들어온 도메인을 견줍니다(통신 방식, 경로, 포트, 대소문자는 무시). 다르면 거절합니다. 글자 기록 확인을 할 수 없기 때문입니다.
:::

### 설정 항목: 기본 설정

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 도메인 연결 | 남들이 어느 도메인으로 들어올지. 위의 세 단계로 정합니다 | 필요 없음. 확인이 통하면 바로 적힙니다 | `IP:포트` 로만 들어올 수 있고, 도메인이 필요한 기능(패스키, 인스턴스 연동)은 켤 수 없습니다 |
| 인스턴스 연동 | 다른 AMMDS와 자료를 나눌지. 켜려면 도메인 연결과 별명·메일·휴대폰이 있어야 합니다 | 필요 없음 | 기본은 꺼짐이고 나누지 않습니다. 조건이 모자라면 스위치가 돌아오며 이유가 나옵니다 |
| API 공개 | 밖으로 API를 열지. 끄면 열쇠가 있어도 남의 프로그램이 못 씁니다 | 필요 없음 | 기본은 꺼짐이고 밖에서는 못 씁니다 |
| 시스템 모드 | 세 가지: 전체 모드(공개 사이트 + 관리 화면), 관리 화면만, API만 | **다시 시작 필요** | 기본은 전체 모드 |
| 서비스 주소 | 밖에 알리는 내 주소. 설명서나 찾기에 쓰이고, 로그인할 때 지금 주소로 덮어씁니다 | 필요 없음 | 안에 든 주소를 씁니다 |
| 디스크 감시 | 켜면 남은 공간을 주기적으로 살피고 모자라면 알립니다 | 필요 없음 | 기본은 꺼짐이고, 공간이 모자라도 알려 주지 않습니다 |
| 광고 보이기 | 페이지에 광고를 띄울지 | 필요 없음 | 기본은 켜짐. 돈을 내지 않은 사용자가 끄면 거절되고 "유료 사용자가 아니면 끌 수 없습니다"라고 나옵니다 |

## 2. 사이트 설정

이 영역에는 「기본 설정」과 「검색과 공유 보이기」두 개의 작은 탭이 있습니다.

### 사이트 정보와 등록 번호

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 사이트 이름 | 공개 페이지 제목과 공유 요약에 나오는 이름 | 필요 없음 | 제목에 사이트 이름이 없습니다 |
| 부제목 | 이름 아래의 작은 줄 | 필요 없음 | 보이지 않습니다 |
| 사이트 설명 | 사이트를 한 줄로 소개하는 글 | 필요 없음 | 공유 요약이 비게 됩니다 |
| 회사 이름 | 바닥글 등에 나오는 운영 주체 | 필요 없음 | 보이지 않습니다 |
| ICP 등록 번호와 조회 주소 | 번호와 눌렀을 때 갈 곳 | 필요 없음 | 번호가 비면 보이지 않습니다 |
| 공안 등록 번호와 조회 주소 | 같음. 공안 등록입니다 | 필요 없음 | 번호가 비면 보이지 않습니다 |
| 사업자 등록 번호와 조회 주소 | 같음. 사업자 등록입니다 | 필요 없음 | 번호가 비면 보이지 않습니다 |
| 저작권 문구 | 바닥글의 저작권 글 | 화면에 고치는 자리가 없습니다 | 정해진 내용입니다 |
| 바닥글 바로 가기 | "이름 + 주소"를 한 줄씩. 위아래로 옮겨 순서를 정하며 최대 20개 | 필요 없음 | 바로 가기가 없습니다. 저장할 때 이름이나 주소가 빈 줄은 버려집니다 |

### 검색과 공유 보이기

> **SEO**: 찾는 곳(검색 엔진)이 잘 담아 가고 보기 좋게 보여 주도록 하는 설정입니다.

> **OG**: 소셜이 읽는 글입니다. 링크를 공유할 때 카드의 제목·그림·요약을 정합니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 검색 제목 | 검색 결과의 큰 제목 | 필요 없음 | 사이트 이름으로 대신합니다 |
| 검색 키워드 | 쉼표로 이은 낱말들 | 필요 없음 | 검색 엔진에 키워드가 넘어가지 않습니다 |
| 검색 설명 | 검색 결과 아래의 설명 | 필요 없음 | 요약이 빕니다 |
| 공유 제목 | 소셜에 공유할 때 카드의 제목 | 필요 없음 | 검색 제목으로 돌아갑니다 |
| 공유 설명 | 카드의 글 | 필요 없음 | 카드에 설명이 없습니다 |
| 공유 그림 | 카드의 그림 | 필요 없음 | 카드에 그림이 없습니다 |
| 카드 모양 | 작은 그림 카드 또는 큰 그림 카드 | 필요 없음 | 기본 모양입니다 |
| 수집기 규칙 | 네 가지 정해진 것 중 고르기, 또는 직접 쓰기 | 필요 없음 | 수집기를 막지 않습니다 |
| 대표 주소 | 어느 주소가 원본인지 검색 엔진에 알려 겹쳐 담기는 것을 막습니다 | 필요 없음 | 지금 들어온 주소를 씁니다 |

저장하면 공개된 데에는 바로 반영되고, 페이지 제목 같은 것은 다음에 열거나 새로 고칠 때 바뀝니다.

## 3. 네트워크 설정

> **중계(프록시)**: 프로그램이 먼저 다른 서버에 붙고, 그 서버가 밖으로 나가 주는 방식입니다. 곧장 나갈 수 없는 환경에서 씁니다.

> **CIDR**: 주소의 무리를 짧게 쓰는 법입니다. 한 줄로 그 무리 전체를 나타냅니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 중계 스위치 | 중계를 쓸지 | 필요 없음. 저장하면 통신 부품을 바로 다시 만듭니다 | 기본은 꺼짐이고 곧장 붙습니다 |
| 중계 방식 | HTTP, SOCKS4, SOCKS5 세 가지. 중계를 주는 쪽에 물어보세요 | 필요 없음 | 방식이 다르면 붙지 않습니다 |
| 중계 호스트 | 중계 서버의 주소 | 필요 없음 | 스위치가 켜졌는데 호스트가 비면 시스템 점검에서 이상으로 적힙니다 |
| 중계 포트 | 숫자. 1~65535 | 필요 없음 | 같으며, 범위를 벗어나도 이상으로 적힙니다 |
| 중계 계정 | 중계가 로그인을 요구하면 넣습니다 | 필요 없음 | 로그인이 필요한 중계는 붙지 않습니다 |
| 중계 비밀번호 | 같습니다 | 필요 없음 | 같습니다 |
| 빼놓을 목록 | 중계를 거치지 않을 곳. 도메인, 주소, 주소 무리, `*.cn` 같은 별표도 되고, "우리 네트워크"·"안쪽 주소"·"특정 도메인" 세 가지 정해진 것에서 골라도 됩니다 | 필요 없음 | 기본으로 내 컴퓨터, 사설 대역, 시각을 맞추는 데 쓰는 몇몇 도메인이 들어 있습니다 |

호스트와 포트는 스위치를 켠 뒤에 고칠 수 있습니다. 빼놓을 목록에서 시각 확인용 도메인은 지우지 마세요. 시각 확인이 실패할 수 있습니다.

:::tip[중계는 바로 바뀝니다]
중계 설정을 저장하면 통신 부품을 다시 만들고 안에 든 자료 서비스도 다시 시작합니다. 앱 전체를 다시 켤 필요는 없습니다. 닿는지는 대시보드의 네트워크 점검에서 곳마다 확인하세요.
:::

## 4. 알림 설정

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 알림 큰 스위치 | 알림을 아예 보낼지 | 필요 없음 | 기본은 꺼짐이고 아무것도 안 가며, 시스템 점검은 "사용 안 함"으로 적습니다 |
| 메시지 종류 | 보낼 종류에 표시: 시스템, 구독, 내려받기, 등록, 인증, 회원, 작품 정보, 출연자 정보 | 필요 없음 | 표시하지 않은 종류는 가지 않습니다 |
| 밤에는 조용히 | 켜면 22:00~08:00에는 보내지 않습니다 | 필요 없음 | 기본은 꺼짐이고 밤에도 갑니다 |

알림을 보내는 갈래마다 필요한 값은 통합 앱에서 정합니다. 큰 스위치가 켜졌는데 갈래가 하나도 없으면 시스템 점검이 경고를 냅니다.

## 5. 겉모습

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 첫 화면을 먼저 | 사이트를 열 때 관리 화면 말고 공개 첫 화면을 먼저 보여 줍니다 | 필요 없음 | 기본은 관리 화면입니다 |
| 테마 | 화면 테마. 누르면 바뀝니다 | 필요 없음 | 기본 테마입니다 |
| 배경과 색 | 배경 그림과 기본 색 | 필요 없음 | 기본 배경과 색입니다 |
| 추모 모드 | 시작과 끝을 정하면 그동안 흑백으로 보입니다 | 필요 없음 | 쓰지 않습니다 |

이 영역은 색과 배경만 바꾸고 화면 배치는 바꾸지 않습니다.

## 6. 보안 설정

> **패스키**: 지문, 얼굴, 기기 비밀번호로 비밀번호 없이 들어오는 방식입니다. 도메인으로 암호화 접속을 해야 하고 브라우저가 받아줘야 합니다.

> **2단계 인증**: 비밀번호에 더해 휴대폰의 6자리 숫자를 넣습니다. 비밀번호가 새도 들어올 수 없습니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 다시 시작 | 비우면 |
| --- | --- | --- | --- |
| 패스키 | 지문·얼굴·기기 비밀번호로 들어오는 것을 허용할지 | 필요 없음 | 기본은 꺼짐. 조건이 모자라면 버튼이 잿빛입니다 |
| 2단계 인증 | 켜면 네 단계: 설명 읽기 → 코드 찍기(손으로 넣어도 됨)→ 6자리 넣기 → 끝. 마지막에 8개의 한 번 쓰는 복구 코드가 나옵니다 | 필요 없음 | 기본은 꺼짐이고 비밀번호만 씁니다 |
| 한 번에 로그인 | 남의 계정으로 들어오기. 나온 되돌아올 주소를 상대의 허용 목록에 넣고, 앱을 만듭니다(이름, 아이콘, 버튼 글, 클라이언트 ID와 비밀, 잇는 항목) | 필요 없음 | 기본은 남의 계정 버튼이 없습니다 |

둘을 기억하세요. 패스키와 남의 계정 로그인은 **추가 숫자를 요구하지 않고**, 비밀번호로 들어올 때만 추가로 묻습니다. 남의 앱을 지우면 그 입구가 바로 죽습니다.

| --- | --- | --- | --- |
| 자료 검색 제한 시간 | 찾을 때 최대 몇 초 기다릴지. 최소 12 | 필요 없음. 지금 브라우저에만 먹힙니다 | 기본값이 쓰입니다. 너무 작으면 찾기가 끝나기 전에 포기합니다 |

브라우저에 저장되므로 서버에는 적히지 않고, 다른 기기나 브라우저로는 넘어가지 않습니다.

## 화면에서 고칠 수 없는 설정

다음은 설치할 때의 환경 값이나 시작 인자로 정해지며 화면에 고치는 자리가 없고, 바꾼 뒤에는 다시 시작해야 합니다. 서비스 포트, 기다리는 주소, 한 파일 올리기 한도, 한 요청 한도, 데이터베이스 연결, 로그 단계, 예약 작업 큰 스위치, 폴더 지켜보기, 디스크 경고 기준, 그리고 로그인하지 않은 이의 공개 API 제한(기본은 분당 100번)입니다.

| 바꾼 것 | 반영되는 방식 |
| --- | --- |
| 중계 설정 | 바로. 통신 부품을 다시 만들고 안에 든 자료 서비스를 다시 시작합니다 |
| 플러그인 켜기·끄기, 안에 든 서비스 우선 바꾸기 | 안에 든 자료 서비스가 바로 다시 시작됩니다 |
| 사이트 구독 설정 | 그 구독을 맡은 스케줄이 바로 다시 만들어집니다 |
| 시스템 모드 | 다시 시작 필요 |
| 사이트 정보와 검색·공유 보이기 | API에는 바로, 페이지는 새로 고칠 때 |
| 환경 값 | 다시 시작 필요(컨테이너면 다시 만들기) |

## 문제가 생기면

- **저장해도 안 바뀐다**: 다시 시작이 필요한 것(시스템 모드, 환경 값)이 아닌지 보세요. 사이트 정보 같은 것은 새로 고쳐야 합니다.
- **도메인이 연결되지 않는다**: 그 도메인으로 열었는지, 기록이 들어가고 찾을 수 있는지 확인하고 「시험 → 값 만들기 → 확인하고 연결」을 다시 하세요.
- **중계를 켜니 느리거나 안 붙는다**: 방식, 호스트, 포트를 확인하고 안쪽 사이트를 빼놓을 목록에 넣으세요.
- **알림이 아예 안 온다**: 큰 스위치와 메시지 종류를 보고, 통합 앱에서 갈래의 값이 들어갔는지도 확인하세요.
- **패스키 버튼이 안 눌린다**: 도메인으로 암호화 접속을 하는지, 브라우저가 충분히 최신인지, 큰 스위치가 켜졌는지 보세요.
- **반영됐는지 확신이 없다**: [시스템 점검, 로그, 저장소, 라이선스와 사용자](./maintenance.md)에서 전체 점검을 돌리면 잘못된 것이 목록으로 나옵니다.
