# 스크레이핑: 작품 정보 자동으로 채우기

스캔은 파일을 등록만 하지만, 스크레이핑은 AMMDS가 「어느 작품인지」 알아내고 표지·줄거리·출연진·태그를 채우고 설명 파일과 이미지를 만든 뒤 지정한 서식대로 놓는 일까지 합니다. 시작 방법, 정보 출처, 생기는 파일, 막혔을 때의 대처, 그리고 빠진 것 보충과 각 설정을 알려 줍니다.

## 먼저 알아 두기

> **스크레이핑**: 자료 사이트에서 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다.

> **메타데이터**: 작품의 표지·줄거리·출연진·태그 같은 설명 정보입니다.

> **작품 번호 / 식별 코드**: 파일명에 들어 있는 식별 번호로, AMMDS는 이것으로 작품을 알아봅니다.

> **NFO**: 동영상과 같은 곳에 두는 작은 설명 파일로 제목·출연진 등이 적혀 있습니다. 재생기도 읽습니다.

> **스크레이퍼**: 작품 정보를 조회할 수 있는 출처입니다. 자료 사이트나 내 기기의 기존 데이터를 말하며 여러 개를 고르면 함께 조회합니다.

> **동시 처리**: 여러 일을 한꺼번에 진행하는 것입니다. 스크레이퍼는 동시에 조회하므로 하나가 멈춰도 나머지는 진행됩니다.

> **자리표시자**: 서식 문자열 안에서 `{}`로 감싼 표시로, 배우 이름·작품 번호·제목 같은 실제 내용으로 바뀝니다.

## 순서대로 해 보기

### 1. 시작 전에 준비하기

1. 자료 출처 플러그인을 하나 이상 켜고 「任务管理 → 任务配置 → 影视刮削规则 → 刮削器（작업 관리 → 작업 설정 → 영상 스크레이핑 규칙 → 스크레이퍼）」에서 체크합니다.
2. 스캔에서 대상 파일이 「刮削入库（등록 대기）」에 등록됐고 그 경로에 아직 접근할 수 있는지 확인합니다. [스캔: AMMDS가 내 파일을 알게 하기](./scan.md) 참고.
3. 자동 정리를 원하면 정리 대상 폴더가 있고 쓸 수 있는지 먼저 확인합니다.
4. NFO와 이미지를 만들려면 해당 스위치와 항목이 설정됐는지 확인합니다.

스크레이핑은 **다운로더에 의존하지 않습니다**. 다운로더는 구독과 수동 전송에만 영향을 주고 정보 대조에는 관계없습니다.

:::note[한 번에 하나만 실행됩니다]
동시에 실행할 수 있는 스크레이핑 작업은 하나뿐입니다. 실행 중에 다시 넣으면 거부되고 「重复执行 - 刮削任务运行中（중복 실행·스크레이핑 실행 중）」이 뜹니다.
:::

### 2. 실행 방법 고르기

任务管理 → 刮削入库 → 影视刮削（작업 관리 → 등록 대기 → 영상 스크레이핑）으로 갑니다(시리즈는 「剧集刮削（시리즈 스크레이핑）」). 다음 중 고를 수 있습니다.

| 항목 | 범위 | 하는 일 |
| --- | --- | --- |
| 刮削整理（스크레이핑 + 정리） | 처리 대기 중인 모든 영상 | 스크레이핑과 파일 정리를 함께 |
| 仅刮削（스크레이핑만） | 처리 대기 중인 모든 영상 | 정보 대조와 NFO·이미지 생성만. 동영상은 옮기거나 이름을 바꾸지 않습니다 |
| 选择整理（선택해 정리） | 체크한 항목 | 일괄 처리. 한 번에 최대 120건 |
| 自动刮削（자동 스크레이핑） | 설정한 간격 | 영상과 시리즈에 각각 스위치·간격이 있고, 켜면 기본 3분마다 대기 항목을 확인합니다 |
| 查漏补缺（빠진 것 보충） | 지정한 작업의 원본 폴더 | 스캔 뒤 빠진 이미지와 NFO만 채우고 폴더 구성은 바꾸지 않습니다. 아래 전용 절 참고 |

### 3. 정보는 어디서 오나

「刮削器（스크레이퍼）」는 여러 개 고를 수 있는 목록입니다. 기본으로 `本地(默认)`(로컬), `MetaTube(插件)`, `ThePornDB(插件)`, `Stash(插件)`, `FANZA_DMM(插件)`, `M-Team_DMM(插件)`, `TheJavDB(插件)`, `R18Dev(插件)`, `TMDB(插件)`가 나옵니다.

실제 동작은 이렇습니다.

1. 체크한 스크레이퍼에 **동시에** 조회를 보냅니다. 하나가 실패하거나 시간이 초과돼도 나머지는 멈추지 않습니다.
2. 각 출처가 찾은 작품을 로컬 영상 라이브러리에 넣고, 시스템이 로컬 대조 결과를 다시 읽습니다.
3. 다시 읽을 때 TMDB가 켜져 있고 체크돼 있으면 그 결과를 우선하고, 아니면 JAV 번호는 MetaTube, 서양 번호는 ThePornDB로 갑니다.
4. Stash, FANZA_DMM, M-Team_DMM, TheJavDB, R18Dev는 보조 출처로, 맞으면 역시 로컬에 들어가고 작품 번호나 파일 지문으로 기록을 찾습니다.
5. 번호 계열이 모두 못 찾고 TMDB를 쓸 수 있으면 「제목 + 연도」로 일반 영화 대조를 한 번 더 시도합니다.

:::tip[이미 정리된 라이브러리에는 「로컬 데이터 우선」]
「本地数据优先（로컬 데이터 우선）」을 켜면 이미 연결돼 있고 연결된 작품이 남아 있는 항목은 인터넷에 접속하지 않고 그대로 재사용합니다. 연결이 끊어졌을 때만 다시 조회합니다. 빠진 항목만 채우고 싶을 때 알맞습니다.
:::

:::warning[출처마다 잘하는 분야가 다릅니다]
MetaTube는 서양 번호를 지원하지 않습니다. 서양 작품에는 ThePornDB나 TMDB를 켜 주세요. 쓸 수 있는지는 플러그인 활성화, 사이트 계정 유효성, 네트워크 연결에도 달려 있습니다.
:::

### 4. 무엇이 채워지나

대조에 성공하면 출처가 돌려준 항목을 작품 기록에 넣고 설정대로 파생 정보도 채웁니다.

| 구분 | 내용 |
| --- | --- |
| 기본 항목 | 제목, 원제, 줄거리, 공개일, 상영 시간, 평점, 감독, 제작사, 시리즈 |
| 출연진 | 배우 이름, 별명, 초상, 작품 연결. 「演员刮削（배우 스크레이핑）」을 끄면 건너뜁니다 |
| 태그 / 분류 | 「自动标签（자동 태그）」「自动分类标签（자동 분류 태그）」설정에 따라 해상도·제작사·식별 코드·발행일·배우·모자이크·중문 자막·해제본 등을 추가 |
| 이미지 | 포스터, 배경, 섬네일, 스틸. 고화질 표지도 고를 수 있습니다 |
| 번역 | 「字段翻译（항목 번역）」을 켜면 시스템 번역 설정으로 제목·줄거리 등을 번역합니다 |
| 작품 번호 | 식별 코드와 보완한 번호를 섞어 출력해 사이트마다 다른 명명에 대응할 수 있습니다 |

「NFO 字段（NFO 항목）」은 NFO를 만들 때 어떤 태그를 쓸지 정합니다. 기본으로 식별 코드 `num`을 포함한 대부분 항목이 들어갑니다. 필요 없는 태그는 설정에서 뺄 수 있습니다.

### 5. 정리 뒤의 폴더와 파일명

어디에 둘지, 무엇이라 부를지는 「影视刮削规则（영상 스크레이핑 규칙）」의 두 서식 문자열이 정합니다.

| 설정 항목 | 기본값 | 내용 |
| --- | --- | --- |
| 整理目录格式（폴더 서식） | `${actor}/${number}` | `/` 하나가 폴더 한 단계가 됩니다 |
| 整理文件名格式（파일명 서식） | `${number}` | 이름 본체만 쓰고 확장자는 넣지 않습니다 |

쓸 수 있는 자리표시자는 배우, 작품 번호, 제목, 날짜, 연도, 월, 일, 모자이크, 해상도, 감독, 제작사 등입니다. 끝이 `_safe`인 종류는 경로 구분자를 공백으로 바꿉니다. 작성법은 패널 위쪽의 「帮助（도움말）」에서 볼 수 있습니다.

:::warning[이름이 길면 잘립니다]
파일명이 200바이트를 넘으면 잘리고, 정리 뒤 상대 경로가 3600바이트를 넘으면 정리가 중단됩니다. 서식에 자리표시자를 너무 많이 넣으면 쉽게 걸립니다.
:::

### 6. 어떤 파일이 늘어나나

스크레이핑 뒤 정리 대상에 이런 파일이 생길 수 있습니다.

| 파일 | 내용 |
| --- | --- |
| `<파일명>.nfo` | NFO 항목 설정대로 만들며 동영상과 같은 이름 |
| `<파일명>-poster.jpg` | 표지. 모자이크 있는 작품은 세로 2:3을 되도록 유지합니다 |
| `<파일명>-fanart.jpg` | 배경. 모자이크 있는 작품은 가로를 되도록 유지합니다 |
| `<파일명>-thumb.jpg` | 섬네일. 모자이크 있는 작품은 가로를 되도록 유지합니다 |
| `<파일명>.srt` | 외부 자막. 같은 이름이 이미 있으면 덮어쓰지 않습니다 |
| `extrafanart/fanart1.jpg` … | 「刮削剧照（스틸 수집）」을 켰을 때 기록합니다. 폴더 이름은 설정 가능 |

이미지 다운로드 실패로 정리를 멈출지는 「允许图片下载失败（이미지 실패 허용）」가 정합니다. 고화질 표지를 켜면 고화질 이미지를 우선합니다. 모자이크 있는 작품에서 표지와 배경 방향이 바뀌어 나오면 시스템이 두 파일을 바꿔 맞추려 하고, 그래도 안 맞으면 도구 상자의 「海报裁剪（포스터 자르기）」로 직접 처리할 수 있습니다.

### 7. 어디까지 진행됐는지 보기

「刮削入库（등록 대기）」목록의 「查看步骤（단계 보기）」를 열면 타임라인에 각 회차의 단계·상태·소요 시간·오류가 나옵니다. 주요 단계는 `文件校验`(파일 검사), `番号识别`(번호 판별), `数据源检索`(출처 조회), `元数据匹配`(메타데이터 대조), `演员刮削`(배우 수집), `文件移动`(파일 이동)이고, 정리 단계에 `海报下载`(포스터), `背景图下载`(배경), `缩略图下载`(섬네일), `NFO生成`(NFO 생성)이 있습니다. 그 밖에 `读取本地 NFO`(로컬 NFO 읽기), `手工绑定`(수동 연결), `查漏补缺`(빠진 것 보충) 같은 특수 단계도 있습니다.

순서는 타임라인이 기준입니다. 같은 작품에 여러 회차가 있을 수 있고, 서랍 위쪽에서 지난 회차로 바꿀 수 있으며 기본은 최신 회차입니다.

## 빠진 것 보충: 모자란 것만 채우고 영상은 그대로

「查漏补缺（빠진 것 보충）」은 정보가 거의 갖춰져 있고 이미지나 NFO 몇 개만 빠졌을 때 씁니다. **폴더 구성과 파일명을 바꾸지 않고 동영상 파일도 옮기지 않으며**, 빠진 이미지와 NFO만 채웁니다.

자주 쓰는 두 상황:

- 스캔 작업의 「整理模式（정리 모드）」를 「查漏补缺（빠진 것 보충）」으로 한 경우: 스캔 직후 이 모드로 채웁니다. [스캔: AMMDS가 내 파일을 알게 하기](./scan.md) 참고.
- 이미 스크레이핑한 작품에 이미지나 NFO가 빠진 경우: 「刮削入库（등록 대기）」에서 작업에 「查漏补缺（빠진 것 보충）」을 쓰면 부속 파일만 추가됩니다.

스크레이핑에 실패한 작품은 「待刮削（처리 대기）」로 남고 자동으로 완료되지 않습니다. 빠진 것을 채운 뒤에도 다시 돌려야 할 것은 따로 재실행하세요.

## 스크레이핑 설정 항목 하나씩

규칙 패널은 **任务管理 → 任务配置（작업 관리 → 작업 설정）**에 있고 「影视刮削规则（영상 스크레이핑 규칙）」과 「剧集刮削规则（시리즈 스크레이핑 규칙）」두 탭으로 나뉩니다. 고친 뒤 「保存配置（설정 저장）」으로 항목마다 제출하고, 「刷新配置（설정 다시 읽기）」는 저장 안 한 변경을 버리고 다시 불러옵니다. 입력칸·숫자칸·스위치·드롭다운 중 무엇이 나올지는 화면이 정합니다.

### 영상 스크레이핑 규칙

| 그룹 | 설정 항목 |
| --- | --- |
| 자료 출처 | 스크레이퍼, 로컬 데이터 우선, 브랜드 접두사 필터 |
| 정리 | 폴더 서식, 파일명 서식 |
| 메타데이터 | 자동 태그, 자동 분류 태그, 항목 번역, 번호 혼합, 배우 스크레이핑 |
| NFO | NFO 항목(NFO에 쓸 태그를 정함) |
| 이미지 | 고화질 표지, 스틸 수집, 스틸 폴더, 이미지 실패 허용 |
| 자막 | 외부 자막 검색 |
| 성능 | 멀티스레드 실행, 최대 스크레이핑 스레드 수 |

### 시리즈 스크레이핑 규칙

시리즈 설정은 한 탭에 모여 있습니다. 시리즈 스크레이퍼(로컬, TMDB, Bangumi, TheTVDB), 자동 스크레이핑 간격, 일치 임계값과 가중치, 시즌 매핑 자동 발견, 시즌별 회차 수, 폴더 / 파일명 서식, 시즌 포스터 이름, NFO 항목, 배우 스크레이핑, 항목 번역, 요청 간격과 스레드 수입니다.

## 시리즈 스크레이핑은 무엇이 다른가

시리즈는 번호로 대조하지 않고 제목·연도·시즌과 회차 구성으로 TMDB, Bangumi, TheTVDB 등에 대조합니다. 스캔 뒤 먼저 「剧集刮削（시리즈 스크레이핑）」페이지에서 그룹을 확정하고(합치기·나누기·무시 가능), 경계가 정해진 뒤에야 시리즈 메타데이터를 만듭니다. 처음 쓸 때는 그룹 경계를 먼저 확정하고 그다음 일치 임계값을 조정하세요. 시리즈의 폴더·파일명 서식, 시즌 포스터와 NFO 명명 규칙은 「剧集刮削规则（시리즈 스크레이핑 규칙）」에 있습니다.

## 설정 항목 설명

| 설정 항목 | 입력할 것 | 비우거나 틀리면 |
| --- | --- | --- |

| 本地数据优先（로컬 데이터 우선） | 켜기 / 끄기 | 끄면 이미 연결돼 있어도 다시 온라인으로 가져옵니다 |
| 品牌前缀过滤（브랜드 접두사 필터） | 필요에 따라 걸러 낼 접두사 | 틀리면 정상 번호까지 막혀 대조가 안 됩니다 |

| 整理文件名格式（파일명 서식） | 기본 `${number}`. 이름 본체만 | 틀리면 파일명이 잘못됩니다. 200바이트 초과 시 잘림, 상대 경로 3600바이트 초과 시 정리 중단 |
| 自动标签 / 自动分类标签 | 해상도·제작사·식별 코드 등을 자동 추가할지 | 끄면 이런 파생 태그가 붙지 않습니다 |
| 字段翻译（항목 번역） | 켜기 / 끄기. 시스템 번역 설정을 따릅니다 | 끄면 번역하지 않습니다. 번역이 설정되지 않으면 켜도 번역문이 없습니다 |
| 番号混合（번호 혼합） | 켜기 / 끄기 | 끄면 번호 표기가 한 가지뿐입니다 |
| 演员刮削（배우 스크레이핑） | 켜기 / 끄기 | 끄면 배우 이름·별명·초상을 가져오지 않습니다 |
| NFO 字段（NFO 항목） | NFO에 쓸 태그 | 뺀 태그는 NFO에서 빠집니다. 기본으로 식별 코드 `num`이 들어갑니다 |
| 高清封面 / 刮削剧照 / 剧照目录 | 이미지 스위치와 스틸 폴더 이름 | 고화질 표지를 끄면 일반 이미지, 스틸 수집을 끄면 `extrafanart`를 만들지 않습니다 |
| 允许图片下载失败（이미지 실패 허용） | 이미지를 못 받아도 정리를 계속할지 | 끄면 한 장 실패로 정리 전체가 멈출 수 있습니다 |
| 外挂字幕搜索（외부 자막 검색） | 외부 자막을 찾을지 | 끄면 `<파일명>.srt`를 쓰지 않습니다. 같은 이름이 있으면 덮어쓰지 않습니다 |
| 多线程执行 / 最大刮削线程数 | 스레드를 쓸지, 동시에 몇 개를 돌릴지 | 너무 많으면 기기와 사이트에 부담, 너무 적으면 느립니다 |
| 自动刮削（영상 / 시리즈별 스위치·간격） | 켜고 간격 설정. 기본 3분마다 대기 항목 확인 | 끄면 수동만 가능. 간격이 너무 짧으면 자주 돕니다 |
| 选择整理（선택해 정리） | 처리할 항목 체크 | 한 번에 최대 120건. 넘으면 나누세요 |
| 일치 임계값과 가중치(시리즈) | 「같은 작품인가」판정의 엄격함과 출처별 가중치 | 너무 엄격하면 못 찾고 너무 느슨하면 엉뚱한 작품에 맞습니다. 먼저 그룹 경계를 확정하세요 |
| 季映射自动发现 / 每季集数（시리즈） | 매핑 자동 발견 여부, 시즌별 회차 수 | 자동 발견을 끄면 수동 연결. 회차 수가 틀리면 시즌 구성이 어긋납니다 |
| 保存配置 / 刷新配置 | 고친 뒤 「保存配置」누르기 | 저장하지 않으면 반영되지 않습니다. 「刷新配置」는 저장 안 한 변경을 버립니다 |

## 문제가 생기면

- **「重复执行 - 刮削任务运行中（중복 실행·실행 중）」표시**: 이미 하나가 돌고 있습니다. 끝날 때까지 기다리거나 취소한 뒤 다시 넣으세요.
- **정보가 전혀 안 들어옴**: 스크레이퍼 체크, 플러그인 활성화, 사이트 계정을 확인하고 홈 화면의 네트워크 점검으로 자료 사이트에 닿는지 확인하세요.
- **서양 작품을 못 찾음**: MetaTube는 서양 번호를 지원하지 않습니다. ThePornDB나 TMDB를 켜세요.
- **작품 번호를 잘못 인식**: 「刮削入库（등록 대기）」에서 인식 번호 태그를 눌러 고치고 다시 스크레이핑하세요.
- **대조가 안 되거나 이미지·NFO가 빠짐**: 먼저 「绑定（연결）」로 라이브러리를 찾아 수동 연결한 뒤 스크레이핑하세요. 이미지나 NFO만 빠졌다면 「查漏补缺（빠진 것 보충）」을 쓰면 영상은 움직이지 않습니다.
- **정리가 도중 멈춤 / 이름이 잘림**: 200바이트 초과 시 잘리고 상대 경로 3600바이트 초과 시 중단입니다. 서식의 자리표시자를 줄이세요.
- **어느 단계에서 실패했는지 알고 싶을 때**: 「查看步骤（단계 보기）」에서 파일 검사·번호 판별·출처 조회·이미지나 NFO 생성 중 어디인지 찾으세요. 단계 오류가 보통 전체 로그보다 구체적입니다.

실행 뒤 상태·로그·재시도는 [자동 실행, 작업 기록, 실패 재시도](./automation.md)를 보세요.
