# 스캔: AMMDS가 내 파일을 알게 하기

동영상이 잔뜩 든 폴더를 AMMDS에 넘기는 첫 단계는 「스캔」입니다. 어떤 파일이 있는지 읽어 등록한 뒤에야 정보를 보충하고 정리할 수 있습니다. 작업 만드는 법, 대상 파일 고르는 법, 옮길 곳, 자동 실행, 결과 확인 위치를 알려 줍니다.

## 먼저 알아 두기

> **스캔**: 지정한 폴더를 돌며 조건에 맞는 동영상 파일을 하나씩 등록하는 일입니다. 파일만 등록하고 작품 정보는 아직 조회하지 않습니다.

> **스크레이핑**: 자료 사이트에서 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다. 스캔 다음에 합니다.

> **작품 번호 / 식별 코드**: 파일명에 들어 있는 식별 번호입니다. 검색칸에서는 「番号（작품 번호）」, 상세·편집 화면에서는 「识别码（식별 코드）」라고 부르지만 같은 것입니다.

> **메타데이터**: 작품의 표지·줄거리·출연진·태그 같은 설명 정보입니다.

> **NFO**: 동영상과 같은 곳에 두는 작은 설명 파일로 제목·출연진 등이 적혀 있습니다. 재생기가 읽고 AMMDS도 여기서 정보를 복원합니다.

> **Cron**: 「언제 실행할까」를 숫자와 기호로 적은 짧은 문자열입니다. 매일 몇 시, 몇 시간마다 등을 지정합니다.

> **허용 목록**: 「이것만 인정한다」는 목록입니다. 올라 있지 않은 것은 모두 건너뜁니다.

> **동시 처리**: 여러 일을 한꺼번에 진행하는 것입니다.

> **자리표시자**: 서식 문자열 안에서 `{}`로 감싼 표시로, 쓸 때 제목·작품 번호·배우 이름 같은 실제 내용으로 바뀝니다.

:::tip[스캔과 스크레이핑은 별개입니다]
스캔은 파일명과 미디어 정보만 등록하고 **작품 번호 판별이나 정보 보충은 하지 않습니다**. 표지·줄거리·출연진까지 채우려면 [스크레이핑: 작품 정보 자동으로 채우기](./scrape.md)로 가세요.
:::

## 순서대로 해 보기

### 1. 스캔 작업 만들기

任务管理 → 任务配置（작업 관리 → 작업 설정）을 엽니다. 기본은 「任务列表（작업 목록）」탭입니다. 「点击创建扫描任务（스캔 작업 만들기）」카드를 누르면 생성 창이 열립니다. 이미 만든 카드에서는 「编辑（편집）」「记录（기록）」「删除（삭제）」와 주 버튼을 쓸 수 있습니다.

만들 때 채울 항목:

| 항목 | 내용 |
| --- | --- |
| 任务名称（작업 이름） | 필수. 목록과 로그에서 알아보기 위한 이름입니다 |
| 分类（분류） | 影视（영상）/ 剧集（시리즈）. 시리즈는 별도의 판별·스크레이핑 경로를 탑니다 |
| 媒体类型（미디어 종류） | 영상일 때만. 산지 구분을 고릅니다(일본 AV, 서양, 국내, FC2 PPV 등) |
| 剧集分区（시리즈 구분） | 시리즈일 때 「媒体类型」대신 표시. 전체, 番剧（애니）, 日剧（일본 드라마）등 |
| 整理模式（정리 모드） | 파일을 어떻게 옮길지. 다음 절 참고 |
| 扫描目录（스캔 폴더） | 필수. 서버 파일 트리에서 고르며 폴더만 가능하고 단일 파일은 안 됩니다 |
| 整理目录（정리 대상 폴더） | 「原地整理（제자리 정리）」「查漏补缺（빠진 것 보충）」외에는 필수. 제자리 계열은 스캔 폴더를 자동으로 따라갑니다 |
| 重命名规则（이름 규칙） | 原文件名（원래 파일명）/ 标准化文件名（표준 파일명） |
| 重复文件处理规则（중복 처리 규칙） | 대상에 같은 이름이 있을 때 어느 쪽을 남길지 |
| 目录监控（폴더 감시） | 새로 만들 때만 설정 가능. 파일 변화로 스캔을 일으킵니다 |
| 加入收藏（즐겨찾기 추가） | 스캔·스크레이핑 뒤 즐겨찾기에 넣습니다. 영상 작업만 적용 |
| 计划任务（일정） | 폴더 감시가 꺼졌을 때만 표시. 여섯 항목 Cron 식을 적습니다 |

:::note[폴더를 고르기 전에 권한을 확인하세요]
扫描目录와 整理目录는 모두 서버 파일 트리에서 고르고, 폴더를 펼칠 때 안의 하위 폴더를 불러옵니다. AMMDS를 돌리는 계정에 스캔 폴더 읽기 권한, 정리 대상 폴더 쓰기 권한이 있는지 먼저 확인하세요. 없으면 나중에 정리가 실패합니다.
:::

작업 카드에는 작업 이름(옆에 시스템 종류와 작업 종류 태그: 影视 / 剧集 / 未知), 媒体类型 또는 剧集分区, 扫描目录와 整理目录, 整理模式, 이름·중복 규칙, 计划任务(꺼져 있으면 「未启用（사용 안 함）」)가 나옵니다.

### 2. 파일을 어떻게 옮길지 고르기（정리 모드）

| 모드 | 하는 일 |
| --- | --- |
| 原地整理（제자리 정리） | 파일을 옮기지 않고 스크레이핑 결과로 이름·정보만 보충 |
| 标准化整理（移动）（표준·이동） | 정리 대상으로 옮기고 폴더 서식과 파일명 서식대로 배치 |
| 标准化整理（复制）（표준·복사） | 정리 대상으로 복사하고 원본은 남김 |
| 标准化整理（软连接）（표준·심볼릭 링크） | 정리 대상에 원본을 가리키는 바로 가기를 만들어 용량을 더 쓰지 않음 |
| 标准化整理（硬连接）（표준·하드 링크） | 같은 데이터에 다른 이름을 붙임. 원본과 대상이 같은 파일 시스템이어야 합니다 |
| 查漏补缺（빠진 것 보충） | 폴더 구성과 파일명은 그대로 두고 빠진 이미지와 NFO만 채움 |

> **심볼릭 링크 / 하드 링크**: 둘 다 원본을 옮기지 않고 정리 대상에 「링크」를 늘리는 방법입니다. 심볼릭 링크는 바로 가기 같아서 원본을 지우면 끊기고, 하드 링크는 같은 데이터의 다른 이름이라 같은 디스크여야 합니다.

「原地整理」와 「查漏补缺」는 정리 대상을 따로 고를 필요가 없고, 이 둘로 바꾸면 정리 대상이 스캔 폴더로 자동 입력됩니다.

### 3. 이름 규칙과 중복 규칙 정하기

두 가지뿐입니다.

- **原文件名（원래 파일명）**: 스캔에서 찾은 이름을 그대로 씁니다.
- **标准化文件名（표준 파일명）**: 「影视刮削规则 → 整理文件名格式（영상 스크레이핑 규칙 → 파일명 서식）」으로 새 이름을 만듭니다.

중복 규칙은 정리 대상에 같은 이름이 있을 때 어느 쪽을 남길지 정합니다.

| 규칙 | 남기는 것 |
| --- | --- |
| 保留（그대로 유지） | 원래 파일. 용량·날짜·해상도로 다시 고르지 않습니다 |
| 大文件 / 小文件（큰 것 / 작은 것） | 용량이 크거나 작은 쪽 |
| 新文件 / 旧文件（새것 / 오래된 것） | 날짜가 새롭거나 오래된 쪽 |
| 高分辨率 / 低分辨率（높은 / 낮은 해상도） | 해상도가 높거나 낮은 쪽 |

### 4. 어떤 파일을 대상으로 할지 고르기

스캔은 「任务配置 → 扫描规则配置（작업 설정 → 스캔 규칙）」의 전체 규칙을 읽습니다. 영상과 시리즈가 같은 탭을 쓰지만 시리즈 작업은 `tv` 접두사가 붙은 항목을 읽습니다.

| 규칙 | 영상 | 시리즈 |
| --- | --- | --- |
| 동영상 형식 제한 | `scanning_video_format` | 같은 항목 공용 |
| 무시 폴더 | `scanning_ignore_dir` | `scanning_tv_ignore_dir` |
| 무시 파일 | `scanning_ignore_file` | `scanning_tv_ignore_file` |
| 최소 동영상 크기(MB) | `scanning_min_size` | `scanning_tv_min_size` |
| 분할 표시자 | `scanning_video_segmentation` | 사용 안 함 |
| 자막 형식 | `scanning_subtitle_format` | 같은 항목 공용 |
| 로컬 NFO 읽기 | `scanning_read_nfo` | `scanning_tv_read_nfo` |

시리즈에는 「特别篇关键词（특별편 키워드）」「集号缺失默认季（회차 누락 시 기본 시즌）」「绝对编号识别（절대 번호 판별）」세 가지가 더 있어 파일명을 시즌과 회차로 풀어 냅니다. **규칙을 바꿔도 이후 스캔에만 적용되고 이미 등록된 기록은 바뀌지 않습니다.**

실제 스캔 순서는 이렇습니다.

1. 스캔 폴더에서 재귀적으로 파일을 모으고 동영상 확장자 허용 목록으로 걸러 냅니다.
2. 「무시 폴더」에 걸린 하위 트리 전체와 이름에 「무시 파일」키워드가 들어간 파일을 건너뜁니다.
3. 전체 스캔일 때만 최소 크기로 걸러 내고, 폴더 감시가 일으킨 단일 파일 스캔은 크기 필터를 쓰지 않습니다.
4. 파일 정보와 미디어 정보(종류, 해상도, 크기, 영상·음성 코덱, 비트레이트 등)를 읽습니다.
5. 같은 폴더에 같은 이름의 자막이 있는지 보고 자막 종류를 기록합니다.
6. 분할 표시자로 `cd1`, `part2` 같은 여러 부분 구성인지 판단합니다.
7. 「读取本地 NFO」가 켜져 있고 옆에 NFO가 있으면 해석해서 단계 기록에 넣습니다.
8. 같은 경로가 이미 등록돼 있으면 새로 만들지 않고 기록만 이번 작업에 다시 연결합니다.

### 5. 자동으로 돌리기

| 방식 | 나오는 상황 | 내용 |
| --- | --- | --- |
| 立即扫描（지금 스캔） | 폴더 감시가 꺼진 작업 | 카드의 주 버튼. 누르면 접수되어 백그라운드에서 실행 |
| 初始化（초기화） | 감시 켜짐, 상태가 「创建（생성）」 | 먼저 전체 스캔을 한 뒤 폴더 감시를 등록 |
| 监控中（감시 중） | 감시 켜짐·초기화 완료 | 버튼이 스캔을 일으키지 않고 감시 중임만 표시 |
| 定时扫描（정기 스캔） | 감시 꺼짐 + Cron 입력 | 스케줄러가 식에 따라 실행. [자동 실행, 작업 기록, 실패 재시도](./automation.md) 참고 |

:::warning[폴더 감시와 수동 스캔은 하나만 고를 수 있습니다]
감시를 켜면 수동 스캔을 쓸 수 없고 먼저 초기화해야 합니다. 감시와 Cron도 둘 중 하나로, 감시 중에는 Cron이 저장되지 않고 감시를 꺼야 Cron으로 정기 작업이 등록됩니다. 한 작업에 둘 다 넣어도 의미가 없습니다.
:::

폴더 감시는 파일 시스템 이벤트를 쓰고 주기적으로 훑지 않습니다.

- 스캔 폴더와 그 아래 모든 하위 폴더를 등록하고, 새 하위 폴더는 재귀적으로 추가 등록합니다.
- **새 동영상 파일**이 생겼을 때만 반응하며 확장자가 형식 허용 목록 안이어야 합니다.
- 그 이벤트에 해당하는 파일만 처리하고 폴더 전체를 다시 스캔하지 않습니다.
- 폴더가 삭제되면 감시를 해제합니다. 앱을 다시 켜면 작업 설정대로 다시 등록합니다.

:::warning[폴더 계층이 깊으면 자원을 씁니다]
폴더 감시는 시스템의 파일 감시 자리를 씁니다. 계층이 깊거나 변경이 잦을수록 부담이 크고, Linux에서는 inotify 자리가 바닥나면 감시 서비스가 시작되지 않습니다. 감시 폴더를 줄이거나 시스템 상한을 올리세요.
:::

카드의 「记录（기록）」은 스캔 로그로 가며 해당 작업으로 자동 필터링됩니다. 「编辑（편집）」은 편집 창을 열지만 **目录监控（폴더 감시）스위치는 편집할 때 바꿀 수 없습니다**. 「删除（삭제）」는 두 번 확인하고, 스캔 중인 작업은 지울 수 없습니다.

### 6. 결과 확인 위치

| 위치 | 볼 수 있는 것 |
| --- | --- |
| 任务管理 → 扫描日志（작업 관리 → 스캔 로그） | 실행 종류, 시작 시각, 소요 시간, 상태, 판별 / 추가 / 갱신 건수. 실행 중에는 취소 가능 |
| 任务管理 → 刮削入库 → 影视刮削（작업 관리 → 등록 → 영상 스크레이핑） | 등록된 동영상, 식별 번호, 미디어 정보, 스크레이핑 / 정리 상태. 연결·해제·삭제·번호 수동 수정 가능 |
| 任务管理 → 刮削入库 → 剧集刮削（작업 관리 → 등록 → 시리즈 스크레이핑） | 작품명별로 모은 확인 대기 그룹. 합치기·나누기·무시·확정 가능 |

스캔이 끝나도 **자동으로 스크레이핑하지 않습니다**. 단 「自动刮削（자동 스크레이핑）」이 켜져 있거나 모드가 「查漏补缺（빠진 것 보충）」일 때는 예외입니다.

## 작품 번호는 언제 알 수 있나

스캔 단계는 파일명과 미디어 정보뿐이라 목록의 「识别番号（인식 번호）」는 스크레이핑에서 맞춘 뒤에야 값이 들어갑니다. 실제 판별은 스크레이핑 쪽의 「识别码规则（식별 코드 규칙）」과 「番号补全规则（번호 보완 규칙）」이 합니다.

예외는 로컬 NFO입니다. 「读取本地 NFO」를 켜면 스캔이 NFO에서 메타데이터와 식별 코드를 바로 복원할 수 있습니다. 판별 실패나 오류는 **任务管理 → 刮削入库 → 影视刮削（작업 관리 → 등록 → 영상 스크레이핑）**에서 인식 번호 태그를 눌러 고치세요.

## 규칙 패널에 또 무엇이 있나

「任务配置（작업 설정）」아래쪽은 탭별 규칙 패널입니다. 작업이 「어느 폴더를 훑을지」를 정하고 규칙이 「어떻게 판별·스크레이핑·정리할지」를 정합니다.

| 탭 | 대략 맡는 일 |
| --- | --- |
| 扫描规则配置（스캔 규칙） | 형식, 무시 폴더 / 파일, 최소 크기, 분할 표시자, 자막, NFO 읽기, 시리즈 전용 항목 |
| 影视刮削规则（영상 스크레이핑 규칙） | 자료 출처, 폴더 / 파일명 서식, NFO 항목, 이미지, 태그, 번역, 스레드 수 등. [스크레이핑: 작품 정보 자동으로 채우기](./scrape.md) 참고 |
| 剧集刮削规则（시리즈 스크레이핑 규칙） | 시리즈 스크레이퍼, 일치 임계값·가중치, 폴더 / 파일명 서식, 시즌 포스터 이름, NFO 항목 등. [스크레이핑: 작품 정보 자동으로 채우기](./scrape.md) 참고 |
| 番号补全规则（번호 보완 규칙） | 파일명에서 불완전한 번호 보완 |
| 识别码规则（식별 코드 규칙） | 파일명에서 식별 코드 추출 |
| CID 转换规则（CID 변환 규칙） | 식별 코드를 다른 번호 형식으로 바꾸기 |
| 订阅规则配置（구독 규칙） | 중문 자막 우선, 검색 순서, 다운로드 폴더 |
| 漫画整理配置（만화 정리 설정） | 형식, 폴더, 이름, 장별 생성, 표지 / 뒷표지 / 목차 키워드 |
| 小说整理配置（소설 정리 설정） | 형식, 폴더, 이름, 장별 생성 여부 |

> **스크레이퍼**: 작품 정보를 조회할 수 있는 출처입니다. 자료 사이트나 내 기존 데이터를 말합니다. 스크레이핑할 때 여러 개를 고르면 그곳에 동시에 조회합니다.

> **스레드**: 한 묶음의 일을 여러 갈래로 나누어 동시에 처리하는 「일꾼」수입니다. 많을수록 빠르지만 너무 많으면 내 기기와 상대 사이트에 부담이 됩니다.

> **정규식**: 어떤 글자에 맞출지 기호로 적은 규칙으로, 파일명에서 번호를 뽑는 데 씁니다.

규칙 패널에서 입력칸·숫자칸·스위치·새 항목을 만들 수 있는 드롭다운 중 무엇이 나올지는 화면이 정합니다. 고친 뒤에는 「保存配置（설정 저장）」으로 항목마다 제출하고, 「刷新配置（설정 다시 읽기）」는 저장하지 않은 변경을 버리고 다시 불러옵니다.

### 번호 보완 규칙

각 규칙에 필요한 것: 备注（메모, 규칙 구분용）, 规则类型（규칙 종류, 일치 문자열 해석법）, 匹配规则（일치 규칙, 파일명 어디를 찾을지）, 模板（템플릿, 번호 조립）, 番号长度（번호 길이. `0`은 자동 보완, 0보다 크면 그 자릿수까지 채움）, 自动补全（자동 보완, 자동 적용 여부）, 启用状态（사용 / 사용 안 함）.

### 식별 코드 규칙과 CID 변환

「识别码规则（식별 코드 규칙）」은 파일명이나 경로에서 식별 코드를 뽑습니다. 일치 방식은 정규식·접두사·포함·접미사 네 가지이고 출력 템플릿(`{num}`, `{match}`, `{group1}` 등), 작품 종류, 有无码（모자이크 여부）, 需包含前缀（필요한 접두사）, 사용 상태, 메모를 정할 수 있습니다. 패널에는 「识别测试（판별 테스트）」가 있어 파일명이나 전체 경로를 넣으면 식별 코드, 맞았는지, 걸린 규칙, 보완된 번호를 돌려 줍니다.

「CID 转换规则（CID 변환 규칙）」은 식별 코드가 맞다는 전제에서 그걸 CID로 바꿉니다. 일치 방식은 같고 출력 템플릿은 `{brand}`, `{num}`, `{num2}` ~ `{num8}`(0 채움), `{match}`, `{group1}` 등을 지원하며 변환 테스트도 있습니다.

:::tip[먼저 판별, 그다음 변환]
CID 변환은 올바른 식별 코드에 달려 있습니다. 결과가 이상하면 「识别测试（판별 테스트）」로 식별 코드 자체를 확인한 뒤 CID 템플릿을 고치세요.
:::

식별 코드 규칙과 CID 변환 규칙은 모두 끌어서 순서를 바꿀 수 있고 **위에 있을수록 우선순위가 높습니다**. 번호 보완 규칙과 마찬가지로 추가·편집·삭제·사용 / 사용 안 함을 지원합니다.

### 구독·만화·소설 정리 규칙

이 세 가지는 영상 스캔 작업과 섞지 않고 각자 탭에서 정합니다.

| 탭 | 채울 것 |
| --- | --- |
| 订阅规则配置（구독 규칙） | 中字优先（중문 자막 우선. 현재 버전은 취향만 저장하고 자동 다운로드 순서에는 영향 없음）, 搜索顺序（검색 순서. 사이트 키워드 목록으로 어디를 먼저 시도할지 정하며 모음형 출처는 항상 마지막）, 下载目录（다운로드 폴더. 비우면 다운로더 기본 경로） |
| 漫画整理配置（만화 정리 설정） | 형식(폴더, CBZ, CBR, CB7, PDF, EPUB), 기본 정리 폴더, 폴더 / 파일 이름, 장별 생성 여부, 표지 / 뒷표지 / 목차 키워드 |
| 小说整理配置（소설 정리 설정） | 형식(EPUB, TXT), 기본 정리 폴더, 폴더 / 파일 이름, 장별 생성 여부 |

만화·소설 이름 규칙은 `${title}`, `${author}`, `${chapter}`, `${index}` 같은 자리표시자를 지원합니다. 자세한 내용은 패널 설명을 따르세요.

규칙은 전체 설정입니다. 바꾸면 그 뒤에 만들거나 실행하는 작업에 적용되고 이미 등록된 메타데이터는 고치지 않습니다. 작업 단위 항목(폴더, 정리 모드, Cron, 폴더 감시)은 작업 카드에서 관리하고 규칙 패널에는 없습니다.

## 설정 항목 설명

### 작업을 만들 때

| 설정 항목 | 입력할 것 | 비우거나 틀리면 |
| --- | --- | --- |
| 任务名称（작업 이름） | 알아보기 쉬운 이름 | 필수. 없으면 작업을 만들 수 없습니다 |
| 分类（분류） | 影视（영상）또는 剧集（시리즈） | 틀리면 판별 경로가 달라지고 시리즈는 별도 경로를 탑니다 |
| 媒体类型 / 剧集分区（미디어 종류 / 시리즈 구분） | 영상은 산지 구분, 시리즈는 구분(전체, 番剧, 日剧 등) | 분류에 맞는 쪽만 보이고 다른 쪽은 숨습니다 |
| 整理模式（정리 모드） | 여섯 가지 이동 방법 중 하나 | 필수. 「原地整理」「查漏补缺」이면 정리 대상이 스캔 폴더와 같아집니다 |
| 扫描目录（스캔 폴더） | 서버 파일 트리에서 고른 폴더 | 필수. 폴더만 되고 파일은 안 됩니다. 읽기 권한이 없으면 찾지 못합니다 |
| 整理目录（정리 대상 폴더） | 제자리 계열 외에는 필수, 쓰기 권한도 필요 | 필수. 권한이 없으면 정리가 실패합니다 |
| 重命名规则（이름 규칙） | 原文件名 또는 标准化文件名 | 표준을 고르면 스크레이핑 규칙의 파일명 서식으로 이름을 바꿉니다 |
| 重复文件处理规则（중복 처리 규칙） | 保留 / 大文件 / 小文件 / 新文件 / 旧文件 / 高分辨率 / 低分辨率 | 「保留」이면 용량·날짜·해상도로 다시 고르지 않습니다 |
| 目录监控（폴더 감시） | 새로 만들 때 켜기 / 끄기 | 편집 때는 못 바꿉니다. 켜면 수동 스캔이 안 되고 Cron도 저장되지 않습니다 |
| 加入收藏（즐겨찾기 추가） | 켜기 / 끄기, 영상 작업만 적용 | 끄면 추가하지 않습니다. 시리즈 작업에서는 효과가 없습니다 |
| 计划任务（일정） | 여섯 항목 Cron 식. 감시가 꺼졌을 때만 표시 | 비우면 수동만 가능. 식이 틀리거나 시간대가 다르면 실행되지 않습니다 |

### 스캔 규칙의 전체 항목

| 설정 항목 | 입력할 것 | 비우거나 틀리면 |
| --- | --- | --- |
| 동영상 형식 제한 `scanning_video_format` | 허용할 동영상 확장자 | 목록에 없는 형식은 스캔되지 않습니다. 감시도 목록 안의 새 파일만 받습니다 |
| 무시 폴더 `scanning_ignore_dir` / `scanning_tv_ignore_dir` | 통째로 건너뛸 폴더 | 걸리면 하위 트리 전체를 건너뜁니다 |
| 무시 파일 `scanning_ignore_file` / `scanning_tv_ignore_file` | 이름에 들어가면 건너뛸 키워드 | 너무 넓으면 본편까지 빠집니다 |
| 최소 동영상 크기 `scanning_min_size` / `scanning_tv_min_size`(MB) | 몇 MB 미만을 동영상으로 보지 않을지 | 전체 스캔만 걸러 내고 감시로 온 단일 파일은 걸러 내지 않습니다 |
| 분할 표시자 `scanning_video_segmentation` | `cd1`, `part2` 같은 여러 부분 표시자 | 시리즈는 쓰지 않습니다. 틀리면 한 편을 여러 개로 쪼갭니다 |
| 자막 형식 `scanning_subtitle_format` | 같은 폴더에서 자막으로 볼 확장자 | 영상과 시리즈가 공용합니다 |
| 로컬 NFO 읽기 `scanning_read_nfo` / `scanning_tv_read_nfo` | 옆의 NFO를 읽을지 | 켜지 않으면 NFO에서 메타데이터와 식별 코드를 복원할 수 없습니다 |
| 特别篇关键词 / 集号缺失默认季 / 绝对编号识别 | 시리즈 전용. 파일명을 시즌과 회차로 | 시리즈 작업만 읽고 비우면 기본 방식으로 풀어 냅니다 |

### 번호 보완·식별 코드와 그 외

| 설정 항목 | 입력할 것 | 비우거나 틀리면 |
| --- | --- | --- |
| 번호 보완의 일치 규칙 / 템플릿 | 파일명 어디를 찾고 어떤 템플릿으로 번호를 만들지 | 규칙이 틀리면 잘못된 번호가 만들어져 스크레이핑이 다른 작품에 맞춥니다 |
| 番号长度（번호 길이） | `0`은 자동 보완, 0보다 크면 그 자릿수까지 | 자릿수가 틀리면 0이 더 붙거나 모자랍니다 |
| 식별 코드 규칙의 일치 방식·템플릿 | 정규식 / 접두사 / 포함 / 접미사, `{num}`, `{match}`, `{group1}` 등의 출력 템플릿 | 식별 코드를 못 뽑으면 스크레이핑이 맞출 수 없습니다. 먼저 「识别测试」로 확인하세요 |
| CID 변환 출력 템플릿 | `{brand}`, `{num}`, `{num2}` ~ `{num8}`, `{match}`, `{group1}` 등 | 식별 코드 자체가 틀리면 변환도 반드시 틀립니다. 먼저 식별 코드를 고치세요 |
| 启用状态 / 정렬 | 규칙 켜기·끄기와 끌어서 정렬 | 꺼진 규칙은 판별에 참여하지 않습니다. 순서가 우선순위입니다 |
| 搜索顺序（구독 규칙의 검색 순서） | 쉼표로 구분한 사이트 키워드 | 틀린 키워드는 그 사이트를 늘 뒤로 밀어 냅니다 |
| 下载目录（구독 규칙의 저장 경로） | 구독 다운로드 저장 경로 | 비우면 다운로더 기본 경로를 씁니다 |
| 保存配置 / 刷新配置 | 고친 뒤 「保存配置」로 항목마다 제출 | 저장하지 않으면 반영되지 않습니다. 「刷新配置」는 저장 안 한 변경을 버립니다 |

## 문제가 생기면

- **파일이 하나도 안 잡힘**: 扫描目录가 맞는지, AMMDS 계정에 읽기 권한이 있는지 보고, 다음에 형식 허용 목록과 「忽略目录 / 忽略文件」에 막혔는지 확인하세요.
- **한 파일이 여러 작품·여러 부분으로 쪼개짐**: 분할 표시자와 식별 코드 규칙을 보고, 먼저 파일명을 「识别测试（판별 테스트）」에 넣어 보세요.
- **감시를 켰는데 아무 일도 없음**: 작업이 초기화됐는지 확인하세요. 「监控中（감시 중）」버튼은 원래 스캔을 일으키지 않습니다. 계층이 깊거나 감시 자리가 부족하면 폴더를 줄이거나 상한을 올리세요.
- **정각에 돌지 않음**: Cron 식과 앱 시간대를 확인하고 전체 스케줄러 스위치가 꺼지지 않았는지 봅니다. [자동 실행, 작업 기록, 실패 재시도](./automation.md) 참고.
- **정리가 실패함**: 대개 정리 대상 폴더에 쓰기 권한이 없거나, 「硬连接（하드 링크）」를 골랐는데 원본과 대상이 다른 디스크이기 때문입니다.
- **규칙을 바꿨는데 옛 기록이 그대로**: 규칙은 이후 스캔에만 적용되고 등록된 기록은 바꾸지 않습니다. 다시 스캔하거나 다시 스크레이핑하세요.
