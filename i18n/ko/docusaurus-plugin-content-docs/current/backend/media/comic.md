# 만화와 소설

만화 라이브러리는 만화와 사진첩, 소설 라이브러리는 소설을 담습니다. 둘 다 「책 한 권 + 여러 장(章)」형태이고, 다른 점은 만화의 한 장이 이미지 묶음, 소설의 한 장이 글 본문이라는 것입니다. 이 페이지는 하려는 일에 따라 책 만들기, 내용 넣기, 순서 맞추기, 파일로 내보내기, 읽은 위치가 어디 남는지를 알려 줍니다. 두 라이브러리는 생김새가 비슷해 함께 다루고, 다른 부분만 짚어 줍니다.

## 먼저 알아 두기

> **메타데이터**: 책이나 장의 설명 정보입니다. 제목, 지은이, 장 순서 등이 들어가며, 만화는 `ComicInfo.xml`이라는 정해진 이름의 파일에 함께 저장합니다.

> **자리표시자**: 이름 서식 안의 `${title}` 같은 표시로, 정리할 때 실제 내용으로 바뀝니다. `${title}`은 책 이름, `${chapter}`는 장 이름이 됩니다.

> **책 출처**: 소설 본문을 가져오는 사이트입니다. 목차와 본문 가져오기만 맡고, 어떤 출처를 켤지와 그 규칙은 연동 앱에서 관리합니다.

> **정리**: 정한 폴더·파일 이름 규칙에 따라 라이브러리 내용을 폴더나 파일 하나로 내보내는 일입니다.

> **EPUB / PDF**: 흔한 전자책 형식입니다. EPUB은 리더 앱에 잘 맞고 PDF는 페이지 단위 문서입니다.

> **CBZ / CBR / CB7 / 압축 파일**: 한 장의 이미지를 파일 하나로 묶는 형식으로, 압축 방식만 다릅니다. CBR은 만들 때 서버에 별도 도구가 필요합니다.

## 책 만들기

두 라이브러리 모두 媒体管理（미디어 관리）아래에 있고, 왼쪽은 만들기, 오른쪽은 정렬·검색, 가운데는 카드로 구성이 같습니다.

### 만화 라이브러리

媒体管理 → 漫画库（미디어 관리 → 만화 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 「创建漫画（만화 만들기）」 |
| 오른쪽 | 정렬 드롭다운, 「搜索我的漫画（내 만화 검색）」 |
| 카드 | 한 줄에 최대 4장, 아래에 페이지 이동 |

정렬은 **최근 만든 순, 처음 만든 순, 제목 오름차순, 제목 내림차순** 네 가지이며, 바꾸면 1페이지로 돌아가 다시 조회합니다.

카드에는 표지, 분류 라벨, 제목, 시리즈, 지은이, 태그, 설명이 보입니다. 제목 오른쪽 부제는 두 가지로, 「全章节（전체 장 모드）」를 켜면 「全集（전집）」, 끄면 「第 N 季（N번째 시즌）」가 뜹니다.

카드 오른쪽 위에 마우스를 올리면 동작 셋이 나옵니다. **编辑（편집）**(편집 화면으로), **分享（공유）**, **删除（삭제）**(확인 후 삭제). 카드 본체(오른쪽 위 버튼이 아닌 곳)를 누르면 장 관리 화면으로 들어가며 「전체 장 모드」표시도 함께 넘어갑니다.

### 소설 라이브러리

媒体管理 → 小说库（미디어 관리 → 소설 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 「创建小说（소설 만들기）」「搜索小说（소설 검색）」「导入 EPUB（EPUB 가져오기）」 |
| 오른쪽 | 정렬 드롭다운, 「搜索我的小说（내 소설 검색）」 |
| 카드 | 한 줄에 최대 4장, 아래에 페이지 이동 |

정렬은 같은 **최근 만든 순, 처음 만든 순, 제목 오름차순, 제목 내림차순**입니다. 한 페이지 기본 12건으로 네 열 배치에 맞습니다.

카드 왼쪽은 표지, 오른쪽 위에 **상태** 라벨이 고정으로 붙습니다(완결 / 연재 / 초고 / 미완 / 집필 중). 오른쪽에 유형, 제목, 지은이, 시리즈, 출처, 태그가 보이고 설명은 최대 세 줄입니다.

카드 오른쪽 위에 마우스를 올리면 동작 아이콘이 나옵니다:

| 아이콘 | 동작 | 설명 |
| --- | --- | --- |
| 다운로드 | 아직 받지 않은 장의 본문 가져오기 | 책 출처에서 온 책만 표시 |
| 편집 | 편집 화면으로 | |
| 공유 | 공유 링크 만들기 | |
| 삭제 | 확인 후 소설 한 권 전체 삭제 | |

:::tip[장 관리 화면으로 들어가기]
카드 본체를 누르면 장 관리 화면으로 들어갑니다. 만화·소설 모두 같은 진입점이고, 오른쪽 위 버튼들과는 다릅니다.
:::

### 만들 때 입력하는 것

만화는 「创建漫画（만화 만들기）」, 소설은 「创建小说（소설 만들기）」에서 입력합니다. 각각 다음과 같습니다.

만화:

| 항목 | 설명 |
| --- | --- |
| 제목 | 필수 |
| 지은이 | 필수 |
| 시리즈 | 속한 시리즈 이름 |
| 유형 | 만화 / 사진첩 |
| 설명 | 여러 줄 글 |
| 全章节（전체 장 모드） | 스위치. 켜면 장을 나누지 않고 책 전체를 하나로 표시 |
| 시즌 수 | `1`～`999` 정수, 드롭다운 또는 직접 입력 가능; 「전체 장 모드」를 켜면 비활성 |
| 표지 | 클릭 또는 드래그 업로드, 권장 비율 9:16, 이미지만, 10 MB 이하 |

시즌 수에 잘못된 값을 넣으면 안내가 뜨고 직전의 올바른 값으로 되돌아갑니다.

소설:

| 항목 | 설명 |
| --- | --- |
| 제목 | 필수 |
| 지은이 | |
| 유형 | 후보에 玄幻、都市、科幻、悬疑、武侠、言情、历史、游戏、轻小说 등, 직접 입력한 사용자 유형도 가능 |
| 시리즈 | 속한 시리즈 이름 |
| 상태 | 완결 / 연재 / 초고 /미완 / 집필 중 |
| 설명 | 여러 줄 글 |
| 표지 | 클릭 또는 드래그 업로드, 권장 비율 2:3 |

## 내용 넣기

### 만화: 내 컴퓨터나 서버에서 가져오기

장 화면 가운데에 가져오기 입구 셋이 있습니다:

1. **이미지**: 클릭 또는 드래그 업로드, JPG·PNG·BMP·GIF 지원. 디렉터리째 한 번에 넣을 수 있고 이름순으로 자동 정렬합니다.
2. **PDF / EPUB**: 클릭 또는 드래그 업로드, PDF·EPUB 지원, 하나씩 올리며 진행 상태를 표시합니다.
3. **CBZ / 메타데이터**: CBZ 입구에서 `.cbz` 파일을 고를 수 있으나 현재 버전은 「暂未支持 CBZ 文件上传（CBZ 업로드는 아직 미지원）」이라고 뜨고 형식·크기 확인만 한 뒤 건너뜁니다. 메타데이터 입구는 `ComicInfo.xml`만 받아 장 메타데이터를 기록합니다.

또 「漫画导入（만화 가져오기）」는 서버 디렉터리를 이용합니다. 창에서 만화 이미지가 든 디렉터리를 고르면 파일명 자연순으로 가져오고, 표지 / 뒷표지 키워드가 붙은 이미지를 알아서 처음과 끝에 배치합니다.

:::warning[압축 파일 가져오기의 현재 상태]
업로드 쪽에서 실제로 저장되는 것은 PDF / EPUB뿐이고 CBZ는 입구만 마련돼 있습니다. 압축 관련 기능은 **내보내기 쪽**에 있어, 「手动整理（수동 정리）」로 장을 CBZ·CBR·CB7로 만들 수 있습니다.
:::

### 소설: EPUB와 책 출처

- **EPUB 가져오기**: 「导入 EPUB（EPUB 가져오기）」에서 `.epub` 파일을 고르면 목차와 장을 해석해 등록하고, 가져오는 동안 불러오는 상태가 표시됩니다. 가진 전자책을 라이브러리로 옮기는 가장 빠른 방법입니다.
- **책 출처 가져오기**: 「搜索小说（소설 검색）」으로 출처 검색 창을 엽니다. 제목 키워드를 넣고 켜진 책 출처에서 검색 → 결과에서 책을 골라 가져옵니다. 가져온 책은 카드에 출처가 표시되고 장 화면에 「来源书源: 书源名（출처: 이름）」라벨이 뜹니다. 책 출처는 목차와 본문 가져오기만 맡고, 출처 자체의 활성화와 규칙은 연동 앱에서 관리합니다.

## 장 관리와 순서

카드에서 들어가면 제목이 「章节管理 · 书名（장 관리 · 책 이름）」이고 위쪽 동작이 좌우로 나뉩니다.

만화:

| 위치 | 동작 | 설명 |
| --- | --- | --- |
| 왼쪽 | 장 드롭다운 | 현재 장 전환 |
| 왼쪽 | 장 새로 만들기 | 장 제목과 설명을 넣어 생성; 전체 장 모드에서는 비활성 |
| 왼쪽 | 만화 가져오기 | 서버 디렉터리에서 이미지 가져오기; 장 미선택 시 비활성 |
| 오른쪽 | 편집 | 만화 편집 화면으로 복귀 |
| 오른쪽 | 立即整理 | 작업 설정대로 곧바로 정리 작업 제출 |
| 오른쪽 | 手动整理 | 정리 폴더, 폴더 서식, 파일 형식을 지정한 뒤 제출 |
| 오른쪽 | 장 삭제 | 전체 장 모드에서는 비활성 |

소설:

| 위치 | 동작 | 설명 |
| --- | --- | --- |
| 왼쪽 | 장 드롭다운 | 번호 + 제목으로 전체 장 나열 |
| 왼쪽 | 장 새로 만들기 | 장 제목만 입력 |
| 왼쪽 | 출처 라벨 | 책 출처에서 가져온 책만 표시 |
| 왼쪽 | 본문 미확보 N장 | 본문 없는 장이 있으면 빨간 라벨로 표시 |
| 오른쪽 | 본문 갱신 | 책 출처 책이고 장을 선택했을 때만 표시 |
| 오른쪽 | 전권 다운로드 | 책 출처 책만 표시, 백그라운드 작업으로 실행 |
| 오른쪽 | 편집 / 立即整理 / 手动整理 | 정리 작업 제출 |
| 오른쪽 | 장 삭제 | 장을 먼저 선택해야 함 |

**만화 장의 이미지**: 장을 고르면 이미지가 격자로 보이고 각 이미지 오른쪽 위에 동작 셋이 있습니다. **앞으로 / 뒤로**(순서 조정, 첫 장은 앞으로, 마지막 장은 뒤로 옮길 수 없음), **삭제**(이미지 제거). 이미지를 누르면 큰 미리보기에서 넘겨 볼 수 있습니다. 아래 페이지 이동은 페이지당 개수를 바꿀 수 있습니다(12, 24, 48, 60, 120, 240, 480, 1000).

**소설 본문 편집**: 장을 고르면 편집 영역으로 들어갑니다:

- 위에 **장 제목** 입력칸과 「保存正文（본문 저장）」버튼이 있습니다.
- 본문은 순수 텍스트 여러 줄 입력칸이고 빈 줄이 문단 구분입니다. HTML 태그는 그대로 글자로 보이고 렌더링되지 않습니다.
- 책 출처에서 가져온 장은 열 때 본문을 자동으로 가져오며, 가져오는 동안 편집 영역이 불러오는 표시에 덮여 중간 내용이 보이지 않습니다.
- 「保存正文（본문 저장）」을 누르기 전까지 변경은 브라우저에만 있습니다.

**전권 다운로드**(책 출처 소설만)는 가져오기를 백그라운드에 맡깁니다:

1. 제출하면 화면 위에 「正在后台下载全本（백그라운드에서 전권 다운로드 중）」진행 바가 뜹니다.
2. 진행은 작업 로그에서 오고 현재 단계 설명이 붙습니다.
3. 「查看任务日志（작업 로그 보기）」로 로그 화면에 가서 실패 원인을 확인할 수 있습니다.

## 파일로 정리해 내보내기

「立即整理（바로 정리）」는 작업 설정의 폴더와 서식을 쓰고 제출 뒤 「提交整理任务成功（정리 작업을 제출했습니다）」라고 뜹니다. 「手动整理（수동 정리）」는 이번 작업에 한해 설정을 덮어쓸 수 있습니다.

만화 수동 정리:

| 항목 | 설명 |
| --- | --- |
| 정리 폴더 | 필수, 서버 디렉터리 트리에서 선택 |
| 폴더 서식 | `${title}` `${author}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 등 태그 지원, 비우면 작업 설정 사용 |
| 파일 형식 | 폴더 정리, CBZ, CBR, CB7, PDF, EPUB |

폴더 / PDF / EPUB는 바로 만들고, CBZ·CB7은 내장 생성입니다. CBR(RAR)은 서버에 `rar` 도구가 있거나 `AMMDS_RAR_TOOL`로 실행 파일을 가리켜야 합니다.

소설 수동 정리(「立即整理」는 「小说整理配置（소설 정리 설정）」대로 제출):

| 항목 | 설명 |
| --- | --- |
| 정리 폴더 | 비우면 「小说整理配置」의 폴더 사용 |
| 폴더 이름 규칙 | `${title}` `${author}` `${category}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 등 태그 지원 |
| 파일 이름 규칙 | 전권 내보내기 때 `${chapter}`는 소설 이름, 장별 내보내기 때는 장 이름 사용 |
| 정리 형식 | **EPUB**(기본) 또는 **TXT** |
| 장별로 생성 | 켜면 장마다 파일 하나, 끄면 전권 파일 하나(EPUB 안에 모든 장 포함) |

EPUB은 장 순서대로 전자책 목차를 만들어 리더 앱에 바로 넘길 수 있습니다.

두 기본 설정은 작업 관리 섹션의 「任务配置（작업 설정）」에 있고 이름으로 찾습니다. **漫画整理配置（만화 정리 설정）**는 정리 형식, 기본 정리 폴더, 폴더 / 파일 이름 규칙, 장별 생성 여부, 표지 / 뒷표지 / 목차 판별 키워드를 다룹니다. **小说整理配置（소설 정리 설정）**는 정리 형식, 기본 정리 폴더, 폴더 / 파일 이름 규칙, 장별 생성 여부를 다룹니다. 이 둘은 만화·소설 등록에만 쓰이고 영화 스캔 작업과 섞이지 않으며, 고치면 이후에 만들거나 실행한 작업에만 적용되고 이미 등록된 내용은 바뀌지 않습니다.

## 읽은 위치는 어디에 남나

장 관리 화면은 내용 관리만 하고 **읽은 위치는 여기서 보이지 않습니다**. 프런트 리더가 기록합니다:

- 만화는 「장 + 페이지」로 저장하고 나가거나 백그라운드로 넘어가면 바로 기록합니다. 같은 만화를 다시 열면 「已恢复到上次阅读位置 第 N 页（지난 위치 N페이지로 돌아왔습니다）」라고 뜹니다. 프런트 상세는 이에 맞춰 「继续阅读（이어 읽기）」「从头阅读（처음부터 읽기）」두 진입점을 둡니다.
- 소설은 「장 + 위치」로 기록합니다. 위치가 있으면 프런트 상세의 주 버튼이 「继续阅读（이어 읽기）」이고 몇 장까지 읽었는지 알려 줍니다. 리더는 장 목차, 넘기기 / 스크롤 두 방식, 테마와 글자 크기 조절을 제공합니다. 위치가 없거나 그 위치의 장이 삭제됐으면 「从头阅读（처음부터 읽기）」로 돌아갑니다.

| 제목 | 만화·소설 모두 필수 | 비우면 책을 만들 수 없음 |

| 전체 장 모드（만화） | 스위치, 켜면 책 전체를 장으로 나누지 않음 | 켜면 시즌 수, 장 새로 만들기, 장 삭제가 모두 비활성 |
| 시즌 수（만화） | `1`～`999` 정수, 드롭다운 또는 직접 입력 | 잘못된 값은 안내가 뜨고 직전 올바른 값으로 복귀 |

| 상태（소설） | 완결 / 연재 / 초고 /미완 / 집필 중 | 카드 오른쪽 위 표시로만 쓰임 |
| 장 드롭다운 | 가져오기 전에 장 하나 선택 | 미선택이면 「만화 가져오기」비활성 |
| 이미지 업로드 | JPG·PNG·BMP·GIF, 디렉터리째 한 번에 가능 | 이름순 자동 정렬, 순서가 틀리면 앞으로 / 뒤로로 수동 조정 |
| `ComicInfo.xml` | 메타데이터 입구는 이 파일명만 허용 | 다른 이름은 장 메타데이터에 기록되지 않음 |
| CBZ 업로드 | `.cbz` 파일 선택 | 현재 버전은 「暂未支持 CBZ 文件上传（CBZ 업로드는 아직 미지원）」이라 뜨고 확인만 하고 건너뜀; 업로드 쪽에서 저장되는 것은 PDF / EPUB뿐 |
| 본문 저장 | 본문을 고친 뒤 「保存正文（본문 저장）」누르기 | 누르지 않으면 변경이 브라우저에만 있어 닫으면 사라짐 |
| 정리 폴더（수동 정리） | 만화는 필수, 서버 디렉터리 트리에서 선택; 소설은 비우면 「小说整理配置」의 폴더 | 만화는 고르지 않으면 제출 불가 |
| 폴더 서식 / 이름 규칙 | `${title}` `${author}` `${chapter}` `${index}` 등 태그 | 비우면 작업 설정 사용; 태그가 틀리면 잘못된 폴더 이름이 생김 |
| 파일 형식 / 정리 형식 | 만화는 폴더 / CBZ / CBR / CB7 / PDF / EPUB, 소설은 EPUB(기본) 또는 TXT | CBR은 서버의 `rar`이나 `AMMDS_RAR_TOOL`이 필요하고 없으면 생성 불가 |
| 장별로 생성（소설） | 켜면 장마다 파일 하나, 끄면 전권 파일 하나 | 끄면 EPUB 하나에 모든 장이 들어감 |
| 파일 이름 규칙（소설） | 전권 내보내기 때 `${chapter}`는 소설 이름, 장별일 때는 장 이름 | 틀리면 파일명과 내용이 안 맞음 |

## 문제가 생기면

- **가져온 장 순서가 엉킴**: 이미지는 파일명순으로 정렬되고 「만화 가져오기」는 표지 / 뒷표지 이미지를 처음과 끝에 둡니다. 그래도 틀리면 각 이미지의 앞으로 / 뒤로로 고치세요. 첫 장은 앞으로, 마지막 장은 뒤로 옮길 수 없습니다.
- **CBZ가 안 올라감**: 현재 버전 업로드 쪽은 `.cbz`를 지원하지 않아 형식·크기 확인만 하고 건너뛰며 「暂未支持 CBZ 文件上传（CBZ 업로드는 아직 미지원）」이라고 뜹니다. 압축 파일을 쓰려면 「手动整理（수동 정리）」로 장을 CBZ / CBR / CB7로 내보내세요.
- **CBR이 생성 안 됨**: CBR은 서버에 `rar` 도구가 있거나 `AMMDS_RAR_TOOL`로 실행 파일을 가리켜야 합니다. 없으면 CBZ나 CB7을 쓰세요.
- **소설 본문을 고쳤는데 저장이 안 됨**: 본문은 「保存正文（본문 저장）」을 눌러야 기록됩니다. 책 출처 장은 열 때 자동으로 가져오고 그동안 불러오는 표시가 덮으니 끝난 뒤 고치세요.
- **전권 다운로드가 멈추거나 실패**: 진행은 작업 로그에서 옵니다. 「查看任务日志（작업 로그 보기）」로 어느 단계에서 멈췄는지 보세요. 전권 다운로드는 책 출처 책에만 있습니다.
- **정리가 기대대로 안 나옴**: 「立即整理（바로 정리）」는 작업 관리 섹션 「任务配置（작업 설정）」의 기본 폴더·서식을 씁니다. 이번만 바꾸려면 「手动整理（수동 정리）」로 덮어쓰고, 기본값을 바꾸려면 작업 설정을 고치세요.
- **「이어 읽기」가 안 보임**: 읽은 위치는 프런트 리더에 있고 장 관리 화면에는 없습니다. 그 위치의 장이 삭제되면 처음부터 읽기로 돌아갑니다.
