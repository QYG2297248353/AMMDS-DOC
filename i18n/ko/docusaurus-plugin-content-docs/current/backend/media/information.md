# 정보 라이브러리

정보 라이브러리는 모든 정보 콘텐츠를 한곳에서 관리합니다. 출처는 두 가지뿐입니다:

- **구독 출처**: RSS 구독이 자동으로 가져온 것으로, 삭제만 할 수 있고 수정할 수 없습니다
- **직접 제작**: 관리자에서 직접 작성한 것으로, 새로 만들고 편집·삭제할 수 있습니다

## 진입점

관리자 왼쪽의 '미디어 관리' → 메뉴 마지막 항목인 '정보 라이브러리'.

## 목록은 어떻게 보나요

위쪽은 필터 영역이고, 아래는 정보 표입니다.

| 필터 | 설명 |
| --- | --- |
| 키워드 | 제목, 요약, 본문을 검색합니다. 입력 후 엔터를 눌러도 조회됩니다 |
| 출처 | 전체, 구독 출처, 직접 제작 |
| 분류 | 전체, 글, 이미지, 동영상, 자료, 기타 |

조건을 바꾼 뒤 '조회'를 누르고, '초기화'를 누르면 조건을 비우고 목록을 다시 가져옵니다.

표의 열과 내용:

| 열 | 설명 |
| --- | --- |
| 정보 | 커버 섬네일, 제목, 두 줄 요약. 제목을 누르면 상세 팝업이 열립니다 |
| 분류 | 글, 이미지, 동영상, 자료, 기타 |
| 작성자 | 여러 명은 가운뎃점으로 구분합니다. 비어 있으면 '미기재'로 표시됩니다 |
| 출처 | '구독 출처' 또는 '직접 제작'. 구독 출처는 마우스를 올리면 구체적인 구독원 이름을 볼 수 있습니다 |
| 게시 시각 | `2026-11-15 10:00:00` 형식이며, 없으면 `-`로 표시됩니다 |
| 상태 | 읽지 않음 또는 읽음 |
| 작업 | 보기, 편집, 삭제 |

목록은 게시 시각이 최신순으로 정렬됩니다. 아래 페이지는 기본적으로 페이지당 20건이며, 10, 20, 50, 100건으로 바꿀 수 있습니다.

## 새로 만들기와 일괄 삭제

- **정보 만들기**: 왼쪽 위에 항상 있으며, 누르면 작성 페이지로 들어갑니다
- **일괄 삭제**: 체크한 뒤에 나타나며, 버튼에 선택한 건수가 붙습니다. 예: '일괄 삭제 (3)'

## 구독 출처는 왜 수정할 수 없나요

구독 정보는 가져온 원문이므로 수정하면 다음 번 가져오기 때 맞지 않게 됩니다. 그래서 시스템이 읽기 전용 콘텐츠로 취급합니다:

- 행 작업에 '편집'이 없고 '보기'와 '삭제'만 있습니다
- 백엔드에서도 수정을 거부하며 '구독 출처의 정보는 편집할 수 없고 삭제만 가능합니다'라고 안내합니다

내용을 조정해야 한다면 삭제한 뒤 직접 제작으로 새로 작성하세요.

## 일괄 삭제

1. 한 건 이상 체크합니다.
2. '일괄 삭제'를 누릅니다.
3. 확인하면 삭제됩니다.

구독 출처와 직접 제작 모두 삭제할 수 있고, 삭제 후에는 복구할 수 없습니다. 단건 삭제는 행 작업에 있으며 이 경우에도 먼저 확인을 받습니다.

## 직접 정보 작성하기

'정보 만들기'를 누르면 왼쪽에 제목과 본문을 쓰고, 오른쪽에 기본 정보를 입력합니다.

| 필드 | 설명 |
| --- | --- |
| 제목 | 필수, 최대 200자 |
| 본문 | 필수, Markdown으로 작성합니다. 아래 참고 |
| 커버 | 선택. 클릭하거나 이미지를 점선 테두리 안으로 끌어다 업로드하며, 업로드 후 교체·삭제할 수 있습니다. 이미지만 허용되고 한 장당 10MB를 넘을 수 없습니다 |
| 작성자 | 선택, 최대 100자 |
| 분류 | 선택. 글, 이미지, 동영상, 자료, 기타 |
| 원문 링크 | 선택. 원본 글 주소를 입력합니다. 예: `https://example.com/article` |
| 게시 시각 | 선택. 시·분·초까지 지정하며, 기본값은 현재 시각입니다 |

이미 존재하는 직접 정보를 편집할 때도 양식은 같습니다. 구독 출처의 정보는 편집 페이지에 들어갈 수 없고, 안내 메시지를 띄운 뒤 목록으로 돌아갑니다.

### 본문 편집기

본문은 Markdown으로 작성하며, 편집기는 세 가지 보기 방식을 제공합니다: **편집**, **분할**, **미리보기**. 분할은 왼쪽에 쓰고 오른쪽에서 결과를 실시간으로 보는 방식입니다.

도구 모음은 왼쪽부터 굵게, 기울임, 제목, 인용, 코드, 목록, 구분선, 링크 삽입, 이미지 삽입 순서입니다.

이미지를 삽입하는 방법은 두 가지입니다:

- 이미지 주소(URL) 입력
- 로컬 이미지 업로드

링크를 삽입할 때는 링크 주소와 링크 텍스트를 입력해야 합니다. 저장하면 Markdown과 함께 변환된 웹 콘텐츠도 한 부 저장되며, 목록과 프런트 화면에서는 변환된 결과를 사용합니다.

## 게시 후 어디에서 보나요

- 프런트 상단 탐색 마지막 항목인 '정보'이며, 주소는 `/home/information`입니다
- 정보 목록은 로그인하지 않아도 볼 수 있습니다
- 상세 페이지에 들어가려면 로그인이 필요합니다

## 자주 묻는 질문

| 현상 | 설명 |
| --- | --- |
| '편집' 버튼을 찾을 수 없음 | 구독 출처의 정보는 읽기 전용이어서 삭제만 가능합니다 |
| 제목이 저장되지 않음 | 제목은 필수이며 최대 200자입니다 |
| 본문이 저장되지 않음 | 본문은 필수입니다 |
| 본문의 이미지가 표시되지 않음 | 이미지 주소를 직접 열 수 있는지 확인하거나 업로드 방식을 사용하세요 |
| 프런트에서 새 정보가 보이지 않음 | 게시 시각이 미래로 설정되었는지 확인하세요. 프런트는 게시 시각 순으로 정렬합니다 |
