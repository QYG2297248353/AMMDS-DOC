# 시리즈 · 메이커 · 태그

이 세 페이지는 영화 자체를 보관하지 않고 영화를 「분류」합니다. 시리즈는 여러 작품을 둘러볼 수 있는 하나로 묶고, 메이커는 발행사별로 작품을 모으고, 태그 라이브러리는 사이트 전체가 함께 쓰는 낱말의 출처입니다. 이 페이지는 하려는 일에 따라 만드는 법, 작품을 넣는 법, 그리고 어떤 변경이 이미 등록된 영화에 영향을 주는지(주지 않는지)를 알려 줍니다.

## 먼저 알아 두기

> **작품 번호 / 식별 코드**: 파일명에 들어 있는 식별 번호입니다. 시리즈 라이브러리와 메이커 라이브러리 모두 이것으로 작품을 역으로 찾습니다.

> **메타데이터**: 작품의 표지·줄거리·출연진·태그 같은 설명 정보입니다. 메이커 이름, 시리즈 이름, 태그가 모두 여기에 기록됩니다.

> **NFO**: 영상과 같은 곳에 두는 작은 설명 파일로 작품의 메타데이터가 적혀 있습니다. 미디어 서버도 읽습니다.

> **스크레이핑**: 자료 사이트에서 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다.

> **별명**: 같은 것의 다른 표기입니다. 메이커는 자료 출처마다 이름이 다를 수 있어, 별명으로 그 차이를 흡수합니다.

> **여러 값 입력**: 한 칸에 값을 여러 개 넣고, 입력할 때마다 Enter로 추가합니다. 별명이나 태그가 그렇습니다.

> **이름 기반 느슨한 연결**: 양쪽이 「이름이 맞는다」는 것만으로 이어질 뿐 단단히 고정된 게 아닙니다. 그래서 표기가 달라지면 그 작품들이 집계에서 빠질 수 있습니다.

> **정규식**: 「어떤 표기에 맞는 문자열」을 기호로 적은 규칙으로, 식별 코드를 한꺼번에 맞대는 데 씁니다. 익숙하지 않으면 다른 두 규칙 유형을 먼저 쓰세요.

> **가중치 / 인용**: 태그 라이브러리에서 그 태그가 얼마나 자주 쓰이는지 보여 주는 값으로, 자주 쓰는 태그를 앞에 두기 위한 것이고 정확한 작품 수는 아닙니다.

## 시리즈: 여러 작품을 하나로 묶기

### 시리즈 찾고 만들기

媒体管理 → 系列库（미디어 관리 → 시리즈 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 시리즈 검색 | 키워드(시리즈 이름 / 설명), 작품 식별 코드 |
| 빠른 동작 | 「新建系列（시리즈 새로 만들기）」, 행 체크 후 「删除（삭제）」등장 |
| 데이터 표 | 시리즈, 동작 |

「시리즈」열이 정보의 중심입니다. 왼쪽 표지, 오른쪽 시리즈 이름(누르면 상세로), 설명, 「N 部作品（작품 N편）」라벨. 「동작」열에 **상세, 공유, 편집, 삭제**가 있습니다. 검색칸의 「작품 식별 코드」는 시리즈를 역으로 찾는 데 써서, 번호 하나를 넣으면 그 작품이 든 시리즈를 찾습니다.

새로 만들기와 편집은 같은 창을 쓰고 항목은 셋뿐입니다:

| 항목 | 설명 |
| --- | --- |
| 표지 | 클릭 또는 드래그로 이미지 업로드, 지우고 다시 올리기도 가능 |
| 시리즈 이름 | 필수 |
| 시리즈 설명 | 선택 |

:::note[표지 규격]
표지 업로드는 이미지만, 최대 10 MB입니다. 올리면 세로 섬네일로 보입니다.
:::

### 시리즈에 작품 넣기

목록 행의 「상세」나 시리즈 이름을 누르면 상세로 들어갑니다. 위에 시리즈 이름과 「작품 N편」, 오른쪽에 **편집**과 **공유**, 왼쪽에 표지와 설명, 오른쪽에 작품 영역 도구 모음과 작품 표——**添加作品（작품 추가）**, **批量导入（일괄 가져오기）**, 체크 후 나타나는 **移出系列（시리즈에서 빼기）**, 그리고 「작품 이름으로 걸러내기」검색칸이 있습니다. 표의 각 행은 번호, 작품(표지 + 제목 + 식별 코드 + 발행일), 동작(보기, 빼기)이고 「보기」는 그 영화의 상세 편집으로 갑니다.

**작품 추가**（이미 있는 영화 라이브러리에서 고르기）:

1. 「添加作品（작품 추가）」로 창을 엽니다.
2. 「라이브러리 작품 검색」칸에서 제목으로 영화 라이브러리를 찾습니다.
3. 작품을 하나 이상 체크하고 「添加选中（N）（선택한 N개 추가）」를 누릅니다.
4. 끝나면 추가한 작품 수가 안내됩니다.

**일괄 가져오기**（식별 코드로 시리즈 전체를 한 번에 정리）:

1. 텍스트칸에 식별 코드를 붙여 넣습니다. 쉼표, 줄바꿈, 공백, 세미콜론으로 구분합니다. 예:

   ```
   SSIS-001, IPX-002
   MIDE-003
   ABP-004
   ```

2. 「开始导入（가져오기 시작）」을 누릅니다.
3. 라이브러리에 있는 작품은 곧바로 시리즈에 들어가고, 없는 작품은 온라인 검색으로 가져오기를 시도합니다.
4. 결과에 성공 수가 나오고, 실패 항목은 「식별 코드」와 「실패 이유」를 알려 줍니다.

:::warning[온라인 가져오기가 의존하는 것]
일괄 가져오기의 「라이브러리에 없으면 온라인 검색」단계는 켜진 자료 출처에 의존합니다. 자료 출처가 설정되지 않았거나 닿지 않으면 그 식별 코드들이 실패 이유로 돌아옵니다. 먼저 연동 앱에서 자료 출처를 설정하세요.
:::

**시리즈에서 빼기**: 한 건은 행 안의 삭제 버튼, 여러 건은 체크 후 「移出系列（시리즈에서 빼기）」이며 둘 다 재확인합니다. 빼기는 작품과 시리즈의 연결만 끊고 영화 항목 자체는 지우지 않습니다.

### 영화의 「시리즈」항목과 혼동하지 않기

영화 상세 편집 화면에도 「시리즈 정보」묶음이 있어 그 작품이 속한 시리즈 이름과 시리즈 안에서의 설명을 기록합니다. 이는 **영화 메타데이터**에 속하며 시리즈 라이브러리의 시리즈와는 별개의 데이터입니다:

| 데이터 | 관리 위치 | 용도 |
| --- | --- | --- |
| 영화의 시리즈 항목 | 영화 라이브러리 → 상세 편집 → 시리즈 정보 | 그 한 편의 메타데이터와 NFO에 기록 |
| 시리즈 실체 | 시리즈 라이브러리 → 시리즈 상세 | 작품을 묶고 시리즈 페이지·시리즈 공유를 만듦 |

따라서 작품을 시리즈 라이브러리에 넣으려면 명시적으로 「작품 추가」나 「일괄 가져오기」를 해야 합니다. 영화 메타데이터에 시리즈 이름을 적었다고 자동으로 소속되지는 않습니다.

## 메이커: 발행사별로 작품 자동으로 모으기

### 메이커 찾고 만들기

媒体管理 → 厂牌库（미디어 관리 → 메이커 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 도구 모음 | 왼쪽 「创建厂牌（메이커 만들기）」「识别码归属测试（식별 코드 소속 테스트）」, 오른쪽 「메이커 이름 또는 별명 검색」 |
| 카드 | 메이커마다 한 장, 누르면 상세 |

검색칸은 입력하는 즉시 걸러 내고, 비우면 전체로 돌아갑니다. 목록은 작품 총수 내림차순이라 작품이 많은 메이커가 앞에 옵니다.

카드 정보:

| 요소 | 설명 |
| --- | --- |
| 이미지 | 마우스를 올리면 「이미지 교체」가 뜨고 누르면 바로 교체 |
| 이름 | 메이커 이름, 오른쪽 별은 「重点关注（주요 관심）」표시 |
| 유형 라벨 | 제작사 / 발행사 / 소속사 / 기타 |
| 태그 | 앞의 2개만 보이고 나머지는 「+N」로 접힘 |
| 집계 | 「영화 N편 · 시리즈 N편」, 규칙이 있으면 「규칙 N개」추가 |
| 삭제 | 카드 위 삭제 버튼 |

「创建厂牌（메이커 만들기）」에서 다음을 입력합니다:

| 항목 | 설명 |
| --- | --- |
| 메이커 이름 | 필수, 영화 메타데이터의 제작사 이름과 일치해야 함, 최대 100자 |
| 메이커 유형 | 제작사 / 발행사 / 소속사 / 기타 |
| 설립 연도 | 1800–2200 정수 |
| 국가 / 지역 | 예 「일본」 |
| 웹사이트 | `https://`로 시작, 상세에서 눌러 이동 가능 |
| 별명 | 여러 값, 입력 후 Enter |
| 태그 | 여러 값, 입력 후 Enter |
| 설명 | 메이커 소개, 최대 500자 |
| 메이커 이미지 | 창 오른쪽에서 업로드, 눌러 교체 |

:::tip[이름은 메타데이터와 일치시킵니다]
메이커와 작품은 이름으로 느슨하게 연결되므로 「메이커 이름」이 영화 메타데이터의 제작사 이름과 완전히 같아야 하며, 그렇지 않으면 집계에 그 작품이 보이지 않습니다. 자료 출처 표기가 다를 때는 「별명」으로 차이를 흡수합니다.
:::

:::warning[메이커 삭제가 미치는 것]
삭제하면 그 메이커의 규칙과 제외 항목도 함께 지워지지만, **영화나 시리즈 메타데이터는 하나도 바꾸지 않습니다**. 이미 작품에 기록된 메이커 이름은 남습니다.
:::

### 식별 코드 규칙으로 작품 자동 거두기

메이커의 작품 출처는 두 길, **직접 추가**와 **식별 코드 규칙 자동 수납**입니다. 별명은 맞대기용, 규칙은 소속 자동 판정용입니다.

메이커 상세 →「식별 코드 규칙」탭에서 관리합니다:

| 항목 | 설명 |
| --- | --- |
| 규칙 유형 | 식별 코드 접두사 / 식별 코드 정확히 / 정규식 |
| 맞댈 식 | 고른 유형에 맞게 입력, 최대 200자 |
| 맞으면 기록할 곳 | 제작사 / 발행사 / 제작 + 발행 |
| 우선순위 | -9999～9999, 여러 규칙이 동시에 맞을 때 정렬에 사용 |
| 사용 | 끄면 이 규칙은 판정에 참여하지 않음 |
| 설명 | 규칙 근거 메모, 예 「이 메이커가 SSIS 시리즈 발행권을 가짐」 |
| 저장 뒤 | 「규칙으로 지금 작품을 영화 메타데이터에 수납」체크 가능 |

「맞은 개수 미리보기」는 기록하지 않고 이 규칙이 몇 편에 맞는지 먼저 볼 수 있어 저장 여부를 정하는 데 쓸 수 있습니다.

소속 판정과 수납 순서:

1. 영화 항목을 저장할 때 **켜진** 규칙에 따라 메이커를 제작사 / 발행사에 자동 기록합니다.
2. 메이커 상세의 「立即收纳作品（지금 작품 수납）」(규칙 탭에서는 「지금 수납」)으로 한 번 직접 실행할 수도 있습니다.
3. 규칙에 맞아 수납된 작품은 카드에 맞은 규칙 이름이 표시돼, 어느 규칙으로 들어왔는지 거슬러 볼 수 있습니다.
4. 작품을 빼면 시스템이 **제외 항목**을 하나 기록해, 다음 자동 수납에서 다시 끌어오지 않게 합니다.

:::note[규칙을 지워도 되돌리지 않습니다]
식별 코드 규칙 삭제는 이후 판정에만 영향을 주고, 이미 영화 메타데이터에 기록된 메이커 이름은 되돌리지 않습니다.
:::

위쪽 「识别码归属测试（식별 코드 소속 테스트）」는 규칙 탭 안의 테스트칸과 같습니다. 식별 코드(예 `SSIS-001`)를 넣으면 맞은 메이커와 해당 식을 돌려주고, 맞는 게 없으면 「未命中任何厂牌规则（어떤 메이커 규칙에도 맞지 않았습니다）」라고 뜹니다. 규칙을 조정할 때 먼저 이걸로 확인하면 저장하고 결과를 보는 것보다 빠릅니다.

### 메이커 상세에서 또 무엇을 고칠 수 있나

카드를 누르면 상세 서랍이 열립니다. 머리에 이미지, 이름, 유형, 주요 관심 별, 국가, 설립 연도, 웹사이트, 설명, 태그, 별명, 그리고 집계 셋——**영화 수, 시리즈 수, 식별 코드 규칙 수**가 있습니다. 아래에 탭 셋:

- **작품**: 위의 라디오 「전체 / 영화 / 시리즈」로 미디어 유형을 바꾸고, 오른쪽에서 「제목 또는 식별 코드」로 검색합니다. 「작품 추가」창에서는 제목이나 식별 코드로 영화를 찾고, 이미 메이커에 있는 항목은 「已在厂牌（메이커에 있음）」으로 표시되며 추가할 수 없습니다. 작품 카드는 유형 각인, 제목, 식별 코드, 연도, 맞은 출처, 맞은 규칙을 보여 주고 동작은 「보기」(해당 영화·시리즈 편집으로)와 「빼기」. 아래에 페이지 이동이 있습니다.
- **식별 코드 규칙**: 식과 설명, 사용 스위치, 편집·삭제를 나열한 표입니다. 위에 「규칙 추가」「지금 수납」, 오른쪽 위에서 식별 코드 소속 테스트를 할 수 있습니다.
- **자료**: 메이커 유형, 설립 연도, 국가 / 지역, 웹사이트, 별명, 태그, 설명, 「주요 관심」스위치를 고칠 수 있고, 저장하면 카드와 집계도 갱신됩니다.

:::tip[주요 관심]
「주요 관심」은 표시일 뿐이라 카드에 별을 보여 주기만 합니다. 작품 수납 방식은 바꾸지 않습니다.
:::

## 태그: 사이트 전체가 쓰는 낱말 출처

### 세 층 구조

태그 라이브러리는 영화·시리즈·배우·만화·소설 다섯 종류의 편집 화면에서 고를 수 있는 후보의 유일한 출처입니다.

| 층 | 뜻 | 개수 |
| --- | --- | --- |
| 미디어 유형 | 내용의 큰 분류, 다섯으로 고정 | 5 |
| 분류 | 각 미디어 유형 아래의 태그 묶음; 시스템 기본 + 사용자 생성 | 5 + N |
| 태그 | 구체적 낱말, 별명·색·가중치를 가짐 | 제한 없음 |

시스템 기본 분류 다섯 개:

| 카드 제목 | 미디어 유형 | 태그 유형 |
| --- | --- | --- |
| 영화 태그 | 영화 | `tag_movie` |
| 시리즈 태그 | 시리즈 | `tag_tv` |
| 배우 태그 | 배우 | `tag_actor` |
| 만화 태그 | 만화 | `tag_comic` |
| 소설 태그 | 소설 | `tag_novel` |

사용자가 만든 분류는 반드시 어떤 미디어 유형 아래에 있어야 하므로, 시스템 분류와 같은 미디어 유형 필터를 함께 씁니다.

### 화면과 카드

媒体管理 → 标签库（미디어 관리 → 태그 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 도구 모음 | 왼쪽 「분류 만들기」, 오른쪽 유형 필터 드롭다운과 「태그 또는 별명 검색」 |
| 카드 | 한 장이 분류 하나, 한 줄에 최대 4개 |

위 유형 필터를 바꾸면 그 미디어 유형의 카드만 남고, 검색칸은 태그 이름이나 별명으로 걸러 냅니다.

카드 제목은 분류 이름이고, 시스템 분류는 「미디어 유형 + 태그」로 이름 붙입니다(예 「영화 태그」). 제목 옆 배지에 「시스템」또는 「사용자」가 표시됩니다. 오른쪽 위에 「共 N 个（총 N개）」, 즉 그 분류의 태그 수가 보입니다. 사용자가 만든 분류는 지울 수 있고, 지우면 그 아래 태그가 **시스템 기본 분류로 되돌아가** 태그가 사라지지 않습니다. 카드 안은 태그 표로, 태그 이름(정한 색으로 칠함), 「인용」값, 편집 / 삭제 두 동작이 있습니다.

### 분류 만들기, 태그 추가와 편집

「분류 만들기」에서 이름(최대 30자)을 넣고 미디어 유형을 하나 고르면 됩니다. 분류는 태그를 정리하는 용도일 뿐 내용 검색에는 참여하지 않습니다.

카드 도구 모음 오른쪽의 「추가」나 태그 행의 편집 아이콘을 누릅니다:

| 항목 | 설명 |
| --- | --- |
| 이름 | 필수, 최대 50자. 정리할 때 **대표 이름**으로 NFO에 기록 |
| 별명 | 여러 값, 입력 후 Enter, 여러 개 가능 |
| 색 | 팔레트의 미리 정한 10색, 또는 HEX 값 직접 입력(기본 `#165dff`) |

:::note[별명의 역할]
자료 출처가 같은 개념을 다르게 돌려줄 수 있습니다(한·중·일, 간체·번체, 줄임말 등). 그 차이를 「별명」에 넣으면 맞댈 때 별명으로도 알아보고, NFO에는 그래도 대표 이름으로 기록합니다.
:::

:::warning[태그 삭제의 경계]
태그 삭제는 태그 라이브러리에서 낱말만 빼고, **이미 저장된 메타데이터에는 영향이 없습니다**. 영화·배우 등 항목에 이미 적힌 유형과 태그 글자는 남고, 이후 후보에서 고를 수 없게 될 뿐입니다.
:::

### 가중치와 「인용」

태그마다 가중치가 있고 카드 표에서는 「인용」열로 보입니다:

- 태그가 한 번 맞을 때마다 가중치가 1 오릅니다;
- 시스템이 주기적으로 깎는데 한 번에 최대 10%(내림)이고, **1 아래로는 절대 내려가지 않습니다**;
- 즉 인기 지표로 「인용된 대략적 횟수」이며 정확한 작품 수가 아닙니다.

정렬과 표시는 이걸 써서 자주 쓰는 태그를 앞에 두어 편집 화면에서 빨리 고를 수 있게 합니다.

### 일상에서 어디서 쓰나

태그 라이브러리 자체에는 검색이 둘 있습니다. 미디어 유형으로 카드를 걸러 내기, 태그 이름이나 별명으로 찾기입니다. 더 자주 쓰는 진입점은 각 내용 편집 화면의 태그 드롭다운입니다:

| 편집 화면 | 찾는 태그 유형 |
| --- | --- |
| 영화 상세 편집 → 유형 / 태그 | 영화 태그 |
| 시리즈 편집 → 유형 / 태그 | 시리즈 태그 |
| 배우 상세 → 태그 / 스타일 / 특징 | 배우 태그 |
| 만화·소설 편집 | 각각의 태그 유형 |

이 드롭다운은 모두 태그 라이브러리를 검색하고(시스템 분류 + 사용자 분류 모두 보임), 새 낱말 직접 입력도 지원합니다. 라이브러리에 없는 값은 새 태그로 함께 제출됩니다.

:::tip[한 곳에서 관리하면 좋은 점]
어느 편집 화면에서 만든 태그든 태그 라이브러리의 해당 분류로 돌아와, 다음엔 어떤 항목에서도 고를 수 있습니다. 동의어를 한꺼번에 정리하려면 여기 별명을 한 번만 고치면 모든 참조처에 반영됩니다.
:::

## 설정 항목 설명

| 설정 항목 | 무엇을 넣나 | 비우거나 틀리면 |
| --- | --- | --- |
| 시리즈 이름 | 필수 | 비우면 시리즈를 만들 수 없음 |
| 시리즈 표지 | 이미지, 최대 10 MB | 이미지가 아니거나 초과하면 올릴 수 없음. 세로 섬네일로 보임 |
| 작품 식별 코드(시리즈 검색) | 번호 하나 | 그 작품이 든 시리즈를 역으로 찾는 데 씀 |
| 일괄 가져오기 식별 코드 | 여러 개 붙여 넣기, 쉼표·줄바꿈·공백·세미콜론 구분 | 라이브러리에 없고 자료 출처도 없으면 「실패 이유」로 돌아옴 |
| 메이커 이름 | 필수, 최대 100자, 영화 메타데이터의 제작사 이름과 완전히 일치 | 표기가 다르면 집계에 안 나옴. 「별명」으로 차이를 흡수 |
| 메이커 유형 | 제작사 / 발행사 / 소속사 / 기타 | 분류 라벨일 뿐 |
| 설립 연도 | 1800–2200 정수 | 범위 밖은 받지 않음 |
| 웹사이트 | `https://`로 시작 | 아니면 상세의 링크가 열리지 않음 |
| 별명 / 태그（메이커） | 여러 값, 입력마다 Enter | Enter를 안 누르면 추가되지 않음 |
| 설명（메이커） | 메이커 소개, 최대 500자 | 글자 초과는 받지 않음 |
| 규칙 유형 | 식별 코드 접두사 / 정확히 / 정규식 | 유형이 틀리면 안 맞거나 너무 많이 맞음 |
| 맞댈 식 | 고른 유형에 맞게, 최대 200자 | 틀리면 작품에 안 맞음. 먼저 「맞은 개수 미리보기」나 「소속 테스트」로 확인 |
| 맞으면 기록할 곳 | 제작사 / 발행사 / 제작 + 발행 | 틀리면 엉뚱한 항목에 기록 |
| 우선순위 | -9999～9999 | 여러 규칙이 동시에 맞을 때 정렬. 틀리면 다른 메이커가 선택됨 |
| 사용（규칙） | 스위치 | 끄면 판정에 참여하지 않음 |
| 식별 코드 소속 테스트 | 식별 코드 하나, 예 `SSIS-001` | 맞는 게 없으면 「어떤 메이커 규칙에도 맞지 않았습니다」라고 뜸 |
| 분류 이름 | 최대 30자, 미디어 유형 하나 | 분류는 태그 정리용이라 검색 논리에 참여 안 함 |
| 태그 이름 | 필수, 최대 50자, 대표 이름으로 NFO에 기록 | 비우면 태그를 만들 수 없음. 대표 이름이 NFO 글자를 정함 |
| 태그 별명 | 여러 값, 입력마다 Enter | 비우면 대표 이름만 맞대어, 같은 개념의 다른 표기를 못 알아봄 |
| 태그 색 | 10색, 또는 HEX 값(기본 `#165dff`) | 카드 칠하기에만 영향 |
| 유형 / 태그 드롭다운 입력 | 후보에서 고르거나 새 낱말 직접 입력 | 라이브러리에 없는 값은 새 태그로 함께 제출됨 |

## 문제가 생기면

- **시리즈 라이브러리에 넣은 작품이 시리즈 페이지에 안 나옴**: 영화 메타데이터에 시리즈 이름을 적어도 자동 소속되지 않습니다. 「작품 추가」나 「일괄 가져오기」를 명시적으로 쓰세요.
- **일괄 가져오기 실패가 많음**: 먼저 「실패 이유」를 보세요. 대부분 자료 출처가 꺼졌거나 닿지 않기 때문입니다. 연동 앱에서 자료 출처를 설정하고 다시 실행하세요.
- **메이커 집계에 일부 작품이 빠짐**: 메이커는 이름으로 느슨하게 연결되므로 「메이커 이름」을 영화 메타데이터의 제작사 이름과 완전히 일치시키세요. 표기가 다르면 「별명」에 넣으세요.
- **수납한 작품을 뺄 수 없거나 다시 돌아옴**: 빼면 제외 항목이 기록돼 다음 자동 수납에서 다시 끌어오지 않습니다. 규칙 삭제는 이후 판정에만 적용되고 이미 메타데이터에 적힌 메이커 이름은 되돌리지 않습니다.
- **규칙이 잘 안 맞음**: 먼저 「맞은 개수 미리보기」로 몇 편에 맞는지 보거나 「소속 테스트」에 식별 코드를 하나 넣어 결과를 확인한 뒤 저장 여부를 정하세요.
- **태그 / 분류 / 메이커를 지워 자료가 사라질까 걱정됨**: 태그 삭제는 낱말만, 사용자 분류 삭제는 태그가 시스템 기본으로 돌아감, 메이커 삭제는 영화·시리즈 메타데이터를 하나도 바꾸지 않습니다. 적힌 글자는 남고 후보에서 못 고를 뿐입니다.
- **「인용」값이 작품 수와 안 맞음**: 깎이는 인기 지표라 정확한 수가 아닙니다. 자주 쓰는 태그가 앞에 오는 건 편집 화면에서 빨리 고르게 하려는 것입니다.

영화·시리즈·배우 관리는[영화 · 시리즈 · 배우](./library.md), 만화와 소설 관리는[만화와 소설](./comic.md)에 있습니다.
