# 영화 · 시리즈 · 배우

스캔과 스크레이핑으로 항목이 라이브러리에 들어온 뒤의 일상 관리가 이 세 페이지에서 이뤄집니다. 영화 라이브러리는 편 한 편, 시리즈 라이브러리는 한 작품의 시즌과 회차, 배우 라이브러리는 사람과 출연작 연결을 맡습니다. 이 페이지는 「하려는 일」에 따라 찾기·채우기·고치기·지우기와, 한 번 지우면 되돌릴 수 없는 동작을 알려 줍니다.

## 먼저 알아 두기

> **작품 번호 / 식별 코드**: 파일명에 들어 있는 식별 번호입니다. 검색창에서는 「番号」, 상세·편집 화면에서는 「识别码」라고 부르지만 같은 것이며, 한 편에 여러 개 있을 수 있습니다.

> **메타데이터**: 한 편의 표지·줄거리·출연진·태그 같은 설명 정보입니다.

> **스크레이핑**: 자료 사이트에서 표지·줄거리·출연진을 찾아 자동으로 채워 넣는 일입니다.

> **사이트 ID**: TMDB, Bangumi, IMDb 같은 자료 사이트가 같은 작품에 붙인 번호로, 사이트끼리 같은 작품을 맞대 볼 때 씁니다.

> **연결**: 라이브러리의 한 기록을 디스크의 특정 영상 파일(또는 다른 기존 기록)에 이어 주어 「바로 이 파일 / 이 작품」이라고 알게 하는 것입니다.

> **여러 값 입력**: 한 칸에 값을 여러 개 넣고, 하나를 입력한 뒤 Enter로 추가합니다. 태그·유형·별명 등이 그렇습니다.

## 기록을 찾고 읽기

세 라이브러리 모두 媒体管理（미디어 관리）아래에 있고 생김새가 비슷합니다. 위는 검색 조건, 가운데는 빠른 동작, 아래는 표나 카드입니다.

### 영화 라이브러리

媒体管理 → 影视库（미디어 관리 → 영화 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 검색 조건 | 제목, 작품 번호, 배우, 유형, 태그, 시리즈 여섯 칸, 오른쪽에 「搜索（검색）」「重置（초기화）」 |
| 빠른 동작 | 왼쪽 「添加媒体（미디어 추가）」「搜索影视（영화 검색）」, 행을 체크하면 「合并媒体（미디어 통합）」「删除媒体（미디어 삭제）」 등장; 오른쪽 「来源（출처）」 드롭다운 |
| 데이터 표 | 번호, 표지, 정보, 태그, 배우, 동작, 아래에 페이지 이동과 페이지당 개수 |

| 검색 항목 | 맞는 방식 |
| --- | --- |
| 제목 | 원제와 중국어 제목을 부분 일치 |
| 작품 번호 | 식별 코드로 일치 |
| 배우 | 배우 이름으로 일치 |
| 유형 | 여러 값, 하나라도 맞으면 됨(입력 후 Enter) |
| 태그 | 여러 값, 하나라도 맞으면 됨 |
| 시리즈 | 시리즈 이름으로 일치 |

「정보」열에는 식별 코드, 중국어 제목(없으면 원제로 대체)이 보이고 아래에 **발행일, 상영 시간, 등급, 평점**이 태그로 나열되며, 홍보 문구가 있으면 한 줄 더 씁니다. 「태그」「배우」두 열은 이 기록의 태그와 배우 이름을 그대로 보여 줍니다.

:::tip[두 조회 경로는 다릅니다]
오른쪽 위 「来源（출처）」드롭다운은 바꾸는 즉시 다시 조회합니다. 「검색 조건」은 값을 고친 뒤 직접 「搜索（검색）」을 눌러야 제출되고, 「重置（초기화）」는 입력칸만 비우며 자동으로 다시 조회하지 않습니다.
:::

### 시리즈 라이브러리

媒体管理 → 剧集库（미디어 관리 → 시리즈 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 시리즈 검색 | 제목, 식별 코드, 배우, 유형(구분), 태그, 상태, 오른쪽에 「搜索（검색）」「重置（초기화）」 |
| 빠른 동작 | 「新建剧集（시리즈 새로 만들기）」「搜索剧集（시리즈 검색）」, 체크하면 「删除（삭제）」 등장; 오른쪽 「来源（출처）」 드롭다운 |
| 데이터 표 | 번호, 표지, 시리즈 정보, 구분, 출처, 시즌 / 회차, 갱신 시각, 동작 |

| 검색 항목 | 맞는 방식 |
| --- | --- |
| 제목 | 작품명·원명·중국어명에 일치 |
| 식별 코드 | TMDB / Bangumi / IMDb 등 사이트 ID |
| 배우 | 배우 이름으로 일치 |
| 유형 | 구분, 값은 프로그램이 내려줍니다 |
| 태그 | 여러 값, 입력 후 Enter |
| 상태 | 연재 중 / 완결 |
| 출처 | 데이터 출처, 「전체」를 고르면 걸러 내지 않음 |

「시즌 / 회차」열은 「N 시즌」「N 회차」두 줄로 보입니다. 각 행 오른쪽에 **공유, 상세, 편집, 삭제**가 있습니다. 검색의 「유형」은 「구분」에 해당하고, 「출처」의 선택지는 프로그램이 내려주며 고정된 값이 아닙니다.

:::note[재생은 프런트에 없습니다]
시리즈의 파일 연결, 사용 가능 여부 검증, 시즌 매핑은 관리 화면에서만 보고 고칠 수 있습니다. 프런트의 시리즈 상세는 자료와 시즌·회차 구조만 보여 주고 파일 목록이나 재생기는 없습니다. 감상하려면 외부 재생기나 미디어 서버를 쓰세요.
:::

### 배우 라이브러리

媒体管理 → 演员库（미디어 관리 → 배우 라이브러리）로 갑니다:

| 영역 | 내용 |
| --- | --- |
| 검색 조건 | 이름, 성별, 은퇴, 사망, 태그, 스타일, 특징, 나이 슬라이더 |
| 빠른 동작 | 「新增演员（배우 추가）」「搜索演员（배우 검색）」, 체크하면 「合并演员（배우 통합）」「删除演员（배우 삭제）」 등장; 오른쪽 「来源（출처）」 드롭다운 |
| 데이터 표 | 번호, 이름, 소속사, 데뷔일, 국적, 동작 |

| 검색 항목 | 설명 |
| --- | --- |
| 이름 | 배우 이름 부분 일치 |
| 성별 | 남성 / 여성 / 트랜스젠더 |
| 은퇴 | 은퇴 / 현역 / 전체 |
| 사망 | 사망 / 생존 / 전체 |
| 태그 / 스타일 / 특징 | 서로 다른 세 태그 축, 각각 여러 값 입력 |
| 나이 | 슬라이더 단계: 전체, 20세, 20–30, 30–40, 40세 |

「이름」열이 중심입니다. 왼쪽에 큰 사진, 오른쪽에 이름과 태그(성별, 나이, 특징, 신체 치수, 은퇴 / 사망 상태). 나머지 열은 소속사, 데뷔일, 국적이고 마지막 열은 **공유, 상세, 삭제**입니다. 영화 라이브러리와 같이 「来源（출처）」는 바꾸면 즉시 재조회하고, 입력 조건은 「搜索（검색）」을 눌러야 제출되며 「重置（초기화）」는 입력칸만 비웁니다.

## 작품을 알아보는 것

같은 편이라도 식별 코드가 여러 개일 수 있고, 화면에서 두 가지로 불립니다:

| 위치 | 설명 |
| --- | --- |
| 검색 조건 → 작품 번호 | 식별 코드로 검색 |
| 목록 → 정보 | 제목 앞에 이 기록의 첫 식별 코드 표시 |
| 상세 서랍 → 식별 코드 | 전체 식별 코드를 쉼표로 구분해 표시 |
| 상세 편집 → 식별 코드 | 여러 값 입력칸, 추가·삭제·직접 지정 가능 |

식별 코드는 스캔할 때 인식 규칙으로 파일명에서 뽑아 정규화한 것이라, 같은 편의 다른 표기가 한 기록으로 합쳐집니다. 규칙은 작업 관리 섹션에서 설정합니다. 직접 편을 추가할 때는 식별 코드를 직접 넣을 수 있고, 구독이 이를 따라 이후 자료를 추적합니다.

## 새 기록 추가하기

### 영화: 搜索影视（영화 검색）

「搜索影视（영화 검색）」을 눌러 온라인 검색 창을 열고 작품 번호나 제목을 입력한 뒤 Enter:

1. 최근 검색어는 최대 20개까지 브라우저에 로컬로 저장되며, 한 번 누르면 다시 쓸 수 있습니다.
2. 결과 카드에 작품 번호, 발행일, 데이터 출처, 제목이 보이고 오른쪽 위에 버튼 셋:

| 버튼 | 하는 일 |
| --- | --- |
| 가져오기 | 영화 라이브러리에 기록, 끝나면 목록을 새로고침하고 창을 닫음 |
| 즐겨찾기 | 먼저 가져온 뒤 즐겨찾기에 추가 |
| 구독 | 먼저 가져온 뒤 작품 번호로 구독을 만들어, 구독 작업이 이후 자료를 추적하게 함 |

3. 결과가 없으면 최근 검색 영역이 보이고 처음에는 「搜索一下，试试看吧（한 번 검색해 보세요）」라고 뜹니다.

즐겨찾기와 구독은 사용자별 표시이며, 「일시 정지 / 재개 / 구독 해지」같은 이후 상태는 구독 관리가 맡고 이 페이지에서는 관리하지 않습니다.

### 시리즈: 搜索剧集（시리즈 검색）

「搜索剧集（시리즈 검색）」은 한 편을 직접 보충할 때 씁니다:

1. 작품명 키워드(예 `葬送的芙莉莲`)를 입력하고 Enter. 키워드는 로컬 최근 검색에 최대 20개 저장됩니다.
2. 후보 카드에 세로 포스터, 연도, 데이터 출처, **일치 점수**(소수 셋째 자리까지)가 보입니다.
3. 「가져오기」를 누르면 시즌 번호 입력칸이 뜹니다. 비우면 그 출처의 모든 시즌, `0`은 특별편, `1`～`99`는 해당 시즌만 가져옵니다.
4. 성공하면 「导入成功，可在剧集详情中完善元数据与季集（가져오기 성공, 시리즈 상세에서 메타데이터와 시즌·회차를 보완하세요）」라고 뜹니다.

:::note[가져오기는 먼저 합칩니다]
데이터 출처에 같은 사이트 ID가 이미 있으면 기존 시리즈에 **합쳐** 들어가고 중복으로 새로 만들지 않습니다. 가져오기는 등록까지만이며, 이후 시즌·회차와 파일은 상세에서 관리합니다.
:::

### 배우: 추가와 검색

「新增演员（배우 추가）」는 편집 화면에서 직접 채우고, 「搜索演员（배우 검색）」은 온라인 검색 뒤 가져옵니다. 입력을 줄이려면 이 순서를 따르세요. 먼저 「搜索演员（배우 검색）」으로 가져오고, 편집 화면에서 이름과 별명을 확인한 뒤, 「在线搜索补充元数据（온라인 검색으로 메타데이터 보충）」로 빠진 항목을 현재 배우에 채웁니다.

## 상세 보기와 자료 고치기

### 영화 상세 서랍

목록의 제목을 누르면 「媒体详情（미디어 상세）」서랍이 열립니다:

| 구역 | 내용 |
| --- | --- |
| 왼쪽 | 표지, 아래에 상영 시간·등급·평점 태그 |
| 설명 항목 | 제목, 식별 코드, 발행일, 상영 시간, 평점, 등급, 감독, 배우, 제작사, 빈 값은 줄을 차지하지 않음 |
| 줄거리 | 개요와 줄거리 두 단락 |
| 유형 / 태그 | 두 묶음의 색 태그 |
| 출연진 | 감독과 배우, 배우에 「역할」이 붙을 수 있음 |
| 이미지 모음 | 배경, 섬네일, 스틸 세 묶음 슬라이드 |

이미지 모음의 고화질 사진은 첫 장으로 올라옵니다. 아무 사진이나 누르면 전체 화면 미리보기가 열리고 좌우 방향키로 순환하며 `Esc`로 닫습니다. 서랍 아래에 버튼 넷: **编辑元数据（메타데이터 편집）, 在线搜索补充（온라인 검색으로 보충）, 高级编辑（상세 편집）, 关闭（닫기）**.

「编辑元数据（메타데이터 편집）」는 자주 쓰는 항목만 고치고, 저장하면 목록과 서랍이 함께 갱신됩니다:

1. 제목(중국어), 원제, 평점(0–10, 0.1 단위).
2. 발행일, 상영 시간(분), 등급, 언어, 국가.
3. 홍보 문구, 유형, 태그, 제작사, 감독.
4. 개요와 줄거리 두 개의 긴 글.
5. 「배우 연결」은 여러 행으로 추가: 배우 이름 + 배역, 배역은 비워도 되고, 이름이 빈 행은 제출되지 않습니다.

창을 열면 상세 전체를 먼저 가져와 채우고, 저장할 때 객체 전체를 제출하므로 **창에 보이지 않는 항목이 지워지지는 않습니다**.

기록 하나에 항목이 빠졌을 때는 「在线搜索补充（온라인 검색으로 보충）」: 작품 번호나 제목으로 검색 → 결과 카드에서 「补充到当前影视（현재 영화에 보충）」 → 후보를 먼저 등록한 뒤 현재 항목과 **합치고**, 끝나면 목록과 서랍을 갱신합니다.

:::note[통합과 보충은 다릅니다]
「合并媒体（미디어 통합）」는 기존 두 기록을 사람이 하나로 합치는 것이고, 「보충」은 후보를 가져와 자동으로 합쳐 한 기록의 빈 항목을 채우는 것입니다.
:::

### 시리즈 상세와 편집

목록 행의 「상세」로 들어가면 시리즈 상세이고, 위에 **重新刮削（다시 스크레이핑）**과 **编辑元数据（메타데이터 편집）**두 버튼, 본문은 위에서 아래로:

| 구역 | 내용 |
| --- | --- |
| 머리 | 포스터, 제목과 원제, 연도·첫 방송일·상태·평점·평점 인원·순위·회당 시간·등급·언어·구분·출처 태그 |
| 개요 | 유형, 태그, 제작사, 국가 / 지역, 감독, 각본, 사이트 ID, 줄거리 |
| 배우 | 이름과 역할 두 열 |
| 시즌 목록 | 시즌 번호(특별편 따로 표기), 시즌 이름, 첫 방송일, 이 시즌 회차(등록됨 / 전체) |
| 회차 목록 | `SxxExx`, 제목, 첫 방송일, 상영 시간, 평점, 유형, 「재생 가능 파일」열 |
| 시즌 매핑 | 로컬 시즌 번호, 데이터 출처, 출처 항목 ID, 연결 방식, 회차 오프셋, 출처 회차 수, 비고 |

「重新刮削（다시 스크레이핑）」은 데이터 출처, 출처 항목 ID, 시즌 번호(`0`～`99`)를 고르고, 새로고침은 데이터를 **현재 이 작품에 합치며** 두 번째 작품을 만들지 않습니다.

목록 행의 「편집」과 상세의 「编辑元数据（메타데이터 편집）」모두 시리즈 편집 화면으로 들어가며, 다음을 관리합니다:

- **기본 정보**: 제목, 원제, 중국어 제목, 정렬 제목, 표시 제목, 상태, 평점, 첫 방송일, 연도, 회당 시간, 등급, 언어, 국가 / 지역, 구분, 홍보 문구, 개요, 줄거리, 중국어 줄거리.
- **분류 정보**: 유형, 태그(시리즈 태그 라이브러리에서 가져옴).
- **제작 정보**: 제작사, 국가 / 지역, 감독, 각본, 그리고 TMDB / Bangumi / TVDB / IMDb 네 종류의 사이트 ID.
- **배우**: 이름과 역할을 추가·삭제 가능.
- **시리즈와 시즌·회차**: 시리즈 소속, 그리고 시즌(시즌 번호, 이 시즌 회차 수, 시즌 이름, 첫 방송일, 시즌 줄거리)과 회차(회차 번호, 절대 회차 번호, 제목, 첫 방송일, 상영 시간, 유형, 평점 등).
- **이미지**: 표지와 배경, 업로드·삭제·정렬 가능.

저장하면 시리즈 목록으로 돌아갑니다.

### 배우 항목

「新增演员（배우 추가）」와 행 안의 「상세」모두 배우 상세 편집 화면이며, 항목은 여섯 묶음입니다:

| 묶음 | 항목 |
| --- | --- |
| 기본 정보 | 이름(필수), 성별(남성 / 여성 / 트랜스젠더), 별명, 생년월일, 나이, 국적 |
| 신체 정보 | 키, 몸무게, 혈액형, 가슴·허리·엉덩이 둘레; 여성은 컵, 남성은 길이 표시 |
| 경력 정보 | 데뷔일, 평점(0–10), 소속사, 은퇴 여부, 사망 여부 |
| 소셜 링크 | 플랫폼 + 링크, 여러 행 추가·삭제 |
| 특징 태그 | 태그, 스타일, 특징 세 항목, 모두 배우 태그 라이브러리에서 가져옴 |
| 소개와 확장 | 소개 긴 글, 사용자 지정 확장 키-값 |

오른쪽 이미지 영역에 두 종류: 큰 사진(2:3, 한 장, 다시 업로드·삭제·미리보기 가능), 포스터 월(3:4, 여러 장, 일괄 업로드와 삭제 가능). 성별이 신체 항목에 영향을 줍니다. 여성이면 「컵」, 남성이면 「길이」가 보이고, 성별을 바꿔야 해당 항목이 나타납니다.

서랍 왼쪽은 큰 사진, 기본 자료, 신체, 태그, 스타일, 소개이고 아래에 버튼 셋: **온라인 검색으로 메타데이터 보충, 배우 편집, 닫기**.

## 이미지 관리

### 영화의 상세 편집

이미지 작업은 「高级编辑（상세 편집）」화면에 모여 있습니다(「添加媒体（미디어 추가）」와 상세의 「高级编辑（상세 편집）」은 같은 화면):

| 이미지 모음 | 권장 비율 | 할 수 있는 일 |
| --- | --- | --- |
| 표지 | 2:3 | 클릭·드래그 업로드, 자르기, 삭제, 위아래로 옮겨 순서 조정 |
| 배경 | 16:9 | 업로드, 삭제, 순서 조정 |
| 섬네일 | 16:9 | 업로드, 삭제, 순서 조정 |
| 스틸 | 16:9 | 업로드, 삭제, 순서 조정 |

순서가 곧 표시 순서이고, 목록과 상세는 첫 표지를 기본으로 씁니다(고화질 표지가 있으면 우선). 자르기 버튼은 별도 자르기 창을 열고, 확인하면 바로 업로드해 교체합니다.

상세 편집 화면에는 기본 정보, 분류 정보, 제작 정보(식별 코드와 모자이크 포함), 시리즈 정보, 배우 정보, 출처 링크, 확장 항목, 연결 목록, 그리고 「미디어 연결 목록」도 있습니다. 서버 파일 트리에서 영상 파일을 이 기록에 연결하거나 해제할 수 있고, 목록에 「사용 가능 / 무효」와 클립 제목이 표시됩니다.

:::tip[저장 전 확인창이 뜹니다]
상세 편집에서 「저장」을 누르면 먼저 「数据共享计划（데이터 공유 계획）」확인창이 뜹니다. 이 편을 **즐겨찾기**, **구독**할지, 데이터 공유에 참여할지 고를 수 있습니다. 체크하면 해당 기록이 추가되고, 체크하지 않아도 기존 상태가 취소되지는 않습니다.
:::

## 통합·삭제와 그 경계

| 동작 | 사용법 | 결과 |
| --- | --- | --- |
| 미디어 통합(영화) | 표에서 **정확히 두 행** 체크 후 「合并媒体（미디어 통합）」 | 첫 행이 남고 두 번째는 합쳐진 뒤 삭제. 두 개보다 적거나 많으면 안내가 뜸 |
| 배우 통합 | **정확히 두 행** 체크 후 「合并演员（배우 통합）」 | 첫 행이 남는 쪽, 두 번째는 합쳐진 뒤 삭제. 개수가 틀리면 안내가 뜸 |
| 미디어 삭제(영화) | 체크 후 「删除媒体（미디어 삭제）」, 한 건씩 제출 | 「删除任务已提交（삭제 작업을 제출했습니다）」가 뜨고 목록이 몇 초 뒤 갱신 |
| 배우 삭제 | 행 안 「삭제」또는 체크 후 「删除演员（배우 삭제）」 | 둘 다 재확인 필요 |
| 시리즈 삭제 | 행 오른쪽 「삭제」 | 그 작품의 시즌, 회차, 파일 연결, 시즌 매핑을 함께 제거 |

:::warning[삭제는 영상을 지우지 않지만 관계는 지웁니다]
- 영화 삭제: 메타데이터와 연결 관계만 지우고 **디스크의 영상 파일은 지우지 않습니다**. 다만 메타데이터, 즐겨찾기, 구독 관계는 복구할 수 없으니 먼저 백업하세요.
- 시리즈 삭제: 디스크의 영상 파일은 지우지 않지만 시즌, 회차, 파일 연결, 시즌 매핑이 함께 사라집니다. 일괄 삭제 전 체크 범위를 확인하세요.
- 통합은 되돌릴 수 없습니다: 연결된 자료를 옮기고 합쳐진 쪽을 지우므로, 두 건이 정말 같은 사람 / 같은 편인지 먼저 확인하고 필요하면 백업하세요.
:::

## 시리즈에만 있는 것: 시즌·회차·파일·시즌 매핑

> **시즌 매핑**: 「시즌 하나가 곧 하나의 항목」인 자료 사이트(예 Bangumi)에 맞대기 위한 것으로, 로컬 N 시즌을 그 사이트의 특정 항목에 가리키고 필요하면 오프셋으로 회차 번호를 환산합니다.

**시즌과 회차**: 시즌 목록의 「회차 보기」가 아래 회차 목록을 해당 시즌으로 바꾸고, 회차 목록 위에는 빠른 버튼 줄(「전체 시즌」과 `S1`, `S2`…)이 있습니다. 회차 목록은 `S{시즌}E{회차}`로 보이고 시즌 버튼으로 걸러 낼 수 있습니다. 「이 시즌 회차 수」는 「등록됨 / 전체」이며, 두 수가 다르면 아직 등록 안 된 회차가 있다는 뜻입니다.

**특정 회차에 파일 연결**: 「재생 가능 파일」열에서 합니다:

1. 「파일 추가」를 눌러 「경로로 파일 추가」창을 엽니다. 위에 대상이 「N 시즌 N 회차」라고 표시됩니다.
2. **파일 절대 경로**(필수, 예 `D:\Media\작품명\Season 1\S01E01.mkv`)를 입력합니다.
3. 분할 파일은 분할 번호를 넣고, `CD1`은 `1`, `CD2`는 `2`로 씁니다.
4. 연결되면 파일이 목록에 뜨고 「사용 가능 / 사용 불가」와 출처가 표시됩니다.
5. 「연결 해제」는 연결 관계만 지우고 디스크 파일은 지우지 않습니다.

:::tip[사용 가능 / 불가는 어디서 오나]
이 표시는 가장 최근 검증 결과에서 옵니다. 파일을 옮기거나 이름을 바꾼 뒤에는 다시 검증해야 사용 불가로 바뀝니다. 연결 해제와 재연결도 이 상태를 갱신합니다.
:::

**시즌 매핑 연결**: 「시즌 매핑 연결」양식에 로컬 시즌 번호, 데이터 출처, 출처 항목 ID(`400602`처럼 숫자만, 또는 항목 링크 그대로)를 넣습니다. 「연결 방식」은 `AUTO`(자동 발견) 또는 `MANUAL`(직접 지정)이고, `MANUAL`행은 자동 발견이 덮어쓰지 않습니다. 「회차 오프셋」환산은 **출처 회차 번호 = 로컬 회차 번호 + 오프셋**입니다. 「자동 발견」을 누르면 데이터 출처 기준으로 다시 찾아 매핑을 갱신하고, 추가 / 갱신 건수를 알려 줍니다.

:::note[자동 발견 결과가 없을 때]
「自动发现未返回任何季映射（자동 발견이 시즌 매핑을 하나도 반환하지 않았습니다）」는 보통 두 가지 이유입니다. 데이터 출처가 연결 항목을 지원하지 않거나, 작업 설정의 `tv_season_auto_discover`가 꺼져 있는 경우입니다.
:::

이 페이지는 **이미 등록된** 시리즈만 관리합니다. 스캔 단계에서 생기는 「확인 대기 시리즈 / 통합 / 확인 경계」는 작업 관리 섹션의 「스크레이핑 등록 → 시리즈 등록」에서 처리합니다.

## 배우에만 있는 것: 별명·출연작·즐겨찾기·구독

**별명**은 여러 값 입력칸으로, 입력 후 Enter로 추가합니다. 같은 배우의 다른 표기를 기록해 검색과 데이터 출처 대조에 쓰고, 제출 전 앞뒤 공백을 없애며 빈 값은 넣지 않습니다. **별명은 「출연 영화」맞대기에 쓰이지 않고, 작품 연결은 이름만 봅니다**.

**작품 연결**: 목록 행의 「상세」가 배우 상세 서랍을 열고 오른쪽이 작품 영역입니다. 제목은 「출연 영화(N)」이고 N은 맞은 영화 총수입니다. 표는 페이지별로 표지, 제목, 식별 코드, 발행일, 평점, 유형을 보여 주고, 각 행의 「상세 / 편집」은 그 영화의 상세 편집으로 바로 갑니다. 작품 목록은 영화 라이브러리를 **배우 이름**으로 걸러 내므로, 영화 항목의 배우 이름 표기가 배우 라이브러리와 꼭 같아야 합니다. 표기가 다르면 그 작품은 여기에 나오지 않습니다.

**즐겨찾기와 구독**: 배우 라이브러리 목록에는 「즐겨찾기만」필터가 없고, 프런트 배우 목록에는 「즐겨찾기 라이브러리」모드가 있습니다. 서로 다른 화면이라 모순이 아닙니다. 즐겨찾기 / 구독이 생기는 입구는 둘입니다:

1. 「搜索演员（배우 검색）」결과 카드: 아이콘 버튼 셋이 가져오기, 즐겨찾기, 구독 순이며 모두 먼저 등록한 뒤 해당 동작을 합니다.
2. 배우 상세 편집에서 저장할 때 뜨는 「데이터 공유 계획」확인창에서 「즐겨찾기」「구독」을 체크하면 해당 기록이 추가됩니다.

구독은 이 배우에 관심을 두는 뜻이고, 이후 새 작품은 구독 작업이 자동으로 가져올 수 있습니다. 일시 정지와 해제는 구독 관리가 맡고 이 페이지에서는 관리하지 않습니다.

| 평점 | 영화 0–10, 0.1 단위; 배우 0–10 | 범위를 넘으면 입력되지 않음 |
| 배우 연결(메타데이터 편집) | 매 행 「이름 + 배역」, 배역은 비워도 됨 | 이름 빈 행은 제출되지 않음 |
| 가져올 시즌 번호 | 비우면 전체 시즌, `0` = 특별편, `1`～`99` = 해당 시즌만 | 틀리면 다른 시즌을 가져옴. 같은 사이트 ID는 기존 시리즈에 합쳐지고 새로 만들지 않음 |
| 다시 스크레이핑 | 데이터 출처, 출처 항목 ID, 시즌 번호(`0`～`99`) | 현재 이 작품에 합쳐지고 두 번째 작품은 생기지 않음 |
| 파일 절대 경로 | 필수, 예 `D:\Media\작품명\Season 1\S01E01.mkv` | 비우면 연결 안 됨. 경로가 틀리면 「사용 불가」표시 |
| 분할 번호 | 분할 파일에서 `CD1` → `1`, `CD2` → `2` | 비우면 분할 파일이 맞지 않을 수 있음 |
| 시즌 매핑 항목 ID | 숫자(예 `400602`) 또는 항목 링크 | 틀리면 다른 항목을 가리켜 회차 수가 안 맞음 |
| 연결 방식 | `AUTO`(자동 발견) / `MANUAL`(직접 지정) | `MANUAL`행은 자동 발견이 덮어쓰지 않음 |
| 회차 오프셋 | 출처 회차 번호 = 로컬 회차 번호 + 오프셋 | 오프셋이 틀리면 회차 번호가 통째로 어긋남 |
| 이미지 비율 | 표지 / 큰 사진 2:3, 배경 / 섬네일 / 스틸 16:9, 포스터 월 3:4 | 비율이 틀리면 잘려 보임. 순서가 곧 표시 순서 |
| 통합 동작 | 정확히 두 행 체크 | 적거나 많으면 안내가 뜨고 실행 불가 |
| 데이터 공유 계획 확인창 | 즐겨찾기·구독·데이터 공유 참여 여부 | 체크 안 해도 기존 상태 취소 안 됨. 체크하면 기록 추가 |

## 문제가 생기면

- **원하는 기록이 안 나옴**: 검색 조건을 고친 뒤 「검색」을 눌렀는지, 「출처」가 걸러 내지 않았는지, 작품 번호 / 식별 코드 표기가 맞는지 확인하세요.
- **배우의 출연작이 몇 편 빠짐**: 작품 연결은 **이름**만 맞대므로, 영화 항목의 배우 이름 표기가 배우 라이브러리와 완전히 같아야 합니다. 별명은 맞대기에 안 쓰입니다.
- **시리즈를 가져왔더니 중복이 생김**: 같은 사이트 ID라면 본래 기존 시리즈에 합쳐집니다. 정말 중복이면 통합으로 처리하되, 정확히 두 건이어야 합니다.
- **시즌 매핑 자동 발견 결과가 없음**: 데이터 출처가 연결 항목을 지원하지 않거나, 작업 설정의 `tv_season_auto_discover`가 꺼져 있습니다.
- **시리즈 파일이 「사용 불가」로 표시됨**: 파일이 옮겨지거나 이름이 바뀌었습니다. 다시 검증하세요. 연결 해제나 재연결도 상태를 갱신합니다.
- **기록을 잘못 지움**: 삭제는 영상 파일을 남기지만 메타데이터, 즐겨찾기, 구독 관계는 복구할 수 없어 다시 스크레이핑하거나 가져와야 합니다. 먼저 백업하세요.
- **항목을 고쳤는데 저장이 안 됨**: 「메타데이터 편집」과 상세 편집 모두 저장을 눌러야 합니다. 상세 편집은 저장 전 「데이터 공유 계획」확인창도 뜨니 이 단계를 빼먹지 마세요.
