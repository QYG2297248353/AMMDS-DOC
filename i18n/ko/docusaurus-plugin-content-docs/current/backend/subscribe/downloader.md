# 내려받기와 등록

이 페이지는 **자료가 검색 화면을 떠난 뒤**의 이야기를 다룹니다. 어떤 프로그램이 내려받는지, 파일이 어디에 놓이는지, 진행을 어디서 보는지, 그리고 보관함에 반영하려면 무엇이 더 필요한지 설명합니다.

## 먼저 알아둘 말

> **다운로더**: 실제로 내려받는 프로그램(여기서는 qBittorrent)입니다. AMMDS는 작업을 넘길 뿐이고, 내려받기 자체는 다운로더가 합니다.

> **분류 / 태그**: 다운로더가 작업에 붙이는 표시입니다. 이것이 있으면 수많은 작업 가운데 AMMDS가 보낸 것을 금방 골라낼 수 있습니다.

> **시드**: 내려받기가 끝난 뒤에도 파일을 계속 나눠 주는 일입니다. 나눠 주는 중에 파일을 지우면 시드가 끊깁니다.

> **추가 시드**: 같은 파일을 다른 사이트에도 올리는 일입니다. 다시 내려받을 필요는 없습니다.

## 순서

### 연결부터 확인하기

**도구함 → 다운로더 → 플러그인 정보**를 열면 다운로더의 주소, 계정, 기본 저장 위치, 버전, 현재 작업 수를 볼 수 있습니다. 플러그인이 꺼져 있으면 "플러그인이 비활성 상태입니다"라고만 나오고 연결을 시도하지 않습니다.

### 작업 보내기

세 경로는 모두 같은 작업 목록으로 모입니다.

| 경로 | 위치 | 적히는 표시 |
| --- | --- | --- |
| 사이트 검색에서 보내기 | 검색 결과의 다운로더 버튼 | 분류 `AMMDS` |
| 마그넷 검색에서 보내기 | 검색 결과의 다운로더 버튼 | 분류 `AMMDS` |
| 구독 자동 내려받기 | 구독이 자료를 찾으면 자동 전송 | 태그 `AMMDS订阅` 와 `subscribe-<구독ID>`, 저장 위치는 구독 규칙에 적은 폴더 |

직접 추가할 수도 있습니다. 「새 작업」을 누르고 창 위쪽에서 두 방식을 오갑니다.

| 방식 | 넣는 것 |
| --- | --- |
| 마그넷 내려받기 | 마그넷 링크를 붙입니다. 여러 개면 줄바꿈으로 구분합니다 |
| 토렌트 파일 | `.torrent` 파일을 하나 이상 올립니다 |

### 진행 보기

**도구함 → 다운로더 → 작업 관리**를 엽니다. 목록은 5초마다 자동으로 새로 고쳐집니다(탭이 보이지 않으면 멈춥니다).

| 열 | 뜻 |
| --- | --- |
| 파일 이름 | 토렌트 이름. 둘째 줄에 저장 위치 |
| 상태 | 다운로더 상태를 우리말로 바꾼 것. 내려받는 중, 올리는 중, 메타데이터 받는 중, 대기 중, 일시 정지, 검사 중, 파일 옮기는 중, 파일 없음, 오류 등 |
| 속도 | 내려받기 속도와 올리기 속도 |
| 크기 | 작업 전체 크기 |
| 분류 / 태그 | 보낼 때 적힌 표시 |
| 진행 | 진행 막대. 끝나면 100% |

### 여러 개 한꺼번에

목록에서 작업을 고른 뒤 위쪽 버튼을 씁니다.

| 버튼 | 하는 일 |
| --- | --- |
| 내려받기 시작 | 고른 작업을 다시 시작합니다 |
| 내려받기 일시 정지 | 고른 작업을 멈춥니다 |
| 작업 삭제 | 확인 창이 뜨고, "원본 파일도 삭제"와 "작업만 삭제" 중 고릅니다 |

:::warning[파일 삭제는 되돌릴 수 없습니다]
삭제 창에서 확인 버튼은 "원본 파일도 삭제", 취소 버튼이 "작업만 삭제"입니다. 확인을 누르면 이미 받은 데이터까지 함께 지워집니다. 시드 중이거나 추가 시드를 기다리는 작업은 관련 흐름이 멈췄는지 확인한 뒤 지우세요.
:::

### 내려받은 뒤에 필요한 일

다운로더는 파일을 디스크에 놓기만 하고, **보관함에 자동으로 등록하지 않습니다**. AMMDS가 새 파일을 알게 하려면 검사 작업(작업 관리 영역)을 한 번 돌리거나, 지켜보기가 켜진 폴더에 파일을 넣어야 합니다.

## 설정 항목

직접 작업을 추가할 때 정할 수 있는 세 가지입니다. 모두 비워도 됩니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 분류 | 다운로더에 보이는 분류 이름 | 분류가 없어 기본 분류에 섞입니다 |
| 태그 | 넣고 엔터로 확정. 여러 개는 쉼표로 이어집니다 | 태그 없음 |
| 저장 위치 | 파일을 둘 폴더 | 다운로더의 기본 저장 위치 |

## 추가 시드와의 관계

다운로더 작업과 추가 시드 작업은 서로 다른 기록입니다. 섞어 보지 마세요.

- **다운로더 작업**은 내려받기와 시드 진행을 보여 줍니다.
- **추가 시드**는 **도구함 → PT 추가 시드**가 다른 사이트를 통해 하는 일로, 자체 계획·사이트 설정·기록을 가집니다. 추가 시드 계획은 다른 클라이언트도 고를 수 있고, 검색 화면의 보내기 대상과는 다른 설정입니다.
- 내려받은 뒤에도 파일은 다운로더가 계속 시드하고, 추가 시드는 같은 파일을 가리키는 새 작업을 다른 사이트에 만듭니다. 파일을 지우기 전에 두 종류의 작업이 모두 멈췄는지 확인하세요.

## 문제가 생기면

- **보내기가 실패한다**: 다운로더가 꺼져 있거나 주소·계정이 틀렸습니다. 플러그인 화면에서 연결을 시험해 보세요.
- **보냈는데 목록에 없다**: 1페이지로 가서 걸러내기를 지우거나, 다운로더에서 직접 확인하세요.
- **"메타데이터 받는 중"에서 멈춘다**: 마그넷에 시드가 없습니다. 토렌트 파일로 시도해 보세요.
- **"파일 없음"이 뜬다**: 저장 위치가 옮겨졌거나 파일이 지워졌습니다. 되돌려 놓고 다시 검사하거나, 작업을 지우고 다시 받으세요.
- **구독이 완료되지 않는다**: 다운로더에서 작업이 지워졌거나 진행을 다시 읽지 못했습니다. 구독 관리에서 다시 보내세요.

검색이나 구독 설정을 바꾸려면 [자료 찾기와 구독](./search.md)을 보세요.
