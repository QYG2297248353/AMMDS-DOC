# 자료 찾기와 구독

이 페이지는 두 가지를 다룹니다. **한 번만 자료를 찾는 것**과 **작품 번호를 지켜보다가 새 자료를 자동으로 받는 것**입니다. 한 번 찾기는 「사이트 검색」이나 「마그넷 검색」을, 오래 지켜보기는 「구독 관리」를 씁니다. 세 곳 모두 **구독 검색** 메뉴 아래에 있습니다.

## 먼저 알아둘 말

> **작품 번호**: 파일 이름에 흔히 들어 있는 식별 번호입니다. AMMDS는 이것으로 작품을 알아봅니다.

> **마그넷 링크**: `magnet:` 로 시작하는 한 줄의 텍스트입니다. 다운로드 프로그램은 이것으로 파일을 나눠 주는 사람을 찾습니다. 토렌트 파일을 먼저 받을 필요가 없습니다.

> **시드 수 / 리치 수**: 그 파일을 나눠 주고 있는 사람 수와 받고 있는 사람 수입니다. 시드가 많을수록 보통 빨리 받힙니다.

> **프로모션**: 사이트가 토렌트에 붙이는 할인 표시입니다. 무료 다운로드, 50% 다운로드, 업로드 2배 계산 같은 것이며, 트래픽 계산에만 영향을 줍니다.

> **API 키**: 사이트가 발급해 주는 문자열입니다. 프로그램은 비밀번호를 몰라도 이것을 내밀어 "이 계정입니다"라고 증명할 수 있습니다.

## 한 번만 찾기

1. **구독 검색 → 사이트 검색**(또는 **마그넷 검색**)을 엽니다.
2. 작품 번호, 제목, 출연진 이름 중 하나를 넣고 엔터를 누릅니다.
3. 결과를 기다립니다. 사이트 검색은 최대 60초까지 기다립니다. 제때 답하지 못한 사이트는 "결과 없음"으로 처리되고 나머지는 그대로 보입니다.
4. 결과 위의 도구 모음으로 걸러 봅니다. 정렬 기준(공개 시각, 파일 크기, 시드 수, 리치 수), 정렬 방향, 매체, 영상 코덱, 음성 코덱, 해상도, 프로모션입니다.
5. 다시 고르려면 「초기화」를 누릅니다. 모든 조건이 지워지고 정렬은 "공개 시각 / 내림차순"으로 돌아갑니다.

검색 기록은 브라우저에 최대 20개까지 저장됩니다. 결과가 없을 때는 검색창 아래에 지난 단어가 나오니, 눌러서 다시 검색하면 됩니다.

"N개를 찾았습니다"는 걸러낸 뒤의 개수이며, 사이트가 보낸 전체 개수가 아닙니다.

## 찾은 뒤: 내려받기 아니면 보내기

| 버튼 | 하는 일 | 쓰기 좋은 때 |
| --- | --- | --- |
| 토렌트 내려받기 | `[AMMDS]제목.torrent` 이름으로 토렌트 파일을 저장합니다 | 다운로드 프로그램을 직접 고르고 싶을 때 |
| 다운로드로 보내기 | 켜 둔 다운로더로 바로 넘깁니다. 분류는 `AMMDS` 가 됩니다 | 이미 다운로더를 쓰고 있을 때 |

마그넷 검색에는 마그넷 링크를 복사하는 버튼과, 제목을 눌러 컴퓨터에 연결된 프로그램에 맡기는 기능이 더 있습니다.

## 오래 지켜보기

1. 작품의 온라인 검색 결과, 대시보드의 인기 차트, 작품 편집 화면 등에서 「구독」을 누릅니다.
2. AMMDS는 작품 번호로 작품 정보를 맞춰 보고, 정해진 순서대로 각 사이트를 찾습니다. 찾는 즉시 자동으로 보냅니다.
3. 상태는 **구독 검색 → 구독 관리**에서 봅니다. 목록은 10초마다 자동으로 새로 고쳐집니다.
4. 바로 다시 돌리려면 「구독 중」또는 「전체」탭의 카드에서 「지금 검색」을 누릅니다.
5. 그만 보려면 「구독 취소」를 누릅니다. 나중에 「취소됨」탭에서 되살릴 수 있습니다.

같은 작품 번호(대소문자 구분 없음)의 구독은 하나뿐이라, 두 번 눌러도 늘어나지 않습니다.

## 두 검색의 차이

| | 사이트 검색 | 마그넷 검색 |
| --- | --- | --- |
| 자료 출처 | 켜 둔 사이트와 인덱서 | 마그넷 인덱스 서비스 |
| 항목 | 프로모션, 시드 수, 해상도 등 사이트 정보 | 출처, 파일 수, 파일 목록 |
| 페이지 나눔 | 한 번에 모두 오고 화면에서는 나누지 않음 | 서버에서 나누며 한 페이지에 20개 |
| 정렬 | 화면에서 다시 정렬 | 서버에서 정렬. 바꾸면 1페이지로 돌아갑니다 |
| 받는 형태 | 토렌트 파일 또는 바로 받는 주소 | 마그넷 링크 |
| 준비물 | 사이트 인덱스 서비스를 하나 이상 켜 둠 | 마그넷 인덱스 서비스가 켜져 있고 닿을 수 있음 |

둘은 서로 독립입니다. 어떤 사이트가 시간이 초과되어도 그 사이트만 비며, 검색 전체가 멈추지 않습니다. 마그넷 검색의 「출처」걸러내기는 현재 페이지에만 적용되고 전체 개수는 바뀌지 않습니다.

## 구독의 여섯 가지 상태

| 탭 | 뜻 | 카드의 버튼 |
| --- | --- | --- |
| 전체 | 상태로 걸러내지 않음 | 지금 검색, 취소, 삭제 |
| 구독 중 | 구독 중. 정보 맞춤 또는 다음 검색을 기다림 | 지금 검색, 취소 |
| 일시 정지 | 정보 맞춤 실패가 이어져 자동으로 멈춤 | 취소 |
| 취소됨 | 직접 멈춤. 기록은 남습니다 | 복원, 삭제 |
| 다운로드 | 다운로더로 넘어감 | 삭제 |
| 완료 | 다운로더가 완료를 알림 | 삭제 |

「삭제」는 완전히 지우는 것이며 되돌릴 수 없습니다. 「취소」는 멈추기만 하므로 언제든 되살릴 수 있습니다.

카드에는 작품 번호, 제목(맞추지 못했으면 "확인 중"), 개봉 시기, 구독 시각, 포스터가 나옵니다. 작품 번호가 없는 기록은 카드로 그려지지 않습니다.

## 「구독 중」에 머물거나 「일시 정지」가 되는 이유

- 검색은 됐지만 어떤 사이트도 내려받을 주소를 주지 않으면 상태는 「구독 중」으로 남고 "아직 자료가 없습니다"라는 알림이 오며, 다음 차례에 자동으로 다시 시도합니다.
- 작품 정보 맞춤이 10번 연속 실패하면, 헛된 요청을 막으려고 자동으로 「일시 정지」가 됩니다.
- 맞추지 못한 구독은 백그라운드에서 처리됩니다. 시작 10분 뒤에 처음, 그다음은 300분마다입니다.
- 「구독 중」기록은 20분마다 처리되며 한 차례에 최대 10개, 구독 시각이 최신인 것부터입니다.

## 설정 항목

구독 전체 설정은 **작업 관리 → 작업 설정 → 구독 규칙**에 있습니다.

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 중국어 자막 우선 | 중국어 자막이 있는 자료를 더 원하면 켭니다 | 이번 버전에서는 취향만 저장되고 자동 내려받기 순서에는 영향을 주지 않습니다 |
| 검색 순서 | 쉼표로 구분한 사이트 이름. 기본값은 `M-Team,NexusPHP,Rousi,Prowlarr` 입니다. 같은 작품 번호에서 어느 사이트를 먼저 시도할지 정합니다 | 위의 기본 순서가 쓰입니다. 이름이 틀리면 그 사이트는 늘 뒤로 밀립니다 |
| 내려받을 폴더 | 받은 파일을 어디에 둘지 | 비우면 다운로더의 기본 저장 위치를 씁니다 |

다시 시작할 필요가 없고, 다음 구독 작업부터 새 값이 쓰입니다. 모아 주는 종류의 출처는 검색 순서와 무관하게 늘 마지막입니다.

마그넷 검색에는 화면 설정이 없습니다. 넣을 수 있는 것은 키워드와 정렬뿐입니다.

## 문제가 생기면

- **아무 결과도 없다**: 사이트나 마그넷 인덱스가 켜져 있는지, 계정이 만료되지 않았는지 확인하고, 키워드를 줄이거나 작품 번호로 바꿔 보세요.
- **일부 사이트만 돌아온다**: 한 사이트의 시간 초과는 정상적인 축소입니다. 잠시 뒤에 다시 시도하세요.
- **결과는 있는데 받을 수 없다**: 먼저 「다운로드로 보내기」를 써 보고, 그래도 안 되면 다운로더의 주소와 계정을 확인하세요.
- **카드가 "확인 중"에서 안 움직인다**: 작품 정보와 맞지 않았습니다. 보관함에서 직접 연결한 뒤 「지금 검색」을 누르세요.
- **「일시 정지」가 됐다**: 정보 맞춤이 10번 연속 실패했습니다. 작품 번호나 정보를 고치고 복원하세요.
- **보냈는데 작업이 안 보인다**: 다운로더에서 직접 확인하거나, [내려받기와 등록](./downloader.md)의 방법대로 목록을 확인하세요.
