# 미디어 서버: 라이브러리와 커버

도구 상자의 '미디어 서버'는 플레이어 쪽의 미디어 라이브러리를 직접 조작하는 데 씁니다. 각 라이브러리에 항목이 얼마나 있는지, 어떤 디렉터리에 있는지 확인하고, 메타데이터와 이미지를 다시 정리하거나, 더 보기 좋은 커버로 바꾸거나, 라이브러리 안으로 들어가한 단계씩 정리할 수 있습니다.

진입점은 **도구 상자 → 미디어 서버 → 라이브러리 관리**입니다.

:::warning[커버를 다시 쓰려면 사용 가능한 미디어 서버가 필요합니다]
커버 교체, 새로고침, 제거는 모두 플레이어의 미디어 라이브러리에 기록하는 작업입니다. 먼저 '연동 앱'에서 Jellyfin 또는 Emby를 설정하고 활성화하세요. 그렇지 않으면 이 작업을 완료할 수 없습니다.
:::

## 페이지 위쪽

위쪽에 '모든 미디어 라이브러리 스캔' 버튼이 있어 Jellyfin과 Emby의 스캔 작업을 함께 제출합니다. 두 플러그인 모두 활성화되지 않았다면 이 버튼은 회색입니다.

아래는 Jellyfin과 Emby로 나뉜 두 영역입니다. 각 영역 맨 위에는 해당 쪽의 통계가 있습니다.

| 통계 | 설명 |
| --- | --- |
| 영화 | 영화 항목 수 |
| 드라마 | 드라마 항목 수 |
| 개별 에피소드 | 개별 에피소드 항목 수 |
| 모음 | 모음 항목 수 |

통계 가져오기가 실패하면 해당 행 전체가 표시되지 않으며, 아래의 라이브러리 카드에는 영향이 없습니다.

각 영역 오른쪽 위에는 '배우 정보 보완', '미디어 라이브러리 동기화', '재생 기록 동기화', '새로고침' 네 개의 버튼이 있습니다. 각각 배우 정보 보완, 로컬 자료를 플레이어에 기록, 재생 기록 가져오기, 라이브러리 목록 다시 가져오기를 합니다. 이 작업들은 모두 백그라운드에서 실행되며, 누르면 '작업이 제출되었습니다'라고만 안내합니다.

## 라이브러리 카드

미디어 라이브러리마다 카드 한 장이 있고, 위에서 아래로 다음과 같습니다.

| 위치 | 내용 |
| --- | --- |
| 커버 | 플레이어에 있는 이 라이브러리의 대표 이미지. 불러오지 못하면 자리 표시자 아이콘이 나타납니다 |
| 이름 | 미디어 라이브러리 이름. 너무 길면 잘리며, 마우스를 올리면 전체 이름을 볼 수 있습니다 |
| 종류 | 영화, 프로그램, 음악, 모음, 책, 기타 |
| 항목 수 | '· 128개 항목' 형식이며, 플레이어가 반환하지 않으면 `-`로 표시됩니다 |
| 물리 경로 | 라이브러리에 대응하는 디스크 디렉터리. 경로가 여러 개면 세미콜론으로 구분하며, 너무 길면 잘립니다 |
| 작업 | 네 개의 버튼. 아래 표 참고 |

| 버튼 | 하는 일 | 설명 |
| --- | --- | --- |
| 라이브러리 들어가기 | 이 라이브러리를 열어 안의 폴더와 작품을한 단계씩 탐색 | 카드의 커버나 이름을 누르는 것과 같습니다 |
| 커버 변경 | 생성형 커버 팝업을 엽니다 | 아래 참고 |
| 지금 스캔 | 플레이어가 이 라이브러리를 스캔하도록 합니다 | 작업만 제출하며 즉시 끝나지 않습니다 |
| 더 보기 | 메타데이터 새로고침, 이미지 새로고침, 커버 제거 | 아래 참고 |

### 더 보기의 세 항목

| 메뉴 항목 | 하는 일 | 주의 |
| --- | --- | --- |
| 메타데이터 새로고침 | 플레이어가 이 라이브러리의 메타데이터를 다시 읽도록 합니다 | 백그라운드에서 실행되며, 기존 커버를 덮어쓰지 않습니다 |
| 이미지 새로고침 | 플레이어가 이미지를 다시 가져오도록 합니다 | 역시 기존 커버를 덮어쓰지 않습니다 |
| 커버 제거 | 미디어 라이브러리의 대표 이미지를 삭제합니다 | 먼저 확인을 받습니다. 플레이어의 이미지를 지우며 영상 파일은 건드리지 않습니다 |

## 커버 변경

'커버 변경'을 누르면 팝업이 열리고, 두 개의 탭이 있습니다: **텍스트 커버**와 **이미지 커버**. 두 탭 모두 오른쪽에는 16:9, 1280×720 실시간 미리보기가 있어 왼쪽에서 바꾸면 오른쪽에 바로 반영됩니다. 확인한 뒤 '커버 교체'를 누르면 이미지가 미디어 서버에 바로 기록되어 기존 대표 이미지를 덮어씁니다.

### 텍스트 커버

설정만으로 생성하며, 라이브러리 안의 작품 이미지에 의존하지 않습니다. 가장 단순한 형태는 라이브러리 이름 + 검은 배경 + 가운데 흰 글씨입니다.

| 설정 항목 | 작성 방법 |
| --- | --- |
| 커버 문구 | 최대 60자. 비우면 미디어 라이브러리 이름을 기본값으로 씁니다 |
| 부제 | 선택, 최대 60자. 예: `Movies / TV Shows` |
| 배경색 | 색상 선택기로 배경 색을 고릅니다 |
| 글자 색 | 색상 선택기로 글자 색을 고릅니다 |
| 글자 크기 | 24~140, 2 단위 |
| 정렬 | 왼쪽 정렬, 가운데 정렬, 오른쪽 정렬 |
| 굵게 | 켜기 / 끄기 |

### 이미지 커버

이 라이브러리의 작품 이미지를 재료로 커버 한 장을 만듭니다.

| 설정 항목 | 작성 방법 |
| --- | --- |
| 커버 문구 | 최대 60자. 비우면 미디어 라이브러리 이름을 기본값으로 씁니다 |
| 부제 | 선택, 최대 60자. 예: `이번 달 인기` |
| 레이아웃 | 격자 콜라주, 또는 대표 이미지 + 제목 표시줄 |
| 작품 수 | 격자 콜라주에서만 있으며 4장, 6장, 9장 중 선택 |
| 마스크 불투명도 | 0~0.85, 0.05 단위. 값이 클수록 글자가 더 선명해집니다 |
| 제목 글자 크기 | 28~120, 2 단위 |
| 글자 색 | 색상 선택기로 글자 색을 고릅니다 |
| 작품 재료 | '다른 묶음'을 누르면 라이브러리 내 작품 이미지를 다시 무작위로 가져오며, 옆에 '작품 이미지 N장을 가져왔습니다'가 표시됩니다 |

재료를 아직 가져오지 않았거나 한 장도 가져오지 못했다면 '커버 교체'는 회색입니다.

매번 직접 누르기 싫다면 라이브러리별로 '자동 커버 교체'를 켜 새 콘텐츠가 생길 때 스스로 바꾸도록 할 수 있습니다. 다음 절을 참고하세요.

## 자동 커버 교체

라이브러리 카드의 작업 영역에 시계 아이콘 버튼이 있고, 마우스를 올리면 '자동 커버 교체'라고 표시됩니다. 누르면 '자동 커버 교체 설정' 팝업이 열리며, **기본값은 꺼짐이고 버튼을 켠 그 라이브러리에만 적용됩니다**. 다른 라이브러리는 영향받지 않습니다.

### 무엇을 설정할 수 있나요

| 설정 항목 | 작성 방법 |
| --- | --- |
| 자동 교체 활성화 | 켜기 / 끄기. 기본값은 꺼짐이며 이 라이브러리에만 적용됩니다 |
| 커버 종류 | 텍스트 커버 또는 이미지 커버 |
| 커버 문구 / 부제 | 최대 60자. 자리표시자 `{library}`(라이브러리 이름), `{count}`(항목 수), `{date}`(당일 날짜)를 지원합니다. 중괄호까지 함께 써야 합니다. 예: `{library} · 총 {count}편` |
| 텍스트 커버 | 배경색, 글자 색, 글자 크기 24~140, 왼쪽 / 가운데 / 오른쪽 정렬, 굵게 |
| 이미지 커버 | 레이아웃(격자 콜라주 / 대표 이미지 + 제목 표시줄), 작품 수 4 / 6 / 9장(격자일 때만), 마스크 불투명도 0~0.95, 제목 글자 크기 24~140, 글자 색 |
| 최소 교체 간격 | 10~10080분, 기본값 720분. 같은 라이브러리에서 자동 교체 두 번 사이의 최소 간격입니다 |

커버는 서버에서 합성하며 1280×720, PNG로 고정됩니다. 각 설정 항목의 의미는 수동 교체 팝업과 같고, 값의 범위는 여기를 기준으로 합니다.

### 언제 바뀌나요

시스템이 시작된 지 25분 뒤에 첫 검사를 하고, 이후 30분마다 확인합니다. 버튼을 켠 라이브러리만 대상이 되며, 하나도 켜지 않았다면 미디어 서버에 요청하지 않습니다.

활성화된 각 라이브러리는 다음 세 조건을 모두 만족할 때 작업합니다:

1. 라이브러리의 항목 수가 마지막 기록보다 증가함
2. 마지막 실행에서 해당 라이브러리의 최소 간격이 지남
3. 미디어 서버에 정상적으로 연결됨. 이미지 커버를 선택했다면 작품 재료도 가져올 수 있어야 함

처음 켰을 때의 첫 검사는 현재 항목 수만 기준선으로 기록하고 커버를 바로 바꾸지 않습니다. 그 뒤 새 항목이 들어와야 위의 판단을 시작합니다.

### 어떤 경우에 커버를 바꾸지 않나요

| 상황 | 결과 |
| --- | --- |
| 항목 수가 증가하지 않음 | 건너뜁니다. 항목이 줄어도(삭제·이동) 바꾸지 않고 기록만 갱신합니다 |
| 마지막 교체에서 최소 간격이 지나지 않음 | 건너뛰고 다음 차례를 기다립니다 |
| 새로 만든 이미지가 지난번과 완전히 같음 | 건너뛰고 다시 기록하지 않아 캐시를 헛되이 갱신하지 않습니다 |
| 커버를 직접 수정함 | 자동 폴링이 건너뛰어 내가 바꾼 커버를 유지합니다. 다시 자동 교체에 맡기려면 '지금 한 번 실행'을 누르고 확인창에서 계속 덮어쓰기를 선택하세요 |
| 재료 부족, 생성 실패, 서버 연결 불가 | 기존 커버를 그대로 두고 실패 이유를 기록합니다 |
| 라이브러리가 비었거나 항목 수를 가져올 수 없음 | 변경하지 않습니다 |

### 결과는 어디에서 보나요

- 활성화하면 라이브러리 카드에 '자동 커버 교체 · 시각 · 성공 / 실패 / 건너뜀' 줄이 추가됩니다. 아직 실행되지 않았다면 '자동 커버 교체 · 폴링 대기'로 표시됩니다.
- 시계 버튼을 눌러 설정을 열면 아래 '최근 자동 교체'에 결과 표시, 실행 시각, 구체적인 설명이 나오며 실패 이유도 여기에서 볼 수 있습니다.
- 더 자세한 오류는 백엔드 로그에 있습니다.

### 지금 한 번 실행

설정 팝업 아래에 '지금 한 번 실행'이 있습니다. 항목 수 증가나 최소 간격을 보지 않고 즉시 커버를 생성합니다.

단, 서버의 현재 커버가 지난번 자동 기록과 다르면(직접 수정했다는 뜻) 곧바로 덮어쓰지 않고 먼저 확인창을 띄웁니다:

> 커버가 수동으로 수정된 것을 감지했습니다
> 계속하면 자동 생성 커버로 덮어쓰며, 현재 수동으로 수정한 커버는 사라집니다. 계속하시겠습니까?

'계속 덮어쓰기'를 누르면 기록하고, '취소'를 누르면 기존 커버를 유지합니다. 예약 폴링은 수동 커버를 덮어쓰지 않으며, 직접 한 번 실행하고 확인해야 그 라이브러리가 다시 자동 교체 대상이 됩니다.

방금 설정하고 바로 결과를 보고 싶을 때도 이 버튼으로 한 번 실행합니다.

이 버튼은 라이브러리에 현재 연결되어 있어야 하며, 미디어 서버에 연결할 수 없으면 실행 실패를 안내하고 기존 커버를 유지합니다.

:::warning[기록은 여전히 미디어 서버에 의존합니다]
자동 교체와 수동 교체 모두 Jellyfin 또는 Emby가 설정·활성화되어 있어야 합니다. 서버를 사용할 수 없으면 실패만 기록할 뿐 커버를 잘못 기록하지는 않습니다.
:::

## 라이브러리에 들어가한 단계씩 탐색하기

'라이브러리 들어가기'를 누르면 목록 영역이 탐색 화면으로 바뀌고, 위쪽이 '뒤로'와 이동 경로 표시로 바뀝니다. 이동 경로는 라이브러리에서 현재 디렉터리까지의 경로를 보여 주며, 앞쪽 단계를 누르면 바로 돌아갈 수 있습니다.

- **검색**: 기본적으로 현재 디렉터리만 검색하며 자동으로 하위로 내려가지 않습니다
- **새로고침**: 현재 디렉터리를 다시 가져옵니다
- **폴더**: 카드로 표시되며 이름, 종류, 'N개 항목'이 보입니다. 각 폴더 카드 오른쪽 아래에 '커버 변경'이 있습니다
- **항목**: 표로 표시되며 열은 커버, 이름, 종류, 연도, 시간, 작업입니다. 페이지당 24건이며 아래에서 페이지를 넘깁니다
- **뒤로**: 루트 디렉터리가 아니라면 한 단계 위로, 이미 루트라면 미디어 라이브러리 목록으로 돌아갑니다
- 현재 디렉터리가 비어 있으면 '현재 디렉터리가 비어 있습니다'라고 안내합니다

폴더나 작품의 커버를 바꿀 때도 같은 생성형 커버 팝업을 사용하며, 기록 대상이 그 폴더·작품으로 바뀝니다. 기록이 성공하면 현재 디렉터리를 다시 불러와 이미지가 즉시 갱신됩니다.

## 전제 조건과 제한

- **설정되어 사용 가능한 Jellyfin 또는 Emby여야 합니다**: 커버 기록, 새로고침, 제거는 모두 플레이어 인터페이스를 통해 이루어지므로 플러그인이 제대로 설정되지 않았거나 활성화되지 않으면 할 수 없습니다.
- **영상은 삭제하지 않습니다**: 새로고침과 커버 제거는 메타데이터와 이미지만 다루며 라이브러리의 영상 파일은 건드리지 않습니다.
- **새로고침은 백그라운드 작업입니다**: 누르자마자 결과가 보이지 않으며, 플레이어가 처리한 뒤 페이지를 새로고침해야 합니다.
- **재료는 라이브러리 안의 작품 이미지에서 가져옵니다**: 이미지 커버는 플레이어에 이미 있는 작품의 대표 이미지를 사용하므로, 라이브러리에 이미지가 없으면 만들 수 없습니다.
- **자동 커버 교체는 기본적으로 꺼져 있습니다**: 라이브러리별로 켜며, 새 항목이 증가하고 최소 간격을 넘었을 때만 바꿉니다. 켠 뒤 첫 검사는 기준선만 만들고 커버를 바로 바꾸지 않습니다.
- **자동 작업은 수동 수정을 덮어쓰지 않습니다**: 커버를 직접 바꾼 것을 발견하면 자동 덮어쓰기를 멈춥니다. 다시 맡기려면 '지금 한 번 실행'을 누르고 확인창에서 계속 덮어쓰기를 선택해야 합니다.

## 자주 묻는 질문

| 현상 | 설명 |
| --- | --- |
| 라이브러리 카드가 계속 자리 표시자로 나옴 | 플레이어가 대표 이미지를 반환하지 않거나 이미지 주소를 열 수 없습니다. 먼저 '이미지 새로고침'을 눌러 보세요 |
| 항목 수가 `-`로 표시됨 | 플레이어가 항목 수를 반환하지 않은 것이며, AMMDS가 집계하지 않은 것이 아닙니다 |
| 물리 경로가 비어 있음 | 이 라이브러리가 플레이어에서 디렉터리로 설정되지 않았거나 인터페이스가 반환하지 않았습니다 |
| '모든 미디어 라이브러리 스캔'이 눌리지 않음 | Jellyfin과 Emby가 모두 활성화되지 않았습니다 |
| '커버 교체'가 회색임 | 이미지 커버의 재료를 아직 가져오지 않았거나 제출 중입니다 |
| 자동 커버 교체를 켰는데 커버가 그대로임 | 켠 뒤 첫 번째는 기준선만 기록합니다. 이후 항목 수가 늘지 않았거나 최소 간격이 지나지 않으면 건너뛰므로 카드의 실행 시각과 결과를 확인하세요 |
| 자동 커버 교체에 '커버가 수동으로 수정됨'이 표시됨 | 플레이어나 수동 팝업에서 커버를 바꾼 것이어서 자동 작업이 덮어쓰지 않습니다. '지금 한 번 실행'을 누르고 확인창에서 계속 덮어쓰기를 선택해야 다시 맡습니다 |
| 자동 커버 교체가 계속 실패함 | 미디어 서버에 연결되는지, 라이브러리에 작품 이미지가 있는지 확인하세요. 실패 이유는 설정 팝업의 '최근 자동 교체'와 백엔드 로그에 있습니다 |
| '다른 묶음'을 눌러도 달라지지 않음 | 라이브러리의 작품 이미지가 너무 적어 같은 묶음이 뽑혔습니다 |
| 기록했는데 플레이어에 여전히 옛 이미지가 나옴 | 플레이어 캐시가 갱신되지 않았습니다. 라이브러리 스캔이나 메타데이터 새로고침을 한 번 실행하세요 |
