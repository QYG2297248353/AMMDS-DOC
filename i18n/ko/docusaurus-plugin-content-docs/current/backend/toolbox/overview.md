# 도구함: 파일을 한꺼번에 처리하기

도구함은 한꺼번에 처리하는 작은 도구들의 선반입니다. 아래에 쓰임별로 나누어, 각각 한 줄로 무엇을 하는지 적었습니다. 눈앞의 일에 맞는 것을 고르세요.

## 먼저 알아둘 말

> **백그라운드 작업**: 버튼을 누르면 등록되고, 일은 뒤에서 돕니다. 페이지를 닫고 다른 일을 하다가 나중에 목록에서 결과를 보면 됩니다.

> **결과물**: 도구가 만드는 파일(새 영상, 자막, 그림)입니다. 디스크에만 쓰이고, **보관함에 자동으로 등록되지 않습니다**. 검사 작업을 돌리거나 지켜보기가 켜진 폴더에 넣으세요.

## 1. 내려받기와 추가 시드

| 도구 | 한 줄 | 준비물 | 결과물 |
| --- | --- | --- | --- |
| 다운로더 | 다운로더의 연결 정보와 토렌트 작업을 보고, 마그넷이나 토렌트 작업을 직접 추가하며, 여러 개를 시작·멈춤·삭제 | 다운로더 플러그인이 켜짐 | 내려받은 파일 |
| PT 추가 시드 | 이미 있는 파일을 다른 사이트에 맞춰 올려 두 번 내려받지 않게 함 | 추가 시드 서비스가 켜짐 | 다른 사이트의 새 작업 |

## 2. 영상 다루기

| 도구 | 한 줄 | 준비물 | 결과물 |
| --- | --- | --- | --- |
| 자막 만들기 | 소리를 듣고 자막을 만들고, 두 언어로도 만들 수 있음 | 음성 인식 서비스가 닿음 | `.srt` 자막 파일 |
| 영상 변환 | 영상을 다시 인코딩해 형식과 코덱을 바꾸고 크기를 줄임 | 영상 처리 프로그램이 있음 | 새 영상 파일 |
| 형식 바꾸기 | 겉포장만 바꾸고(MKV에서 MP4로 등) 내용은 그대로. 빠르고 화질 손실 없음 | 영상 처리 프로그램이 있음 | 새 영상 파일 |

> **스트림 복사**: 영상과 소리를 다시 인코딩하지 않고 새 그릇으로 그대로 옮기는 일입니다. 그래서 변환보다 훨씬 빠르고 화질도 떨어지지 않습니다. 다만 옮길 형식이 이것을 받아줄 때만 됩니다.

고르는 법: 겉포장만 안 맞고 옮길 형식이 확인 결과에 있다면 「형식 바꾸기」입니다. 코덱을 바꾸거나 크기를 줄여야 하거나, 옮길 형식이 목록에 없으면 「영상 변환」입니다.

## 3. 그림 다루기

| 도구 | 한 줄 | 준비물 | 결과물 |
| --- | --- | --- | --- |
| 포스터 자르기 | 가로로 긴 그림을 세로 포스터로 자르고, 같은 폴더에 짝맞춤 그림도 만듦 | 플러그인 필요 없음 | `-poster` / `-fanart` / `-thumb` 그림 |

## 4. 서버 파일 정리하기

| 도구 | 한 줄 | 준비물 | 결과물 |
| --- | --- | --- | --- |
| 파일 탐색기 | 브라우저로 서버 폴더를 다룹니다. 찾기, 올리기, 내리기, 복사, 옮기기, 압축, 풀기, 이름 바꾸기, 지우기, 미리보기, 자르기 | 플러그인 필요 없음 | 조작으로 생긴 파일과 폴더 |

> **NFO**: 영상 옆에 두는 글자만 있는 설명 파일로, 보통 수록 정보를 적어 둡니다. 파일 탐색기에서 열어 고칠 수 있습니다.

## 5. 플레이어와 잇기

| 도구 | 한 줄 | 준비물 | 결과물 |
| --- | --- | --- | --- |
| 미디어 서버 도구 | 플레이어의 보관함, 작품, 출연자를 보고, 검사·표지 변경·정보 수정·내 기록과 연결을 함 | 플레이어 플러그인이 켜짐 | 플레이어 쪽의 변경 |

## 모두에게 맞는 규칙

어느 도구에서나 다음은 같습니다.

- **파일 고르기**: 서버의 파일 나무에서 고릅니다. 폴더를 펼칠 때 불러오고, 못 쓰는 종류는 잿빛입니다.
- **기다릴 필요 없음**: 작업은 백그라운드로 돌고, 동시 실행 한도를 넘으면 줄을 섭니다.
- **작업 목록**: 모두 자세히 보기와 취소가 있고, 실패·취소 뒤에는 다시 시도할 수 있습니다. 지우면 결과물도 함께 지워지는 경우가 있습니다(원본은 지워지지 않습니다).
- **자동 새로 고침**: 목록은 일정한 간격으로 갱신되고, 탭이 보이지 않으면 멈춥니다.
- **덮어쓰지 않음**: 만들어질 자리에 같은 파일이 있거나, 자리가 원본과 완전히 같으면 작업 만들기가 거절됩니다. 원본을 남기려면 "원본 폴더에 덧말"이나 "한 폴더로 모으기"를 고르세요.

## 설정 항목

### 영상 변환 / 형식 바꾸기

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 범위 | 영상 하나, 또는 폴더 전체 | 폴더는 안의 모든 지원 파일을 처리하니, 원치 않는 것은 미리 옮기세요 |
| 목표 형식 | MP4, MKV, MOV, WebM, AVI, TS, M4V, MPG, FLV, 3GP, OGV, WMV 등 | 형식 바꾸기에서 맞는 형식이 없으면 목록이 비고, 영상 변환을 써야 합니다 |
| 무손실 | 코덱과 그릇이 맞으면 내용을 그대로 옮깁니다 | 맞지 않으면 스위치가 잿빛이 되고 다시 인코딩만 됩니다 |
| 영상 코덱 | 무손실을 끄면 고를 수 있음. 호환성이 가장 좋은 것 또는 크기가 줄어드는 것 | 기본 코덱이 쓰입니다 |
| 인코딩 단계 | 가장 빠름에서 가장 느림까지 아홉 단계. 빠를수록 크기가 커지고, 느릴수록 압축이 잘 됩니다 | 기본 단계 |
| 화질(CRF) | 0~51, 기본 23. 작을수록 화질이 좋고 파일이 커지며, 18~28이 무난합니다 | 기본 23 |
| 출력 방식 | 원본 폴더에 같은 이름 / 덧말 붙이기(`transcode` 또는 `convert`) / 한 폴더로 모으기 | 자리에 파일이 있으면 거절되고 덮어쓰지 않습니다 |

> **CRF**: 화질을 뜻하는 0~51의 숫자입니다. 작을수록 화질이 좋고 파일이 커지며, 클수록 그 반대입니다.

### 자막 만들기

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 범위 | 영상 하나, 또는 폴더 전체 | 위와 같습니다 |
| 인식 언어 | 자동 알아보기, 또는 언어를 지정 | 자동 알아보기. 소리가 섞이면 언어를 틀릴 수 있습니다 |
| 두 언어 자막 | 켜면 인식 결과를 번역해 두 줄로 보여 줍니다 | 한 언어 자막만 나옵니다 |
| 번역할 언어 | 두 언어를 켰으면 필수 | 번역 작업을 등록할 수 없습니다 |

영상 하나는 최대 12시간까지입니다. 한 번의 인식은 60분까지이고, 넘는 부분은 자동으로 나뉩니다. 정확도는 소리가 얼마나 또렷한지에 달려 있고, 여러 사람이 함께 말하거나 소음이 크면 오타가 늘어납니다.

### PT 추가 시드

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 사용 | 자동으로 추가 시드를 돌릴지 | 손으로 「지금 실행」만 가능합니다 |
| 실행 주기 | 언제 돌릴지 적은 한 줄 | 주기 실행을 하지 않습니다 |
| 클라이언트 | 토렌트를 어느 다운로더에 넘길지 | 자동 실행이 안 됩니다 |
| 알림 | 끝나면 알림을 보낼지 | 알림이 없어 기록을 보러 와야 합니다 |

> **Cron**: "언제 실행할까"를 한 줄로 적은 식입니다. "매일 04:45", "5분마다"처럼 씁니다. 비우면 주기 실행을 하지 않습니다.

사이트 카드에는 사용 스위치와, 그 사이트가 요구하는 인증 값(사용자 ID, 개인 키, 로그인 값 등)을 넣는 버튼이 있습니다. 넣은 버튼은 강조되어 보이고, 저장 전에 식의 형식을 검사합니다. 설정은 뒤의 스케줄러가 맡으며 「예약 작업」목록에는 나오지 않습니다.

### 파일 탐색기

| 설정 항목 | 무엇을 정하는지 / 입력법 | 비워 두면 |
| --- | --- | --- |
| 하위 폴더까지 | 찾을 때 아래 폴더까지 볼지 | 지금 폴더만 찾습니다 |
| 압축 형식 | ZIP 또는 7Z | 압축할 수 없습니다 |
| 압축 파일 이름과 저장 위치 | 이름과 둘 곳 | 기본은 지금 폴더입니다 |
| 풀 곳 | 어디에 풀지 | 기본은 지금 폴더. 압축 파일만 고를 수 있습니다 |
| 원격 내려받기 주소와 파일 이름 | 서버가 주소를 받아 오게 합니다 | 파일 이름은 주소에서 추측됩니다 |
| 보기 설정 | 숨은 파일 보기와 크기·수정 시각·종류·동작 열의 표시 | 기본은 모두 보기 |

파일 탐색기에서 폴더를 지우면 안의 모든 것이 함께 지워지고 **휴지통이 없습니다**. 모든 동작은 AMMDS를 돌리는 계정의 권한으로 이루어지므로 권한이 모자라면 그냥 실패합니다.

## 문제가 생기면

- **"플러그인이 비활성 상태입니다"만 나온다**: 그 도구가 의지하는 서비스가 아직 켜지지 않았습니다. 통합 앱에서 켜고 연결을 시험하세요.
- **작업이 계속 줄을 선다**: 동시에 도는 수에 한도가 있습니다. 기다리거나 한꺼번에 맡기는 양을 줄이세요.
- **작업이 실패한다**: 「자세히」를 열거나 줄을 펴서 오류와 최근 출력을 보세요. 원본 파일 손상, 디스크 공간 부족, 프로그램 경로 오류가 흔합니다.
- **결과물이 안 보인다**: 고른 출력 폴더에 있습니다. 모르면 자세히 보기의 출력 경로를 확인하고, 검사를 돌려 보관함에 넣으세요.
- **갑자기 공간이 줄었다**: 변환과 캐시가 디스크를 먹습니다. 시스템 관리의 저장소 화면에서 내역을 보고 그쪽 입구에서 정리하세요.
