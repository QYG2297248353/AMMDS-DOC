# 방문객이 보는 화면

내 라이브러리를 다른 사람에게도 보여 줄 때 쓰는 것이 **공개 사이트**입니다. 이 페이지는 그것이 어떤 화면으로 되어 있는지, 방문객과 이용자에게 무엇이 다른지, 그리고 소식은 어떻게 훑고 찾는지 알려 줍니다.

> **공개 사이트**: 방문객과 훑어보는 사람을 위한 화면입니다. 보고 찾는 일은 여기서 합니다.

> **관리 화면**: 관리자를 위한 화면입니다. 파일을 읽어들이고, 정보를 채우고, 설정을 고치는 일은 그쪽에서 합니다.

> **방문객(게스트)**: 로그인하지 않고 구경하러 온 사람입니다.

## 공개 사이트와 관리 화면의 나눔

둘은 같은 계정과 데이터를 쓰지만, 들어가는 곳과 맡은 일이 다릅니다.

| 비교 | 공개 사이트 | 관리 화면 |
| --- | --- | --- |
| 대상 | 방문객과 로그인한 훑어보는 이 | 관리자와 정보를 가꾸는 이 |
| 로그인 | 목록은 열려 있고, 상세와 동작은 로그인 필요 | 전체가 로그인 필요 |
| 할 수 있는 일 | 훑기, 검색, 즐겨찾기, 구독, 공유, 읽기 | 읽어들이기, 정보 채우기, 고치기, 작업 실행, 설정 변경 |
| 정보를 관리하는 쪽 | 직접 고치지 않음 | 여기만이 정보를 고칠 수 있음 |

## 화면 한눈에 보기

| 메뉴 | 내용 | 로그인 없이 볼 수 있나 |
| --- | --- | --- |
| 작품 | 목록과 상세 | 목록은 가능, 상세는 로그인 필요 |
| 드라마 | 목록과 상세 | 목록은 가능, 상세는 로그인 필요 |
| 배우 | 목록과 상세 | 목록은 가능, 상세는 로그인 필요 |
| 만화 | 목록과 읽기 | 목록은 가능, 상세는 로그인 필요 |
| 소설 | 목록과 읽기 | 목록은 가능, 상세는 로그인 필요 |
| 소식 | 구독이 가져온 항목 | 목록은 가능, 상세는 로그인 필요 |
| 상점 | 공식 상점 | 관리 화면에서 켰을 때만 메뉴에 보임 |

:::note[사이트 첫 주소가 어디로 가는지]
사이트 뿌리 주소는 내용을 바로 보여 주지 않고, 관리 화면의 '먼저 열 곳' 설정에 따라 옮겨 갑니다. 공개를 고르면 작품 목록, 관리를 고르면 로그인한 이는 작업대로, 안 한 이는 로그인 화면으로 갑니다. 기본값은 관리입니다.
:::

## 화면 생김새

모든 화면이 같은 껍데기를 씁니다.

1. **위 띠**: 왼쪽에 사이트 표식과 첫 줄 메뉴, 오른쪽에 검색, 언어 바꾸기, 밝고 어두운 테마, 전체 화면, 로그인 입구. 폭이 좁으면 첫 줄 메뉴가 접히고 오른쪽 동작만 남습니다.
2. **내용 칸**: 목록은 '왼쪽 카드 바둑판 + 오른쪽 걸러보기' 두 칸, 상세는 한 칸입니다. 폭이 좁으면 걸러보기가 목록 위로 옮겨 갑니다.
3. **바닥글**: 관리 화면에서 정한 바로가기, 신고 정보, 정해진 저작권 문구.

## 위쪽 검색 쓰는 법

위 띠의 돋보기를 누르면 검색창이 열립니다.

1. 글자를 넣으면 저절로 찾지만, 실제로 묻는 것은 입력을 멈추고 약 300밀리초 뒤입니다.
2. 대상은 작품, 드라마, 배우, 만화, 소설, 소식 여섯 종류. 각각 최대 8건이며 종류별로 묶여 나옵니다.
3. 결과를 누르면 그 상세로 곧장 갑니다.
4. 못 찾으면 '맞는 것 없음(전체 이름으로 시도해 보세요)'이 나옵니다.

:::tip[안 나오면 색인부터 확인]
위쪽 검색은 MeiliSearch 색인(연동 앱의 보조 도구에서 설정)에 기댑니다. 색인이 만들어지지 않았으면 계속 빕니다.
:::

## 로그인과 계정

로그인하지 않았을 때 위 띠 오른쪽은 '로그인' 단추입니다. 로그인 화면에는 다음이 있습니다.

- 계정과 비밀번호. 비밀번호는 브라우저에서 암호로 바꾼 뒤 보냅니다.
- 개인정보 방침 동의. 체크하지 않으면 보낼 수 없습니다.
- 두 단계 확인. 비밀번호 뒤에 6자리 번호나 복구 코드를 넣습니다.
- '비밀번호를 잊음'은 서버에 둔 복구 열쇠로 다시 정합니다.

:::warning[스스로 가입할 수 없습니다]
로그인 화면의 '계정 등록'은 눌리지 않습니다. 공개 사이트에 가입 입구가 없습니다. 계정은 처음 설치할 때 만들어집니다.
:::

로그인하면 단추가 아바타 메뉴로 바뀌고 **개인 센터**, **관리 화면**, **스포일러 켜기 / 끄기**, **로그아웃** 넷이 들어 있습니다.

## 방문객과 이용자의 차이

| 할 수 있는 일 | 방문객 | 이용자 |
| --- | --- | --- |
| 각 목록 훑기 | 가능 | 가능 |
| 상세 열기 | 막히고 로그인 화면으로. 들어가면 원래 화면으로 돌아옴 | 가능 |
| 작품 / 배우 목록 건수 | 한 페이지 최대 30건, 페이지는 서버가 무작위로 고름 | 보통대로 페이지 이동 |
| 즐겨찾기 / 구독 / 공유 | 먼저 로그인 | 가능 |
| 만화와 소설 이어 읽기 | 읽기 입구가 로그인을 요구 | 계정별로 저장되어 이어 읽기 가능 |

:::note[방문객이 보는 것은 달라집니다]
작품·배우·소식의 방문객용 목록은 일부러 제한되어 있습니다. 요청한 페이지는 무시되고, 한 페이지가 무작위로 골라지며, 건수는 30으로 잘립니다. 그래서 새로고침하면 다른 것이 나올 수 있습니다. 한꺼번에 긁어가는 것을 막는 설계이며 데이터가 잘못된 것이 아닙니다.
:::

## 겉모습과 테마

- **모두 같은 모양**: 테마 색, 배경, 모서리 둥글기, 움직임, 추모 모드는 관리 화면의 시스템 설정에서 내려오므로 방문객은 모두 같은 것을 봅니다.
- **내 기기 취향**: 밝고 어두운 테마, 언어, 전체 화면은 방문객이 위 띠에서 바꾸며 자기 브라우저에만 남습니다.
- **스포일러 모드**: 로그인 뒤 아바타 메뉴에서 켜고 끕니다. 켜면 목록과 상세의 내용이 사이트 설정대로 다뤄집니다.

## 소식: 구독이 가져온 내용

위 메뉴의 '소식'은 구독으로 가져온 항목의 목록입니다. 여기 놓이는 것은 관리 화면에서 정한 구독 원천에서 온 것이며, 공개 사이트는 보여 주기만 합니다.

### 목록 카드

카드는 가로 표지로 깔립니다. 책상에서는 한 줄에 4장, 태블릿 3장, 휴대전화 1장입니다.

| 요소 | 내용 |
| --- | --- |
| 표지 | 없거나 못 읽으면 '그림 불러오기 실패'로 나옴 |
| 분류 꼬리표 | 왼쪽 위. 글은 파랑, 그림은 초록, 영상은 주황, 자료는 보라, 그 밖은 회색 |
| 제목 | 한 줄. 길면 줄임. 비면 `--` |
| 요약 | 최대 두 줄. 비면 `--` |
| 출처 | 왼쪽 아래에 구독 원천 이름. 비면 `--` |
| 올라온 시각 | 오른쪽 아래 |
| 바로 동작 | '원천으로'는 새 탭에서 원래 경로를 염. 토렌트 / 마그넷 / 토렌트 파일이 있으면 '원문 보기'나 '자료 내려받기'도 나옴 |

목록이 비면 '소식이 없습니다'가 나옵니다. 카드를 누르면 **새 탭**에서 상세가 열려 목록 훑기를 방해하지 않습니다.

> **RSS**: 사이트가 새 내용을 정해진 형식으로 늘어놓은 목록으로, 다른 프로그램이 정해진 때에 와서 읽습니다. 이 소식이 그렇게 들어옵니다.

### 분류와 검색

옆 칸(폭이 좁으면 목록 위로 옮겨 감)에 검색, 분류, 검색 기록이 있습니다.

- **분류**는 다섯으로 고정: 전체, 글, 그림, 영상, 자료. 단추에 올리면 '분류 이름 · 모두 N건'. 실제로 내용이 있는 분류만 나옵니다.
- 분류를 누르면 첫 페이지부터 다시 찾습니다. '전체'는 분류 조건을 붙이지 않습니다.
- **검색**은 제목과 요약을 대상으로 하며, 단추를 누르거나 줄바꿈을 해야 비로소 묻습니다. 입력 중에는 묻지 않습니다.
- **검색 기록**은 최대 15건. 겹치는 것을 빼고 위로 모읍니다. 꼬리표를 누르면 다시 찾고, **같은 꼬리표를 다시 누르면 검색 취소**입니다.
- 분류, 낱말, 페이지는 브라우저에 남아 새로고침하면 지난 상태로 돌아옵니다.

목록에 **구독 원천으로 거르는** 조작은 없습니다. 범위를 좁히려면 '분류 + 낱말'을 함께 쓰세요.

### 페이지 이동

기본은 한 페이지 20건이고 건수를 바꿀 수 있습니다. 건수를 바꾸면 첫 페이지로 돌아갑니다. 이동 도구는 전체가 0보다 클 때만 나옵니다. 방문객이 보는 전체 건수와 페이지는 실제 양을 뜻하지 않습니다(위 '방문객과 이용자의 차이' 참조).

### 상세

| 구역 | 내용 |
| --- | --- |
| 위쪽 | '목록으로' 단추 |
| 제목 칸 | 제목, 그 아래 분류 꼬리표, 출처 꼬리표, 올라온 시각 꼬리표(비면 안 나옴) |
| 영상 칸 | 영상 첨부가 있을 때 나옴. 붙박이 재생기로 재생하고 아래에 '원천으로' |
| 그림 모음 | 그림 첨부가 있을 때 나옴. 작은 그림을 누르면 커짐 |
| 본문 | 여러 모양의 글로 그림 |
| 자료 | 그림과 영상 외의 첨부를 늘어놓음. 주소, 종류, 크기를 보여 주고 오른쪽 '자료 내려받기'는 새 탭으로 |
| 옆 정보 | 출처, 올라온 시각, 분류, 작가 |
| 옆 동작 | '원문 보기'는 새 탭으로 원래 경로, '목록으로' |

소식이 없거나 지워졌으면 '소식이 없거나 이미 삭제되었습니다'가 온 화면에 나옵니다. 구역은 내용이 있을 때만 그려지므로 분류마다 보이는 구역 수가 다릅니다.

:::tip[여기서 재생할지 원천으로 갈지]
영상 칸이 재생하는 것은 첨부에 적힌 주소입니다. 관리 화면에서 내 기기에 사본을 만들어 뒀으면 그것을, 아니면 원천을 가리킵니다. 재생기가 안 되거나 원래 페이지를 보고 싶으면 '원천으로'를 쓰세요.
:::

바깥 경로는 모두 새 탭에서 열리며, 지금 화면의 정보를 상대에게 넘기지 않습니다.

## 실행 모드가 공개 사이트에 주는 영향

| 모드 | 방문객이 보는 것 |
| --- | --- |
| 보통 | 목록과 검색이 됨. 로그인하면 상세와 동작도 |
| 관리만 | 공개 주소가 '사이트가 닫혔습니다' 화면으로 바뀜 |
| 창구만 | 관리를 포함한 모든 화면이 '사이트가 닫혔습니다'로 감 |

:::note[잠깐의 이상으로 전체가 멈추지는 않음]
실행 모드 판단이 실패해도 이동을 막지 않습니다. 공개 사이트는 계속 열립니다.
:::

## 문제가 생겼을 때

- **상세를 눌러도 안 되고 로그인으로 감**: 상세는 로그인이 필요합니다. 들어가면 저절로 원래 화면으로 돌아옵니다.
- **검색에 아무것도 안 나옴**: MeiliSearch가 설정되고 색인이 만들어졌는지 확인하세요(연동 앱의 보조 도구).
- **목록이 계속 빔**: 관리 화면에서 아직 읽어들이지 않았거나, 걸러보기가 너무 좁습니다.
- **방문객은 볼 때마다 다름**: 의도한 설계입니다. 로그인하면 보통의 페이지 이동으로 돌아옵니다.
- **소식 표지가 깨지거나 영상이 안 나옴**: 첨부가 원천을 가리키는데 이 기기에서 닿지 않습니다. '원천으로'를 쓰거나 관리 화면에서 내 기기 사본을 만드세요.
- **소식이 늘 '없습니다'**: 구독 원천이 아직 없거나 가져온 것이 없습니다.
