# 작품, 드라마, 배우, 만화와 소설 둘러보기

영상 작품, 드라마, 배우, 만화, 소설 이 다섯 자료실은 화면 구조가 비슷합니다. 왼쪽에 카드가 늘어서 있고 오른쪽에 걸러보기가 늘어서 있습니다. 이 페이지에서는 먼저 공통점을 설명하고, 이어서 각 자료실에서 무엇을 보고 무엇을 할 수 있는지 하나씩 알려 드립니다.

> **식별 번호(인식 코드)**: 작품을 구별하는 번호로 보통 파일 이름에 들어 있습니다. 예: `SSIS-001`. 카드에서는 보라색 작은 꼬리표로 보입니다.

> **시즌 / 회**: 드라마의 층위입니다. 한 편의 드라마가 여러 시즌으로 나뉘고, 시즌 아래에 다시 회가 나뉩니다.

> **마그넷**: 내려받기 도구에 바로 맡길 수 있는 글자열로, 씨앗 파일과 같은 구실을 합니다.

## 다섯 자료실의 공통점

### 목록 화면의 생김새

| 구역 | 내용 |
| --- | --- |
| 왼쪽 내용 칸 | 카드 바둑판과 쪽 넘김 |
| 오른쪽 걸러보기 | 검색, 한국어 우선, 모드, 검색 기록, 인기 꼬리표, 이 자료실 소개 |

넓은 화면에서는 한 줄에 6장, 창이 좁아지면 차례로 4, 3, 2, 1줄로 줄어듭니다. 폭이 1024px을 넘지 않으면 오른쪽 걸러보기가 통째로 숨고, 만화와 소설은 그것을 목록 위로 옮깁니다.

### 걸러보기 요소

| 요소 | 구실 | 안 쓰거나 안 바꾸면 |
| --- | --- | --- |
| 검색창 | 낱말을 넣고 Enter를 누르거나 검색 단추를 누름 | 안 쓰면 전체 내용 |
| 한국어 우선 | 제목 표시에만 작용: 켜면 한국어 제목, 끄면 원제 | 찾아온 결과에는 영향 없음. 보이는 이름만 바뀜 |
| 모드 | '전체 자료실' 또는 '즐겨찾기 자료실', 바꾸면 곧 다시 검색 | 기본은 전체 자료실, 전체 내용이 보임 |
| 검색 기록 | 최대 15개까지 브라우저에 남고, 누르면 다시 쓸 수 있음 | 지금의 낱말을 다시 누르면 검색 취소와 같음 |
| 꼬리표 | 인기 꼬리표(최대 20개)를 보여 주고 누르면 꼬리표로 걸러봄 | 다시 누르면 해제. 꼬리표를 고르면 낱말이 지워짐 |

:::warning[낱말과 꼬리표는 함께 못 씁니다]
낱말을 넣으면 고른 꼬리표가 지워지고, 꼬리표를 고르면 낱말이 지워집니다. 둘이 '동시에 만족'하는 조건으로 합쳐지지는 않습니다.
:::

### 쪽 넘김과 기억

- 한 쪽에 20건(소설은 16건)으로 고정되고, 쪽 표시에는 총수만 있으며 쪽당 건수 고르기는 없습니다.
- 검색 조건, 모드, 한국어 우선 등은 브라우저에 저장되어 새로 고침 후에도 돌아옵니다.
- 작품과 드라마는 상세로 들어갈 때 쪽수를 주소창에 남겨, 상세에서 뒤로 가면 원래 쪽으로 돌아옵니다.
- 로그인하지 않은 방문객은 한 쪽에 최대 30건이며 쪽수는 서버가 무작위로 고릅니다. 그래서 새로 고침하면 다른 내용이 보일 수 있는데, 일괄 수집을 막기 위한 설계입니다.

## 작품(영상)

목록 주소는 작품 목록 화면이고, 카드를 누르면 상세로 들어갑니다(**상세는 로그인 필요**, 안 한 상태면 로그인 화면으로 갔다가 로그인 뒤 그 화면으로 자동 돌아옵니다).

### 카드에 무엇이 있나

- **표지**: 고화질 표지를 우선. 그림이 없거나 불러오기에 실패하면 '그림 불러오기 실패'를 보입니다.
- **떠 있는 꼬리표**: 개봉 날짜, 평점(10점 만점), 그리고 서버가 단 '재생 가능' 표시. 값이 있을 때만 보입니다.
- **제목**: '한국어 우선'의 영향을 받습니다. 작품 목록은 한국어 제목이 비었을 때 되돌림 처리를 하지 않아, 비어 있으면 제목이 비어 보입니다.
- **식별 번호**: 보라색 작은 꼬리표, 여러 개일 수 있습니다.
- **배우**: 청색 꼬리표. 아이콘은 역할 글자에 '남 / 여'가 들어 있느냐에 따라 바뀌고, 판단이 안 되면 물음표 사람 아이콘을 보입니다.

### 상세 화면

맨 위는 큰 제목과 한국어 제목('번역' 꼬리표 붙음)이고, 큰 그림은 고화질 배경 그림을 우선합니다.

| 정보 항목 | 설명 |
| --- | --- |
| 식별 번호 | 전체 식별 번호를 꼬리표로 표시 |
| 개봉 날짜 | 원래 날짜 글자 그대로 |
| 길이 | 분 단위 수 |
| 감독 / 제작사 / 배급사 | 여러 값 꼬리표 |
| 배우 | 이름 꼬리표. 작품실에 그 배우가 있으면 배우 상세로 들어갈 수 있음 |

정보 오른쪽에 단추 세 개: **구독**, **즐겨찾기**, **공유**. 구독과 즐겨찾기는 지금 상태에 따라 아이콘과 색이 바뀌고, 공유는 로그인하지 않았으면 로그인이 필요하다는 안내가 뜹니다.

그 아래는:

| 구역 | 내용 |
| --- | --- |
| 평점 | 별 5개를 10점 만점으로 환산, 반 별 지원. 점수는 구간별 색(8점 이상 초록, 4점 이상 주황, 나머지 빨강) |
| 마그넷 제출 | 마그넷 링크를 넣고 '제출' 누름. 비었으면 '마그넷 링크를 입력해 주세요' 안내 |
| 확장 정보 | 꼬리표 세 개: 분류, 태그, 확장 정보 짝꿍 표 |
| 배우 | 얼굴 + 이름 + 역할, 가로로 넘김 |
| 표지 / 배경 그림 / 썸네일 / 스틸컷 | 그림 벽. 고화질이 맨 위, 누르면 전체 화면으로 볼 수 있음 |
| 자원 공유 | 마그넥 목록: 이름, 크기, 공유 날짜와 동작 |
| 댓글칸 | 앞면 자리만 있음. 맨 아래 설명 참고 |

:::warning[상세 화면에 재생기가 없습니다]
작품 상세는 자료, 그림과 자원만 보여 주고 **재생기도 '재생' 단추도 없습니다**. 카드의 '재생 가능'은 항목에 단 표시일 뿐 여기서 재생된다는 뜻이 아닙니다. 영상을 보려면 겉의 재생 도구를 쓰세요.
:::

'자원 공유'의 각 줄에는 동작 세 개: **내려받기로 보내기**(지금 버전에서는 눌러도 '곧 만나요' 안내만 뜸), **마그넷 복사**, **자원 신고**(지금 버전에서는 눌러도 '곧 만나요' 안내만 뜸). 마그넷 표가 비었으면 '공유된 자원이 없습니다'가 보입니다.

## 드라마

드라마는 연속극, 일본 애니메이션, 예능을 '한 편의 극'으로 모으고, 상세 화면에서 모든 시즌과 회를 한 화면에 펼쳐 구조를 보기 쉽게 합니다.

### 카드에 무엇이 있나

- **표지**: 세로형. 그림이 없거나 불러오기에 실패하면 '그림 불러오기 실패'를 보입니다.
- **떠 있는 꼬리표**: 첫 방송 연도, 평점.
- **제목**: '한국어 우선'의 영향을 받습니다.
- **구역**: 인터페이스가 돌려준 구역 이름을 우선, 없으면 안에 있는 대응표에 따라 일본 애니메이션, 일본 드라마, 한국 드라마, 중국 드라마, 미드·유럽 드라마, 다큐멘터리, 예능, 기타를 보입니다.
- **연재 상태**: `Continuing`는 '연재 중', `Ended`는 '완결'로 보입니다.
- **시즌·회 수**: '3시즌 · 24회' 꼴.
- **종류**: 앞의 세 종류를 ' / '로 이어 붙입니다.

### 상세 화면

| 정보 항목 | 설명 |
| --- | --- |
| 첫 방송 날짜 | 없으면 `-` 표시 |
| 길이 | 분 단위 수 |
| 구역 | 한국어 구역 이름, 알 수 없는 코드는 그대로 표시 |
| 자료 출처 | 자료 출처 코드, 없으면 `-` |
| 시즌 수 / 회 수 | 출처가 밝힌 총수를 우선, 없으면 실제 등록 수 |
| 상태 | 연재 중 / 완결 / 원래 값 |
| 종류 / 제작사 | 여러 값 꼬리표 |

여기에도 **구독, 즐겨찾기, 공유** 단추 세 개가 있습니다. 평점은 작품과 같고, 마그넷 제출칸은 링크 제출만 맡아 제출 뒤 입력칸을 비우며 **화면에 마그넥 목록을 보여 주지는 않습니다**.

### 시즌과 회

'시즌·회 목록'은 모든 시즌을 접을 수 있는 판으로 한꺼번에 그립니다:

1. 판 제목은 시즌 이름 또는 '제 N 시즌'. 시즌 번호가 0이거나 특별편 표시가 있으면 '특별편'으로 통일해 보입니다.
2. 판 오른쪽에 '이 시즌은 모두 N회'가 보입니다.
3. 판 안에는 시즌 포스터, 시즌 첫 방송 날짜와 시즌 소개가 있습니다.
4. 시즌 안은 표로 회 번호, 제목, 첫 방송 날짜, 길이, 평점, 썸네일을 나열. 제목은 한국어 이름을 우선하고 없으면 원래 이름으로 되돌립니다.
5. 기본으로 '회가 있는' 첫 시즌을 펼칩니다. 시즌이 없으면 '시즌·회 자료가 없습니다'가 보입니다.

:::warning[시즌·회 표는 재생 목록이 아닙니다]
표는 회 번호, 제목, 첫 방송 날짜, 길이, 평점, 썸네일만 보여 주고 회에 파일 정보가 들어 있지 않으며 재생기도 없습니다. 파일 묶기는 관리 화면에서 이루어집니다.
:::

그림 구역에는 표지, 배경 그림, 썸네일, 로고와 배너가 있습니다. 드라마 항목에는 '스틸컷' 항목이 없어 스틸컷 구역도 없습니다.

## 배우

배우실은 배우 인적 사항과 출연 작품을 이어 줍니다.

### 카드에 무엇이 있나

- **포스터**: 세로형. 그림이 없거나 불러오기에 실패하면 '그림 불러오기 실패'를 보입니다.
- **떠 있는 꼬리표**: 데뷔 날짜, 키(cm), 몸무게(kg).
- **이름**: '한국어 우선'의 영향을 받습니다.
- **기본 꼬리표**: 성별, 나이, 국적, 은퇴, 별세, 가슴 둘레 등 값이 있을 때만 보입니다. 목록에서 성별은 `female`(여로 표시)와 나머지(남으로 표시)만 구분합니다.

### 상세 화면

맨 위는 배우 이름이고, 별명이 있으면 아래에 '별명: A / B'로 보입니다. 주 카드 왼쪽은 얼굴 그림, 오른쪽에 차례로:

| 정보 | 보이는 방식 |
| --- | --- |
| 성별 | 남 / 여 / 트랜스젠더 / 알 수 없음 |
| 나이 | 'N살' |
| 은퇴 / 별세 | 주황 / 빨강 꼬리표 |
| 키 / 몸무게 | 'N cm', 'N kg' |
| 혈액형 / 생년월일 / 국적 | 꼬리표 |
| 세 치수 | '가슴-허리-엉덩이', 가슴 둘레 등급을 덧붙일 수 있음 |
| 데뷔 날짜 / 소속사 | 날짜 글자와 꼬리표 목록 |
| 평점 | 별 5개 + 10점 만점 점수 |
| 소셜 링크 | 도메인으로 흔한 소셜 사이트를 알아 맞히고 나머지는 일반 링크 아이콘 |

여기에도 **구독, 즐겨찾기, 공유** 단추 세 개가 있습니다.

| 구역 | 내용 |
| --- | --- |
| 확장 정보 | 꼬리표 다섯 개: 소개, 스타일, 특징, 태그, 확장 정보(짝꿍 표) |
| 포스터 | 배우 그림 모음, 미리 볼 수 있음. 없으면 '포스터가 없습니다' |
| 출연작 | 최근 20편의 출연 작품을 개봉 시간 새 순으로. 앞면은 한 쪽 10건, 제목을 누르면 작품 상세로 |
| 소식 | 배우 이름을 낱말로 찾아 최대 10건 |

:::tip[건수 한계]
출연작은 한 번에 최근 20편, 소식은 한 번에 10건만 가져오며 두 목록 모두 '더 보기'가 없습니다. 더 보려면 작품 목록이나 소식 화면에서 찾아 보세요.
:::

:::note['추천 배우'는 지금 비어 있습니다]
'추천 배우' 카드에는 아직 자료를 채울 곳이 없어 늘 '추천 배우가 없습니다'를 보입니다. 손 모양 커서가 있지만 눌러도 이동하지 않으니 입구로 여기지 마세요.
:::

## 만화

만화는 '표지 목록 → 상세와 회 → 전체 화면 읽기 도구'의 세 단계입니다.

### 카드와 걸러보기

카드에는 표지, 분류(전집이 아니고 시즌 번호가 0보다 크면 '제 N 시즌', 전집이면 '전집'), 제목, 작가, 시리즈와 최대 3개의 꼬리표가 있습니다. 검색창은 제목, 설명, 메모, 작가, 그린이, 출판 정보와 시리즈를 함께 찾습니다.

### 상세 화면

왼쪽은 표지, 오른쪽에는 먼저 꼬리표 한 줄(분류, 전집 / 제 N 시즌, 연령 등급, 쪽 수 '모두 N쪽'), 다음은 '항목 - 값' 꼴의 자료 표(작가, 시리즈, 출판사, 인쇄소, 출판 날짜, 언어, 형식, 색채, 읽는 방향, 연령 등급, 공동체 평점, 메모, 링크. 빈 값은 줄을 차지하지 않음), 그다음 꼬리표, 등장인물, 팀, 장소와 소개, 마지막으로 평점이 놓입니다.

오른쪽 세로로 단추 네 개:

1. **이어 읽기**: 이 이용자의 읽기 진행이 있고 그 진행이 속한 회가 회 목록에 아직 있을 때만 보입니다.
2. **읽기 / 처음부터 읽기**: 진행이 없으면 '읽기', 있으면 '처음부터 읽기'. 언제나 첫째 회를 엽니다.
3. **즐겨찾기 / 즐겨찾기됨**: 로그인하지 않았으면 로그인 확인창이 뜹니다.
4. **공유**: 로그인하지 않았으면 로그인 확인창이 뜹니다.

회 목록은 한 쪽 20회, 각 회는 제목, '제 N 화 · X쪽'과 선택적인 설명을 보입니다. 이어 읽는 회에는 '제 N쪽까지 읽음'이 붙고, 진행이 있으면 카드 오른쪽 위에 '이어 읽기 제 N쪽'이 나타납니다.

### 읽기 도구

읽기 도구는 전체 화면이며, 위 띠, 읽는 칸, 아래 띠와 맨 아래 진행줄로 나뉩니다. 위 띠에는 돌아가기, 제목, 회 고르기, 이전 회 / 다음 회, 넘기는 방향, 전체 화면이 있고, 아래 띠에는 넘기기, 쪽수 입력, 확대·축소, 쪽 이동과 설정이 있습니다.

- **넘기기**: 한 쪽 / 두 쪽 지원(칸 폭이 720px 이상이어야 두 쪽, 아니면 한 쪽으로 되돌아감). 왼쪽 3분의 1을 누르면 앞쪽, 오른쪽 3분의 1을 누르면 뒷쪽, 가운데를 누르면 도구 막대를 접거나 폅니다. 마지막 쪽에서 계속 넘기면 다음 회로 들어갑니다.
- **흐름 방식**: 모든 그림이 세로로 늘어서고, 화면 맨 위 35% 기준으로 쪽수를 맞춥니다.
- **확대·축소**: 0.5–5배. 단추는 한 번에 ±0.25, 백분율을 누르면 원위치. 두 번 누르면 1배와 2배를 오갑니다.
- **빠른 글쇠**: 왼쪽·오른쪽 방향 글쇠로 넘기기, 빈칸 뒷쪽, PageUp / PageDown 넘기기, Home / End 첫·끝쪽, `+` / `-` 확대·축소, `0` 원위치, `F` 전체 화면, `Esc` 전체 화면 끝내기 또는 도구 막대 접기·펴기.

### 읽기 도구 설정 항목 설명

오른쪽 아래 '설정' 서랍:

| 설정 항목 | 무엇을 고르나 | 안 바꾸거나 잘못 고르면 |
| --- | --- | --- |
| 읽는 방식 | 넘기기 / 흐름 | 기본은 넘기기. 흐름을 고르면 세로로 긴 그림줄이 됨 |
| 그림 맞춤 | 폭 / 높이 / 원래 크기 | 잘못 고르면 화면을 넘거나 너무 작아짐 |
| 그림 사이 | 0–40px | 기본은 그대로 |
| 넘기는 방향 | 왼쪽에서 오른쪽 / 오른쪽에서 왼쪽 | 방향이 반대면 누르는 자리가 바뀜 |
| 한 쪽 / 두 쪽 | 한 쪽 / 두 쪽 | 화면이 좁으면 한 쪽으로 강제됨 |
| 배경 테마 | 검정 / 짙은 회색 / 크림 / 눈 보호 / 흰색 | 보이는 느낌만 다름 |
| 미리 읽기 | 0–10쪽 | 크게 하면 부드럽지만 통신이 늘어남 |
| 바퀴로 확대 | 켬 / 끔 | 끄면 바퀴는 넘기기에 쓰임 |
| 양옆 눌러 넘기기 | 켬 / 끔 | 끄면 눌렀을 때 막대 접기·펴기만 됨 |
| 터치 화면에서 막대 자동 숨김 | 켬 / 끔 | 켜면 휴대폰에서 살짝 대야 막대가 나타남 |

설정은 지금 브라우저에만 남으며 **다른 기기로 따라가지 않습니다**. '기본값으로 되돌리기'로 모두 되돌릴 수 있습니다.

:::tip[설정과 진행은 별개입니다]
진행 정도는 계정별로 서버에 남아 다른 기기에서도 이어 읽을 수 있습니다. 설정은 이 브라우저에만 저장됩니다.
:::

진행은 '만화 + 회 + 쪽수'로 기록하고, 쪽수나 회가 바뀐 뒤 약 800밀리초 후에 저장합니다. 회를 바꾸거나, 돌아가거나, 화면이 숨거나 떠날 때는 곧바로 저장합니다. 서버에 문제가 생겨도 손 안의 임시 저장이 남아 다음에 이어 읽을 수 있습니다.

## 소설

소설은 '목록 → 상세와 목차 → 읽기 도구'의 세 단계입니다.

### 목록

한 쪽 16권. 카드에는 표지, 왼쪽 위 파란 종류 꼬리표, 제목('한국어 우선'을 켜면 한국어 제목 우선), 작가(비었으면 '작가 미상'), '모두 12장 · 연재' 꼴의 장 수와 상태(완결 / 연재 / 초고 / 계속 대기 / 집필 중)가 있습니다.

### 상세 화면

| 구역 | 내용 |
| --- | --- |
| 제목칸 | 책 이름과 '작가: xxx' |
| 꼬리표 줄 | 종류, 상태, 언어와 '모두 N장'. 비으면 보이지 않음 |
| 설명 목록 | 작가, 시리즈, 출판사, 출판 연도, ISBN, 총 장 수, 쪽 수. 값이 있는 항목만 표시 |
| 꼬리표 / 소개 | 청색 작은 꼬리표와 긴 글 |
| 평점 | 10점 만점을 하트 5개로 환산, 오른쪽에 'N점' |
| 빠른 동작 | 이어 읽기(진행이 있을 때 나타남), 처음부터 읽기 / 읽기(언제나 첫째 장부터), 진행 안내 '지난번에 제 N장 · 장 제목까지 읽음', 즐겨찾기 / 즐겨찾기됨, 공유 |
| 장 목차 | '차례 + 제목 + 글자 수'로 한 줄씩, 오른쪽에 '읽기'. 한 쪽 20장. 지난번에 읽은 장에는 주황 '지난번' 꼬리표가 붙고, 상세에 들어오면 그 쪽으로 자동으로 넘겨 줌 |

즐겨찾기는 로그인하지 않았으면 '작업 실패, 로그인했는지 확인해 주세요'라는 안내가 뜹니다. 공유는 창을 열고 만든 뒤 공유 링크 한 줄을 얻습니다.

### 읽기 도구

읽기 도구는 화면을 가득 채우며, 위·아래 조작줄은 기본으로 숨겨져 화면 가운데를 눌러 꺼내고 4초 동안 조작이 없으면 저절로 접힙니다.

| 위치 | 요소 |
| --- | --- |
| 위 | 돌아가기, 책 이름, 목차, 전체 화면 / 끝내기, 설정 |
| 본문 | 장 제목, 본문 문단, 장 끝의 '—— 이 장 끝 ——' |
| 장 끝 | 다음 장이 있으면 '다음 장: 제목'이 보이고 누를 수 있음. 마지막 장이면 '마지막 장입니다' |
| 아래 | 이전 장, 이전 쪽, 상태 글자, 다음 쪽, 다음 장 |
| 아래 상태 | 넘기기 방식은 '제 x/y장 · 제 a/b쪽 · 책 전체 백분율', 흐름 방식은 '제 x/y장 · 흐른 백분율 · 이 장 글자 수' |

목차는 화면을 덮는 서랍으로 제목이 '목차 · 모두 N장', 지금 장이 밝게 표시되고 열면 지금 장으로 자동 스크롤합니다. 장을 바꿔도 본문을 지우지 않고 위에 가는 진행줄만 보입니다.

### 읽기 설정 항목 설명

설정 판의 고르기는 바로 반영되고 브라우저에 저장되어 다른 기기로 옮겨지지 않습니다.

| 설정 항목 | 고를 수 있는 값 | 안 바꾸면 |
| --- | --- | --- |
| 읽는 방식 | 넘기기 / 흐름 | 지난번 선택을 따름 |
| 테마 | 흰색, 크림, 눈 보호, 어두운 밤 | 색만 달라짐 |
| 글자 크기 | A- / A+로 한 번에 2px씩, 범위 12–34px. 가운데 숫자를 누르면 18px로 되돌림 | 지난값 유지 |
| 줄 간격 | 1.4 / 1.6 / 1.8 / 2.0 / 2.4 | 지난값 유지 |
| 글꼴 | 시스템 기본, 명조, 해서, 고딕 | 지난값 유지 |
| 본문 폭 | 좁 / 알맞 / 넓(620 / 760 / 900px) | 지난값 유지 |
| 쪽 여백 | 좁 / 알맞 / 넓. 좁은 화면에서는 비율로 줄어듦 | 지난값 유지 |
| 넘김 움직임 | 켬 / 끔 | 끄면 미끄러지는 넘김 사라짐 |
| 첫 줄 들여쓰기 | 켬 / 끔 | 끄면 문단이 들여쓰기되지 않음 |
| 양옆 눌러 넘기기 | 켬 / 끔 | 끄면 눌렀을 때 조작줄 접기·펴기만 됨 |
| 바퀴로 넘기기 | 켬 / 끔, 넘기기 방식에서만 작동 | 흐름 방식은 언제나 스크롤을 따름 |
| 장 끝에서 자동으로 다음 장 | 켬 / 끔 | 끄면 장 끝에서 '이 장의 마지막 쪽입니다'만 안내 |
| 진행줄 보이기 | 켬 / 끔 | 끄면 아래의 책 전체 진행줄이 보이지 않음 |

글자 크기, 줄 간격, 글꼴, 들여쓰기, 본문 폭, 여백을 바꾸면 쪽을 다시 나누고 지금 쪽의 첫 문단을 기준으로 읽던 자리를 지킵니다.

### 조작 방식

| 조작 | 결과 |
| --- | --- |
| 화면 왼쪽 3분의 1쯤 누르기 | 앞쪽. 장 첫 쪽이면 앞 장의 마지막 쪽으로 되돌아 넘김 |
| 화면 오른쪽 3분의 1쯤 누르기 | 뒷쪽. 장 마지막 쪽이면 설정에 따라 다음 장으로 |
| ← / → / 빈칸 / PageUp / PageDown | 앞 / 뒤 |
| ↑ / ↓ | 흐름 방식에서는 화면 단위, 넘기기 방식에서는 앞 / 뒤와 같음 |
| Esc | 조작줄, 설정 판, 목차 닫기 |
| 터치 화면에서 좌우 쓸기 | 가로 움직임이 40px을 넘고 세로보다 눈에 띄게 크면 넘겨 짐 |

글자를 선택한 상태에서 누르면 넘겨지지 않으며, 조작줄과 목차, 설정 덮개 위의 누름도 넘기기에 참여하지 않습니다.

### 읽기 진행

| 상황 | 행동 |
| --- | --- |
| 로그인하고 읽기 | 진행이 서버에 기록됨. 장, 장 차례, 장 안 백분율과 쪽수 |
| 방문객이 읽기 | 브라우저 임시 저장에만 남음. 기기를 바꾸거나 저장을 지우면 사라짐 |
| 저장되는 때 | 넘기거나 흐름이 멈춘 뒤 약 1.2초 후. 장을 바꾸거나, 화면이 숨거나 떠날 때는 곧바로 |
| 다시 열 때 | 서버와 손 안 저장을 함께 읽고 더 새 것을 택함 |
| 같은 장 이어 읽기 | 장 안 자리를 되살림. 주소창에 장이 지정돼 있으면 그 장의 처음부터 |

:::tip[상세 화면에서 들어가세요]
책 지정 없이 읽기 도구 주소를 열면 '소설 지정이 없습니다. 소설 상세에서 들어와 주세요'라는 안내가 나옵니다. 상세의 장 목차나 빠른 동작에서 들어가 주세요.
:::

## 아직 안 된 몇 군데

있는 그대로 알려 드립니다. 내 탓이 아닙니다:

- **작품 '같은 시리즈 작품'** 카드는 늘 '같은 시리즈 작품이 없습니다'를 보입니다. 이 구역에 자료를 채우는 일이 아직 없습니다.
- **드라마 '같은 시리즈 드라마'**도 늘 비어 있습니다. 드라마 시리즈 모형이 아직 없습니다.
- **댓글칸**은 앞면 자리입니다. 기본으로 'AMMDS 공식 / 곧 만나요' 한 줄을 보이고, 제출해도 지금 화면에 끼워 넣을 뿐 새로 고침하면 사라지며 좋아요와 답글도 뒷단과 이어지지 않았습니다. 공동체 기능으로 쓰지 마세요.
- **작품의 '내려받기로 보내기'와 '자원 신고'**는 지금 눌러도 '곧 만나요'만 안내합니다.
- 작품 상세에는 언어, 나라 / 지역, 등급, 시리즈 같은 항목 표시가 **없습니다**. 이런 것은 관리 화면의 자료실에서 확인하세요.

## 문제가 생겼을 때

- **카드를 눌렀더니 로그인 화면으로 감**: 상세는 로그인이 필요합니다. 로그인에 성공하면 원래 화면으로 자동 돌아옵니다.
- **목록이 계속 비어 있음**: 관리 화면에서 아직 읽어들이지 않았거나, 걸러보기 조건이 너무 좁습니다(낱말과 꼬리표는 겹칠 수 없으니 조건이 하나만 남았는지 살펴 보세요).
- **새로 고침했더니 목록이 달라짐**: 방문객이면 한 쪽 건수에 제한이 있고 쪽수가 무작위이므로 정상입니다. 로그인하면 돌아옵니다.
- **카드 제목이 비어 있음**: 작품 목록은 한국어 제목이 비었을 때 되돌림을 하지 않습니다. '한국어 우선'을 끄면 원제가 보입니다.
- **배우를 눌렀는데 '이 배우의 상세가 없습니다'라는 안내**: 그 배우는 작품의 배우 대응에만 있고 배우실에는 아직 들어오지 않았습니다.
- **만화의 이어 읽기 단추가 사라짐**: 서버에 그 계정의 진행이 없거나, 진행이 속한 회가 회 목록에서 빠졌습니다.
- **기기를 바꿨더니 진행은 남고 설정이 없어짐**: 진행은 계정과 함께 서버에, 설정은 원래 브라우저에만 저장됩니다. 예상된 행동입니다.
- **소설 읽기 도구를 열었더니 지정이 없다는 안내**: 상세 화면의 장 목차나 '읽기 / 이어 읽기' 단추에서 들어가 주세요.
