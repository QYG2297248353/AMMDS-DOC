# 공유, 상점과 개인 홈페이지

이 페이지는 사람과 어울리는 세 가지 일을 다룹니다. **공유**(항목을 로그인 없이 열리는 공개 주소로 바꾸는 일), **상점**(사이트 안에 작은 가게를 여는 일), **개인 홈페이지**(다른 사람에게 보이는 나와, 내 자료를 가꾸는 곳)입니다.

> **짧은 코드**: 공유 링크 끝에 붙는 무작위 글자열, 예: `ABC123`. 그 공유만의 표지입니다.

> **Passkey**: 암호 대신 기기의 생체 정보나 기기에 묶인 열쇠로 들어가는 방식입니다. 관리 화면에서 해당 기능을 켰을 때만 로그인 화면에 이 선택이 나타납니다.

> **복구 열쇠**: 설치할 때 만들어지는 비상 열쇠입니다. 암호를 잊었을 때 이것으로 되돌립니다. 잃어버리면 배포 문서의 초기화 절차를 따라야 하니 소중히 보관하세요.

## 공유 화면

공유 링크는 영상 작품, 배우, 시리즈, 만화, 소설, 드라마를 짧은 코드가 붙은 공개 주소로 바꿉니다. 상대는 로그인 없이 열 수 있습니다. 공유 화면은 보여 주기만 합니다. 가져올 수 있느냐는 만든 이가 정하고, 가져오기 자체는 받는 쪽의 자기 시스템 안에서 이루어집니다.

### 주소의 생김새

```
https://당신의 도메인/share/짧은 코드
```

| 항목 | 설명 |
| --- | --- |
| 경로 | `/share/:code`. `code`는 만들 때 나온 짧은 코드 |
| 로그인 | 필요 없음. 방문객이 바로 열 수 있음 |
| 틀 | 공용 틀. 사이트의 위 띠가 없고 어느 메뉴에도 나타나지 않음 |
| 폭 | 내용 칸은 최대 약 1040px. 책상 위에서는 가운데, 휴대폰에서는 한 줄 |

짧은 코드만이 표지이며 주소에는**열쇠가 들어 있지 않습니다**. 열쇠를 붙였다면 다른 수단으로 상대에게 따로 알려 주어야 합니다.

### 화면의 짜임

| 자리 | 내용 |
| --- | --- |
| 위 꼬리표 | '공유 링크에서 옴' 표, 종류 꼬리표(작품 / 시리즈 / 배우 / 만화 / 소설 / 드라마, 종류별로 색이 다름), 가져오기가 허락되지 않을 때 '보기만' 꼬리표 |
| 제목 | 공유된 항목의 제목. 길면 줄바꿈됨 |
| 유효 기간 | 영구이면 '영구 유효', 아니면 '유효 기간 YYYY-MM-DD HH:mm' |
| 내용 | 종류에 맞춰 그려지는 항목의 상세. 다음 절 참고 |
| 바닥글 | 정해진 문구 '© AMMDS 提供技术支持' |

'보기만' 꼬리표는 만든 이가 '다른 사람의 가져오기 허용'을 껐을 때만 나타납니다. 꼬리표가 없으면 상대가 바로 가져올 수 있습니다.

### 열쇠

열쇠를 붙인 공유는 내용 대신 먼저 열쇠 판을 보입니다.

1. 판의 제목은 '이 공유에는 열쇠가 필요합니다'이고, 아래에 공유된 항목의 제목이 붙어 어떤 공유인지 알 수 있게 합니다.
2. '열쇠를 입력해 주세요' 칸에 넣고 Enter나 '풀기'를 누릅니다.
3. 비어 있으면 그 자리에서 '열쇠를 입력해 주세요'가 뜨고 요청은 보내지지 않습니다.
4. 틀리면 칸 아래에 '열쇠가 틀렸습니다. 다시 시도해 주세요'가 뜨고 계속 시도할 수 있습니다.
5. 통과하면 돌아온 내용 전체로 판을 바로 바꿉니다. 새로 고침은 필요 없습니다.

열쇠 확인은 이 화면에서만 유효하고 새로 고침하면 다시 입력해야 합니다. 열쇠는 주소창에도 브라우저 저장에도 남지 않습니다.

### 공유 내용의 종류

하나의 공유는 한 종류에만 속하고 화면은 종류에 맞는 구성요소를 불러옵니다. 아래 구역은 자료가 있을 때만 나타납니다.

| 종류 | 보이는 것 |
| --- | --- |
| 작품 | 머리(표지, 평점, 꼬리표, 식별 번호 / 초연 / 길이 / 제작 / 등급 / 언어 / 해상도 / 용량 / 부호 / 자막 등 자료), 줄거리, 배우, 스틸컷, 속한 시리즈 |
| 시리즈 | 머리와 자료, 시리즈 소개, 작품 수, 작품 목록. 없으면 '이 시리즈에는 아직 작품이 없습니다' |
| 배우 | 머리(얼굴, 별명, 성별, 나이, 키, 몸무게, 생일, 국적, 혈액형, 세 치수, 데뷔 날, 소속, 상태), 약력, 사진 |
| 만화 | 머리(작가, 시리즈, 분류, 종류, 시즌, 쪽 수, 연령 등급, 평점, 언어, 출판 정보, 읽는 방향 등), 소개, 메모, 만든 이, 등장인물, 팀, 장소, 회 목록(각 회에 쪽 수 표기) |
| 소설 | 머리(부제, 분야, 상태, 출판사, 출판 연도, 언어, 쪽 수, 장 수, 속한 시리즈, ISBN), 내용 소개 |
| 드라마 | 머리(종류, 제작사, 연도, 첫 방송, 평점, 길이, 상태, 구역), 줄거리, 배우, 시즌과 회(특별편이 맨 앞, 각 시즌은 회 번호 / 제목 / 첫 방송 세 줄), 종류와 제작사 |

소설 공유는 장의 총수만 가지고 **장 목차는 보여 주지 않습니다**. 만화 공유에는 회 목록이 따라옵니다. 공유 화면에는 영상 파일이나 본문을 내려받는 입구도 없습니다.

### 끊겼을 때와 실패 안내

상태에 따라 반쪽짜리 내용이 아니라 판 전체로 알려 줍니다.

| 상태 | 제목 | 문구 |
| --- | --- | --- |
| 불러오기 실패 또는 짧은 코드 없음 | 공유가 없거나 불러오지 못했습니다 | 내용을 가져올 수 없습니다. 링크가 유효한지 확인하거나 나중에 다시 시도해 주세요. 판 안에 '다시 불러오기' 있음 |
| 만든 이가 일시 중지 | 공유가 중지되었습니다 | 만든 이가 이 공유를 일시 중지하여 지금은 열 수 없습니다 |
| 유효 기간 지남 | 공유가 만료되었습니다 | 이 공유 링크는 유효 기간을 지나 열 수 없습니다 |
| 종류에 맞는 구성요소 없음 | 보여 줄 내용이 없습니다 | 이 공유 종류는 아직 미리보기를 지원하지 않습니다. 나중에 다시 시도해 주세요 |

불러오는 동안에는 뼈대 화면을 보여 주어 빈 화면이 깜빡이지 않습니다. 지워진 공유의 짧은 코드는 없어지고, 열어도 '공유가 없거나 불러오지 못했습니다'로 떨어집니다.

:::warning[유효 기간은 만든 이의 것]
공유 화면에서 기간을 늘리거나, 열쇠를 바꾸거나, 중지를 스스로 풀 수 없습니다. 필요하면 만든 이에게 부탁해 그 사람의 관리 화면 공유 목록에서 고치게 하세요.
:::

### 공유를 내 서재로 가져오기

공유 화면에는 **가져오기 단추가 없습니다**. 가져오기는 받는 쪽의 관리 화면에서 이루어지고, 공개 화면은 '보기만' 꼬리표로 가능 여부만 알립니다.

**가져올 수 있을 때: 바로 가져오기**

1. 받는 쪽 시스템에서 **시스템 관리 → 백업과 복원 → 공유 가져오기**를 엽니다.
2. 공유 링크나 짧은 코드를 넣고, 열쇠가 붙었으면 열쇠도 함께 넣습니다.
3. '공유 미리보기'를 눌러 제목, 종류, 항목 목록을 확인합니다.
4. 가져오기 방안을 고릅니다: 이미 있는 것 건너뛰기, 덮어쓰기 갱신, 합치기 갱신.
5. '공유 가져오기'를 누르면 성공과 실패 건수가 나옵니다. 실패 상세는 처음 50건까지 보입니다.

**가져올 수 없을 때: 먼저 신청하기**

1. 마찬가지로 '공유 가져오기'에 주소를 넣고 '공유 미리보기'를 누릅니다.
2. 그 공유가 '보기만'이어서 '공유 가져오기' 단추는 쓸 수 없고, '이 공유는 가져올 수 없습니다'라는 안내가 뜹니다.
3. '공유 신청'으로 창을 엽니다. 대상 공유는 읽기 전용이고 '신청 사유'는 필수, 최대 200자입니다.
4. '신청 보내기'를 누르면 공유의 주인이 **정보 관리 → 공유 → 받은 편지함**에서 이 신청을 받습니다.
5. 주인은 받은 편지함에서 '통과'나 '거절'을 누릅니다. 이 두 동작은 '심사 대기'인 신청에만 보입니다.
6. 결과는 주인 쪽의 사이트 안 알림(시스템 메시지)에 기록으로 남고 상태는 '통과됨' 또는 '거절됨'이 됩니다.

가져오기가 끝나면 받는 쪽은 같은 화면의 '링크 기록'에서 이 결과를 확인할 수 있습니다. 아직 처리되지 않은 신청도 여기서 취소할 수 있습니다.

:::note[신청과 가져오기는 별개입니다]
승인은 신청 상태를 바꾸고 알림을 보낼 뿐, 자료가 받는 쪽 시스템으로 저절로 옮겨지지는 않습니다. 실제 가져오기는 여전히 받는 이가 '공유 가져오기'에서 수행하고 방안도 받는 이가 고릅니다.
:::

## 상점

위 띠의 '상점'으로 들어갑니다. 물건 목록이나 분류를 둘러보고, 물건 상세에서 규격을 골라 장바구니에 넣고, 로그인한 뒤 주문을 확정하며, 그 후 '내 주문'에서 진행을 보거나 취소·반품을 신청할 수 있습니다.

### 입구와 화면 한눈에 보기

- 상점은 관리 화면에서 켠 뒤에야 위 띠에 '상점'이 나타납니다. 꺼져 있으면 메뉴에서 숨지만 주소를 직접 입력하면 열립니다. 상점이 아직 열리지 않았으면 물건 목록과 가게 정보 화면 모두 '상점이 아직 열리지 않았습니다. 잠시 후 다시 와 주세요'라고 안내합니다.
- 물건 목록, 분류 화면, 가게 정보는 이름 없이 볼 수 있습니다. 장바구니, 결제, 주문 목록과 주문 상세는 로그인이 필요하고, 안 하면 로그인 화면으로 보내집니다.

| 화면 | 주소 | 로그인 |
| --- | --- | --- |
| 물건 목록 | `/home/store` | 이름 없이 가능 |
| 물건 분류 | `/home/store/category/{handle}` | 이름 없이 가능 |
| 물건 상세 | `/home/store/product/{handle}` | 이름 없이 가능. 담기는 로그인 필요 |
| 장바구니 | `/home/store/cart` | 필요 |
| 결제 | `/home/store/checkout` | 필요 |
| 주문 결과 | `/home/store/order/{token}` | 필요 |
| 주문 목록 | `/home/store/orders` | 필요 |
| 주문 상세 | `/home/store/orders/{주문ID}` | 필요 |
| 가게 정보 | `/home/store/info` | 이름 없이 가능 |

### 물건 목록

화면 폭에 맞춘 격자로, 책상 위에서는 한 줄에 4장, 판형 기기 3장, 휴대폰 1장. 한 쪽에 12개입니다.

| 요소 | 설명 |
| --- | --- |
| 표지 | 1:1 네모. 실패하면 '그림 불러오기 실패' 자리 그림. 팔 수 없는 물건은 표지에 '지금은 판매할 수 없습니다' |
| 제목과 금액 | 제목은 한 줄로 줄이고 부제는 비면 숨김. 규격마다 금액이 다르면 범위로, 같으면 하나로. 정확한 금액과 화폐는 화면의 실시간 표시를 따름 |
| 쪽 넘김 | 자료가 있으면 쪽 넘김기와 총수. 비면 '물건이 아직 없습니다' |

카드를 누르면 물건 상세로 들어갑니다. 분류 화면 `/home/store/category/{handle}`은 같은 쪽면과 카드를 쓰고, 분류 이름, 설명, 아래 분류 꼬리표를 더 보여 줍니다. 설명이 비면 '이 분류의 판매 중인 물건 전부'라는 기본 문구를 씁니다.

#### 걸러보기와 쪽면

책상 위에서는 오른쪽에 상점 쪽면, 좁은 화면에서는 검색과 분류가 목록 위로 옮겨 갑니다.

| 구역 | 내용 |
| --- | --- |
| 안내와 화폐 | 물건 첫 페이지, 내 주문, 가게 정보, 장바구니 네 단추. 아래에 지금의 결제 화폐와 지역 이름이 있고, 누르면 가게 정보 화면으로 가서 바꿀 수 있음 |
| 검색 | 칸에 넣고 Enter나 검색 단추. 낱말은 주소창의 `q` 변수에 들어가 그 링크를 그대로 공유할 수 있음 |
| 분류 | 꼬리표 구름. '전체'와 각 단계의 분류. 누르면 걸러지고 첫 쪽으로 돌아감 |
| 시리즈 | 시리즈 자료가 있을 때 나타남. '전체 시리즈'와 각 시리즈 꼬리표 |
| 장바구니 | 로그아웃 중이면 '로그인하면 장바구니와 주문을 볼 수 있습니다.'와 로그인 단추. 로그인 중이면 처음 3줄의 물건, 수량, 합계와 '장바구니 보기' |
| 가게 | 가게 이름, 설명, 유형(공식 직영), 화폐, 상담 이메일, 정해진 상점 소개 문구 |

### 물건 상세

| 자리 | 내용 |
| --- | --- |
| 동작 줄과 큰 그림 | 상점으로 돌아가기, 장바구니, 내 주문, 가게 정보. 그림이 여러 장이면 돌림판(자동으로는 안 돎). 없으면 자리 그림 |
| 판매 상태 | 팔 수 있으면 '재고 있음', 없으면 '이 물건은 지금 판매할 수 없습니다' |
| 규격 고르기 | 선택지가 있는 물건은 선택지끼리 묶어 단추를 그림. 선택지는 없지만 규격이 여러 개면 규격 단추를 바로 늘어놓음. 팔 수 없는 규격은 흐리게 |
| 수량과 속성 | 수량 입력은 1–99. 속성 칸에 품번, 규격(규격 제목 전부), 재고 상태(팔 수 있으면 '판매 가능(재고는 결제 시 확정)') |
| 동작 단추 | '장바구니에 담기'와 '바로 구매'. 팔 수 없을 때는 둘 다 막힘 |
| 상세와 그림·글 | 이름, 부이름, 번호, 분류, 화폐, 판매 상태, 규격 표(규격, SKU, 금액, 판매 상태). 아래의 소개 글이 비면 '소개 글이 아직 없습니다', 그 뒤에 정해진 면책 문구 |

> **SKU**: 재고 단위입니다. 같은 물건도 규격마다 번호가 따로 있고, 결제할 때 이 번호에 맞춰 재고를 줄입니다.

로그아웃 중에 '장바구니에 담기'를 누르면 '로그인하면 장바구니와 주문을 볼 수 있습니다.'가 뜨고 로그인 화면으로 갔다가(로그인 뒤 그 물건으로 돌아옴), 로그인 중이면 '장바구니에 담았습니다'가 뜹니다. '바로 구매'는 담은 뒤 곧바로 결제 화면으로 갑니다. 물건이 없거나 판매가 끝났으면 화면 전체에 '물건이 없거나 판매가 끝났습니다'와 '상점으로 돌아가기'를 보입니다.

### 장바구니

장바구니는 지금의 계정과 결제 지역에 묶여 있어, 계정이나 지역을 바꾸면 다른 바구니가 됩니다.

| 요소 | 설명 |
| --- | --- |
| 물건 줄 | 표지, 제목, 규격 이름, 단가, 수량(1–99, 바로 반영), 줄 합계 |
| 빼기 | 줄마다 '빼기' 단추. 성공하면 '물건을 뺐습니다'. 빈 바구니는 '장바구니가 비어 있습니다'와 '계속 고르기' |
| 주문 요약 | 결제 화폐, 소계, 배송비, 세금, 할인(음수), 합계. 아래에 결제 화면으로 들어가는 '결제하기' |
| 할인 코드 | '할인 코드 입력'에 넣고 '사용'. 성공하면 '할인 코드를 적용했습니다' |
| 바구니 버리기 | '지금 장바구니를 버릴까요?' 두 번 확인. 비우면 '지금 바구니를 버렸습니다' |

줄마다 고르는 표시는 없고, 바구니 안의 물건은 전부 함께 결제됩니다.

### 결제

결제 화면은 왼쪽이 서식, 오른쪽이 주문 요약입니다. 바구니가 비면 빈 바구니 안내와 '계속 고르기'만 보입니다.

| 구역 | 항목과 행동 |
| --- | --- |
| 자주 쓰는 주소 | 로그인 뒤에만 표시. 저장한 주소의 고르기 목록(바구니 지역과 어울리는 것만). 고르면 자동으로 채워짐. 들어올 때는 기본 주소가 선택되어 있음 |
| 연락처와 주소 | 이메일(필수, `@` 포함), 전화, 이름, 성. 상세 주소, 도시, 나라/지역(셋 다 필수). 우편 번호와 주/도는 선택. 나라 선택은 바구니 지역 안으로 한정됨 |
| 배송 방법 | '배송 방법 가져오기'를 누르면 먼저 연락처와 주소를 저장한 뒤 쓸 수 있는 배송 방법과 금액을 읽음. 쓸 것이 없으면 안내 문구가 나옴 |
| 지불 방법 | 가게가 돌려주는 지불 방법에서 하나 고르기. 건너뛰어야 하는 경로에는 '건너뛰기 지불 필요'가 덧붙음. 쓸 것이 없으면 '현재 지역은 쓸 수 있는 지불 방법이 없습니다' |
| 주문 요약 | 물건 줄, 결제 화폐, 소계, 배송비, 세금, 할인, 합계, '주문 제출'과 '장바구니 버리기' |

제출할 때 차례로 확인합니다. 이메일이 비었거나 `@`가 없으면 '올바른 이메일을 입력해 주세요'. 상세 주소, 도시, 나라 중 하나라도 비면 '완전한 배송 주소를 입력해 주세요'. 지불 방식을 안 골랐으면 '지불 방법을 선택해 주세요'. 배송이 필요한 물건이 있는데 배송 방법을 못 가져오면 '현재 지역은 쓸 수 있는 배송 방법이 없습니다'.

건너뛰기 지불은 이 사이트를 떠나 지불 화면으로 갔다가 끝나면 `payReturn=1`과 함께 돌아옵니다. 읽기(QR)형 지불은 '읽어서 지불' 창이 뜨고, '지불을 마쳤습니다'를 누른 뒤 주문 확인으로 넘어갑니다. 확인이 끝나면 주문 결과 화면으로 옮기고, 주문 ID가 돌아오면 바로 주문 상세로 들어갑니다.

주문 제출에는 겹침을 막는 표가 붙어 있어 같은 주문으로 '주문 제출'을 여러 번 눌러도 두 건이 되지 않습니다. '주문을 확인하는 중입니다. 다시 제출하지 마세요'가 뜨면 되풀이하지 말고, 잠시 뒤 주문 목록에서 결과를 확인하세요.

### 주문 결과

`/home/store/order/{token}`은 주문 뒤의 영수증 화면입니다. 주소에는 무작위 token을 쓰고 짐작할 수 있는 주문 ID가 아닙니다. 화면이 열려 있는 동안 임시로 `no-referrer`가 설정되어 token이 참조 주소로 새는 것을 막습니다.

| 자리 | 내용 |
| --- | --- |
| 결과 칸 | '주문 성공', 주문 번호, '계속 고르기', '내 주문', '주문 상세' 세 단추 |
| 주문 정보와 내역 | 주문 시각, 주문 상태, 지불 상태, 이행 상태, 연락 이메일(가림 처리), 주문 금액. 내역은 표지, 제목, 규격, 수량, 줄 금액 |

주문이 없거나 token이 끊겼으면 '주문이 없거나 링크가 만료되었습니다'를 보입니다.

### 주문 목록

한 쪽에 10건. 위에 '새로 고침'과 '계속 고르기'가 있습니다.

| 요소 | 설명 |
| --- | --- |
| 주문 머리 | 주문 번호, 주문 시각, 주문 상태 꼬리표, 지불 상태 꼬리표 |
| 물건 줄 | 표지, 제목, 규격, 수량, 줄 금액. 아래는 주문 합계. 주문이 없으면 '주문이 아직 없습니다' |
| 동작 | 지불할 수 있으면 '지불하기', 아니면 '상세 보기'. 취소할 수 있으면 '주문 취소', 반품할 수 있으면 '반품·환불' |
| 취소 | 두 번 확인 필요. 제출하면 '취소 신청을 보냈습니다. 판매자의 처리를 기다려 주세요'가 뜨고 상태는 '취소 신청 중'이 됨 |

### 주문 상세

| 자리 | 내용 |
| --- | --- |
| 안내 띠와 상태 | 주문에 설명이 있으면 안내 띠로 보이고, 취소 신청이 있으면 덧붙여 안내. 이어 주문 상태, 지불 상태, 이행 상태 세 꼬리표와 주문 시각 |
| 정보 표 | 주문 번호, 연락 이메일, 주문 시각, 주문 금액, 지불 상태, 이행 상태 |
| 배송 정보 | 이행 기록이 있으면 이행 상태, 운송자, 보냄/도착 시각과 운송장 번호. 번호가 없으면 '판매자가 아직 운송장 번호를 적지 않았습니다'. 주문 안의 물건이 모두 배송 불필요면 가상 상품으로 따로 표기 |

| 동작 칸 | 주문이 취소를 허락하면 취소 카드. 반품을 허락하면 반품 서식으로, 반품 가능 수량, 사유, 줄별 메모와 설명을 쓸 수 있고 제출하면 '반품·환불 신청을 보냈습니다' |

동작 구역은 주문의 지금 상태가 허락할 때만 그려지므로, 주문마다 보이는 구역이 다릅니다.

## 개인 홈페이지

사이트에는 '사람'에 관한 화면이 두 종류 있습니다. 누구나 열 수 있는 **공개 홈페이지**와, 로그인 뒤 자신을 가꾸는 **개인 센터**입니다. 앞은 자료에서 공개로 고른 항목만 보여 주고, 뒤가 그 항목과 얼굴, 배너, 페이지 전체 테마를 정합니다.

### 로그인과 입구

#### 위 띠

로그아웃 중에는 위 띠 오른쪽에 '로그인' 단추만 있고, 누르면 로그인 화면으로 갑니다. 로그인 뒤에는 얼굴 그림의 고르기 메뉴로 바뀝니다.

| 항목 | 행동 |
| --- | --- |
| 개인 센터 | `/admin/user/info`를 엽니다 |
| 관리 화면 | 관리 작업대를 엽니다 |
| 스포일러 보기 / 숨기기 | 목록과 상세에서 스포일러 내용을 고쳐 보여 줌 |
| 로그아웃 | 로그인 상태를 지우고 로그인 화면으로 돌아감 |

위 띠에는 그 밖에 언어 바꾸기, 밝고 어두운 바꾸기, 전체 화면 단추와 빠른 검색이 있으며, 이것들은 로그인 상태를 가리지 않습니다.

#### 로그인 화면

| 요소 | 설명 |
| --- | --- |
| 계정 / 암호 | 칸의 안내 문구는 '관리자 계정', '관리자 암호'. 관리자에서 RSA 공개 키를 설정했으면 보내기 전에 암호화하고, 키가 없거나 형식이 잘못되면 그대로(평문으로) 보냅니다. |
| 개인정보 약관과 암호 찾기 | 개인정보 약관에 동의해야 들어갈 수 있고, 안 하면 '먼저 개인정보 약관을 읽고 동의해 주세요'. 암호 찾기는 복구 열쇠로 되돌리는 창을 엽니다 |
| 다른 들어가기 | 뒷단이 해당 기능을 켰을 때만 'Passkey로 로그인'과 '통합 로그인'이 나타남. 통합 로그인은 창에서 앱을 고르고 새 창에서 제3자 인증을 마침 |
| 두 단계 확인 | 켠 계정은 암호가 통과한 뒤 확인 번호 단계로 넘어가, 6자리 번호나 복구 코드로 마칩니다 |

> **RSA 공개 열쇠로 감추기**: 암호는 보내기 전에 한 번 걸려서 나가므로, 도중에 주운 것으로는 암호를 바로 되찾을 수 없습니다.

:::warning[스스로 등록할 수 없습니다]
로그인 화면 아래의 '계정 등록' 단추는 지금 **쓸 수 없는 상태**이고, 앞면에는 등록 입구가 열려 있지 않습니다. 계정은 설치 때의 초기화(기본 관리자 `ammds`)로 만들어지며 여기서 새로 등록할 수 없습니다.
:::

로그인에 성공하면 주소창의 `redirect` 변수를 따라 원래 화면으로 돌아갑니다. 없으면 시스템 설정 → 주제와 모양 → 착지 페이지의 '우선하여 열 곳'을 따라 앞면이나 관리면으로 들어갑니다.

### 공개 홈페이지

#### 두 가지 주소

`/user/{사용자ID}`가 표준형이고 `/u/{사용자ID}`가 짧은 별명입니다. 둘 다 같은 화면을 그립니다.

둘 다 로그인이 필요 없고 공용 틀(사이트 위 띠 없음)을 씁니다. 화면 아래는 '첫 화면 | © AMMDS 提供技术支持'로 정해져 있습니다. '첫 화면'은 사이트 앞면의 첫 페이지로 돌아갑니다. 개인 센터의 '공개 홈페이지' 단추가 여는 것이 바로 `/u/{사용자ID}`입니다. 사용자 ID를 바꾸면 옛 주소는 곧 쓸 수 없게 됩니다.

#### 화면 내용

| 요소 | 설명 |
| --- | --- |
| 얼굴과 별명 | 얼굴을 안 정했으면 기본 사용자 아이콘, 별명이 없으면 'AMMDS 用户' |
| 표지 | `@사용자ID` 꼴 |
| 꼬리표 | 계정 상태가 있으면 초록 꼬리표. 정해진 'AMMDS 인증 사용자' 꼬리표도 함께 |
| 배너와 배경 | 머리의 배너를 안 정했으면 테마의 무지개 배경, 페이지 바닥을 안 정했으면 시스템 배경 |
| 기본 정보 | 공개로 고른 항목만 그림. 빈 항목은 나타나지 않음 |
| 없을 때의 문구 | 공개 항목이 모두 비면 '이 사용자는 공개 정보가 아직 없습니다' |

불러오는 동안에는 읽는 중 표시를 보입니다. 사용자가 없거나 홈페이지가 닫혀 있으면 '사용자가 없거나 열 수 없습니다'와 '다시 불러오기'를 보입니다.

:::note[무엇이 보이는지는 본인이 정합니다]
이메일, 전화, 등록 시각, 마지막 로그인 시각, 계정 상태는 모두 고를 수 있는 공개 항목입니다. 전화는 공개해도 가린 번호만 보입니다. 모든 표시를 끄면 공개 홈페이지에는 얼굴, 별명, 테마 모양만 남습니다.
:::

#### 테마

공개 홈페이지에는 12 가지 테마가 있고, 각각 페이지 짜임과 배열이 독립적입니다. 단순한 색 바꾸기가 아닙니다.

| 테마 | 설명 |
| --- | --- |
| 经典卡片(고전 카드) | 가운데 배너 카드 + 두 줄 정보 격자. 기본 테마 |
| 极简线框(간결한 틀) | 흑백 스위스 배열, 왼쪽 큰 얼굴 + 정보 표 |
| 清雅海洋(맑은 바다) | 전체 폭 물결 머리 + 떠 있는 수 칸 + 가로 정보줄 |
| 日落暖橙(해질 녘 주황) | 왼쪽 좁고 오른쪽 넓은 나눔. 필름 알갱이와 따뜻한 무지개 테두리 |
| 暗夜霓虹(깊은 밤 네온) | 어두운 바탕에 네온 선, 붙는 쪽면 + 빛나는 정보 카드 |
| 纸质书卷(종이 책) | 잡지 판형 배열. 첫 글자 가라앉힘 + 두 단 본문 + 아래 판권란 |
| 玻璃拟态(유리 모양) | 떠 있는 유리 카드, 위아래 엇갈림 + 부드러운 빛 |
| 艺术画框(예술 액자) | 캔버스형 비대칭 짜임, 기울어진 액자 + 번호 패 |
| 时尚杂志(유행 잡지) | 큰 그림 표지, 가득 찬 인물 + 아래 겹친 제목 |
| 赛博终端(사이버 단말) | 단말 창의 상호작용, 타자기 줄 번호 + 훑는 선 감시 판 |
| 樱花物语(벚꽃 이야기) | 분홍 벚꽃 무지개 고리 얼굴, 흩날리는 꽃잎 + 부드러운 카드 |
| 新粗野(새 거칠음) | 짙은 색면의 굳은 그림자, 스티커식 꼬리표 + 굳은 모서리 카드 |

테마는 계정에 저장되고, 방문객이 열 때는 계정 설정대로 그려집니다. 값이 올바르지 않으면 '经典卡片'로 되돌아갑니다. 배경 그림과 배너는 모든 테마에 적용되며, 자르는 방식은 테마마다 스스로 정합니다.

### 개인 센터

위 띠의 얼굴에서 '개인 센터'를 골라 들어갑니다. 위에서부터 머리 모습 칸, 페이지 설정, 사용자 정보, 허가증 네 구역입니다.

#### 머리 모습 칸

| 요소 | 동작 |
| --- | --- |
| 얼굴 | 얼굴을 눌러 그림을 고릅니다. 올리면 바로 바뀝니다 |
| 배너 | 오른쪽 위 올리기 단추로 그림을 고릅니다. 이미 있으면 지울 수 있어 기본 배경으로 돌아갑니다 |
| 별명 | 지금의 별명을 보여 줍니다 |
| 역할과 허가증 꼬리표 | 역할은 관리자 또는 사용자. 허가증 꼬리표는 허가증 상태와 같음(유효 / 무효). 회원 표시가 있으면 VIP 꼬리표가 따로 붙습니다 |
| 암호 바꾸기 | 창을 열어 지금의 암호와 새 암호를 넣습니다 |

#### 페이지 설정

이 구역은 다른 사람이 보는 공개 홈페이지의 모습을 정합니다.

| 자리 | 설명 |
| --- | --- |
| 페이지 배경 그림 | 올리거나 지웁니다. 안 정했으면 '배경 그림 미설정' 자리 그림 |
| 페이지 배너 | 올리거나 지웁니다. 안 정했으면 '배너 미설정' 자리 그림 |
| 공개 화면 테마 | 12 가지 테마 카드. 줄어든 그림과 한 줄 설명이 붙고, 누르면 바뀌고 저장됩니다 |

배경 그림과 배너는 서로 독립된 두 항목이고, 머리 모습 칸의 배너에는 영향을 주지 않습니다.

#### 사용자 정보

정보 카드는 사용자 ID, 별명, 이메일, 전화, 역할, 상태, 등록 시각, 마지막 로그인 시각을 보여 주고, 오른쪽 위에 입구가 둘 있습니다.

- **정보 고치기**: 고치기 창을 엽니다.
- **공개 홈페이지**: 새 탭에서 `/u/{사용자ID}`를 엽니다. 사용자 ID가 없으면 쓸 수 없고, 카드는 '미설정(고친 뒤 공개 홈페이지가 만들어집니다)'이라고 알립니다.

#### 정보 고치기 항목 설명

| 항목 | 규칙 | 안 채우거나 틀리면 |
| --- | --- | --- |
| 사용자 ID | 필수. 공개 홈페이지 주소 안의 한 토막입니다 | 바꾸면 옛 링크는 끊어짐 |
| 별명 | 필수, 최대 32 글자 | 넘치면 저장 안 됨 |
| 이메일 | 필수, 이메일 형식에 맞아야 함 | 형식이 틀리면 저장 안 됨 |
| 전화 | 선택. 공개 홈페이지는 가린 번호만 보임 | 안 채워도 지장 없음 |
| 공개 홈페이지에 내보낼 항목 | 여러 개 고르기: 사용자 ID, 별명, 얼굴, 이메일, 전화(가림), 등록 시각, 마지막 로그인 시각, 상태 | 모두 끄면 공개 홈페이지에 아무 자료도 안 나옴 |

내보낼 항목에는 기본 규칙이 하나 있습니다. **한 번도 설정한 적이 없으면** 전화를 뺀 나머지 항목이 모두 보입니다.

### 즐겨찾기와 읽기 위치

| 기능 | 입구 | 설명 |
| --- | --- | --- |
| 즐겨찾기와 즐겨찾기 서재 | 각 미디어 상세의 즐겨찾기 단추. 목록 쪽면의 '모드' 고르기 | 소설 상세는 '즐겨찾기 / 즐겨찾기됨'을 보이고, 로그아웃 중이면 '작업 실패, 로그인했는지 확인해 주세요'. 즐겨찾기 모드로 고르면 목록은 즐겨찾기 항목만 돌려줌 |
| 소설 읽기 진행 | 소설 상세의 '이어 읽기'와 진행 안내 | 로그인 중이면 진행이 서버에, 방문객은 브라우저 저장에 남음. 이 절의 둘러보기 페이지 참고 |

지금 앞면에는 시청 기록, 재생 기록, 개인 즐겨찾기 목록 화면이 따로 없습니다. 즐겨찾기는 상세의 단추로 가꾸고 각 미디어 목록의 '즐겨찾기' 모드로 봅니다. 읽기 위치의 이어 읽기는 소설에만 입구가 있습니다.
:::

## 문제가 생겼을 때

**공유 관련**

- **링크가 안 열리고 '공유가 없거나 불러오지 못했습니다'**: 짧은 코드를 잘못 적었거나 공유가 지워졌을 수 있습니다. 만료·중지 판인지도 확인하세요. 판에 이유가 쓰여 있습니다.
- **열쇠가 계속 안 통함**: 칸 아래에 '열쇠가 틀렸습니다. 다시 시도해 주세요'가 뜹니다. 만든 이가 준 것이 바로 이 열쇠인지 확인하세요.
- **새로 고침하면 열쇠를 또 물음**: 확인은 이 화면에서만 유효합니다. 원래 그렇습니다.
- **기간을 늘리고 싶거나 중지를 풀고 싶음**: 공유 화면에서는 안 됩니다. 만든 이에게 부탁해 관리 화면에서 고치게 하세요.

**상점 관련**

- **위 띠에 '상점'이 없음**: 관리 화면에서 상점을 아직 안 켰습니다. 켰어도 안 열렸으면 '상점이 아직 열리지 않았습니다. 잠시 후 다시 와 주세요'가 뜹니다.
- **장바구니에 담으려는데 로그인 화면으로 감**: 장바구니, 결제, 주문은 모두 로그인이 필요합니다. 뒤에 같은 물건으로 돌아옵니다.
- **'주문을 확인하는 중입니다. 다시 제출하지 마세요'가 뜸**: 계속 누르지 마세요. 잠시 뒤 '내 주문'에서 결과를 확인하세요. 겹침 방지 장치가 있어 두 건이 되지는 않습니다.
- **금액이 전과 다름**: 금액, 배송비, 세금은 지금 결제 지역의 화폐로 그때마다 불러옵니다. 가게 정보 화면에서 지역이 바뀌지 않았는지 확인하세요.

**계정과 홈페이지 관련**

- **'계정 등록'이 눌리지 않음**: 앞면에는 등록 입구가 없습니다. 계정은 설치 때의 초기화(기본 관리자 `ammds`)로 만들어집니다.
- **옛 공개 홈페이지 링크가 끊어짐**: 사용자 ID가 바뀐 것입니다. 새 주소(개인 센터의 '공개 홈페이지' 단추)를 쓰세요.
- **암호를 잊음**: 로그인 화면의 '암호 찾기'로 창을 열고 복구 열쇠로 되돌리세요.
- **내 홈페이지가 '아무것도 없다'고 함**: 공개 항목을 모두 껐을 수 있습니다(얼굴, 별명, 테마 모양만 남음). '정보 고치기'에서 다시 켜세요.
