# 초기 설정 마법사: 첫 구성

프로그램을 설치한 뒤 처음 열었을 때 시스템에 관리자 계정이 아직 없다면 초기 설정 마법사가 자동으로 실행됩니다(주소는 `/setup`). 네 단계를 모두 마치면 방금 만든 계정으로 로그인할 수 있습니다.

:::note[마법사는 언제 나타나나요]
초기 설정이 끝나지 않았을 때만 나타납니다. 이미 초기 설정을 마친 뒤 `/setup`에 접속하면 자동으로 홈으로 돌아갑니다. 다시 진행하려면 빈 데이터베이스로 바꾸는 수밖에 없습니다.
:::

## 시작하기 전에

- 프로필과 아바타 동기화에 사용할 이메일을 준비하세요(이메일이 실제로 존재하는지는 확인하지 않습니다)
- 관리자 사용자 이름과 비밀번호를 미리 정하세요(규칙은 아래 참고)
- 전체 과정은 2~3분이며, 중간에 '이전 단계'를 눌러 돌아가 수정할 수 있습니다

## 1단계: 약관 동의

페이지에 '요약', '사용자 약관', '개인정보 처리방침' 세 개의 탭이 있습니다. 요약은 프로그램이 무엇을 하는지, 첫 실행 때 어떤 파일을 만드는지, 데이터가 어디에 저장되는지 쉬운 말로 설명합니다. 전체 조항은 페이지의 링크로 열 수 있습니다.

다 읽은 뒤 '위 내용을 읽고 동의합니다'를 체크해야 '다음 단계'를 누를 수 있습니다.

:::warning[반드시 체크해야 합니다]
체크하지 않고 다음 단계를 누르면 약관에 동의해야 한다고 안내하며 진행되지 않습니다.
:::

## 2단계: 관리자 생성

| 항목 | 작성 방법 | 규칙 |
| --- | --- | --- |
| 사용자 이름 | 이후 로그인에 사용할 이름 | 3~32자. 영문자, 숫자, 밑줄, 하이픈만 사용 가능 |
| 이메일 | 연락용 이메일 | 필수이며 형식이 올바라야 합니다. 이후 아바타 동기화에 이 이메일을 사용합니다 |
| 비밀번호 | 로그인 비밀번호 | 6~22자. 대문자와 소문자를 모두 포함하고 숫자나 특수문자를 하나 이상 포함해야 합니다 |
| 비밀번호 확인 | 한 번 더 입력 | 위 항목과 완전히 같아야 합니다 |

> 실행 시 환경 변수 `ADMIN_USER` / `ADMIN_PASS`로 이미 관리자가 만들어졌다면, 이 단계는 '완료'로 표시되며 이메일만 입력하면 됩니다. 나머지 세 항목은 다시 입력할 필요가 없습니다.

## 3단계: 사이트 정보

| 항목 | 작성 방법 | 입력하지 않으면 |
| --- | --- | --- |
| 사이트 이름 | 브라우저 제목과 푸터에 표시되는 이름 | 필수 |
| 첫 화면 | '관리자 우선' 또는 '프런트 우선' | 기본값은 관리자 우선. 프런트를 선택하면 이후 루트 주소를 열었을 때 프런트 홈으로 먼저 들어갑니다 |
| 등록 번호 | 필요하면 입력하며 선택 사항 | 비워 두면 푸터에 등록 정보가 표시되지 않습니다 |

## 4단계: 개인 프로필 보완

이 단계에서 프런트에 표시되는 자신의 신원을 정합니다.

| 항목 | 설명 |
| --- | --- |
| 아바타 | 이메일을 기준으로 Gravatar(이메일로 아바타를 찾는 공개 서비스)에서 자동으로 가져오며, 찾지 못하면 이니셜이 들어간 이미지를 만듭니다. 직접 업로드할 수도 있고 PNG / JPEG / GIF / WebP / BMP를 지원하며 2MB를 넘을 수 없습니다 |
| 사용자 ID | 4~32자의 영문자, 숫자, 밑줄, 하이픈. `admin`, `root`, `ammds` 같은 예약어(시스템이 이미 사용하는 이름)는 쓸 수 없고 숫자로만 이루어질 수도 없습니다 |
| 닉네임 | 프런트에 표시되는 이름이며 최대 32자 |
| 휴대전화 번호 | 선택 |
| 소셜 링크 | 선택, 최대 20개. 주소는 반드시 `https://`로 시작해야 합니다 |

'프로필 동기화'를 누르면 이메일로 아바타와 닉네임을 다시 가져올 수 있습니다. 이미 직접 수정한 내용은 덮어쓰지 않습니다.

## 제출한 뒤

'초기 설정 완료'를 누르면 성공 후 자동으로 로그인 페이지로 이동하므로, 2단계에서 만든 계정으로 로그인하면 됩니다.

:::tip[계정 정보는 잘 기억하세요]
마법사에서 입력한 사용자 이름은 이후 화면에서 수정할 수 없습니다. 비밀번호는 사용자 센터에서 언제든 바꿀 수 있습니다. 복구 키는 별개의 것으로, 프로그램이 첫 실행 때 자동으로 만들며 여기서 입력한 비밀번호와는 무관합니다.
:::

## 자주 묻는 질문

| 현상 | 원인과 처리 |
| --- | --- |
| 어떤 주소를 열어도 `/setup`으로 이동함 | 아직 초기 설정이 끝나지 않았다는 뜻입니다. 마법사를 끝까지 진행하세요 |
| `/setup`에 접속했다가 홈으로 돌아감 | 이미 초기 설정을 마쳤으므로 바로 로그인하세요 |
| 사용자 ID가 이미 사용 중이라고 나옴 | 다른 것으로 바꾸세요. 예약어와 순수 숫자도 거부됩니다 |
| 소셜 링크가 제출되지 않음 | 주소가 `https://`로 시작하는지 확인하세요 |
| 아바타 업로드가 실패함 | 이미지가 2MB 이하이고 지원되는 형식인지 확인하세요 |
| 제출 후 로그인되지 않음 | 2단계에서 입력한 사용자 이름과 비밀번호를 사용하고 있는지 확인하세요. 비밀번호를 잊었다면 복구 키로 재설정할 수 있습니다 |
