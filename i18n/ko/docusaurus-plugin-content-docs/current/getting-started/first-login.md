# 처음 열기: 로그인과 기본 설정

설치가 끝나면 기본 관리자 계정으로 관리 화면에 들어가 순서대로 필요한 것을 합니다. 기본 비밀번호를 바꾸고, 복구 키를 안전한 곳에 두고, 필요하면 도메인을 묶고 사이트 정보를 채우는 것입니다. 모두 십 분 남짓입니다.

이 순서를 지켜 끝낸 뒤에 스캔과 정보 가져오기를 시작하면 나중에 살펴볼 일이 크게 줄어듭니다.

## 기본 계정

| 항목 | 기본값 |
| --- | --- |
| 사용자 이름 | `ammds` |
| 비밀번호 | `ammds` |

:::warning[사용자 이름은 바꿀 수 없습니다]
관리자 이름은 `ammds`로 고정되어 있습니다. 실행할 때 이것과 다른 값이 보이면 프로그램은 바로 끝나 버립니다. 비밀번호는 **데이터베이스를 처음 만들 때만** 정할 수 있고, 그 뒤에는 내 정보에서 바꿔 주세요.
:::

## 로그인

1. 브라우저에서 `http://기기주소:포트`를 엽니다. 포트는 설치 방법에 따라 다릅니다. Docker는 이어 준 포트, NAS는 설치 때 정한 포트, 직접 실행은 기본 `8080`입니다.
2. 설정 마법사에서 만든 계정로 들어갑니다.
3. 기본으로는 관리 화면의 워크벤치가 열립니다. 이전에 '처음으로 열 페이지'를 공개 사이트로 바꿔 두었다면 공개 첫 화면이 열리니, 메뉴에서 관리 쪽으로 돌아오세요.

:::note[먼저 오래 쓸 주소로 한 번 로그인하기]
로그인에 성공하면 그때 열고 있던 주소가 '서비스 주소'로 자동 기록되어 문서나 찾기 같은 데 쓰입니다. 그러니 도메인을 묶기 전에, **앞으로 계속 쓸 주소로 한 번 로그인**해 주세요.
:::

## 하나, 기본 비밀번호 바꾸기

1. 오른쪽 위 아바타를 누르고 **사용자 센터**를 고릅니다.
2. 내 정보 화면 위쪽에서 **비밀번호 변경**을 누릅니다.
3. **현재 비밀번호**, **새 비밀번호**, **다시 확인**을 차례로 적습니다.
4. **변경 신청**을 누릅니다. 성공하면 자동으로 로그아웃되니 새 비밀번호로 다시 들어가세요.

새 비밀번호는 다음을 지켜야 합니다.

| 규칙 | 설명 |
| --- | --- |
| 길이 | 6~22자 |
| 구성 | 대문자와 소문자를 모두 담고, 숫자나 특수문자를 하나 더 담기 |

## 둘, 복구 키 보관하기

복구 키는 처음 실행 때 만들어져 프로그램 폴더의 `data/secret/recovery.key`에 저장됩니다. 관리자 비밀번호를 잊으면 로그인 화면의 **비밀번호 찾기**에서 복구 키를 넣어 다시 정할 수 있습니다.

> **복구 키**: 비밀번호를 잊었을 때 다시 정할 수 있게 파일로 보관되는 열쇠입니다. 데이터베이스에 의존하지 않습니다.

:::tip[지금 백업하세요]
`db/`만 남기고 `data/secret/`을 잃으면 비밀번호를 되찾을 길이 없습니다. 이 파일은 데이터베이스와 함께 안전한 곳에 남겨 주세요.
:::

## 셋, 도메인 묶기(선택)

도메인으로 열고 싶다면 먼저 도메인 관리처에서 도메인을 이 기기로 향하게 한 뒤, **시스템 설정 → 기본 설정 → 도메인 묶기**로 갑니다.

1. **변경**을 누르고 도메인을 적습니다.
2. 저장하면 표시가 '묶이지 않음'에서 '묶임'으로 바뀝니다.
3. **시스템 점검**을 열어 '도메인 묶기' 항목이 통과하는지 확인합니다. 이 항목은 도메인이 정말 이 기기를 가리키는지 직접 확인합니다. 실패하면 대개 주소 풀이가 아직 먹지 않았거나, 포트가 열리지 않았거나, 가운데 중계가 제대로 넘기지 않는 경우입니다.

내부망에서만 쓴다면 이 단계를 건너뛰고 주소로 계속 써도 됩니다. 도메인을 묶는 것이 다른 기능의 조건은 아닙니다.

## 넷, 사이트 정보 채우기

**시스템 설정 → 사이트 설정 → 기본 설정**에서 사이트 이름, 부제, 설명, 회사 이름을 적습니다. 이 내용은 공개 화면의 제목, 공유 요약, 아래쪽 글에 나옵니다. 신고 정보가 필요하면 같은 화면에 신고 번호와 확인 링크도 적을 수 있습니다.

'시스템 설정'의 다른 탭에는 겉모습, 알림, 안전 설정이 있습니다. 모르는 항목은 기본대로 두고 언제든 돌아와 바꿀 수 있습니다.

## 다섯, 네트워크 설정(필요할 때)

서버에서 해외 사이트가 불안정하면 **시스템 설정 → 네트워크 설정**으로 갑니다.

1. **프록시 모드 켜기**를 넣습니다.
2. 방식(HTTP / SOCKS4 / SOCKS5)을 고르고 주소, 포트, 인증 정보를 적습니다.
3. 필요하면 '예외' 목록을 다듬어 내부 주소를 프록시에서 뺍니다.
4. 저장한 뒤 연결을 다시 확인합니다.

## 여섯, 외부 서비스와 작품 폴더

기본 설정을 마치면 필요한 대로 외부 서비스와 폴더를 더합니다.

| 순서 | 할 일 |
| --- | --- |
| 1 | 정보 출처, 다운로더, 미디어 서버 등을 설정합니다 |
| 2 | 작품 폴더를 추가하고 스캔 작업을 만듭니다 |
| 3 | 스캔 결과에 정보 가져오기를 실행합니다 |
| 4 | 작품 라이브러리를 훑어보고 정리합니다 |

하는 방법은 [10분에 첫 작품 정리하기](./first-library.md)에 모아 두었습니다.

## 일곱, 시스템 점검 한 번 돌리기

오른쪽 위 아바타를 누르고 **시스템 점검**을 골라 한 번 실행합니다. 데이터베이스, 디스크, 포트, 기기 시각, 부속 프로그램(FFmpeg 등), 프록시, 플러그인 설정을 살피고 문제를 분야별로 보여 줍니다.

:::tip[시스템 점검을 확인표로 쓰세요]
처음 설치에서 나온 노란색이나 빨간색 항목은 대개 해당 설정 화면에서 고칠 수 있습니다. 모두 통과한 뒤에 한꺼번에 스캔과 정보 가져오기를 시작하세요.
:::

## 설정 항목

| 설정 항목 | 무엇을 적나요 | 적지 않거나 틀리면 |
| --- | --- | --- |
| 사용자 이름 | `ammds`로 고정되어 적을 것이 없습니다 | 다른 값은 실행 실패로 이어집니다 |
| 현재 비밀번호 / 새 비밀번호 / 다시 확인 | 이전 비밀번호와 규칙에 맞는 새 비밀번호(6~22자, 대문자와 소문자를 담고 숫자나 특수문자 포함) | 둘이 다르거나 규칙에 어긋나면 신청이 안 됩니다. 이전 것을 잊었다면 복구 키로 다시 정합니다 |
| 도메인 묶기 | 이 기기로 향하게 해 둔 도메인 | 없으면 주소로만 열립니다. 풀이가 아직 먹지 않으면 시스템 점검의 이 항목이 통과하지 않습니다 |
| 사이트 이름 / 부제 / 설명 / 회사 이름 | 공개 화면 제목, 공유 요약, 아래쪽 글에 나올 문구 | 적지 않으면 기본 문구가 쓰이며 기능에는 영향이 없습니다 |
| 처음으로 열 페이지 | 로그인 뒤 관리 쪽인지 공개 쪽인지 | 공개 쪽을 고르면 로그인 뒤 메뉴에서 돌아와야 합니다 |
| 프록시 모드 켜기 | 스위치와 HTTP / SOCKS4 / SOCKS5 고르기 | 필요 없다면 켜지 않습니다. 주소가 틀리면 대부분의 사이트에 닿지 못합니다 |
| 프록시 주소 / 포트 / 인증 | 프록시의 주소와 포트, 필요하면 아이디와 비밀번호 | 틀리면 연결되지 않습니다. SOCKS는 아이디와 비밀번호를 받지 않습니다 |
| 예외 목록 | 프록시를 타지 않을 주소(내부 대역 등) | 없으면 내부 기기(NAS, 플레이어)도 프록시를 타 붙지 못합니다 |

이런 변경은 **대개 다시 실행이 필요 없습니다**. 저장하면 바로 먹습니다.

## 문제가 생기면

- **들어갈 수 없음**: 사용자 이름이 `ammds`인지 확인합니다. 여러 번 틀렸거나 잊었다면 로그인 화면에서 복구 키로 다시 정합니다.
- **비밀번호 변경이 자꾸 거절됨**: 위 규칙을 다시 보세요. 길이, 대문자와 소문자, 숫자나 특수문자 세 가지입니다.
- **복구 키를 못 찾겠음**: 프로그램 폴더의 `data/secret/`에서 `recovery.key`를 찾습니다. 복사본도 없이 잃었다면 다시 설치하고 정리부터 해야 합니다.
- **도메인을 묶었는데 안 통해요**: 풀이가 먹었는지, 포트가 열렸는지, 가운데 중계가 올바른지 확인합니다. '도메인 묶기' 항목이 결과를 알려 줍니다.
- **로그인 뒤 화면이 깨짐**: 강제로 다시 불러오세요(`Ctrl` + `F5`). 버전을 올린 뒤에 특히 잘 생깁니다.
