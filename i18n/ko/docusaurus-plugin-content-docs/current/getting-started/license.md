# 라이선스

이 페이지에는 **바로 사용할 수 있는 라이선스 키**를 모아 두었습니다. 아무 키나 복사해 사용자 센터에서 활성화하면 **워터마크가 즉시 사라지고 모든 기능이 그대로 동작합니다**. 키는 관리자가 수시로 갱신합니다. "활성화 자리가 꽉 찼다"거나 사용할 수 없다고 나오면 다음 키로 다시 시도하세요.

> **라이선스**: 이 설치가 정당하게 인가되었다는 기록입니다. 유효한 인가가 없으면 전체 화면에 워터마크가 표시되지만, 로그인, 시스템 설정, 사이트 인증, 자료 백업 등은 모두 영향이 없습니다.
>
> **키**: `AMMDS-XXXX-XXXX-XXXX-XXXX` 형태의 문자열로, 이 설치의 인가 자격에 해당합니다.

워터마크·체험·오프라인 활성화 같은 개념만 알고 싶다면 [용어집](../glossary.md)과 [자주 묻는 질문: 라이선스와 워터마크](../faq.md#라이선스와-워터마크)를 보세요. 활성화·갱신·비활성화 전체 흐름은 [시스템 관리: 라이선스와 워터마크](../backend/system/maintenance.md#4-라이선스와-워터마크)를 참고하세요.

아래의 완전한 키(하이픈 포함)를 복사해 다음 절의 순서대로 활성화하세요.

| 사용 가능한 키 | 상태 | 비고 |

| `AMMDS-XXXX-XXXX-XXXX-XXXX` | 자리표시자 | 관리자: 여기에 실제 키를 입력 |
| `AMMDS-XXXX-XXXX-XXXX-XXXX` | 자리표시자 | 관리자: 여기에 실제 키를 입력 |

:::note[키 하나는 설치 하나에]
보통 키 하나로 활성화할 수 있는 설치는 하나뿐입니다. 자리가 다 차면 이후 활성화에서 "활성화 자리가 꽉 찼다"고 표시됩니다. 서버를 옮기거나 재설치하기 전에 기존 인스턴스에서 **온라인 라이선스 비활성화**로 자리를 비워 두고, 새 인스턴스에서 키를 사용하세요.
:::

## 활성화 방법

**관리자** 계정으로 로그인한 뒤 아래 세 단계로 진행합니다. 다른 로그인 계정은 상태와 혜택만 볼 수 있고 활성화는 할 수 없습니다.

1. 오른쪽 위 아바타 → **사용자 센터**를 열고 페이지 하단의 "라이선스" 카드까지 스크롤합니다.
2. **활성화**를 클릭합니다(이미 활성화된 경우에는 "라이선스 변경"을 먼저 눌러 펼친 뒤) 키를 붙여넣습니다.
3. 확인을 누릅니다. 성공하면 워터마크가 사라지고 카드에 요금제와 만료일이 표시됩니다.

상태 항목, 오프라인 활성화, 체험 규칙에 대한 자세한 내용은 [시스템 관리: 라이선스와 워터마크](../backend/system/maintenance.md#4-라이선스와-워터마크)를 참고하세요. 서버가 인가 서비스에 연결되지 않으면 **오프라인 활성화**를 사용합니다. 화면 안내에 따라 인스턴스 ID와 명령을 받아 연결된 다른 기기에서 실행하고, 반환된 JSON을 파일(64 KiB 이하)로 저장해 다시 업로드하세요.

## 몇 가지 규칙

| 항목 | 규칙 |
| --- | --- |
| 활성화 자리 | 설치 하나가 자리 하나를 차지하며 로그인 사용자 수와는 무관합니다. 자리가 꽉 차면 기존 기기를 해제하세요 |
| 라이선스 변경 | 현재 인가를 교체합니다. 체험 중에 활성화가 성공하면 체험은 즉시 종료됩니다 |
| 온라인 갱신 | 한 번 검증합니다. 서비스가 일시적으로 사용 불가하면 캐시된 상태를 반환합니다 |
| 온라인 인가 비활성화 | 원격 해제가 확인된 뒤에 로컬 자료를 삭제합니다 |
| 로컬 인가만 지우기 | 로컬 키와 토큰만 삭제하며, 원격 자리를 해제하거나 체험 기록을 지우지는 않습니다 |
| 멤버십과 라이선스 | 멤버십은 계정의 표식, 라이선스는 이 설치의 인가로 서로 독립적입니다 |

비활성화와 삭제에는 확인이 필요하며 되돌릴 수 없습니다. 요금제 이름, 가격, 혜택 범위는 구매 페이지와 라이선스 페이지의 표시를 따르세요.

## 키가 안 될 때

- **"활성화 자리가 꽉 찼다"**: 해당 키의 자리가 모두 사용 중입니다. 다음 키로 다시 시도하세요. 내 키라면 라이선스 포털에서 기존 기기를 해제하거나 기존 인스턴스에서 온라인 라이선스를 비활성화하세요.
- **"인가를 사용할 수 없음" / 검증 실패**: 만료·취소·일시 중지되었을 수 있습니다. 다른 키를 시도하고, 키가 빠짐없이 복사되었는지 불필요한 공백이 없는지 확인하세요.
- **워터마크가 그대로다**: 활성화가 성공하면 사라집니다. 그래도 남아 있으면 사용자 센터의 라이선스 상태와 알림 줄을 확인하고, [자주 묻는 질문: 라이선스와 워터마크](../faq.md#라이선스와-워터마크)에서 해당 항목을 찾으세요. 기능에는 영향이 없으므로 그대로 계속 사용할 수 있습니다.
- **인가 서비스에 연결되지 않는다**: 이미 활성화된 인스턴스는 캐시된 유효한 자격으로 일정 기간(오프라인 유예 기간) 계속 동작합니다. 네트워크가 돌아오면 갱신하세요. 유예가 끝나도 워터마크가 돌아올 뿐 기능에는 영향이 없습니다.
- **그래도 안 된다**: 버전, 시각, 로그 조각을 첨부해 GitHub에 이슈를 올리세요: https://github.com/QYG2297248353/AMMDS-Docker/issues/new
