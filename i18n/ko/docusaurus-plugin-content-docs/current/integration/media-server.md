# TV에서 보도록 동기화하기

AMMDS는 재생기가 아니라 자료를 정리하는 도구입니다. TV에서 깔끔한 포스터 목록을 보려면 Jellyfin이나 Emby를 붙여 정리한 정보를 넘겨야 합니다.

> **미디어 서버 / 플레이어**: TV, 셋톱박스, 컴퓨터에서 도는 재생 프로그램입니다. Jellyfin, Emby 등이 여기에 해당합니다. 영상을 재생하고 포스터 목록을 보여 줍니다.

> **API 키**: 플레이어가 발급하는 문자열로, 전용 열쇠와 같습니다. 가진 사람은 그 프로그램의 권한으로 자료를 읽고 쓸 수 있습니다.

> **묶기(바인딩)**: 내 작품과 플레이어 안의 작품을 서로 이어 주는 일입니다. 묶어야 양쪽이 동기화됩니다.

## 먼저 하나 고르기

Jellyfin과 Emby는 같은 뿌리라서 설정 항목과 할 수 있는 일이 아주 비슷합니다. **둘을 함께 켤 수도 있습니다.** 재생 기록은 각기 묶은 사용자별로 가져온 뒤 합쳐집니다. 하나로도 충분합니다.

| 비교 | Jellyfin | Emby |
| --- | --- | --- |
| 위치 | 연동 앱 → 미디어 서버 → Jellyfin | 연동 앱 → 미디어 서버 → Emby |
| 통신 | 플레이어 창구 + API 키 | 플레이어 창구 + API 키 |
| 기본 서비스 주소 | `http://127.0.0.1:8096` | `http://127.0.0.1:8096` |
| 키 받는 곳 | 관리 콘솔 → API 키(일부 버전은 '고급' 아래) | 설정 → 고급 → API 키 |
| 관리 입구 | 도구함 → 미디어 서버 → 라이브러리 관리 / 작품 / 배우 | 위와 같음 |

## 같은 세 단계

1. 플레이어에서 API 키를 만듭니다(이름은 `AMMDS` 로 두면 나중에 그것만 폐기할 수 있습니다).
2. AMMDS 플러그인 화면으로 돌아와 서비스 주소와 키를 적고 **저장**합니다.
3. 화면을 새로고침해 사용자 목록이 뜨면 **묶을 사용자**를 고르고 저장한 뒤 '연결 테스트'를 누릅니다.

:::tip[전용 키를 만드세요]
관리자가 평소 쓰는 키를 함께 쓰지 마세요. 따로 만들면 문제가 생겼을 때 그것만 폐기할 수 있습니다.
:::

## Jellyfin

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 미디어 서버 창구가 모두 '먼저 JellyFin 플러그인을 켜세요'를 돌려줍니다 |
| 서비스 주소 | 기본 `http://127.0.0.1:8096`. 컨테이너라면 호스트 주소나 서비스 이름 | 컨테이너에서 `127.0.0.1`을 적으면 AMMDS 자신에게 붙습니다 |
| API 키 | Jellyfin 관리 콘솔에서 발급. 켠 뒤에는 시스템 점검의 필수 항목 | 비거나 무효면 '올바른 플러그인 설정을 입력하세요'가 납니다 |
| 사용자 이름 | 로그인 이름.**선택** | 보통 동기화에 영향 없습니다 |
| 비밀번호 | 로그인 비밀번호.**선택** | 위와 같음 |
| 묶을 사용자 | 재생 기록을 어느 Jellyfin 사용자 것으로 볼지. 여러 명은 쉼표로 구분 | 안 묶어도 재생 기록 동기화는 돌지만 그 계정의 집계가 나오지 않습니다 |
| 자동 보충 | 기본 꺼짐. 켜면 정해진 때마다 배우 정보를 비동기로 채움 | 내 배우 라이브러리에 없는 정보는 채울 수 없습니다 |

### 묶는 순서

1. 먼저 서비스 주소와 API 키를 적고 **저장**합니다.
2. 설정 화면을 새로고침해 Jellyfin 사용자 목록을 불러옵니다.
3. '묶을 사용자'에서 계정을 고르고(관리자는 붉은 표식, 일반은 파란 표식) 저장합니다.

### 동기화되는 것

| 내용 | 방향 | 설명 |
| --- | --- | --- |
| 라이브러리 항목 | 플레이어 → AMMDS | 라이브러리의 작품·배우 등을 가져와 묶기와 표시에 씁니다 |
| 라이브러리 동기화 | 양방향 | 내 작품 정보와 표지를 플레이어에 적고 묶음을 만듭니다 |
| 재생 기록 | 플레이어 → AMMDS | 묶은 사용자별로 재생 기록을 가져와 재생 집계에 씁니다 |
| 배우 보충 | 양방향 | 플레이어의 배우 정보를 채웁니다. 반대로 플레이어에서 긁은 배우를 내 쪽에 적을 수도 있습니다 |
| 그림 | AMMDS → 플레이어 | 라이브러리나 항목의 대표 그림을 올려 기존 그림을 덮어씁니다 |
| 라이브러리 검사 | AMMDS → 플레이어 | 라이브러리 하나 또는 전체 검사를 실행합니다 |

그에 맞는 조작은 **도구함 → 미디어 서버 → 라이브러리 관리**에 있습니다. '모든 라이브러리 검사', '배우 정보 보충', '라이브러리 동기화', '재생 기록 동기화', '새로고침'.

## Emby

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |

키를 만든 계정에 라이브러리를 관리할 권한이 없으면 사용자 목록 가져오기가 실패합니다.
:::

### 묶는 순서

1. 서비스 주소와 API 키를 적고 저장합니다.
2. 설정 화면을 새로고침해 Emby 사용자 목록이 뜨기를 기다립니다.
3. '묶을 사용자'에서 계정을 고르고(관리자는 붉은 표식, 일반은 파란 표식) 저장합니다.

### 동기화되는 것

| 내용 | 방향 | 설명 |
| --- | --- | --- |
| 라이브러리 항목 | 플레이어 → AMMDS | 라이브러리의 작품과 배우를 가져옵니다 |
| 라이브러리 동기화 | 양방향 | 내 작품 정보와 표지를 적고 작품 묶음을 만듭니다 |
| 재생 기록 | 플레이어 → AMMDS | 묶은 사용자별로 재생 기록을 가져와 재생 집계에 씁니다 |
| 배우 보충 | 양방향 | 배우 정보를 채웁니다. 플레이어에서 긁은 배우를 내 쪽에 적을 수도 있습니다 |
| 그림 | AMMDS → 플레이어 | 라이브러리나 항목의 대표 그림을 올립니다 |
| 라이브러리 검사 | AMMDS → 플레이어 | 라이브러리 하나 또는 전체 검사를 실행합니다 |

## 둘 다 알아야 할 한계

- **모두 비동기**: 동기화와 보충은 뒤에서 돌고, 창구는 바로 '동기화 중… 나중에 로그를 보세요'를 돌려줍니다. 진행은 실행 로그로만 볼 수 있습니다.
- **묶으면 씁니다**: 작품이나 배우를 묶을 때 내 자료와 그림을 플레이어로 되돌려 적습니다. 최선을 다하는 방식이라 되돌려 적기가 실패해도 묶음 자체는 성공합니다.
- **파일은 지우지 않음**: 동기화가 적는 것은 정보와 그림뿐이며 플레이어의 영상 파일은 지우지 않습니다.
- **묶음 해제는 관계만**: 해제로 지워지는 것은 내 쪽 묶음 기록뿐이고 플레이어 쪽 자료는 그대로입니다.
- **자동 보충에는 전제가 있음**: 내 배우 라이브러리에 있는 자료나 사진에 기댑니다. 내게 없는 것은 채울 수 없습니다.
- **주소에 127.0.0.1 적지 않기**: 컨테이너에서 `127.0.0.1` 은 AMMDS 컨테이너 자신입니다.

## 문제가 생겼을 때

- **'올바른 플러그인 설정을 입력하세요'**: 서비스 주소가 틀렸거나, API 키가 무효거나, 플레이어가 안 떠 있습니다. 먼저 '연결 테스트'로 가늠하세요.
- **'먼저 XX 플러그인을 켜세요'**: 플러그인의 '사용 상태'를 켜고 저장하세요.
- **사용자 목록이 빔**: 설정이 아직 저장되지 않았습니다. 저장하고 화면을 새로고침하세요.
- **재생 기록에 데이터가 없음**: 묶은 사용자가 없거나 그 사용자가 최근에 재생한 것이 없습니다. 묶고 다시 동기화하세요.
- **동기화 진행이 안 보임**: 뒤에서 돕니다. 실행 로그를 보세요.
- **표지가 안 바뀜**: 되돌려 적기 실패이거나 원본 그림이 고정되어 있습니다. 플레이어에서 그림 고정 상태를 확인하고 다시 하세요.
- **Emby에 적었는데 화면이 그대로**: 플레이어의 임시 저장이 갱신되지 않았습니다. 라이브러리 검사나 정보 갱신을 한 번 실행하세요.
