# 판별을 돕는 작은 도구

이 분류는 작품 정보를 직접 주지도 않고 내려받기를 맡지도 않습니다. 그러나 앞의 일이 잘 돌게 합니다. 판별이 정확해지고, 검색이 빨라지고, 영상을 바꿀 수 있고, 자막이 저절로 만들어집니다.

> **변환(트랜스코딩)**: 영상을 다른 형식이나 다른 화질로 다시 만드는 일입니다. 더 많은 기기에서 재생되도록 합니다.

> **프록시**: 먼저 다른 서버에 붙고, 그 서버가 목적지 사이트로 가게 하는 방식입니다. 이 기기에서 직접 닿지 않을 때 씁니다.

> **색인(인덱스)**: 검색만을 위해 만들어 둔 목록입니다. 내용을 미래에 정리해 두면 검색이 빨라집니다.

> **객체 저장소**: '통 + 파일 이름'으로 파일을 두는 온라인 공간입니다. 여러 클라우드 드라이브나 기업용 저장 서비스가 여기에 해당합니다.

## 어느 것이 무엇을 하나

| 도구 | 해결하는 것 | 직접 준비해야 하나 | 기본값 |
| --- | --- | --- | --- |
| Amap | 작업대에 현재 도시와 날씨를 보여 줌 | 아니오. 키만 넣음(안 넣어도 됨) | 기본 꺼짐 |
| 클라우드 저장소 | 설정을 암호화해 백업. S3는 그림도 둘 수 있음 | 예: WebDAV 또는 S3 주소와 계정 | 기본 꺼짐 |
| DeepSeek | AI 번역, 판별 보조, Telegram 대화 | 예: 주소와 키 | 기본 꺼짐 |
| FFmpeg | 변환, 형식 바꾸기, 화면 캡처, 표지, 길이 읽기 | 아니오. 없으면 자동으로 내려받음 | 기본 **켜짐** |
| FlareSolverr | 일부 사이트의 '사람인지 확인' 페이지 통과 | 예: 직접 구축 | 기본 꺼짐 |
| MeiliSearch | 위 검색창에서 작품·배우·만화 등을 빨리 찾게 함 | 예: 직접 구축 | 기본 꺼짐 |
| 번역 서비스 | 가져온 외국어 제목과 줄거리를 중국어로 | 경로에 따라 키 필요. 내장 무료 경로는 불필요 | 기본 꺼짐 |
| VibeVoice | 영상 속 대사를 자막 파일로 | 선택: 이 기기에서 돌림(모델 필요) 또는 외부 서비스 | 기본 꺼짐 |

## Amap

작업대의 날씨 카드에 현재 도시와 날씨를 띄웁니다. 나가는 네트워크로 도시를 짐작하지만, 도시를 고정할 수도 있습니다.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 적은 키를 쓰지 않습니다 |
| 서비스 주소 | 기본 `https://restapi.amap.com`. 프록시나 미러를 쓰면 변경 | 틀리면 날씨 불러오기가 실패합니다 |
| API 키 | Amap 개방 플랫폼에서 신청.**서비스 플랫폼은 'Web 서비스'를 고를 것** | 비면 내장 할당량으로 돌아갑니다. 날씨는 나오지만 정확도와 사용량은 내장 할당량에 따릅니다 |
| 도시 코드 | 도시의 숫자 코드. 예: 베이징 `110000`, 상하이 `310000` | 비면 나가는 네트워크로 추정. 3~6자리 숫자여야 하고 어긋나면 미입력으로 봅니다 |

:::tip[도시를 고정하면 안정적]
서버가 프록시나 VPN 안에 있으면 추정이 기계실 위치로 될 수 있습니다. 도시 코드를 넣으면 날씨가 늘 원하는 도시 것이 됩니다.
:::

'연결 테스트'는 서비스 주소에 대한 상태 확인일 뿐이며, 키를 확인하지도 않고 날씨도 주지 않습니다.

## 클라우드 저장소

'클라우드 저장소'는 WebDAV와 S3라는 서로 다른 두 플러그인으로 이루어져 있고, '암호화 백업 + 단위별 복원'이라는 같은 방식을 씁니다.

| 할 수 있는 일 | WebDAV | S3 호환 객체 저장소 |
| --- | --- | --- |
| 설정 암호화 백업 | 됨 | 됨 |
| 설정 복원 | 됨 | 됨 |
| 그림 등 자료 두기 | **안 됨** | 됨(따로 켜야 함) |
| 암호화 암구 | 따로 | 따로. WebDAV와 서로 영향 없음 |

:::warning[WebDAV의 자리]
WebDAV는 할당량이 넉넉하지 않고 많은 그림을 두기에 알맞지 않습니다. 그림 등을 멀리 두려면 S3를 쓰세요.
:::

### 백업 범위

백업에는 **설정류**만 들어갑니다. 작품 항목, 그림, 메타데이터 같은 큰 내용은 들어가지 않습니다.

| 단위 | 내용 |
| --- | --- |
| 시스템 설정 | 도메인 연결, 시스템 모드, 디스크 감시, 광고 스위치 등 |
| 연동 플러그인 설정 | 각 플러그인의 설정 |
| 겉모습과 테마 설정 | 테마, 배경, 추모 모드, 착지 페이지 |
| 개인과 홈 설정 | 별명, 메일, 전화번호, 공개 홈 테마(아바타는 제외) |
| 창구 열쇠 | 공개 창구 이용 키와 유효 기간 |
| 작업과 스캔 규칙 | 스캔 정의, 실행 종류, 예정 규칙 |
| 구독 규칙 | 구독 키워드, 일치 규칙, 자동 내려받기 방침 |
| 관리 화면 설정 | 관리 메뉴, 탭, 테마 색 |

기본으로 고른 단위는 `system,plugin,user,secret,task,subscribe` 입니다.

### 설정 항목 설명(WebDAV)

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 백업하지 않습니다 |
| 서비스 주소 | 프로토콜을 붙임. 예: `https://dav.example.com` | 비면 연결 테스트가 실패합니다 |
| 저장 폴더 | 기본 `ammds-backup`. 비면 서비스의 뿌리 | 없으면 연결 테스트가 자동으로 만듭니다 |
| 계정 | 비면 익명 | 인증이 필요한데 비면 연결이 안 됩니다 |
| 비밀번호 | 로그인 비밀번호. 창구는 평문을 보여 주지 않음 | 위와 같음 |
| 자체 서명 인증서 허용 | 기본 꺼짐. 직접 구축이면 켬 | 끄면 자체 서명 인증서가 실패합니다 |
| 백업 암호화 | 기본 **켜짐**. AES-256-GCM으로 암호화 | 끄면 백업이 평문이 됩니다 |
| 암호화 암구 | 키를 만드는 데 사용 | **잃으면 복원할 수 없습니다** |
| 복원 방침 | 기본 '합쳐 갱신'. '내 것 우선', '먼 것 우선'도 있음 | 잘못 고르면 복원된 값이 원하는 것이 아닙니다 |
| 백업 단위 | 쉼표로 구분한 단위 코드. 기본 `system,plugin,user,secret,task,subscribe` | 고르지 않은 단위는 들어가지 않습니다 |
| 보관 개수 | 기본 `5`. 넘는 옛것은 자동으로 지움. `0` 은 무제한 | 너무 작으면 옛 백업이 지워집니다 |

### 설정 항목 설명(S3)

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 백업과 자료 저장이 모두 이것에 기댐 |
| S3 서비스 주소 | 예: `https://s3.us-east-1.amazonaws.com` 이나 직접 만든 MinIO 주소 | 비면 연결이 안 됩니다 |
| S3 지역 | 기본 `us-east-1` | 안 맞으면 서명이 실패합니다 |
| S3 버킷 | 미리 서비스에서 만들어 두어야 함 | 없으면 연결 테스트가 실패합니다 |
| S3 접두어 | 기본 `ammds-backup`. 백업이 쓰일 폴더 | 안 맞으면 목록이 빕니다 |
| S3 액세스 키 / 시크릿 키 | 키 한 쌍. 창구는 평문을 보여 주지 않음 | 틀리면 서명이 실패합니다 |
| S3 경로 방식 주소 지정 | 기본 **켜짐**. MinIO 등은 대개 필요, 큰 클라우드는 끄는 편 | 안 맞으면 연결이 안 됩니다 |
| 자체 서명 인증서 허용 | 기본 꺼짐 | 직접 만들고 자체 서명이면 켬 |
| 자료를 S3에 저장 | 기본 꺼짐. 켜면 새로 올린 그림이 S3로 가고 내 것에도 사본 유지 | 안 켜면 옮겨지지 않습니다. 켜기 전의 내 자료는 자동으로 옮겨지지 않습니다 |
| 자료 접근 접두어 | 비면 이 시스템을 거쳐 읽음. 넣으면 바로 이어붙여 배포망에도 붙일 수 있음 | 틀리면 그림이 안 열립니다 |
| 내 사본 보관 | 기본 **켜짐**. S3에서 읽은 자료의 사본을 남김 | 끄면 매번 S3로 가서 통신이 늘어납니다 |
| 암호화 / 암구 / 복원 방침 / 단위 / 보관 개수 | 뜻은 WebDAV와 같고 암구는 따로 | 위와 같음 |

### 백업과 복원 순서

1. '설정 정보'에서 연결, 암호화, 복원 방침을 적고 저장합니다.
2. '단위 백업 관리'에서 남길 단위를 고르고 '단위 저장'을 누릅니다.
3. '백업과 복원'에서 메모를 적고 '지금 백업'을 누릅니다.
4. 끝나면 목록이 새로고침되고 파일 이름, 만든 시각, 크기, 암호화 여부가 보입니다.
5. 되돌리려면 '복원'을 누르고 방침을 고른 뒤 암구를 넣고 확인해 씁니다.

| 복원 방침 | 동작 |
| --- | --- |
| 합쳐 갱신 | 없는 것과 다른 것만 채웁니다 |
| 내 것 우선 | 내게 없는 설정만 더하고 내 값을 남깁니다 |
| 먼 것 우선 | 백업 내용으로 내 설정을 덮어씁니다 |

:::warning[암구를 잃으면 복원 불가]
암구는 내 기기에서 키를 만드는 데만 쓰이고 서버는 평문을 저장하지 않습니다. 따로 적어 두세요. 또한 복원할 때 WebDAV와 S3 자신의 연결 설정과 암구는 덮어쓰지 않습니다. 복원한 뒤에도 계속 백업할 수 있도록입니다.
:::

## DeepSeek

DeepSeek은 큰 언어 모델을 AMMDS에 붙입니다. AI 번역, 판별 보조, Telegram 대화에 씁니다.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 잔액과 모델 카드가 안 보이고 뒤에서의 호출도 꺼진 것으로 봅니다 |
| 서비스 주소 | 기본 `https://api.deepseek.com`. 중계나 직접 만든 프록시면 변경 | 비면 '먼저 연결 주소를 설정하세요'가 나오고 요청하지 않습니다 |
| API 키 | 부르는 증표 | 없으면 잔액도 모델도 대화도 안 됩니다 |
| 추론 모델 | 기본 `deepseek-v4-pro`. 직접 적거나 모델 목록의 '사용'으로 가능 | 옛 이름은 바뀝니다: `deepseek-chat` → `deepseek-v4-pro`, `deepseek-reasoner` → `deepseek-v4-flash` |
| 모델 온도 | 기본 `0.7`. 클수록 흔들리고 작을수록 안정 | 보통 바꾸지 않습니다 |
| 문맥 길이 / 출력 길이 | 기본 `1M` / `384K`. **능력 표시일 뿐 요청에 안 쓰임** | 바꿔도 실제 요청에는 영향 없습니다 |

### 화면에서 할 수 있는 것

| 구역 | 내용 |
| --- | --- |
| 앱 정보 | 이름, 로고, 공식 사이트, 문서, 연동 버전, 소개 |
| 설정 정보 | 위 표의 항목들. '설정 새로고침', '설정 저장' |
| 잔액 | 켜면 나타남. 통화별로 총액, 선물분, 충전분. 쓸 수 있으면 녹색 '계정 사용 가능', 부족하면 붉은 '잔액 부족' |
| 모델 목록 | 켜면 나타남. 모델 ID, 주인, 만든 시각. '사용'을 누르면 설정에 적히고 쓰는 것은 '사용 중' |
| 연결 테스트 | 현재 서비스 주소로 상태 확인 |

:::note[동시 실행과 실패]
제한은 모델별입니다. `deepseek-v4-pro` 는 500, `deepseek-v4-flash` 는 2500까지. 자리가 없으면 최대 30초 기다리고, 안 되면 '동시 요청이 가득 참'을 돌려줍니다. 429는 실패로 보며 플러그인이 다시 시도하지 않습니다.
:::

## FFmpeg

FFmpeg는 소리와 영상 처리의 바탕입니다. 변환, 형식 바꾸기, 화면 캡처, 표지 자르기, 작은 그림, 그리고 길이와 해상도 읽기를 맡습니다. **기본으로 켜져 있습니다.**

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 기본 **켜짐** | 끄면 새 변환 / 바꾸기 작업을 못 만듭니다(이미 있는 작업은 영향 없음) |
| 작업 수 | 기본 `2`. 1~5. 종류별로 셈 | 너무 크면 CPU를 다 씁니다 |
| 변환 출력 방식 | 기본 '뒤에 붙임'(다른 것: '한 폴더에') | '한 폴더에'인데 폴더가 비면 실패 |
| 변환용 한 폴더 경로 | 출력 방식이 '한 폴더에'일 때 사용 | 위와 같음 |
| 변환 기본 뒤붙이 | 기본 `transcode`. 파일 이름 뒤에 붙음 | 보통 바꾸지 않습니다 |
| 형식 바꾸기 출력 방식 | 기본 '원 폴더에 같은 이름'(다른 것: '한 폴더에') | 위와 같음 |
| 형식 바꾸기용 한 폴더 경로 | 출력 방식이 '한 폴더에'일 때 사용 | 위와 같음 |
| 변환 기본 영상 부호화 | 기본 `libx264`. 다른 것 `libx265` | 부품이 없으면 '부호화기를 찾을 수 없음'이 납니다 |
| 변환 기본 사전 설정 | 기본 `veryfast`. `ultrafast` 부터 `veryslow` 까지 | 느릴수록 작아지지만 오래 걸립니다 |
| 변환 기본 화질(CRF) | 기본 `23`. 18~28 권장. 작을수록 화질이 좋고 커짐 | 권장을 벗어나면 크기나 화질이 크게 달라집니다 |
| 줄 서기 | 기본 **켜짐**. 작업 수를 넘으면 순서를 기다림 | 끄면 넘는 것이 바로 실패 |
| 작업 이어하기 | 기본 **켜짐**. 다시 시작하면 안 끝난 작업을 자동으로 이음 | 끄면 안 끝난 것이 실패로 되고 손으로 다시 해야 함 |

### 부품 관리

- 부품은 내 기기의 `data/ffmpeg` 에 들어가고 운영체제와 CPU에 맞는 것이 골라집니다.
- 시작 뒤에 확인하고, **없으면 비동기로 내려받으며 매분 다시 시도**합니다. 32비트는 지원하지 않습니다.
- '자료 내려받기' 카드에서 파일 이름, 상태, 진행, 경로를 볼 수 있고, **없는 부품 내려받기**, **상태 새로고침**, **삭제**가 있습니다.

:::note[내려받기가 끊겼다면]
상태는 시작 안 함, 내려받는 중, 끝남, 실패 등입니다. 끊긴 부품은 지우고 다시 받으면 되며 다른 쪽에는 영향이 없습니다.
:::

변환 입구는 **도구함 → 영상 변환**, 형식 바꾸기는 **도구함 → 형식 변환**입니다.

## FlareSolverr

어떤 사이트는 본문 앞에 '브라우저를 확인하고 있습니다' 같은 페이지를 띄워, 보통 요청으로는 그 페이지만 받습니다. FlareSolverr는 이런 페이지를 전문으로 처리하는 서비스이고, AMMDS가 가져오기를 맡길 수 있습니다.

> **확인 페이지 / 사람 확인**: 사이트가 '프로그램이 아니라 진짜 브라우저인지' 확인하려고 사이에 두는 페이지입니다.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 쓰지 않고 요청은 원래 흐름으로 나갑니다 |
| 서비스 주소 | 기본 `http://127.0.0.1:8191`. 돌고 있는 FlareSolverr를 가리킴. 프로토콜과 포트 필요 | 비면 '먼저 연결 주소를 설정하세요'. 다른 기기라면 실제 주소로 |
| 프록시 설정 동기화 | 기본 **켜짐**. 시스템의 네트워크 프록시를 넘김 | 컨테이너에서 `127.0.0.1` 은 자기 자신. 그 기기가 밖으로 바로 나갈 수 있으면 동기화를 끔 |
| 시간 초과 | 기본 `60`초. 두 번 확인이 느린 사이트면 90~120초로 | 너무 크면 실패한 요청이 오래 연결을 잡습니다 |

:::note[따로 도는 서비스]
AMMDS는 내려받지도, 품지도, 시작하지도 않습니다. 직접 컨테이너나 실행 파일로 돌리세요. 플러그인은 주소만 저장하고 부릅니다.
:::

### 켜야 할 때와 아닐 때

| 상황 | 알맞은가 |
| --- | --- |
| 상대가 '브라우저를 확인하고 있습니다' 같은 페이지를 띄움 | 알맞음 |
| 보통의 고정된 사이트, 열린 창구 | 필요 없음. 켜면 매번 한 단계가 늘어남 |
| 로그인이나 결제가 필요, 또는 상대가 내 주소를 막음 | 알맞지 않음. 계정과 권한을 대신하지 못함 |
| 401 / 403이 오는데 확인 페이지는 없음 | 알맞지 않음. 먼저 키와 계정 상태를 확인 |

'연결 테스트'는 AMMDS가 FlareSolverr에 닿는지만 확인하며, 상대 사이트가 확인을 통과한다는 뜻은 아닙니다.

## MeiliSearch

MeiliSearch는 전문(全文) 검색 장치입니다. 설정하면 작품, 드라마, 배우, 만화, 소설, 소식이 색인에 적히고, 공개 사이트와 위 검색창이 그 색인을 봅니다.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 색인도 검색도 안 하고 공개 검색 창구는 빈 것을 줍니다 |
| 서비스 주소 | 기본 `http://192.168.10.24:7700` 은 **예시 주소**입니다. 반드시 내 주소로 바꿈. 프로토콜과 포트 필요 | 그대로면 반드시 연결이 안 됩니다 |
| API 키 | 색인과 검색의 인증 키. 다시 만들려면 **쓸 수 있는** 키가 필요 | 권한이 부족하면 다시 만들기가 실패합니다 |
| 자동 색인 | 기본 **켜짐**. 주기적으로 모든 종류를 전부 다시 만듦 | 끄면 손으로만 가능하고 새 작품이 색인에 안 들어갑니다 |

### 색인 관리와 다시 만들기

'색인 관리'는 종류별로 다시 만들며 매번 **전부**입니다.

| 선택 | 내용 |
| --- | --- |
| 전체 | 모든 종류를 차례로 다시 만듦(작품, 드라마, 배우, 만화, 소설, 소식) |
| 작품 | 작품 제목, 작품 번호 등 |
| 배우 | 배우 이름, 다른 이름 등 |
| 만화 | 만화 제목, 작가 등 |
| 소설 | 소설 제목, 작가, 시리즈 등 |
| 소식 | 소식 항목 |

'색인 다시 만들기'를 누르면 종류별로 적힌 건수가 보입니다. 예: `movie=1024, actor=356`. 다시 만들기는 '그 종류를 비운 뒤 나눠서 적는' 방식이라 그동안 검색 결과가 잠깐 비거나 모자랄 수 있습니다.

:::tip[처음에는 손으로 한 번]
새로 깔았거나 데이터가 크게 바뀌었다면 먼저 손으로 '전체'를 한 번 다시 만들고, 그다음은 자동 색인에 맡기는 것이 좋습니다. 자동 색인이 켜져 있고 서비스가 쓰일 수 있으면 시작 약 5분 뒤에 처음 전부를 만들고 그다음은 한 시간마다입니다.
:::

'검색 테스트'는 색인만 읽고 데이터는 바꾸지 않습니다. 안 나오면 그 종류가 다시 만들어졌는지 확인하세요.

## 번역 서비스

번역 서비스는 가져온 외국어 제목·줄거리·태그를 중국어로 옮깁니다. 길은 둘입니다. AMMDS 내장 번역 또는 MetaTube에 맡기기.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태(화면에서는 '번역 사용') | 스위치를 켬 | 끄면 번역 요청이 '번역 서비스가 꺼져 있음'을 돌려줍니다 |
| AI 우선 | 기본 꺼짐. 켜면 AI 번역을 먼저 시도하고 다 실패하면 기계 번역을 차례로 | 끄면 내장 순서로 갑니다 |
| 기본 번역 방식 | 기본 `ammds`(내장). 다른 것 `metatube` | `metatube` 인데 MetaTube 쪽 번역이 꺼져 있으면 결과가 없습니다 |
| 제목 / 설명 / 태그 / 기본 번역 프롬프트 | 내장 영문 형식. 직접 쓸 수 있음. 변수 `{source_lang}`, `{target_lang}`, `{content}` | 잘못 써도 오류는 아니고 번역 품질에 나타납니다 |

:::note[간체 중국어로만]
정보 가져오기 흐름은 외국어를 간체 중국어로 고정해 옮깁니다. 원문 언어는 자동으로 알아보고 이 화면에 대상 언어 설정은 없습니다. 또한 정보 가져오기 설정의 '항목 번역'이 기본으로 꺼져 있어 켜지 않으면 번역이 안 됩니다.
:::

### 내장 번역의 공급자

내장 번역은 쓸 수 없는 공급자를 빼고 우선순위대로 시도해 처음 성공한 것을 돌려줍니다.

| 분류 | 공급자 | 적어야 하는 것 |
| --- | --- | --- |
| 기계 번역 | DeepL | 서비스 주소, 창구 경로, 인증 코드 |
| 기계 번역 | DeepLX | 서비스 주소, 창구 경로, 인증 코드 |
| 기계 번역 | Google 번역 Free | 없음 |
| 기계 번역 | Microsoft 번역 Free | 없음 |
| 기계 번역 | Baidu 번역 | 서비스 주소, 창구 경로, 앱 ID, 키 |
| 기계 번역 | Niutrans 번역 | 서비스 주소, 창구 경로, 앱 ID, 앱 키 |
| 기계 번역 | Caiyun 번역 | 서비스 주소, 창구 경로, 토큰 |

| AI 번역 | OpenAI 호환 | 서비스 주소, 창구 경로, 키, 모델, 온도, 지시문 |
| AI 번역 | Gemini 호환 | 서비스 주소, 창구 경로, 키, 모델, 온도, 지시문 |
| AI 번역 | Anthropic 호환 | 서비스 주소, 창구 경로, 키, 모델, 온도, 지시문 |

공급자는 카드로 보이고 켜짐 / 꺼짐 상태와 우선순위가 보이며, 사용 스위치, **테스트**, 고치기, 지우기가 있습니다.

:::tip[AI 우선의 실제]
'AI 우선'은 AI를 앞에 줄 세우는 것만이 아닙니다. 흐름이 AI 공급자를 기계 번역보다 앞에 묶어 놓고, AI가 다 실패해도 기계 번역을 계속 시도합니다. 손으로 보험을 걸 필요가 없습니다.
:::

`metatube` 를 고르면 번역 요청이 MetaTube로 넘어가 그 화면에서 관리하는 엔진과 키(Google, OpenAI, DeepL, Baidu 등. 고른 것의 키가 필요)를 씁니다.

쓸 수 있는 언어 코드: `auto`(원본만, 자동 판별), `zh`, `cht`, `en`, `ja`, `ko`, `ru`, `cs`. 공급자가 받지 않는 언어는 건너뜁니다.

## VibeVoice

VibeVoice는 영상 속 대사를 자막 파일(`.srt`)로 만듭니다. 이 기기에서 돌릴 수도 있고 밖의 서비스에 붙일 수도 있습니다.

> **음성 인식**: 영상 속 말을 프로그램이 알아듣게 하고 글로 적게 하는 일입니다.

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 연결 방식 | 기본 `local`(이 기기). 다른 것 `remote`(외부 서비스) | local에서는 주소, 키, 모델 이름이 안 보입니다 |
| 사용 상태 | 스위치를 켬 | 끄면 자막 작업을 못 만들고 도구함 입구에 꺼져 있다고 나옵니다 |
| 서비스 주소 | 기본 `http://127.0.0.1:8000`. 로컬은 자동 입력, 리모트는 손으로 | 리모트에서 틀리면 감지가 실패 |
| API 키 | 선택. 서비스가 인증을 안 하면 비움 | 인증이 필요한데 비면 연결이 안 됩니다 |
| 인식 모델 이름 | 기본 `vibevoice-asr`. 서비스가 읽은 모델과 같게 | 다르면 인식이 실패 |
| 최대 동시 작업 수 | 기본 `1`. 1~5 | 이 기기 추론은 메모리를 많이 써서 차례로 하는 것이 좋습니다 |
| 작업당 최대 스레드 | 기본 `4`. 서비스에 알림으로 넘김 | 보통 바꾸지 않습니다 |
| 한 구간 최대 분 | 기본 `3`. 최대 60 | 너무 길면 이 기기 추론이 끊겨 자막 뒤가 잘립니다 |
| 모델 저장소 | 기본 `microsoft/VibeVoice-ASR-BitNet`. 모델 내려받기에 사용 | 보통 바꾸지 않습니다 |
| 모델 파일 이름 | 내려받기가 끝나면 자동 입력. 비면 아직 안 받음 | 비면 모델이 준비 안 됨 |
| 실행기 우선 | 기본 `asr_infer` | 아래 참조 |
| 자막 만들 곳 | 기본 `video_dir`(영상과 같은 곳). 다른 것 `unified`(한 폴더) | '한 폴더'면 `data/subtitles/vibevoice/` 에 작업 ID 이름으로 적힙니다 |

| 실행기 | 동작 | 쓰임 |
| --- | --- | --- |
| `asr_infer`(권장) | 구간마다 독립된 프로세스로 한 번 추론 | 기본. 상주 메모리 없이 더 빠름 |
| `asr_stream_server` | 상주하며 흐름으로 응답. 약 2.5 GB 상주 | 구간마다 모델을 다시 읽는 것을 피하고 싶을 때만 |

### 로컬 방식 준비

1. 플러그인 화면에서 연결 방식으로 '로컬'을 고릅니다.
2. '내장 서비스 → 실행기 내려받기'에서 추론 프로그램을 받고 준비 완료가 될 때까지 기다립니다.
3. '모델 내려받기'에서 저장소가 공식인지 확인하고 '모델 내려받기'를 눌러 파일 두 개(합계 약 1.5 GB)를 기다립니다.
4. '서비스 시작'을 누르고 상태가 '실행 중'이며 포트가 보이는지 확인합니다.
5. '서비스 감지'에서 '서비스 감지'를 눌러 연결됐고 읽힌 모델에 `vibevoice-asr` 이 있는지 확인합니다.

### 자막 만들기

입구는 **도구함 → 자막 생성**입니다. 플러그인이 꺼져 있으면 먼저 켜라는 안내가 납니다.

1. '새 자막 작업'을 누르고 영상 하나 또는 폴더를 고릅니다.
2. 인식 언어를 고릅니다(기본은 자동 판별). 두 언어가 필요하면 '두 언어 자막'을 켜고 대상 언어를 고릅니다.
3. 보내면 작업이 줄에 들어가고 목록에 영상, 길이, 언어, 두 언어, 상태, 진행, 만든 시각이 나옵니다.

| 상태 | 할 수 있는 것 |
| --- | --- |
| 실행 중 / 줄 서는 중 / 번역 중 | 취소 |
| 실패 / 취소됨 | 다시 시도 |
| 완료 | 상세, 보기, 고치기, 내려받기, 번역 |

끝난 작업은 그 자막으로 '번역 작업'을 하나 더 만들 수 있습니다. 음성 인식을 건너뛰고 바로 번역하며 언어 꼬리가 붙은 새 자막이 생깁니다.

## 문제가 생겼을 때

- **날씨가 계속 불러오기 실패**: 서버가 `restapi.amap.com` 에 닿지 않습니다. 연결 테스트로 확인하고 밖으로 나가는 길과 프록시를 보세요.
- **도시 추정이 틀림**: 나가는 길이 기계실이나 프록시 것입니다. 도시 코드를 손으로 넣으세요.
- **백업 목록이 빔**: 연결 설정이 틀렸거나 그 폴더 / 접두어에 백업이 없습니다. 먼저 연결 테스트를 하세요.
- **복원에서 암구가 다르다고 함**: 백업할 때 쓴 것과 다릅니다. 잃으면 복원할 수 없습니다.
- **S3는 주소에 닿는데 연결이 안 됨**: 지역, 주소 지정 방식, 서명이 안 맞습니다. 직접 만든 것이면 경로 방식을 켜 보세요.
- **DeepSeek 잔액이나 모델 목록이 빔**: 먼저 연결 테스트로 주소를 확인하고 키를 보세요. 모델 목록 권한이 없으면 모델 이름을 직접 적으세요.
- **'동시 요청이 가득 참'**: 같은 모델이 한계입니다. 잠시 뒤 다시 하거나 `deepseek-v4-flash` 로 바꾸세요.
- **'부호화기를 찾을 수 없음'**: 부품이 없거나 깨졌습니다. 자료 내려받기에서 지우고 다시 받으세요.
- **변환이 모두 실패**: 줄 서기가 꺼져 있고 동시 실행이 가득 찼습니다. 줄 서기를 켜고 다시 하세요.
- **FlareSolverr가 거부되거나 시간 초과**: 서비스가 안 돌거나, 포트가 다르거나, 방화벽이 막았습니다. 8191번이 듣고 있는지 확인하세요.
- **FlareSolverr를 켰는데도 가져오기 실패**: 확인 페이지가 아니라 로그인이나 차단입니다. 계정, 키, 또는 나가는 네트워크를 보세요.
- **MeiliSearch에 안 붙음**: 주소가 예시 그대로거나, 포트가 안 열렸거나, 키 권한이 부족합니다.
- **검색이 안 됨**: 그 종류가 아직 다시 만들어지지 않았습니다. 한 번 만들고 다시 하세요.
- **'번역 서비스가 꺼져 있음'**: 번역 플러그인의 '사용 상태'를 켜세요. 정보를 가져온 뒤에도 중국어가 없으면 정보 가져오기 설정의 '항목 번역'을 확인하세요.
- **VibeVoice 서비스 감지 실패**: 로컬이면 먼저 '서비스 시작'을, 리모트면 주소와 키를 확인하세요.
- **자막 뒤가 잘림**: 구간이 너무 길어 추론이 끊겼습니다. '한 구간 최대 분'을 줄이거나 `asr_infer` 로 바꾸세요.
