# 외부 서비스 연결, 딱 세 단계

AMMDS는 작품 정보를 스스로 만들어 내지 않고, 파일을 대신 받아 주지도 않습니다. 표지를 자동으로 채우고, 자료를 찾고, 알림을 보내려면 '연동 앱'에서 외부 서비스를 하나씩 연결해야 합니다.

어떤 서비스든 순서는 같습니다. **켜기 → 정보 입력 → 테스트** 세 단계입니다. 항목별로 무엇을 적는지는 이 장의 다른 페이지를 보세요.

## 먼저, 연동 앱이란

> **연동 앱**: AMMDS가 외부 서비스를 한곳에서 관리하는 곳입니다. 주소와 계정 정보를 입력하면 AMMDS가 그 설정대로 서비스를 이용합니다.

> **외부 서비스**: AMMDS 본체 기능이 아니라 다른 사이트나 다른 기기에서 돌고 있는 프로그램입니다. 자료 사이트, 다운로드 프로그램, 플레이어 등이 여기에 해당합니다. 위치와 계정 정보를 알려 주면 둘이 연결됩니다.

> **설정 항목**: 설정 화면에서 채우는 칸이나 켜는 스위치입니다. 모두 해당 페이지의 표에 설명이 붙어 있습니다.

## 여섯 분류, 각자의 역할

사이드바는 쓰임새에 따라 여섯으로 나뉩니다.

| 분류 | 담당 | 들어 있는 것 |
| --- | --- | --- |
| 메타데이터 | 작품·드라마·배우의 표지, 줄거리, 출연진 | MetaTube, TMDB, TheTVDB, Bangumi, ThePornDB, TheJavDB, R18.dev, FANZA DMM, Madou |
| 사이트 자료 | 어느 사이트에서 자료를 찾을지 | M-Team, NexusPHP, Rousi, FSM, Prowlarr, BitMagnet |
| 다운로더 | 찾은 자료를 무엇이 받을지 | qBittorrent, Transmission, IYUU |
| 미디어 서버 | 정리한 정보를 어떤 플레이어에 넘길지 | Jellyfin, Emby |
| 알림 | 일이 끝나면 누구에게 알릴지 | Bark, Telegram, Webhook |
| 보조 도구 | 판별을 돕는 작은 도구 | FFmpeg, 번역, DeepSeek, VibeVoice, MeiliSearch, FlareSolverr, Amap, 클라우드 저장소 |

:::note[분류가 하나 더]
사이드바에는 '클라우드 동기화' 분류도 있습니다. 설정을 네트워크 저장소에 백업하는 용도이며, 작품 정보를 채우는 흐름에는 참여하지 않습니다.
:::

## 꼭 필요한 것과 미뤄도 되는 것

| 하고 싶은 일 | 꼭 필요 | 지금은 없어도 되는 것 |
| --- | --- | --- |
| 작품명을 알아보고 표지·줄거리 채우기 | 메타데이터 출처 하나 이상 + 정보 가져오기 실행 | 출처를 늘리면 적중률이 오르지만 하나로도 됩니다 |
| 자료를 찾아 자동으로 받기 | 사이트 자료 하나 이상 + qBittorrent | Prowlarr, BitMagnet은 보조라 나중에 넣어도 됩니다 |
| TV에서 깔끔한 포스터 목록 보기 | Jellyfin 또는 Emby 중 하나 | 둘 다 써도 되고, 재생 기록은 합쳐집니다 |
| 휴대전화로 알림 받기 | 알림 경로 아무거나 하나 + 알림 마스터 스위치 | Telegram은 명령도 되지만 필수는 아닙니다 |
| 파일 스캔과 변환이 되게 하기 | FFmpeg(기본으로 켜져 있음) | 변환할 일이 없으면 건드리지 않아도 됩니다 |
| 위쪽 검색창에서 찾히게 하기 | MeiliSearch | 목록 필터는 되지만 전체 검색은 비어 있습니다 |

:::tip[하나씩 추가하기]
한꺼번에 다 켜지 마세요. 메타데이터 출처 하나를 먼저 성공시키고 다음을 넣으면, 문제가 생겨도 금방 찾을 수 있습니다.
:::

## 순서

1. **열기**: 연동 앱을 열고 왼쪽 분류를 펼쳐 원하는 항목을 누릅니다.
2. **'사용 상태' 켜기**. 입력만 하고 이 스위치를 켜지 않으면 아무 일도 일어나지 않습니다.
3. **정보 입력**: 서비스 주소, 키나 토큰, 계정과 비밀번호입니다. 다 적었으면 오른쪽 위 **설정 저장**을 누릅니다. 저장 성공 표시가 떠야 반영됩니다.
4. **하위 스위치 켜기**: '작품 검색', '드라마 검색', '랭킹 수집', '메타데이터 검색'처럼 항목별로 작은 스위치가 있습니다. 쓰는 만큼 켜고 저장합니다.
5. **'연결 테스트'** 를 눌러 주소에 닿는지 확인하고, 이어서 '검색 테스트'로 실제로 데이터가 오는지 확인합니다.

:::warning[닿는 것과 쓸 수 있는 것은 다릅니다]
대부분의 연결 테스트는 상대가 무슨 말이든 한 마디라도 돌려주면 성공으로 봅니다. '권한 없음'이라고 돌아와도 성공입니다. 그러니 테스트는 통과하는데 검색이 비어 있다면, 네트워크가 아니라 키·잔여량·하위 스위치·검색어를 확인하세요.
:::

## 설정 항목 설명

모든 설정 화면은 같은 종류의 부품으로 이루어져 있습니다.

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 켜지 않으면 뒤에 무엇을 적어도 반영되지 않습니다 |
| 서비스 주소 | 상대 서비스의 주소. `http://` 또는 `https://` 를 붙입니다 | 비거나 틀리면 연결 테스트가 실패합니다. 컨테이너 안에서 `127.0.0.1`을 쓰면 자기 자신을 가리킵니다 |
| 키 / 토큰 / API 키 | 사이트에서 발급받는 문자열. 열쇠와 같아서 가진 사람이 당신으로 행동할 수 있습니다 | 비거나 틀리면 보통 '연결은 되는데 결과가 빔' 또는 401 / 403으로 나타납니다 |
| 계정 / 비밀번호 | 다운로더나 미디어 서버의 로그인 정보 | 틀리면 '연결 테스트는 통과하는데 정보 가져오기 실패'로 나타납니다 |
| 하위 스위치(작품 검색, 드라마 검색, 랭킹 수집, 메타데이터 검색) | 쓰는 만큼 켬 | 꺼두면 그 일에 참여하지 않습니다. 예: 드라마가 계속 안 잡힘 |
| 요청 간격 | 두 요청 사이에 최소한으로 비우는 밀리초 | 너무 작으면 사이트 속도 제한에 걸려 자주 시간 초과가 나거나 429가 옵니다 |
| 언어 | 받고 싶은 글의 언어. 예: `zh-CN` | 틀려도 오류는 아니고 번역을 못 받아 원문이 그대로 옵니다 |

설정 카드 오른쪽 위에는 단추가 두 개 더 있습니다.

| 단추 | 하는 일 |
| --- | --- |
| 설정 새로고침 | 저장하지 않은 변경을 버리고 저장된 값을 다시 읽습니다 |
| 설정 저장 | 화면의 모든 값을 보내고, 모두 성공해야 '저장 성공'이 뜹니다 |

:::note[저장은 과거로 거슬러 올라가지 않습니다]
저장한 설정은 **이후** 작업에만 적용됩니다. 이미 끝난 스캔이나 정보 가져오기를 다시 채워 주지 않습니다. 우선순위·언어·이미지 주소를 바꿨다면 정보 가져오기를 한 번 더 실행해 보세요.
:::

## 열쇠는 잘 간수하기

다음은 자격 증명입니다. 새면 남이 잔여량을 쓰거나 당신인 척 사이트를 이용할 수 있습니다.

- MetaTube 토큰과 각 번역 서비스 키
- TMDB 인증 코드
- TheTVDB 키와 구독 PIN
- Bangumi 인증 토큰
- ThePornDB 키와 Stash 클라이언트 키
- M-Team 패스키, 액세스 토큰, 임시 인증 코드
- 각 사이트의 사이트 토큰, 패스키, API 토큰
- IYUU, Telegram, Bark 토큰

꼭 지킬 것 몇 가지:

- 자격 증명은 내 데이터베이스에 저장되고 설정 화면에 현재 값이 다시 표시됩니다. 관리 계정과 데이터베이스 접근 권한을 좁히고, 백업 파일도 잘 보관하세요.
- 관리 화면 주소를 인터넷에 그대로 열어 두지 마세요.
- **스크린샷, 문의 글, 단체 대화, 로그에 키를 그대로 붙이지 마세요.** 새었다 싶으면 먼저 해당 사이트에서 폐기하고, 새로 발급받아 다시 붙여 넣습니다.
- 쓰지 않는 항목은 끄고 키도 비워 두는 것이 좋습니다.
- TMDB 인증이 끝나면 화면에는 계정 ID와 토큰 끝 4자리만 돌아오고 전체 토큰은 보이지 않습니다. Bangumi 토큰은 인증 후 돌아오는 주소에서 자동으로 기록되므로 손으로 옮길 필요가 없습니다.

## 문제가 생겼을 때

- **저장했는데 적용이 안 됨**: '사용 상태'와 관련 하위 스위치가 모두 켜진 채 저장됐는지 확인하세요. 둘을 동시에 켜야 하는 항목도 있습니다.
- **연결 테스트 실패**: 주소의 프로토콜과 포트를 잘못 적지 않았는지 확인합니다. Docker에서 돌린다면 `127.0.0.1`을 쓰지 마세요. 그리고 그 기기가 밖으로 나갈 수 있는지 확인합니다.
- **테스트는 통과하는데 검색이 빔**: 대개 키가 무효이거나, 잔여량이 바닥났거나, 하위 스위치가 꺼져 있거나, 검색어가 그 출처가 알아볼 수 있는 형식이 아닌 경우입니다.
- **401 또는 403**: 토큰이 만료됐거나 권한이 부족합니다. 사이트에서 새로 만드세요.
- **429 또는 잦은 시간 초과**: 속도 제한에 걸렸습니다. 요청 간격을 늘리세요.
- **그림이 안 보임**: 그림 주소가 막혀 있거나 사이트가 외부 링크를 막고 있습니다.
