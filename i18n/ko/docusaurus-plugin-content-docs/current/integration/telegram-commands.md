# Telegram으로 AMMDS 원격 조작하기

알림을 받는 것 외에도 Telegram은 리모컨이 될 수 있습니다. 휴대전화나 그룹에서 명령어를 보내 AMMDS가 영화를 검색하고, 번호를 구독하고, 미디어 라이브러리와 다운로드 작업을 보고, 스캔을 실행하고, 115에 로그인하도록 할 수 있습니다.

이 페이지에서는 봇을 연결하는 법, 자신을 바인딩하는 법, 어떤 명령어가 있는지, 무엇에 관리자 권한이 필요한지, 위험한 작업은 어떻게 확인하는지를 설명합니다.

## 먼저 봇 설정하기

1. Telegram에서 `@BotFather`를 찾아 새 봇을 만들고 **Bot Token**을 받습니다.
2. 관리자에서 '연동 앱 → 푸시 알림 → Telegram'을 열고 Bot Token을 입력한 뒤 '사용 상태'를 켭니다.
3. '시스템 설정 → 알림'에서 **푸시 알림 활성화**가 켜져 있는지 확인합니다. 이는 전체 스위치로, 꺼져 있으면 시스템이 내가 보낸 명령어를 처리하지 않아 봇이 메시지를 받기만 하고 응답하지 않습니다.
4. **Webhook을 등록하지 마세요.** 명령어는 시스템이 주기적으로 Telegram에서 메시지를 가져오는 방식에 의존합니다. Webhook을 등록하면 시스템이 가져오기를 멈춰 명령어가 응답하지 않습니다. 가정 내망 배포에는 Webhook이 원래 필요하지 않습니다.

서비스 주소는 기본값이 공식 주소이며, 직접 구축한 역프록시를 쓸 때만 바꾸면 됩니다.

## 계정 바인딩

처음 사용할 때는 시스템이 내가 누구인지 모릅니다.

1. 봇과의 개인 채팅에서 `/whoami`를 보냅니다.
2. 봇이 내 **Chat ID**, **From ID**, 닉네임, 현재 역할을 회신합니다.
3. From ID를 관리자의 '사용자 화이트리스트'에 `FromID:역할` 형식으로 입력합니다. 여러 계정은 쉼표로 구분합니다. 예:

```text
123456789:OWNER,987654321:ADMIN,555555555:GUEST
```

4. 저장한 뒤 `/whoami`를 다시 보내면 역할이 바뀌어 있습니다.

화이트리스트를 작성하지 않고 내 개인 채팅 Chat ID를 `Chat ID` 설정 항목에 바로 넣을 수도 있습니다. 개인 채팅에서는 Chat ID와 From ID가 같으며, 이 계정은 소유자(OWNER)로 취급됩니다. 그룹에서는 화이트리스트를 쓰는 것이 좋으며, 사람별로 역할을 나누면 더 명확합니다.

## 역할과 권한

역할의 등급은 높은 순서로 OWNER, ADMIN, GUEST, NONE이며, 높은 등급은 낮은 등급의 모든 명령어를 사용할 수 있습니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| OWNER(소유자) | 모든 명령어 |
| ADMIN(관리자) | 읽기 전용 명령어와 스캔, 스크레이핑, 재시작, 115 삭제, 다운로더 조작 등 |
| GUEST(게스트) | 검색, 구독, 즐겨찾기, 상태 확인, 점검 요약 등 읽기 전용이거나 일반적인 작업 |
| NONE(미바인딩) | `/start`와 `/whoami`만 사용 가능 |

### 마그넷 푸시

마그넷 링크는 검색 외에도 다운로더로 바로 보낼 수 있습니다. 이 명령어들의 차이는 '어디로 보내는가'뿐입니다.

| 명령어 | 보내는 곳 | 권한 |
| --- | --- | --- |
| `/115 <마그넷 링크>` | 115 클라우드 다운로드 | ADMIN |
| `/magnet <마그넷 링크>` | 현재 기본 다운로더 | ADMIN |
| `/qb <마그넷 링크>` | qBittorrent | ADMIN |
| `/tr <마그넷 링크>` | Transmission | ADMIN |

`/115 <마그넷 링크>`는 먼저 링크를 검증한 뒤 115 플러그인이 활성화되었는지, 인증되었는지, 바인딩되었는지를 순서대로 확인하고, 마지막으로 클라우드 다운로드의 남은 할당량을 봅니다. **할당량이 0이면 작업을 제출하지 않고 바로 거부합니다.** 성공 회신에는 작업 이름(마그넷의 `dn` 이름을 쓰고 없으면 해시 앞 8자리), 대상 '115 클라우드 다운로드', 해시 접두사, 남은 할당량만 표시됩니다. 실패하면 할당량 부족, 작업 이미 존재, 인증 만료, 생성 실패 등의 이유를 설명합니다.

`/magnet` 뒤에 마그넷 링크를 붙이면 현재 기본 다운로더로 보내고, 키워드를 붙이면 여전히 마그넷 검색을 합니다. `/qb`와 `/tr`은 각각 qBittorrent와 Transmission을 지정하며, 사용 가능한 다운로더가 없으면 관리자에서 활성화하고 설정하라고 안내합니다.

몇 가지 규칙:

- `magnet:?xt=urn:btih:` 뒤에 40자리 16진수 또는 32자리 Base32가 오는 링크만 받으며, 전체 링크는 2048자를 넘을 수 없습니다
- 같은 infohash를 60초 안에 다시 제출하면 차단되며, 방금 제출했다고 안내합니다
- 이 푸시 작업은 쓰기 작업이므로 OWNER와 ADMIN만 실행할 수 있고, 게스트는 거부됩니다

### 인증과 체험

| 명령어 | 하는 일 | 권한 |
| --- | --- | --- |
| `/license` | 인증 상태 조회: 상태, 인증 방식과 요금제, 만료 시각과 유예 마감, 현재 인스턴스 바인딩 여부, 체험 사용 여부. 미인증 시 다음 단계를 안내합니다 | GUEST |
| `/license <키>` | 라이선스 활성화 | ADMIN, 확인 필요 |
| `/license <키> replace` | 기존 라이선스가 있을 때 교체하며, 이전 인스턴스가 차지한 자리를 해제합니다 | ADMIN, 확인 필요 |

`/license`에 인수를 붙이지 않으면 읽기 전용으로 인증 상태를 바꾸지 않으며, 회신에 다음 정보가 보입니다:

- 상태와 그에 대응하는 인증 방식, 요금제, 마스킹된 키
- 만료 시각과 남은 일수. 영구 인증은 '영구'로 표시됩니다
- 현재 인스턴스의 바인딩 여부와 차지한 자리
- 체험 사용 여부와 체험 마감 시각
- 미인증일 때의 진단 코드

특히 주의해야 할 표시:

- **만료되었지만 유예 기간 중**: 만료 경고와 유예 마감 시각이 나타납니다. 유예 기간에는 계속 사용할 수 있지만 빨리 갱신해야 합니다
- **15일 이하 남음**: 이 구간에서만 '곧 만료됩니다'라고 안내합니다
- **미인증**: 관리자는 '`/license <키>`를 보내 활성화하거나 관리자에서 '시스템 설정 → 라이선스'를 이용하세요'라는 안내를 받습니다. 체험을 사용하지 않았다면 관리자에서 7일 체험을 시작할 수 있다는 안내도 붙습니다. 게스트는 관리자에게 문의하라는 설명을 받습니다

활성화는 ADMIN과 OWNER만 할 수 있습니다. `/license <키>`를 보내면 바로 적용되지 않고, 봇이 먼저 확인 카드를 회신합니다:

> 라이선스를 활성화합니다: ABC123…7890
> 확인하면 활성화 자리 1개를 차지하며, 유효 기간은 인증 서비스의 반환값을 따릅니다.

카드의 키는 **앞 6자리와 뒤 4자리만** 표시하며, 키가 10자리 미만이면 끝자리만 표시합니다. 로그에도 전체 키를 기록하지 않습니다. '✅ 활성화 확인'을 눌러야 실제로 활성화됩니다.

실패하면 이유를 바로 설명하며, 흔한 경우는 키 형식이 올바르지 않음, 라이선스가 만료·정지·취소됨, 활성화 자리가 가득 참, 라이선스 서비스가 일시적으로 사용 불가, 이전 활성화가 아직 처리 중인 경우입니다. 이미 라이선스가 있다면 `/license <키> replace`를 사용하라고 안내합니다.

## 위험 작업은 어떻게 확인하나요

아래 동작은 즉시 실행되지 않고, 봇이 '✅ 확인'과 '취소' 버튼이 있는 메시지를 먼저 회신합니다:

- `/stop`, `/restart`, `/scan`, `/scrape`
- `/system restart`, `/system stop`
- `/115_del <순번>`
- `/unsubscribe <번호>`
- `/dl pause`, `/dl del`
- `/license <키>`

'확인'을 눌러야 실행되고, '취소'를 누르면 중단됩니다. 확인 버튼은 **120초 동안만 유효**하며, 시간이 지나거나 그 확인이 다른 대화에서 이미 눌렸다면 명령어를 다시 보내야 합니다. 버튼을 누를 때 시스템이 역할을 한 번 더 확인하며, 권한이 부족하면 실행하지 않습니다.

## 바인딩되지 않은 사용자는 무엇을 보나요

화이트리스트에 없고 Chat ID도 일치하지 않는 계정은 다음 고정 안내만 받습니다:

> 현재 계정이 AMMDS에 바인딩되지 않아 이 명령어를 사용할 수 없습니다. 관리자에게 Telegram ID를 보내 바인딩을 완료하세요. /whoami를 보내면 자신의 ID를 확인할 수 있습니다.

이 외에는 `/start`와 `/whoami`만 사용할 수 있고 나머지 명령어는 모두 거부됩니다. 낯선 대화가 도배하는 것을 막기 위해 같은 사람에게 이 안내는 10분에 한 번만 보냅니다.

권한이 부족하지만 바인딩된 계정은 별도의 '권한 부족' 안내를 받으며, 내부 데이터는 전혀 노출되지 않습니다.

## 도움말과 알 수 없는 명령어도 역할에 따라 달라집니다

`/help`는 현재 역할에서 사용할 수 있는 명령어만 분류별로 나열하며, 관리 명령어를 함께 보여 주지 않습니다.

- 게스트는 `/jellyfin`, `/emby`, `/check`, `/system`, `/tasks`처럼 자신이 쓸 수 있는 명령어는 볼 수 있고, `/115_del`, `/dl pause` 같은 관리 명령어는 볼 수 없습니다
- `/help <명령어>`로 관리 명령어의 상세를 보려 하면 바로 거부됩니다
- 존재하지 않는 명령어를 보내면 '인식할 수 없는 명령어입니다'라고 회신하고 현재 사용 가능한 명령어 중 일부를 나열한 뒤, 끝에 전체 목록은 `/help`를 보라고 안내합니다

그래서 같은 `/help`라도 관리자와 게스트가 보는 항목 수가 다르며, 이는 정상입니다.

## 명령어 메뉴는 어떻게 갱신하나요

Telegram 설정 페이지에서 '명령어 등록'을 누르면 시스템이 위 표의 명령어 전체를 봇의 명령어 메뉴에 등록합니다.

- 이미 모든 명령어가 존재하면 그냥 건너뛰며, 내가 직접 추가한 같은 이름의 명령어를 덮어쓰지 않습니다
- 하나라도 빠져 있으면 전체를 다시 제출하며, 이때 내가 사용자 지정한 같은 이름의 명령어는 덮어써집니다

명령어를 추가하거나 조정한 뒤에는 다시 한 번 눌러 주세요.

## 자주 묻는 질문

| 현상 | 설명 |
| --- | --- |
| 명령어를 보내도 반응이 없음 | '사용 상태'와 '푸시 알림 활성화'가 모두 켜져 있는지 확인하세요. 그리고 Webhook 등록 여부를 확인해 등록했다면 삭제해야 폴링이 복구됩니다 |
| 계속 미바인딩이라고 나옴 | `/whoami`로 From ID를 얻어 사용자 화이트리스트에 입력하고 저장한 뒤, 명령어를 다시 보내세요 |
| 관리자 명령어가 권한 없다고 나옴 | 화이트리스트의 역할이 GUEST로 되어 있습니다. ADMIN 또는 OWNER로 바꾸세요 |
| 확인을 눌렀는데 실행되지 않음 | 120초가 지났거나 확인 버튼이 이미 사용되었습니다. 명령어를 다시 보내세요 |
| `/deepseek`이 플러그인 활성화를 안내함 | 먼저 연동 앱에서 DeepSeek를 활성화하세요 |
| `/library`에 미디어 서버가 보이지 않음 | 해당 Jellyfin / Emby가 활성화되지 않았거나 제대로 설정되지 않았습니다 |
| `/license <키>`가 권한 없다고 나옴 | 활성화는 ADMIN과 OWNER만 가능합니다. 관리자가 보내야 합니다 |
| `/license`가 기존 라이선스가 있다고 함 | 다시 바인딩하려면 `replace`를 붙여 `/license <키> replace`를 사용하세요. 이전 자리가 해제됩니다 |
| `/license`에 유예 마감이 표시됨 | 인증이 만료됐지만 유예 기간 중입니다. 빨리 갱신하세요. 유예가 끝나면 기능이 제한됩니다 |
| 마그넷 푸시가 권한 없다고 나옴 | 마그넷 푸시는 OWNER와 ADMIN만 가능하며 게스트는 검색만 할 수 있습니다 |
| `/115 <마그넷 링크>`가 할당량 부족을 안내함 | 클라우드 다운로드 남은 할당량이 0이어서 이번에는 작업을 제출하지 않습니다. 할당량이 회복되면 다시 시도하세요 |
| 푸시가 방금 제출되었다고 나옴 | 같은 infohash는 60초에 한 번만 제출할 수 있습니다. 잠시 뒤 다시 시도하세요 |
| 명령어 메뉴가 오래됨 | Telegram 설정 페이지에서 '명령어 등록'을 한 번 누르세요 |
