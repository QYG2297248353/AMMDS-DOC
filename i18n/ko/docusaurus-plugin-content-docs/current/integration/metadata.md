# 작품 정보는 어디서 오나요

표지·줄거리·출연진·태그 같은 정보는 AMMDS가 스스로 만드는 것이 아니라 외부 자료 사이트에서 가져온 것입니다. 이 페이지는 모든 출처를 나란히 놓고, 각각 무엇을 주는지, 무엇이 필요한지, 어떻게 켜는지, 그리고 여러 개를 함께 켰을 때 어떤 결과가 채택되는지 알려 줍니다.

> **메타데이터 출처**: 작품 정보를 주는 외부 사이트입니다. AMMDS가 파일 이름의 번호를 건네 물어보면 표지·줄거리·출연진 등을 돌려줍니다.

> **정보 긁어오기(스크레이핑)**: AMMDS가 자료 사이트에서 작품을 찾아 그 결과를 자기 라이브러리에 채워 넣는 과정입니다.

> **작품 번호**: 파일 이름에 들어 있는 식별 번호입니다. 예: `SSIS-001`. AMMDS는 주로 이것으로 작품을 알아봅니다.

## 같은 세 단계

무엇을 설정하든 흐름은 같습니다. 자세한 내용은 [외부 서비스 연결, 딱 세 단계](./overview.md)를 보세요.

1. **'사용 상태'를 켜고**, 필요한 하위 스위치(작품 검색, 드라마 검색 등)도 함께 켭니다.
2. 주소와 키를 채우고 **설정 저장**을 누릅니다.
3. **'연결 테스트'** 로 주소에 닿는지 확인하고, **'검색 테스트'** 로 실제로 데이터가 오는지 확인합니다.

:::warning[스위치는 둘 다]
대부분의 출처에는 '작품 검색', '드라마 검색', '메타데이터 검색' 같은 하위 스위치가 있습니다. 원 스위치만으로는 검색에 참여하지 않고, 랭킹도 모으지 않습니다.
:::

## MetaTube

MetaTube는 여러 작품 사이트와 배우 사이트를 묶은 서비스입니다. 한 번 설정으로 여러 사이트를 덮을 수 있고, 제목과 줄거리를 중국어로 옮기는 것도 함께 됩니다. AMMDS는 본체에 내장된 프로세스를 쓸 수도 있고, 직접 준비한 원격 서비스를 쓸 수도 있습니다.

| 항목 | 내용 |
| --- | --- |
| 위치 | 연동 앱 → 메타데이터 → MetaTube |
| 내장 서비스 | '내장 서비스 우선'이 켜져 있고 본체 프로세스가 돌 때 사용. 기본 대기 포트는 18080 |
| 원격 서비스 | 그 스위치를 끄거나, 내장 프로세스가 안 돌 때 사용 |
| 주는 것 | 제목, 작품 번호, 발매일, 길이, 평점, 출연진, 감독, 제작사, 레이블, 시리즈, 장르, 줄거리, 스틸. 배우의 생일·국적·키·삼위·혈액형 |
| 준비할 것 | 원격이면 주소와 토큰. 내장이면 프로그램이 없을 때 자동으로 내려받습니다 |

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 꺼두면 정보 가져오기에 참여하지 않습니다 |
| 내장 서비스 우선 | 기본 켜짐. 원격을 쓰려면 끔 | 내장 프로세스가 안 돌면 원격 주소로 돌아가 다른 실체에 붙을 수 있습니다 |
| 원격 서비스 주소 | 기본 `https://metatube.lifebus.fun`. `http(s)://` 로 시작하고 끝에 `/` 를 붙이지 않습니다 | 형식이 어긋나면 연결 테스트가 실패합니다 |
| 인증 사용 | 원격에 토큰이 있을 때만 켬 | 켰는데 토큰이 비면 원격이 거부합니다 |
| 토큰 | 원격 서비스의 토큰과 같게 | 틀리면 '연결은 되는데 결과가 빔'으로 나타납니다 |
| 우선순위 | 출처를 시도하는 순서. 앞쪽이 우선. 기본값은 `Caribbeancom,AVBASE,Pcolle,DUGA,MYWIFE,1Pondo,JAV321,FC2,TOKYO-HOT,JavBus,Getchu,fc2hub,Gcolle,HeyDouga,FALENO,FANZA,H0930,DAHLIA,H4610,HEYZO,SOD,10musume,KIN8,ThePornDBScene,C0930,AVE,PACOPACOMAMA,MGS,ThePornDBMovie,JAVFREE,CaribbeancomPR,MURAMURA`. 여러 값은 쉼표로 구분 | 찾는 사이트가 너무 뒤면 차례가 오지 않습니다 |
| 번역 사용 | 기본 꺼짐. 켜면 정보 가져올 때 제목·줄거리를 번역 | 끄면 원문 그대로 |
| 번역 서비스 | 후보 `GoogleFree,Google,OpenAI,DeepL,Baidu,Microsoft`. 저장한 것이 실제로 쓰이고 처음은 `GoogleFree` | 키가 필요한 엔진을 골랐는데 키가 비면 번역이 안 됩니다 |
| Google / DeepL / OpenAI 키와 주소 | 해당 엔진을 고르면 키는 필수. 주소는 비면 기본 주소 | 키가 없으면 번역 실패. 로그만 남고 등록은 됩니다 |
| OpenAI 모델 / 프롬프트 | 모델 이름과 번역 지시문 | 비면 서비스 쪽 판단 |
| Baidu 앱 ID / 키 | Baidu를 고르면 필수 | 없으면 번역이 안 됩니다 |

설정 카드 오른쪽 위 단추: **내장 서비스 시작**, **내장 서비스 정지**, **내장 서비스 재시작**, **설정 새로고침**, **설정 저장**. '자료 내려받기' 카드는 MetaTube 본체용이며, 없으면 시작 뒤 자동으로 내려받습니다.

:::note[연결 테스트는 원격 주소를 봅니다]
'연결 테스트'가 보는 것은 '원격 서비스 주소'이며 내장 프로세스가 아닙니다. 내장 서비스 상태는 '내장 앱 정보'로 확인합니다. 가져오기 실패가 뜨면 프로그램이 내려받아졌는지 확인하고 **내장 서비스 시작**을 누르세요.
:::

## TMDB

TMDB(The Movie Database)는 영화와 드라마의 종합 데이터베이스입니다. 연결하면 작품·배우·드라마 검색에 참여합니다.

| 항목 | 내용 |
| --- | --- |
| 위치 | 연동 앱 → 메타데이터 → TMDB |
| 주는 것 | 작품 상세, 스틸, 스태프. 배우 프로필. 드라마의 시즌과 에피소드 |
| 준비할 것 | TMDB 개발자 사이트에서 앱을 만들어 받는 인증 코드. 또는 '인증 받기'로 자동 입력 |
| 화면 | '설정 정보', '연결 테스트', '자료 검색' 세 카드 |

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 아무 검색도 안 합니다 |
| 서비스 주소 | 기본 `https://api.themoviedb.org`. 보통 바꿀 필요 없음 | 틀리면 연결이 안 됩니다 |
| 인증 코드 | TMDB의 API Read Access Token | 비거나 틀리면 키 확인이 401을 돌려줍니다 |
| 계정 ID | '계정 정보 가져오기'에 사용. 인증 성공 시 자동 입력 | 비면 계정 정보 가져오기가 실패합니다 |
| 작품 검색 | 기본 켜짐 | 끄면 작품 검색에 참여하지 않습니다 |
| 드라마 검색 | 기본 **꺼짐** | 끄면 '관련 드라마를 찾지 못했습니다'가 고정으로 돌아옵니다 |
| 배우 검색 | 기본 켜짐 | 끄면 배우 검색에 참여하지 않습니다 |
| 그림 주소 | 기본 `https://image.tmdb.org/t/p/`. 비면 자동으로 가져옴 | 주소가 막히면 그림이 안 나옵니다 |
| 그림 크기 | 기본 `original`. 그림 주소 뒤에 붙습니다 | 틀리면 그림이 404가 됩니다 |
| 검색 언어 | 기본 `zh-CN` | 틀려도 오류는 아니고 그 번역만 못 받습니다 |

### 단추와 검색

| 단추 | 하는 일 |
| --- | --- |
| 인증 받기 | TMDB 인증 화면을 열고, 동의하면 우리 사이트의 돌아오는 주소로 와서 인증 코드와 계정 ID를 자동으로 적습니다 |
| 연결 테스트 | 서비스에 닿는지 판단 |
| 키 확인 | 인증 코드가 유효한지 판단 |
| 계정 정보 가져오기 | 아바타와 계정 정보를 보여줌. 계정 ID 필요 |

검색은 탭이 셋입니다. TMDB 작품(결과를 누르면 상세와 스태프가 보이고 '담기'로 작품 라이브러리에 기록), TMDB 배우('담기'로 배우 라이브러리에), TMDB 드라마(먼저 '담기 미리보기'를 보고 '모든 시즌 담기' 또는 '이 시즌 담기'). 시즌 번호 `0`은 특별편입니다. 미리보기는 초안만 만들고 기록하지 않습니다.

## TheTVDB

TheTVDB는 드라마의 시즌과 에피소드 구성이 본령입니다. 같은 검색 창구로 영화도 찾을 수 있습니다. v4는 모두 먼저 키로 로그인해야 하므로 키가 필수입니다.

| 항목 | 내용 |
| --- | --- |
| 위치 | 연동 앱 → 메타데이터 → TheTVDB |
| 주는 것 | 드라마 기본 정보, 캐릭터와 스태프, 시즌 목록, 에피소드 목록. 영화의 포스터, 설명, 장르, 제작사, 줄거리 |
| 준비할 것 | API 키(필수). '사용자 지원형' 키는 구독 PIN도 |

### 설정 항목 설명

| 설정 항목 | 무엇을 적는지 | 비었거나 틀리면 |
| --- | --- | --- |
| 사용 상태 | 스위치를 켬 | 끄면 정보 가져오기에 참여하지 않습니다 |
| 서비스 주소 | 기본 `https://api4.thetvdb.com`. `/v4` 가 있든 없든 동작 | 틀리면 연결이 안 됩니다 |
| API 키 | 필수 | 없으면 플러그인이 쓸 수 없는 것으로 봅니다 |
| 구독 PIN | '사용자 지원형' 키만. 그 외는 비움 | 필요한데 비면 로그인 실패 |
| 언어 | 세 글자 코드. 기본 `zho`(간체 중국어). `eng` 영어, `jpn` 일본어 | 틀려도 오류는 아니고 원문으로 돌아갑니다 |
| 드라마 검색 | 기본 꺼짐. 드라마 검색 참여를 제어 | 끄면 드라마를 못 찾습니다(영화는 별도 스위치 없음) |
| 요청 간격 | 기본 `1000`밀리초. 같은 프로세스에서 TheTVDB로 가는 모든 요청이 공유 | 너무 작으면 속도 제한에 걸립니다 |

검색은 종류(드라마 또는 영화)를 고르고, 검색어·첫 방송 연도·가져올 개수(기본 10, 한 페이지 최대 50)를 넣고 '검색'을 누릅니다. '상세 보기'로 확장 정보를 읽고, '담기'로 등록합니다. 시즌 번호를 비우면 모든 시즌을 담습니다.

:::note[연결 테스트와 키 확인은 별개]
'연결 테스트'는 네트워크가 TheTVDB에 닿는지만 봅니다. 키가 무효하면 로그인은 실패합니다. 둘 다 통과해야 설정이 끝납니다.
:::

## Bangumi

Bangumi(bgm.tv)는 애니메이션 데이터베이스로, 각 화와 캐릭터·성우·스태프가 강점입니다.

| 항목 | 내용 |
| --- | --- |
| 위치 | 연동 앱 → 메타데이터 → Bangumi |
| 주는 것 | 작품 제목, 줄거리, 각 화, 캐릭터와 성우, 스태프, 관련 작품 |
| 준비할 것 | 검색과 보기에는 토큰이 필요 없음. 계정 기능은 '인증 받기' |

검색 테스트는 네 종류를 고를 수 있습니다: DMM 메타데이터(번호나 제목 검색어. 바로 담기 가능), 여배우 / 기획, 모음집, 키워드. 결과는 '표지, ID, 제목, 작품 번호, 정보, 동작'을 표로 보여주고 맞은 개수와 걸린 시간도 나옵니다. 줄을 누르면 상세 서랍이 열립니다.

:::tip[담기 단추가 나오는 때]
줄 안의 '담기'는 검색 종류가 'DMM 메타데이터'이고 그 줄에 작품 번호가 있을 때만 나옵니다. 그 밖의 종류는 상세를 열고 자료 목록에서 번호로 담으세요.
:::

## 여러 개를 함께 켰을 때의 규칙

- **우선순위**: MetaTube 안에서는 '우선순위'에 적힌 순서대로 출처를 시도합니다. 서로 다른 출처 사이에서는 정보 가져오기와 판별 규칙이 어떤 결과를 쓸지 정합니다.
- **하위 스위치가 범위를 정함**: 작품 검색, 드라마 검색, 메타데이터 검색은 각각 그 출처가 해당 종류의 검색에 참여할지 정합니다.
- **자동으로 다시 채우지는 않음**: 우선순위, 언어, 그림 주소, 스위치를 바꿔도 **이후** 작업에만 적용됩니다. 이미 등록된 작품에 새 설정을 반영하려면 정보 가져오기를 한 번 더 실행하세요.
- **번역은 덧붙임**: 제목과 줄거리의 중국어는 번역 경로가 채웁니다. 실패해도 로그에만 남고 이미 맞춘 정보에는 영향이 없습니다.

> **다시 채우기**: 새 설정을 이미 정리된 작품에 다시 적용하는 일입니다. AMMDS는 자동으로 하지 않습니다. 정보 가져오기를 한 번 더 실행하세요.

## 열쇠는 잘 간수하기

TMDB 인증 코드, TheTVDB 키와 구독 PIN, Bangumi 토큰, ThePornDB와 Stash 키, MetaTube 토큰, M-Team 패스키와 토큰은 모두 자격 증명입니다.

- 스크린샷, 문의 글, 단체 대화, 로그에 키를 그대로 붙이지 마세요.
- 새었다 싶으면 먼저 해당 사이트에서 폐기하고, 새로 발급받아 다시 붙여 넣으세요.
- 오래 쓰지 않는 출처는 끄고 키도 비워 두는 것이 좋습니다.

## 문제가 생겼을 때

- **저장했는데 정보 가져오기에 안 붙음**: '사용 상태'와 '작품 검색 / 드라마 검색 / 메타데이터 검색'이 모두 켜진 채 저장됐는지 확인하세요.
- **연결 테스트 실패**: 서비스 주소의 프로토콜과 포트를 확인합니다. 컨테이너라면 `127.0.0.1`을 쓰지 마세요. 그리고 밖으로 나갈 수 있는지 확인합니다.
- **테스트는 통과하는데 검색이 빔**: 키가 유효한지, 잔여량이 남았는지, 하위 스위치가 켜졌는지, 그리고 검색어가 그 출처가 알아볼 수 있는 형식인지 확인합니다.
- **401 또는 403**: 토큰이 만료됐거나 권한이 부족합니다. 사이트에서 새로 만드세요.
- **429 또는 잦은 시간 초과**: 속도 제한입니다. 요청 간격을 늘리세요.
- **그림이 안 나옴**: 그림 주소가 막혀 있거나 사이트가 외부 링크를 막고 있습니다.
- **어느 출처가 계속 빔**: 상대 서비스가 아무 살아 있는지 확인하세요(Madou 화면 위에는 종료 안내가 있습니다).
