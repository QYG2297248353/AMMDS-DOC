# 만화 리더로 만화 보기

AMMDS에 만화를 넣어 두면 컴퓨터 앞에 앉지 않아도 휴대전화 리더로 바로 볼 수 있습니다. 이 페이지에서는 어떤 앱을 깔고, 무엇을 적고, 잘 안 될 때 어떤 표시가 뜨는지를 설명합니다.

코드를 쓸 일은 없습니다. 'AMMDS에서 인증 코드를 발급한다' → '앱에 주소와 인증 코드를 넣는다' 두 걸음뿐입니다.

## 먼저 말부터 정리합니다

> **Mihon**: 안드로이드용 만화 리더입니다. Tachiyomi는 그 앞 세대이고 쓰임새는 거의 같습니다. 아래에서는 둘을 묶어 '리더'라고 부릅니다.

> **인증 코드**: 문자 한 줄로, 그 앱에 내주는 출입증 같은 것입니다. 앱은 만화를 가져올 때마다 이것을 함께 보냅니다.

> **인증**: 들어가기 전에 신분을 밝히는 일입니다. 리더에서는 요청에 인증 코드를 넣어 보내는 것이 여기에 해당합니다.

> **인터페이스 / API**: AMMDS가 밖으로 열어 둔 문입니다. 리더가 정해진 형식으로 묻고, AMMDS가 정해진 형식으로 답합니다.

## 어떤 앱을 깔까요

| 해야 할 일 | 방법 |
| --- | --- |
| 리더 깔기 | 휴대전화에 Mihon(또는 Tachiyomi 계열의 비슷한 앱)을 설치합니다 |
| AMMDS에 연결하기 | AMMDS가 배포하는 Mihon 확장을 설치합니다. 직접 지정한 서버를 지원하는 다른 수단을 쓴다면, 그 수단의 연결 방식을 따릅니다 |

:::note[두 종류의 증표는 섞어 쓸 수 없습니다]
리더가 쓰는 것은 **인증 코드**이고, '먼저 열쇠부터 받기'에 나오는 작품 라이브러리용 열쇠와는 다른 것입니다. 리더용 코드는 만화를 읽는 데만 쓰이고, 반대도 마찬가지입니다.
:::

## 1단계: AMMDS에서 인증 코드 발급하기

1. AMMDS 관리 화면에 로그인하고 **시스템 → 키 관리**를 엽니다.
2. 키 만들기를 선택합니다.
3. 종류는 **Mihon 확장**(`secret_mihon`)을 고릅니다.
4. 저장한 뒤 바로 인증 코드를 복사해 리더에 붙입니다.

이 인증 코드는 주소가 `/api/mihon`으로 시작하는 인터페이스에서만 쓸 수 있습니다. 다른 데는 쓸 수 없습니다.

:::note[계정과 비밀번호로도 들어갈 수 있습니다]
리더는 AMMDS 계정과 비밀번호로 로그인하는 방식도 지원합니다. 다만 받는 증표의 유효 시간은 **2시간**이고, 지나면 다시 로그인해야 합니다. 늘 쓰기에는 인증 코드가 편하고, 따로 무효로 할 수도 있습니다.
:::

## 2단계: 앱에 주소 넣기

1. 리더에서 AMMDS 확장의 설정 화면을 엽니다.
2. 서버 주소에 `http://<내 주소>:8080`을 넣습니다.
3. 인증 코드에 앞 단계에서 복사한 문자열을 붙입니다.
4. 저장한 뒤 만화 라이브러리를 한 번 새로고침해 목록이 받아지는지 확인합니다.

## 설정 항목

| 설정 항목 | 무엇을 넣나 | 넣지 않거나 잘못 넣으면 |
| --- | --- | --- |
| 서버 주소 | AMMDS가 도는 기기를 `http://<주소>:<포트>` 형태로. 포트 기본값은 `8080` | 잘못 쓰면 연결이 안 되어 목록이 뜨지 않습니다 |
| 인증 코드 | 시스템 → 키 관리에서 만들고, 종류는 반드시 **Mihon 확장** | 종류가 다르거나 지워졌으면 '권한이 없습니다'가 뜹니다 |
| 키 종류 | 만들 때 **Mihon 확장**(`secret_mihon`) 고르기 | X-API-KEY로 하면 리더에서는 매번 거절됩니다 |
| 계정과 비밀번호(선택) | AMMDS 계정과 비밀번호 | 2시간만 쓰이는 증표로 바뀝니다. 지나면 다시 로그인 |

:::warning[휴대전화와 컴퓨터가 같은 네트워크에 있어야 붙습니다]
AMMDS가 집 안 네트워크에서 돌고 있다면 휴대전화도 같은 무선 인터넷에 붙여야 합니다. 주소에는 컴퓨터의 내부망 주소를 적습니다. `127.0.0.1`은 휴대전화 자신을 뜻하므로 쓸 수 없습니다.
:::

## 붙으면 무엇을 할 수 있나요

| 앱에서의 동작 | 뒤에서 받아 오는 것 |
| --- | --- |
| 만화 라이브러리 열기 | 만화 목록. 한 페이지씩. 갱신 시각, 제목, 쪽수로 정렬할 수 있습니다 |
| 검색 | 제목, 작가, 시리즈, 분류, 태그로 찾기 |
| 한 권 열기 | 만화 상세. 작가, 줄거리, 쪽수, 화수 |
| 회차 열기 | 회차 목록. 번호가 오름차순으로 정리되어 건너뛰지 않습니다 |
| 페이지 넘기기 | 각 페이지의 그림 |
| 표지 보기 | 표지 그림. 표지가 외부 링크이면 앱이 그 주소를 바로 불러옵니다 |

## 자주 나오는 표시와 원인

| 뜨는 표시 | 흔한 원인 | 어떻게 하나 |
| --- | --- | --- |
| 권한이 없습니다 | 인증 코드 종류가 'Mihon 확장'이 아니거나 이미 지워짐 | Mihon 확장 인증 코드를 새로 만듭니다 |
| 목록이 비어 있습니다 | 만화 라이브러리에 앨범이 없거나 회차가 안 들어옴 | 먼저 AMMDS 관리 화면에서 만화를 넣습니다 |
| 표지가 안 나옵니다 | 그 만화의 표지가 외부 링크라 서버에 그림이 없음 | 정상 동작입니다. 앱이 외부 링크를 바로 불러옵니다 |
| 그림이 안 열립니다 | 회차 페이지 파일이 자료 폴더에 없음 | AMMDS 자료 폴더의 만화 파일이 온전한지 확인합니다 |
| 연결이 안 되거나 시간이 초과됩니다 | 주소나 포트가 다르거나, 휴대전화와 AMMDS가 같은 네트워크에 없음 | 먼저 브라우저에서 `http://<내 주소>:8080/api/mihon/health`를 엽니다. 열리면 주소는 맞습니다 |

## 잘 안 될 때는

- **먼저 주소만 따로 확인합니다**: 휴대전화 브라우저에서 `http://<내 주소>:8080/api/mihon/health`를 여세요. 인증 코드는 필요 없습니다. 열리면 네트워크와 주소는 문제없고 남은 것은 인증 코드뿐입니다.
- **권한이 없다고 계속 뜹니다**: 옛 인증 코드를 지우고 새로 만드세요. 종류를 'Mihon 확장'으로 하고, 복사할 때 글자를 빼먹지 않도록 합니다.
- **목록이 비었는데 분명히 라이브러리에 있습니다**: AMMDS 관리 화면에서 만화 넣기가 끝났는지, 회차까지 들어갔는지 확인하세요.
- **잠시 뒤에 다시 로그인하라고 합니다**: 계정과 비밀번호 방식을 쓰고 있습니다. 유효 시간이 2시간입니다. 인증 코드로 바꾸면 다시 묻지 않습니다.
