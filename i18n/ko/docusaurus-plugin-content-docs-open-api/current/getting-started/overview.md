# 오픈 플랫폼으로 할 수 있는 일

AMMDS에서 자료를 정리한 뒤, **다른 프로그램이 그 자료를 읽게 하고 싶을 때** 쓰는 것이 바로 '오픈 플랫폼'입니다. 휴대전화 클라이언트, 만화 리더 앱, 직접 만든 백업 스크립트, 간단한 집계 도구 같은 것들이 여기에 해당합니다.

이 페이지에서는 '어떤 선택지가 있고 각각 누구에게 맞는지'만 다룹니다. 열쇠를 만드는 법과 첫 호출은 다음 두 페이지에 있습니다.

## 먼저 말부터 정리합니다

> **인터페이스 / API**: AMMDS가 밖으로 열어 둔 문입니다. 다른 프로그램이 정해진 형식으로 묻고, AMMDS가 정해진 형식으로 답합니다. 주소 하나가 인터페이스 하나이고, 그 모음을 API라고 부릅니다.

> **요청**: 다른 프로그램이 AMMDS에게 보내는 "이걸 원한다"는 물음입니다.

> **응답**: AMMDS가 돌려보내는 답변 내용입니다.

> **JSON**: 그 답변의 형식입니다. `{"code": 200, "data": true}` 같은 모습으로, 사람도 프로그램도 읽을 수 있습니다.

> **인증**: 들어가기 전에 "이 사람은 봐도 되는 사람"이라고 신분을 밝히는 일입니다.

## 어떤 분이 쓰시나요

| 하고 싶은 일 | 쓰는 것 |
| --- | --- |
| 휴대전화 클라이언트로 작품 라이브러리 보기 | 오픈 API |
| AMMDS의 만화를 만화 리더로 읽기 | 만화 리더 |
| 자료를 정기적으로 파일로 백업하기 | 백업 패키지 |
| "몇 개나 모았는지" 세는 작은 도구를 직접 만들기 | 오픈 API |
| 두 AMMDS 사이에서 자료 옮기기 | 백업 패키지 |

보고 정리하는 것만으로 충분하다면 관리 기능 쪽만 봐도 됩니다. 이 부분은 넘어가셔도 괜찮습니다.

## 세 가지 선택지

| 선택지 | 주소 | 들어가는 방법 | 어울리는 용도 |
| --- | --- | --- | --- |
| 오픈 API | `/api/v1/**` | 헤더에 `x-api-key` | 스크립트, 자동화 도구, 외부 앱의 작품 자료 조회와 번역 |
| 만화 리더 | `/api/mihon/**` | 헤더에 `Authorization: Bearer <인증 코드>` | Mihon, Tachiyomi 같은 리더 |
| 백업 패키지 | 네트워크 주소 없이 파일 하나 | 네트워크 불필요 | 자료를 압축 파일로 내보내 다른 곳에 다시 넣기 |

외부 시스템과 연결되는 기능이 두 가지 더 있지만, 설정은 화면에서 하고 여기에는 포함되지 않습니다.

- **알림 보내기**: AMMDS가 지정한 주소로 소식을 보냅니다. 연동 앱에서 설정합니다.
- **AMMDS끼리 연결**: 서로를 연락처에 추가하고 검색을 공유합니다. 관리 기능 → 메시지 센터에서 설정합니다.

## 오픈 API로 무엇을 할 수 있나요

| 할 수 있는 일 | 주소 |
| --- | --- |
| 서비스가 살아 있는지 확인하기(열쇠 불필요) | `/api/v1/health` |
| 작품 넣기, 상세 정보, 개수, 로컬 대조, 여러 출처 검색 | `/api/v1/movie` |
| 글의 언어를 알아내고 다른 언어로 번역하기 | `/api/v1/translate` |

:::note[열쇠와 로그인은 별개입니다]
오픈 API는 열쇠만 봅니다. 브라우저 로그인 상태는 보지 않습니다. 반대로 관리 쪽 인터페이스는 로그인만 보고 열쇠는 받지 않습니다. 둘이 섞이는 일은 없고, 열쇠로 관리 권한을 얻을 수도 없습니다.
:::

## 프로그램에 들어 있는 목록

AMMDS에는 브라우저로 훑어볼 수 있는 목록이 들어 있습니다.

| 주소 | 내용 |
| --- | --- |
| `/swagger/swagger-ui.html` | 눌러서 시험해 볼 수 있는 웹 목록 |
| `/swagger/swagger-api` | 프로그램이 읽는 목록 파일 |

오픈 API, 공개 사이트, 클라이언트용이 대상이고 관리 쪽 인터페이스는 들어 있지 않습니다.

## 설정 항목

시작하기 전에 정할 것이 세 가지 있습니다.

| 설정 항목 | 무엇을 넣나 | 넣지 않거나 잘못 넣으면 |
| --- | --- | --- |
| 인스턴스 주소 | AMMDS가 도는 기기를 `http://<주소>:<포트>` 형태로. 포트 기본값은 `8080` | 잘못 쓰면 아무것도 연결되지 않고 매번 시간 초과가 납니다 |
| 오픈 API 스위치 | 시스템 → 시스템 설정에서 켭니다(설정 키 `GLOBAL_OPEN_API`) | 꺼져 있으면 올바른 열쇠라도 들여보내 주지 않습니다 |
| 열쇠 | 시스템 → 키 관리에서 만듭니다. 종류는 X-API-KEY | 만들지 않았거나 종류가 다르면 모두 거절됩니다 |

## 잘 안 될 때는

- **연결이 안 됩니다**: 브라우저에서 `http://<내 주소>:8080/api/v1/health/check`를 열어 보세요. 열리면 주소와 포트는 맞습니다. 열리지 않으면 AMMDS가 돌고 있는지, 포트가 바뀌지 않았는지 확인합니다.
- **계속 권한이 없다고 합니다**: 시스템 → 시스템 설정에서 오픈 API 스위치가 켜져 있는지, 그다음 열쇠 종류가 X-API-KEY인지 확인합니다.
- **같은 기기에서는 되는데 다른 기기에서는 안 됩니다**: 같은 기기라면 `127.0.0.1`을 씁니다. 다른 기기에서는 AMMDS 쪽의 내부망 주소를 적습니다. `127.0.0.1`은 쓸 수 없습니다.
- **내 버전에 무엇이 있는지 모르겠습니다**: 위의 두 Swagger 주소를 열어 보세요. 지금 돌리는 버전에 실제로 있는 것만 나옵니다.
