# 这个版本有什么（v1.6.84）

这一页用大白话说明 v1.6.84 相比之前多了什么、修了什么。**这是旧版本的存档文档**，如果你用的是最新版，请回到页面右上角的版本下拉框切换到「最新版」。

## 新增了什么

### 可以多查一个影视资料库（TMDB）

TMDB 是一个公开的影视资料网站。接上它之后，AMMDS 能按影片编号去查片名、简介、演员、海报，并把查到的内容自动填进你的媒体库。

在「集成 → TMDB」里打开开关、填上网站给的授权码就能用，页面上还有「测试」按钮，可以先确认填得对不对。

> **授权码**：网站发给你的一串字符，用来证明「是你在查」。在 TMDB 网站注册后就能拿到，不需要懂技术。

### 已整理好的影片可以只补缺，不用重来

以前的整理任务会把文件重新排一遍。这个版本新增了「查漏补缺」模式：

- 文件夹名字、文件名**一个都不动**；
- 只补齐缺的封面、背景图、剧照，以及记录影片信息的小文件；
- 已经有图的地方，只在新图更清楚时才换掉，不会用差图盖掉好图；
- 已经有影片信息文件的，只补缺的字段，你手改过的内容会保留。

> **影片信息文件（NFO）**：和影片放在一起的一个小文本文件，Emby、Jellyfin 这类播放器靠它显示片名、演员、简介。你不用自己打开它。

### 给其他程序用的接口变多了

新增了标签、演员、资讯、小说、在线搜索、系统检查等对外接口。如果你只是正常使用网页或手机客户端，这一条可以跳过。

## 修了什么

- 免安装 Java 的单文件版（Windows / Linux 直接运行的那个）里，有些页面会显示空白或只剩 `{}`，这个版本修好了。
- 顺手清理了一批用不到的旧文件，程序体积更小。

## 这个版本能从哪里装

| 设备 | 方式 |
| --- | --- |
| 飞牛 FnOS | 应用商店的离线安装包 |
| Windows 10 / 11 | Windows 离线安装包（AMMDS Launcher） |
| 威联通 QNAP | 应用中心离线安装包 |
| 通用 Docker | 镜像照常更新 |

## 升级要注意什么

- 这个版本**没有改动数据格式**，按平时的升级方式替换程序即可，原来的媒体库、账号、配置都还在。
- 升级后建议打开「系统 → 系统检查」看一眼，确认各项状态正常。
- 如果页面看起来还是旧样子，按 `Ctrl` + `F5` 强制刷新一次浏览器。
