# 开放平台能做什么

你在 AMMDS 里把资料整理好之后，如果还想让**别的程序**来读这些资料——手机上的客户端、漫画阅读器 App、自己写的备份脚本、统计小工具——就要用到「开放平台」。

这一页只讲「一共有哪些能力、分别适合谁」。怎么拿钥匙、怎么发第一次请求，看后面两页。

## 先说清楚

> **接口 / API**：AMMDS 对外开的一扇门。别的程序按固定格式问一句，AMMDS 就按固定格式答一句。一个地址就是一个接口，一串这样的接口叫 API。

> **请求**：别的程序发给 AMMDS 的那句「问话」，内容就是「我要什么」。

> **响应**：AMMDS 听完问话之后，回答回来的内容。

> **JSON**：回答内容的排版格式，样子像 `{"code": 200, "data": true}`，人能看懂，程序也能直接读。

> **鉴权**：进门之前先亮一下身份，证明「这个人有权看这些资料」。

## 什么样的人需要它

| 你想做的事 | 用哪一种 |
| --- | --- |
| 在手机客户端上翻自己的影片库 | 开放接口 |
| 用漫画阅读器 App 看 AMMDS 里的漫画 | 漫画阅读器 |
| 定时把资料自动备份成一个文件 | 备份包 |
| 自己写个小工具，统计「我一共存了多少部」 | 开放接口 |
| 把两台 AMMDS 的资料搬来搬去 | 备份包 |

如果你只是想看片、整理文件、刮削资料，后台功能那几栏就够用了，这一块可以先跳过。

## 三种能力

| 能力 | 入口地址 | 进门方式 | 适合什么 |
| --- | --- | --- | --- |
| 开放接口 | `/api/v1/**` | 请求头里带 `x-api-key` | 脚本、自动化工具、第三方程序读影片资料和调用翻译 |
| 漫画阅读器 | `/api/mihon/**` | 请求头里带 `Authorization: Bearer <授权码>` | Mihon、Tachiyomi 这类漫画 App |
| 备份包 | 没有网络地址，就是一个文件 | 不用联网 | 把资料导出成压缩包，再导入到别处 |

另外还有两件跟外部系统有关的事，入口在软件界面上，不在这一块：

- **消息推送**：AMMDS 主动往你填的地址发消息，在「集成应用」里配。
- **两台 AMMDS 互通**：互相加好友、共享检索，在「后台功能 → 消息中心」里配。

## 开放接口能读什么

| 能做的事 | 地址 |
| --- | --- |
| 看看服务还活着吗（不用钥匙） | `/api/v1/health` |
| 影片的导入、详情、总数、本地匹配、多来源检索 | `/api/v1/movie` |
| 判断一段文字是什么语言、把它翻译成别的语言 | `/api/v1/translate` |

:::note[钥匙和登录是两回事]
开放接口只认钥匙，不认你在网页上的登录状态；反过来，后台管理接口只认登录状态，不认钥匙。两者不会互相串，一把钥匙拿不到管理权限。
:::

## 本机自带的接口清单

AMMDS 自己带了一份能在浏览器里翻的接口清单：

| 地址 | 里面是什么 |
| --- | --- |
| `/swagger/swagger-ui.html` | 可以直接点着试的网页版清单 |
| `/swagger/swagger-api` | 给程序读的清单文件 |

这份清单只收开放接口、前台站点和客户端接口，不含后台管理接口。

## 设置项说明

开始前要先确定这三样东西：

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 实例地址 | AMMDS 那台机器的地址，写成 `http://<地址>:<端口>`，端口默认是 `8080` | 填错就完全连不上，每次调用都会卡到超时 |
| 开放接口开关 | 在「系统 → 系统配置」里打开（配置键 `GLOBAL_OPEN_API`） | 不开的话，钥匙就算是对的也会被挡在门外 |
| 钥匙 | 在「系统 → 密钥管理」里创建，类型选 X-API-KEY | 没创建、或类型选错，调用一律被拒 |

## 出问题了怎么办

- **连不上**：先在浏览器里打开 `http://<你的地址>:8080/api/v1/health/check`。打得开说明地址和端口没错；打不开就先确认 AMMDS 正在运行、端口有没有被改过。
- **一直提示没权限**：先去「系统 → 系统配置」确认开放接口开关是打开的，再确认钥匙类型选的是 X-API-KEY。
- **在本机能连，别的机器连不上**：同一台机器上用 `127.0.0.1`；从别的机器访问要填 AMMDS 那台机器的局域网地址，不能填 `127.0.0.1`。
- **不知道自己这个版本有哪些接口**：打开上面那两个 Swagger 地址，里面是你当前版本真实存在的清单。
