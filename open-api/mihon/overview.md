# 用漫画阅读器看你的漫画

AMMDS 里存了漫画之后，可以不在电脑上看，而是用手机上的漫画 App 直接翻。这一页讲装哪个 App、在里面填什么、填错了会看到什么提示。

整个过程不用写任何代码，就是「在 AMMDS 里拿一个授权码 → 在 App 里填地址和授权码」两步。

## 先说清楚

> **Mihon**：一款安卓上的漫画阅读 App，Tachiyomi 是它的前身，两者用法基本一致。下面统称「阅读器」。

> **授权码**：一串字符，相当于你给这个 App 办的门禁卡。App 每次来取漫画都要带上它。

> **鉴权**：进门之前先亮身份。阅读器这边就是把授权码放进请求里一起发出去。

> **接口 / API**：AMMDS 对外开的一扇门。阅读器按固定格式问一句，AMMDS 就按固定格式答一句。

## 装哪个 App

| 你要做的事 | 怎么做 |
| --- | --- |
| 装阅读器 | 在手机上安装 Mihon（或 Tachiyomi 一类同款 App） |
| 让它能连 AMMDS | 安装 AMMDS 提供的 Mihon 扩展；如果你用的是支持自定义服务器的替代方案，用那套方案自带的连接方式也可以 |

:::note[两套钥匙不能混用]
阅读器用的是**授权码**，跟「开放平台 → 先拿一把钥匙」里那把开影片库的钥匙不是一回事。给阅读器的授权码只能用来读漫画，反过来也一样。
:::

## 第一步：在 AMMDS 里拿授权码

1. 登录 AMMDS 后台，进入 **系统 → 密钥管理**。
2. 点创建密钥。
3. 类型选 **Mihon 扩展**（`secret_mihon`）。
4. 保存后立刻复制授权码，填到阅读器里。

这个授权码只能用在地址以 `/api/mihon` 开头的那一套接口上，不能拿去调用别的接口。

:::note[也可以用账号密码登录]
阅读器还支持用 AMMDS 的账号密码登录，换来的凭证有效期是 **2 小时**，过期要重新登录。长期用还是授权码省事，而且授权码可以单独作废。
:::

## 第二步：在 App 里填地址

1. 打开阅读器里 AMMDS 扩展的设置页。
2. 服务器地址填 `http://<你的地址>:8080`。
3. 授权码填上一步复制的那一串。
4. 保存之后先刷新一次漫画库，确认能拉到列表。

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 服务器地址 | AMMDS 那台机器的地址，写成 `http://<地址>:<端口>`，端口默认 `8080` | 填错就一直连不上，列表拉不出来 |
| 授权码 | 在「系统 → 密钥管理」创建，类型必须是 **Mihon 扩展** | 类型选错或已删除，App 会提示未授权 |
| 密钥类型 | 创建时选 **Mihon 扩展**（`secret_mihon`） | 选成 X-API-KEY 的话，阅读器这边一律进不去 |
| 账号密码（可选） | 你的 AMMDS 账号和密码 | 用来换一张 2 小时有效的临时凭证，过期要重登 |

:::warning[手机和电脑不在同一个网络就连不上]
AMMDS 装在家庭局域网里时，手机要连同一个 Wi-Fi，地址要填电脑的局域网地址，不能填 `127.0.0.1`（那个指的是手机自己）。
:::

## 连上之后能做什么

| App 里的动作 | 背后取的是什么 |
| --- | --- |
| 打开漫画库 | 漫画列表，一次一页，可以按更新时间、标题、页数排序 |
| 搜索 | 按标题、作者、系列、分类、标签匹配 |
| 点进一本 | 漫画详情，含作者、简介、页数、章节数 |
| 看章节 | 章节列表，章节序号从小到大排好，不会跳章 |
| 翻页看图 | 每一页的图片 |
| 看封面 | 封面图；封面本身是外链地址时，App 会直接加载那个地址 |

## 常见报错对照

| 你看到的现象 | 通常是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示未授权 | 授权码类型不是「Mihon 扩展」，或者已经被删掉了 | 重新创建一条 Mihon 扩展类型的授权码 |
| 列表是空的 | 漫画库里还没有相册，或者章节没导入 | 先在 AMMDS 后台把漫画导入进来 |
| 封面不显示 | 这本漫画的封面是外链地址，服务器本地没有这张图 | 属于正常行为，App 会直接加载外链 |
| 图片打不开 | 章节页的文件在数据目录里缺失 | 检查 AMMDS 数据目录里的漫画文件是否完整 |
| 连不上 / 超时 | 地址或端口填错，或者手机和 AMMDS 不在同一个网络 | 用浏览器先打开 `http://<你的地址>:8080/api/mihon/health`，能打开说明地址对 |

## 出问题了怎么办

- **先单独验一次地址**：在手机浏览器里打开 `http://<你的地址>:8080/api/mihon/health`。这个地址不用授权码，能打开就说明网络和地址都没问题，剩下的就是授权码的事。
- **一直提示未授权**：删掉旧授权码重新建一条，注意类型选「Mihon 扩展」，复制时不要漏字符。
- **列表空但库里明明有漫画**：确认漫画已经在 AMMDS 后台导入完成，并且章节也在。
- **过一段时间就要重登**：你用的是账号密码方式，凭证只有 2 小时。改成授权码就不用反复登录了。
