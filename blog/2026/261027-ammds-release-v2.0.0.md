# 发布 AMMDS v2.0.0 — 商城收口、连通性诊断与文档重写

v2.0.0 是一次「收口」性质的版本：商城从可编辑后台收敛为只读官方商城，仪表盘补上网络连通性诊断，M-Team 的搜索测试补全了「看详情、再入库」的闭环，同时把列表页的典型 N+1 查询做了批量化改造。文档也在这个版本完成整体重写。

{/* truncate */}

## 商城：从管理后台到只读官方商城

此前商城模块带着商品管理、Webhook 等自建能力，实际使用率很低，还带来一套需要长期维护的写入链路。v2.0 起商城定位为**只读的官方商城入口**：

- 商品、分类、变体数据来自官方商城服务，本地不再维护商品编辑
- 保留购物车、结算、订单、地址与售后等购买链路
- 移除商品管理与 Webhook 写入能力，减少配置面与出错面

如果你此前在本地维护过商品，升级后这些入口会消失，属预期变更。

## 仪表盘：网络连通性诊断

仪表盘的「网络信息」卡片新增 **连通性** 标签页，把「后端到底能不能访问这些站点」从猜测变成一张清单：

- 覆盖后端实际使用的全部公共域名，按元数据源、站点索引、通知、AI 与翻译、基础设施、DNS 分组
- 按表格顺序逐行检测，每行实时回显可访问性与耗时
- 判定标准是「后端能否拿到 HTTP 响应」：401/403/404 同样算可访问，只有解析失败、超时、连接重置、TLS 失败才算不可访问

详细说明见[网络与连通性](/docs/dashboard/network)。

## M-Team 搜索测试：检索 → 详情 → 导入

M-Team 插件的搜索测试模块补全了详情能力：

- 结果列表支持点击任意行查看详情
- DMM 元数据详情展示番号、发行日期、时长、评分、制作商、厂牌、系列、导演、女优、类型、简介与剧照
- 女优 / 企划与合集详情支持加载关联种子，并可直接导入绑定了 DMM 番号的种子
- 详情抽屉内可直接完成「导入影视库」

## 性能：把 N+1 收敛成常数次查询

后台影视列表此前会对每一行分别查询「番号库是否已完成」与「是否已订阅」，一页 20 行就是 40 次数据库往返。v2.0 改为按页批量预取，两次查询覆盖整页：

- 影视列表：2N 次查询 → 2 次
- 影视详情：演员回查改为一次 `IN` 查询
- 存储统计：由「加载全表再累加」改为数据库侧 `SUM`
- 单条影视的订阅判断：由逐识别码查询改为一次集合计数
- 工作台网络信息：IPv4/IPv6 并行探测，并增加 5 分钟缓存

## 文档：整体重写

文档站新增为项目子模块，并按「功能路由」重组：

- **指南**按应用主路由划分：快速开始、仪表盘、媒体库、订阅与下载、任务与自动化、插件集成、信息中心、工具箱、系统管理、账号与商城、常见问题
- 每个根路由下的子路由最多三层，与界面菜单一一对应
- **开发平台**重写为「接入指南 + 接口参考 + Mihon 阅读器 + 备份包规范」
- 主页文档补齐能力边界与阅读路径

:::note[文档原则]
文档只描述当前版本已实现的能力。找不到文档里提到的入口时，先核对版本号。

## 升级提示

- 本次不涉及数据格式变更，按常规方式替换程序即可
- 商城入口变化见上文，不再提供本地商品管理
- 建议升级后打开 **系统 → 系统检查** 与仪表的连通性页各跑一次，确认插件与网络状态
