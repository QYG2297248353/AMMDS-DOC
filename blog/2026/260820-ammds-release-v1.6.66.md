# 发布 AMMDS v1.6.66 — DeepSeek 大模型集成与系统维护增强

紧接 v1.6.64 的 VibeVoice 字幕能力，AMMDS v1.6.66 将“智能化”进一步推向纵深。本版本接入了 DeepSeek 大模型，让 AMMDS 拥有了 AI 对话助手与知识库增强能力；同时完善了字幕翻译、封面裁剪、StashBox 检索、系统检查与运行日志导出等系统级功能，全面提升了平台的可维护性。

## 新功能与改进

### DeepSeek 大模型集成

新增 DeepSeek 大模型插件完整集成，通过 OpenAI 兼容的对话接口（`POST /v1/chat/completions`）接入 DeepSeek 服务，为 AMMDS 提供 AI 对话能力。旧模型 `deepseek-chat` / `deepseek-reasoner` 已废弃，由服务层自动映射为新模型。

入口：**集成 → DeepSeek**

集成页面新增以下展示卡片：

- **账户余额卡片**：展示当前账户余额信息，支持手动刷新
- **模型列表卡片**：展示 DeepSeek 可用模型列表
- **连接测试**：提供一键测试连接能力

**会话管理特性**：

- 模型映射：旧模型自动映射为新模型，配置无需手动调整
- 并发隔离：多用户会话并发隔离，互不干扰
- 错误码友好提示：异常类统一封装错误码，提供友好提示
- 动态系统提示词：会话管理器支持动态系统提示词，可加载本地知识库

### 知识库系统与对话增强

新增 AMMDS 知识库系统，加载本地知识库语料增强 DeepSeek 系统提示词，使 AI 对话更了解 AMMDS 项目本身的功能与使用方式。

- 会话初始化时从知识库服务加载 AMMDS 知识库语料
- 将知识库内容拼接到系统提示词，增强 AI 对 AMMDS 功能的理解
- 项目文档已更新为标准 AI 语料格式，便于知识库加载与 AI 理解

这意味着你在 AMMDS 中向 DeepSeek 提问时，AI 已经“读过”了 AMMDS 的功能文档，能更准确地回答关于插件配置、刮削流程、部署方式等问题，而无需自行检索资料。

### 字幕翻译功能

在 VibeVoice 字幕生成基础上新增字幕翻译功能，支持基于已有字幕任务创建翻译任务，生成双语字幕。

新增 `TRANSLATING`（翻译中）字幕任务状态，完善任务状态展示：

| 状态 | 说明 |
|---|---|
| 等待中 | 等待执行（并发槽位不足） |
| 排队中 | 超出最大并发任务数，等待空闲槽位 |
| 进行中 | 正在识别 |
| 翻译中 | 翻译任务：基于源字幕文件进行翻译 |
| 已完成 | 字幕生成成功 |
| 失败 | 识别失败 |
| 已取消 | 用户手动取消 |

同时完善了 SRT 工具类，支持更宽容的字幕文件解析，提升对非标准 SRT 文件的兼容性；优化了异步刮削任务调度与 Future 管理逻辑，修复了取消竞态与清理规则，避免任务取消后资源泄漏。

### 封面裁剪工具箱

新增可视化封面裁剪工具箱，支持本地图片裁剪和服务器图片批量生成裁剪副本，并可在媒体编辑页面快速裁剪封面。

入口：**工具箱 → 封面裁剪 / 媒体编辑 → 封面裁剪**

主要能力：

- 通用裁剪弹窗组件，可在多处复用
- 工具箱图片裁剪页面替换原有裁剪面板为弹窗组件
- 媒体编辑页面新增封面快速裁剪入口
- 影视编辑页面新增海报、缩略图等图片的上下移动排序功能

针对裁剪选框错位问题进行了重构修复：

| 问题 | 修复方案 |
|---|---|
| 裁剪选框错位 | 使用 `offsetWidth` 替代 `getBoundingClientRect`，避免动画缩放导致选框错位 |
| 裁剪框定位偏差 | 新增图片舞台偏移计算，修正裁剪框定位 |
| 跨来源裁剪结果残留 | 新增窗口 resize 监听和组件卸载时的资源清理 |
| 本地/服务器图片选择 | 重构页面，新增双预览区域和裁剪结果展示 |

### StashBox 检索拓展

为 ThePornDB 插件新增 StashBox 影视/演员详情检索接口，扩展元数据检索来源。入口位于 **集成 → ThePornDB**，让 ThePornDB 不仅能从其自身数据库获取元数据，也能通过 StashBox 检索更丰富的影视与演员信息。

### 系统检查功能

新增系统检查功能，包含后端服务、前端页面与 API 接口，可扫描系统基础配置、软件依赖、运行状态等项目并生成检查报告，便于快速定位系统问题。

入口：**系统 → 系统检查**

检查项覆盖：

- 系统基础配置
- 软件依赖
- 运行状态
- 网络连通性（多 URL 多角度探测）

扫描进度优化：新增 `scanDone` 状态与扫描完成文案，扫描进度最小保底时长从 5s 调整为 8s，避免扫描过快闪烁；网络检查重构为多 URL 多角度探测，提升连通性判断准确性。

### 运行日志导出功能

完成运行日志导出功能，支持按时间范围导出运行日志，自动聚合滚动日志并处理大小上限。

入口：**系统 → 运行日志**

| 特性 | 说明 |
|---|---|
| 时间范围 | 支持 1/7/30 天范围导出，参数范围 1~90 天 |
| 日志聚合 | 自动聚合指定时间范围内的主日志与滚动日志文件，按日期升序拼接 |
| 文件命名 | `ammds-logs-{起始日期}-{结束日期}.log` |
| 大小上限 | 导出大小上限 100MB，超出时截断最旧部分，保留最新日志 |
| 单文件截断 | 单个日志文件超过剩余配额时，仅读取最新部分 |
| 编码格式 | UTF-8 编码，`text/plain` 类型 |

导出文件包含元信息头（导出时间、时间范围、文件数量）与各日志文件内容，方便排查与归档。

### Telegram 与 Markdown 工具增强

- 为 Telegram 消息仓库新增无指令未回复查询方法
- 重构 Telegram 通知发送逻辑，增加 Markdown 降级处理
- 修复 MarkdownV2 转义逻辑，移除重复转义
- 新增磁力链接提取工具类 `MagnetUtils`
- 新增 `MarkdownV2Utils` 工具类，补充全量测试用例

### 系统优雅停止

新增系统服务 `stop` 异步停止接口，实现优雅关机流程，避免强制终止时任务与资源未正常释放。

## 配置项说明

DeepSeek 集成支持以下配置项（保存在系统配置表中）：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用状态 | `false` | 是否启用 DeepSeek 插件 |
| 服务地址 | `https://api.deepseek.com` | DeepSeek API 服务地址 |
| API Key | (空) | 鉴权 API Key |
| 推理模型 | `deepseek-v4-pro,deepseek-v4-flash,deepseek-chat,deepseek-reasoner` | 推理模型，旧模型自动映射 |
| 模型温度 | `0.7` | 模型温度 |
| 上下文长度 | `1M` | 上下文长度 |
| 输出长度 | `384K` | 输出长度 |

模型与配置自动迁移：新增 `deepseek-v4-flash`、`deepseek-v4-pro` 模型选项，旧模型由服务层自动映射，完成 DeepSeek 配置自动迁移，兼容旧版模型参数。

## 测试与质量保障

本版本新增了大量单元测试保障逻辑正确性，覆盖知识库服务、DeepSeek 会话管理与服务、请求模板、磁力链接与 MarkdownV2 工具、通知 Markdown 序列化、JSON 转义、异步刮削 Future 管理、字幕流程与服务、元数据服务、SRT 工具等多个模块，显著提升了核心链路的稳定性。

## 升级指南

### Docker 部署

```bash
# 拉取最新镜像
docker pull ghcr.io/mengshou/ammds:latest  # 国内用户可替换为 qyg2297248353/ammds:latest（Docker Hub）

# 重新启动容器
docker compose down
docker compose up -d
```

### 注意事项

1. 启用 DeepSeek 需先在 [DeepSeek 平台](https://platform.deepseek.com) 获取 API Key，并在集成页面填入
2. 字幕翻译功能依赖 AMMDS 既有的翻译服务集成，请先在翻译模块中配置至少一种翻译引擎
3. 系统检查与运行日志导出为只读与导出能力，不影响既有业务运行，可放心使用

## 已知问题

- DeepSeek 远程调用受 API 速率限制影响，高并发场景下建议适当降低并发任务数
- 运行日志导出超大文件时浏览器可能短暂卡顿，建议按时间范围分批导出
