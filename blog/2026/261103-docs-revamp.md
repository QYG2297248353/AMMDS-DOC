# 文档站改版：按你要做的事重新组织，看得懂才配叫说明书

这次文档整体重写了一遍：结构按「你要完成什么事」重新组织，语言全面去术语化，四种语言同步更新，版本只保留 v1.6.84 和最新版。这篇文章说明改了什么、旧习惯去哪找。

{/* truncate */}

## 改了什么

**结构**：原来的三十多个插件页面合并成按用途分类的七章（资料来源、找资源、下载、播放器、通知、小工具），后台功能跟着界面菜单走，一个页面讲一整块，不用再在几十个页面里来回跳。

**语言**：所有页面重写为面向普通用户的写法——每一页开头都告诉你「这页帮你做什么」，步骤一步步列出来，凡是要你填东西的地方都附「设置项说明」表，说清楚要填什么、不填会怎样。看不懂的词集中收进了新的《看不懂的词，这里都有》词表。

**新页面**：

- 《十分钟整理好第一批影片》：从刚装好到看到有封面有简介的媒体库，端到端走一遍；
- 《想改端口、上传大小？看这张表》：所有启动设置项一张表查完；
- 《看不懂的词，这里都有》：四十多个词的大白话对照表。

**多语言**：英文、日文、韩文翻译与中文同步补齐，包括最新版全部指南与开放平台文档——此前最新版翻译是缺失的。

**版本**：版本下拉框只保留 **v1.6.84** 和**最新版**。v1.6.84 是上一个稳定版的存档文档，附带一页白话版《这个版本有什么》。更早的历史版本文档已下线。

## 旧的链接还能用吗

大部分旧主题都还在，只是换了位置：

| 你以前看的 | 现在去哪 |
| --- | --- |
| 各插件的单独页面 | 集成应用 → 对应分类页（每个插件都有小节和设置项表） |
| 部署 / 环境变量 | 快速开始 → 先选一种安装方式、想改端口看那张表 |
| 系统配置各分区 | 后台功能 → 系统管理 → 系统设置项逐条说明 |
| 任务配置 / 记录 | 后台功能 → 任务（扫描、刮削、定时与记录） |
| 前台各库页面 | 前台站点 → 浏览影片、剧集、演员与漫画小说 |

搜索框仍然可用，输入关键词是最快的找法。

## 一句话原则

文档只描述当前版本已经实现的功能，用你能在界面上找到的名字。找不到文档里提到的入口，先核对版本号；确认没有，欢迎反馈，我们会修文档或修问题。
