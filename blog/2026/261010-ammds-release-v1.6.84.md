# 发布 AMMDS v1.6.84 — TMDB 资料源与「查漏补缺」整理

v1.6.84 带来两个实用更新：可以接入 TMDB 这个公开影视资料库，以及新增只补缺、不动文件的「查漏补缺」整理模式。另外修复了单文件版部分页面显示空白的问题。

## 新增：TMDB 资料源

TMDB 是一个公开的影视资料网站，片名、简介、演员、海报都齐全。接上之后，AMMDS 会按影片编号自动去查，把查到的内容填进你的媒体库：

- 在「集成 → TMDB」打开开关、填上授权码就能用；
- 页面上有「测试」按钮，能先确认填得对不对；
- 影片搜索和演员搜索可以分别开关，不想用哪个就关哪个。

> **授权码**：网站发给你的一串字符，用来证明「是你在查」。在 TMDB 网站注册后就能拿到，不需要懂技术。

## 新增：「查漏补缺」整理模式

以前想补齐缺的封面和资料，得让整理任务把整个目录重排一遍。现在多了一个选择：

- 文件夹名、文件名**一个都不动**；
- 只补缺失的封面、背景图、剧照和影片信息文件；
- 已有图片只在找到更清楚的版本时才替换，不会用差图盖好图；
- 已有的信息文件只补缺的字段，你手动改过的内容会保留。

这个模式特别适合「媒体库已经整理得差不多，只想把漏网的补上」的场景。

> **影片信息文件（NFO）**：和影片放在一起的小文本文件，Jellyfin、Emby 这类播放器靠它显示片名、演员、简介。你不需要自己打开它。

## 修复与优化

- 修复了 GraalVM Native Image 打包的单文件二进制版（免装 Java，Windows / Linux 直接运行）里部分页面空白或只显示 `{}` 的问题；
- 新增一批供其它程序使用的公开接口（标签、演员、资讯、小说、在线搜索、系统检查）；
- 清理了一批不再使用的旧文件，程序更轻了。

## 这个版本能从哪里装

| 设备 | 方式 |
| --- | --- |
| 飞牛 FnOS | 应用商店离线安装包 |
| Windows 10 / 11 | Windows 离线安装包（AMMDS Launcher） |
| 威联通 QNAP | 应用中心离线安装包 |
| Docker | 照常更新镜像 |

## 升级提示

- 本版本**没有数据格式变更**，按平时的方式替换程序即可，媒体库、账号、配置都会保留；
- 升级后建议打开「系统 → 系统检查」看一眼各项状态；
- 页面看起来还是旧样子时，按 `Ctrl` + `F5` 强制刷新一次浏览器。
