# 名词说明

AMMDS 的文档和界面里有不少词不太好懂。这一页分成六类，每个词都用大白话说一遍，告诉你在哪儿会碰到它。凡是要你填的东西，解释里也会写明填错了会有什么后果。

碰到生词，先在这一页按 `Ctrl` + `F` 搜一下；还是不明白的，可以去[常见问题](./faq.md)看看有没有对应的解决办法。

## 一、安装与运行

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| Docker | 一种把软件连同它需要的环境打包在一起的运行方式。装好 Docker 之后，拉一个包就能跑，不用自己在电脑上一件件装依赖。设备不支持 Docker 就换别的方式装。 | 安装方式对比、用 Docker 安装 |
| 镜像 | 软件的打包文件，相当于「安装盘」。名字写成 `qyg2297248353/ammds:latest` 这样，冒号后面是版本标签。**填错了会怎样**：标签写错会拉到别的版本，或者根本拉不下来，容器起不来。 | 拉取镜像、升级步骤 |
| 容器 | 镜像跑起来之后的那一份运行实例。删掉容器不会删掉你挂载出去的数据目录。 | 启动命令、目录挂载 |
| 挂载 | 把主机上一个真实目录接到容器内部，让容器能读写它，写法是「主机目录:容器内目录」。**填错了会怎样**：没挂或路径写错，程序找不到你的影片文件；数据目录没挂，删容器就等于删数据。 | Docker 命令里的 `-v`、目录挂载表 |
| 二进制程序 | 也叫可执行文件，是 AMMDS 发行包里那个可以直接运行的程序文件。Windows 上是 `.exe` 结尾，Linux 上没有扩展名。**填错了会怎样**：下错系统的包会提示无法执行，Windows 和 Linux 不通用。 | 在 Windows / Linux 上直接运行、升级步骤 |
| GraalVM Native Image | 一种打包方式：把程序提前编译成一个独立的可执行文件。好处是运行时不用装 Java，双击或输一行命令就能启动，启动也更快。你不需要懂原理，记住「不用装 Java」就够了。 | 安装方式对比、排障 |
| JAR / WAR | Java 程序常见的两种打包格式。**AMMDS 的发行包不提供这类文件**，也不需要 Java 环境；网上看到的 `java -jar` 教程是自己编译源码时才用的，拿来装 AMMDS 用不上。 | 旧教程、开发者资料 |
| NAS | 专门用来存文件的网络设备，例如飞牛 FnOS、威联通 QNAP。可以装应用包，也可以跑 Docker。 | 在 NAS 上安装、目录规划 |
| 环境变量 | 启动前写给程序的一组设置，比如端口、上传大小。Docker 里写在配置文件的 `environment` 段，直接运行时写在可执行文件的启动命令前面。**填错了会怎样**：名字写错等于没设置，程序按默认值跑；值写错可能导致页面打不开、上传被拒。改完必须重启才生效。 | 设置项表格、启动命令 |
| 端口 | 一台机器上区分不同服务的号码。`http://主机IP:8080` 里的 8080 就是端口。**填错了会怎样**：改了端口就要用新端口访问，否则打不开；端口被别的程序占用时启动失败。 | 访问地址、端口映射表 |
| 路径 | 文件或目录在磁盘上的位置，例如 `/mnt/media`、`C:\AMMDS`。**填错了会怎样**：路径写错就扫描不到文件，或者数据被写到别的地方，看起来像「数据不见了」。 | 媒体目录、数据目录 |
| 代理 | 让程序的联网请求先经过另一台服务器再出去。访问境外站点不稳时会用到，可选 HTTP 或 SOCKS。**填错了会怎样**：地址或端口填错会大面积连不上网；内网地址没加进「免代理」名单，会导致 NAS、播放器这类内网服务连不上；SOCKS 不支持填账号密码。 | 系统配置 → 网络配置 |

## 二、文件与目录

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| 扫描 | 让 AMMDS 去你指定的目录里翻一遍文件，认出里面有哪些影片。 | 扫描任务、快速开始教程 |
| 任务 | 一次具体的操作记录，比如一次扫描、一次刮削。可以在任务记录里看进度、结果和失败原因。 | 任务页面、任务日志 |
| 定时任务 | 按你设定的时间自动跑的任务，例如每天自动扫描一次。**填错了会怎样**：时间写错不会报错，只是跑的时机不对；把定时任务总开关关掉后，连手动执行也会被拒绝。 | 定时任务、调度开关 |
| NFO | 放在影片旁边的小文本文件，记录这部片子的资料，播放器可以直接读取它。 | 扫描的整理模式、「查漏补缺」 |
| 封面 | 影片列表里那张小图，一眼认片子用。 | 影片列表、媒体库 |
| 海报 | 竖着的那张大图，就是海报墙上那一张。 | 详情页、海报墙 |
| 剧照 | 影片里的截图，一部片子通常有多张。 | 详情页的图集 |

## 三、影片资料

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| 刮削 | 程序自动去资料网站查这部片子的封面、简介、演员、标签，然后填回来。这一步需要能访问外网。 | 刮削任务、快速开始教程 |
| 番号 | 影片的识别编号，通常写在文件名里。程序靠它认片子；认不出来就刮不到资料。 | 扫描结果、刮削结果 |
| 媒体库 | 整理好之后，你能翻、能搜的那一份影片清单。 | 后台媒体菜单、前台站点 |
| 演员 | 一部片子相关的演职员信息，刮削时会一起带回来。 | 详情页、演员列表 |
| 标签 | 给影片打的关键词，方便筛选和归类。 | 详情页、整理页面 |
| 系列 | 把同一系列的多部片子归在一起。 | 影片详情、整理页面 |
| 厂牌 | 出品方或制作公司，和系列、标签一样是一种归类方式。 | 影片详情、整理页面 |
| 数据源 | 提供影片资料的网站或服务，也就是刮削时「去哪儿查」。**填错了会怎样**：地址或授权码填错会连不上，刮削一直失败；可以在插件配置页做连通性测试确认。 | 集成应用、插件配置页 |
| 阅读进度 | 看漫画或小说时看到第几页，程序帮你记下来，换设备也能接着看。 | 漫画与小说阅读器 |

## 四、找资源与下载

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| 站点资源 | 你在资源站注册的账号接入程序后，程序就能替你去那里搜资源、拿下载地址。**填错了会怎样**：密钥或 Cookie 不对，检索正常但一下载就失败。 | 集成应用 → 站点资源 |
| 订阅 | 你给它一个番号或演员，它替你持续盯着有没有新资源出现。 | 订阅页面、自动化任务 |
| 磁力 | 一串以 `magnet:` 开头的链接，下载器靠它找到并下载文件。 | 搜索结果、下载任务 |
| 种子 | 记录文件信息的小文件，下载器打开它才开始下载。 | 搜索结果、下载器 |
| 下载器 | 真正负责下载的程序，例如 qBittorrent、Transmission。**填错了会怎样**：地址或账号填错，AMMDS 推送过去没有反应，订阅会一直停在「订阅中」。 | 下载器配置、订阅设置 |
| 辅种 | 借助其他站点已有的相同文件，让你的下载更快开始或继续做种。 | 辅种工具、下载相关页面 |
| RSS | 网站定期发布的一份「更新清单」。程序订阅它，就能自动看到新内容。 | 消息中心、订阅设置 |
| 触发器 | 自动化任务的启动条件：到了设定时间、出现新资源等情况时，自动执行对应的任务。**填错了会怎样**：条件写错，任务要么从不执行，要么反复执行。 | 自动化任务、任务管理 |

## 五、账号与设置

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| 授权码 | 接入外部服务时用来证明身份的一串字符。**填错了会怎样**：对方不认，连接测试失败，对应的功能就查不到资料。 | 插件配置页、集成应用 |
| API Key | 和授权码是一回事，只是有些服务叫这个名字。填错一样连不上，功能用不了。 | 插件配置页、开放平台 |
| 密钥 | 用来做身份验证或加密的那一串秘密字符的统称。AMMDS 里还有「密钥管理」，可以生成不同类型的密钥给外部程序用，类型要选对，否则对方一直提示未授权。 | 密钥管理、个人中心 |
| 许可证 | 证明这个部署已获得授权的记录。没激活只是显示水印，不会锁住任何功能；可以先试用，每份数据只能试用一次。 | 个人信息 → 许可证 |
| 水印 | 未激活时页面上出现的标记，只影响显示，不影响使用。 | 全站页面 |
| 系统检查 | 头像菜单里的一键体检：检查数据库、磁盘、端口、系统时间、依赖程序、代理和插件配置，并按类别列出问题。 | 头像菜单、初始化收尾 |
| 备份 | 把资料导出成文件（可选是否连图片一起导出），或者直接把 `db/` 与 `data/` 复制一份。 | 系统管理 → 备份恢复 |
| 恢复 | 把备份导回来。**填错了会怎样**：包的结构不对会提示校验未通过；一个备份包只能装一种类型的内容，混装会失败。 | 系统管理 → 备份恢复 |
| 日志 | 程序运行的流水记录，出问题时第一手线索就在里面。文件在程序目录的 `data/logs/` 下。 | 运行日志、任务日志 |

## 六、对接其他程序

| 词 | 大白话解释 | 在哪里会看到 |
| --- | --- | --- |
| Webhook | 一个网址。发生事情时 AMMDS 往这个网址发一条消息，用来接手机推送等服务。**填错了会怎样**：地址不对或对方收不到，消息就没了，不会报错到页面上。 | 通知配置、消息推送 |
| 分享链接 | 把某条影片生成一个链接发给别人看。 | 分享页面、前台站点 |
| 提取码 | 打开分享链接时要填的口令。**填错了会怎样**：链接打不开。 | 分享设置、访客打开页 |

## 出问题了怎么办

- **文档里的词这里没收录**：先确认自己用的版本号（工作台「系统信息」卡片里能看到），旧版本的一些说法在新版本里已经改名。
- **照着解释填了还是不行**：把设置改回原样，重启一次，确认问题消失后再一次只改一项，这样容易定位是哪一项填错了。
- **怀疑是词理解错了**：到[常见问题](./faq.md)按你看到的现象找，那里给出的都是能照做的步骤。
- **还是卡住**：记下版本号、出问题的时间点和日志里的报错片段，到 GitHub 提交问题：https://github.com/QYG2297248353/AMMDS-Docker/issues/new
