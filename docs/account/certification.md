# 站点认证

先说明一点：本页是**站点账号认证**，校验的是你在各 PT 站点的 UID 与 PassKey，不涉及姓名、证件等实名信息。认证结果决定系统能否用该站点的账号凭据读取账号数据。

{/* truncate */}

## 打开方式

点击右上角头像，在下拉菜单中选择 **站点认证**。页面按卡片网格展示已配置的认证站点，每行三个；没有站点时显示「暂无认证站点」。

## 卡片上的信息

| 元素 | 说明 |
| --- | --- |
| 站点图标与名称 | 站点展示信息 |
| 类型标签 | 如 NexusPHP、M-Team、PtYes |
| 认证状态 | 已认证 / 未认证 |
| 最后认证时间 | 从未认证时显示「暂无认证」 |
| 站点描述 | 站点简介 |
| 启用开关 | 切换后立即保存，卡片角落的「启用 / 禁用」标签同步变化 |
| UID 按钮 | 已填写时按钮高亮；点击打开参数弹窗 |
| PassKey 按钮 | 已填写时按钮高亮；点击打开参数弹窗 |
| 立即认证 | 发起一次认证请求 |

## 认证前提

| 站点类型 | 需要填写 |
| --- | --- |
| NexusPHP | UID（正整数）与 PassKey |
| M-Team | UID（正整数）与 PassKey |
| PtYes | 仅 PassKey |

另外三个前提缺一不可：站点处于**启用**状态、站点本身支持认证（`siteStatus` 为真）、凭据已保存。未登记的站点类型不允许发起认证。

## 操作步骤

1. 点「UID」，在弹窗中填入站点用户 ID，提交即保存。
2. 点「PassKey」，填入站点提供的 Passkey，提交即保存。
3. 确认开关为启用。
4. 点「立即认证」。

提交前页面会做四项前置校验，任一不满足就直接提示、不发请求：站点未启用、UID 或 PassKey 未填写、站点 ID 为空、该站点尚未支持认证。

认证请求由后端发起，页面不需要你停留在原地：结果由后端异步更新，列表每 10 秒自动刷新一次，切换到其他标签页时暂停。

## 认证状态含义

| 状态 | 含义 |
| --- | --- |
| 已认证 | 最近一次认证成功，且在有效期内 |
| 未认证 | 从未认证、认证失败，或已超出有效期 |

:::info[认证有有效期]
认证结果的有效期是 **6 小时**。超过有效期后认证状态会自动变为未认证，但最后认证时间与失败原因会保留，便于排查。系统内置的定时任务会定期重新执行站点认证，正常情况下不需要你手动续期。
:::

认证成功时，系统会记录站点返回的用户名与邮箱，并推送一条「站点认证成功」通知。

## 认证失败怎么排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「站点未启用」 | 开关被关闭 | 打开卡片上的开关后重试 |
| 提示「请先设置 UID 和 PassKey」 | 凭据缺失 | 分别填写 UID 与 PassKey |
| 提示「该站点尚未支持认证」 | 站点类型不在支持范围内 | 该站点只能用插件方式接入，见[插件总览](/docs/integration/overview) |
| 认证失败但没有明显提示 | UID 与 PassKey 不匹配、Passkey 已在站点侧重置、插件里的站点地址变化 | 到站点重新核对 UID 与 Passkey，确认插件配置中的站点地址无误 |
| 认证成功后又变「未认证」 | 超出 6 小时有效期且定时任务未跑 | 手动点「立即认证」，或检查[定时任务](/docs/system/scheduled-job)是否开启 |
| 一直停留在未认证 | 站点无法访问 | 先用[网络与连通性](/docs/dashboard/network)确认站点域名可达 |

## 安全建议

- PassKey 等同于站点登录凭据，不要截图分享，也不要在多个站点重复使用同一个 Passkey。
- 只为你实际使用的站点填写凭据；不用的站点关闭开关。
- 认证状态与登录安全无关，它是站点维度的凭据校验，不会影响 AMMDS 自身的登录方式。账号安全设置见[用户与安全](/docs/system/users)。
