# 官方商城

官方商城是 AMMDS 内置的商店入口：商品、价格、库存与支付由官方托管店铺提供，本站负责展示与下单。购买会员或服务是对项目持续开发最直接的支持。

{/* truncate */}

## 打开方式

- **前台**：访问 `/home/store` 打开商品列表，可自由浏览与搜索；商品详情、购物车、结算需要登录。
- **后台**：**官方商城** 一级菜单下有「状态」「订单」「购物车」「常用地址」四个页面，用于查看同步情况、订单与本账号的购物车、地址。

## 商品浏览

| 页面 | 内容 |
| --- | --- |
| 商品列表 `/home/store` | 搜索框、分类、商品系列筛选、分页（每页 12 个）与商品卡片 |
| 商品分类 `/home/store/category/{handle}` | 某个分类下的在售商品 |
| 商品详情 `/home/store/product/{handle}` | 规格选择、数量、加入购物车；不可售时提示「该商品暂不可售」 |

商城未开放时页面顶部提示「商城尚未开放，请稍后再来」；商品不存在或已下架时提示「商品不存在或已下架」。

商品卡片会标注「暂不可售」状态，此时无法加入购物车。

## 购物车

1. 在详情页选择规格与数量，点「加入购物车」。
2. 打开购物车 `/home/store/cart`，可调整数量、移除单项或清空。
3. 勾选要结算的商品，点结算进入收银台。

购物车展示单价、数量、小计与合计；币种跟随商城配置（默认 EUR）。

## 结算与下单

结算页 `/home/store/checkout` 分四块：

| 区域 | 需要填什么 |
| --- | --- |
| 收货地址簿 | 登录后可选择已保存的地址，自动回填到下方表单 |
| 联系方式 | 邮箱（必填）、手机号、姓、名 |
| 收货地址 | 地址、城市、国家（必填）；邮编、省/州为选填 |
| 配送方式 | 点「加载运费」获取可选配送方式与金额，选定后计入总价 |
| 支付方式 | 由商城提供的支付渠道列表，选择后提交订单 |

下单成功后跳转到**订单结果页**。该页使用随机 token 而不是可枚举的订单 ID，链接可以安全地转发给自己留存。

## 查看订单

| 页面 | 内容 |
| --- | --- |
| 订单列表 `/home/store/orders` | 本账号的历史订单 |
| 订单详情 `/home/store/orders/{id}` | 商品行、金额、订单状态、支付状态、履约状态 |
| 店铺信息 `/home/store/info` | 店铺名称、客服邮箱等公开信息 |

后台「官方商城 → 订单」可以跨账号查看全部订单并查看明细（合并展示邮箱脱敏、支付状态、履约状态、退款与取消申请），也支持按关键词与支付状态筛选。

## 后台的商城页面

| 页面 | 用途 |
| --- | --- |
| 状态 | 店铺信息、商品数、分类数、购物车数、订单数、最近同步时间与连接状态；可手动触发同步 |
| 订单 | 查询、查看详情、删除本地订单记录 |
| 购物车 | 查看各账号的购物车、移除条目或清空 |
| 常用地址 | 维护本账号的收货地址，可设为默认 |

同步操作包括「同步商品（增量）」「同步信息」「同步订单」「全量校准」。任务在后台执行，页面显示当前任务的进度、成功/失败计数与错误摘要；全量校准进行中不能再次发起。

:::note[本站不提供商品管理]
AMMDS 是展示端，商品、价格、库存、支付与发货都在官方店铺侧维护。后台只能触发同步，不能在这里创建或改价。
:::

## 地址管理

在后台 **官方商城 → 常用地址** 可以新增、编辑、删除地址，并设置默认地址。字段包括邮箱、手机号、姓、名、国家、省/州、城市、邮编与详细地址；其中邮箱、手机号、国家、城市为必填。

默认地址会在结算页的地址簿里排在前面，选中后自动回填表单。

## 支持项目

- 通过商城购买会员或服务，可以支持 AMMDS 的持续开发。
- 具体套餐名称、价格与权益范围**以购买页与许可证页展示为准**。
- 购买后拿到许可证密钥，到[许可证](/docs/system/license)页激活即可；会员标识与许可证是两套独立的概念。
- 权益与许可证的对应关系如有疑问，请以购买页与许可证页的实际展示为准。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 商品列表是空的 | 商城未开放或尚未同步，管理员可在后台「状态」里点「同步商品」 |
| 加入购物车失败 | 商品暂不可售、规格未选或库存不足 |
| 结算页没有配送方式 | 先点「加载运费」，未填国家/地址时拿不到运费选项 |
| 支付后订单状态没变 | 订单状态由商城回调与定时同步更新，可在后台点「同步订单」 |
| 价格与印象中不一致 | 价格与币种以商城实时返回为准，可能受地区与汇率影响 |
| 地址保存后没出现在结算页 | 确认登录的是同一账号，并在地址簿里选中该地址 |
