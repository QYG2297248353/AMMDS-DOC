# 上不了网？先查这里

天气刷不出来、影片信息补不上、消息发不出去，多半是程序连不上外面的网站。工作台的「网络信息」里自带一个检查工具，能把程序要用的网站一个一个测过去。这一页教你怎么打开它、怎么看懂结果、以及不同结果该往哪里查。

## 先说清楚

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。

> **代理**：程序不直接连目标网站，而是让另一台机器替它把请求转发一次。

> **缓存**：把刚查到的结果临时存一份，短时间内再用就直接拿出来，不重新联网。这里存 5 分钟。

> **并发**：好几件事同时抢着做。这里的检查是一个一个来，不同时测，免得把网速挤满。

> **DNS**：把网址翻译成机器能认的地址的一套服务。它不通，网站就打不开。

> **HTTP 响应**：对方网站回过来的一句话。哪怕回的是「没权限」「找不到」，也说明网络是通的。

## 一步一步做

### 1. 打开检查窗口

到 **仪表盘 → 工作台** 找到「网络信息」卡片，点卡片任意位置打开弹窗。弹窗顶部只有一个开关，三个选项共用同一块区域：

| 选项 | 看什么 |
| --- | --- |
| 当前网页 | 以你正在用的浏览器为准，看它的公网地址、地理位置和代理情况 |
| 后台服务 | 以装 AMMDS 那台服务器为准，看同一组信息 |
| 连通性 | 把程序用到的公共网站列成清单，逐个测能不能连 |

选「连通性」时，右上角按钮变成「重新测试」；选前两个时是「刷新」。

### 2. 看网络详情

在「当前网页」和「后台服务」之间切换，就是换看哪台机器的出口地址：

| 来源 | 数据怎么来的 | 代表什么 |
| --- | --- | --- |
| 当前网页 | 浏览器直接去查 `ip.sb` | 你现在这台设备上网用的地址 |
| 后台服务 | 由后台替你转发这次查询 | 服务器上网用的地址 |

两个地址不一样，通常是服务器走了代理，或者你的浏览器和服务器根本不在同一个网络里。

展示的项目：

| 项目 | 说明 |
| --- | --- |
| IPv4 / IPv6 | 两种地址格式分开探测，哪一种连不上就显示「暂不支持」 |
| 网络优先级 | 两种都能用时，标出当前实际走的是哪一种 |
| 地理位置 | 国家 / 地区、城市、网络运营商、运营商编号、时区、经纬度 |
| 代理情况 | 系统里设的代理开关、协议、地址、登录用户名；密码不会显示出来 |

:::tip[结果会存 5 分钟]
同一个来源的详情会缓存 5 分钟，切换来源或点「刷新」才会重新查；「网络信息」卡片本身也缓存 5 分钟，免得每次进工作台都重新探测一遍。
:::

### 3. 跑一遍连通性检查

切到「连通性」，面板先把要测的网站全列出来（状态都是「待测试」），然后**从表格第一行开始，一行一行往下测**，每测完一行立刻显示结果。全部测完，顶部汇总总数、可访问数、不可访问数和总耗时。

判定只有两种：

- **可访问**：后台收到了对方网站的任意 HTTP 响应，包括「没权限」「找不到」这类回复。这说明网络是通的；对方要求登录、或者网址不存在，都不影响这个结论。
- **不可访问**：域名解析失败、连接超时、连接被重置、加密连接没建立起来等。

:::warning[可访问不等于功能能用]
比如 TMDB 显示可访问，但刮削还是失败，通常是接口钥匙（API Key）没填对、或者当天的免费次数用完了，不是网络问题。
:::

表格里三列：

| 字段 | 说明 |
| --- | --- |
| 测试对象 | 站点图标加域名，下面一行是名称和分组 |
| 连通性 | 待测试 / 测试中 / 可访问 / 不可访问；鼠标悬浮能看状态码（对方返回的编号）或失败原因 |
| 耗时 | 从发出请求到收到对方第一句回复的时间 |

几个要注意的地方：

- 中途关掉弹窗，后面的测试立刻停下。
- 清单只加载一次，在三个选项之间来回切不会重复去取。
- 点右上角「重新测试」会把所有行清空，再从头按顺序测一遍。

### 4. 看清单里都测了哪些网站

清单按分组维护，覆盖后台真正会访问的公共网站：

| 分组 | 包含 |
| --- | --- |
| 元数据源 | DMM、FANZA、DMM 图片、R18.dev、TMDB、TMDB 图片、TheTVDB、Bangumi、ThePornDB、TheJavDB、MGS、JavBus、JAV321、AV-Legue、麻豆、MetaTube |
| 站点索引 | M-Team、M-Team API、Rousi、FSM、IYUU、KamePT |
| 通知服务 | Telegram、Bark、高德地图 |
| AI 与翻译 | DeepSeek、Gemini、百度翻译、DeepL、新译、彩云小译、Google 翻译、微软翻译、腾讯翻译 |
| 基础设施 | GitHub、GitHub 加速、HuggingFace、HF 镜像、官方资源、官方 S3、许可证服务、官方商城、统计服务 |
| DNS 与基础 | Cloudflare DoH、Google DoH、DNSPod DoH、IP 查询（ip-api / ipw.cn）、时间校验（苏宁 / 淘宝） |

:::note[清单会自己长]
清单由后台统一维护，新增一个网站就自动出现在这里，不用改页面。你自己搭的服务（Jellyfin、qBittorrent、本机的 MetaTube 等）不在这个清单里，能不能连要在各自的插件配置页里测。
:::

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 网络代理 | 在「系统配置 → 网络代理」里打开代理，填协议、地址、登录用户名；密码不会显示出来 | 不启用时，只有境外网站测不通；地址填错会让「后台服务」这一项也取不到数据 |
| 三个选项开关 | 弹窗顶部选「当前网页」「后台服务」或「连通性」 | 选错只是看到另一台机器的信息，不影响功能；不选「连通性」就不会跑域名检查 |
| 刷新 | 看「当前网页」「后台服务」时点它 | 不点就沿用 5 分钟前的缓存结果 |
| 重新测试 | 选「连通性」后点右上角 | 不点就沿用上次结果；它会清空所有行重新测 |

## 出问题了怎么办

| 现象 | 可能原因 | 怎么处理 |
| --- | --- | --- |
| 大面积不可访问，耗时都接近 4 秒 | 服务器根本出不了网 | 检查主机的 DNS、防火墙和上游网络 |
| 只有境外网站不可访问 | 跨境链路受限 | 在「系统配置 → 网络代理」里启用代理后重测 |
| 网站都能访问，刮削还是失败 | 接口钥匙、免费次数或站点限制 | 检查插件配置和站点账号状态，不是网络问题 |
| DNS 那一组整体失败 | 加密域名查询的通道被挡 | 属于网络策略限制，通常不影响其它功能 |

- 想做更完整的体检（数据库、磁盘、依赖程序、插件配置），到「系统管理 → 系统检查」；本页只管网络通不通。
- 天气卡片刷不出来时，先回工作台看天气卡片有没有报「天气信息加载失败」，再按上面顺序测一遍，详见[工作台：一开门看到什么](./overview.md)。
- 结果一直拿不准，就点右上角「重新测试」重跑一遍，别反复开关弹窗。
