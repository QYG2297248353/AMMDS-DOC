# 仪表盘与工作台

仪表盘是登录后默认进入的后台区域，其中「工作台」把存储、媒体数量、天气、网络、系统版本与服务状态压缩到一屏。本页说明每张卡片展示什么、数据从哪里来、多久刷新一次。

{/* truncate */}

## 卡片布局

工作台按响应式栅格排列，顺序固定为：存储空间、媒体统计、天气、网络信息、系统信息、AMMDS 服务状态、支持一下。窄屏下卡片会依次堆叠为整行。

## 存储空间

左侧是环形图，右侧是两个统计值：

| 项目 | 含义 |
| --- | --- |
| 总空间 | 服务端磁盘总容量；Linux 与容器按数据目录所在文件系统统计，Windows 累加各盘符 |
| 影视空间 | 媒体库中全部影视文件的字节数合计 |
| 已使用 / 剩余空间 | 磁盘层面的已用与可用容量，构成环形图的两段 |

数据来自后端 `GET /api/admin/dashboard/storage`，页面每 10 秒静默刷新一次。影视空间只统计已入库影视的文件大小，不含漫画、小说与下载中的文件。

## 媒体统计

一行五个计数，分别对应：

| 指标 | 统计口径 |
| --- | --- |
| 收藏影视 | 被标记为收藏的影视数量 |
| 收藏演员 | 收藏的演员数量 |
| 订阅影视 | 订阅记录数量 |
| 漫画 | 漫画相册数量 |
| 小说 | 小说数量 |

同样每 10 秒静默刷新。数字为 0 时不代表功能异常，只表示还没有对应数据。

## 天气

卡片展示当前实况天气：图标、温度、天气现象、风向风力，以及省份与城市。

- 城市优先取「集成应用 → 高德地图」中配置的城市代码（adcode，3–6 位数字）。
- 未配置城市代码时，会先查询公网 IP，再通过高德 IP 定位接口换算成城市。
- 未启用自定义高德配置时，使用内置的 Web 服务 Key，保证天气仍可用。
- 请求失败时卡片显示「天气信息加载失败」与 **重试** 按钮。

:::note[网络要求]
天气依赖高德地图接口。直连失败时会自动改走后端代理；两者都不可用时才会显示失败，此时优先检查[网络与连通性](/docs/backend/dashboard/network)。
:::

## 网络信息

展示服务端视角的公网地址、连接协议族、地理位置与代理状态，弹窗内还有「连通性」标签页，可按顺序逐个检测后端使用到的公共域名。

这一卡片的判定标准、缓存时间与排查方法较细，单独成页：见[网络与连通性](/docs/backend/dashboard/network)。

## 系统信息

卡片默认只显示四行，便于快速核对版本：

| 项目 | 说明 |
| --- | --- |
| Java 版本 | 当前 JVM 版本 |
| Spring Boot | 框架版本 |
| AMMDS 内核版本 | 后端版本号 |
| 运行系统 | 操作系统与架构；运行在容器中时统一显示为 `Docker` |

点击卡片任意位置打开「系统信息详情」，分两块：

- **服务端信息**：应用名称与描述、AMMDS / Spring Boot / Java 版本、JVM 与供应商、运行系统与架构、处理器核心数、堆内存占用、运行时长、服务端时间与时区、监听地址、开发方与官网、联系邮箱。
- **浏览器信息**：User-Agent、运行平台、语言、时区、屏幕与窗口尺寸、设备像素比、逻辑核心数、设备内存、网络状态、Cookie 支持情况与当前地址。

服务端信息在进入工作台时请求一次，打开详情后复用同一份数据；页面本身不会定时刷新这四项版本信息。

## AMMDS 服务状态

卡片标题为「AMMDS 服务状态」，展示六项指标：

| 指标 | 说明 |
| --- | --- |
| 在线人数 | 当前在线访问者数量 |
| 浏览量 | 最近 24 小时的页面浏览量 |
| 独立访客 | 最近 24 小时的独立访客数 |
| 访客 | 最近 24 小时的访问次数 |
| 跳出率 | 最近 24 小时的跳出率 |
| 平均访问时长 | 总访问时长除以访问次数，按天/时/分/秒展示 |

这些数据来自 AMMDS 官方统计服务（Umami）的站点统计，**反映的是官方站点的使用情况，不是本机 AMMDS 的运行指标**。卡片每 10 秒刷新一次，统计服务不可达时各项可能显示为 0。

:::tip[想看本机指标]
本机的 CPU、内存、磁盘、数据库连接与插件状态，请看「系统检查」；本机的端口、版本与监听地址，看上面的「系统信息」卡片。
:::

## 支持一下

卡片是一张可点击的图片，点击后在新标签页打开官方商城的购买页。它不参与任何统计，也不影响功能。

## 常见疑问

| 疑问 | 说明 |
| --- | --- |
| 存储空间和「存储管理」页的数字不一致 | 工作台统计的是磁盘总量与影视文件合计；存储管理按 `data/`、`db/` 的一级子目录分类统计 |
| 媒体统计一直是 0 | 先确认是否已有收藏、订阅与漫画/小说数据 |
| 天气城市不对 | 在「集成应用 → 高德地图」中填写正确的城市代码，或关闭自定义城市改用 IP 定位 |
| 服务状态全是 0 | 官方统计服务不可达，与本机功能无关 |

想了解榜单类页面的数据来源，继续阅读[榜单](/docs/backend/dashboard/rankings)。
