# 漫画库

漫画库用来收纳漫画与相册：一本书对应若干章节，每个章节是一组按顺序排列的图片。本页说明怎么建书、怎么把图片导进来，以及整理与阅读进度的相关约定。

{/* truncate */}

## 列表与工具栏

进入 **媒体管理 → 漫画库**：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 「创建漫画」 |
| 右侧 | 排序方式下拉、「搜索我的漫画」 |
| 卡片区 | 每行最多 4 张卡片，底部翻页 |

排序支持**最新创建、最早创建、标题升序、标题降序**四种，切换后回到第一页重新查询。

### 卡片信息

卡片展示封面、分类标签、标题、系列、作者、标签与描述。标题右侧的副标题有两种：

- 开启「全章节」的漫画显示「全集」；
- 未开启时显示「第 N 季」。

鼠标悬浮卡片右上角出现三个操作：**编辑**（进编辑页）、**分享**、**删除**（二次确认后删除）。

:::tip[进入章节管理]
点击卡片主体（不是右上角按钮）进入章节管理页，并会把该书的「全章节」标记一并带过去。
:::

## 创建漫画

点「创建漫画」填写：

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 作者 | 必填 |
| 系列 | 所属系列名称 |
| 类型 | 漫画 / 相册 |
| 描述 | 多行文本 |
| 全章节 | 开关。开启后不再分章节，整本作为一个整体展示 |
| 季数 | `1`～`999` 的整数，可下拉选择也可直接输入；开启「全章节」时该字段禁用 |
| 封面 | 点击或拖拽上传，推荐比例 9:16，仅图片且不超过 10 MB |

季数输入非法值时会提示并回退到上一次的合法值。

## 章节管理

从卡片进入后，页面标题为「章节管理 · 书名」，顶部操作分左右两组：

| 位置 | 操作 | 说明 |
| --- | --- | --- |
| 左 | 章节下拉 | 切换当前章节 |
| 左 | 新建章节 | 填章节标题与描述即可创建；「全章节」模式下禁用 |
| 左 | 漫画导入 | 按服务器目录导入图片；未选章节时禁用 |
| 右 | 编辑 | 回到漫画编辑页 |
| 右 | 立即整理 | 按任务配置直接提交整理任务 |
| 右 | 手动整理 | 指定整理目录、目录格式与文件格式后再提交 |
| 右 | 删除章节 | 「全章节」模式下禁用 |

### 导入方式

章节页中部有三列导入入口：

1. **图片**：点击或拖拽上传，支持 JPG、PNG、BMP、GIF。可以一次拖入整个目录，系统按名称自动排序。
2. **PDF / EPUB**：点击或拖拽上传，支持 PDF 与 EPUB 两种格式，逐个上传并显示进度。
3. **CBZ / 元数据**：
   - CBZ 入口可选中 `.cbz` 文件，但当前版本会提示「暂未支持 CBZ 文件上传」，仅做格式与大小校验后跳过；
   - 元数据入口只接受 `ComicInfo.xml`，用于写入章节元数据。

「漫画导入」走服务器目录：在弹窗里选择包含漫画图片的目录，系统按文件名自然排序导入，并识别封面 / 封底关键词的图片，自动排到首尾。

:::warning[压缩包导入的现状]
上传侧目前只有 PDF / EPUB 能真正落库，CBZ 只是预留入口。压缩包相关能力体现在**输出侧**：手动整理可把章节生成为 CBZ、CBR 或 CB7。
:::

## 整理输出

「立即整理」使用任务配置里的目录与格式，提交后提示「提交整理任务成功」。「手动整理」可以在本次任务里覆盖配置：

| 字段 | 说明 |
| --- | --- |
| 整理目录 | 必选，从服务器目录树中选择 |
| 目录格式 | 支持 `${title}` `${author}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 等标签，留空则用任务配置 |
| 文件格式 | 文件夹整理、CBZ、CBR、CB7、PDF、EPUB |

文件夹 / PDF / EPUB 直接生成，CBZ 与 CB7 内置生成；CBR（RAR）需要服务器安装 `rar` 工具，或配置 `AMMDS_RAR_TOOL` 指向可执行文件。

## 章节图片

选中章节后，图片以网格展示，每张图右上角有三个操作：

- **前移 / 后移**：调整图片顺序，第一张不能前移，最后一张不能后移；
- **删除**：移除该图片。

点击图片可在大图预览中翻页查看。底部翻页支持切换每页数量（12、24、48、60、120、240、480、1000）。

## 阅读进度

章节页只负责内容维护，**阅读进度不在这里展示**，它由前台阅读器记录：

- 阅读器会按「章节 + 页码」保存进度，退出或切到后台时立即落盘。
- 再次打开同一本漫画时，会提示「已恢复到上次阅读位置 第 N 页」。
- 前台详情页据此提供「继续阅读」与「从头阅读」两个入口。
