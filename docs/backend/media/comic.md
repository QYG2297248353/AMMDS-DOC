# 漫画与小说

漫画库收漫画和相册，小说库收小说：都是「一本书 + 若干章节」，区别是漫画的一章是一组图片，小说的一章是一段文字。这一页按你要做的事讲：建一本书、把内容放进去、按顺序排好、导出成文件，以及阅读进度记在哪儿。两个库界面很像，放在一起讲，不一样的地方会点出来。

## 先说清楚

> **元数据**：书或章节的描述信息，比如标题、作者、章节顺序。漫画里用 `ComicInfo.xml` 这个固定名字的文件随书保存。

> **占位符**：命名格式里 `${title}` 这样的记号，整理时会被真实内容替换，`${title}` 换成书名、`${chapter}` 换成章节名。

> **书源**：小说正文的来源网站。它只负责抓目录和正文，启用哪些书源、规则怎么配在集成应用里维护。

> **整理**：按你定的目录和文件名规则，把库里的内容导出成文件夹或单个文件。

> **EPUB / PDF**：两种常见的电子书文件格式。EPUB 适合阅读器翻页，PDF 是逐页文档。

> **CBZ / CBR / CB7 / 压缩包**：把一章的图片打包成单个文件的几种格式，区别只在压缩方式。CBR 需要服务器额外装工具才能生成。

## 建一本书

两个库都在 **媒体管理** 下，长得很像：左边建书、右边排序和搜索，中间是卡片。

### 漫画库

进入 **媒体管理 → 漫画库**：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 「创建漫画」 |
| 右侧 | 排序方式下拉、「搜索我的漫画」 |
| 卡片区 | 每行最多 4 张卡片，底部翻页 |

排序支持**最新创建、最早创建、标题升序、标题降序**四种，切换后回到第一页重新查询。

卡片展示封面、分类标签、标题、系列、作者、标签与描述。标题右侧的副标题有两种：开了「全章节」显示「全集」，没开显示「第 N 季」。

鼠标悬浮卡片右上角出现三个操作：**编辑**（进编辑页）、**分享**、**删除**（二次确认后删除）。点卡片主体（不是右上角按钮）进章节管理页，并会把该书的「全章节」标记一并带过去。

### 小说库

进入 **媒体管理 → 小说库**：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 「创建小说」「搜索小说」「导入 EPUB」 |
| 右侧 | 排序方式下拉、「搜索我的小说」 |
| 卡片区 | 每行最多 4 张卡片，底部翻页 |

排序同样是**最新创建、最早创建、标题升序、标题降序**。每页默认 12 条，与四列栅格对齐。

卡片左侧是封面，右上角固定显示**状态**标签（完结 / 连载 / 草稿 / 待续 / 创作中）；右侧展示类型、标题、作者、系列、来源与标签，描述最多三行。

鼠标悬浮卡片右上角出现操作图标：

| 图标 | 动作 | 说明 |
| --- | --- | --- |
| 下载 | 抓取未下载的章节正文 | 只有来自书源的书才显示 |
| 编辑 | 进入编辑页 | |
| 分享 | 创建分享链接 | |
| 删除 | 二次确认后删除整本小说 | |

:::tip[进入章节管理]
点击卡片主体进入章节管理页，漫画和小说都是这个入口，跟右上角那几个按钮不是一回事。
:::

### 创建时填什么

漫画点「创建漫画」、小说点「创建小说」，字段分别如下。

漫画：

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 作者 | 必填 |
| 系列 | 所属系列名称 |
| 类型 | 漫画 / 相册 |
| 描述 | 多行文本 |
| 全章节 | 开关。开启后不再分章节，整本作为一个整体展示 |
| 季数 | `1`～`999` 的整数，可下拉选择也可直接输入；开启「全章节」时该字段禁用 |
| 封面 | 点击或拖拽上传，推荐比例 9:16，仅图片且不超过 10 MB |

季数输入非法值时会提示并回退到上一次的合法值。

小说：

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 作者 | |
| 类型 | 候选含玄幻、都市、科幻、悬疑、武侠、言情、历史、游戏、轻小说，也可直接输入自定义类型 |
| 系列 | 所属系列名称 |
| 状态 | 完结、连载、草稿、待续、创作中 |
| 描述 | 多行文本 |
| 封面 | 点击或拖拽上传，推荐比例 2:3 |

## 把内容放进去

### 漫画：从电脑或服务器导入

章节页中部有三列导入入口：

1. **图片**：点击或拖拽上传，支持 JPG、PNG、BMP、GIF。可以一次拖入整个目录，系统按名称自动排序。
2. **PDF / EPUB**：点击或拖拽上传，支持 PDF 与 EPUB 两种格式，逐个上传并显示进度。
3. **CBZ / 元数据**：CBZ 入口可选中 `.cbz` 文件，但当前版本会提示「暂未支持 CBZ 文件上传」，只检查格式和大小，然后跳过；元数据入口只接受 `ComicInfo.xml`，用于写入章节元数据。

还有「漫画导入」走服务器目录：在弹窗里选择包含漫画图片的目录，系统按文件名的数字顺序导入，并识别封面 / 封底关键词的图片，自动排到首尾。

:::warning[压缩包导入的现状]
上传这边目前只有 PDF / EPUB 能真正导进来，CBZ 只是先留了一个入口。压缩包相关能力体现在**输出侧**：手动整理可把章节生成为 CBZ、CBR 或 CB7。
:::

### 小说：EPUB 与书源

- **EPUB 导入**：点「导入 EPUB」选择 `.epub` 文件，系统解析书目录与章节后入库，导入过程显示加载状态。这是把已有电子书搬进媒体库最快的方式。
- **书源导入**：点「搜索小说」打开书源检索弹窗：输入书名关键词，按已启用的书源检索 → 从结果中选择书籍导入。导入后的书会在卡片上标注来源，章节页展示「来源书源: 书源名」标签。书源只负责目录与正文抓取，书源本身的启用与规则在集成应用中维护。

## 章节管理与顺序

从卡片点进去，页面标题是「章节管理 · 书名」，顶部操作分左右两组。

漫画：

| 位置 | 操作 | 说明 |
| --- | --- | --- |
| 左 | 章节下拉 | 切换当前章节 |
| 左 | 新建章节 | 填章节标题与描述即可创建；「全章节」模式下禁用 |
| 左 | 漫画导入 | 按服务器目录导入图片；未选章节时禁用 |
| 右 | 编辑 | 回到漫画编辑页 |
| 右 | 立即整理 | 按任务配置直接提交整理任务 |
| 右 | 手动整理 | 指定整理目录、目录格式与文件格式后再提交 |
| 右 | 删除章节 | 「全章节」模式下禁用 |

小说：

| 位置 | 操作 | 说明 |
| --- | --- | --- |
| 左 | 章节下拉 | 按序号 + 标题列出全部章节 |
| 左 | 新建章节 | 只需填章节标题 |
| 左 | 来源书源标签 | 书源导入的书才会出现 |
| 左 | 未抓取正文 N 章 | 有未抓取章节时以红色标签提示 |
| 右 | 更新正文 | 仅书源导入的书且已选章节时显示 |
| 右 | 下载全本 | 仅书源导入的书显示，后台任务执行 |
| 右 | 编辑 / 立即整理 / 手动整理 | 提交整理任务 |
| 右 | 删除章节 | 需先选中章节 |

**漫画的章节图片**：选中章节后，图片以网格展示，每张图右上角有三个操作——**前移 / 后移**（调整图片顺序，第一张不能前移，最后一张不能后移）、**删除**（移除该图片）。点击图片可在大图预览中翻页查看。底部翻页支持切换每页数量（12、24、48、60、120、240、480、1000）。

**小说的正文编辑**：选中章节后进入编辑区：

- 顶部是**章节标题**输入框与「保存正文」按钮。
- 正文是纯文本框，空行分段；里面写 HTML 标签也不会变成格式，会原样显示成文字。
- 书源导入的章节在打开时会自动抓取正文，抓取期间编辑区被加载遮罩盖住，避免看到半截内容。
- 未点「保存正文」时，改动只留在你当前的浏览器里。

**下载全本**（仅书源导入的小说）把抓取任务交给后台：

1. 提交后页面顶部出现「正在后台下载全本」进度条。
2. 进度来自任务日志，附带当前阶段说明。
3. 点「查看任务日志」可跳到日志页排查失败原因。

## 整理成文件导出

「立即整理」使用任务配置里的目录与格式，提交后提示「提交整理任务成功」；「手动整理」可以在本次任务里覆盖配置。

漫画的手动整理：

| 字段 | 说明 |
| --- | --- |
| 整理目录 | 必选，从服务器目录树中选择 |
| 目录格式 | 支持 `${title}` `${author}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 等标签，留空则用任务配置 |
| 文件格式 | 文件夹整理、CBZ、CBR、CB7、PDF、EPUB |

文件夹 / PDF / EPUB 直接生成，CBZ 与 CB7 内置生成；CBR（RAR）需要服务器安装 `rar` 工具，或配置 `AMMDS_RAR_TOOL` 指向可执行文件。

小说的手动整理（「立即整理」按「小说整理配置」提交）：

| 字段 | 说明 |
| --- | --- |
| 整理目录 | 留空则使用「小说整理配置」里的目录 |
| 目录命名规则 | 支持 `${title}` `${author}` `${category}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 等标签 |
| 文件命名规则 | 整本导出时 `${chapter}` 使用小说名称，按章节导出时使用章节名称 |
| 整理格式 | **EPUB**（默认）或 **TXT** |
| 是否按照章节生成 | 开启后每章一个文件；关闭则整本一个文件（EPUB 内含全部章节） |

EPUB 会按章节顺序生成电子书目录，适合直接交给阅读器。

两套默认配置在任务管理栏目的「任务配置」里，用文字找过去：**漫画整理配置**管整理格式、默认整理目录、目录 / 文件命名规则、是否按章节生成、封面 / 封底 / 目录识别关键词；**小说整理配置**管整理格式、默认整理目录、目录 / 文件命名规则、是否按章节生成。这两套只服务于漫画与小说入库，不与影视扫描任务混用；改了只影响之后创建或执行的任务，不会回改已经入库的内容。

## 阅读进度记在哪

章节管理页只负责内容维护，**阅读进度不在这里展示**，它由前台阅读器记录：

- 漫画按「章节 + 页码」保存进度，退出或切到后台时立即存下来。再次打开同一本漫画时，会提示「已恢复到上次阅读位置 第 N 页」。前台详情页据此提供「继续阅读」与「从头阅读」两个入口。
- 小说按「章节 + 位置」记录：前台详情页有进度时主按钮是「继续阅读」，并提示读到第几章；阅读器提供章节目录、翻页 / 滚动两种模式、主题与字号调节。没有进度或进度所属章节已被删除时，回退为「从头阅读」。

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 标题 | 漫画、小说都必填 | 不填建不了书 |
| 作者 | 漫画必填；小说可留空 | 漫画不填建不了书 |
| 类型 | 漫画选「漫画 / 相册」；小说从候选里选，或直接输入自定义类型 | 只影响分类展示，不影响导入 |
| 全章节（漫画） | 开关，开启后整本不再分章节 | 开启后季数、新建章节、删除章节都禁用 |
| 季数（漫画） | `1`～`999` 的整数，下拉选或直接输入 | 非法值会提示并回退到上一次的合法值 |
| 封面 | 点击或拖拽上传；漫画推荐 9:16、小说 2:3，漫画仅图片且不超过 10 MB | 格式或大小不对传不上去 |
| 状态（小说） | 完结 / 连载 / 草稿 / 待续 / 创作中 | 只作为卡片右上角的标记 |
| 章节下拉 | 导入前先选中一个章节 | 未选章节时「漫画导入」禁用 |
| 图片上传 | JPG、PNG、BMP、GIF，可一次拖入整个目录 | 系统按名称自动排序，顺序不对要用前移 / 后移手动调 |
| `ComicInfo.xml` | 元数据入口只接受这个文件名 | 别的文件名不会写入章节元数据 |
| CBZ 上传 | 选中 `.cbz` 文件 | 当前版本提示「暂未支持 CBZ 文件上传」，只检查格式和大小后跳过；上传这边只有 PDF / EPUB 真正能导进来 |
| 保存正文 | 改完正文点「保存正文」 | 不点的话改动只在你当前浏览器里，关掉就没了 |
| 整理目录（手动整理） | 漫画必选，从服务器目录树选；小说留空则用「小说整理配置」里的目录 | 漫画不选提交不了 |
| 目录格式 / 目录命名规则 | 填 `${title}` `${author}` `${chapter}` `${index}` 等标签 | 留空则用任务配置；标签写错会生成错误的目录名 |
| 文件格式 / 整理格式 | 漫画选文件夹 / CBZ / CBR / CB7 / PDF / EPUB；小说选 EPUB（默认）或 TXT | CBR 需要服务器装 `rar` 或配 `AMMDS_RAR_TOOL`，否则生成不了 |
| 是否按照章节生成（小说） | 开启每章一个文件；关闭整本一个文件 | 关闭时 EPUB 内含全部章节 |
| 文件命名规则（小说） | 整本导出时 `${chapter}` 用小说名，按章节导出时用章节名 | 写错会让文件名对不上内容 |

## 出问题了怎么办

- **导入的章节顺序乱了**：图片按文件名自动排序，「漫画导入」还会把封面 / 封底关键词的图片排到首尾；仍不对就用每张图的前移 / 后移手动调，第一张不能前移、最后一张不能后移。
- **CBZ 传不进去**：当前版本上传这边不支持 `.cbz`，只检查格式和大小后跳过，会提示「暂未支持 CBZ 文件上传」。想用压缩包，走「手动整理」把章节导出成 CBZ / CBR / CB7。
- **CBR 生成不了**：CBR 要服务器安装 `rar` 工具，或把 `AMMDS_RAR_TOOL` 指到可执行文件；没装就改用 CBZ 或 CB7。
- **小说正文改了却没保存**：正文要点「保存正文」才会存到服务器；书源导入的章节打开时会自动抓取，抓取期间编辑区被盖住，等抓完再改。
- **下载全本卡住或失败**：进度来自任务日志，点「查看任务日志」看停在哪个阶段；只有书源导入的书才有「下载全本」。
- **整理没按预期生成**：「立即整理」用的是任务管理栏目「任务配置」里的默认目录与格式；想临时改就用「手动整理」覆盖，改默认要去任务配置。
- **找不到「继续阅读」**：阅读进度在前台阅读器里，后台章节管理页不展示；进度所属章节被删掉后会回退到「从头阅读」。
