# 影片、剧集与演员

扫描和刮削把影片记录放进库之后，日常维护都在这三个页面：影视库管单部影片，剧集库管一部剧的季和集，演员库管人和作品关联。这一页按「你要做什么」讲怎么找、怎么补、怎么改、怎么删，以及哪些操作删了就找不回来。

## 先说清楚

> **番号 / 识别码**：影片的识别编号，通常写在文件名里。搜索框里叫「番号」，详情和编辑页里叫「识别码」，是同一样东西，一部片子可以有多个。

> **元数据**：一部片子的封面、简介、演员、标签这些描述信息。

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。

> **站点 ID**：TMDB、Bangumi、IMDb 这类资料网站给同一部剧编的号码，用来跨网站对上同一部作品。

> **绑定**：把库里的一条记录和硬盘上的某个视频文件（或另一条已有记录）关联起来，让它知道「就是指这个文件 / 这部片」。

> **多值输入**：一个框里能填好几个值，输完按回车加一个，比如标签、类型、别名。

## 找到并看懂一条记录

三个库都在 **媒体管理** 下，页面长得很像：上面是检索条件，中间是快捷操作，下面是表格或卡片。

### 影视库

进入 **媒体管理 → 影视库**：

| 区域 | 内容 |
| --- | --- |
| 搜索条件 | 标题、番号、演员、类型、标签、系列六个输入项，右侧「搜索」「重置」 |
| 快捷操作 | 左侧「添加媒体」「搜索影视」，勾选行后出现「合并媒体」「删除媒体」；右侧「来源」下拉 |
| 数据表格 | 序号、封面、信息、标签、演员、操作，底部翻页与每页条数 |

| 检索字段 | 匹配方式 |
| --- | --- |
| 标题 | 模糊匹配原标题与中文标题 |
| 番号 | 按识别码匹配 |
| 演员 | 按演员姓名匹配 |
| 类型 | 多值，命中任一即可（输入后回车） |
| 标签 | 多值，命中任一即可 |
| 系列 | 按系列名称匹配 |

「信息」列展示识别码、中文标题（缺失时回退原标题），下面用标签列出**发行日期、时长、分级、评分**，有宣传语时再占一行；「标签」「演员」两列直接显示这条记录的标签和演员名。

:::tip[两个查询入口不一样]
右上角「来源」下拉一切换就立即重新查询；「搜索条件」里改了东西要手动点「搜索」才提交，「重置」只清空表单，不会自动重新查。
:::

### 剧集库

进入 **媒体管理 → 剧集库**：

| 区域 | 内容 |
| --- | --- |
| 剧集检索 | 标题、识别码、演员、类型（分区）、标签、状态，右侧「搜索」「重置」 |
| 快捷操作 | 「新建剧集」「搜索剧集」，勾选后出现「删除」；右侧「来源」下拉 |
| 数据表格 | 序号、封面、剧集信息、分区、来源、季 / 集、更新时间、操作 |

| 检索字段 | 匹配方式 |
| --- | --- |
| 标题 | 匹配剧名、原名与中文名 |
| 识别码 | TMDB / Bangumi / IMDb 等站点 ID |
| 演员 | 按演员姓名匹配 |
| 类型 | 对应「分区」，可选项由系统提供 |
| 标签 | 多值，输入后回车 |
| 状态 | 连载中 / 已完结 |
| 来源 | 数据源，选「全部」等于不过滤 |

「季 / 集」列分两行显示「N 季」「N 集」。每行右侧有**分享、详情、编辑、删除**。检索里的「类型」对应的是「分区」，「来源」的可选项由系统提供，不是固定几个。

:::note[播放不在后台]
剧集的文件绑定、可用性校验和季映射只在后台能看能改。前台剧集详情页只展示资料和季集结构，没有文件列表，也不提供播放器；要看片请用外部播放器或媒体服务器。
:::

### 演员库

进入 **媒体管理 → 演员库**：

| 区域 | 内容 |
| --- | --- |
| 检索条件 | 姓名、性别、退役、已故、标签、风格、特征，年龄滑块 |
| 快捷操作 | 「新增演员」「搜索演员」，勾选后出现「合并演员」「删除演员」；右侧「来源」下拉 |
| 数据表格 | 序号、姓名、经纪公司、出道日期、国籍、操作 |

| 检索字段 | 说明 |
| --- | --- |
| 姓名 | 模糊匹配演员姓名 |
| 性别 | 男性 / 女性 / 人妖 |
| 退役 | 已退役 / 未退役 / 全部 |
| 已故 | 已故 / 未故 / 全部 |
| 标签 / 风格 / 特征 | 三个独立的标签维度，各自多值输入 |
| 年龄 | 滑块分档：全部、20 岁、20–30、30–40、40 岁 |

「姓名」列是主体：左边大头照，右边姓名和标签（性别、年龄、特征、三围、退役 / 已故状态）。其余列是经纪公司、出道日期、国籍，最后一列是**分享、详情、删除**。和影视库一样，「来源」下拉切换立即重查，表单条件要点「搜索」才提交，「重置」只清空表单。

## 认片子靠什么

同一部片子可以有好几个识别码，界面上有两种叫法：

| 位置 | 说明 |
| --- | --- |
| 搜索条件 → 番号 | 按识别码检索 |
| 列表 → 信息 | 标题前显示这条记录的首个识别码 |
| 详情抽屉 → 识别码 | 显示全部识别码，多个用逗号分隔 |
| 高级编辑 → 识别码 | 多值输入框，可增删、可自定义 |

识别码是扫描时按识别规则从文件名里提取、再统一写法得来的，所以同一部片子的不同写法会并到同一条记录，规则在任务管理栏目里配。手工新增影片时可以自己填识别码，订阅会按它跟踪后续资源。

## 补一条新记录

### 影视：搜索影视

点「搜索影视」打开在线检索弹窗，输入番号或标题后回车：

1. 历史搜索词最多留 20 条，存在浏览器本地，点一下就能复用。
2. 结果卡片显示番号、发行日期、数据来源和标题，右上角三个按钮：

| 按钮 | 做什么 |
| --- | --- |
| 导入 | 写入影视库，完成后刷新列表并关掉弹窗 |
| 收藏 | 先导入，再加入收藏 |
| 订阅 | 先导入，再按番号建一条订阅，交给订阅任务跟踪后续资源 |

3. 没有结果时会显示历史搜索区，初始提示「搜索一下，试试看吧」。

收藏和订阅是按用户记的标记，「暂停 / 恢复 / 退订」这些后续状态由订阅管理负责，不在本页维护。

### 剧集：搜索剧集

「搜索剧集」用来手工补录单部剧：

1. 输入剧名关键词（如 `葬送的芙莉莲`）回车；关键词会写进本地历史搜索，最多 20 条。
2. 候选卡片显示竖版海报、年份、数据源和**匹配分**（保留三位小数）。
3. 点「导入」会弹出季号输入框：留空表示导入该数据源的全部季，`0` 表示特别篇，填 `1`～`99` 只导入这一季。
4. 成功后提示「导入成功，可在剧集详情中完善元数据与季集」。

:::note[导入会先合并]
数据源里已经有相同站点 ID 时，会**并入**现有剧集，不会新建一条重复的。导入只是把资料存进来，后面的季集和文件还要到详情页维护。
:::

### 演员：新增与搜索

「新增演员」进编辑页手工填；「搜索演员」在线检索后导入。想少填点，顺序是：先用「搜索演员」导入，再进编辑页核对姓名和别名，最后用「在线搜索补充元数据」把缺字段补到当前演员上。

## 查看详情与改资料

### 影视详情抽屉

点列表里的标题打开「媒体详情」抽屉：

| 区块 | 内容 |
| --- | --- |
| 左侧 | 封面，下面标签显示时长、分级、评分 |
| 描述项 | 标题、识别码、发行日期、时长、评分、分级、导演、演员、制作商，空值不占行 |
| 剧情简介 | 大纲与简介两段 |
| 类型 / 标签 | 两组彩色标签 |
| 演职人员 | 导演与演员，演员可带「饰 角色」 |
| 图集 | 背景图、缩略图、剧照三组轮播 |

图集里的高清图会被提到第一张。点任意图片进全屏预览，左右方向键循环翻页，`Esc` 关闭。抽屉底部四个按钮：**编辑元数据、在线搜索补充、高级编辑、关闭**。

「编辑元数据」只动常用字段，保存后列表和抽屉一起刷新：

1. 标题（中文）、原标题、评分（0–10，步长 0.1）。
2. 发行日期、时长（分钟）、分级、语言、国家。
3. 宣传语、类型、标签、制作商、导演。
4. 概述与简介两段长文本。
5. 「绑定演员」可加多行：演员姓名 + 饰演角色，角色可留空，空姓名行不会提交。

弹窗打开时会把这条记录的详情读出来填好；保存时整条记录一起写回，所以**弹窗里没显示的字段不会被清空**。

单条记录缺字段时用「在线搜索补充」：输入番号或标题搜索 → 在结果卡片点「补充到当前影视」 → 系统先把候选存进库，再和当前条目**合并**，完成后刷新列表与抽屉。

:::note[合并和补充不是一回事]
「合并媒体」是把两条已有记录人工并成一条；「补充」是先导入候选再自动合并，适合给一条记录补字段。
:::

### 剧集详情与编辑

列表行点「详情」进剧集详情页，顶部是**重新刮削**和**编辑元数据**两个按钮，主体自上而下：

| 区块 | 内容 |
| --- | --- |
| 头部 | 海报、标题与原标题，标签显示年份、首播日期、状态、评分、评分人数、排名、单集时长、分级、语言、分区、来源 |
| 概要 | 类型、标签、制作公司、国家 / 地区、导演、编剧、站点 ID 与剧情简介 |
| 演员 | 姓名与角色两列 |
| 季列表 | 季号（特别篇单独标注）、季名、首播日期、本季集数（已入库 / 总数） |
| 集列表 | `SxxExx`、标题、首播日期、时长、评分、类型，以及「可播放文件」列 |
| 季映射 | 本地季号、数据源、数据源条目 ID、绑定方式、集号偏移、数据源集数、备注 |

「重新刮削」要选数据源、数据源条目 ID 和季号（`0`～`99`），刷新会把数据**并入当前这部剧**，不会新建出第二部。

列表行的「编辑」和详情页的「编辑元数据」都进剧集编辑页，能维护：

- **基本信息**：标题、原标题、中文标题、排序标题、展示标题、状态、评分、首播日期、年份、单集时长、分级、语言、国家 / 地区、分区、宣传语、大纲、简介与中文简介。
- **分类信息**：类型、标签（取自剧集标签库）。
- **制作信息**：制作公司、国家 / 地区、导演、编剧，以及 TMDB / Bangumi / TVDB / IMDb 四类站点 ID。
- **演员**：姓名与角色可增删。
- **系列与季集**：系列归属，以及季（季号、本季集数、季名、首播日期、季简介）与集（集号、绝对集号、标题、首播日期、时长、类型、评分等）。
- **图片**：封面与背景图，可上传、删除、排序。

保存后回到剧集列表。

### 演员资料字段

「新增演员」和行内「详情」都进演员详情编辑页，字段分六组：

| 分组 | 字段 |
| --- | --- |
| 基本信息 | 姓名（必填）、性别（男性 / 女性 / 人妖）、别名、出生日期、年龄、国籍 |
| 身材信息 | 身高、体重、血型、胸围、腰围、臀围；女性显示罩杯，男性显示长度 |
| 事业信息 | 出道日期、评分（0–10）、经纪公司、是否退役、是否已故 |
| 社交链接 | 平台 + 链接，可增删多行 |
| 特征标签 | 标签、风格、特征三项，均取自演员标签库 |
| 简介与扩展 | 简介长文本、自定义扩展键值对 |

右侧图片区两类图：大头照（2:3，单张，可重新上传、删除、点击预览）、海报墙（3:4，多张，可批量上传与删除）。性别会影响身材字段：选女性显示「罩杯」，选男性显示「长度」，切换性别后相应字段才出现。

抽屉左侧是大头照、基础资料、身材、标签、风格与简介，底部三个按钮：**在线搜索补充元数据、编辑演员、关闭**。

## 管图片

### 影视的高级编辑

图片操作集中在「高级编辑」页（「添加媒体」和详情里的「高级编辑」进的是同一个页面）：

| 图集 | 推荐比例 | 能做什么 |
| --- | --- | --- |
| 封面图 | 2:3 | 点击或拖拽上传、裁剪、删除、上下移动调顺序 |
| 背景图 | 16:9 | 上传、删除、调整顺序 |
| 缩略图 | 16:9 | 上传、删除、调整顺序 |
| 剧照 | 16:9 | 上传、删除、调整顺序 |

顺序就是展示顺序，列表和详情默认取第一张封面（有高清封面时优先高清）。裁剪按钮打开独立裁剪框，确认后直接上传替换。

高级编辑页还包含基本信息、分类信息、制作信息（含识别码与马赛克）、系列信息、演员信息、源链接、扩展字段、绑定列表，以及「媒体绑定列表」——可以按服务器文件树把视频文件绑到这条记录，也能解绑，列表会标「可用 / 失效」和片段标题。

:::tip[保存前会弹确认框]
高级编辑点「保存」会先弹「数据共享计划」确认框：可以勾选是否**收藏**、**订阅**这部片子，以及是否参与数据共享。勾选会追加对应记录，不勾选也不会取消已有状态。
:::

## 合并、删除，以及它们的边界

| 操作 | 怎么用 | 后果 |
| --- | --- | --- |
| 合并媒体（影视） | 勾选表格，**恰好两条**，点「合并媒体」 | 第一条保留，第二条并入后被删除；少于或多于两条都会提示 |
| 合并演员 | 勾选**恰好两条**，点「合并演员」 | 第一条为保留方，第二条数据并入后被删除；数量不对会提示 |
| 删除媒体（影视） | 勾选后点「删除媒体」，逐条提交 | 提示「删除任务已提交」，列表延时数秒后刷新 |
| 删除演员 | 行内「删除」或勾选后「删除演员」 | 两者都要二次确认 |
| 删除剧集 | 行右侧「删除」 | 同时移除该剧的季、集、文件绑定与季映射 |

:::warning[删除删不掉视频，但删得掉关系]
- 删影视：只移除元数据与绑定关系，**不删磁盘上的视频文件**；但元数据、收藏、订阅关系无法恢复，动手前建议先备份。
- 删剧集：不删磁盘上的视频文件，但季、集、文件绑定与季映射一起没。批量删除前确认勾选范围。
- 合并不可撤销：会迁移关联数据并删掉被合并那条，先确认两条确实是同一人 / 同一部片，必要时先备份。
:::

## 剧集特有的：季、集、文件与季映射

> **季映射**：用来对接「一季就是一个条目」的资料网站（如 Bangumi），把本地第 N 季指到那个网站上的某一条，必要时用偏移换算集号。

**季与集**：季列表的「查看集」把下方集列表切到该季，集列表上方还有一排快捷按钮（「全部季」和 `S1`、`S2`……）；集列表按 `S{季}E{集}` 显示，点季按钮就能筛。「本季集数」是「已入库 / 总数」，两个数不一样说明还有集没入库。

**给某一集绑文件**：在「可播放文件」列操作：

1. 点「添加文件」打开「按路径添加文件」弹窗，顶部会提示目标是「第 N 季 第 N 集」。
2. 填**文件绝对路径**（必填，例如 `D:\Media\剧名\Season 1\S01E01.mkv`）。
3. 分段文件填分段序号，`CD1` 填 `1`，`CD2` 填 `2`。
4. 绑定成功后文件出现在列表里，标「可用 / 不可用」和来源。
5. 「解绑」只删绑定关系，不删磁盘文件。

:::tip[可用 / 不可用怎么来的]
这个标记来自最近一次校验结果。把文件移走或改名后要重新校验才会变成不可用；解绑和重新绑定都会刷新这个状态。
:::

**绑季映射**：在「绑定季映射」表单填本地季号、数据源、数据源条目 ID（可以是纯数字如 `400602`，也可以直接粘条目链接）；「绑定方式」选 `AUTO`（自动发现）或 `MANUAL`（手工指定），`MANUAL` 的行不会被自动发现覆盖；「集号偏移」的换算规则是 **数据源集号 = 本地集号 + 偏移**；点「自动发现」会按数据源重新发现并更新映射，结果提示新增 / 更新条数。

:::note[自动发现没结果]
提示「自动发现未返回任何季映射」通常是两种原因：数据源不支持关联条目，或者任务配置里的 `tv_season_auto_discover` 被关了。
:::

本页只维护**已入库**的剧集。扫描阶段产生的「待确认剧集 / 合并 / 确认边界」在任务管理栏目的「刮削入库 → 剧集入库」里处理。

## 演员特有的：别名、作品、收藏与订阅

**别名**是多值输入框，输完回车添加：用来记同一个演员的其他写法，方便检索和数据源比对；提交前会去掉首尾空格，空值不写入；**别名不参与「出演影视」匹配，作品关联只看姓名**。

**作品关联**：列表行点「详情」打开演员详情抽屉，右侧就是作品区——标题「出演影视（N）」，N 是匹配到的影视总数；表格按页显示封面、标题、识别码、发行日期、评分与类型；每行的「详情 / 编辑」直接跳到该影视的高级编辑页。作品列表按**演员姓名**在影视库里比对，所以影视条目里的演员姓名写法必须和演员库一致，写法不一致时这部作品不会出现在这里。

**收藏与订阅**：演员库列表页没有「只看收藏」筛选；前台演员列表有「收藏库」模式，两边是不同界面，不矛盾。产生收藏 / 订阅的入口有两个：

1. 「搜索演员」的结果卡片：三个图标按钮依次是导入、收藏、订阅，都是先入库再做对应动作。
2. 演员详情编辑页保存时弹出的「数据共享计划」确认框里，可勾选「收藏」「订阅」，勾选会追加对应记录。

订阅表示关注这个演员，后续新作品可由订阅任务自动抓取；暂停与取消由订阅管理负责，不在本页维护。

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 搜索条件（六个字段） | 标题、番号、演员、类型、标签、系列 | 不点「搜索」就不生效；「重置」只清表单，不会重新查 |
| 「来源」下拉 | 选一个数据来源，或全部 | 切换立即重新查询，不用点「搜索」 |
| 类型 / 标签 / 别名等多值输入 | 输一个按一次回车加一个 | 不回车不会加进去；别名会去掉首尾空格，空值不写入 |
| 识别码（高级编辑） | 多值，可增删、可自定义 | 和文件名写法不一致会认错片；订阅按它跟踪后续资源 |
| 评分 | 影视 0–10、步长 0.1；演员 0–10 | 超出范围填不进去 |
| 绑定演员（编辑元数据） | 每行「姓名 + 饰演角色」，角色可留空 | 空姓名行不会被提交 |
| 导入季号 | 留空 = 全部季，`0` = 特别篇，`1`～`99` = 只导该季 | 填错会导错季；相同站点 ID 会并入已有剧集而不是新建 |
| 重新刮削 | 数据源、数据源条目 ID、季号（`0`～`99`） | 数据并入当前这部剧，不会新建出第二部 |
| 文件绝对路径 | 必填，例如 `D:\Media\剧名\Season 1\S01E01.mkv` | 不填绑不上；路径不对会标「不可用」 |
| 分段序号 | 分段文件填，`CD1` 填 `1`，`CD2` 填 `2` | 不填多段文件可能对不上 |
| 季映射条目 ID | 纯数字（如 `400602`）或条目链接 | 填错指向别的条目，集数会对不上 |
| 绑定方式 | `AUTO`（自动发现）/ `MANUAL`（手工指定） | `MANUAL` 行不会被自动发现覆盖 |
| 集号偏移 | 数据源集号 = 本地集号 + 偏移 | 偏移写错集号整体错位 |
| 图片比例 | 封面 / 大头照 2:3，背景 / 缩略图 / 剧照 16:9，海报墙 3:4 | 比例不对显示会被裁；顺序即展示顺序 |
| 合并操作 | 恰好勾选两条 | 少于或多于两条都会提示，做不了 |
| 数据共享计划确认框 | 是否收藏、订阅、参与数据共享 | 不勾选不会取消已有状态；勾选会追加记录 |

## 出问题了怎么办

- **搜不到想要的记录**：先确认「搜索条件」改完点了「搜索」；「来源」下拉是不是把它筛掉了；番号 / 识别码写法对不对。
- **演员的作品列表少了几部**：作品关联只按**姓名**匹配，影视条目里的演员姓名写法要和演员库完全一致，别名不参与匹配。
- **导入剧集变成重复条目**：相同站点 ID 本来会并入已有剧集；真出现重复，用「合并」处理，注意合并要求恰好两条。
- **季映射自动发现没结果**：数据源不支持关联条目，或任务配置里的 `tv_season_auto_discover` 关了。
- **剧集文件标成「不可用」**：文件被移走或改名了，重新校验一次；解绑或重新绑定也会刷新状态。
- **误删了记录**：删除不删视频文件，但元数据、收藏、订阅关系恢复不了，只能重新刮削或重新导入，所以动手前先备份。
- **改了字段却没保存**：「编辑元数据」和高级编辑都要点保存；高级编辑保存前还会弹「数据共享计划」确认框，别漏了这一步。
