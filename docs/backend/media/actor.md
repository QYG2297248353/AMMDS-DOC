# 演员库

演员库保存演员的姓名、别名、身材与事业资料，并通过姓名与影视库建立作品关联。本页说明如何检索、补录、合并演员，以及在哪里看他的作品。

{/* truncate */}

## 页面结构

进入 **媒体管理 → 演员库**：

| 区域 | 内容 |
| --- | --- |
| 检索条件 | 姓名、性别、退役、已故、标签、风格、特征，年龄滑块 |
| 快捷操作 | 「新增演员」「搜索演员」，勾选后出现「合并演员」「删除演员」；右侧「来源」下拉 |
| 数据表格 | 序号、姓名、经纪公司、出道日期、国籍、操作 |

「来源」下拉切换后立即重新检索；表单里的条件需要点「搜索」提交，「重置」只清空表单。

### 检索字段

| 字段 | 说明 |
| --- | --- |
| 姓名 | 模糊匹配演员姓名 |
| 性别 | 男性 / 女性 / 人妖 |
| 退役 | 已退役 / 未退役 / 全部 |
| 已故 | 已故 / 未故 / 全部 |
| 标签 / 风格 / 特征 | 三个独立的标签维度，各自多值输入 |
| 年龄 | 滑块分档：全部、20 岁、20–30、30–40、40 岁 |

### 列表字段

「姓名」列是信息主体：左侧大头照，右侧姓名与标签（性别、年龄、特征、三围、退役 / 已故状态）。其余列展示经纪公司、出道日期、国籍，最后一列是行操作：**分享**、**详情**、**删除**。

## 资料字段

「新增演员」与行内的「详情」都进入演员详情编辑页，字段分为六组：

| 分组 | 字段 |
| --- | --- |
| 基本信息 | 姓名（必填）、性别（男性 / 女性 / 人妖）、别名、出生日期、年龄、国籍 |
| 身材信息 | 身高、体重、血型、胸围、腰围、臀围；女性显示罩杯，男性显示长度 |
| 事业信息 | 出道日期、评分（0–10）、经纪公司、是否退役、是否已故 |
| 社交链接 | 平台 + 链接，可增删多行 |
| 特征标签 | 标签、风格、特征三项，均取自演员标签库 |
| 简介与扩展 | 简介长文本、自定义扩展键值对 |

右侧图片区有两类图：

| 图集 | 推荐比例 | 说明 |
| --- | --- | --- |
| 大头照 | 2:3 | 单张，可重新上传、删除，点击可预览 |
| 海报墙 | 3:4 | 多张，可批量上传与删除 |

性别会影响身材字段的显示：选女性展示「罩杯」，选男性展示「长度」，切换性别后相应字段才会出现。

## 别名

「别名」是多值输入框，输入后回车添加：

- 用于记录同一演员的其他写法，便于在检索与数据源比对时识别。
- 提交前会去掉首尾空格，空值不会写入。
- 别名不参与「出演影视」的匹配，作品关联只看**姓名**。

## 作品关联

列表行点「详情」打开演员详情抽屉，右侧就是作品区：

- 标题为「出演影视（N）」，N 为匹配到的影视总数。
- 表格按页展示封面、标题、识别码、发行日期、评分与类型。
- 每行的「详情 / 编辑」直接跳转到该影视的高级编辑页。
- 作品列表按**演员姓名**过滤影视库，因此影视条目里的演员姓名写法要与演员库的姓名一致；写法不一致时该作品不会出现在这里。

抽屉左侧展示大头照、基础资料、身材、标签、风格与简介；底部有**在线搜索补充元数据**、**编辑演员**、**关闭**三个按钮。

:::tip[补全资料的顺序]
先用「搜索演员」在线检索并导入，再进编辑页核对姓名与别名，最后用「在线搜索补充元数据」把缺字段补到当前演员上，能少手工填很多内容。
:::

## 合并与删除

### 合并演员

1. 勾选表格中的演员，**恰好两条**。
2. 点「合并演员」。
3. 第一条作为保留方，第二条的数据并入后会被删除；少于或多于两条都会收到提示。

:::warning[合并不可撤销]
合并会迁移关联数据并删除被合并的那条记录，操作前建议先确认两条确实是同一人，必要时先备份。
:::

### 删除演员

单条删除在行内「删除」，批量删除用勾选后的「删除演员」，两者都会二次确认。

## 收藏与订阅

演员库列表页当前不提供按收藏筛选，收藏与订阅通过两个入口产生：

:::note[前后台的筛选入口不同]
后台演员库列表没有「只看收藏」筛选；前台演员列表提供「收藏库」模式，二者是不同界面，不矛盾。前台侧说明见[前台 · 演员](/docs/site/actor)。
:::

1. **搜索演员**的结果卡片：三个图标按钮依次为导入、收藏、订阅，均先入库再执行对应动作。
2. **演员详情编辑页保存时**：弹出的「数据共享计划」确认框里可勾选「收藏」「订阅」，勾选后会追加对应记录。

订阅表示关注该演员，后续新作品可由订阅任务自动抓取；暂停与取消由订阅管理负责，不在本页维护。
