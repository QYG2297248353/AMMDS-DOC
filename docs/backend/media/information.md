# 资讯库

资讯库集中管理所有资讯内容。来源只有两种：

- **订阅来源**：由 RSS 订阅自动抓取，只能删除，不能修改
- **人工创作**：在后台自己写，可以新建、编辑、删除

## 入口

后台左侧「媒体管理」→ 菜单最后一项「资讯库」。

## 列表怎么看

顶部是筛选区，下面是资讯表格。

| 筛选 | 说明 |
| --- | --- |
| 关键词 | 匹配标题、摘要和正文；输入后按回车也能查询 |
| 来源 | 全部、订阅来源、人工创作 |
| 分类 | 全部、文章、图像、视频、资源、其他 |

改完条件点「查询」，点「重置」清空条件并重新拉列表。

表格的列和内容：

| 列 | 说明 |
| --- | --- |
| 资讯 | 封面缩略图、标题和两行摘要；点标题打开详情弹窗 |
| 分类 | 文章、图像、视频、资源、其他 |
| 作者 | 多个作者用顿号隔开；没填时显示「未署名」 |
| 来源 | 「订阅来源」或「人工创作」；订阅来源把鼠标放上去能看到具体订阅源名称 |
| 发布时间 | 形如 `2026-11-15 10:00:00`；没有时显示 `-` |
| 状态 | 未读或已读 |
| 操作 | 查看、编辑、删除 |

列表按发布时间从新到旧排列。底部分页默认每页 20 条，可以切换成 10、20、50 或 100 条。

## 新建和批量删除

- **创建资讯**：一直在左上角，点了进入创作页
- **批量删除**：勾选之后才出现，按钮上会带上已选条数，例如「批量删除 (3)」

## 为什么订阅来源不能改

订阅资讯是抓取来的原文，改了下次抓取就对不上，所以系统把它当成只读内容：

- 行操作里没有「编辑」，只有「查看」和「删除」
- 后端也会拒绝修改，并提示「订阅来源的资讯不支持编辑，只能删除」

需要调整内容时，请删除后改用人工创作重新写一条。

## 批量删除

1. 勾选一条或多条。
2. 点「批量删除」。
3. 确认后删除。

订阅来源和人工创作都可以删除，删除后不可恢复。单条删除在行操作里，同样会先确认。

## 写一条人工资讯

点「创建资讯」，左边写标题和正文，右边填基础信息。

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填，最多 200 字 |
| 正文 | 必填，用 Markdown 写，见下文 |
| 封面 | 可选；点击或把图片拖进虚线框上传，上传后可以更换或删除；只接受图片，单张不超过 10MB |
| 作者 | 可选，最多 100 字 |
| 分类 | 可选，文章、图像、视频、资源、其他 |
| 原文链接 | 可选，填原始文章地址，例如 `https://example.com/article` |
| 发布时间 | 可选，精确到时分秒，默认是当前时间 |

编辑已有的人工资讯时，表单内容一样。订阅来源的资讯进不了编辑页，会直接提示并退回列表。

### 正文编辑器

正文用 Markdown 写，编辑器有三种查看方式：**编辑**、**分栏**、**预览**。分栏就是左边写、右边实时看效果。

工具栏从左到右提供：加粗、斜体、标题、引用、代码、列表、分割线、插入链接、插入图片。

插入图片有两种方式：

- 填图片地址（URL）
- 上传本地图片

插入链接时需要填链接地址和链接文字。保存后，Markdown 会同时存一份转换好的网页内容，列表和前台展示用的都是转换后的结果。

## 发布后在哪里看

- 前台顶部导航最后一项「资讯」，地址是 `/home/information`
- 资讯列表不用登录就能看
- 点进详情页需要登录

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 找不到「编辑」按钮 | 订阅来源的资讯只读，只能删 |
| 标题保存不了 | 标题必填且最多 200 字 |
| 正文保存不了 | 正文必填 |
| 正文里图片显示不出来 | 确认图片地址能直接打开，或改用上传 |
| 前台看不到新资讯 | 检查发布时间是否设成了将来；前台按发布时间排序 |
