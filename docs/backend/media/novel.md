# 小说库

小说库管理书籍与章节：一本书对应若干章节，章节正文以纯文本保存。本页说明书目怎么建、正文怎么导入和整理，以及阅读进度存在哪里。

## 列表与工具栏

进入 **媒体管理 → 小说库**：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 「创建小说」「搜索小说」「导入 EPUB」 |
| 右侧 | 排序方式下拉、「搜索我的小说」 |
| 卡片区 | 每行最多 4 张卡片，底部翻页 |

排序支持**最新创建、最早创建、标题升序、标题降序**。每页默认 12 条，与四列栅格对齐。

### 卡片信息

卡片左侧是封面，右上角固定显示**状态**标签（完结 / 连载 / 草稿 / 待续 / 创作中）；右侧展示类型、标题、作者、系列、来源与标签，描述最多三行。

鼠标悬浮卡片右上角出现操作图标：

| 图标 | 动作 | 说明 |
| --- | --- | --- |
| 下载 | 抓取未下载的章节正文 | 只有来自书源的书才显示 |
| 编辑 | 进入编辑页 | |
| 分享 | 创建分享链接 | |
| 删除 | 二次确认后删除整本小说 | |

:::tip[进入章节管理]
点击卡片主体进入章节管理页，与漫画库的交互一致。
:::

## 创建小说

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 作者 | |
| 类型 | 候选含玄幻、都市、科幻、悬疑、武侠、言情、历史、游戏、轻小说，也可直接输入自定义类型 |
| 系列 | 所属系列名称 |
| 状态 | 完结、连载、草稿、待续、创作中 |
| 描述 | 多行文本 |
| 封面 | 点击或拖拽上传，推荐比例 2:3 |

## 导入方式

### EPUB 导入

点「导入 EPUB」选择 `.epub` 文件，系统解析书目录与章节后入库，导入过程显示加载状态。这是把已有电子书搬进媒体库最快的方式。

### 书源导入

点「搜索小说」打开书源检索弹窗：

1. 输入书名关键词，按已启用的书源检索。
2. 从结果中选择书籍导入。
3. 导入后的书会在卡片上标注来源，且在章节页展示「来源书源: 书源名」标签。

书源只负责目录与正文抓取，书源本身的启用与规则在集成应用中维护。

## 章节管理

进入章节页后，标题为「章节管理 · 书名」：

| 位置 | 操作 | 说明 |
| --- | --- | --- |
| 左 | 章节下拉 | 按序号 + 标题列出全部章节 |
| 左 | 新建章节 | 只需填章节标题 |
| 左 | 来源书源标签 | 书源导入的书才会出现 |
| 左 | 未抓取正文 N 章 | 有未抓取章节时以红色标签提示 |
| 右 | 更新正文 | 仅书源导入的书且已选章节时显示 |
| 右 | 下载全本 | 仅书源导入的书显示，后台任务执行 |
| 右 | 编辑 / 立即整理 / 手动整理 | 提交整理任务 |
| 右 | 删除章节 | 需先选中章节 |

### 正文编辑

选中章节后进入编辑区：

- 顶部是**章节标题**输入框与「保存正文」按钮。
- 正文是纯文本多行输入框，空行分段；HTML 标签会按纯文本显示，不会被渲染。
- 书源导入的章节在打开时会自动抓取正文，抓取期间编辑区被 loading 遮住，避免看到半截内容。
- 未点「保存正文」时改动只存在于浏览器端。

### 下载全本

「下载全本」把抓取任务交给后台：

1. 提交后页面顶部出现「正在后台下载全本」进度条。
2. 进度来自任务日志，附带当前阶段说明。
3. 点「查看任务日志」可跳到日志页排查失败原因。

## 整理输出

「立即整理」按「小说整理配置」提交；「手动整理」可为本次任务单独指定：

| 字段 | 说明 |
| --- | --- |
| 整理目录 | 留空则使用「小说整理配置」里的目录 |
| 目录命名规则 | 支持 `${title}` `${author}` `${category}` `${date}` `${year}` `${month}` `${day}` `${chapter}` `${index}` 等标签 |
| 文件命名规则 | 整本导出时 `${chapter}` 使用小说名称，按章节导出时使用章节名称 |
| 整理格式 | **EPUB**（默认）或 **TXT** |
| 是否按照章节生成 | 开启后每章一个文件；关闭则整本一个文件（EPUB 内含全部章节） |

EPUB 会按章节顺序生成电子书目录，适合直接交给阅读器。

## 阅读进度

章节管理页不展示阅读进度，进度由前台阅读器按「章节 + 位置」记录：

- 前台详情页据此显示「继续阅读」与「从头阅读」：有进度时主按钮是继续阅读，并提示读到第几章。
- 阅读器提供章节目录、翻页/滚动两种模式、主题与字号调节；具体操作见[前台 · 小说](/docs/site/novel)。
- 没有进度或进度所属章节已被删除时，回退为从头阅读。
