# 影视库

影视库是媒体管理的入口页面：扫描与刮削产生的影视条目都在这里按番号归档，你可以检索、查看详情、修订元数据、合并重复条目，并维护海报与剧照。

{/* truncate */}

## 页面结构

进入 **媒体管理 → 影视库**。页面自上而下分为三块：

| 区域 | 内容 |
| --- | --- |
| 搜索条件 | 标题、番号、演员、类型、标签、系列六个输入项，右侧「搜索」「重置」 |
| 快捷操作 | 左侧「添加媒体」「搜索影视」，勾选行后出现「合并媒体」「删除媒体」；右侧「来源」下拉 |
| 数据表格 | 序号、封面、信息、标签、演员、操作，底部翻页与每页条数 |

:::tip[两种查询入口的差别]
右上角「来源」下拉切换后立即重新查询；「搜索条件」里的改动需要手动点「搜索」才提交，「重置」只清空表单，不会自动重新检索。
:::

## 识别码与番号

同一条影视可以有多个识别码。界面上有两处叫法：搜索条件里叫**番号**，详情与编辑页里叫**识别码**。

| 位置 | 说明 |
| --- | --- |
| 搜索条件 → 番号 | 按识别码检索 |
| 列表 → 信息 | 标题前展示该条目的首个识别码 |
| 详情抽屉 → 识别码 | 展示全部识别码，多个以逗号分隔 |
| 高级编辑 → 识别码 | 多值输入框，可增删、可自定义 |

识别码由扫描阶段的识别规则从文件名中提取并归一，同一部片子的不同写法会收敛到同一条记录，规则本身在[扫描任务](/docs/backend/task/scan)中配置。手工新增影视时可以自己填写识别码，订阅会按它跟踪后续资源。

## 列表筛选

### 检索字段

| 字段 | 匹配方式 |
| --- | --- |
| 标题 | 模糊匹配原标题与中文标题 |
| 番号 | 按识别码匹配 |
| 演员 | 按演员姓名匹配 |
| 类型 | 多值，命中任一即可（输入后回车） |
| 标签 | 多值，命中任一即可 |
| 系列 | 按系列名称匹配 |

### 列表字段

「信息」列展示识别码、中文标题（缺失时回退原标题），下方用标签列出**发行日期、时长、分级、评分**，有宣传语时再占一行。「标签」「演员」两列直接展示该条目的标签与演员名。

### 批量操作

1. 勾选表格左侧复选框。
2. 顶部出现「合并媒体」与「删除媒体」。
3. 合并要求**恰好两条**：第一条保留，第二条并入后被删除；少于或多于两条都会提示。
4. 批量删除逐条提交，提示「删除任务已提交」，列表延时数秒后刷新。

:::warning[删除的边界]
删除影视只移除元数据与绑定关系，不会删除磁盘上的视频文件；但元数据以及收藏、订阅关系无法恢复，操作前建议先备份。
:::

## 搜索影视：导入、收藏与订阅

点「搜索影视」打开在线检索弹窗，输入番号或标题后回车：

1. 历史搜索词最多保留 20 条，存在浏览器本地，点一下即可复用。
2. 结果卡片展示番号、发行日期、数据来源与标题，右上角三个按钮：
   - **导入**：写入影视库，完成后刷新列表并关闭弹窗。
   - **收藏**：先导入，再把它加入收藏。
   - **订阅**：先导入，再按番号创建订阅，交给订阅任务跟踪后续资源。
3. 没有结果时展示历史搜索区，初始提示「搜索一下，试试看吧」。

收藏与订阅是用户维度的标记，「暂停 / 恢复 / 退订」等后续状态由订阅管理负责，不在本页维护。

## 详情抽屉

点击列表中的标题打开「媒体详情」抽屉：

| 区块 | 内容 |
| --- | --- |
| 左侧 | 封面，下方标签展示时长、分级、评分 |
| 描述项 | 标题、识别码、发行日期、时长、评分、分级、导演、演员、制作商，空值不占行 |
| 剧情简介 | 大纲与简介两段 |
| 类型 / 标签 | 两组彩色标签 |
| 演职人员 | 导演与演员，演员可带「饰 角色」 |
| 图集 | 背景图、缩略图、剧照三组轮播 |

图集中的高清图会被提到第一张。点击任意图片进入全屏预览，左右方向键循环翻页，`Esc` 关闭。

抽屉底部四个按钮：**编辑元数据**、**在线搜索补充**、**高级编辑**、**关闭**。

## 编辑元数据

「编辑元数据」弹窗只动常用字段，保存后同时刷新列表与抽屉：

1. 标题（中文）、原标题、评分（0–10，步长 0.1）。
2. 发行日期、时长（分钟）、分级、语言、国家。
3. 宣传语、类型、标签、制作商、导演。
4. 概述与简介两段长文本。
5. 「绑定演员」区可添加多行：演员姓名 + 饰演角色，角色可留空，空姓名行不会被提交。

弹窗打开时会先拉取完整详情再回填，保存时提交整条对象，因此未在弹窗中展示的字段不会被清空。

### 在线搜索补充

单条记录字段不全时使用「在线搜索补充」：

1. 输入番号或标题搜索。
2. 在结果卡片上点「补充到当前影视」。
3. 系统先把候选入库，再与当前条目**合并**，完成后刷新列表与抽屉。

:::note[合并与补充的差别]
「合并媒体」是对两条已有记录做人工归并；「补充」是先导入候选再自动合并，适合单条记录补字段。
:::

## 海报与剧照管理

图片操作集中在**高级编辑**页（「添加媒体」与详情里的「高级编辑」进入同一个页面）：

| 图集 | 推荐比例 | 可做的操作 |
| --- | --- | --- |
| 封面图 | 2:3 | 点击或拖拽上传、裁剪、删除、上下移动调整顺序 |
| 背景图 | 16:9 | 上传、删除、调整顺序 |
| 缩略图 | 16:9 | 上传、删除、调整顺序 |
| 剧照 | 16:9 | 上传、删除、调整顺序 |

顺序即展示顺序，列表与详情默认取第一张封面（存在高清封面时优先高清）。裁剪按钮打开独立裁剪对话框，确认后直接上传替换。

高级编辑页还包含基本信息、分类信息、制作信息（含识别码与马赛克）、系列信息、演员信息、源链接、扩展字段、绑定列表，以及「媒体绑定列表」——可按服务器文件树选择视频文件绑定到本条目，也可解绑，列表标注「可用 / 失效」与片段标题。

:::tip[保存前的确认框]
高级编辑点「保存」会先弹出「数据共享计划」确认框：可勾选是否**收藏**、**订阅**该影视，以及是否参与数据共享。勾选后会追加对应记录，不勾选不会取消已有状态。
:::
