# 系列、厂牌与标签

这三个页面都不是存影片本身，而是给影片「归类」：系列把多部作品打包成一个可浏览的整体，厂牌按片商把作品自动收拢，标签库是全站共用的词条来源。这一页按你要做的事讲：怎么建、怎么把作品放进去、哪些改动会（或不会）影响已经入库的影片。

## 先说清楚

> **番号 / 识别码**：影片的识别编号，通常写在文件名里。系列库和厂牌库都靠它反查作品。

> **元数据**：一部片子的封面、简介、演员、标签这些描述信息。厂牌名、系列名、标签都会写进它。

> **NFO**：和视频放在同一个目录里的小说明文件，记录影片的元数据，媒体服务器也读它。

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。

> **别名**：同一事物的其他写法。片商在不同数据源里名称可能不一样，用别名把这些写法都兜住。

> **多值输入**：一个框里能填好几个值，输完按回车加一个，比如别名、标签。

> **软关联**：两边只靠「名称对得上」联系起来，不是硬绑定。所以名字写法一变，统计里就可能看不到那些作品。

> **正则表达式**：一种用符号描述「符合某种写法的字符串」的规则，用来批量匹配识别码。不熟可以先用另外两种规则类型。

> **权重 / 引用**：标签库里记录一个标签被用到的频繁程度的数值，用来把常用标签排在前面，不是精确的作品数。

## 系列：把多部作品打包成一个整体

### 找到并新建系列

进入 **媒体管理 → 系列库**：

| 区域 | 内容 |
| --- | --- |
| 系列检索 | 关键字（系列名称 / 描述）、作品识别码 |
| 快捷操作 | 「新建系列」，勾选后出现「删除」 |
| 数据表格 | 系列、操作 |

「系列」列是信息主体：左侧封面，右侧系列名称（可点击进详情）、描述与「N 部作品」标签。「操作」列提供**详情、分享、编辑、删除**。检索框里的「作品识别码」用来反查系列：填一个番号就能找到包含该作品的系列。

新建与编辑共用同一个弹窗，字段只有三项：

| 字段 | 说明 |
| --- | --- |
| 封面 | 点击或拖拽上传图片，也可删除后重传 |
| 系列名称 | 必填 |
| 系列描述 | 可选 |

:::note[封面规格]
封面上传只接受图片，大小上限 10 MB；上传后以竖版缩略图展示。
:::

### 往系列里放作品

在列表行点「详情」或点系列名称进入详情页：顶部是系列名称与「N 部作品」，右侧是**编辑**与**分享**；左侧是封面与描述；右侧是作品区工具条与作品表格——**添加作品**、**批量导入**、勾选后出现的**移出系列**，以及「按作品名称筛选」搜索框。表格每行展示序号、作品（封面 + 标题 + 识别码 + 发行日期）与操作（查看、移出），点「查看」跳到该影视的高级编辑页。

**添加作品**（从已有影视库里挑）：

1. 点「添加作品」打开弹窗。
2. 在「搜索媒体库作品」输入框按标题搜索影视库。
3. 勾选一个或多个作品，点「添加选中（N）」。
4. 完成后提示成功添加的作品数。

**批量导入**（按识别码一次整理整个系列）：

1. 在文本框中粘贴识别码，支持逗号、换行、空格、分号分隔，例如：

   ```
   SSIS-001, IPX-002
   MIDE-003
   ABP-004
   ```

2. 点「开始导入」。
3. 已在媒体库中的作品直接加入系列；不在库中的会尝试在线搜索导入。
4. 导入结果列出成功数量，失败项会给出「识别码」与「失败原因」。

:::warning[在线导入的依赖]
批量导入里「不在库中就去在线搜索」这一步依赖已启用的资料来源。资料来源没配或连不上时，这些识别码会以失败原因的形式返回，需要先在集成应用里把资料来源配好。
:::

**移出系列**：单条用行内删除按钮，批量用勾选后的「移出系列」，都会二次确认。移出只解除作品与系列的关联，不删除影视条目本身。

### 别和影视里的「系列」字段搞混

影视高级编辑页里也有「系列信息」分组，用来记录该作品所属的系列名称与系列内描述。这块信息属于**影视元数据**，与系列库里的系列是两处独立数据：

| 数据 | 维护位置 | 用途 |
| --- | --- | --- |
| 影视的系列字段 | 影视库 → 高级编辑 → 系列信息 | 写入单条影视的元数据与 NFO |
| 系列实体 | 系列库 → 系列详情 | 聚合作品、生成系列页与系列分享 |

所以把作品放进系列库需要显式「添加作品」或「批量导入」，不会因为影视元数据里填了系列名就自动归属。

## 厂牌：让作品按片商自动收拢

### 找到并新建厂牌

进入 **媒体管理 → 厂牌库**：

| 区域 | 内容 |
| --- | --- |
| 操作栏 | 左侧「创建厂牌」「识别码归属测试」，右侧「搜索厂牌名称或别名」 |
| 卡片区 | 每个厂牌一张卡片，点击卡片打开详情 |

搜索框输入即过滤，清空后恢复全量列表。列表按作品总数倒序排列，作品多的厂牌排在前面。

卡片信息：

| 元素 | 说明 |
| --- | --- |
| 图像 | 鼠标悬浮显示「更换图像」，点击可直接换图 |
| 名称 | 厂牌名，右侧带星标表示已标记为「重点关注」 |
| 类型标签 | 制作商 / 发行商 / 经纪公司 / 其他 |
| 标签 | 最多展示前 2 个，其余折叠为「+N」 |
| 统计 | 「N 部影视 · N 部剧集」，有规则时追加「N 条规则」 |
| 删除 | 卡片上的删除按钮 |

点「创建厂牌」后填写：

| 字段 | 说明 |
| --- | --- |
| 厂牌名称 | 必填，需与影视元数据中的制作公司名保持一致，最长 100 字符 |
| 厂牌类型 | 制作商 / 发行商 / 经纪公司 / 其他 |
| 成立年份 | 1800–2200 的整数 |
| 国家 / 地区 | 如「日本」 |
| 官网 | 以 `https://` 开头，详情页可点击跳转 |
| 别名 | 多值，输入后回车 |
| 标签 | 多值，输入后回车 |
| 描述 | 厂牌简介，最多 500 字 |
| 厂牌图像 | 弹窗右侧上传，可点击更换 |

:::tip[名称必须与元数据一致]
厂牌与作品之间按名称做软关联，所以「厂牌名称」要和影视元数据里的制作公司名完全一致，否则统计里看不到那些作品。数据源写法不同时，用「别名」兜住差异。
:::

:::warning[删除厂牌的影响]
删除会同时移除该厂牌的规则与排除项，但**不修改任何影视或剧集元数据**，已写入作品里的厂牌名会保留。
:::

### 用识别码规则自动认领作品

厂牌的作品来源有两条路：**手动添加**与**识别码规则自动收纳**。别名用于匹配，规则用于自动判定归属。

在厂牌详情 →「识别码规则」页签维护：

| 字段 | 说明 |
| --- | --- |
| 规则类型 | 识别码前缀 / 识别码精确 / 正则表达式 |
| 匹配表达式 | 按所选类型填写，最长 200 字符 |
| 命中后写入 | 制作公司 / 发行公司 / 制作 + 发行 |
| 优先级 | -9999～9999，多条规则同时命中时按它排序 |
| 启用 | 关闭后该规则不参与判定 |
| 说明 | 备注规则的依据，如「该厂牌拥有 SSIS 系列发行权」 |
| 保存后 | 可勾选「立即按规则收纳作品到影视元数据」 |

「预览命中数量」不会真的保存，只是先算一下这条规则会命中多少作品，再决定要不要保存。

归属判定与收纳的顺序：

1. 保存影视记录时，系统会按**已启用**的规则自动把厂牌写入制作公司 / 发行公司。
2. 也可以在厂牌详情点「立即收纳作品」（规则页签里叫「立即收纳」）手动触发一次。
3. 规则命中收纳进来的作品，会在作品卡片上标注命中的规则名，方便回溯是哪条规则带进来的。
4. 把作品移出时，系统会记录一条**排除项**，避免下次自动收纳又把它拉回来。

:::note[删除规则不回滚]
删除识别码规则只影响后续判定，已经写入影视元数据的厂牌名不会被回滚。
:::

顶部「识别码归属测试」与规则页签内的测试框功能相同：输入一个识别码（如 `SSIS-001`），返回命中的厂牌与对应表达式；没命中时提示「未命中任何厂牌规则」。调规则时先用它验证，比直接保存再看结果快。

### 厂牌详情里还能改什么

点击卡片打开详情抽屉，头部是图像、名称、类型、重点关注星标、国家、成立年份、官网、描述、标签与别名，以及三项统计：**影视数、剧集数、识别码规则数**。下方三个页签：

- **作品**：顶部单选「全部 / 影视 / 剧集」切换媒体类型，右侧可按「标题或识别码」搜索；「添加作品」弹窗中按标题或识别码搜索影视，已在厂牌中的条目标注「已在厂牌」并禁用添加；作品卡片展示类型角标、标题、识别码、年份、命中来源与命中规则，操作是「查看」（跳到对应影视或剧集编辑页）与「移出」；底部按页翻页。
- **识别码规则**：规则表格列出表达式与说明、启用开关、编辑与删除；上方有「添加规则」「立即收纳」，右上可测试识别码归属。
- **资料**：可修改厂牌类型、成立年份、国家 / 地区、官网、别名、标签、描述与「重点关注」开关，保存后卡片与统计同步更新。

:::tip[重点关注]
「重点关注」只是标记，用于在卡片上显示星标；它不会改变作品收纳逻辑。
:::

## 标签：全站共用的词条来源

### 三层结构

标签库是影视、剧集、演员、漫画、小说五类内容在编辑页里能选到的标签的唯一来源。

| 层级 | 含义 | 数量 |
| --- | --- | --- |
| 媒体类型 | 内容的大类，固定五种 | 5 |
| 分类 | 每个媒体类型下的一组标签；系统默认分类 + 用户自建分类 | 5 + N |
| 标签 | 具体词条，带别名、颜色与权重 | 不限 |

五个系统默认分类：

| 卡片标题 | 媒体类型 | 标签类型 |
| --- | --- | --- |
| 影视标签 | 影视 | `tag_movie` |
| 剧集标签 | 剧集 | `tag_tv` |
| 演员标签 | 演员 | `tag_actor` |
| 漫画标签 | 漫画 | `tag_comic` |
| 小说标签 | 小说 | `tag_novel` |

用户自建分类必须归在某个媒体类型下，因此它和系统分类共用同一套媒体类型筛选。

### 页面与卡片

进入 **媒体管理 → 标签库**：

| 区域 | 内容 |
| --- | --- |
| 操作栏 | 左侧「创建分类」，右侧类型筛选下拉与「搜索标签或别名」 |
| 卡片区 | 每张卡片是一个分类，一行最多 4 个 |

顶部类型筛选切换后只保留该媒体类型的卡片；搜索框按标签名或别名过滤。

卡片标题是分类名，系统分类按「媒体类型 + 标签」命名（如「影视标签」）；标题旁徽标标注「系统」或「用户」。右上角显示「共 N 个」，即该分类下的标签数量。用户自建分类可以删除，删除后分类下的标签会**回落到系统默认分类**，不会丢标签。卡片内是标签表格：标签名（按设定颜色着色）、「引用」值（被用到的频繁程度），以及编辑 / 删除两个操作。

### 创建分类、添加与编辑标签

点「创建分类」，填名称（最多 30 字）并选择媒体类型即可。分类只用于组织标签，不参与内容检索逻辑。

卡片工具条右侧点「添加」，或在标签行点编辑图标：

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填，最长 50 字。整理时作为**主名称**写入 NFO |
| 别名 | 多值，输入后回车，可填多个 |
| 颜色 | 调色板 10 个预设色，也可直接填 HEX 值（默认 `#165dff`） |

:::note[别名的作用]
不同数据源返回同一概念的写法可能不同（中英日、简繁、缩写），把差异写进「别名」，匹配时按别名识别，最终写入 NFO 时仍以主名称为准。
:::

:::warning[删除标签的边界]
删除标签只从标签库里移除词条，**不影响已保存的元数据**：影视、演员等条目里已经写入的类型与标签文本会保留，只是之后不能再从候选里选到它。
:::

### 权重与「引用」

每个标签有一个权重值，卡片表格里以「引用」列展示：

- 标签每被命中一次，权重加 1；
- 系统会定期衰减，每次最多降 10%（向下取整），且**永不低于 1**；
- 因此它是个热度指标，可以理解成「被引用的近似次数」，不是精确的作品计数。

排序与展示用它来把常用标签排在前面，便于在编辑页快速命中。

### 日常在哪儿用到它

标签库本身提供两种检索：按媒体类型筛卡片、按标签名或别名搜索。更常见的入口是各内容编辑页的标签下拉：

| 编辑页 | 检索的标签类型 |
| --- | --- |
| 影视高级编辑 → 类型 / 标签 | 影视标签 |
| 剧集编辑 → 类型 / 标签 | 剧集标签 |
| 演员详情 → 标签 / 风格 / 特征 | 演员标签 |
| 漫画、小说编辑 | 各自的标签类型 |

这些下拉统一检索标签库（系统分类 + 用户自建分类都可见），并支持直接输入新的标签：库里没有的值会作为新标签一起提交。

:::tip[统一维护的好处]
在任一编辑页新建的标签会回到标签库对应的分类里，下次在任何内容上都能选到；想批量整理同义词，改这里的别名单次即可覆盖所有引用方。
:::

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 系列名称 | 必填 | 不填建不了系列 |
| 系列封面 | 图片，上限 10 MB | 传非图片或超大小传不上去；上传后按竖版缩略图展示 |
| 作品识别码（系列检索） | 填一个番号 | 用来反查包含该作品的系列 |
| 批量导入识别码 | 粘贴多个识别码，用逗号、换行、空格或分号分隔 | 不在库中且资料来源没配好的，会以「失败原因」返回 |
| 厂牌名称 | 必填，最长 100 字符，需与影视元数据里的制作公司名完全一致 | 写法不一致就统计不到作品；用「别名」兜住差异 |
| 厂牌类型 | 制作商 / 发行商 / 经纪公司 / 其他 | 只作为分类标签 |
| 成立年份 | 1800–2200 的整数 | 超出范围填不进去 |
| 官网 | 以 `https://` 开头 | 不是这个开头，详情页点不开 |
| 别名 / 标签（厂牌） | 多值，输完按回车加一个 | 不回车不会加进去 |
| 描述（厂牌） | 厂牌简介，最多 500 字 | 超出字数填不进去 |
| 规则类型 | 识别码前缀 / 识别码精确 / 正则表达式 | 选错类型会匹配不到或匹配过头 |
| 匹配表达式 | 按所选类型填，最长 200 字符 | 填错命中不到作品；先用「预览命中数量」或「识别码归属测试」验证 |
| 命中后写入 | 制作公司 / 发行公司 / 制作 + 发行 | 选错会写进错误的字段 |
| 优先级 | -9999～9999 | 多条规则同时命中时按它排序，设错会认错厂牌 |
| 启用（规则） | 开关 | 关闭后该规则不参与判定 |
| 识别码归属测试 | 输入一个识别码，如 `SSIS-001` | 未命中时提示「未命中任何厂牌规则」 |
| 分类名称 | 最多 30 字，并选一个媒体类型 | 分类只组织标签，不参与检索逻辑 |
| 标签名称 | 必填，最长 50 字，作为主名称写入 NFO | 不填建不了标签；主名称决定写进 NFO 的文本 |
| 标签别名 | 多值，输完按回车加一个 | 不填则只按主名称匹配，同一概念的其他写法认不出 |
| 标签颜色 | 10 个预设色，或填 HEX 值（默认 `#165dff`） | 只影响卡片上的着色 |
| 类型 / 标签下拉输入 | 从候选里选，或直接输入新词条 | 库里没有的值会作为新标签一起提交 |

## 出问题了怎么办

- **放进系列库的作品没出现在系列页**：影视元数据里填了系列名不会自动归属，要显式「添加作品」或「批量导入」。
- **批量导入有一堆失败项**：先看「失败原因」，多数是资料来源没启用或连不上；到集成应用里把资料来源配好再重试。
- **厂牌统计里看不到某些作品**：厂牌按名称软关联，「厂牌名称」要和影视元数据里的制作公司名完全一致；写法不同就把那些写法加进「别名」。
- **作品被自动收纳后又删不掉 / 又被拉回来**：移出时系统会记一条「排除项」，避免下次自动收纳再拉回来；删除规则只影响后续判定，已经写进元数据的厂牌名不会回滚。
- **规则调不准**：先用「预览命中数量」看会命中多少，或用「识别码归属测试」输入一个识别码看命中结果，再决定保存。
- **删了标签 / 分类 / 厂牌，担心作品丢数据**：删除标签只移走词条、删除自建分类标签会回落到系统默认分类、删除厂牌不修改任何影视或剧集元数据——已写入的文本都保留，只是之后不能再从候选里选到。
- **「引用」值和作品数对不上**：它是带衰减的热度指标，不是精确计数；常用标签排前面只是为了方便编辑页快速命中。
