# 片库体检

片库体检负责把「看起来不对劲」的地方集中找出来：订阅停了、播放进度指向已删除的片子、存储目录打不开、海报缺失等等。它只做检查，不会自己改数据；要修哪一条，由你手动点。

## 入口

点击右上角头像，在下拉菜单里选「片库体检」。

:::note[为什么媒体管理菜单里没有]
这是有意设计的：体检入口只保留在头像菜单，媒体管理侧边栏不显示，避免和日常的媒体管理操作混在一起。直接访问地址是 `/admin/media/health`。
:::

## 体检是只读的

页面顶部写着「体检本身只读，不会修改任何数据；修复动作需要手动触发」。意思是：

- 打开页面、切换筛选、点「开始体检」，都不会删改任何东西
- 只有你点某条问题后面的修复按钮，才会真正执行修改
- 涉及删除的操作会先弹二次确认，部分还会标注「不可撤销」

## 能查出什么

| 分类 | 用大白话说 |
| --- | --- |
| 失效文件绑定 | 数据库里记着这个文件，但磁盘上已经找不到，或标记为不可用 |
| 缺海报 / 背景图 | 有这部片子，但本地没有海报或背景图 |
| 封面比例异常 | 封面尺寸比例不符合规范 |
| 重复文件 | 同一个扫描路径、同一个番号或同一个文件被记录了多次 |
| 未匹配番号 / 元数据 | 扫描到了文件，但还没认出是哪部作品 |
| 扫描残留 / 孤儿 | 扫描留下的无效记录，或没有任何文件对应的元数据 |
| 漫画页丢失 | 章节记录还在，但磁盘上的漫画图片已被删除或磁盘不可用 |
| 订阅异常 | RSS 订阅被停用、长期没更新；影视订阅暂停或长期匹配不到 |
| 播放进度异常 | 播放进度指向已经删除的影片、文件，或文件不可用 |
| 存储目录异常 | 数据目录不存在，或没有写入权限 |
| 元数据不完整 | 上映日期、时长、简介这类核心信息缺了 |

「扫描残留 / 孤儿」里有一类叫「元数据无文件」，它可能是你特意保留的纯资料条目，所以系统默认不给它删除按钮。

## 严重度怎么看

| 级别 | 含义 | 建议 |
| --- | --- | --- |
| 严重 | 会直接影响播放、刮削或数据安全 | 优先处理 |
| 警告 | 功能还能用，但状态不对 | 有空再修 |
| 提示 | 只是不够整齐，不影响使用 | 可以忽略 |

## 筛选和搜索

- **库类型**：影视、剧集、漫画、订阅、系统
- **严重度**：严重、警告、提示
- **关键字**：搜标题、路径或番号

列表里每条会显示封面、条目、关键信息、状态和可用操作。没有可执行操作的条目会显示「只读」。

## 哪些能一键修

| 按钮 | 实际会做什么 | 注意 |
| --- | --- | --- |
| 重新检测 | 重新看磁盘上的文件还在不在，更新可用状态 | 安全 |
| 重新刮削 | 提交一个后台刮削任务，重新抓元数据和图片 | 不会立刻完成，需要等任务跑完 |
| 忽略 | 标记为忽略，以后扫描不再提示这一条 | 安全 |
| 清除标记 | 只清掉「封面比例异常」标记，不动封面文件 | 安全 |
| 删除绑定 | 只删数据库里的文件绑定记录，**不删磁盘文件** | 安全 |
| 解除引用 | 解除失效的元数据引用，条目回到未匹配状态 | 安全 |
| 合并重复 | 按现有规则保留最早一条，删除或合并其余记录 | **不可撤销** |
| 立即抓取 | 立刻抓一次这条 RSS 订阅的最新内容 | 安全 |
| 启用订阅 | 把停用的 RSS 订阅重新打开，之后按计划抓取 | 安全 |
| 重新匹配 | 清空匹配次数、恢复订阅状态，重新进入匹配队列 | 安全 |
| 删除进度 | 删掉指向失效影片或文件的播放进度记录 | 不影响影片和文件本身 |
| 存储管理 | 跳到存储管理页面查看磁盘和目录状态 | 只是跳转 |

## 批量修复

1. 勾选多条问题。
2. 底部出现「已选 N 条」，点「批量修复」。
3. 只有所有选中条目都支持的修复动作才会出现在选项里；没有共同动作时会提示「所选条目没有共同可用的修复动作」。
4. 弹窗会写明本次影响多少条，确认后执行。

执行完会汇总提示「已处理 N 条」，或「成功 X 条，失败 Y 条」。

## 体检记录

- 点「开始体检」会生成一条新记录，完成后统计和列表自动刷新
- 「历史记录」里能看到开始时间、状态、结果、耗时和触发方式
- 触发方式分「手动」和「定时」；状态有「运行中」「已完成」「失败」
- 点「查看」可以看这一次体检的分类明细

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 点修复没反应 | 可能是这条只读，或需要先勾选再批量修复 |
| 修复后列表没变 | 重新检测类操作会立即刷新；刮削、抓取是后台任务，要等完成后再看 |
| 删除绑定后文件还在 | 正常，删除绑定只清理数据库记录 |
| 存储目录异常修不了 | 这类问题要人工处理，按提示去「存储管理」检查挂载和权限 |
