# 下载与入库

这一页讲的是**资源离开检索页面之后**的事：它被交给哪个下载工具、文件落在哪里、在哪里看进度，以及下载完成后还要做什么才能进入媒体库。

## 先说清楚

> **下载器**：真正负责下载的程序（这里是 qBittorrent）。AMMDS 只负责把任务交给它，下载本身由它完成。

> **分类 / 标签**：下载器里给任务贴的记号。有了它们，你在一堆任务里一眼就能筛出 AMMDS 提交的那几个。

> **做种**：下载完成后继续把文件分享给别人。做种期间不要删文件，否则分享会中断。

> **辅种**：把同一份文件再挂到别的站点上，不用重复下载。

## 一步一步做

### 看一眼下载器连上没有

进入 **工具箱 → 下载器 → 插件信息**，能看到下载器的地址、账号、默认保存路径、版本和当前任务总数。插件没启用时页面只显示「插件未启用」，不会去连。

### 提交一个任务

三种方式都会落到同一个任务列表：

| 方式 | 入口 | 提交时带的记号 |
| --- | --- | --- |
| 站点搜索推送 | 检索结果右侧的下载器按钮 | 分类 `AMMDS` |
| 磁力搜索推送 | 检索结果右侧的下载器按钮 | 分类 `AMMDS` |
| 订阅自动下载 | 订阅命中资源后自动提交 | 标签 `AMMDS订阅` 和 `subscribe-<订阅ID>`，保存路径用订阅规则里填的目录 |

手动新建也可以：点「新建任务」，在弹窗顶部切换两种模式。

| 模式 | 填什么 |
| --- | --- |
| 磁力下载 | 把磁力链接粘进「下载链接」，多个链接换行分隔 |
| 种子文件 | 上传一个或多个 `.torrent` 文件 |

### 看进度

进入 **工具箱 → 下载器 → 任务管理**，列表每 5 秒自动刷新一次（页面切走时暂停）。

| 列 | 说明 |
| --- | --- |
| 文件名称 | 种子名称，下面一行是保存路径 |
| 状态 | 下载器状态翻译成中文，例如下载中、上传中、获取元数据中、排队等待、已暂停、校验中、移动文件、缺少文件、错误状态 |
| 速度 | 下载速度与上传速度 |
| 大小 | 任务总大小 |
| 分类 / 标签 | 提交时写入的记号 |
| 进度 | 进度条，跑完是 100% |

### 批量处理

先在列表里勾选任务，再用顶部按钮：

| 按钮 | 做什么 |
| --- | --- |
| 开始下载 | 让勾选的任务继续下载 |
| 暂停下载 | 暂停勾选的任务 |
| 删除任务 | 二次确认，可选「删除原文件」或只删任务 |

:::warning[删文件不可恢复]
删除弹窗里，确认按钮是「删除原文件」，取消按钮才是「删除任务」。点了确认，已经下好的数据会一起删掉。正在做种或准备辅种的任务，先确认相关流程已经停下再删。
:::

### 下完之后还要做什么

下载器只负责把文件放到磁盘上，**不会自动进媒体库**。要让 AMMDS 认识这些新文件，需要跑一次扫描任务（在「任务管理」栏目里），或者把文件放进已经开启目录监控的目录。

## 设置项说明

手动新建任务时可以填这三项，都不填也能提交：

| 设置项 | 管什么 / 怎么填 | 不填会怎样 |
| --- | --- | --- |
| 分类 | 下载器里的分类名 | 没有分类，任务混在默认分类里 |
| 标签 | 输入后按回车确认，多个标签用逗号分隔 | 没有标签 |
| 保存路径 | 文件存到哪个目录 | 用下载器的默认保存路径 |

## 与辅种的关系

下载器任务和辅种任务是两套记录，别混着看：

- **下载器任务**反映下载和做种进度。
- **辅种**由「工具箱 → PT 辅种」通过别的站点完成，有自己的计划、站点配置和记录。辅种计划可以选 qBittorrent 或另一种客户端，跟检索页面「推送下载」的目标不是同一个设置。
- 下完之后文件继续由下载器做种，辅种会在其他站点创建新的种子任务指向同一份文件。删文件之前，先确认这两类任务都停了。

## 出问题了怎么办

- **推送后提示失败**：下载器没启用，或者地址、账号写错了。先在下载器插件页测一下连接。
- **推送成功但列表里没有任务**：切到第一页、清空筛选再看，或者直接在下载器里确认。
- **任务卡在「获取元数据」**：磁力没有可用的做种者，换用种子文件试试。
- **任务显示「缺少文件」**：保存路径被挪走或文件被删了。把文件放回去重新校验，或删掉任务重新下。
- **订阅一直不显示完成**：下载器里的任务被移除了，或系统没查到它的完成进度。在订阅管理里重新提交一次。

想重新找资源、改订阅规则，见[找资源与订阅](./search.md)。
