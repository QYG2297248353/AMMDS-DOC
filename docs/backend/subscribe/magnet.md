# 磁力检索

「磁力搜索」通过 BitMagnet 服务检索磁力资源，支持服务端分页与排序，并可在结果中直接查看种子文件列表、复制磁力链接或推送到 qBittorrent。

{/* truncate */}

## 打开方式

在 **订阅检索 → 磁力搜索** 打开页面。输入关键词后按回车或点击搜索按钮，结果以列表形式展示。

:::note[前置条件]
磁力检索依赖 [BitMagnet](/docs/integration/indexer/bitmagnet) 插件。插件未启用或服务地址不可用时，搜索会失败并提示错误；页面本身不内置任何磁力索引。
:::

## 检索与分页

| 项目 | 说明 |
| --- | --- |
| 关键词 | 电影、电视剧、音乐、游戏等任意文本；空关键词会被拦截并提示 |
| 每页条数 | 固定 20 条 |
| 总数 | 使用后端返回的 `totalCount`，分页组件据此计算页数 |
| 翻页 | 按目标页码重新请求，不改变排序与关键词 |
| 排序变化 | 回到第 1 页并重新搜索，排序由服务端执行 |

历史搜索保存在浏览器本地，最多 20 条；没有结果时显示在搜索框下方，点击即可重新检索。

## 筛选与排序

| 控件 | 可选值 | 执行位置 |
| --- | --- | --- |
| 排序字段 | 相关性、文件大小、发布时间、文件数量 | 服务端排序 |
| 排序方向 | 降序、升序 | 服务端排序 |
| 来源 | 当前页结果中出现过的来源名称 | 前端过滤当前页 |

「共找到 N 个结果」显示的是后端返回的总数，来源筛选只影响当前页展示，不会改变该总数。点击「重置」会清空来源筛选，并把排序恢复为「相关性 / 降序」。

:::tip[来源筛选的范围]
来源过滤只针对已经加载的当前页数据。若需要跨页筛选某个来源，请先调整关键词或排序，让目标结果集中到同一页。
:::

## 结果字段

| 字段 | 说明 |
| --- | --- |
| 缩略图 | 按磁力链接获取预览截图；获取失败时显示占位图标 |
| 来源数量 | 封面左下角显示该种子命中的来源数量 |
| 标题 | 点击后在新窗口打开磁力链接 |
| 大小 / 发布时间 | 文件总大小与发布时间 |
| 做种数 / 下载数 | 大于 0 时显示，分别带上升与下降图标 |
| 文件数量 | 种子包含的文件数 |
| 单文件 | 种子为单文件时显示「文件」标签 |
| 来源 | 结果命中的全部来源名称，逐个小标签展示 |

## 文件列表与文件树

当种子带有文件信息且不是单文件时，结果卡片会展开「文件信息」区域：

- 列表只展示前 5 个文件，避免撑高卡片。
- 点击「文件树」打开弹窗，按目录层级展示完整结构，文件夹与文件分别带图标与大小。
- 文件树按 `infoHash` 单独加载；加载失败时清空数据并提示，不会残留上一次的结果。

单文件种子不请求文件列表，只显示「单文件: 种子名称」。

## 结果操作

| 操作 | 行为 |
| --- | --- |
| 复制磁力 | 把磁力链接写入剪贴板，成功或失败都有提示 |
| 推送下载 | 把磁力链接提交给 qBittorrent，固定使用分类 `AMMDS` |
| 打开标题 | 在新窗口打开磁力链接，由系统关联的下载工具接管 |

:::warning[推送目标]
磁力结果只提供「推送到 qBittorrent」，不支持选择其他下载器。推送成功后到 [下载器使用](/docs/backend/subscribe/downloader) 或 **工具箱 → 下载器 → 任务管理** 查看任务。
:::

## 与站点检索的区别

| 维度 | 站点资源检索 | 磁力检索 |
| --- | --- | --- |
| 数据来源 | 已启用的 PT 站点 / 索引器 | BitMagnet 的磁力索引 |
| 分页 | 一次性返回全部结果 | 服务端分页，每页 20 条 |
| 排序 | 前端排序 | 服务端排序 |
| 下载方式 | 种子文件或直链 | 磁力链接 |
| 适用场景 | 需要站点促销、做种数等 PT 字段 | 查找公网磁力资源 |

需要按番号持续跟踪并自动下载时，使用 [订阅管理](/docs/backend/subscribe/manage)；需要 PT 站点的促销与做种信息时，使用 [站点资源检索](/docs/backend/subscribe/search)。
