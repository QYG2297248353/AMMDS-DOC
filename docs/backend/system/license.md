# 许可证

许可证是**部署实例级**的授权：它决定当前这套 AMMDS 是否处于有效授权状态，以及未授权时的水印表现。未授权**不会锁住功能**，登录、系统配置、站点认证与媒体库都照常可用，只是全站显示水印。

{/* truncate */}

## 打开方式

点击右上角头像 → **用户中心**，页面底部的「许可证」卡片即本页内容。也可以从[系统检查](/docs/backend/system/system-check)的「许可证」项快速判断当前状态。

- 所有登录账号都能查看授权状态与权益明细。
- 只有管理员能激活、刷新、试用、停用与清除授权；其他账号看到的是只读视图，并提示「仅管理员可修改实例许可证」。

## 状态明细

| 字段 | 说明 |
| --- | --- |
| 授权状态 | 有效 / 无效 |
| 激活方式 | 在线激活、离线激活或未激活 |
| 套餐 | 套餐名称；鼠标悬浮可看套餐 ID，名称未下发时显示「套餐名称暂不可用」 |
| 许可证有效期 | 到期时间，长期授权显示「永久 / 未返回」 |
| 密钥 | 脱敏后的许可证密钥，未保存过显示「未保存」 |
| 最近成功校验 | 上次在线校验通过的时间 |
| 试用状态 | 已使用 / 未使用 |
| 试用截止 | 仅在试用相关状态下展示 |
| 实例标识 | 本部署的稳定标识，离线激活时要用到 |

## 状态含义与提示

页面顶部会根据当前状态给出不同的提示条：

| 状态 | 提示 | 含义 |
| --- | --- | --- |
| `TRIAL_ACTIVE` | 试用进行中（剩余 x 小时 y 分钟），到期后水印恢复 | 7 天试用期内 |
| `TRIAL_EXPIRED` | 7 天试用已结束，且不能再次试用 | 试用到期，需激活许可证 |
| `GRACE` | 暂时无法连接许可证服务，正在使用已验证的许可证（离线宽限至 …） | 断网但仍在宽限期 |
| `CHECK_UNAVAILABLE` | 无法连接许可证服务且已超出离线宽限期 | 需要恢复网络后刷新 |
| `LICENSE_INVALID` | 许可证当前不可用（可能已到期、撤销、暂停或未激活） | 去 Keygate 门户核对状态 |
| `LICENSE_PLAN_MISCONFIGURED` | 套餐缺少 `ammds.license.base_access`，水印保持开启 | 属于套餐配置问题，需联系维护人员 |

:::info[授权怎么判定]
后端读取 Keygate 返回的权益，其中 `ammds.license.base_access` 为真即视为有效许可证并关闭全站水印。`ammds.full_access` 不再作为基础授权键。判定以服务端验签结果为准，修改页面或映射文件都不会影响授权结论。
:::

## 权益明细

有效的许可证会展示一张权益表：

| 列 | 说明 |
| --- | --- |
| 名称 / 描述 | 由权益映射文件提供的中文名称与说明 |
| 标识符 | Keygate 返回的权益标识，如 `ammds.license.base_access` |
| 类型 | 布尔、整数、数字、字符串或对象 |
| 功能 | 布尔显示「开启 / 关闭」；带配额的权益显示为 `已用/上限（周期）` |

映射文件里没有登记的权益不会被隐藏，而是直接以标识符作为名称展示，描述留空。因此新增权益不需要改前端。

## 激活方式

### 在线激活

1. 在「在线激活」区域填入 Keygate 许可证密钥，形如 `KG-XXXX-XXXX-XXXX-XXXX`。
2. 点「激活」，由 AMMDS 后端直接调用 Keygate 完成激活。
3. 成功后状态区立即更新，水印随之关闭。

完整密钥只在本次提交时使用，不会保存在浏览器里。

### 离线激活

服务器访问不了 Keygate 时使用：

1. 点「离线激活」，页面给出产品 ID、实例标识与实例标签，并生成一条可直接复制的调用命令。
2. 在另一台联网设备上执行该命令（把占位符替换为你的密钥与一个随机 UUID，重试请沿用同一个 UUID）。
3. 把返回的 JSON 保存为文件，回到本页上传（不超过 64 KiB）。
4. 导入成功后状态更新。

### 更换许可证

已激活的实例默认隐藏激活区，需要点右上角「更换许可证」才会展开。更换会替换当前授权；如果试用仍在进行，激活成功后试用立即结束，且不会在新许可证到期后恢复。

## 试用与维护

| 操作 | 规则 |
| --- | --- |
| 开始 7 天试用 | 每个部署数据库只能启动一次；按服务端时间连续计时，停机期间也计入；已有完整授权或已用过时按钮置灰 |
| 在线刷新 | 主动向 Keygate 校验一次；服务暂时不可用时返回当前缓存状态 |
| 停用在线许可证 | 远端确认释放槽位后才清除本地资料 |
| 仅清除本地授权 | 只清本机的密钥与令牌，不释放远端槽位，也不清除试用记录 |

:::warning[清除操作不可撤销]
「停用」和「仅清除本地授权」都需要显式确认。清除后如需恢复授权，必须重新激活。
:::

## 会员与许可证的关系

- **会员（VIP）**是账号维度的标识，展示在用户中心头部；**许可证**是部署实例维度的授权，两者独立。
- 通过[官方商城](/docs/backend/account/store)购买的服务用于支持项目持续开发，具体套餐名称、价格与权益范围**以购买页与许可证页展示为准**，本文不罗列。
- 购买后拿到的是许可证密钥，回到本页激活即可；权益明细表会按 Keygate 的返回逐项列出。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 水印一直在 | 授权无效或未激活；先看状态与提示条，再按提示激活或刷新 |
| 「开始 7 天试用」是灰的 | 已有完整授权、试用已用过或试用进行中 |
| 离线激活失败 | 实例标识不一致、响应文件超过 64 KiB、或文件不是 Keygate 的激活响应 JSON |
| 状态显示宽限期 | 网络暂时不通，恢复网络后点「在线刷新」 |
| 套餐显示「套餐名称暂不可用」 | Keygate 未下发名称而已，套餐 ID 仍可正常展示 |
| 系统检查里许可证是警告 | 与本节同一套状态判定，处理方式一致 |
