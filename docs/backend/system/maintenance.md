# 系统检查、日志、存储、许可证与用户

这一页是「出问题先来这儿」的一页：先做一次自检，再看日志和空间，顺带处理授权、账号安全和后台任务。每节都能单独看。

## 一、系统检查：先跑一次

> **系统检查**：内置的自检工具。它只读配置和状态，不改任何东西，也不自动修复。

点右上角头像 → **系统检查**。进页面先看一张只读快照：版本号、操作系统、内存、磁盘剩余、服务端口、数据库、已运行时长、数据目录（AMMDS 存放资料和文件的文件夹）、服务器时间和时区。

点「开始扫描」，扫描在服务器上跑，完成后顶部显示正常、警告、异常、未启用各有多少项，以及这次花了多久。

### 检查哪些东西

| 分组 | 关注什么 |
| --- | --- |
| 基础信息 | 版本、操作系统、内存、磁盘、系统时间、外网连接 |
| 软件配置 | 依赖程序有没有就绪、代理配置完不完整、各集成服务能不能连上 |
| 系统配置 | 服务端口、数据库连接、域名绑定、通知渠道、许可证 |
| 运行状态 | 日志里的错误数量、处理器和内存压力、磁盘压力 |

几个常见的判定标准：

- **内存**：占用超过九成，或系统可用内存不足一成，会警告。
- **硬盘**：数据目录剩余不足 1GB，或使用率超过九成，会警告。
- **系统时间**：和网络时间相差超过 5 分钟会警告，影响授权校验、定时任务和时间判断。
- **网络连接**：并行探测一批地址，全部可达才算正常；只通一部分是警告，全不通是异常。
- **依赖程序**：缺了会给出警告，并说明会影响哪些功能（例如缺视频处理程序会影响视频处理、截图、封面裁剪、缩略图）。
- **代理**：没开记成「未启用」；开了但主机或端口空着、端口不在 1–65535，记成异常。
- **集成服务**：没启用不算问题；启用了但缺必填配置是警告；地址填了却连不上是异常。

### 结果怎么读

| 状态 | 意思 | 要不要动手 |
| --- | --- | --- |
| 正常 | 符合预期 | 不用 |
| 警告 | 能用但有隐患，功能可能受限 | 按提示处理 |
| 异常 | 功能已经不可用或配置明显错了 | 必须处理 |
| 未启用 | 这个东西本身没开 | 不用，除非你需要它 |

有些条目还带标签：「需要配置」让你去对应页面补齐参数；「需要重启」表示改动后要重启服务才生效；「受影响功能」指出这条问题会波及什么。

## 二、日志：三类各看各的

**系统管理 → 日志审计** 下有三个页面：

| 页面 | 看什么 | 适合排查 |
| --- | --- | --- |
| 登录日志 | 谁在什么时候登录过，成功失败都记 | 密码错误、账号被禁用、异常来源 |
| 运行日志 | 服务器上刚刚发生了什么 | 页面报错、服务异常 |
| 任务日志 | 后台任务跑到哪一步、为什么失败 | 扫描、刮削、整理、同步、导入导出失败 |

### 登录日志

字段有：用户名、来源地址、登录地点、时间、设备信息（系统 / 设备 / 浏览器）、状态和原因。可以按关键词和登录状态筛选，每页 10 条，从新到旧。失败原因来自登录校验，例如「用户名不存在」「账号已被禁用」「密码错误」；成功记录为「登录成功」。

### 运行日志

字段有：时间、线程、级别、来源、消息。级别分四档：错误（红）、警告（橙）、信息（蓝）、调试或正常。页面默认取最近 300 条，每 8 秒自动刷新一次。

右上角可以选「最近 1 天 / 7 天 / 30 天」导出：系统把主日志和按天滚动的日志拼成一个文本文件，总体积超过 100MB 时裁掉最旧的部分。日志存在数据目录下，主文件按天滚动，错误单独存一份。

### 任务日志

工具栏显示执行中的任务数，可以按任务名称、类型、状态筛选，也能开自动刷新。列表列有任务、类型、状态、进度、已完成 / 总量、耗时。点「详情」能看到失败原因、开始结束时间和**执行明细**——逐条列出时间、级别和消息，这是定位失败原因最直接的材料。

可执行的操作：详情（随时）、取消（只有执行中且支持取消的任务）、删除（非执行中）、清理已完成（清掉全部已结束的任务，执行中的保留）。

### 建议的排查顺序

1. 先到**任务日志**找到失败的那次，看执行明细里第一条错误。
2. 记住时间，回**运行日志**看同一时刻的上下文。
3. 涉及服务地址、钥匙或网络的，用**系统检查**确认。
4. 怀疑是登录或权限问题，再看**登录日志**。

## 三、存储：空间被谁占了

进入 **系统管理 → 存储管理**，看四个数字：磁盘总空间、磁盘已用、磁盘可用、数据目录占用。后面两者之差，通常是影片原文件、系统占用和其他程序。

统计由后台定时执行（启动时一次，之后每 5 分钟一次），页面每 30 秒刷新。数据目录按一级子目录拆开统计大小和文件数，图片目录还有二级细分。常见分类：图片、缓存、视频处理程序、字幕、元数据服务、密钥、日志、临时文件；没登记的子目录归到「其他数据」。

:::warning[不要手工删目录]
数据目录里的密钥目录和数据库目录保存着凭据和全部资料。运行中直接移动或删除可能造成数据损坏，要清理请用下面这些页面上的入口。
:::

这个页面是只读的，清理入口分散在各处：

| 想清理什么 | 去哪儿 |
| --- | --- |
| 任务日志 | 日志审计 → 任务日志 → 清理已完成 |
| 导出的备份包 | 备份与恢复 → 数据导出 → 导出记录 → 删除 |
| 资讯离线缓存 | 信息中心 → 资讯 → 缓存面板 → 清理缓存 |
| 没用的文件和临时文件 | 工具箱 → 文件浏览器 → 删除 |
| 服务下载的资源 | 对应服务页面的资源卡片 |

空间不够会怎样：系统检查的硬盘项在剩余不足 1GB 或使用率超过九成时警告；开启「系统配置 → 基础配置 → 磁盘监测」后，空间不足会主动推送通知；刮削、下载、转码都要临时空间，空间耗尽时这些任务会失败。

## 四、许可证与水印

> **水印**：页面上一层半透明的字样。没有有效授权时全站显示它，但**所有功能照常能用**，登录、系统配置、站点认证、资料备份都不受影响。

> **密钥**：这里指授权用的一串字符，相当于这套部署的授权凭证。

点右上角头像 → **用户中心**，页面底部的「许可证」卡片就是它。所有登录账号都能看状态和权益，**只有管理员能激活、刷新、试用、停用和清除**。

### 状态怎么读

页面上会显示授权状态（有效 / 无效）、激活方式、套餐、有效期、密钥（脱敏）、最近成功校验时间、试用状态和本部署的实例标识。顶部提示条会说明当前处于哪种情况：

| 提示 | 意思 | 该做什么 |
| --- | --- | --- |
| 试用进行中（还剩多久） | 7 天试用期内，到期后水印恢复 | 到期前激活 |
| 试用已结束且不能再次试用 | 这份数据只能试用一次 | 激活许可证 |
| 暂时连不上授权服务，正在用已验证的授权（离线宽限至某个时间） | 断网但还在宽限期 | 恢复网络后刷新 |
| 连不上授权服务且已超出宽限期 | 需要网络 | 恢复网络后刷新 |
| 授权当前不可用 | 可能到期、撤销、暂停或未激活 | 去授权门户核对 |
| 套餐缺了基础授权项 | 套餐配置问题 | 联系维护人员 |

### 三种激活方式

| 方式 | 怎么做 |
| --- | --- |
| 在线激活 | 填入形如 `AMMDS-XXXX-XXXX-XXXX-XXXX` 的密钥，点「激活」，系统直接完成激活，水印随即关闭 |
| 离线激活 | 服务器访问不了授权服务时用：点「离线激活」拿到产品 ID、实例标识和一条可直接复制的命令，在另一台联网设备上执行，把返回的 JSON 存成文件（不超过 64 KiB）再上传回来 |
| 7 天试用 | 不需要密钥，点一下就开始连续倒计时，停机期间也照算 |

已激活的实例默认隐藏激活区，点右上角「更换许可证」才会展开；更换会替换当前授权，试用进行中时激活成功会立即结束试用。

### 几个规则

| 操作 | 规则 |
| --- | --- |
| 开始 7 天试用 | 每份部署数据只能开始一次；已有完整授权或已用过时按钮是灰的 |
| 在线刷新 | 主动校验一次；服务暂时不可用时返回当前缓存的状态 |
| 停用在线授权 | 远端确认释放后才清除本地资料 |
| 仅清除本地授权 | 只清本机的密钥和令牌，不释放远端位置，也不清试用记录 |

停用和清除都需要确认，且不可撤销。会员是账号上的标识，许可证是这套部署的授权，两者独立；具体套餐名称、价格和权益范围以购买页与许可证页的展示为准。

## 五、用户与登录安全

AMMDS 是自托管的单管理员应用：一个实例只有一个管理员账号，重点是**把唯一的入口守住**。

| 角色 | 说明 |
| --- | --- |
| 管理员 | 唯一能改实例授权、执行敏感操作的账号 |
| 用户 | 能登录使用业务功能，但不能改实例级授权 |
| 游客 | 没登录访问公开页面，受公共接口限流约束 |

初始管理员在首次启动时创建：提供了 `ADMIN_USER` / `ADMIN_PASS` 就按环境变量自动建号，没提供则由初始化向导创建。**部署完成后第一件事就是改掉初始密码**。

### 登录是怎么校验的

密码在提交前会先在浏览器里加密，明文不会发出去；校验用户名、密码和账号状态，开了两步验证再校验动态码。

> **登录令牌**：登录成功后拿到的一张通行证，之后每次操作带上它就不用重复输密码。访问令牌有效期 120 分钟，刷新令牌 30 天。每次登录尝试都会写进登录日志，成功失败都留痕。

密码强度要求（登录、改密、重置三处一致）：**6–22 位，同时含大写和小写字母，且至少含一个数字或一个符号**。

### 安全巡检四步

1. 打开**登录日志**，按状态筛「失败」，看有没有连续尝试；按地址或地点筛，确认有没有异地登录。
2. 发现异常先改密码，再启用两步验证或免密码登录。
3. 账号被禁用时登录会直接失败，日志里记录原因。
4. 忘记密码时用下面的恢复密钥重置。

### 两步验证

> **两步验证**：登录时除了密码，还要再输一次手机上的 6 位动态码。密码泄露了对方也进不去。

入口：**系统配置 → 安全配置 → 两步验证**。

1. 打开总开关。
2. 点「启用」，走四步向导：看说明 → 扫码（也可手动输入密钥）→ 输入认证器里的 6 位验证码 → 完成。
3. 完成时会生成 **8 个一次性恢复码**，可以复制或下载保存，每个只能用一次。
4. 关闭时同样要验证：输入认证器当前的 6 位码，或者一个还没用过的恢复码。

恢复码用完了，先关闭再重新启用，会重新生成 8 个。收不到动态码时先校准设备时间，动态码依赖时间同步。

### 免密码登录

入口：**系统配置 → 安全配置 → 免密码登录**。用指纹、面容或设备密码登录。开启前必须同时满足三个条件：

| 条件 | 不满足时 |
| --- | --- |
| 用域名访问（不是地址端口，也不是本机地址） | 提示先绑定域名并用域名访问 |
| 加密方式访问（地址以加密协议开头） | 提示浏览器不会提供认证器 |
| 浏览器支持这种认证方式 | 提示换较新的浏览器 |

满足后点「创建」，系统会调起本机的认证方式（例如系统生物识别、手机），确认后出现在列表里：显示名称（可重命名）、创建时间、最近使用，操作是重命名和删除。删除后这个设备就没法用它登录了。免密码登录和第三方登录**不需要**再验动态码。

### 统一登录

入口：**系统配置 → 安全配置 → 统一登录**，接第三方账号登录。

1. 复制页面给出的回调地址，填到身份提供方的回调白名单里。
2. 点「创建应用」，填应用名称、图标、按钮文案、客户端 ID 与密钥，以及用户映射字段（默认是身份标识）。
3. 保存后可以绑定自己的第三方账号，也能随时解绑或停用。
4. 登录页会出现对应的按钮。

客户端密钥只存在本机数据库，页面上不会显示；删除应用会让入口立刻失效。

### 设置项说明：安全相关

| 设置项 | 管什么 / 怎么填 | 不填会怎样 |
| --- | --- | --- |
| 免密码登录总开关 | 是否允许用指纹、面容等登录 | 默认关闭 |
| 两步验证总开关 | 登录是否要追加动态码 | 默认关闭，只用密码 |
| 游客访问限流 | 未登录访问公开接口的次数上限（次/分钟，默认 100） | 由系统直接读取，页面没有修改入口 |

## 六、密钥与找回密码

**系统管理 → 密钥管理** 这里说的是**接口钥匙**：给别的程序用的凭证。

| 列 | 说明 |
| --- | --- |
| 名称 | 创建时填的用途说明，旁边标注「正常」或「已过期」 |
| 密钥 | 点标签就复制完整的钥匙 |
| 类型 | 浏览器插件用 / 接口调用用 / 漫画阅读器用 |
| 过期时间 | 到点自动失效，标签变红 |
| 操作 | 删除（二次确认，删了不可恢复） |

> **API Key**：给别的程序用的一串钥匙。程序带着它来请求，就能证明「这是我允许的调用」，不需要你的账号密码。

创建时填：名称（必填）、类型（必填）、过期时间（可留空表示长期有效；填的话必须比当前时间晚至少 10 分钟）。

:::warning[类型不能混用]
三种类型分别只对各自的用途生效：接口钥匙只在开放接口下有效，不会放行后台管理接口；漫画阅读器用的钥匙只服务对应接口。用错会得到「未授权」。开放接口还要在[系统设置项逐条说明](./config.md)里把「开放接口」打开。
:::

**找回管理员密码**走另一条路，用的是一次性恢复密钥：它存放在数据目录的一个文件里，只在磁盘上，不会显示在页面上，也不会写进日志。登录页点「忘记密码」，填入恢复密钥和新密码提交，成功后这个文件会被销毁，成为一次性凭证。文件不存在时重启服务就会重新生成。

新密码同样要满足强度要求。常见提示对照：「恢复密钥不存在」说明用过了或还没生成；「恢复密钥错误」是内容不对；「密码过于简单」是不满足强度；「管理员账户异常」是管理员账号数不等于 1。

日常改密请走个人中心（要提供当前密码），和「忘记密码」是两条独立的路。

## 七、后台定时任务

进入 **系统管理 → 计划任务**，能看到系统内置的全部调度任务：多久跑一次、上次成功没有、现在是不是在跑，也可以手动补跑一次。

列表显示任务名称（副标题是它属于哪个模块）、执行周期（人话描述，鼠标悬浮能看原始表达式）、运行状态、上次执行时间，操作是「执行」。点「执行」会立即返回，任务在后台开始跑；执行中不能重复触发。

> **Cron**：一行表示「什么时候跑」的定时表达式，例如「每天 04:45」「每 5 分钟」。页面会把它翻成人话，认不出来的直接显示原文。

本页只保留每个任务**最近一次**的执行时间和结果，不提供历史列表。要看完整过程，去**任务日志**按类型或状态筛选，点「详情」看逐条明细。

:::warning[关掉总开关不等于全停]
总开关（安装时由对应环境变量控制，默认开启）关闭后：页面提示「计划任务已关闭」，手动执行会被拒绝；由配置注册的周期任务（例如自动辅种）不再注册；但程序内置的任务仍会照常执行。想彻底停掉某类自动行为，还要同时关掉对应的功能开关。
:::

## 出问题了怎么办

- **扫描结果一堆警告**：先处理「异常」，再看带「需要配置」标签的条目，改完点「重新扫描」复查。
- **系统时间差太多**：校准宿主机时间后重启；同时检查免代理名单里时间校验用的域名还在不在。
- **任务一直显示执行中**：去任务日志看是不是卡在同一进度，必要时取消后重跑。
- **空间告警**：按本文第三节的入口清理，别手工删数据目录里的文件。
