# 扫描：让 AMMDS 认识你的文件

把硬盘里一堆视频交给 AMMDS，第一步是「扫描」：让它先看到有哪些文件，登记下来，之后才能补资料、整理归类。这一页讲怎么建扫描任务、怎么挑要扫的文件、怎么安排文件搬去哪、怎么让它自己跑，以及去哪看结果。

## 先说清楚

> **扫描**：程序到你指定的目录里，把符合要求的视频文件一个个登记下来。它只认文件，还不会去查影片资料。

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。扫描之后才有刮削。

> **番号 / 识别码**：影片的识别编号，通常写在文件名里。搜索条件里叫「番号」，详情和编辑页里叫「识别码」，指的是同一样东西。

> **元数据**：一部片子的封面、简介、演员、标签这些描述信息。

> **NFO**：和视频放在一起的一个小说明文件，里面记着片名、演员等信息。播放器能读它，AMMDS 也能从它恢复资料。

> **Cron**：一串用数字和符号写成的「什么时候跑」的时间表，比如每天几点、每隔几小时。

> **白名单**：一张「只认这些」的清单。不在清单里的东西一律跳过。

> **并发**：好几件事同时抢着做。

> **占位符**：格式串里用 `{}` 包起来的记号，填的时候会被真实内容替换，比如片名、番号、演员名。

:::tip[扫描和刮削是两件事]
扫描只登记文件名和媒体信息，**不做番号识别，也不会自动补资料**。想让封面、简介、演员都填好，接着看[刮削：自动补齐影片信息](./scrape.md)。
:::

## 一步一步做

### 1. 建一个扫描任务

进入 **任务管理 → 任务配置**，默认停在「任务列表」页签。点「点击创建扫描任务」卡片，会弹出创建窗口。

已经建好的任务卡片上有「编辑」「记录」「删除」三个按钮，最显眼的主按钮是执行。

创建时要填这些：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 必填，起个好认的名字，方便在列表和日志里找到它 |
| 分类 | 影视 或 剧集。选剧集会走另一套识别流程 |
| 媒体类型 | 只有影视任务要选，指影片的产地分区，如日本AV、欧美、国产、FC2 PPV 等 |
| 剧集分区 | 只有剧集任务要选，可选全部、番剧、日剧等 |
| 整理模式 | 整理时文件怎么搬，六种选一种，见下一节 |
| 扫描目录 | 必填，从服务器文件树里挑一个目录，不能选单个文件 |
| 整理目录 | 除「原地整理」「查漏补缺」外都要填，这两种会自动用扫描目录 |
| 重命名规则 | 沿用原文件名，还是换成标准化文件名 |
| 重复文件处理规则 | 整理目录里已有同名文件时，留下哪一份 |
| 目录监控 | 只有新建时能设；打开后一有新文件就自动扫 |
| 加入收藏 | 扫描并刮削后顺手加入收藏，只对影视任务有效 |
| 计划任务 | 关掉目录监控后才出现，填六段式 Cron，到点自动扫 |

:::note[选目录前先确认权限]
扫描目录和整理目录都通过服务器文件树选择，展开目录时才按需加载里面的子目录。创建前请确认运行 AMMDS 的账户对扫描目录有读取权限、对整理目录还有写入权限，否则后面整理会失败。
:::

任务卡片上能一眼看到：任务名称、媒体类型或剧集分区、扫描目录与整理目录、整理模式、命名和重复规则、计划任务。名称旁边还会贴「影视 / 剧集 / 未知」标签，计划任务没开时显示「未启用」。

### 2. 选文件怎么搬（整理模式）

| 模式 | 会做什么 |
| --- | --- |
| 原地整理 | 不移动文件，只按刮削结果重命名、补充资料 |
| 标准化整理（移动） | 把文件移到整理目录，按目录格式和文件名格式放好 |
| 标准化整理（复制） | 复制一份到整理目录，源文件留着 |
| 标准化整理（软连接） | 在整理目录建一个指向源文件的快捷方式，不额外占空间 |
| 标准化整理（硬连接） | 在整理目录建另一个名字指向同一份数据，要求源和目标在同一块磁盘上 |
| 查漏补缺 | 不改目录结构和文件名，只补齐缺的图片和 NFO |

> **软连接 / 硬连接**：都是让整理目录里多出一个「链接」而不搬动原文件。软连接像快捷方式，原文件删了就失效；硬连接是同一份数据的另一个名字，要求两个目录在同一块磁盘上。

「原地整理」和「查漏补缺」不用单独选整理目录，切到这两种模式时，整理目录会自动填成扫描目录。

### 3. 定重命名和重复文件规则

重命名规则只有两种：

- **原文件名**：整理后沿用扫描到的文件名。
- **标准化文件名**：按「影视刮削规则 → 整理文件名格式」生成新名字。

重复文件规则决定目标目录已经有同名文件时保留哪一份：

| 规则 | 保留谁 |
| --- | --- |
| 保留 | 保留原文件，不按体积、日期、分辨率重新挑 |
| 大文件 / 小文件 | 保留体积较大或较小的一份 |
| 新文件 / 旧文件 | 保留日期较新或较旧的一份 |
| 高分辨率 / 低分辨率 | 保留分辨率较高或较低的一份 |

### 4. 挑哪些文件要、哪些不要

扫描会按「任务配置 → 扫描规则配置」里的全局规则挑文件。影视和剧集共用同一个页签：多数规则只有一份，剧集另有一套独立的（配置名带 `tv`）。

下表里的英文是设置对应的配置名，排查问题或看日志时才用得上。平时照着页面上的中文标签勾选就行：

| 规则 | 影视 | 剧集 |
| --- | --- | --- |
| 视频格式限制 | `scanning_video_format` | 和影视共用这一项 |
| 忽略目录 | `scanning_ignore_dir` | `scanning_tv_ignore_dir` |
| 忽略文件 | `scanning_ignore_file` | `scanning_tv_ignore_file` |
| 最小视频大小（MB） | `scanning_min_size` | `scanning_tv_min_size` |
| 视频分段标记 | `scanning_video_segmentation` | 不使用 |
| 字幕格式 | `scanning_subtitle_format` | 和影视共用这一项 |
| 读取本地 NFO | `scanning_read_nfo` | `scanning_tv_read_nfo` |

剧集还多三项专属规则：「特别篇关键词」「集号缺失默认季」「绝对编号识别」，用来把文件名解析成季和集。**规则改了只影响之后的扫描，不会回改已经入库的记录。**

扫描真正跑起来是这个顺序：

1. 从扫描目录开始一层层往下找，只留下允许的视频格式。
2. 碰到「忽略目录」里列出的目录就整个跳过，文件名带「忽略文件」关键词的也跳过。
3. 一次性全量扫描会丢掉小于「最小视频大小」的文件；目录监控发现新文件时单独扫，不按体积过滤。
4. 读取文件的基本信息：分辨率、大小、音视频编码、码率等。
5. 看同一个目录里有没有同名字幕文件，记下字幕类型。
6. 文件名带 `cd1`、`part2` 这类分段标记的，当成同一部片的几段。
7. 开了「读取本地 NFO」，且文件旁边确实有 NFO 时，读出来并记进这次扫描的步骤。
8. 同一个文件之前扫过的，不重复建记录，只把它归到这次扫描任务名下。

### 5. 让它自己跑

| 方式 | 什么时候出现 | 做什么 |
| --- | --- | --- |
| 立即扫描 | 没开目录监控的任务 | 卡片主按钮，点一下交给后台跑，页面不用等 |
| 初始化 | 开了目录监控、状态还是「创建」 | 先完整扫一遍，再开始盯着目录 |
| 监控中 | 开了目录监控且已初始化 | 这个按钮不再触发扫描，只表示正在盯着目录 |
| 定时扫描 | 关掉目录监控且填了 Cron | 到点由调度器自动跑，见[定时自动跑、任务记录与失败重试](./automation.md) |

:::warning[目录监控和手动扫描只能选一个]
开了目录监控就不支持手动扫描，必须先完成初始化。目录监控和 Cron 也是二选一：开着监控时不会保存 Cron，关掉监控才会按 Cron 注册定时任务。同一个任务两样都填没有意义。
:::

目录监控走的是「目录里有动静就通知我」，不是隔一会儿去翻一遍目录：

- 把扫描目录和它下面的子目录都盯上，新建了子目录也会自动加进来。
- 只在出现**新视频文件**时触发，而且格式要在扫描规则的允许清单里。
- 只处理刚冒出来的那一个文件，不会把整个目录重扫一遍。
- 目录被删掉就自动停止盯着；程序重启后会按任务配置重新盯上。

:::warning[目录太深会吃资源]
目录监控要占用系统的文件监听名额。目录层级很深、文件变动很频繁时消耗更大；Linux 下名额用光会导致监控服务起不来，这时要减少监控目录或调高系统上限。
:::

任务卡片上的「记录」会跳到扫描日志并自动按当前任务过滤；「编辑」打开编辑弹窗，但**目录监控开关在编辑时不能改**；「删除」要二次确认，正在扫描的任务不许删。

### 6. 去哪看结果

| 地方 | 能看到什么 |
| --- | --- |
| 任务管理 → 扫描日志 | 每次扫描的运行类型、开始时间、耗时、状态，以及识别 / 新增 / 更新数量；进行中的任务可以取消 |
| 任务管理 → 刮削入库 → 影视刮削 | 已登记的视频文件、识别番号、媒体信息、刮削与整理状态；可以绑定、解绑、删除、手工改番号 |
| 任务管理 → 刮削入库 → 剧集刮削 | 剧集文件按剧名聚合后的待确认分组，可以合并、拆分、忽略、确认 |

扫描完成**不会自动刮削**，除非开了「自动刮削」或者任务模式是「查漏补缺」。

## 番号在哪一步才认出来

扫描阶段只登记文件名和媒体信息，列表里的「识别番号」要等刮削匹配之后才有值。真正认番号靠刮削阶段的「识别码规则」和「番号补全规则」。

一个例外是本地 NFO：开了「读取本地 NFO」，扫描可以直接从 NFO 恢复元数据和识别码。识别失败或认错了，到 **任务管理 → 刮削入库 → 影视刮削**，点识别番号标签手工改。

## 规则面板里还有哪些设置

「任务配置」下半部分是按页签分的规则面板。任务决定「扫哪些目录」，规则决定「怎么认、怎么刮、怎么整理」。

| 页签 | 大致管什么 |
| --- | --- |
| 扫描规则配置 | 视频格式、忽略目录 / 文件、最小体积、分段标记、字幕格式、读取 NFO，以及剧集专属扫描项 |
| 影视刮削规则 | 数据源、整理目录 / 文件名格式、NFO 字段、图片、标签、翻译、线程数等，详见[刮削：自动补齐影片信息](./scrape.md) |
| 剧集刮削规则 | 剧集刮削器、匹配阈值与权重、目录 / 文件名格式、季海报命名、NFO 字段等，详见[刮削：自动补齐影片信息](./scrape.md) |
| 番号补全规则 | 按文件名把不完整的番号补全 |
| 识别码规则 | 从文件名里提取识别码 |
| CID 转换规则 | 把识别码换成另一种编号格式 |
| 订阅规则配置 | 中字优先、搜索顺序、下载目录 |
| 漫画整理配置 | 整理格式、目录、命名、章节生成、封面 / 封底 / 目录关键词 |
| 小说整理配置 | 整理格式、目录、命名、是否按章节生成 |

> **刮削器**：一个能去查影片资料的来源，比如某个资料网站或本地已有数据。刮削时勾选几个，程序就向这几个一起查。

> **线程 / 并发**：把一批活分成几股同时干。线程数越大越快，但太大会把机器和网站压住。

> **正则表达式**：一种用符号写「要匹配什么样的文字」的规则，用来从文件名里抠出编号。

规则面板里的每一项，页面上会自动显示成输入框、数字框、开关或下拉选项，照着填就行。改完点「保存配置」才会生效；点「刷新配置」会丢掉还没保存的改动，重新读一遍当前配置。

### 番号补全规则

每条规则要填几项：备注（自己认得出用途就行）、规则类型（用什么方式去匹配）、匹配规则（从文件名哪一段开始找）、模板（拼成什么格式的番号）、番号长度（`0` 表示自动补，大于 0 表示补足到指定位数）、自动补全（要不要自动套用）、启用状态。

### 识别码规则与 CID 转换

「识别码规则」从文件名或路径里提取识别码，支持正则、前缀、包含、后缀四种匹配方式，可以设输出模板（`{num}`、`{match}`、`{group1}` 等）、影片类型、有无码、需包含前缀、启用状态和备注。面板里有「识别测试」：随手填一个文件名或完整路径，就能看到有没有认出来、是哪条规则认出来的、最后补成的番号是什么。

「CID 转换规则」在识别码正确的前提下，把它换成 CID。匹配方式和识别码规则一样，输出模板支持 `{brand}`、`{num}`、`{num2}` 到 `{num8}`（补零）、`{match}`、`{group1}` 等，也带转换测试。

:::tip[先认对，再转换]
CID 转换依赖正确的识别码。转换结果不对，先用「识别测试」确认识别码本身没错，再改 CID 模板。
:::

识别码规则和 CID 转换规则都能拖拽排序，**排得越前优先级越高**；和番号补全规则一样，都支持新增、编辑、删除、启用 / 禁用。

### 订阅、漫画与小说的整理规则

这三项不跟影视扫描任务混用，各自在自己的页签里填：

| 页签 | 要填什么 |
| --- | --- |
| 订阅规则配置 | 中字优先（当前版本只保存这个偏好，不参与自动下载排序）、搜索顺序（站点关键词列表，决定先试哪个站点，聚合类来源固定排最后）、下载目录（留空用下载器默认路径） |
| 漫画整理配置 | 整理格式（文件夹、CBZ、CBR、CB7、PDF、EPUB）、默认整理目录、目录 / 文件命名、是否按章节生成、封面 / 封底 / 目录识别关键词 |
| 小说整理配置 | 整理格式（EPUB、TXT）、默认整理目录、目录 / 文件命名、是否按章节生成 |

漫画和小说的命名规则支持 `${title}`、`${author}`、`${chapter}`、`${index}` 这类占位符，具体以面板说明为准。

规则是全局的：改了影响之后创建或执行的任务，不会回改已入库的元数据。任务级别的字段（目录、整理模式、Cron、目录监控）只在任务卡片里维护，不在规则面板里。

## 设置项说明

### 建任务时要填的

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 任务名称 | 一个好认的名字 | 必填，不填建不了任务 |
| 分类 | 影视 或 剧集 | 选错会用错识别流程，剧集走的是另一套 |
| 媒体类型 / 剧集分区 | 影视选产地分区，剧集选分区（全部、番剧、日剧等） | 只会出现和分类对应的那一项，另一项自动隐藏 |
| 整理模式 | 六种搬法里选一种 | 不填不能建；选「原地整理」「查漏补缺」时整理目录自动等于扫描目录 |
| 扫描目录 | 从服务器文件树里选一个目录 | 必填，只能选目录不能选文件；没读权限就扫不到 |
| 整理目录 | 除原地类外都要填，且要有写入权限 | 不填不能建；权限不够整理会失败 |
| 重命名规则 | 原文件名 或 标准化文件名 | 选标准化会按刮削规则里的文件名格式改名 |
| 重复文件处理规则 | 保留 / 大文件 / 小文件 / 新文件 / 旧文件 / 高分辨率 / 低分辨率 | 选「保留」就不按体积、日期、分辨率重新挑 |
| 目录监控 | 新建时开或关 | 编辑时改不了；开了就不能手动扫描，也不保存 Cron |
| 加入收藏 | 开或关，仅影视任务生效 | 不开就不加收藏；剧集任务开了也没效果 |
| 计划任务 | 六段式 Cron 表达式，关掉目录监控时才显示 | 不填就只手动跑；写错或时区不对会到点不触发 |

### 扫描规则配置里的全局项

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 视频格式限制 `scanning_video_format` | 允许哪些视频扩展名 | 不在清单里的格式不会被扫进来；目录监控也只认清单内的新文件 |
| 忽略目录 `scanning_ignore_dir` / `scanning_tv_ignore_dir` | 要整棵跳过的目录 | 命中就整棵子树不扫 |
| 忽略文件 `scanning_ignore_file` / `scanning_tv_ignore_file` | 文件名里带哪些关键词就跳过 | 写太宽会把正片也跳掉 |
| 最小视频大小 `scanning_min_size` / `scanning_tv_min_size`（MB） | 小于多少 MB 不算视频 | 全量扫描才过滤；目录监控触发的单文件扫描不过滤 |
| 视频分段标记 `scanning_video_segmentation` | 多段文件的标记，如 `cd1`、`part2` | 剧集不使用；填错会把一部片拆成好几段 |
| 字幕格式 `scanning_subtitle_format` | 同目录下哪些扩展名算字幕 | 影视与剧集共用这一项 |
| 读取本地 NFO `scanning_read_nfo` / `scanning_tv_read_nfo` | 是否读文件旁边的 NFO | 开了才能从 NFO 直接恢复元数据和识别码 |
| 特别篇关键词 / 集号缺失默认季 / 绝对编号识别 | 剧集专属，把文件名解析成季和集 | 只有剧集任务会读；不填就按默认方式解析 |

### 番号补全、识别码与其它规则

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 番号补全的匹配规则 / 模板 | 从文件名定位哪一段、按什么模板补成番号 | 规则不对会补出错误番号，导致刮削认错片 |
| 番号长度 | `0` 自动补全，大于 0 补足到指定位数 | 位数不对会补出多余或缺失的零 |
| 识别码规则的匹配方式与模板 | 正则 / 前缀 / 包含 / 后缀，输出模板如 `{num}`、`{match}`、`{group1}` | 提不出识别码，后面刮削就无从匹配；先用「识别测试」验证 |
| CID 转换的输出模板 | `{brand}`、`{num}`、`{num2}` 到 `{num8}`、`{match}`、`{group1}` 等 | 识别码本身不对时转换一定不对，先修识别码 |
| 启用状态 / 排序 | 规则开关与拖拽排序 | 关掉的规则不参与判定；排序即优先级 |
| 搜索顺序（订阅规则） | 逗号分隔的站点关键词 | 写错的关键词会让该站点一直排后面 |
| 下载目录（订阅规则） | 订阅下载时的保存路径 | 留空用下载器默认路径 |
| 保存配置 / 刷新配置 | 改完点「保存配置」逐项提交 | 不点保存就不生效；点「刷新配置」会丢掉未保存改动 |

## 出问题了怎么办

- **一个文件都没扫到**：先看扫描目录选对没有、运行 AMMDS 的账户有没有读权限，再看视频格式白名单和「忽略目录 / 忽略文件」是不是把它挡了。
- **文件被当成好几部 / 好几段**：检查「视频分段标记」和「识别码规则」，先拿一个文件名去「识别测试」里试。
- **开了目录监控却不动**：确认任务已经「初始化」；监控中状态的按钮本来就不触发扫描。目录层级太深或监听名额用光时，减少监控目录或调高系统上限。
- **到点没自动跑**：核对 Cron 写法和应用时区，还要确认全局计划任务开关没关，详见[定时自动跑、任务记录与失败重试](./automation.md)。
- **整理失败**：多半是整理目录没有写入权限，或者选了「硬连接」但源和目标不在同一块磁盘上。
- **改了规则但老记录没变**：规则只影响之后的扫描，不会回改已入库的记录，需要重新扫描或刮削。
