# 刮削：自动补齐影片信息

扫描只是把文件登记下来，刮削才是让 AMMDS 认出「这是哪部片子」，然后补上封面、简介、演员、标签，生成说明文件和图片，按你定的格式把文件摆好。这一页讲怎么开始刮削、资料从哪来、会多出哪些文件、卡住了怎么办，以及查漏补缺和各项设置。

## 先说清楚

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。

> **元数据**：一部片子的封面、简介、演员、标签这些描述信息。

> **番号 / 识别码**：影片的识别编号，通常写在文件名里，程序靠它认片子。

> **NFO**：和视频放在一起的小说明文件，里面记着片名、演员等信息，播放器能读它。

> **刮削器**：一个能去查影片资料的来源，比如某个资料网站，或者本机已经存好的数据。勾几个就向几个一起查。

> **并发**：好几件事同时抢着做。多个刮削器是一起查的，一个卡住不影响别的。

> **占位符**：格式串里用 `{}` 包起来的记号，会被真实内容替换，比如演员名、番号、标题。

## 一步一步做

### 1. 刮削前先备好

1. 至少启用一个资料来源插件，并在「任务管理 → 任务配置 → 影视刮削规则 → 刮削器」里把它勾上。
2. 确认扫描已经把目标文件登记到「刮削入库」，而且这些文件的路径还访问得到，见[扫描：让 AMMDS 认识你的文件](./scan.md)。
3. 想让程序自动整理文件，先确认整理目录存在、也能写进去。
4. 想生成 NFO 和图片，确认对应开关和字段都配好了。

刮削**不依赖下载器**。下载器只影响订阅和手动推送，不影响资料匹配。

:::note[同一时间只跑一个]
同一时间只允许一个刮削任务在跑。已经有一个在执行时，再提交会被拒绝，并提示「重复执行 - 刮削任务运行中」。
:::

### 2. 挑一种触发方式

进入 **任务管理 → 刮削入库 → 影视刮削**（剧集走「剧集刮削」），页面上可以选：

| 入口 | 处理范围 | 做什么 |
| --- | --- | --- |
| 刮削整理 | 全部待刮削影视 | 刮削 + 文件整理一起做 |
| 仅刮削 | 全部待刮削影视 | 只匹配资料、生成 NFO 和图片，不移动、不重命名视频 |
| 选择整理 | 你勾选的媒体 | 批量处理，单次最多 120 条 |
| 自动刮削 | 按设置的间隔 | 影视和剧集各有开关与间隔；开启后默认每 3 分钟检查一次待办 |
| 查漏补缺 | 指定任务的源目录 | 扫描完成后只补齐缺的图片和 NFO，不改目录结构，详见下面专门一节 |

### 3. 资料从哪来

「刮削器」是一个多选列表，默认给出这些：`本地(默认)`、`MetaTube(插件)`、`ThePornDB(插件)`、`Stash(插件)`、`FANZA_DMM(插件)`、`M-Team_DMM(插件)`、`TheJavDB(插件)`、`R18Dev(插件)`、`TMDB(插件)`。

真正执行时是这样：

1. 勾选的刮削器会**同时**去查；某一个失败或太慢，不会拖住别的。
2. 各来源把查到的影片先存进本机影视库，系统再从本机取匹配结果。
3. 取结果时如果 TMDB 已启用又被勾上，优先用它的；否则 JAV 番号找 MetaTube，欧美番号找 ThePornDB。
4. Stash、FANZA_DMM、M-Team_DMM、TheJavDB、R18Dev 是补充来源，查到也会存进本机库，再按番号或文件指纹对上记录。
5. 按番号都没查到、而 TMDB 可用时，会再拿「片名 + 年份」按普通影视试一次。

:::tip[已经整理过的库用「本地数据优先」]
开启「本地数据优先」后，媒体已经绑定过、且绑定的影视还在，就直接复用，不再联网刮削；绑定失效才重新查。适合只想补缺字段、不想重跑一遍的媒体库。
:::

:::warning[来源也有挑片子的]
MetaTube 不支持欧美番号，欧美片子要启用 ThePornDB 或 TMDB。来源能不能用，还取决于插件有没有启用、站点账号是否有效、以及网络通不通。
:::

### 4. 会填回来哪些内容

匹配成功后，系统会把查到的内容填进这部片子的资料里，再按配置补一些附加信息：

| 类别 | 内容 |
| --- | --- |
| 基础字段 | 标题、原始标题、简介、上映日期、时长、评分、导演、制作商、系列 |
| 演员 | 演员名、别名、头像与作品关联；可以关掉「演员刮削」跳过 |
| 标签 / 分类 | 按「自动标签」「自动分类标签」追加分辨率、制作商、识别码、发行日期、演员、马赛克、中文字幕、破解等 |
| 图片 | 海报、背景图、缩略图、剧照；可选高清封面 |
| 翻译 | 开启「字段翻译」后，按系统翻译设置翻译标题 / 简介等字段 |
| 番号 | 识别码和补全后的番号可以混合输出，方便兼容不同站点的命名 |

「NFO 字段」决定生成 NFO 时写哪些标签，默认包含大部分字段（含识别码 `num`）；不需要的标签可以从配置里去掉。

### 5. 整理后的目录和文件名

两个格式串决定文件放哪、叫什么，都在「影视刮削规则」里：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 整理目录格式 | `${actor}/${number}` | 每一级 `/` 切分成一级目录 |
| 整理文件名格式 | `${number}` | 只写文件名主体，不含扩展名 |

可用占位符有演员、番号、标题、日期、年份、月份、日、马赛克、分辨率、导演、制作商等；以 `_safe` 结尾的变体会把路径分隔符换成空格。占位符怎么写，可以点面板头部的「帮助」看。

:::warning[名字太长会被截断]
文件名超过 200 字节会被截断；整理后的相对目录路径超过 3600 字节会直接终止整理。格式串里堆太多占位符就容易踩到。
:::

### 6. 会多出哪些文件

刮削完成后，整理目录里可能多出这些：

| 文件 | 说明 |
| --- | --- |
| `<文件名>.nfo` | 按 NFO 字段配置生成，和视频同名 |
| `<文件名>-poster.jpg` | 封面；有码影片尽量保证竖版 2:3 |
| `<文件名>-fanart.jpg` | 背景图；有码影片尽量保证横版 |
| `<文件名>-thumb.jpg` | 缩略图；有码影片尽量保证横版 |
| `<文件名>.srt` | 外挂字幕；目标已存在时不覆盖 |
| `extrafanart/fanart1.jpg`… | 开启「刮削剧照」后写入，目录名可配置 |

图片下载失败要不要中止整理，由「允许图片下载失败」控制。开了高清封面就优先用高清图；有码影片如果封面和背景方向放反了，系统会试着把两张图对调回来，还对不上就到工具箱里用「海报裁剪」手工处理。

### 7. 看每一步跑到哪了

「刮削入库」列表里的「查看步骤」会打开一条时间线，显示每一轮刮削的步骤、状态、耗时和错误信息。主要步骤有：`文件校验`、`番号识别`、`数据源检索`、`元数据匹配`、`演员刮削`、`文件移动`，整理阶段还有 `海报下载`、`背景图下载`、`缩略图下载`、`NFO生成`；另外有 `读取本地 NFO`、`手工绑定`、`查漏补缺` 这些特殊步骤。

顺序以时间线为准。同一部片子可能有多轮记录，抽屉顶部可以切换历史轮次，默认显示最新一轮。

## 查漏补缺：只补缺的，不动视频

「查漏补缺」是给「资料基本齐了，只差几张图或 NFO」用的。它**不改变目录结构和文件名，也不移动视频文件**，只把缺的图片和 NFO 补上。

用它的两个常见场景：

- 扫描任务的「整理模式」选了「查漏补缺」：扫完直接按这个模式补齐，见[扫描：让 AMMDS 认识你的文件](./scan.md)。
- 已经刮削过的媒体缺图或缺 NFO：在「刮削入库」对任务用「查漏补缺」，只补附属文件。

刮削失败的媒体会一直保持「待刮削」，不会自动变成完成，所以补完缺之后该重试的还要重试。

## 刮削设置项逐条看

规则面板在 **任务管理 → 任务配置**，分「影视刮削规则」和「剧集刮削规则」两个页签。改完点「保存配置」才会生效；点「刷新配置」会丢掉还没保存的改动，重新读一遍当前配置。每一项在页面上会自动显示成输入框、数字框、开关或下拉，照着填就行。

### 影视刮削规则

| 分组 | 有哪些设置项 |
| --- | --- |
| 数据源 | 刮削器、本地数据优先、品牌前缀过滤 |
| 整理 | 整理目录格式、整理文件名格式 |
| 元数据 | 自动标签、自动分类标签、字段翻译、番号混合、演员刮削 |
| NFO | NFO 字段（决定生成 NFO 时写哪些标签） |
| 图片 | 高清封面、刮削剧照、剧照目录、允许图片下载失败 |
| 字幕 | 外挂字幕搜索 |
| 性能 | 多线程执行、最大刮削线程数 |

### 剧集刮削规则

剧集的配置集中在同一个页签：剧集刮削器（本地、TMDB、Bangumi、TheTVDB）、自动刮削间隔、匹配阈值与权重、季映射自动发现、每季集数、目录 / 文件名格式、季海报命名、NFO 字段、演员刮削、字段翻译、请求间隔与线程数。

## 剧集刮削有什么不一样

剧集不用番号匹配，而是按剧名、年份、季集结构去匹配 TMDB、Bangumi、TheTVDB 等来源。扫描之后先到「剧集刮削」页确认剧集分组（可以合并、拆分、忽略），边界确认好了才生成剧集资料。第一次用建议先确认分组边界，再调匹配阈值。剧集的目录格式、文件名格式、季海报与 NFO 命名规则，都在「剧集刮削规则」里。

## 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 刮削器（多选） | 至少勾一个已启用的资料来源 | 一个都不勾就查不到任何资料；来源没启用、账号失效或断网时同样查不到 |
| 本地数据优先 | 开或关 | 关闭时即使已经绑定过也会重新联网刮削 |
| 品牌前缀过滤 | 按需要过滤的品牌前缀 | 填错会把正常番号也挡掉，导致匹配不到 |
| 整理目录格式 | 默认 `${actor}/${number}`，用占位符拼 | 留空或写错，整理出来的目录就不是你想要的样子 |
| 整理文件名格式 | 默认 `${number}`，只写名字主体 | 写错会导致文件名不对；超 200 字节被截断，相对路径超 3600 字节终止整理 |
| 自动标签 / 自动分类标签 | 要不要自动追加分辨率、制作商、识别码等标签 | 关闭就不追加这些衍生标签 |
| 字段翻译 | 开或关，按系统翻译设置生效 | 关闭就不翻译；翻译设置没配好，开了也没有译文 |
| 番号混合 | 开或关 | 关闭时只输出一种番号写法 |
| 演员刮削 | 开或关 | 关闭就不抓演员名、别名和头像 |
| NFO 字段 | 生成 NFO 时要写哪些标签 | 去掉某个标签，NFO 里就没有它；默认含识别码 `num` |
| 高清封面 / 刮削剧照 / 剧照目录 | 图片相关开关与剧照目录名 | 不开高清封面就用普通图；不开刮削剧照就不写 `extrafanart` 目录 |
| 允许图片下载失败 | 图片下不下来时要不要继续整理 | 关闭时一张图失败就可能中断整次整理 |
| 外挂字幕搜索 | 要不要找外挂字幕 | 关闭就不会写出 `<文件名>.srt`；目标已有同名文件时不覆盖 |
| 多线程执行 / 最大刮削线程数 | 是否多线程、最多几条一起跑 | 线程数太大容易把机器和网站压住；太小就慢 |
| 自动刮削（影视 / 剧集各自开关与间隔） | 打开并设间隔，默认每 3 分钟检查一次待办 | 关闭就只能手动触发；间隔设太短会频繁跑 |
| 选择整理 | 勾选要处理的媒体 | 单次最多 120 条，超了要分批 |
| 匹配阈值与权重（剧集） | 判定「是不是同一部剧」的门槛与各来源权重 | 太严会匹配不上，太松会认错剧；先确认分组边界再调 |
| 季映射自动发现 / 每季集数（剧集） | 是否自动发现季映射、每季多少集 | 关闭自动发现就要手工绑；集数填错季集结构会不对 |
| 保存配置 / 刷新配置 | 改完点「保存配置」 | 不保存不生效；点「刷新配置」会丢掉未保存改动 |

## 出问题了怎么办

- **提示「重复执行 - 刮削任务运行中」**：已经有一个刮削在跑，等它结束或先取消，再重新提交。
- **完全没补上资料**：先看刮削器勾了没、插件有没有启用、站点账号是否有效，再到工作台的网络检查里确认资料网站能连通。
- **欧美片子查不到**：MetaTube 不支持欧美番号，改启用 ThePornDB 或 TMDB。
- **番号认错了**：在「刮削入库」点识别番号标签手工改，再重新刮削。
- **匹配不到、或有图缺 NFO**：先用「绑定」搜影视库手工绑定再刮削；只缺图片或 NFO 就用「查漏补缺」，不会动视频文件。
- **整理中途停了 / 名字被截断**：文件名超 200 字节会截断、相对路径超 3600 字节会终止整理，把格式串里的占位符减一减。
- **想知道卡在哪一步**：点「查看步骤」看时间线，先定位是文件校验、番号识别、数据源检索，还是图片 / NFO 生成失败；步骤里的错误信息通常比整批日志更具体。

任务跑完的状态、日志和失败重试，见[定时自动跑、任务记录与失败重试](./automation.md)。
