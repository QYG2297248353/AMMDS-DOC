# 生活档案

生活档案是给你自己用的记录本，放在后台左侧菜单里，分成四个页面：**纪念日**、**身材记录**、**健身记录**、**亲密生活**。每个页面都是独立的，互不影响，想记哪一类就进哪一类。

这一块只对登录后台的人开放，前台站点没有入口。记录只存在你自己的 AMMDS 里，不会同步到外部服务。

## 入口与共同点

登录后台后，在左侧菜单找到「生活档案」，展开就是四个子页面。

四页的用法基本一样：

- 右上角或页面上方有「新增」按钮，填完保存即可。
- 每行记录都能编辑、删除；删除前会二次确认，**删掉之后不能恢复**。
- 列表默认每页 10 条，可以调整每页条数或翻页。
- 顶部统计和图表在保存、编辑、删除后会自动刷新。

## 一、纪念日

纪念日用来记生日、结婚纪念日、节日、重要的工作节点等。页面顶部有四张统计卡：

| 统计卡 | 算的是什么 |
| --- | --- |
| 纪念日 | 全部纪念日的数量 |
| 即将到来 | 下一次发生日在未来 7 天内（含今天）的数量 |
| 本月纪念日 | 月份和本月相同的数量 |
| 今日纪念日 | 月、日都和今天相同的数量 |

这四张卡都按**全部记录**统计，不会跟着下面的搜索和筛选变化。

### 新增一条纪念日

点「新增纪念日」，按下表填写：

| 设置项 | 怎么填 | 说明 / 限制 |
| --- | --- | --- |
| 事件名称 | 必填 | 2–30 个字符，比如「结婚纪念日」 |
| 日期类型 | 新历或农历，默认「新历」 | 选「农历」只是在记录上做个标记，不会把日期换算成农历 |
| 日期 | 必填 | 选这件事发生的日期；以后新增也可以选未来的日期 |
| 事件类型 | 必填，默认「纪念日」 | 生日、纪念日、节日、工作、个人、其他，列表里用不同颜色的标签区分 |
| 重复类型 | 必填，默认「每年」 | 每年、每月、一次性 |
| 提醒时间 | 默认「1 天前」 | 当天、1 天前、3 天前、7 天前、无提醒；保存后列表会带「提醒」标记 |
| 备注 | 选填 | 最多 200 个字符 |

:::note[关于重复类型和倒计时]
重复类型目前只作为记录信息保存。列表里的倒计时和顶部统计都按「每年同月同日」计算，不会因为选了「每月」或「一次性」而改变。
:::

### 列表和筛选

- 搜索框可以搜纪念日名称，也可以搜备注。
- 点「筛选」可以按事件类型和日期范围筛选，选完点「应用筛选」。
- 筛选项里有生日、纪念日、节日、工作、其他，**没有「个人」**。新增时仍然可以选「个人」，只是暂时不能按它筛选。
- 倒计时会显示「今天」「明天」「后天」或「N 天后」，按日期里的月日计算，和年份无关。
- 勾选多条记录后，可以批量删除。

## 二、身材记录

身材记录用来跟踪身高、体重和围度的变化。页面顶部有四张统计卡：

| 统计卡 | 算的是什么 |
| --- | --- |
| 记录总数 | 全部身材记录的数量 |
| 平均身高 | 全部记录的平均值 |
| 平均体重 | 全部记录的平均值 |
| 平均 BMI | 全部记录的平均值 |

统计卡按全部记录计算；下面的「体重与 BMI 趋势」图会跟随当前筛选条件，筛完再画。

### 新增一条身材记录

点「新增记录」，按下表填写：

| 设置项 | 怎么填 | 说明 / 限制 |
| --- | --- | --- |
| 记录时间 | 必填 | 只能选今天或更早的日期，不能选未来 |
| 身高 | 必填 | 100–250 cm，最多 1 位小数 |
| 体重 | 必填 | 30–200 kg，最多 1 位小数 |
| BMI | 自动计算，不用填 | 根据身高和体重算出来，保留 1 位小数；改身高或体重会跟着变 |
| 胸围 / 腰围 / 臀围 | 选填 | 各自 40–200 cm，最多 1 位小数 |
| 大臂围 | 选填 | 15–60 cm，最多 1 位小数 |
| 大腿围 | 选填 | 30–100 cm，最多 1 位小数 |
| 小腿围 | 选填 | 20–60 cm，最多 1 位小数 |
| 备注 | 选填 | 最多 200 个字符 |

BMI 的区间和页面上的标签一致：

| BMI | 标签 |
| --- | --- |
| 小于 16 | 严重偏低 |
| 16 到不足 18.5 | 偏瘦 |
| 18.5 到不足 24 | 健康 |
| 24 到不足 28 | 超重 |
| 28 到不足 32 | 肥胖 |
| 32 及以上 | 严重肥胖 |

### 列表和筛选

- 搜索框可以搜备注，也可以直接输入身高或体重的数字。
- 点「筛选」可以按记录时间范围和体重范围筛选。
- 开始日期不能晚于结束日期；最小体重不能大于最大体重，否则页面会提示。
- 列表每页可以选 10、20、50 条。
- 支持编辑、单条删除和勾选后批量删除。
- 趋势图没有数据时，会显示「当前筛选范围内暂无趋势数据」。

## 三、健身记录

健身记录用来记每次运动。页面顶部有四张统计卡：总记录数、总运动时长、平均时长、消耗卡路里，都按全部记录计算。

下面有两张图：

| 图表 | 看什么 |
| --- | --- |
| 近30天运动趋势 | 最近 30 天每天的总时长和总卡路里，没运动的日子按 0 算 |
| 运动类型分布 | 各种运动类型的占比，按全部记录的总时长排序 |

这两张图是固定口径，不受列表筛选影响。

### 新增一条健身记录

点「新增记录」，按下表填写：

| 设置项 | 怎么填 | 说明 / 限制 |
| --- | --- | --- |
| 记录时间 | 必填 | 只选日期，不记具体时刻 |
| 运动类型 | 必填 | 有氧运动、力量训练、瑜伽、游泳、跑步、骑行、其他 |
| 具体项目 | 必填 | 最多 128 个字符，比如「慢跑」「卧推」 |
| 运动强度 | 必填 | 低、中、高 |
| 感受 | 必填 | 轻松、适中、疲劳、非常疲劳 |
| 持续时间 | 必填 | 0–1440 分钟，只能填整数 |
| 消耗卡路里 | 必填 | 0–20000 千卡，只能填整数；填好类型、强度和时长后会自动估算 |
| 运动地点 | 选填 | 最多 128 个字符 |
| 心率 | 选填 | 0–300，填平均心率，只能填整数 |
| 体重 | 选填 | 0–500 kg，最多 1 位小数 |
| 肩宽 | 选填 | 0–300 cm，最多 1 位小数 |
| 大臂围 | 选填 | 0–300 cm，最多 1 位小数 |
| 小臂围 | 选填 | 0–300 cm，最多 1 位小数 |
| 胸围 | 选填 | 0–300 cm，最多 1 位小数 |
| 腰围 | 选填 | 0–300 cm，最多 1 位小数 |
| 臀围 | 选填 | 0–300 cm，最多 1 位小数 |
| 大腿围 | 选填 | 0–300 cm，最多 1 位小数 |
| 小腿围 | 选填 | 0–300 cm，最多 1 位小数 |
| 备注 | 选填 | 最多 1000 个字符 |

:::note[卡路里只是估算]
自动算出来的卡路里按运动类型、强度和时长给一个常见参考值，不是精确测量。你可以直接改这个数字；也可以点「计算器」，填入体重、运动类型、强度和时长，按体重重新估算，再把结果填回记录。
:::

### 列表和筛选

- 搜索框可以搜运动类型或地点。
- 点「筛选」可以按运动类型、强度和记录时间范围筛选。
- 点表头可以按记录时间、时长或卡路里排序。
- 支持编辑、单条删除和勾选后批量删除。
- 列表只显示概要字段；心率、围度、备注这些要进编辑弹窗才能看到完整内容。

## 四、亲密生活

亲密生活用来记录私密数据。页面顶部有四张统计卡：

| 统计卡 | 算的是什么 |
| --- | --- |
| 总记录数 | 全部记录的数量 |
| 高潮次数 | 记录里「高潮」选「是」的条数 |
| 平均时长 | 全部记录的平均持续时间 |
| 伴侣数量 | 记录里出现过的不同伴侣名字数量 |

下面的「最近 12 个月频率」图按月份统计记录条数，包含当前月；没有记录的月份按 0 显示。统计和图表都按全部记录计算。

:::note[列表只显示概要]
列表里只有日期、类型、伴侣、地点、时长、保护措施和心情。备注等私密细节不会显示在列表里，只有点「编辑」时才能看到。
:::

### 新增一条亲密记录

点「新增记录」，按下表填写：

| 设置项 | 怎么填 | 说明 / 限制 |
| --- | --- | --- |
| 记录时间 | 必填 | 只选日期 |
| 记录类型 | 必填 | 自慰、伴侣、同性、多人 |
| 伴侣 | 除「自慰」外必填 | 可以从以前记录里的名字中选，也可以直接输入新名字；选「多人」时可以填多个 |
| 地点 | 必填 | 最多 128 个字符 |
| 持续时间 | 必填 | 0–1440 分钟，只能填整数 |
| 保护措施 | 选填 | 安全套、女用避孕套、避孕药、节育环、结扎、无保护 |
| 姿势 | 选填 | 最多 64 个字符 |
| 情趣内衣 | 选填 | 是或否，默认「否」 |
| 高潮 | 选填 | 是或否，默认「否」 |
| 伴侣高潮 | 除「自慰」外显示 | 是或否，默认「否」 |
| 射精位置 | 除「自慰」外显示 | 体内、体外、面部、胸部、口腔、肛门 |
| 潮吹 | 选填 | 是或否，默认「否」 |
| 道具 | 选填 | 最多 255 个字符 |
| 心情 | 选填 | 愉悦、兴奋、平静、疲惫 |
| 备注 | 选填 | 最多 1000 个字符 |

:::note[选「自慰」后字段会变]
记录类型选「自慰」时，「伴侣」「伴侣高潮」「射精位置」会自动隐藏，也不需要填伴侣。切回伴侣、同性或多人，这几个字段会重新出现。
:::

### 列表和筛选

- 搜索框可以搜伴侣或地点。
- 点表头可以按记录时间、伴侣或持续时间排序。
- 这一页只有搜索，没有日期或类型筛选。
- 支持编辑、单条删除和勾选后批量删除。

## 数据与隐私

- 生活档案只对登录后台的人开放，前台站点没有入口，也不提供分享链接。
- 记录只保存在你自己的 AMMDS 里，不会上传到外部服务。
- 删除是永久删除，删掉之后不能恢复；批量删除同样不可恢复。
- 顶部统计按全部记录计算，不受搜索和筛选影响；身材趋势图会跟随筛选，健身和亲密的图表是固定口径。

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 左侧菜单找不到生活档案 | 需要先登录后台。生活档案不在前台站点的菜单里 |
| 筛选后顶部统计没变 | 正常，统计按全部记录算；身材的体重与 BMI 趋势图会跟着筛选变 |
| 纪念日选了「每月」，倒计时还是按年算 | 倒计时和统计固定按「每年同月同日」计算，重复类型只做记录 |
| 农历日期没有自动换算 | 选「农历」只做标记，日期仍按你选的那一天保存，需要自己对照农历填写 |
| BMI 不能手动改 | BMI 是根据身高和体重自动算的，改这两个值就会更新 |
| 自动算的卡路里不准 | 只是参考值，可以直接改；也可以用计算器按体重重新估算 |
| 选了「自慰」后伴侣项不见了 | 这是设计好的，伴侣相关字段会自动隐藏；换回其他类型会重新出现 |
| 亲密生活列表里看不到备注 | 列表只显示概要，备注要在「编辑」里看 |
| 删掉的记录还能找回吗 | 不能，删除不可恢复 |
