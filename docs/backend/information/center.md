# 消息、RSS、分享与实例互通

**信息中心**管四件事：看系统消息、订阅外部资讯、把条目分享给别人、和另一个 AMMDS 站点互通。四节互不依赖，哪件着急就先看哪一节。

## 一、看系统消息

消息页集中放 AMMDS 自己产生的通知：后台任务（点完就能离开、由系统自己跑完的事）的结果、站点认证的状态、分享申请和导入的进展，还有官方公告。

> **通知类型**：消息分三类。系统通知由程序自动发出，比如订阅下载结果、站点认证、整理进度；官方通知是官方账号发布的公告；分享通知是分享申请和导入的结果。

### 筛选与查看

页面顶部有两个筛选：通知类型（全部 / 系统通知 / 官方通知 / 分享通知）和阅读状态（全部 / 已读 / 未读）。选好后点「查询」，列表才会刷新。列表每页 10 条，也可以改每页显示多少条。

每条消息显示类型、等级、标题、内容摘要、时间和操作。等级有四种：

| 等级 | 颜色 | 意思 |
| --- | --- | --- |
| 信息 | 蓝色 | 一般性提示，不用处理 |
| 成功 | 绿色 | 操作正常完成 |
| 警告 | 橙色 | 可能有问题，但不影响继续用 |
| 错误 | 红色 | 操作失败或出错，需要处理 |

### 标记已读与删除

- 点操作列的勾选按钮，就把这条标成已读。标过之后按钮会变灰，再点也不会有反应。
- 点删除按钮移除这条消息，删了就不再出现。
- 目前只能一条一条处理，没有「全部已读」，也不能批量删除。

本页只管站内消息。想把通知发到手机上，要在「集成应用」里配置对应的通知服务。

## 二、订阅外部资讯（RSS）

> **RSS**：很多网站提供的一种固定格式的更新清单。你把它填进来，AMMDS 就会定期去取，把新文章收进站内读。

在信息中心里打开「资讯」，里面有六个标签页：

| 标签页 | 用来做什么 |
| --- | --- |
| 仪表盘 | 看订阅数、条目数、分类分布、近 14 天趋势和最近任务 |
| 订阅管理 | 添加、编辑、抓取、归档、删除订阅 |
| 离线缓存 | 看缓存占用与进度，清理缓存 |
| 热门订阅 | 从线上热门清单里挑，一键订阅或退订 |
| 链接预览 | 先解析一个地址看看内容，再决定订不订 |
| 设置 | 全局默认值 |

### 添加一个订阅

1. 在「订阅管理」点添加，按下表逐项填好。
2. 保存后点这一行的「抓取」，会马上抓一次；抓完会提示新增了多少条。
3. 想一次全部抓完，点「抓取全部」。它在后台自己跑，点完就能离开页面。

拿不准一个地址能不能用，先用「链接预览」试试：填入地址、点「解析预览」，就能看到条目数、内容分类、语言和前几条内容。觉得合适，再点「订阅该源」。

### 设置项说明：订阅能填什么

| 设置项 | 管什么 / 怎么填 | 不填会怎样 |
| --- | --- | --- |
| 启用状态 | 关掉之后这个订阅不再参与抓取 | 默认启用 |
| 订阅地址 | RSS / Atom 地址 | 没有地址就没法抓取 |
| 名称 | 站内显示的名字 | 列表里显示不出名字，不好认 |
| 描述 | 可选的一段说明 | 留空不显示 |
| 内容分类 | 文章 / 图像 / 视频 / 资源 / 其他 | 归到「其他」，前台标签页里不展示 |
| 图标链接 | 可选，列表上显示的小图标 | 显示默认图标 |
| 深度解析 | 抓取时再点开每条详情，把正文、图片和视频一起取回来 | 只拿到列表里的摘要 |
| 离线缓存 | 把正文、图片等存到本地 | 源站删了或打不开，内容就看不到了 |

有些订阅是插件自动带进来的，叫「集成源」。这类只能改名称、描述和图标，订阅地址改不了。

### 离线缓存

> **离线缓存**：把条目的正文和图片、视频等资源下载到本机保存。源站不稳定或会清旧文时很有用。

缓存页按订阅列出「条目总数 / 已缓存 / 待缓存」、占用的空间和完成比例。「刷新缓存」会交给后台去下载；「清理缓存」会把已下载的内容全部删掉，清完得重新缓存才能离线看。归档的订阅不再抓取，也不再缓存。

### 热门订阅

热门订阅是一份系统整理好的订阅清单。列表里显示名称、描述、分类、类型和来源域名，来源有三种标记：

- 线上同步：刚刚从线上取到的最新清单。
- 本地缓存：线上暂时连不上，用的是本地存的那一份。
- 内置兜底：第一次部署、线上又取不到时，用自带的清单。

没订过的源可以直接点「订阅」；已经订的可以退订，退订会把已抓到的条目一起删掉。「立即同步」用来马上刷新这份清单。系统还会定时检查这些源能不能打开，打不开的会被标出来。

### 资讯的全局设置

下面这些只在**新建订阅**时生效，改了不会动已有的订阅。单个订阅自己的开关，优先于这里的设置。

| 设置项 | 管什么 / 怎么填 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 自动归档 | 每天把超过保留天数的订阅整体归档 | 默认关闭，归档只由你手动做 |
| 自动归档保留天数 | 数字，默认 30 | 填 0 或负数等于不自动归档 |
| 默认深度解析 | 新建订阅时「深度解析」是否默认勾上 | 默认不勾 |
| 默认离线缓存 | 新建订阅时「离线缓存」是否默认勾上 | 默认不勾 |
| 单条目缓存图片上限 | 数字，默认 20 | 图片特别多的条目只会缓存一部分 |
| 单条目缓存视频上限 | 数字，默认 0 | 默认不缓存视频文件本身 |
| 单轮缓存条目上限 | 数字，默认 200 | 一次最多处理这么多条，其余的等下一轮 |
| 缓存请求超时（秒） | 数字，默认 30 | 慢的资源会失败，需要重跑 |
| 热门订阅缓存时长（分钟） | 数字，默认 360 | 时间越短越频繁去线上取，越长越可能是旧清单 |
| 热门订阅可用性校验 | 是否定时检查清单里的源能不能打开 | 默认开启；关掉后可能推荐失效地址 |
| 链接预览超时（秒） | 数字，默认 20 | 慢的站点会解析失败 |

:::warning[删订阅会删条目]
删除订阅会一并删掉这个订阅下的全部资讯条目，不可撤销。
:::

## 三、把条目分享给别人

分享链接把影片、演员、系列、漫画、小说或剧集生成一个公开地址。对方不用登录就能打开，看到的是条目介绍，拿不到媒体文件。

### 新建一次分享

1. 点「新建分享」，选择分享类型。
2. 搜索并选中要分享的条目。
3. 选有效期：永久，或者自己定一个过期时间。
4. 决定「是否允许他人导入」：关掉之后对方只能看，要导入得先申请。
5. 需要的话填访问密码，留空就是无密码。
6. 点「创建」。成功后弹窗里会给出二维码和完整链接，链接也已经替你复制好了。

> **访问密码**：就是常说的提取码。给别人时要链接和密码一起给，密码不会出现在链接里。

分享列表可以按类型筛选，也能用短码（每条分享自带的短编号）或标题搜索。每条显示类型、标题、短码、完整链接、有没有密码、有效期、状态、是否允许导入和创建时间。

| 状态 | 什么时候出现 | 对方看到什么 |
| --- | --- | --- |
| 正常 | 没过期也没暂停 | 能看；能不能导入取决于你开没开「允许导入」 |
| 已暂停 | 你手动暂停了 | 提示分享已暂停 |
| 已过期 | 超过了设定的过期时间 | 提示分享已过期 |

暂停后随时能恢复；删除分享不可撤销，链接立刻失效。

### 处理别人的导入申请

别人想导入你的分享时，申请会进「收件箱」。每一条会写明申请的是哪条分享、申请人（昵称和账号 ID）、邮箱、理由、状态和时间。只有状态是「待审核」的，才能点通过或拒绝。

审批结果会变成一条分享通知。注意：**审批只改这一条申请的状态**，分享本身能不能导入，还是看你创建时的设置。

## 四、导入别人的分享

导入入口在 **系统管理 → 备份与恢复 → 分享导入**：

1. 填入分享链接或短码。
2. 对方设了密码就填访问密码。
3. 点「预览分享」看看内容，再点「导入分享」。
4. 选导入方案：跳过已存在（默认）、覆盖更新或合并更新。三种都不会删你本地其他数据。

如果对方没开放导入权限，页面会提示「该分享不允许导入」，可以填理由提交申请，等对方审批（提交前要把用户 ID、昵称和邮箱补全）。

同一页下方还能切到「链接记录」和「申请记录」：链接记录按关键词、类型、结果筛选；申请记录显示目标分享、理由和状态，待处理的可以取消。删记录不影响已经导入的数据。

## 五、连上另一个 AMMDS（实例互通）

> **实例互通**：让两套 AMMDS 互为好友。连上之后可以互发消息、搜对方的媒体库、把对方的漫画或小说资料导入到本地。用的是站点令牌，不用把账号密码交给对方。

> **令牌**：一串有时效的凭证，相当于临时通行证。失效后重新换一张就行。

### 前提条件

1. 两边都在 **系统配置** 里打开「互联互通」开关（默认是关的）。
2. 两边都能从对方的网络访问到；用域名的话建议配好加密访问。
3. 知道对方的站点地址（前面要带 `http://` 或 `https://`，或者写成 `IP:端口`）。

开关没开，加好友和检索都不会成功。

### 加好友和收发申请

1. 点「添加好友」，填对方站点地址。
2. 点「解析」，系统会去探一下对方的互通服务，自动把好友 ID 和昵称填好。
3. 按需填站点名称、备注，再填申请理由（必填），点「申请添加」。
4. 等对方在收件箱里通过，关系就建立了。长时间没处理可以在「已发申请」里重发；被拒绝就重新发起。

好友列表显示好友名、状态（在线 / 连接中 / 长期离线 / 离线）、站点地址和备注。每一行有续签、资料、消息、修改、删除五个操作。站点地址旁边还有「检测」按钮，可以立刻刷新一下状态。

- **续签**：换一张新令牌，令牌失效或对方重置之后用。
- **资料**：改好友昵称、站点名称和备注；站点地址是只读的。
- **修改**：只改备注。
- **删除**：删掉好友关系，历史消息和申请记录会保留。

### 好友检索与消息

「好友检索」会把同一个关键词同时发给所有好友站点，再把结果合并给你。可以查影视、演员、漫画、小说，关键词必填。只有漫画和小说有「导入」按钮，影视和演员只能看。碰到同名冲突或对方资料不全，导入会失败，并提示原因。

在好友那一行点「消息」就能打开聊天窗口：消息按时间排列，自己发的靠右、对方发来的靠左。聊天内容只存在双方各自的站点里，不经过别的服务器。

互通不会复制对方的媒体文件，正文和海报仍由各自的站点自己维护。

## 出问题了怎么办

- **消息找不到**：确认筛选没有停在「未读」或某一个类型上，清空筛选再查一次。
- **订阅源抓不到东西**：先用「链接预览」确认地址还能解析；地址失效就换一个，或者去热门订阅里挑同类源。
- **分享打不开**：多半是过期或被暂停了，让分享者延期或重新创建；提示要密码就向对方要密码。
- **导入按钮点不动**：对方设成了「仅查看」，提交申请等审批。
- **解析对方站点失败**：核对地址、确认对方开了互通开关，并先在浏览器里打开对方站点看看通不通。
- **好友长期离线**：点「检测」确认，再试「续签」；仍不行就检查对方站点和网络。
