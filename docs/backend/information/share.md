# 分享链接

分享链接用于把本地媒体条目分享给他人查看或导入：创建时选择条目、设置有效期与访问密码，得到形如 `/share/{短码}` 的公开地址，对方无需登录即可打开。

## 分享列表

顶部左侧是「新建分享」，右侧是类型筛选、关键词搜索与「收件箱」。

| 列 | 说明 |
| --- | --- |
| 类型 | 影片、演员、系列、漫画、小说、剧集 |
| 标题 | 被分享条目的标题 |
| 短码 | 链接中的唯一标识 |
| 短链接 | 完整地址，点击即可复制 |
| 访问密码 | 有密码显示「有密码」，否则显示「无密码」 |
| 有效期 | 永久，或具体过期时间 |
| 状态 | 正常、已暂停、已过期 |
| 允许导入 | 允许，或「仅查看」 |
| 创建时间 | 分享创建时间 |
| 操作 | 暂停 / 恢复、删除 |

类型筛选与关键词（短码或标题）可组合使用；清空搜索框会立即重新查询。

## 新建分享

1. 点击「新建分享」，选择分享类型。
2. 搜索并选中目标条目（影片按标题、演员按姓名、系列按名称，漫画/小说/剧集同理）。
3. 选择有效期：永久，或自定义过期时间（精确到秒）。
4. 设置「是否允许他人导入」：关闭后他人只能查看公开页面，需要向分享者申请后才能导入。
5. 按需填写访问密码，留空表示无密码。
6. 点击「创建」。

创建成功后弹窗切换为结果页：上方是二维码，下方是完整链接，链接已自动复制一次。可点链接再次复制、使用「系统分享」调用浏览器分享能力，或「复制关闭」复制后关闭弹窗。

:::tip[提取码就是访问密码]
界面上的「访问密码」即通常所说的提取码。分享给他人时，需要同时给出链接与密码；密码不会出现在链接里。
:::

## 有效期与状态

| 状态 | 触发条件 | 对方看到 |
| --- | --- | --- |
| 正常 | 未过期且未暂停 | 可查看；是否可导入取决于「允许导入」 |
| 已暂停 | 分享者手动暂停 | 页面提示分享已暂停 |
| 已过期 | 超过设定的过期时间 | 页面提示分享已过期 |

暂停后可以随时恢复；删除分享不可撤销，删除后链接立即失效。

## 导入申请收件箱

当分享设置为「仅查看」或对方需要导入时，可在收件箱处理申请：

| 字段 | 说明 |
| --- | --- |
| 分享 | 申请的分享标题或短码 |
| 申请人 | 昵称与 `@用户ID` |
| 邮箱 | 申请人账号邮箱 |
| 申请原因 | 申请人填写的理由 |
| 状态 | 待审核、已通过、已拒绝 |
| 申请时间 | 提交时间 |
| 操作 | 仅「待审核」显示通过、拒绝 |

审批结果会产生分享通知，可在[系统消息](/docs/backend/information/message)中查看。审批只更新申请状态，不改变分享本身的「允许导入」设置：能否导入仍由分享创建时的设置决定。

## 导入他人的分享

导入入口在 **系统管理 → 备份恢复 → 分享导入** 标签页：

1. 输入分享链接或短码，如 `https://域名/share/ABC123`。
2. 如果分享设置了密码，填写访问密码。
3. 点击「预览分享」查看内容，再点「导入分享」。
4. 导入时可选择「跳过已存在」「覆盖更新」或「合并更新」，默认「跳过已存在」；任何一种都不会删除本地其他数据。

若分享不允许直接导入，页面提示「该分享不允许导入」，可点「申请分享」提交理由，等分享者审批。

## 导入记录

同一标签页下方可切换「链接记录」与「申请记录」：

- 链接记录展示标题、导入时间与导入结果，支持按关键词、类型、结果筛选。
- 申请记录展示目标分享、申请原因与状态。
- 单条记录可删除；删除记录不影响已导入的数据。

:::note[权限边界]
分享只暴露条目详情与可导入的元数据，不提供媒体文件下载；导入也不会复制对方的图片与视频文件。
:::

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 打开链接提示已过期 | 超过有效期 | 让分享者延长有效期或重新创建 |
| 提示需要访问密码 | 分享设置了密码 | 向分享者索取密码后重试 |
| 导入按钮不可用 | 分享设置为「仅查看」 | 提交导入申请，等分享者审批 |
| 收件箱没有申请 | 申请发给了别的实例或已被处理 | 确认分享者身份，检查已处理记录 |
| 复制链接失败 | 浏览器限制剪贴板 | 手动选中文本复制，或使用二维码 |

分享创建的条目详情可参考[影视](/docs/backend/media/movie)；配置备份与恢复中的其它能力见[备份与恢复](/docs/backend/system/backup-restore)。
