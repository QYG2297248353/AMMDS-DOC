# RSS 订阅与热门 RSS 榜单

RSS 资讯模块把外部 RSS / Atom 源变成站内可读的资讯条目：可以自己添加订阅、批量抓取、离线缓存正文与媒体，也可以直接从热门榜单里挑选订阅源。

## 标签页总览

| 标签页 | 作用 |
| --- | --- |
| 仪表盘 | 订阅与条目统计、分类/类型分布、近 14 天趋势、条目数 Top 订阅与最近任务 |
| 订阅管理 | 添加、编辑、抓取、归档、删除订阅 |
| 离线缓存 | 缓存统计、按订阅查看缓存进度、清理缓存 |
| 热门订阅 | 浏览线上热门清单，一键订阅或退订 |
| 链接预览 | 输入地址解析后确认内容，再决定是否订阅 |
| 设置 | RSS 全局配置，作为新建订阅的默认值 |

## 订阅管理

列表支持按名称搜索，并按订阅类型、内容分类、归档状态筛选。每行展示订阅名称与描述、类型与分类标签、更新时间，以及启用/禁用、已归档、集成源等状态标记；操作包括预览、抓取、编辑、归档/取消归档、删除。集成源（由站点插件带入的系统内置订阅）只能改名称、描述与图标，订阅地址为只读。

添加订阅时需要填写：

| 字段 | 说明 |
| --- | --- |
| 启用状态 | 关闭后不参与抓取 |
| 订阅地址 | RSS / Atom 链接 |
| 名称 | 站内展示名 |
| 描述 | 可选说明 |
| 内容分类 | 文章 / 图像 / 视频 / 资源 / 其他 |
| 图标链接 | 可选，用于列表图标 |
| 深度解析 | 抓取后二次加载详情，补全正文与媒体 |
| 离线缓存 | 把正文与图片、视频等资源本地化，已包含离线图片 |

抓取行为：

- **抓取**（单条）：同步执行，完成后提示新增条目数。
- **抓取全部**：耗时较长，接口只提交后台任务并立即返回；已有抓取任务在执行时会提示稍后查看进度。
- 归档后的订阅不参与抓取与缓存；「自动归档」按保留天数每日处理。

删除订阅会一并删除该订阅下的全部资讯条目，操作不可撤销。

## 订阅类型与内容分类

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 订阅类型 | `news` 资讯、`pt` PT 种子 | 描述抓取方式，PT 类型会二次加载详情 |
| 内容分类 | `article` 文章、`image` 图像、`video` 视频、`resource` 资源、`other` 其他 | 描述展示形态；「其他」是保底类型，前台标签页不展示 |

同一个 PT 订阅抓到的条目也可能分别归入图像、视频或资源分类。

## 离线缓存

离线缓存把条目正文、图片与可缓存的媒体保存到本地，适合源站不稳定或会清理旧文的场景。

| 指标 | 说明 |
| --- | --- |
| 条目总数 / 已缓存 / 待缓存 | 按订阅统计的缓存进度 |
| 缓存占用 | 全部缓存文件体积 |
| 图片缓存 / 视频缓存 / 正文缓存 | 分类占用 |
| 各订阅缓存进度 | 每个订阅的完成比例 |
| 已缓存内容 | 标题、分类、资源数与缓存时间 |

- **刷新缓存**：提交后台缓存任务，可指定订阅或处理全部符合条件的订阅。
- **清理缓存**：删除全部离线缓存文件，清理后需要重新缓存。

## 热门订阅与榜单

热门订阅数据来自线上清单，按订阅地址增量同步到本地数据库，列表展示名称、描述、分类、类型、来源域名与同步时间。

| 来源标记 | 含义 |
| --- | --- |
| 线上同步 | 成功从线上清单同步 |
| 本地缓存 | 线上暂不可用，读取已落库的清单 |
| 内置兜底 | 首次部署且线上不可用，使用内置清单 |

- 支持按关键词、分类、类型、来源域名筛选。
- 「立即同步」主动拉取线上清单；同步失败会保留已有数据。
- 对未订阅的源可直接「订阅」，成功后可在订阅管理看到；已订阅项显示标记，退订会一并删除已抓取条目。

平台还会定时校验热门源可用性，不可访问的源会被标记，避免推荐失效地址。

## 链接预览

用于在订阅前确认一个地址是否可用：

1. 输入 RSS / Atom 地址，点击「解析预览」。
2. 查看解析结果：条目数、内容分类、语言与条目预览。
3. 确认内容符合预期后点「订阅该源」，成功后跳回订阅管理。

解析失败会显示具体原因，常见为地址不是订阅源、站点不可达或超时。

## 全局设置

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `rss_auto_archive_enabled` | 自动归档 | 布尔 | `false` | 每日把早于保留天数的订阅整体归档 |
| `rss_auto_archive_days` | 自动归档保留天数 | 数字 | `30` | 小于等于 0 视为不启用自动归档 |
| `rss_default_deep_parse` | 默认深度解析 | 布尔 | `false` | 新建订阅时深度解析的默认值 |
| `rss_default_offline_cache` | 默认离线缓存 | 布尔 | `false` | 新建订阅时离线缓存的默认值 |
| `rss_offline_cache_max_images` | 单条目缓存图片上限 | 数字 | `20` | 避免单条目图片过多占满磁盘 |
| `rss_offline_cache_max_videos` | 单条目缓存视频上限 | 数字 | `0` | 默认不缓存视频本体 |
| `rss_offline_cache_batch_size` | 单轮缓存条目上限 | 数字 | `200` | 每轮最多处理的条目数 |
| `rss_offline_cache_timeout` | 缓存请求超时(秒) | 数字 | `30` | 单个媒体资源的下载超时 |
| `rss_hot_subscribe_cache_minutes` | 热门订阅缓存时长(分钟) | 数字 | `360` | 清单落库后的内存缓存时长 |
| `rss_hot_subscribe_check_enabled` | 热门订阅可用性校验 | 布尔 | `true` | 定时校验清单内订阅源是否可访问 |
| `rss_preview_timeout` | 链接预览超时(秒) | 数字 | `20` | 预览时抓取目标地址的超时 |

全局配置作为默认值生效，单个订阅上的开关优先于全局配置。

:::tip[抓取与缓存都在后台]
「抓取全部」与「刷新缓存」都是异步任务，提交后可以离开页面；进度可在仪表盘的「最近任务」中查看。
:::
