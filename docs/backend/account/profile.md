# 个人信息

用户中心是账号维度的设置页：上面是展示形象（头像、横幅、主页主题），中间是资料字段，底部是实例许可证。所有改动即时生效，不需要重启。

{/* truncate */}

## 打开方式

点击右上角头像，在下拉菜单中选择 **用户中心**。页面自上而下分为四块：头部形象区、主页配置、用户信息、许可证。

## 头部形象区

| 元素 | 操作 |
| --- | --- |
| 头像 | 点击头像选择图片，上传成功后立即替换 |
| 横幅 | 右上角上传按钮选择图片；已有横幅时可点删除恢复默认背景 |
| 昵称 | 展示当前昵称 |
| 角色标签 | 管理员或用户 |
| 授权标签 | 与许可证状态一致（有效 / 无效） |
| VIP 标签 | 账号具有会员标识时展示 |
| 修改密码 | 点击打开改密弹窗 |

头部背景优先使用你上传的横幅，未设置时使用内置默认背景图。

## 主页配置

这一块控制**公共主页**的视觉，影响他人访问你的主页时看到的样子。

| 区域 | 说明 |
| --- | --- |
| 主页背景图 | 上传或删除；未设置时显示占位 |
| 主页横幅 Banner | 上传或删除；与头部横幅各自独立 |
| 公共页主题 | 多套主题卡片，点击即切换并保存，每套主题是独立的页面设计与组件摆放 |

背景图与横幅会应用到公共主页的全部主题，不同主题自行决定使用方式与裁切比例。

## 用户信息

信息卡展示：用户 ID、昵称、邮箱、手机号、角色、状态、注册时间、最后登录时间。右上角有两个入口：

- **编辑信息**：打开编辑弹窗。
- **公开主页**：在新标签页打开 `/u/{用户ID}`；未设置用户 ID 时不可用。

### 编辑资料

| 字段 | 规则 |
| --- | --- |
| 用户 ID | 必填，仅支持字母、数字、下划线、短横线，至少 4 位，不能是纯数字，不能使用系统保留 ID（如 `admin`、`root`、`ammds`） |
| 昵称 | 必填，最长 32 个字符 |
| 邮箱 | 必填，需符合邮箱格式 |
| 手机号 | 选填，公开主页仅展示脱敏号码 |
| 公开主页展示字段 | 多选：用户 ID、昵称、头像、邮箱、手机号（脱敏）、注册时间、最后登录时间、状态 |

展示字段有一层约定：**从未配置过**时默认展示除手机号外的全部字段；把勾选全部取消则公开主页不再展示任何资料。

:::tip[用户 ID 就是主页地址]
公开主页地址形如 `/u/{用户ID}`。改动用户 ID 后旧链接会失效，如果已经分享出去，请一并更新。
:::

## 修改密码

点头部「修改密码」，填写三项：

1. **当前密码**
2. **新的密码**
3. **二次确认**

新密码需满足：6–22 位，同时包含大写与小写字母，且至少包含一个数字或一个符号；两次输入必须一致。

提交时新旧密码都会先用 RSA 公钥加密再上传。修改成功后页面提示「即将登出」，约 5 秒后自动退出，用新密码重新登录即可。

:::warning[忘记当前密码怎么办]
改密要求提供原密码。如果已经无法登录，请用恢复密钥重置，步骤见[密钥管理](/docs/backend/system/secret)。
:::

## 小提示

- 头像、横幅、背景图都会占用 `data/images` 空间，容量可在[存储管理](/docs/backend/system/storage)查看。
- 昵称、邮箱、手机号也是「互联互通」的前置条件，缺失时无法开启该功能。
- 公开主页的展示字段随时可改，改完立即对访客生效。
