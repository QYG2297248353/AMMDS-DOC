# 个人资料、商城与登录安全

这一页管三块：**你自己的账号**（头像、资料、公开主页、改密码）、**官方商城**（买东西支持项目）、**站点认证**（把 PT 站点的账号凭据交给 AMMDS）。三块互不依赖，缺哪块看哪块。

## 一、个人资料

点右上角头像 → **用户中心**。页面从上到下是：头部形象区、主页配置、用户信息、许可证。所有改动即时生效，不用重启。

### 头部形象区

| 元素 | 怎么改 |
| --- | --- |
| 头像 | 点头像选图片，上传成功就换掉 |
| 横幅 | 右上角上传按钮选图片；已经有横幅时可以点删除，恢复默认背景 |
| 昵称 | 展示当前昵称 |
| 角色标签 | 管理员或用户 |
| 授权标签 | 跟许可证状态一致（有效 / 无效） |
| 会员标签 | 账号有会员标识时才显示 |
| 修改密码 | 点开改密弹窗 |

没传横幅时，头部用内置的背景图。

### 主页配置

这一块决定**别人访问你的公开主页时看到什么样子**：

| 区域 | 说明 |
| --- | --- |
| 主页背景图 | 上传或删除；没设置时显示占位 |
| 主页横幅 | 上传或删除；和头部的横幅各自独立 |
| 公共页主题 | 多套主题卡片，点一下就切换并保存；每套主题的页面设计和组件摆放都不一样 |

背景图和横幅会用在公共主页的所有主题上，不同主题自己决定怎么用、怎么裁。

### 用户信息

信息卡显示用户 ID、昵称、邮箱、手机号、角色、状态、注册时间和最后登录时间。右上角两个入口：「编辑信息」打开编辑弹窗，「公开主页」在新标签页打开你的主页。

> **用户 ID**：你自己起的账号代号，同时就是公开主页的地址，形如 `/u/你的ID`。改了之后旧链接会失效，已经分享出去的要一起更新。

> **脱敏**：只显示一部分，中间用星号挡住，比如手机号只露首尾几位。

### 设置项说明：编辑资料

| 设置项 | 管什么 / 怎么填 | 不填会怎样 |
| --- | --- | --- |
| 用户 ID | 必填。只能用字母、数字、下划线、短横线，至少 4 位，不能是纯数字，也不能用系统保留的名字（如 `admin`、`root`、`ammds`） | 不能保存；公开主页地址也打不开 |
| 昵称 | 必填，最长 32 个字符 | 不能保存 |
| 邮箱 | 必填，要符合邮箱格式 | 不能保存；也会导致「实例互通」开不起来 |
| 手机号 | 选填，公开主页只显示脱敏号码 | 可以留空 |
| 公开主页展示字段 | 多选：用户 ID、昵称、头像、邮箱、手机号（脱敏）、注册时间、最后登录时间、状态 | 从没配置过时默认展示除手机号外的全部项目；全取消则主页不展示任何资料 |

### 修改密码

点头部的「修改密码」，填三项：当前密码、新的密码、再输一遍新密码。

密码规则（登录、改密、重置三处一样）：**6–22 位，要有大写和小写字母，并且至少含一个数字或一个符号**；两次输入必须一致。

密码会先在浏览器里加密再发出去。改成功后页面提示「即将登出」，大约 5 秒后自动退出，用新密码重新登录。改密需要提供原密码；已经登不进去的话，要用「系统管理」栏目里的恢复密钥来重置。

头像、横幅、背景图都会占用数据目录的空间。昵称、邮箱、手机号也是「实例互通」的前提，缺了开不了。

## 二、官方商城

> **官方商城**：AMMDS 里内置的商店入口。商品、价格、库存、支付和发货都由官方店铺维护，这边只负责展示和下单。买会员或服务是对项目开发最直接的支持。

### 买一次东西

1. **浏览**：打开商品列表，可以匿名浏览、搜索、看详情（商品卡片上标了「暂不可售」的无法加入购物车）。
2. **加购物车**：在详情页选好规格和数量，点「加入购物车」（这一步需要登录）。购物车里可以改数量或删掉某一项。
3. **结算**：点「去结算」，填好下面几块，选好支付方式提交订单。

购物车是整单结算，不能只挑其中几件。币种在第一次加购时按结算地区定下来；要换币种只能放弃购物车重新买（会二次确认，不会产生订单也不会扣款）。下单成功后会跳到订单结果页，那个链接可以安全地自己留着。

### 结算页要填什么

| 设置项 | 管什么 / 怎么填 | 不填会怎样 |
| --- | --- | --- |
| 联系信息 | 邮箱必填；手机号、姓、名可选 | 邮箱空了不能提交 |
| 常用地址 | 登录后可以直接选已保存的地址，自动回填 | 每次手填 |
| 收货地址 | 地址、城市、国家必填；邮编、省/州选填 | 必填项空了不能提交 |
| 配送方式 | 点「获取配送方式」拿到当前地区可用的方式和运费 | 也可以直接提交订单，系统会自动获取 |
| 支付方式 | 从商城给的渠道里选一个 | 不选无法下单 |

### 看订单

订单列表和订单详情在前台看，后台的 **官方商城** 菜单下有四个页面：

| 页面 | 用途 |
| --- | --- |
| 状态 | 店铺信息、商品数、分类数、购物车数、订单数、最近同步时间和连接状态；可以手动触发同步 |
| 订单 | 跨账号查看全部订单和明细，也能按关键词、支付状态筛选 |
| 购物车 | 查看各账号的购物车，移除条目或清空 |
| 常用地址 | 维护本账号的收货地址，可以设默认 |

同步有「同步商品（增量）」「同步信息」「同步订单」「全量校准」几种，都在后台跑；页面显示进度、成功 / 失败条数和错误摘要，全量校准跑完之前不能再来一次。

### 地址怎么填

在 **官方商城 → 常用地址** 里新增、编辑、删除，并设默认地址。字段有邮箱、手机号、姓、名、国家、省/州、城市、邮编、详细地址；其中**邮箱、手机号、国家、城市必填**。进结算页时会自动选中默认地址并回填。

## 三、站点认证

> **PT 站点**：要注册账号、按上传量和下载量计分的资源站。

> **站点认证**：把你在 PT 站点的账号信息（用户 ID 加个人钥匙）交给 AMMDS，让它能用这个账号去读站点数据。它不涉及姓名、证件这类实名信息。

> **PassKey**：站点发给你的个人钥匙，作用等同于该站点的登录凭证。不要截图分享，也不要在多个站点用同一个。

点右上角头像 → **站点认证**。页面按卡片显示已配的站点，每行三个；没有站点时显示「暂无认证站点」。

### 怎么认证

1. 点卡片上的「UID」，填入你在该站点的用户 ID，提交即保存。
2. 点「PassKey」，填入站点给你的钥匙，提交即保存。
3. 确认卡片上的开关是启用的。
4. 点「立即认证」。

不同站点要填的不一样：多数站点要用户 ID 加个人钥匙，也有只要个人钥匙的。另外三个前提缺一不可：站点是启用状态、站点本身支持认证、账号信息已经保存。任一项不满足，页面直接提示，不会真的去站点认证。

认证由后台去做，你不用守在页面上：列表每 10 秒自动刷新一次，切到别的标签页时暂停。

### 认证状态

| 状态 | 意思 |
| --- | --- |
| 已认证 | 最近一次认证成功，并且还在有效期内 |
| 未认证 | 从没认证过、认证失败，或者已经超出有效期 |

认证结果的有效期是 **6 小时**，超了会自动变回未认证，但最后认证时间和失败原因会留着方便排查。系统内置的定时任务会定期重新认证，正常情况下不用你手动续。认证成功时，系统会记下站点返回的用户名和邮箱，并发一条「站点认证成功」的通知。

## 出问题了怎么办

- **提示「站点未启用」**：把卡片上的开关打开再试。
- **提示「请先设置 UID 和 PassKey」**：两项分别填一次，填完按钮会高亮。
- **提示「该站点尚未支持认证」**：这类站点只能用插件方式接入，去「集成应用」里配。
- **认证失败但没说原因**：多半是用户 ID 和个人钥匙对不上，或者站点那边重置过钥匙；去站点重新核对。
- **认证成功又变回未认证**：超过 6 小时有效期且定时任务没跑，手动点一次「立即认证」。
- **商品列表是空的**：商城还没同步，管理员去后台「状态」页点同步。
- **改完密码被登出**：这是预期行为，用新密码重新登录。
