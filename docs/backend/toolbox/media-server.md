# 媒体服务器：库与封面

工具箱里的「媒体服务器」用来直接操作播放器那边的媒体库：看每个库有多少东西、放在哪个目录，重新整理元数据和图片，换一张更好看的封面，或者点进库里一层层整理。

入口是**工具箱 → 媒体服务器 → 库管理**。

:::warning[写回封面需要可用的媒体服务器]
换封面、刷新、移除封面都是往播放器的媒体库里写。请先在「集成应用」里配置并启用 Jellyfin 或 Emby，否则这些操作无法完成。
:::

## 页面顶部

顶部有一个「扫描所有媒体库」按钮，会把 Jellyfin 和 Emby 的扫描任务一起提交。两个插件都没启用时，这个按钮是灰的。

下面按 Jellyfin、Emby 分成两块。每块最上面是这一端的统计：

| 统计 | 说明 |
| --- | --- |
| 电影 | 电影条目数 |
| 剧集 | 剧集条目数 |
| 单集 | 单集条目数 |
| 合集 | 合集条目数 |

统计拉取失败时整行不显示，不影响下面的库卡片。

每块右上角还有「补全演员信息」「同步媒体库」「同步播放记录」「刷新」四个按钮，作用分别是补演员资料、把本地资料写进播放器、拉播放记录、重新拉库列表。这些任务都在后台跑，点完只提示「任务已提交」。

## 库卡片

每个媒体库一张卡片，从上到下是：

| 位置 | 内容 |
| --- | --- |
| 封面 | 播放器里这个库的主图；加载不出来时显示一个占位图标 |
| 名称 | 媒体库名称，太长会截断，鼠标停上去看全名 |
| 类型 | 影片、节目、音乐、合集、书籍、其他 |
| 条目数 | 形如「· 128 个条目」；播放器没返回时显示 `-` |
| 物理路径 | 库对应的磁盘目录；有多个路径时用分号隔开，太长会截断 |
| 操作 | 四个按钮，见下表 |

| 按钮 | 作用 | 说明 |
| --- | --- | --- |
| 进入媒体库 | 打开这个库，逐层浏览里面的文件夹和作品 | 等同于点卡片封面或名称 |
| 更换封面 | 打开生成式封面弹窗 | 见下文 |
| 立即扫描 | 让播放器扫描这个库 | 只提交任务，不会当场扫完 |
| 更多 | 刷新元数据、刷新图片、移除封面 | 见下文 |

### 更多里的三项

| 菜单项 | 做什么 | 注意 |
| --- | --- | --- |
| 刷新元数据 | 让播放器重新读取这个库的元数据 | 后台执行；不会覆盖已有封面 |
| 刷新图片 | 让播放器重新拉取图片 | 同样不会覆盖已有封面 |
| 移除封面 | 删掉媒体库的主图 | 会先弹确认；删的是播放器上的图，不动视频文件 |

## 更换封面

点「更换封面」会打开一个弹窗，上面有两个页签：**文本封面**和**图像封面**。两个页签右边都是 16:9、1280×720 的实时预览，左边改什么，右边立刻变。确认后点「替换封面」，图片会直接写入媒体服务器，覆盖原来的主图。

### 文本封面

纯配置生成，不依赖库里的作品图。最简形态就是库名 + 黑底 + 居中白字。

| 设置项 | 怎么填 |
| --- | --- |
| 封面文案 | 最多 60 字；留空时默认用媒体库名称 |
| 副标题 | 可选，最多 60 字，例如 `Movies / TV Shows` |
| 底色 | 取色器选背景颜色 |
| 文字颜色 | 取色器选文字颜色 |
| 字号 | 24~140，步长 2 |
| 对齐 | 左对齐、居中、右对齐 |
| 加粗 | 开关 |

### 图像封面

用这个库里的作品图当素材，拼出一张封面。

| 设置项 | 怎么填 |
| --- | --- |
| 封面文案 | 最多 60 字；留空时默认用媒体库名称 |
| 副标题 | 可选，最多 60 字，例如 `本月热门` |
| 排版 | 宫格拼贴，或主图 + 标题栏 |
| 作品数量 | 只有宫格拼贴才有，可选 4 张、6 张、9 张 |
| 遮罩透明度 | 0~0.85，步长 0.05；越大文字越清楚 |
| 标题字号 | 28~120，步长 2 |
| 文字颜色 | 取色器选文字颜色 |
| 作品素材 | 点「换一批」重新随机取库内作品图，旁边显示「已获取 N 张作品图」 |

素材还没取到，或者一张都没取到时，「替换封面」是灰的。

不想每次都手动点，可以按库开启「自动换封面」，让它在有新内容时自己换，见下一节。

## 自动换封面

库卡片的操作区里有一个时钟图标按钮，悬停提示「自动换封面」。点开是「自动换封面设置」弹窗，**默认关闭，只对你打开开关的那个库生效**。其他库不受影响。

### 能配什么

| 设置项 | 怎么填 |
| --- | --- |
| 启用自动更换 | 开关，默认关闭，仅对本库生效 |
| 封面类型 | 文本封面，或图像封面 |
| 封面文案 / 副标题 | 最多 60 字；支持占位符 `{library}`（库名）、`{count}`（条目数）、`{date}`（当天日期），要连花括号一起写，例如 `{library} · 共 {count} 部` |
| 文本封面 | 底色、文字颜色、字号 24~140、左对齐 / 居中 / 右对齐、加粗 |
| 图像封面 | 排版（宫格拼贴 / 主图 + 标题栏）、作品数量 4 / 6 / 9 张（宫格才有）、遮罩透明度 0~0.95、标题字号 24~140、文字颜色 |
| 最小更换间隔 | 10~10080 分钟，默认 720 分钟；同一个库两次自动更换之间的最短间隔 |

封面由服务端合成，固定 1280×720、PNG。各设置项的含义与手动更换弹窗一致，取值范围以这里为准。

### 什么时候会换

系统启动 25 分钟后做第一次检查，之后每 30 分钟轮询一次。只有打开开关的库会参与；一个都没开时不会去请求媒体服务器。

对每个已开启的库，要同时满足三个条件才动手：

1. 库里条目数比上次记录的增加
2. 距上次执行已经超过这个库的最小间隔
3. 能正常连上媒体服务器；选图像封面时还要能取到作品素材

刚开启时的第一次检查只记录当前条目数作为基线，不会立刻换封面。之后有新条目进来，才进入上面的判断。

### 什么情况下不会改封面

| 情况 | 结果 |
| --- | --- |
| 条目数没增加 | 跳过；条目减少（删除、移库）也不会换，只更新记录 |
| 距上次更换不到最小间隔 | 跳过，等下一轮 |
| 新生成的图和上次完全一样 | 跳过，不重复写入，避免白白刷新缓存 |
| 封面被你手动改过 | 自动轮询跳过，保持你改的封面；想重新交给自动更换，点「立即执行一次」并在确认框里选择继续覆盖 |
| 素材不足、生成失败、服务器不可达 | 保持原封面不动，并记下失败原因 |
| 库是空的，或拿不到条目数 | 不动 |

### 结果在哪看

- 开启后，库卡片上会多一行「自动换封面 · 时间 · 成功 / 失败 / 跳过」；还没跑过显示「自动换封面 · 等待轮询」。
- 点时钟按钮打开设置，底部「最近一次自动更换」会显示结果标签、执行时间和具体说明，失败原因也在这里。
- 更详细的错误在后端日志里。

### 立即执行一次

设置弹窗底部有「立即执行一次」。它不看条目数有没有增加、也不看最小间隔，当场生成封面。

但如果检测到服务器上的当前封面和上次自动写入的不一致（说明被手动改过），它不会直接覆盖，而是先弹一个确认框：

> 检测到封面已被手动修改
> 继续将覆盖为自动生成封面，当前手动修改的封面会丢失。是否继续？

点「继续覆盖」才写回，点「取消」保持原封面不动。定时轮询不会覆盖手动封面，只有你手动执行一次并确认后，这个库才重新交给自动更换。

刚配好想马上看效果时，也用它执行一次。

这个按钮要求库当前可达，媒体服务器连不上时会提示执行失败，并保持原封面。

:::warning[写回仍然依赖媒体服务器]
自动更换和手动更换一样，前提是 Jellyfin 或 Emby 已配置并启用。服务器不可用时只会记录失败，不会写坏封面。
:::

## 进入媒体库，逐层浏览

点「进入媒体库」后，列表区域会被浏览界面替换，顶部变成「返回」加面包屑。面包屑显示从库到当前目录的路径，点前面的层级可以直接跳回。

- **搜索**：默认只搜当前目录，不会自动往下钻
- **刷新**：重新拉当前目录
- **文件夹**：卡片展示，显示名称、类型和「N 项」；每个文件夹卡片右下角有「更换封面」
- **条目**：表格展示，列有封面、名称、类型、年份、时长、操作；每页 24 条，底部翻页
- **返回**：不在根目录时回上一级；已经在根目录时回到媒体库列表
- 如果当前目录什么也没有，会提示「当前目录为空」

给文件夹或作品换封面时，用的还是同一个生成式封面弹窗，只是写入目标变成了这个文件夹 / 作品。写入成功后会重新加载当前目录，图片立刻更新。

## 前提和限制

- **必须是已配置可用的 Jellyfin 或 Emby**：封面写回、刷新、移除都走播放器接口，插件没配好或者没启用时做不了。
- **不会删视频**：刷新和移除封面只动元数据与图片，不碰库里的视频文件。
- **刷新是后台任务**：点完不会立刻看到结果，需要等播放器处理完再刷新页面。
- **素材来自库内作品图**：图像封面取的是播放器里已有作品的主图，库里没图就拼不出来。
- **自动换封面默认关闭**：按库单独开启，只在新条目增加且超过最小间隔时更换；开启后的第一次检查只建立基线，不会立刻改封面。
- **自动任务不覆盖手动修改**：发现封面被你改过就停止自动覆盖；需要点「立即执行一次」，并在确认框里选择继续覆盖，才重新接管。

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 库卡片一直是占位图 | 播放器没返回主图，或者图片地址打不开；可以先点「刷新图片」再试 |
| 条目数显示 `-` | 播放器没有返回条目数，不是 AMMDS 没统计 |
| 物理路径是空的 | 这个库在播放器里没有配置目录，或接口没返回 |
| 「扫描所有媒体库」点不动 | Jellyfin 和 Emby 都没启用 |
| 「替换封面」是灰的 | 图像封面还没取到素材，或者正在提交 |
| 开了自动换封面但封面一直没变 | 开启后第一次只记基线；之后条目数没增加、或没到最小间隔都会跳过，看卡片上的执行时间与结果 |
| 自动换封面显示「封面已被手动修改」 | 你在播放器或手动弹窗里改过封面，自动任务不会覆盖；点「立即执行一次」，在确认框里选择继续覆盖才会重新接管 |
| 自动换封面一直失败 | 检查媒体服务器是否可达、库内是否有作品图；失败原因在设置弹窗的「最近一次自动更换」和后端日志里 |
| 点「换一批」没变化 | 库里作品图太少，随机到的是同一批 |
| 写回后播放器里还是旧图 | 播放器缓存没刷新，触发一次库扫描或刷新元数据 |
