# 文件浏览器

文件浏览器把服务器文件系统映射到网页：浏览目录、搜索文件、上传下载、复制移动、压缩解压、重命名与删除，并内置文本/图片预览与图片裁剪。

{/* truncate */}

## 打开方式

进入 **工具箱 → 文件浏览器**。页面左侧是位置列表，中间是地址栏与文件表格，顶部是搜索框，右上角是显示设置。

## 界面结构

| 区域 | 内容 |
| --- | --- |
| 标题搜索 | 「递归」复选框与搜索框；搜索当前目录或递归子目录 |
| 操作栏 | 上级、刷新、新建、上传、地址面包屑、显示设置 |
| 批量栏 | 收藏夹、任务、复制、移动、粘贴、压缩、解压、删除 |
| 左侧位置 | 服务器根目录/挂载点列表，点击切换 |
| 文件表格 | 名称、大小、修改时间、类型、操作 |
| 底部 | 目录/文件数量统计与分页 |

地址栏支持两种方式：点击面包屑跳转，或点击编辑图标输入绝对路径后回车。首页按钮回到初始位置。

## 浏览与搜索

- 点击目录行或「打开」进入下一级；「上级」返回父目录。
- 搜索框默认只搜当前目录；勾选「递归」后搜索子目录。
- 搜索会替换当前列表并显示搜索横幅，退出搜索后回到原目录。
- 目录大小默认不计算，点击「计算」后才统计；文件大小直接显示。

当前路径与收藏夹保存在浏览器本地，刷新页面后会回到上次的位置；换浏览器或清空本地存储后回到默认位置。

## 新建与上传

| 操作 | 说明 |
| --- | --- |
| 新建文件 | 输入名称后创建空文件 |
| 新建文件夹 | 输入名称后创建目录 |
| 本机上传 | 选择一个或多个文件上传到当前目录，以客户端任务展示进度 |
| 远程下载 | 输入 URL 与可选保存文件名，由服务器下载到当前目录 |

远程下载的文件名留空时由后端根据 URL 推导。上传与远程下载都会出现在任务面板中。

## 文件操作

| 操作 | 说明 |
| --- | --- |
| 打开 | 目录进入下一级；文件打开预览弹窗 |
| 下载 | 文件直接下载；目录先压缩为临时包，完成后在任务面板下载，下载后自动清理 |
| 复制 / 移动 | 先复制/移动选中项到剪贴板，再进入目标目录点「粘贴」 |
| 粘贴 | 按剪贴板模式提交复制或移动任务 |
| 压缩 | 选择 ZIP 或 7Z，填写压缩包名称与存储路径；默认当前目录 |
| 解压 | 仅对 ZIP 文件显示；填写解压目标目录，默认当前目录 |
| 重命名 | 输入新名称后提交 |
| 删除 | 二次确认，目录会递归删除，不可恢复 |
| 属性 | 查看名称、路径、类型、大小、修改时间；目录大小可手动计算 |
| 收藏 | 目录可加入/取消收藏，收藏项出现在「收藏夹」下拉 |
| 裁剪 | 图片文件可打开裁剪弹窗，结果以 `原文件名_cropped.扩展名` 上传到当前目录 |

:::warning[删除不可恢复]
删除目录会递归删除其下全部内容，且没有回收站。批量删除前先确认选中项，重要数据请先备份。
:::

## 预览与裁剪

点击文件行会打开预览弹窗。图片、视频、音频、PDF 可直接预览；文本与 NFO 还可在「编辑 / 源码」标签中修改并保存；其它类型以文件信息为主。

图片裁剪复用 [海报裁剪](/docs/backend/toolbox/poster-crop) 的裁剪组件：确认后生成 `_cropped` 文件，不会覆盖原图。

## 任务面板

上传、下载、远程下载、复制、移动、压缩、解压、文件夹下载等操作都会进入任务面板：

| 状态 | 说明 |
| --- | --- |
| 进行中 | 显示进度；无法获取实时进度时显示「处理中」 |
| 已完成 | 进度条走满 |
| 失败 | 显示失败原因 |
| 已取消 | 用户取消 |

- 客户端任务（上传、文件下载、远程下载）由前端跟踪；服务端任务（复制、移动、压缩、解压、文件夹下载）由后端执行。
- 有运行中的服务端任务时按约 1.2 秒间隔轮询，全部结束后停止。
- 任务可取消；服务端任务还可从面板移除并删除服务端记录。
- 文件夹下载完成后，可在任务面板直接下载压缩包，下载后自动清理临时文件。

## 显示设置

点击操作栏右侧的设置按钮，可以：

- 显示/隐藏隐藏文件。
- 控制大小、修改时间、类型、操作四列的显隐。

表格密度固定为中等，分页支持 10 / 20 / 50 / 100 条每页，底部显示当前目录的目录数与文件数。

## 注意事项

- 所有操作以运行 AMMDS 的进程权限执行；权限不足时会直接失败，需在宿主机调整目录权限。
- 压缩/解压、复制/移动大目录会占用磁盘 I/O，建议避开扫描与刮削高峰。
- 远程下载依赖服务器出网能力；内网地址或需要鉴权的链接可能失败。
- 删除、覆盖、移动都是不可逆操作；批量操作前先用单个文件验证。
- 文件浏览器不负责媒体库入库；新增/移动文件后仍需扫描任务发现。

需要整理媒体文件时，配合 [扫描任务](/docs/backend/task/scan) 使用；图片处理见 [海报裁剪](/docs/backend/toolbox/poster-crop)。
