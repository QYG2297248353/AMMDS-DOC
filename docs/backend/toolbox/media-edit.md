# 媒体编辑

「媒体编辑」在工具箱中对应「媒体处理」分组：字幕生成、封面裁剪、视频转码与格式转换四个工具都从这里进入，各自有独立的任务列表与产物。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体处理**，展开后可见四个子页。四个工具互不依赖，可以单独使用。

| 工具 | 作用 | 依赖 | 产物 |
| --- | --- | --- | --- |
| [字幕生成](/docs/backend/toolbox/subtitle) | 从视频音轨识别字幕，支持双语与翻译 | VibeVoice 插件 | `.srt` 字幕文件 |
| [封面裁剪](/docs/backend/toolbox/poster-crop) | 把横版图裁成竖版海报，或生成配套图片 | 无 | `-poster` / `-fanart` / `-thumb` 图片 |
| [视频转码](/docs/backend/toolbox/video-convert) | 重新编码视频，转换容器与编码 | FFmpeg 插件 | 新视频文件 |
| [格式转换](/docs/backend/toolbox/format-convert) | 仅换容器、不重新编码的流拷贝 | FFmpeg 插件 | 新视频文件 |

## 怎么选

| 你的目标 | 用哪个 |
| --- | --- |
| 视频没有字幕，想自动生成 | 字幕生成 |
| 已有字幕，想翻译成双语 | 字幕生成 → 翻译 |
| 海报是横图，媒体服务器显示不完整 | 封面裁剪 |
| 想把 MKV 换成 MP4，编码不变 | 格式转换（流拷贝） |
| 想减小体积或统一编码 | 视频转码（重新编码） |
| 想批量处理一个目录 | 字幕生成、视频转码、格式转换都支持目录批量 |

:::tip[先判断是否需要重新编码]
只是容器不兼容、目标格式又在探测结果的支持列表里时，优先用「格式转换」，速度快且无损。只有目标格式不支持流拷贝，或需要改变编码/码率时，才用「视频转码」。
:::

## 共同约定

- **文件选择**：都通过服务器文件树选择，展开目录时才按需加载；不可用的文件类型会置灰。
- **异步任务**：提交后立即返回，任务在列表中异步执行；超出最大并发数的任务进入排队状态。
- **任务操作**：列表统一提供详情、取消、重试（失败/取消后）、删除；删除可能同时删除已生成的输出文件。
- **轮询刷新**：任务列表会定时轮询刷新，页面不可见时暂停。
- **产物落盘**：输出写入服务器磁盘，不会自动写入媒体库；需要由扫描任务发现，或放到已开启目录监控的目录中。

## 前置条件

| 工具 | 需要先配置 |
| --- | --- |
| 字幕生成 | [VibeVoice](/docs/integration/auxiliary/vibevoice) 已启用并可访问 |
| 视频转码 / 格式转换 | [FFmpeg](/docs/integration/auxiliary/ffmpeg) 已启用，且服务端能调用 ffmpeg/ffprobe |
| 封面裁剪 | 无需插件；服务器图片路径可读即可 |

插件未启用时，对应页面只显示空状态提示，不展示任务列表。

## 注意事项

- 批量任务会处理目录内的全部受支持文件，提交前先用单个文件验证参数。
- 转码是 CPU/GPU 密集型操作，建议控制并发数，避免与扫描、刮削同时抢占资源。
- 「源目录同名」输出会用目标扩展名生成文件；目标路径已存在或与源文件相同时，后端会拒绝创建任务，不会覆盖。需要保留原文件时选「源目录加后缀」或「统一输出目录」。
- 字幕、转码、格式转换的产物都需要重新扫描才会进入媒体库；已经整理过的影片可用「查漏补缺」补充附属文件。
- 删除任务时若勾选删除输出文件，原始视频不会被删除，但已生成的转码/字幕/图片会丢失。

四个工具的字段、状态与操作细节分别见 [字幕](/docs/backend/toolbox/subtitle)、[封面裁剪](/docs/backend/toolbox/poster-crop)、[视频转码](/docs/backend/toolbox/video-convert) 与 [格式转换](/docs/backend/toolbox/format-convert)。
