# 格式转换

格式转换只更换容器（如 MKV → MP4），视频与音频流直接拷贝，不重新编码。它比转码快得多，也不损失画质，但目标容器必须与源编码兼容。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体处理 → 格式转换**。页面顶部是「新建转换任务」与状态页签，下方是任务列表。

:::note[前置条件]
格式转换依赖 [FFmpeg](/docs/integration/auxiliary/ffmpeg) 插件。插件未启用时页面只显示启用提示，不展示任务列表。
:::

## 与视频转码的区别

| 维度 | 格式转换 | [视频转码](/docs/backend/toolbox/video-convert) |
| --- | --- | --- |
| 处理方式 | 流拷贝，不重新编码 | 重新编码视频流 |
| 画质 | 无损 | 由 CRF/预设决定 |
| 速度 | 很快，接近文件复制 | 慢，取决于视频长度与编码 |
| 兼容范围 | 仅源编码支持的目标容器 | 几乎所有目标格式 |
| 参数 | 目标格式、输出方式 | 目标格式、编码、预设、CRF、输出方式 |

目标格式不在可选列表时，说明源编码无法通过流拷贝写入该容器，应改用「视频转码」。

## 新建任务

### 选择范围

| 方式 | 输入 | 目标格式来源 |
| --- | --- | --- |
| 单个视频 | 选择一个视频文件 | 探测后只列出与当前编码兼容的格式 |
| 目录批量 | 选择一个目录 | 列出全部常见格式，逐个检测，无法无损转换的文件跳过 |

支持的视频扩展名与视频转码一致，包括 `.mp4`、`.mkv`、`.avi`、`.mov`、`.wmv`、`.flv`、`.webm`、`.m4v`、`.ts`、`.rmvb`、`.mpg`、`.mpeg`、`.3gp`、`.ogv`、`.vob`。

### 目标格式

常见选项：MP4、MKV、MOV、WebM、AVI、TS、M4V、MPG、FLV、3GP、OGV、WMV。

单文件选择视频后会自动探测；探测完成前目标格式下拉不可用。若探测结果中没有兼容格式，列表为空，此时只能改用视频转码。

### 输出方式

| 方式 | 输出路径 | 文件名 | 后缀默认值 |
| --- | --- | --- | --- |
| 源目录同名 | 视频所在目录 | 原文件名 + 目标扩展名 | - |
| 源目录加后缀 | 视频所在目录 | 原文件名 + 后缀 + 目标扩展名 | `convert` |
| 统一输出目录 | 指定目录 | 原文件名 + 目标扩展名 | - |

:::warning[不会覆盖已有文件]
目标文件已存在，或目标路径与源文件完全相同时，后端会拒绝创建任务并提示更换目标格式/输出目录。需要保留原文件时选择「源目录加后缀」或「统一输出目录」。
:::

## 任务列表

| 列 | 说明 |
| --- | --- |
| 视频文件 | 文件名，悬浮显示完整路径 |
| 目标格式 | 源格式 → 目标格式 |
| 方式 | 固定显示「无损」 |
| 状态 | 等待、排队、进行中、完成、失败、已取消 |
| 进度 | 运行时显示进度条、已处理时长/总时长、速度与码率 |
| 创建时间 | 任务创建时间 |
| 操作 | 详情、取消、重试、删除 |

列表每 5 秒刷新一次；页面不可见时暂停轮询。

### 状态与操作

| 状态 | 可执行操作 |
| --- | --- |
| 等待 / 排队 / 进行中 | 详情、取消 |
| 完成 | 详情、删除 |
| 失败 / 已取消 | 详情、重试、删除 |

展开行会展示视频路径、输出路径、帧率、速度、执行命令与最近输出。删除任务会同时删除已生成的输出文件，原始视频不受影响。

## 使用建议

| 场景 | 建议 |
| --- | --- |
| 播放器只支持 MP4 | 先把 MKV 转为 MP4；若探测显示 H.265 不兼容，改用视频转码 |
| 想批量统一容器 | 用目录批量；先看创建结果数量，跳过的文件在服务日志中 |
| 保留原文件 | 输出方式选「源目录加后缀」或「统一输出目录」 |
| 目标格式不在列表 | 源编码不支持流拷贝，改用 [视频转码](/docs/backend/toolbox/video-convert) |
| 转换后没有声音 | 检查源音频编码是否被目标容器支持，必要时改用转码 |

## 注意事项

- 格式转换不修复损坏的源文件；源文件本身无法解码时，转换也会失败。
- 批量创建只统计成功创建的任数；全部失败时返回错误，部分失败时成功部分照常执行。
- 产物不会自动入库，需要重新扫描或放到已监控目录。
- 同一目标路径已存在文件时不会覆盖，这是有意的保护；需要替换时先手动删除旧文件。

FFmpeg 的安装与路径配置见 [FFmpeg](/docs/integration/auxiliary/ffmpeg)；需要重新编码时见 [视频转码](/docs/backend/toolbox/video-convert)。
