# 下载器工具

下载器工具是 qBittorrent 的管理入口：一边展示插件连接信息，一边管理种子任务。站点检索、磁力检索与订阅提交的任务，最终都会出现在这里。

{/* truncate */}

## 打开方式

进入 **工具箱 → 下载器**，包含两个子页：

| 子页 | 作用 |
| --- | --- |
| 插件信息 | qBittorrent 连接参数、版本、默认保存路径与种子数量 |
| 任务管理 | 种子任务列表与新建、开始、暂停、删除操作 |

:::note[前置条件]
两个页面都依赖 qBittorrent 插件。未启用时只显示「插件未启用」空状态，不发起请求。配置方式见 [qBittorrent](/docs/integration/downloader/qbittorrent)。
:::

## 插件信息

| 字段 | 说明 |
| --- | --- |
| 用户名 / 密码 | 插件配置中的登录凭据，密码按后端返回值展示 |
| URL | qBittorrent Web API 地址 |
| 默认保存路径 | 未指定保存路径时任务的落盘目录 |
| API 版本 | Web API 版本 |
| App 版本 | qBittorrent 客户端版本 |
| 种子数量 | 当前下载器中的任务总数 |

这些信息来自 qBittorrent 的实时接口。若页面显示空状态或数值异常，先检查插件是否启用、地址与凭据是否正确、Web API 是否可访问。

## 任务列表

在「任务管理」中查看种子任务，列表每 5 秒静默刷新一次，页面不可见时暂停轮询。

| 列 | 说明 |
| --- | --- |
| 文件名称 | 种子名称；下方副行显示保存路径 |
| 状态 | 状态码转换后的中文说明，并附带下载/上传速度 |
| 大小 | 任务总大小 |
| 分类 | 提交时写入的分类，如 `AMMDS` |
| 标签 | 提交时写入的标签，可多个 |
| 进度 | 0~1 的比例转换为进度条 |

### 状态说明

| 状态码 | 中文 |
| --- | --- |
| `downloading` | 下载中 |
| `uploading` | 上传中 |
| `metaDL` | 获取元数据中 |
| `allocating` | 分配硬盘空间中 |
| `queuedDL` / `queuedUP` | 排队等待下载 / 上传 |
| `pausedDL` / `pausedUP` | 已暂停（下载 / 上传） |
| `stoppedDL` / `stoppedUP` | 已停止（未完成 / 已完成） |
| `stalledDL` / `stalledUP` | 下载 / 上传停滞（无连接） |
| `forcedDL` / `forcedUP` | 强制下载 / 上传（绕过队列） |
| `checkingDL` / `checkingUP` | 校验未完成 / 已完成数据 |
| `checkingResumeData` | 检查断点续传数据 |
| `moving` | 移动文件中 |
| `missingFiles` | 缺少文件 |
| `error` | 错误状态 |

未在映射表中的状态会原样显示状态码。

## 新建任务

点击「新建任务」打开弹窗，顶部切换两种模式：

| 模式 | 输入 | 说明 |
| --- | --- | --- |
| 磁力下载 | 下载链接文本框 | 支持多个磁力链接换行输入 |
| 种子文件 | 上传 `.torrent` 文件 | 支持多选与拖拽上传 |

两种模式共用以下参数：

| 参数 | 说明 |
| --- | --- |
| 分类 | 下载器中的分类名，可留空 |
| 标签 | 输入后按回车确认，提交时拼接为逗号分隔字符串 |
| 保存路径 | 留空时使用 qBittorrent 默认保存路径 |

表单校验只要求「有链接」或「有种子文件」；分类、标签、保存路径都是可选项。提交成功后弹窗关闭并提示「下载任务已提交」。

## 批量操作

先在列表中勾选任务，再使用顶部按钮：

| 按钮 | 行为 |
| --- | --- |
| 开始下载 | 对勾选任务调用开始接口，成功后清空选择 |
| 暂停下载 | 对勾选任务调用暂停接口，成功后清空选择 |
| 删除任务 | 二次确认，可选择「删除原文件」或仅「删除任务」 |

:::warning[删除原文件不可恢复]
删除弹窗的确认按钮是「删除原文件」，取消按钮才是「删除任务」。误点确认会同时删除已下载的数据。正在做种或准备辅种的任务，删除前先确认相关流程已停止。
:::

## 与订阅、辅种的关系

| 链路 | 写入内容 | 查看位置 |
| --- | --- | --- |
| 站点搜索推送 | 分类 `AMMDS` | 本页任务管理 |
| 磁力搜索推送 | 分类 `AMMDS` | 本页任务管理 |
| 订阅自动下载 | 标签 `AMMDS订阅`、`subscribe-<订阅ID>`，保存路径取订阅配置 | 本页任务管理 |
| IYUU 辅种 | 由辅种计划提交到 qBittorrent 或 Transmission | [PT 辅种](/docs/backend/toolbox/subspecies) |

订阅提交后会按标签回查哈希并删除临时标签；辅种任务与下载器任务不是同一份记录。推送链路与保存路径的完整说明见 [下载器使用](/docs/backend/subscribe/downloader)。

## 排查建议

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 任务列表为空 | 插件未启用、连接失败或当前页无数据 | 检查插件配置，切换分页或刷新 |
| 新建任务提示失败 | 链接/种子无效、保存路径不可写 | 换种子文件，检查保存路径权限 |
| 进度不更新 | 轮询被暂停或下载器无响应 | 刷新页面，检查 qBittorrent 状态 |
| 任务显示缺少文件 | 文件被移动或删除 | 恢复文件后重新校验，或删除任务重下 |
| 删除后文件也没了 | 确认时选择了「删除原文件」 | 无法恢复，只能重新下载 |

站点侧的资源检索见 [站点资源检索](/docs/backend/subscribe/search)；订阅的匹配与重试见 [订阅管理](/docs/backend/subscribe/manage)。
