# 媒体服务器工具

媒体服务器工具把 Jellyfin 与 Emby 的管理能力集中到工具箱：查看服务器信息、管理媒体库、浏览影视与演员，并把服务器上的条目与本地影视库建立绑定。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体服务器**，包含四个子页：

| 子页 | 作用 |
| --- | --- |
| 插件信息 | Jellyfin / Emby 服务器名称、版本与服务地址 |
| 库管理 | 媒体库卡片、全库扫描、单库扫描、换封面、同步媒体库/播放记录 |
| 影视库 | 按媒体库与类型浏览影视，编辑元数据、换封面、绑定本地影片 |
| 演员库 | 浏览演员，编辑资料、换头像、绑定本地演员、同步到本地 |

:::note[前置条件]
Jellyfin 与 Emby 各自独立启用。未启用的服务不会出现在列表中，相关按钮置灰或不显示。Jellyfin 的配置见 [Jellyfin](/docs/integration/media-server/jellyfin)。
:::

## 插件信息

页面展示 Jellyfin 与 Emby 的联合标识，并按已启用的服务列出：

| 字段 | 说明 |
| --- | --- |
| 客户端 | Jellyfin 或 Emby |
| 服务器名称 | 媒体服务器实例名称 |
| 版本 | 服务器版本 |
| 服务地址 | 服务器访问地址 |

未启用任何媒体服务器或取不到信息时显示空状态。

## 库管理

### 全局操作

| 按钮 | 行为 |
| --- | --- |
| 扫描所有媒体库 | 同时向 Jellyfin 与 Emby 提交全库扫描任务 |

全库扫描是异步任务，提交后立即返回，实际进度由媒体服务器执行。

### 单服务操作

Jellyfin 与 Emby 各有独立的操作区：

| 按钮 | 行为 |
| --- | --- |
| 补全演员信息 | 提交该服务全部媒体库的演员信息补全任务 |
| 同步媒体库 | 把该服务的媒体库列表同步到 AMMDS |
| 同步播放记录 | 拉取该服务的播放记录 |
| 刷新 | 重新加载该服务的媒体库卡片 |

### 媒体库卡片

每张卡片展示库封面、库名称与类型（影片 / 节目 / 其他），并提供两个操作：

- **更换封面**：支持「本地上传」与「封面库」两个页签。本地上传接受图片，大小上限 10MB；封面库按分组展示内置封面，点击选中后提交。
- **立即扫描**：只扫描该媒体库。

没有媒体库时显示空状态；服务未启用时显示启用提示。

## 影视库

影视库按 Jellyfin 与 Emby 分开展示，支持：

| 控件 | 说明 |
| --- | --- |
| 搜索影片名称 | 按名称搜索 |
| 媒体库筛选 | 全部媒体库或指定库 |
| 类型 | 电影 / 剧集 / 全部 |
| 刷新 | 重新加载两端的影视列表 |

卡片展示海报、评分、名称、年份与演员数量。点击卡片打开详情：

- 编辑名称、原文名、年份、首映日期、评分、地区/国家、类型、标签、出品公司、简介。
- 更换封面：上传图片后提交。
- 绑定本地影片：搜索 AMMDS 影视库并选择一条记录绑定；已绑定时可解除绑定。
- 查看演员列表；演员由媒体服务器管理，页面不提供增删。

保存后写回媒体服务器；同步存在延迟时以服务器实际状态为准。

## 演员库

演员库同样按服务分开展示：

| 控件 | 说明 |
| --- | --- |
| 搜索演员名称 | 按名称过滤 |
| Jellyfin 同步到本地 / Emby 同步到本地 | 把该服务的演员数据同步到 AMMDS 本地演员库 |
| 刷新 | 重新加载演员列表 |

点击演员卡片打开详情：

- 编辑名称、原文名、出生日期、地区/国籍等资料。
- 更换头像：上传图片后提交。
- 绑定本地演员：搜索本地演员库并绑定；已绑定时可解除。
- 查看关联影片。

演员列表在前端分页，适合快速浏览；数据量很大时先用搜索缩小范围。

## 同步与扫描的区别

| 操作 | 作用 |
| --- | --- |
| 扫描媒体库 | 让媒体服务器重新扫描磁盘文件，发现新增/删除的媒体 |
| 同步媒体库 | 把媒体服务器的库列表与条目同步到 AMMDS |
| 同步播放记录 | 拉取观看进度与播放状态 |
| 补全演员信息 | 为库内缺失演员资料的条目补齐信息 |
| 绑定本地记录 | 把服务器条目与 AMMDS 影视/演员记录关联，便于统一维护 |

这些操作都是异步提交，页面只提示「任务已提交」；执行结果在媒体服务器或系统任务日志中查看。

## 使用建议

| 场景 | 建议 |
| --- | --- |
| 新增影片后服务器没显示 | 先对目标库点「立即扫描」，再刷新列表 |
| 换了海报但服务器没变 | 换封面后让媒体服务器刷新元数据 |
| 本地记录与服务器对不上 | 在影视库/演员库详情中手工绑定 |
| 播放记录不同步 | 检查媒体服务器插件凭据与连通性，再点「同步播放记录」 |
| 库封面缺失 | 用「更换封面」上传，或先用 [海报裁剪](/docs/backend/toolbox/poster-crop) 生成合适比例 |

影视与剧集的本地维护见 [影视](/docs/backend/media/movie) 与 [剧集](/docs/backend/media/tvshow)；其它工具见 [媒体编辑](/docs/backend/toolbox/media-edit)。
