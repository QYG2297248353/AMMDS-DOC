# 视频转码

视频转码会**重新编码**视频流，用于改变编码格式、缩小体积或统一媒体库规格。它与只换容器的「格式转换」不同，耗时更长，但兼容性与压缩率可控。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体处理 → 视频转码**。页面顶部是「新建转码任务」与状态页签，下方是任务列表。

:::note[前置条件]
视频转码依赖 [FFmpeg](/docs/integration/auxiliary/ffmpeg) 插件。插件未启用时页面只显示启用提示；FFmpeg 不可用时任务会失败并记录错误。
:::

## 新建任务

### 选择范围

| 方式 | 输入 | 说明 |
| --- | --- | --- |
| 单个视频 | 选择一个视频文件 | 选择后自动探测分辨率、时长、音视频编码与支持无损的目标格式 |
| 目录批量 | 选择一个目录 | 为目录内全部受支持视频创建任务，超出并发上限的进入「排队中」 |

支持的视频扩展名包括 `.mp4`、`.mkv`、`.avi`、`.mov`、`.wmv`、`.flv`、`.webm`、`.m4v`、`.ts`、`.rmvb`、`.mpg`、`.mpeg`、`.3gp`、`.ogv`、`.vob`。

### 目标与方式

| 参数 | 说明 |
| --- | --- |
| 目标格式 | MP4、MKV、MOV、WebM、AVI、TS、M4V、MPG、FLV、3GP、OGV、WMV |
| 无损转换 | 源编码与目标容器兼容时可直接流拷贝，速度极快且不损失画质 |
| 视频编码 | 关闭无损时可选 H.264（libx264，兼容性最好）或 H.265（libx265，体积更小） |
| 编码预设 | ultrafast ~ veryslow 九档；越快体积越大，越慢压缩率越高 |
| 质量（CRF） | 0~51，默认 23；数值越小画质越高、体积越大，建议 18~28 |

单文件模式下，探测结果会显示「支持无损」或「当前编码不支持无损」。不支持时「无损转换」开关置灰，只能重新编码；批量模式会在创建任务时逐个检测编码兼容性，不兼容的视频自动跳过。

### 输出方式

| 方式 | 输出路径 | 文件名 |
| --- | --- | --- |
| 源目录同名 | 视频所在目录 | 原文件名 + 目标扩展名 |
| 源目录加后缀 | 视频所在目录 | 原文件名 + 后缀 + 目标扩展名，后缀默认 `transcode` |
| 统一输出目录 | 指定目录 | 原文件名 + 目标扩展名 |

:::warning[不会覆盖已有文件]
目标文件已存在，或目标路径与源文件完全相同时，后端会拒绝创建任务并提示更换目标格式/输出目录。需要保留原文件时选择「源目录加后缀」或「统一输出目录」。
:::

## 任务列表

| 列 | 说明 |
| --- | --- |
| 视频文件 | 文件名，悬浮显示完整路径 |
| 目标格式 | 源格式 → 目标格式 |
| 方式 | 无损 / 重新编码 |
| 状态 | 等待、排队、进行中、完成、失败、已取消 |
| 进度 | 运行时显示进度条、已处理时长/总时长、速度与码率；结束后显示百分比 |
| 创建时间 | 任务创建时间 |
| 操作 | 详情、取消、重试、删除 |

列表每 5 秒刷新一次，运行时进度自动更新；页面不可见时暂停。

### 状态与操作

| 状态 | 可执行操作 |
| --- | --- |
| 等待 / 排队 / 进行中 | 详情、取消 |
| 完成 | 详情、删除 |
| 失败 / 已取消 | 详情、重试、删除 |

点击「详情」打开侧边抽屉；展开行则直接展示视频路径、输出路径、视频编码、预设、CRF、帧率、执行命令与最近输出，便于排查失败原因。

删除任务会同时删除已生成的输出文件，原始视频不受影响。

## 使用建议

| 目标 | 建议参数 |
| --- | --- |
| 最大兼容性 | MP4 + H.264 + `veryfast` + CRF 23 |
| 更小体积 | MKV 或 MP4 + H.265 + `medium` + CRF 24~28 |
| 仅换容器 | 优先用 [格式转换](/docs/backend/toolbox/format-convert)，不要重新编码 |
| 批量统一规格 | 先用单个文件验证预设与 CRF，再提交目录批量 |
| 保留原文件 | 输出方式选「源目录加后缀」或「统一输出目录」 |

## 注意事项

- 转码是 CPU/GPU 密集型操作，建议控制并发，避免与扫描、刮削同时抢占资源。
- H.265 体积更小，但部分老旧播放器/浏览器不支持，选择前确认目标设备。
- CRF 与预设共同决定体积与画质；只调 CRF 不调预设，压缩收益有限。
- 转码产物不会自动入库，需要重新扫描或放入已监控目录。
- 任务失败时先看「最近输出」与执行命令，常见原因是源文件损坏、磁盘空间不足或 FFmpeg 路径错误。

FFmpeg 的安装与路径配置见 [FFmpeg](/docs/integration/auxiliary/ffmpeg)；只换容器时用 [格式转换](/docs/backend/toolbox/format-convert)。
