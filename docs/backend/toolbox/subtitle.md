# 字幕

字幕工具调用 VibeVoice 从视频音轨识别语音并生成 `.srt` 字幕，支持自动检测语言、指定识别语言，以及识别后翻译为双语字幕。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体处理 → 字幕生成**。页面顶部是「新建字幕任务」按钮与状态页签，下方是任务列表。

:::note[前置条件]
字幕功能依赖 [VibeVoice](/docs/integration/auxiliary/vibevoice) 插件。插件未启用时页面只显示启用提示，不展示任务列表；服务地址或模型不可用时，任务会以失败状态结束并记录错误信息。
:::

## 新建任务

点击「新建字幕任务」打开抽屉，先选择创建方式：

| 方式 | 输入 | 行为 |
| --- | --- | --- |
| 单个视频 | 选择一个视频文件 | 为该文件创建一个识别任务 |
| 目录批量 | 选择一个目录 | 为目录内全部受支持视频批量创建任务，超出并发上限的进入「排队中」 |

视频文件通过服务器文件树选择，支持 `.mp4`、`.mkv`、`.avi`、`.mov`、`.wmv`、`.flv`、`.webm`、`.m4v`、`.ts`、`.rmvb`、`.mpg`、`.mpeg`。其它文件节点会置灰不可选。

### 识别参数

| 参数 | 说明 |
| --- | --- |
| 识别语言 | 自动检测、简体中文、英语、日语、韩语、俄语、西班牙语、法语、德语、意大利语、葡萄牙语、阿拉伯语、泰语、土耳其语 |
| 双语字幕 | 开启后把识别结果翻译为目标语言，字幕双行显示 |
| 目标语言 | 双语开启时必填：简体中文、繁体中文、英语、日语、韩语、俄语、捷克语 |

:::info[时长限制]
单个视频最长支持 12 小时；单次识别请求最大 60 分钟，超出部分会自动分段处理。分段进度可在任务展开行中查看「已完成分段 / 总分段」。
:::

## 任务列表

| 列 | 说明 |
| --- | --- |
| 视频文件 | 显示文件名，悬浮可看完整路径 |
| 时长 | 视频时长 |
| 识别语言 | 任务使用的识别语言 |
| 双语 | 开启时显示目标语言标签，否则显示 `-` |
| 状态 | 状态名与颜色 |
| 进度 | 等待/进行中/翻译中显示进度条，其余显示百分比 |
| 创建时间 | 任务创建时间 |
| 操作 | 详情、取消、重试、查看、编辑、下载、翻译、删除 |

列表每 10 秒刷新一次，运行时进度会自动更新；页面不可见时暂停轮询。

## 状态

| 状态 | 含义 |
| --- | --- |
| `waiting` | 等待执行 |
| `queued` | 排队中，等待并发名额 |
| `running` | 正在识别 |
| `translating` | 识别完成，正在翻译 |
| `success` | 生成成功，可查看/编辑/下载 |
| `failed` | 失败，展开行显示错误信息 |
| `canceled` | 已取消，可重试 |

「进行中」页签对应 `waiting,queued,running,translating`；「已完成」页签对应 `success,failed,canceled`。

## 任务操作

| 操作 | 可用状态 | 行为 |
| --- | --- | --- |
| 详情 | 全部 | 打开侧边详情，查看任务字段与执行信息 |
| 取消 | 等待、排队、识别中、翻译中 | 请求取消，成功后刷新列表 |
| 重试 | 失败、已取消 | 重新加入队列 |
| 查看 | 成功 | 以只读方式打开字幕内容 |
| 编辑 | 成功 | 打开字幕文本，可修改并保存 |
| 下载 | 成功 | 下载 `.srt`；翻译任务的文件名会带目标语言后缀 |
| 翻译 | 成功 | 基于当前字幕创建一条新的翻译任务 |
| 删除 | 全部 | 删除任务及其生成的字幕文件 |

删除会同时删除字幕产物，且不可恢复；只想换语言时用「翻译」而不是删除重建。

## 展开行与详情

展开一行可看到：

- 失败任务：错误信息。
- 其它任务：视频路径、分段数（已完成 / 总数）、字幕片段数、识别模型、线程数、字幕文件路径。
- 翻译任务：源任务 ID 与目标语言。

任务详情侧边栏提供更完整的任务信息，适合排查「为什么排队」「用了哪个模型」「产物在哪里」。

## 翻译任务

对已成功的字幕点击「翻译」，选择目标语言后提交：

1. 系统基于当前字幕创建一条新任务，源任务 ID 记录在新任务上。
2. 新任务走翻译流程，状态会经历 `translating`，完成后为 `success`。
3. 翻译任务的字幕可单独查看、编辑、下载；下载文件名会追加目标语言后缀。
4. 翻译不覆盖原字幕，两个任务各自保留产物。

翻译使用系统配置的翻译服务；翻译服务不可用时任务会失败，需先检查翻译插件配置。

## 注意事项

- 识别质量取决于音轨清晰度、背景音乐与语言；多人同时说话或强噪声会增加错字。
- 字幕文本编辑保存后直接写回字幕文件，媒体服务器需要刷新元数据才能看到变化。
- 双语字幕的翻译是逐句进行的，长视频耗时明显高于单纯识别。
- 批量创建前先确认目录内没有不需要的视频，避免无谓的识别开销。
- 字幕产物不会自动入库；需要由扫描任务发现，或放到已监控目录中。

VibeVoice 的安装与模型配置见 [VibeVoice](/docs/integration/auxiliary/vibevoice)；其它媒体处理工具见 [媒体编辑](/docs/backend/toolbox/media-edit)。
