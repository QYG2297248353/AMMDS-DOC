# PT 辅种

「PT 辅种」把已下载的资源按特征码匹配到其他站点，减少重复下载与做种成本。功能由 IYUU 提供，AMMDS 负责账户、站点、计划与记录的统一入口。

{/* truncate */}

## 打开方式

进入 **工具箱 → PT 辅种**，包含四个子页：

| 子页 | 作用 |
| --- | --- |
| 插件信息 | IYUU 账户状态与 TOKEN |
| 站点管理 | 支持辅种的站点清单、认证参数与辅种计划 |
| 辅种记录 | 每次辅种的结果、数量与原因 |
| 辅种任务 | 每个种子的辅种状态与站点明细 |

:::note[前置条件]
四个页面都依赖 IYUU 插件。未启用时只显示「插件未启用」空状态，不发起请求。配置方式见 [IYUU](/docs/integration/downloader/iyuu)。
:::

## 插件信息

启用 IYUU 后，页面展示「IYUU × AMMDS 联合出品」标识与账户信息：

| 字段 | 说明 |
| --- | --- |
| 用户名 | IYUU 账户名 |
| 站点 ID | IYUU 站点编号 |
| TOKEN | 点击标签可复制到剪贴板，复制成功/失败都有提示 |
| 是否激活 | 已激活 / 未激活 |
| 激活日期 | 账户激活时间 |
| 创建日期 | 账户创建时间 |
| 账户状态 | 正常 / 异常 |

账户信息来自 IYUU 接口，不是本地缓存；IYUU 不可用时页面会显示空状态或请求失败的提示。

## 站点管理

站点管理页展示每个支持辅种的站点卡片：

| 元素 | 说明 |
| --- | --- |
| 站点 ID / 昵称 | 蓝色标签与站点昵称 |
| 域名 | 站点主域名 |
| 官网 | 在新窗口打开站点首页 |
| 启用开关 | 切换后立即提交，成功/失败即时提示 |
| 认证参数按钮 | 仅站点声明需要时显示：UID、PassKey、cuhash、AuthKey、TorrentPass、RssKey、Authorization、Cookie |

点击参数按钮会打开编辑弹窗，输入值并提交；已填写的按钮会高亮。站点详情每 10 秒刷新一次，外部修改后会自动同步。

页面右上角有三个操作：

- **导入站点**：上传 IYUU 站点配置 JSON 文件，导入完成后刷新列表。
- **辅种计划**：配置自动辅种。
- **立即辅种**：手动触发一次，提示后端预计处理的种子数量。

### 辅种计划

| 字段 | 说明 |
| --- | --- |
| 启用 | 是否开启自动辅种 |
| 执行周期 | Cron 表达式，留空则不按周期执行 |
| 辅种客户端 | qBittorrent / Transmission |
| 通知 | 辅种完成后是否推送通知 |

提交前会校验 Cron 格式；配置保存后由任务调度器注册，不在「系统管理 → 计划任务」列表中展示。

## 辅种记录

辅种记录按批次展示每次执行结果：

| 字段 | 说明 |
| --- | --- |
| 运行模式 | 自动辅种 / 手动辅种 |
| 辅种结果 | 成功 / 失败 |
| 查询数量 | 本次查询的种子数量 |
| 辅种时间 | 执行时间 |
| 结果 | 结果原因或说明 |

页面支持分页与切换每页条数，右上角「清空日志」会删除全部辅种记录，不影响正在运行的辅种任务。

## 辅种任务

辅种任务按种子展示辅种进度：

| 字段 | 说明 |
| --- | --- |
| 种子名称 | 资源名称 |
| 种子 Hash | 同时展示 v1 与 v2；缺失时显示「暂无 Hash v1/v2」 |
| 辅种状态 | 未辅种、等待辅种、辅种完成、辅种失败 |
| 辅种时间 | 任务加入时间 |
| 完成时间 | 辅种完成时间，未完成显示「暂无时间」 |

展开一行可查看逐站点明细：站点名称与标识、种子 ID、种子 Hash，以及「下载」「详情」两个快捷链接。没有站点明细时，展开行显示失败或等待原因。

任务列表每 10 秒轮询一次，辅种状态会自动更新；「清空辅种」会删除全部辅种任务记录。

## 与下载器的关系

辅种计划里的「辅种客户端」决定 IYUU 把种子提交到哪个下载器：

- 选择 qBittorrent 时，使用 [qBittorrent](/docs/integration/downloader/qbittorrent) 插件配置的连接信息。
- 选择 Transmission 时，使用 [Transmission](/docs/integration/downloader/transmission) 插件配置。
- 站点检索与磁力检索的推送按钮只面向 qBittorrent，与辅种客户端是两套配置。

辅种任务与下载器任务不是同一份列表：下载器任务反映下载/做种进度，辅种任务反映「这个种子在哪些站点被辅种」。删除文件前应先确认相关做种与辅种任务都已停止。

## 使用建议

| 场景 | 建议 |
| --- | --- |
| 第一次使用 | 先启用 IYUU，导入站点，再逐个填写站点要求的认证参数 |
| 站点认证失败 | 检查 PassKey、Cookie 等参数是否过期，必要时重新登录站点获取 |
| 辅种失败 | 展开任务查看各站点原因，常见为种子不存在、站点未启用或客户端未连接 |
| 自动辅种太频繁 | 调整辅种计划的 Cron，避免对站点造成压力 |
| 想手动补一次 | 点击「立即辅种」，完成后到辅种记录与辅种任务查看结果 |

下载器侧的推送与任务查看见 [下载器使用](/docs/backend/subscribe/downloader) 与 [下载器工具](/docs/backend/toolbox/downloader)。
