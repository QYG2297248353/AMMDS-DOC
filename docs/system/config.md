# 系统配置

系统配置集中维护全站级别的运行参数：域名与访问方式、站点信息与 SEO、网络代理、通知推送、界面主题、安全功能开关以及后台请求超时。改动会直接写入配置表，不需要编辑配置文件，多数配置保存后立即生效。

{/* truncate */}

## 打开方式

进入 **系统管理 → 系统配置**。页面顶部是七个标签页，同一时间只展示一个分区；切换标签页时各分区保留自己的表单状态，刷新页面会回到上次停留的分区。

| 标签页 | 管什么 |
| --- | --- |
| 基础配置 | 域名绑定、互联互通、开放 API、系统模式、磁盘监测、广告 |
| 主题外观 | 落地页、系统主题、背景与配色、哀悼模式 |
| 通知配置 | 通知总开关、消息类型、夜间免打扰 |
| 网络配置 | 代理开关、协议、主机与端口、认证、免代理名单 |
| 后台配置 | 后台请求超时（保存在浏览器本地） |
| 安全配置 | Passkey、两步验证、统一登录 |
| 站点配置 | 站点信息、备案信息、页脚快捷链接、SEO |

## 基础配置

### 域名绑定

未绑定域名时显示「未绑定」，绑定后显示「已绑定」。修改域名是三步流程，顺序不能颠倒：

| 步骤 | 按钮 | 做了什么 |
| --- | --- | --- |
| 1 | 测试 | 验证域名是否已解析并指向本服务器，不写入绑定关系 |
| 2 | 生成校验令牌 | 服务端下发令牌，页面给出需添加的 TXT 记录（主机记录为域名，值为令牌） |
| 3 | 验证并绑定 | 服务端核对 DNS TXT 记录，通过后写入域名配置 |

:::warning[必须通过待绑定域名访问]
绑定前请先用新域名打开本系统。页面会比较输入域名与当前访问域名（忽略协议、路径、端口与大小写），不一致时直接拒绝，因为无法完成 TXT 记录校验。
:::

### 互联互通

与其他 AMMDS 站点共享数据。开启前要求已绑定域名并完善个人信息，条件不满足时开关会自动回滚并提示原因。

### 开放 API

控制 `/api/v1/**` 是否对外开放。关闭后第三方程序即使用 API Key 也无法调用，接口说明见[开发平台](/open-api/getting-started/overview)。

### 系统模式

| 模式 | 含义 |
| --- | --- |
| 完整模式 | 前台站点与后台管理都可用 |
| 纯后台模式 | 只保留后台管理界面 |
| API 模式 | 只提供接口服务 |

切换后立即保存，但**需要重启服务**才真正生效。

### 磁盘监测与广告

- **磁盘监测**：开启后按周期检查剩余空间，空间不足时推送通知。
- **显示广告**：关闭可减少页面负担；非订阅用户关闭时会被后端拒绝，页面提示「非付费用户无法关闭」。

## 站点配置

「站点配置」标签页下分「基本配置」与「SEO 设置」两个子标签。

### 站点信息与备案

站点名称、副标题、描述、公司名称决定前台标题与分享摘要；ICP 备案号、公安备案号、营业执照备案号各配一个查询链接，号码留空即不展示。版权文案是固定内容，页面不提供修改入口。

### 页脚快捷链接

按行维护「名称 + 地址」，可上下移动调整展示顺序，最多 20 条。保存时会丢弃名称或地址为空的行。

### SEO 设置

| 配置项 | 说明 |
| --- | --- |
| SEO 标题 / 关键词 / 描述 | 用于搜索结果与分享摘要；标题留空时使用站点名称 |
| OG 标题 / 描述 / 图片 | 社交平台分享卡片；标题留空时回退 SEO 标题 |
| Twitter Card | `summary` 或 `summary_large_image` |
| robots | 四种预设，也可自定义 |
| canonical | 留空时使用当前访问地址 |

:::note[生效时机]
保存后立即对公开接口生效；页面标题与 meta 会在下次进入页面或刷新时更新。
:::

## 网络配置

代理配置分为开关、协议、主机、端口、认证与免代理六部分。协议支持 HTTP、SOCKS4、SOCKS5；主机与端口在开关打开后才可编辑，端口范围为 1–65535。

免代理名单支持域名、IP、CIDR 与通配符（如 `*.cn`），可从「本地网络」「内网地址」「特定域名」三类预设中勾选，也可手动输入标签。默认已包含回环地址、私有网段与系统时间校验用到的四个国内域名——删掉它们可能导致时间校验失败。

:::tip[保存即热更新]
`proxy_` 开头的配置保存后，后端会立即重建 HTTP 客户端并重启内置 MetaTube，不需要重启整个服务。连通性排查请用[网络与连通性](/docs/dashboard/network)。
:::

## 通知、主题与安全

- **通知配置**：通知推送总开关、消息类型（系统、订阅、下载、入库、认证、会员、影片刮削、演员刮削）、夜间免打扰（22:00–08:00 不推送）。各渠道的密钥在插件页配置，例如 [Telegram](/docs/integration/notification/telegram)。
- **主题外观**：落地页优先进入、系统主题、背景与配色、哀悼模式起止时间。只影响配色与背景，不改变页面布局。
- **安全配置**：Passkey、两步验证、统一登录三个模块，详见[用户与安全](/docs/system/users)。

## 后台配置

「后台配置」目前只有一项：**资源检索超时时间**（秒，最小 12）。它保存在浏览器本地，只影响当前浏览器后续发出的请求，不写入服务端配置，换设备或换浏览器不会继承。

上传体积上限、服务端口、数据库连接、日志级别等由环境变量或启动参数决定，页面不提供修改入口，改完需要重启服务；常见变量见[部署环境](/docs/getting-started/environment)。

## 生效时机

| 改动 | 生效方式 |
| --- | --- |
| 代理类配置 | 立即生效，并重建 HTTP 客户端、重启内置 MetaTube |
| 启用/关闭插件、切换内置服务优先 | 立即重启内置 MetaTube |
| `fsm_` / `m_team_` 配置 | 立即重建对应订阅调度 |
| 系统模式 | 需要重启服务 |
| 站点信息与 SEO | 立即对接口生效，页面下次刷新更新 |

:::info[配置项由枚举维护]
基础配置、网络代理与站点配置的键名、默认值与控件类型分别由 `AmmdsSystemConfigEnum`、`NetworkProxyConfigEnum`、`SiteConfigEnum` 定义。新增配置项只要登记到枚举，页面就能按分区读取与保存；少数配置（例如游客接口限流，默认 100 次/分钟）由后端直接读取，页面未提供修改入口。
:::
