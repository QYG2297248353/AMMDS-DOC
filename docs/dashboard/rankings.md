# 榜单

仪表盘下有三个榜单页面：**巅峰榜单**基于 Jellyfin / Emby 的播放记录做观影统计，**电影榜单**汇总外部元数据源的近期上新，**PT 站点榜单**展示各站点账号的数据。三者数据来源完全不同，本页分别说明。

## 巅峰榜单

### 数据来源

播放记录来自 Jellyfin 与 Emby 集成：开启插件并绑定用户后，后台每 5 分钟同步一次播放记录，写入本地数据库。巅峰榜单只统计**绑定用户**的记录，不读取媒体服务器自身的报表。

:::note[没有数据先检查绑定]
如果页面全为空，先到「集成 → Jellyfin / Emby」确认插件已启用、服务地址与密钥可连通，并且已选择绑定用户。系统检查里也能看到对应插件的启用与配置状态。
:::

### 页面结构

| 区域 | 内容 |
| --- | --- |
| 顶部统计 | 播放次数（近 N 天）、总观影时长（分钟）、日均观影（分钟/天）、覆盖天数 |
| 播放趋势 / 观影时长 | 按天展示各客户端播放时长与总量的柱状图 / 折线组合图 |
| 播放来源分布 | 按播放来源（客户端）聚合播放时长的饼图 |
| 月度播放日历 | 当前自然月每天的播放热度，颜色越深表示当天播放时长越长 |

右上角的 **7 天 / 14 天 / 30 天** 按钮同时影响顶部统计与趋势图，默认为 14 天。

### 统计口径

- 日期按播放记录的**开始时间**归组，统一格式为 `yyyy-MM-dd`。
- 结束时间为空的记录视为未播放完成，不计入按日统计。
- 没有播放记录的日期也会出现在结果中（数值为 0），因此「覆盖天数」等于所选天数。
- 顶部「播放次数」由观看时长换算：每累计 10 分钟计 1 次，向上取整，不是播放记录条数。
- 月度日历里的「播放次数」是播放记录条数，与顶部口径不同，悬浮提示会同时展示两者。

## 电影榜单

### 数据来源

榜单数据由后台定时任务从集成插件采集后落库，页面只读本地数据，不会在打开页面时临时请求上游。

| 榜单 | 上游 | 采集条件 |
| --- | --- | --- |
| ThePornDB | ThePornDB 的「最近更新」接口 | 「启用状态」与「榜单采集」都打开，且服务地址、API Key 完整 |
| Fanza DMM | FANZA DMM 的日期榜单 | 「启用状态」与「榜单采集」都打开 |

采集节奏：

- ThePornDB：启动后约 8 分钟首次采集，之后每 6 小时 10 分钟一次；每次最多翻 10 页、每页 20 条，按「上游 ID + 榜单类型」去重。
- Fanza DMM 今日新作：启动后约 10 分钟首次采集，之后每 6 小时 15 分钟一次；按自然日幂等，当天已有数据就跳过。
- Fanza DMM 即将上映：启动后约 10 分钟首次采集，之后每 13 小时 30 分钟一次，只补采未来 3 天中尚无记录的日期。

### 页面结构

1. 顶部选择榜单来源：**ThePornDB** 或 **Fanza DMM**。
2. 选择分类：

| 榜单来源 | 分类 |
| --- | --- |
| ThePornDB | Jav即将上映、欧美即将上映 |
| Fanza DMM | 今日上新、即将上映 |

3. 卡片列表按发布日期倒序展示，最多 30 条。每张卡片包含封面、番号、发布日期、标题、演员与剧照数量。
4. 卡片右上角是状态按钮：

| 按钮 | 含义 |
| --- | --- |
| 完成 | 该番号已入库，按钮不可点击 |
| 订阅 | 尚未订阅，点击后提交订阅并在后台补全元数据 |
| 已订阅 | 已存在订阅记录，按钮不可点击 |

:::tip[订阅后会发生什么]
订阅会创建订阅记录并异步补全元数据，之后由订阅与下载流程匹配资源。若长时间没有进展，先检查下载器插件与站点配置，再查看订阅状态。
:::

## PT 站点榜单

### 数据来源

数据来自已配置的 PT 站点账号，按站点框架分别拉取：M-Team、Rousi、FSM 与 NexusPHP 系站点。页面不要求先完成「站点认证」，只要站点已配置并同步过数据就会展示。

### 顶部统计

| 指标 | 口径 |
| --- | --- |
| 站点总数 | 有数据的站点数量 |
| 总上传量 / 总下载量 | 各站点上传、下载字节数求和 |
| 总做种数 / 总下载数 | 各站点做种、下载任务数求和 |
| 平均分享率 | 仅统计有分享率的站点，取平均值 |
| 总魔力值 | 各站点魔力值求和 |
| 活跃站点 | 最近 30 天内有过登录记录的站点数 |

### 站点卡片

每张卡片展示站点 Logo、名称、框架标签，以及：

- 分享率、魔力值
- 上传量、下载量
- 做种数、下载数
- 做种时长、下载时长
- 用户名与头像、警告 / 吸血 / 等级标签、注册时间与最后登录时间

卡片右上角有两个按钮：**刷新**（只更新该站点）与**打开主页**。刷新会按站点框架调用对应接口；NexusPHP 系站点按站点 ID 更新。

### 顶部操作

| 按钮 | 作用 |
| --- | --- |
| 刷新数据 | 仅重新读取本地已有的站点数据，不请求上游 |
| 更新所有站点 | 触发后端逐个站点拉取最新数据，耗时较长 |

顶部提示条显示本页最近一次刷新或更新的时间，它只是页面内的时间戳，不代表数据在服务端的实际更新时间。

:::warning[刷新频率]
频繁点击「更新所有站点」会连续请求各站点接口，可能触发风控或临时封禁。数据不需要实时刷新时，保持默认节奏即可。
:::

## 三个榜单怎么配合使用

| 想看什么 | 用哪个榜单 |
| --- | --- |
| 自己的观影时长、习惯与设备分布 | 巅峰榜单 |
| 最近有哪些新片、是否已入库 | 电影榜单 |
| 各 PT 站点的分享率、魔力值与做种情况 | PT 站点榜单 |

观影统计依赖媒体服务器插件，上新榜单依赖元数据插件，站点数据依赖站点配置。三者互相独立，可以只启用其中一部分。
