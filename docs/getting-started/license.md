# 许可证

这一页集中列出一批**可以直接使用的许可证密钥**。选中一条复制，去用户中心激活即可，**水印随即关闭，所有功能照常使用**。密钥由本站维护者不定期更新；如果某条提示「激活数量已满」或不可用，换下一条再试。

> **许可证**：证明这套部署已获得授权的记录。没有有效授权时全站显示水印，但登录、系统配置、站点认证、资料备份等功能都不受影响。
>
> **密钥**：一串形如 `AMMDS-XXXX-XXXX-XXXX-XXXX` 的字符，相当于这套部署的授权凭证。

只是想了解水印、试用、离线激活这些概念，可以直接看[名词说明](../glossary.md)、[常见问题：许可证与水印](../faq.md#许可证与水印)；想看完整的激活、刷新、停用流程，见[系统维护：许可证与水印](../backend/system/maintenance.md#四许可证与水印)。

## 怎么激活

拿到密钥后，用**管理员**账号按下面三步操作。其他登录账号只能看状态和权益，不能激活。

1. 点右上角头像 → **用户中心**，滑到页面底部的「许可证」卡片。
2. 点「激活」（已激活的实例先点「更换许可证」展开），粘贴密钥。
3. 点确认，激活成功后水印关闭，卡片上会显示套餐与有效期。

详细的状态字段、离线激活和试用规则，见[系统维护：许可证与水印](../backend/system/maintenance.md#四许可证与水印)。服务器连不上授权服务时，用「离线激活」：按页面提示拿到实例标识和一条命令，到另一台联网设备执行，把返回的 JSON 存成文件（不超过 64 KiB）再上传回来。

## 几条规则

| 事项 | 规则 |
| --- | --- |
| 激活名额 | 一套部署占一个名额，与登录用户数无关；名额用完需先释放旧设备 |
| 更换许可证 | 替换当前授权；试用进行中时激活成功会立即结束试用 |
| 在线刷新 | 主动校验一次；授权服务暂时不可用时返回当前缓存的状态 |
| 停用在线授权 | 远端确认释放后才清除本地资料 |
| 仅清除本地授权 | 只清本机的密钥和令牌，不释放远端名额，也不清试用记录 |
| 会员与许可证 | 会员是账号上的标识，许可证是这套部署的授权，两者独立 |

停用和清除都需要确认，且不可撤销。具体套餐名称、价格和权益范围以购买页与许可证页的展示为准。

## 密钥用不了怎么办

- **提示「激活数量已满」**：说明这条密钥的名额已被占满，换下一条再试；如果这是你自己的密钥，先到授权门户释放旧设备，或在旧实例上停用在线许可证。
- **提示授权不可用 / 校验失败**：可能已到期、被撤销或暂停，换一条再试；确认密钥复制完整、没有多余空格。
- **水印还在**：激活成功后水印会关闭；若仍在，去用户中心看许可证状态与提示条，按现象去[常见问题：许可证与水印](../faq.md#许可证与水印)找对应条目。功能不受影响，可以先继续用。
- **连不上授权服务**：已经激活的会凭缓存的有效凭证继续运行，还有一段离线宽限期；恢复网络后刷新即可。宽限用完只是恢复水印，不影响功能。
- **还是不对**：带上版本号、时间点、日志片段，到 GitHub 提问题：https://github.com/QYG2297248353/AMMDS-Docker/issues/new
