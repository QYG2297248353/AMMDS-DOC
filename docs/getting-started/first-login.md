# 首次登录与初始化

安装完成后，先用默认管理员账号进入后台，再按顺序完成密码、访问地址、站点信息等设置。本页给出建议的初始化顺序，以及每一步在界面中的实际位置。

{/* truncate */}

## 默认账号

| 项目 | 默认值 |
| --- | --- |
| 用户名 | `ammds` |
| 密码 | `ammds` |

:::warning[用户名不可修改]
管理员用户名固定为 `ammds`。启动时如果发现 `ADMIN_USER` 被改成其他值，或数据库中的管理员用户名不符合约定，程序会直接退出。密码可以通过 `ADMIN_PASS` 在**首次建库时**指定；数据库里已有管理员后再改该变量不会生效。
:::

## 登录

1. 浏览器打开 `http://主机IP:端口`。Docker 示例映射到宿主机的 8080，NAS 应用包以安装时填写的端口为准。
2. 输入 `ammds` / `ammds` 登录。
3. 默认进入「仪表盘 → 工作台」。如果之前把「系统配置 → 主题外观 → 落地页」改成了「优先进入前台影视」，登录后会先到前台首页，从菜单切回后台即可。

登录成功后，系统会把本次访问的 `scheme://host[:port]` 自动写入「服务地址」，作为 OpenAPI 文档、服务发现等场景的对外地址。因此请**先用最终要使用的地址登录一次**，再去做域名绑定。

## 第一步：修改默认密码

1. 点击右上角头像，选择 **用户中心**。
2. 在个人信息页头部点击 **修改密码**，在弹窗中填写原密码与新密码。
3. 依次填写 **当前密码**、**新的密码**、**二次确认**。
4. 点击 **提交修改**。修改成功后会自动登出，用新密码重新登录。

新密码需满足：

| 规则 | 说明 |
| --- | --- |
| 长度 | 6–22 个字符 |
| 组成 | 同时包含大写字母与小写字母，并且包含数字或特殊字符 |

## 第二步：保管恢复密钥

系统在首次启动时会生成恢复密钥，保存在程序目录的 `data/secret/recovery.key`。忘记管理员密码时，在登录页点击 **忘记密码**，输入恢复密钥即可重置密码。

:::tip[现在就备份]
恢复密钥不依赖数据库，重装时如果只备份了 `db/` 而丢失 `data/secret/`，将无法通过恢复密钥找回密码。请把该文件与数据库一起备份到安全位置。
:::

## 第三步：绑定域名（可选）

如果打算用域名访问，先在 DNS 服务商处把域名解析到这台主机，再进入 **系统配置 → 基础配置 → 域名绑定**：

1. 点击 **修改**，填写域名。
2. 保存后标签会从「未绑定」变为「已绑定」。
3. 打开 **系统检查**，确认「域名绑定」这一项通过。该项会用回显挑战验证域名是否真的指向本机；失败通常意味着解析未生效、端口未放行，或中间还有一层反向代理未正确转发。

:::note[没有域名]
只在内网使用可以跳过这一步，继续用 IP 访问。绑定域名不是使用其他功能的前提。
:::

## 第四步：完善站点信息

进入 **系统配置 → 站点配置 → 基本配置**，填写站点名称、副标题、描述与公司名称。这些内容会出现在前台页面标题、分享摘要与页脚。需要备案信息时，可在同一页填写 ICP 备案号、公安备案号及对应查询链接。

「系统配置」的其他标签页还提供主题外观、通知配置与安全配置；不确定的选项保持默认即可，后续随时可以回来修改。

## 第五步：配置网络（按需）

如果服务器访问境外站点不稳定，进入 **系统配置 → 网络配置**：

1. 打开 **开启代理模式**。
2. 选择代理协议（HTTP / SOCKS4 / SOCKS5），填写代理主机、端口与认证信息。
3. 按需维护「免代理」列表，把内网地址排除在代理之外。
4. 保存后到[网络与连通性](/docs/backend/dashboard/network)重新测试。

## 第六步：接入插件与媒体目录

基础设置完成后，再按实际需要接入外部服务：

| 顺序 | 做什么 | 参考 |
| --- | --- | --- |
| 1 | 配置元数据源、下载器、媒体服务器等插件 | [插件总览](/docs/integration/overview) |
| 2 | 添加媒体目录并建立扫描任务 | [扫描任务](/docs/backend/task/scan) |
| 3 | 对扫描结果执行刮削 | [刮削任务](/docs/backend/task/scrape) |
| 4 | 浏览与整理影视库 | [影视](/docs/backend/media/movie) |

## 第七步：跑一次系统检查

点击右上角头像，选择 **系统检查**，执行一次扫描。它会检查数据库、磁盘、端口、系统时间、依赖资源（FFmpeg、MetaTube 等）、代理与插件配置，并把问题按「基础信息 / 系统配置 / 软件配置 / 运行状态」分类列出。

:::tip[把系统检查当作验收清单]
首次部署后出现的黄色或红色项，基本都能在对应配置页修掉。确认全部通过后，再开始批量扫描与刮削，能省下大量排查时间。详细判定标准见[系统检查](/docs/backend/system/system-check)。
:::

## 初始化完成

到这里，AMMDS 已经可以正常登录和使用。建议再完成两件事：

1. 在 **系统管理 → 备份恢复** 中导出一份配置与数据备份。
2. 记录当前版本号（工作台「系统信息」卡片），升级后便于对比。
