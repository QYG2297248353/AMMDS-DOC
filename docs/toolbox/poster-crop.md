# 海报裁剪

海报裁剪工具把一张图片裁成适合媒体服务器展示的竖版比例，并可在服务器图片所在目录直接生成 `-poster`、`-fanart`、`-thumb` 三个文件。

{/* truncate */}

## 打开方式

进入 **工具箱 → 媒体处理 → 封面裁剪**。页面顶部有两个来源页签：「拖入图片」与「从页面选择」。

本工具不需要插件，只要能访问服务器上的图片文件即可。

## 两种图片来源

| 来源 | 选择方式 | 能力 |
| --- | --- | --- |
| 拖入图片 | 点击选择或把图片拖到虚线区域 | 仅在本页裁剪与下载，不写服务器 |
| 从页面选择 | 通过服务器文件树选择图片文件 | 可下载，也可在原图所在目录生成三件套 |

本地来源支持 jpg / png / gif / webp / bmp；服务器文件树只把图片文件标记为可选，其它文件置灰。

## 裁剪操作

选择图片后，页面并排展示「原图」与「裁剪结果」。点击「开始裁剪」打开裁剪弹窗：

- 裁剪框是**全高**的竖向区域，只能拖动左右两条边调整宽度。
- 最小宽度为 40 显示像素，避免拖到 0 后无法恢复。
- 弹窗底部显示原图尺寸与当前裁剪宽度（按原图像素换算）。
- 默认裁剪框按原图宽高比推算：
  - 高宽比 ≥ 1.4：视为竖长图，不裁剪，使用全宽。
  - 高宽比在 1.0 ~ 1.4：宽度取 `高 / 1.5`，左右居中，得到约 2:3 的竖版。
  - 高宽比 < 1.0：从 `宽 / 1.9` 处开始裁到右边，保留右侧区域。

确认后回到主页面，右侧显示裁剪结果；不满意可点「重新裁剪」。

## 下载与生成

| 操作 | 来源 | 行为 |
| --- | --- | --- |
| 下载裁剪图 | 本地 / 服务器 | 以「原文件名去扩展名 + `-poster.jpg`」下载裁剪结果 |
| 在图片所在目录生成 | 服务器 | 同时生成 `-poster.jpg`、`-fanart.<原扩展名>`、`-thumb.<原扩展名>` |

生成规则：

- `-poster` 是裁剪后的图片。
- `-fanart` 与 `-thumb` 是原图的副本，扩展名沿用原图。
- 基础文件名会剥离已存在的 `-poster`、`-fanart`、`-thumb` 后缀，重复生成不会叠加后缀。

生成完成后页面展示三个文件的预览与可复制路径，方便直接填入整理目录或媒体服务器。

:::tip[适用场景]
媒体服务器把横版图当封面时会拉伸或留黑边。先用本工具把横图裁成竖版，再生成三件套，比手工改图更省事。批量整理后的图片缺失，也可以用刮削的「查漏补缺」补齐。
:::

## 注意事项

- 裁剪框高度始终等于图片高度，不能上下裁切；需要裁掉上下内容时先在其他工具中处理。
- 本地来源的图片不会上传到服务器，刷新页面后需要重新选择。
- 生成操作只写入图片所在目录，不会自动更新媒体库记录；媒体服务器需要刷新元数据才能看到新图。
- 生成前确认目录中没有需要保留的同名图片，避免覆盖已有素材。
- `-poster` 固定输出 jpg，其它两张沿用原图扩展名。

封面裁剪的产物可以直接用于 [媒体服务器工具](/docs/toolbox/media-server-tools) 的库封面或影视封面；其它媒体处理工具见 [媒体编辑](/docs/toolbox/media-edit)。
