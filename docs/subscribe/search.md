# 站点资源检索

「站点搜索」把已启用的站点索引插件聚合成一个检索框：输入番号、标题或演员，系统并发请求各站点，把返回的种子按发布时间汇总成一张结果列表。

{/* truncate */}

## 打开方式

在 **订阅与下载 → 站点搜索** 打开页面。首次进入时页面中央只有搜索框与历史搜索；出现结果后，头部会自动切换为紧凑布局。

:::tip[前置条件]
站点搜索依赖「站点索引」类插件。至少启用一个站点（如 [M-Team](/docs/integration/indexer/m-team)）并完成账号或 API Key 配置，否则检索结果为空。
:::

## 发起检索

1. 在搜索框输入关键词，例如番号 `SSIS-001`、作品标题或演员名。
2. 按回车或点击搜索按钮，页面进入加载状态。
3. 后端并发请求各站点，等待时间上限由请求参数控制（页面默认 60 秒）；超时未返回的站点按空结果处理，已返回的结果照常展示。
4. 结果按发布时间倒序汇总，页面不做二次分页。

检索历史保存在浏览器本地，最多保留 20 条。没有结果时历史词会显示在搜索框下方，点击任意词条即可直接复用该关键词重新检索。

## 数据源

| 来源 | 平台标识 | 说明 |
| --- | --- | --- |
| M-Team | `M-Team` | 通过 M-Team API 检索，支持由后端按种子 ID 换取下载直链 |
| FSM | `FSM` | 通过 FSM 接口检索，支持由后端换取下载直链 |
| NexusPHP 站点 | `NexusPHP (站点名)` | 在「站点索引 → NexusPHP」中配置的每个站点都会单独参与检索，结果直接带回下载地址 |
| Rousi / PtYes | `PtYes (Rousi)` | 列表返回基础字段，详情接口补齐哈希与下载地址 |
| Prowlarr | `Prowlarr (索引器名)` | 作为聚合兜底来源，结果自带下载地址，平台名会带上索引器名称 |

各站点独立请求、互不阻塞。某个站点超时或报错只会让该站点结果为空，不会中断整次检索。

## 筛选与排序

结果列表上方是筛选工具栏，所有候选项都从当前结果中动态去重生成：

| 控件 | 可选值 | 作用 |
| --- | --- | --- |
| 排序字段 | 发布时间、文件大小、做种数、下载数 | 在前端对已返回结果重新排序 |
| 排序方向 | 降序、升序 | 与排序字段组合使用 |
| 媒介 | 结果中出现过的媒介值 | 如 BluRay、WEB-DL |
| 视频编码 | 结果中出现过的视频编码 | 如 H.264、HEVC |
| 音频编码 | 结果中出现过的音频编码 | 如 AAC、DTS |
| 分辨率 | 结果中出现过的标准 | 如 1080p、2160p |
| 促销 | 结果中出现过的促销标记 | 免费下载、50% 下载、2 倍上传等 |

点击「重置」会清空全部筛选条件，并把排序恢复为「发布时间 / 降序」。左侧的「共找到 N 个结果」统计的是筛选后的条数，不是后端返回总数。

## 结果字段

| 字段 | 展示方式 |
| --- | --- |
| 封面 | 经后端图片代理加载；无封面时回退为平台 Logo，点击可预览大图 |
| 平台 | 封面左下角的标签，对应来源站点或索引器 |
| 标题 / 副标题 | 标题为主信息，副标题通常是演员、标签或站点描述 |
| 大小 / 发布时间 | 蓝色与绿色标签 |
| 做种数 / 下载数 | 大于 0 时才显示，分别带用户与下载图标 |
| 促销 | 按 Free、50%、70%、2x 等关键词转换为中文描述 |
| 媒介 / 视频编码 / 音频编码 / 分辨率 | 站点提供时才显示 |

## 结果操作

每条结果右侧有两个图标按钮：

- **下载种子**：结果已有直链时直接在新窗口打开；没有直链时先调用后端按 `searchId + platform` 换取地址，再以 `[AMMDS]标题.torrent` 为文件名触发浏览器下载。
- **推送下载**：先确保拿到种子地址，再提交给 qBittorrent，固定使用分类 `AMMDS`。

:::note[推送目标]
站点搜索的推送按钮只面向 qBittorrent。推送后可在 [下载器使用](/docs/subscribe/downloader) 或 **工具箱 → 下载器 → 任务管理** 查看进度。
:::

## 使用建议

| 现象 | 处理 |
| --- | --- |
| 只返回部分站点结果 | 单站点超时属于正常降级，可缩短关键词或稍后重试 |
| 完全没有结果 | 检查站点插件是否启用、账号是否失效，以及关键词是否过于宽泛 |
| 有结果但无法下载 | 部分来源需要登录态或站点直链接口，优先尝试「推送下载」 |
| 结果很多难以挑选 | 先用促销、分辨率、做种数筛选，再按做种数降序 |

需要按番号长期跟踪资源时，改用 [订阅管理](/docs/subscribe/manage)；想搜索非 PT 资源时，使用 [磁力检索](/docs/subscribe/magnet)。
