# 下载器使用

本页说明资源从「检索结果」或「订阅」进入下载器后的完整路径：推送到哪个客户端、写入什么分类与标签、在哪个页面查看任务，以及下载完成后与辅种的关系。

{/* truncate */}

## 相关入口

| 入口 | 位置 | 作用 |
| --- | --- | --- |
| 站点搜索推送 | [站点资源检索](/docs/subscribe/search) 结果右侧的 qBittorrent 图标 | 把种子文件地址推送到 qBittorrent，分类固定为 `AMMDS` |
| 磁力搜索推送 | [磁力检索](/docs/subscribe/magnet) 结果右侧的 qBittorrent 图标 | 把磁力链接推送到 qBittorrent，分类固定为 `AMMDS` |
| 订阅自动下载 | [订阅管理](/docs/subscribe/manage) | 命中资源后自动提交，写入标签 `AMMDS订阅` 与 `subscribe-<订阅ID>` |
| 任务查看与管理 | **工具箱 → 下载器** | 查看插件信息与下载器任务列表，手动新建、开始、暂停、删除任务 |

:::note[推送目标]
当前推送链路只面向 qBittorrent。Transmission 在辅种计划中作为可选客户端出现，但站点与磁力检索的推送按钮不会提交到 Transmission。
:::

## 推送时写入的参数

| 来源 | 分类 | 标签 | 保存路径 |
| --- | --- | --- | --- |
| 站点搜索 | `AMMDS` | 无 | qBittorrent 默认路径 |
| 磁力搜索 | `AMMDS` | 无 | qBittorrent 默认路径 |
| 订阅下载 | 无 | `AMMDS订阅`、`subscribe-<订阅ID>` | 订阅规则中的「下载目录」，留空则用默认路径 |

订阅提交后会用 `subscribe-<订阅ID>` 标签回查下载器中的任务，查到哈希后立即删除该临时标签，避免后续同步重复命中。分类与标签可以帮助你在下载器里快速筛出 AMMDS 提交的任务。

## 查看下载器信息

在 **工具箱 → 下载器 → 插件信息** 查看 qBittorrent 的连接信息：

| 字段 | 说明 |
| --- | --- |
| 用户名 / 密码 | 插件配置中的登录凭据，密码按后端返回值展示 |
| URL | qBittorrent Web API 地址 |
| 默认保存路径 | 未指定保存路径时任务的落盘目录 |
| API 版本 / App 版本 | 用于确认客户端版本兼容性 |
| 种子数量 | 当前下载器中的任务总数 |

插件未启用时页面只显示「插件未启用」空状态，不发起请求。

## 查看任务

在 **工具箱 → 下载器 → 任务管理** 查看任务列表。列表每 5 秒静默刷新一次，下载进度会持续更新；页面不可见时轮询自动暂停。

| 列 | 说明 |
| --- | --- |
| 文件名称 | 种子名称，下方副行显示保存路径 |
| 状态 | qBittorrent 状态码转换后的中文说明 |
| 速度 | 下载速度与上传速度，分别带下降/上升图标 |
| 大小 | 任务总大小 |
| 分类 | 提交时写入的分类，如 `AMMDS` |
| 标签 | 提交时写入的标签，可多个 |
| 进度 | 0~1 的比例转换为进度条 |

常见状态包括：分配硬盘空间、获取元数据、下载中、上传中、排队等待、已暂停、已停止、校验中、移动文件、缺少文件、错误状态。完整映射以页面展示为准。

## 手动新建任务

点击「新建任务」，在弹窗顶部切换两种模式：

| 模式 | 输入 |
| --- | --- |
| 磁力下载 | 在「下载链接」中粘贴磁力链接，多个链接用换行分隔 |
| 种子文件 | 上传一个或多个 `.torrent` 文件 |

两种模式都可以填写分类、标签与保存路径。标签输入后需要按回车确认，提交时会拼接为逗号分隔字符串；保存路径留空时使用 qBittorrent 默认路径。

## 批量操作

先在列表中勾选任务，再使用顶部按钮：

| 按钮 | 行为 |
| --- | --- |
| 开始下载 | 对勾选任务调用开始接口，成功后清空选择 |
| 暂停下载 | 对勾选任务调用暂停接口，成功后清空选择 |
| 删除任务 | 弹出二次确认，可选择「删除原文件」或仅「删除任务」 |

:::warning[删除不可恢复]
选择「删除原文件」会同时删除已下载的数据，删除后无法通过下载器恢复。正在做种或准备辅种的任务，请先确认辅种流程已经接管，再决定是否删除文件。
:::

## 与辅种的关系

下载器任务与辅种任务是两套记录：

- 下载器任务由 qBittorrent 管理，反映下载/做种进度。
- 辅种由 [PT 辅种](/docs/toolbox/subspecies) 通过 IYUU 完成，使用独立的辅种计划、站点配置、辅种记录与辅种任务。
- 辅种计划可以选择 qBittorrent 或 Transmission 作为辅种客户端；它与站点检索的推送目标不是同一个配置。
- 下载完成后，文件继续由下载器做种；辅种流程会在其他站点创建新的种子任务，指向同一份文件。删除文件前应先停止相关做种/辅种任务。

## 排查建议

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 推送后提示失败 | qBittorrent 未启用、地址或凭据错误 | 在 [qBittorrent](/docs/integration/downloader/qbittorrent) 配置页测试连接 |
| 推送成功但列表没有任务 | 分类/标签过滤或分页位置不对 | 切到第一页并清空筛选，或直接在 qBittorrent 中确认 |
| 任务停在「获取元数据」 | 磁力没有可用做种或 DHT 未连通 | 换用种子文件，或检查下载器网络 |
| 任务显示「缺少文件」 | 保存路径被移动或文件被删除 | 恢复文件后重新校验，或删除任务重新下载 |
| 订阅一直不完成 | 下载器任务被移除或哈希未回查 | 在订阅管理中重新提交，并确认下载器连接正常 |

更完整的下载器接入说明见 [qBittorrent](/docs/integration/downloader/qbittorrent)；订阅侧的匹配与重试见 [订阅管理](/docs/subscribe/manage)。
