# 演员列表与详情

演员库把演员档案与参演作品关联起来：列表页用来快速浏览与检索，详情页集中展示个人资料、扩展标签、海报、参演作品与相关资讯。

{/* truncate */}

## 列表页结构

页面地址 `/home/actor`：

| 区域 | 内容 |
| --- | --- |
| 左侧内容区 | 演员卡片网格、分页 |
| 右侧侧栏 | 搜索、中文优先、模式、搜索历史、热门标签、演员库简介 |

宽屏每行 6 张卡片，窄屏依次降为 4、3、2、1 列；宽度不超过 1024px 时侧栏隐藏。

## 检索与筛选

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 按演员姓名检索，占位文案“请输入演员名称” |
| 中文优先 | 只影响姓名展示；开启后优先中文名，缺失时回退原名 |
| 模式 | `全局库` / `收藏库`，切换后立即重新检索 |
| 搜索历史 | 最多 15 条，存在浏览器本地 |
| 标签 | 点击按标签筛选，再次点击取消；选中标签会清空关键词 |

页面没有性别、年龄、身高、国籍、退役状态等筛选控件，也没有排序控件。服务端默认按创建时间倒序。

## 卡片字段

- **海报**：2:3 竖版，无图或加载失败显示“图像加载失败”。
- **悬浮标签**：出道日期（只取日期部分）、身高（cm）、体重（kg）。
- **姓名**：受“中文优先”控制。
- **基础标签**：性别、年龄（岁）、国籍、退役、已故、罩杯、其他尺寸字段；有值才显示。

性别在列表里只区分 `female` 与其他值：`female` 显示“女”，其余显示“男”。

## 分页与状态记忆

每页 20 条，分页条只显示总数，没有每页条数选择器。搜索条件与页码写入 `localStorage`，刷新后恢复上次状态；本页没有像影视那样把页码写入地址栏 query。

## 详情页

详情地址为 `/home/actor/details/:id`，要求登录。页面从路由参数读取演员 ID，先拉详情，再加载作品与资讯。

### 资料区

顶部大标题为演员姓名，存在别名时在标题下方以“别名：A / B”展示。主卡片左侧是 2:3 头像，右侧依次展示：

| 信息 | 展示方式 |
| --- | --- |
| 姓名 | 大号标题 |
| 性别 | `male` 男、`female` 女、`shemale` 人妖、其余“未知性别” |
| 年龄 | “N 岁” |
| 退役 / 已故 | 橙色 / 红色标签 |
| 身高 / 体重 | “N cm”“N kg” |
| 血型 | 血型 + “血型” |
| 出生日期 | 日期标签 |
| 国籍 | 国籍标签 |
| 别名 | 标签列表 |
| 三围 | “胸-腰-臀”，可追加罩杯与其他尺寸 |
| 出道日期 | 日期文本 |
| 所属公司 | 标签列表 |
| 评分 | 5 星 + 10 分制分数 |
| 社交链接 | 按域名识别 Twitter、X、Instagram、Facebook、YouTube、TikTok / 抖音、Telegram、VK、TMDB，其余用通用链接图标 |

主卡片提供**订阅**、**收藏**、**分享**三枚按钮，交互与影视详情一致；分享未登录时会先弹出登录确认。

### 扩展信息

“扩展信息”卡片包含五个标签页：

1. **简介**：演员简介正文。
2. **风格**：风格标签。
3. **特征**：特征标签。
4. **标签**：普通标签。
5. **扩展信息**：按后台维护的键值对逐行展示，无内容时显示“暂无扩展信息”。

### 海报

“海报”卡片展示演员图集，2:3 比例，多图可预览；无图时显示“暂无海报”。

## 周边：作品与资讯

详情页的“周边”卡片分成两个标签页：

### 作品

- 表格列为海报、标题、发布日期、番号。
- 只取最近 20 部参演影视，服务端按发行时间从新到旧返回。
- 点击标题进入对应影视详情。
- 表格在前端按每页 10 条分页。

### 资讯

- 以演员姓名作为关键词检索资讯，最多取 10 条。
- 展示标题与日期，点击进入资讯详情。
- 无结果时显示“暂无相关资讯”。

:::tip[数量上限]
作品一次只取最近 20 部，资讯一次只取 10 条；两个列表都没有“加载更多”，需要更多内容时请到影视列表或资讯页检索。
:::

## 推荐演员

“推荐演员”卡片目前没有数据来源，`relatedActors` 始终为空数组，因此页面始终显示“暂无推荐演员”。卡片样式虽然带手型光标，但没有绑定跳转，不要把它当作可用入口。

## 评论区

评论区与影视、漫画、小说详情共用同一组件，当前为前端本地占位：默认一条“AMMDS 官方 / 敬请期待”，提交后只插入当前页面，刷新即丢失。
