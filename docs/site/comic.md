# 漫画列表与阅读器

漫画库把漫画 / 相册整理成“封面列表 → 详情与章节 → 全屏阅读器”三段式体验。列表页负责发现，详情页负责选章与续读，阅读器负责实际的翻页、缩放与进度记录。

{/* truncate */}

## 列表页结构

页面地址 `/home/comic`：

| 区域 | 内容 |
| --- | --- |
| 左侧内容区 | 漫画卡片网格、分页 |
| 右侧侧栏 | 搜索、中文优先、模式、搜索历史、热门标签、漫画库简介 |

卡片按响应式栅格排列，宽屏每行 6 张，窄屏依次减少；宽度不超过 1024px 时侧栏隐藏。

## 检索与筛选

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 占位“输入漫画名称、作者”；服务端同时匹配标题、描述、备注、作者、绘者、出版信息与系列 |
| 中文优先 | 只影响标题展示，开启后优先中文标题，缺失时回退原标题 |
| 模式 | `全局库` / `收藏库`，切换后立即重新检索 |
| 搜索历史 | 最多 15 条，存在浏览器本地 |
| 标签 | 热门标签（最多 20 个），点击筛选，再次点击取消；选中标签会清空关键词 |

页面没有单独的排序控件。服务端列表默认按创建时间倒序；虽然服务层还支持标题升序、标题降序、最早优先三种排序标识，但前台没有传入排序参数。

## 卡片字段

- **封面**：2:3 竖版，懒加载；无图或加载失败显示“图像加载失败”。
- **悬浮标签**：分类；非全集且季号大于 0 时显示“第 N 季”，全集显示“全集”。
- **标题**：受“中文优先”控制。
- **作者**：显示“作者：”加作者名，有值才显示。
- **系列**：显示“系列：”加系列名，有值才显示。
- **标签**：最多展示前 3 个。

## 详情页

详情地址为 `/home/comic/details/:id`，要求登录。页面自上而下分为标题、基本信息、章节列表与评论区。

### 基本信息

左侧是 2:3 封面；右侧首先展示标题与一排标签：

| 标签 | 条件 |
| --- | --- |
| 分类 | 有分类时显示 |
| 全集 / 第 N 季 | 全集显示“全集”，否则季号存在时显示“第 N 季” |
| 年龄分级 | 有值时显示 |
| 页数 | 始终显示“共 N 页”，缺失按 0 |

标签下方是按“标签 - 值”排列的资料表，包含作者、系列、出版社、印刷商、出版日期、语言、格式、色彩（黑白 / 彩色）、阅读方向、年龄分级、社区评分、备注、链接。空值不占行。

再往下是标签、角色、团队、地点四组标签，以及漫画描述。资料区下方是评分：5 星 + 社区评分（10 分制）。

右侧竖排四枚按钮：

1. **继续阅读**：仅当服务端存在该用户的阅读进度，且进度所属章节仍在章节列表中时显示。
2. **阅读 / 从头阅读**：没有进度时显示“阅读”，有进度时显示“从头阅读”，总是打开第一章。
3. **收藏 / 已收藏**：未登录时弹登录确认；已登录时按当前状态切换。
4. **分享**：未登录时弹登录确认；已登录时打开分享弹窗。

### 章节列表

- 卡片标题旁的数量标签显示章节总数。
- 章节按顺序分页展示，每页 20 章。
- 每一章显示章节标题、“第 N 话 · X 页”与可选章节描述。
- 当前续读章节会额外显示“读至第 N 页”标签。
- 点击“阅读”进入该章第一页。
- 有续读进度时，卡片右上角出现“继续阅读 第 N 页”快捷按钮。
- 章节为空时显示“暂无章节”。

## 阅读器入口与地址参数

阅读器是独立路由 `/home/comic/reader`，要求登录，参数通过 query 传递：

| 参数 | 含义 |
| --- | --- |
| `comic` | 漫画 ID |
| `chapter` | 章节 ID，缺省时按阅读进度或第一章决定 |
| `page` | 起始页码，仅大于 1 时才会写入地址 |

打开顺序为：地址栏参数 → 服务端 / 本地阅读进度 → 第一章。若从进度恢复且页码大于 1，会提示“已恢复到上次阅读位置 第 N 页”。

## 阅读器界面

阅读器是全屏覆盖层，分为顶栏、阅读区、底栏与常显的底部进度线。

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 返回、漫画标题、章节下拉、上一章 / 下一章、翻页方向、全屏 |
| 底栏 | 上一页 / 下一页、页码输入 / 当前章总页数 / 全书百分比、缩小 / 缩放百分比 / 放大、页面导航、设置 |

开启“触屏自动隐藏工具栏”时，移动端会隐藏工具栏，轻触屏幕可重新显示；窄屏按钮只保留图标。

## 翻页与滚动

- 翻页模式支持单页 / 双页；双页需要容器宽度至少 720px，否则回退单页。
- 点击左三分区上一页、右三分区下一页、中间切换工具栏；从右到左时左右互换。
- 到本章末页继续翻会进入下一章，到本章首页继续向前会进入上一章；没有相邻章节时提示“已经是最后一页 / 第一页了”。
- 滚动模式把全部图片纵向排列，以视口顶部 35% 为参考线同步页码；翻页按钮按 90% 视口高度滚动，方向键上下按 120px 微调。

## 缩放与快捷键

- 缩放范围 0.5–5 倍，按钮每次 ±0.25，点击百分比文本复位；双击在 1 倍与 2 倍间切换，触摸双指可捏合。
- 翻页模式下放大后可用鼠标拖拽或单指拖动平移；开启“滚轮缩放”后滚轮以指针为锚点缩放，关闭时用于翻页。
- 键盘：左右方向键翻页（右到左模式互换），空格下一页（Shift 上一页），PageUp / PageDown 翻页，Home / End 首末页，`+` / `-` 缩放，`0` 复位，`F` 全屏，`Esc` 退出全屏或切换工具栏。

## 阅读设置

“设置”抽屉提供：阅读模式（翻页 / 滚动）、图片适应（宽度 / 高度 / 原始尺寸）、图片间距 0–40px、翻页方向、单双页、背景主题（纯黑 / 深灰 / 米黄 / 护眼 / 纯白）、预加载 0–10 页，以及滚轮缩放、点击左右分区翻页、触屏自动隐藏工具栏三个开关。设置写入浏览器 `localStorage`，有 300ms 防抖；“恢复默认设置”还原全部选项。

:::tip[设置与进度不是一回事]
阅读设置只保存在当前浏览器，换设备不会跟随；阅读进度按登录账号保存，换设备登录后仍可续读。
:::

## 阅读进度保存

- 进度按“漫画 + 章节 + 页码”记录；滚动模式下页码使用当前图片序号。
- 页码或章节变化后防抖 800ms 保存；切章、返回、页面隐藏、组件卸载时立即落盘。
- 保存时先写本地缓存，再请求服务端；接口异常时至少保留本地缓存，下次可继续读取。
- 服务端进度按登录用户隔离；详情页“继续阅读”只读服务端进度，未登录或没有服务端记录时不显示。
- 首次位置恢复完成前不写进度，避免覆盖服务端记录。
