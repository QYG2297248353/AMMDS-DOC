# 访客看到的页面

把你的媒体库开放给别人看，用的就是「前台站点」。这一页讲它由哪些页面组成、访客和登录用户各能看到什么，以及资讯这一类内容怎么翻、怎么搜。

> **前台站点**：给访客和浏览者看的界面。看片、翻资料在这里。

> **后台管理**：给管理员用的界面。扫描文件、补资料、改设置在那里做。

> **访客**：没有登录、只是来逛一逛的人。

## 前台和后台的分工

两边共用同一套账号和数据，但入口和职责不同。

| 对比 | 前台站点 | 后台管理 |
| --- | --- | --- |
| 面向对象 | 访客与已登录的浏览者 | 管理员与内容维护者 |
| 登录要求 | 列表页可以随便看，详情页与操作需要登录 | 整个后台都要登录 |
| 主要能做什么 | 浏览、搜索、收藏、订阅、分享、阅读 | 扫描、补资料、编辑、跑任务、改设置 |
| 谁来维护资料 | 不直接改资料 | 唯一能改资料的地方 |

## 页面一览

| 菜单 | 内容 | 不登录能看吗 |
| --- | --- | --- |
| 影视 | 影片列表与详情 | 列表能看，详情要登录 |
| 剧集 | 剧集列表与详情 | 列表能看，详情要登录 |
| 演员 | 演员列表与详情 | 列表能看，详情要登录 |
| 漫画 | 漫画列表与阅读器 | 列表能看，详情要登录 |
| 小说 | 小说列表与阅读器 | 列表能看，详情要登录 |
| 资讯 | 订阅抓回来的条目 | 列表能看，详情要登录 |
| 商城 | 官方商城 | 只有后台启用后才出现在导航里 |

:::note[打开网站先去哪]
站点根地址不会直接显示内容，而是按后台「打开优先进入」的设置跳转：选前台就进影视列表，选后台时已登录进工作台、未登录进登录页。默认设置是后台。
:::

## 页面长什么样

所有页面共用同一套外壳：

1. **顶部栏**：左边是站点标识和一级菜单，右边是搜索、语言切换、明暗主题、全屏和登录入口。屏幕窄的时候一级菜单会收起来，只留右边几个按钮。
2. **内容区**：列表页是「左边卡片网格 + 右边筛选栏」两栏；详情页是单列。屏幕窄时筛选栏会移到列表上方。
3. **页脚**：后台配置的快捷链接、备案信息与版权文案。

## 顶部搜索怎么用

点顶部栏的放大镜打开搜索框：

1. 边打边搜：停下大约 300 毫秒才开始找，不会每敲一个字就搜一次。
2. 覆盖影视、剧集、演员、漫画、小说、资讯六类，每类最多 8 条，按类型分组显示。
3. 点结果直接跳到对应的详情页。
4. 没结果时提示「无匹配结果(可尝试完整名称)」。

:::tip[搜不到东西先查索引]
顶部搜索靠的是 MeiliSearch 索引（可以理解成给站内内容做的一份目录，在「集成应用」的辅助工具里配置）。索引没建好，这里就搜不出东西。
:::

## 登录与账号

未登录时，顶部栏右侧是一个「登录」按钮。登录页提供：

- 账号与密码登录，密码在浏览器里加密后再提交。
- 隐私协议勾选，不勾无法提交。
- 两步验证：密码通过后还要输 6 位验证码或恢复码。
- 「忘记密码」：用服务端保存的恢复密钥重置密码。

:::warning[现在不能自己注册]
登录页的「注册账号」按钮是禁用状态，前台没有开放注册。账号来自部署时的初始化。
:::

登录后，登录按钮变成头像下拉菜单，里面有**个人中心**、**后台管理**、**开启 / 关闭剧透**、**退出登录**四项。

## 访客和登录用户的差别

| 能力 | 访客 | 登录用户 |
| --- | --- | --- |
| 浏览各库列表 | 可以 | 可以 |
| 打开详情页 | 被拦住，跳到登录页，登录后回到原页面 | 可以 |
| 影视 / 演员列表条数 | 每页最多 30 条，翻到哪一页由后台随机决定 | 正常分页 |
| 收藏 / 订阅 / 分享 | 要先登录 | 可以 |
| 漫画与小说续读 | 阅读入口要求登录 | 按账号保存，可以续读 |

:::note[访客看到的内容会变]
影视、演员、资讯的访客列表是后台有意限制的：不管你点到第几页，都随机给一页，最多 30 条。所以刷新一下看到的内容可能不一样，这是为了防批量抓取，不是数据出错。
:::

## 外观与主题

- **统一样式**：主题色、背景、圆角、动效、哀悼模式等由后台系统配置下发，所有访客看到的效果一致。
- **本地偏好**：明暗主题、界面语言、浏览器全屏由访客自己在顶部栏切换，只存在自己的浏览器里。
- **剧透模式**：登录后可在头像菜单开关；开启后列表与详情里的内容按站点配置处理。

## 资讯：订阅抓回来的内容

顶部菜单「资讯」打开的是订阅条目的列表。这里的条目来自后台配置的订阅源，前台只负责展示。

### 列表卡片

卡片按横向封面平铺，桌面一行 4 张、平板 3 张、手机 1 张。

| 卡片元素 | 说明 |
| --- | --- |
| 封面 | 缺失或加载失败时显示「图像加载失败」 |
| 分类角标 | 左上角标签：文章蓝、图像绿、视频橙、资源紫，其它为灰 |
| 标题 | 单行，超长省略；为空显示 `--` |
| 摘要 | 最多两行；为空显示 `--` |
| 来源 | 左下角显示订阅源名称；为空显示 `--` |
| 发布时间 | 右下角 |
| 快捷操作 | 「前往源站」在新标签打开原链接；条目带种子 / 磁力 / 种子文件时另显示「查看原文」或「下载资源」 |

列表为空时显示「暂无资讯」。点卡片会在**新标签页**打开详情，不会打断你在列表里的浏览。

> **RSS**：网站把最新内容按固定格式列出来的一份清单，别的程序定时来读。这里的资讯就是这么抓回来的。

### 分类与搜索

侧栏（窄屏移到列表顶部）有搜索、分类与搜索历史。

- **分类**固定五项：全部、文章、图像、视频、资源。按钮上方悬浮显示「分类名 · 共 N 条」。只显示实际有内容的分类。
- 点任一分类都会回到第一页重新查；「全部」不带分类条件。
- **搜索**匹配标题与摘要，点搜索按钮或回车才开始搜，打字过程中不搜。
- **搜索历史**最多 15 条，按关键词去重后置顶；点标签再次检索，**再点同一个标签等于取消搜索**。
- 分类、关键词与页码会存在浏览器里，刷新后恢复上次状态。

列表页**没有**按订阅源筛选的控件，想缩小范围就用「分类 + 关键词」组合。

### 分页

每页默认 20 条，可切换每页条数；换条数会回到第一页。分页器只在总数大于 0 时显示。访客看到的总条数与页码不代表真实总量（见上文「访客和登录用户的差别」）。

### 详情页

| 区域 | 内容 |
| --- | --- |
| 顶部 | 「返回列表」按钮 |
| 标题区 | 标题，下方是分类标签、来源标签与发布时间标签（为空则不显示） |
| 视频区块 | 条目带视频附件时出现，用内嵌播放器播放，下方提供「前往源站」 |
| 图库 | 条目带图片附件时出现，缩略图可点击放大 |
| 正文 | 按富文本渲染 |
| 资源 | 除图片与视频外的附件逐条列出，显示地址、类型与大小，右侧「下载资源」在新标签打开 |
| 侧栏信息 | 来源、发布时间、分类、作者 |
| 侧栏操作 | 「查看原文」在新标签打开原链接；「返回列表」 |

资讯不存在或已删除时整页显示「资讯不存在或已删除」。各区块只在有对应内容时才出现，所以不同分类看到的区块数量不同。

:::tip[站内播放还是跳原站]
视频区块播放的是条目附件里记录的地址：后台做过离线缓存时指向本地缓存，没缓存时指向源站。播放器用不了或想看原始页面，就用「前往源站」。
:::

所有外链都在新标签页打开，也不会把你在当前页面的信息带给对方站点。

## 运行模式对前台的影响

| 模式 | 访客看到什么 |
| --- | --- |
| 正常模式 | 能浏览列表与搜索；登录后能看详情并使用操作 |
| 仅后台模式 | 前台地址会被改写到「站点已关闭」提示页 |
| 纯接口模式 | 所有页面（含后台）都跳到「站点已关闭」提示页 |

:::note[后台短暂出错不会让整站打不开]
如果程序一时判断不出运行模式，也不会拦住页面，前台照样能打开。
:::

## 出问题了怎么办

- **详情页点了没反应，被踢到登录页**：详情页需要登录，登录成功后会自动回到原来那个页面。
- **搜索框什么都搜不到**：先看 MeiliSearch 是否已配置并建立索引（在「集成应用」的辅助工具里）。
- **列表一直空**：后台还没有扫描入库，或列表筛选条件太窄。
- **访客看到的内容每次都不一样**：这是有意设计，登录后就恢复正常分页。
- **资讯卡片封面裂了 / 视频播不了**：条目附件指向源站，而你这台机器访问不到源站；改用「前往源站」或让后台做离线缓存。
- **资讯一直显示暂无**：后台还没有添加订阅源或还没抓到条目。
