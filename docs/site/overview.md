# 前台站点导览

前台站点是 AMMDS 的“观看者界面”：它把后台整理好的影视、剧集、演员、漫画、小说与资讯以卡片和详情页的形式呈现出来，并承载收藏、订阅、分享与阅读进度等轻量操作。

## 前台与后台的关系

前台与后台共用一套账号体系与后端数据，但入口、职责和登录要求不同。

| 对比项 | 前台站点 | 后台管理 |
| --- | --- | --- |
| 访问地址 | `/home/**` | `/admin/**` |
| 面向对象 | 访客与已登录的浏览者 | 管理员与内容维护者 |
| 登录要求 | 内容库列表页可匿名浏览，内容详情页与操作需登录 | 整个后台需要登录 |
| 数据来源 | 通过 `/api/pub/**` 读取内容；收藏、订阅、分享等写操作走登录后的接口 | 调用 `/api/admin/**` 管理接口 |
| 主要内容 | 浏览、搜索、收藏、订阅、分享、阅读 | 扫描、刮削、编辑、任务、系统配置 |
| 数据维护 | 不直接修改媒体元数据 | 元数据的唯一维护入口 |

前台不提供独立的“首页组件”。`/home` 只是前台布局壳，默认首屏是影视列表，对应路由名 `PubMedia`、地址 `/home/media`，也是系统配置“打开优先进入 = 前台影视”时的落地页。

## 访问入口

| 地址 | 页面 | 是否需要登录 |
| --- | --- | --- |
| `/` | 站点根路径，按“打开优先进入”配置跳转 | 否 |
| `/home/media` | 影视列表（前台默认首屏） | 否 |
| `/home/tvshow` | 剧集列表 | 否 |
| `/home/actor` | 演员列表 | 否 |
| `/home/comic` | 漫画列表 | 否 |
| `/home/novel` | 小说列表 | 否 |
| `/home/information` | 资讯列表 | 否 |
| `/home/store` | 官方商城（仅商城启用时出现在导航） | 否 |
| `/share/:code` | 分享链接落地页 | 否 |
| `/user/:userId`、`/u/:userId` | 用户公共主页（两种地址渲染同一页面） | 否 |
| `/login` | 登录页 | 否 |

:::note[根路径去哪个页面]
站点根路径 `/` 不直接渲染内容，而是根据后台“打开优先进入”配置决定：选择前台时跳到 `/home/media`；选择后台时，已登录进入工作台，未登录进入 `/login`。默认配置为后台。
:::

## 首页结构

前台页面由三部分组成，所有列表页与详情页共用同一套外壳：

1. **固定顶栏**：左侧为 AMMDS 标识与一级导航；右侧为全局搜索、语言切换、明暗主题、全屏与登录入口。顶栏固定在页面顶部，内容区自动让出高度。
2. **内容区**：列表页采用“左侧卡片网格 + 右侧功能侧栏”的两栏布局；详情页为单列，最大宽度约 1400px。窄屏下侧栏隐藏、卡片列数递减。
3. **页脚**：展示后台配置的快捷链接、ICP 备案、公安备案、营业执照备案，以及固定的版权文案。

页面切换后自动回到顶部；顶栏在窄屏（宽度不超过 768px）会隐藏一级导航，只保留右侧操作。

## 顶部导航与搜索

一级导航由 `/home` 下带名称且未隐藏的路由自动生成，按 `order` 升序排列：

| 顺序 | 菜单 | 路由 |
| --- | --- | --- |
| 0 | 影视 | `/home/media` |
| 1 | 剧集 | `/home/tvshow` |
| 2 | 演员 | `/home/actor` |
| 3 | 漫画 | `/home/comic` |
| 4 | 小说 | `/home/novel` |
| 5 | 资讯 | `/home/information` |
| 6 | 商城 | `/home/store`，仅在商城启用时显示 |

顶栏右侧的放大镜按钮打开“全局搜索 (MeiliSearch)”弹窗：

1. 输入关键词后自动搜索，输入停止约 300ms 才发起请求。
2. 搜索覆盖影视、剧集、演员、漫画、小说、资讯六类，每类最多返回 8 条，按类型分组展示。
3. 点击结果直接跳转对应详情页；影视结果进影视详情，剧集进剧集详情，其余同理。
4. 无结果时提示“无匹配结果(可尝试完整名称)”；未登记跳转目标的类型会提示暂不支持。

:::tip[搜索依赖索引]
全局搜索走 MeiliSearch 索引，搜索不到内容时先确认索引是否已建立；索引与数据源的配置见[插件集成总览](/docs/integration/overview)。
:::

## 登录与账号

未登录时，顶栏右侧的账号入口是一个“登录”按钮（搜索、语言、主题、全屏按钮仍在）。登录页提供：

- 管理员账号与密码登录，密码在浏览器端用 RSA 公钥加密后提交。
- 隐私协议勾选，未勾选无法提交。
- 两步验证：账号密码通过后进入 6 位验证码 / 恢复码页面。
- Passkey 登录与统一登录，是否显示由后端能力探测结果决定。
- “忘记密码”：使用服务端 `data/secret/recovery.key` 中的恢复密钥重置密码。

:::warning[当前版本没有开放注册]
登录页的“注册账号”按钮是禁用状态，后端 `/api/oauth` 下也没有注册接口。首次使用的账号获取方式见[首次登录](/docs/getting-started/first-login)，不要期待访客能自行注册。
:::

登录后，顶栏的登录按钮变为头像下拉菜单，包含**个人中心**、**后台管理**、**开启 / 关闭剧透**、**退出登录**四项。个人中心与后台管理都位于 `/admin` 下。

## 访客与登录用户的差异

| 能力 | 访客（未登录） | 登录用户 |
| --- | --- | --- |
| 浏览各库列表 | 可以 | 可以 |
| 查看详情页 | 被登录守卫拦截，跳转 `/login` 并携带 `redirect` | 可以 |
| 影视 / 演员列表条数 | 服务端限制每页最多 30 条，并随机选取页码 | 不受该限制，按前端页码正常分页 |
| 剧集 / 漫画 / 小说列表 | 前台服务未应用上述 30 条限制 | 正常分页 |
| 收藏 / 订阅 / 分享 | 需先登录 | 可以 |
| 漫画续读进度 | 阅读器入口要求登录 | 按账号保存并可续读 |

影视、演员与资讯的访客策略由服务端统一执行：忽略请求页码、随机取一页、把返回条数裁剪到 30，并重置分页信息。因此访客在相同条件下刷新，看到的内容片段可能不同；这是防止批量抓取的刻意设计，不是数据错乱。

:::note[详情页鉴权发生在路由层]
影视、剧集、演员、漫画、小说、资讯的详情页都声明了 `requiresAuth: true`。未登录点击卡片时，守卫会带着原地址跳到登录页，登录成功后再回到该详情页。
:::

## 外观与主题

前台外观分为“站点统一样式”和“访问者本地偏好”两层：

- **统一样式**：主题色、表面质感、边角样式、背景图案或背景图、背景遮罩强度、界面动效、哀悼模式，由后台系统配置下发，所有访客看到一致效果。配置入口见[系统配置](/docs/backend/system/config)。
- **本地偏好**：顶栏可切换明暗主题（保存在浏览器 `localStorage` 的 `arco-theme`，刷新不丢失）、切换界面语言、进入浏览器全屏。
- **剧透模式**：登录后可在头像菜单开启或关闭；开启后列表与详情中的剧透内容按站点配置处理。
- **哀悼模式**：只作用于前台布局，可在导航栏下方显示悼念横幅并将页面置灰，后台不受影响。

## 运行模式对前台的影响

后端运行模式会直接改变前台的可用性：

| 模式 | 前台表现 |
| --- | --- |
| 正常模式 | 访客可浏览列表与搜索；登录后可查看详情并使用操作 |
| 仅后台模式（BACKEND） | 访问 `/home/**` 会被改写到“站点已关闭”提示页 |
| 纯 API 模式（API） | 所有前端页面（含后台）都跳到“站点已关闭”提示页 |

模式判断失败时不会阻断导航，前台仍可打开，避免后端短暂异常导致整站不可用。
