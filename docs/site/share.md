# 分享、商店与个人主页

这一页讲三件和人打交道的事：**分享**（把一个条目变成免登录的公开链接发给别人）、**商店**（在站点里开一家小店卖东西）、**个人主页**（别人眼里的你，以及你自己维护资料的地方）。

> **短码**：分享链接末尾的一段随机字符，例如 `ABC123`，是这条分享的唯一标识。

> **Passkey**：一种用设备指纹或面容/指纹代替密码的登录方式。只有管理员在后台开启对应能力后，登录页才会显示这个选项。

> **恢复密钥**：部署时生成的应急钥匙，忘记密码时用它重置。请妥善保存，丢了就只能按部署文档的初始化流程处理。

## 分享页

分享链接把影片、演员、系列、漫画、小说或剧集变成一条带短码的公开地址，对方不用登录就能打开看。分享页只负责展示：能不能把这些资料拿走，由创建者决定；真要导入，是在接收方自己的后台操作。

### 链接形态

```
https://你的域名/share/短码
```

| 项目 | 说明 |
| --- | --- |
| 地址 | 域名后面接 `/share/` 和创建时生成的短码（代码里写作 `/share/:code`） |
| 登录要求 | 不需要登录，游客可以直接打开 |
| 布局 | 简洁的公共页，不显示前台顶部菜单，也不会出现在任何菜单里 |
| 页面宽度 | 内容区最大约 1040px，桌面端居中，手机端单列 |

短码是唯一标识，链接里**不含访问密码**；分享设置了密码时，需另行把密码告知对方。

### 页面结构

| 区域 | 内容 |
| --- | --- |
| 顶部标签 | 「来自分享链接」徽标、分享类型标签（影片 / 系列 / 演员 / 漫画 / 小说 / 剧集，按类型着色）、不允许导入时的「仅查看」标签 |
| 标题 | 被分享条目的标题，超长自动换行 |
| 有效期 | 永久有效时显示「永久有效」，否则显示「有效期至 YYYY-MM-DD HH:mm」 |
| 内容区 | 按分享类型渲染的条目详情，见下一节 |
| 页脚 | 固定文案「© AMMDS 提供技术支持」 |

「仅查看」标签只有在创建者关闭了「允许他人导入」时才出现；没有该标签表示对方可以直接导入。

这条链接还能用多久，看一眼页面上那一行就知道：写「永久有效」就是不会过期，写「有效期至 YYYY-MM-DD HH:mm」就是到这个时间点失效。

### 访问密码

分享设置了访问密码时，页面先显示密码面板而不是内容：

1. 面板标题是「该分享需要访问密码」，副标题是被分享条目的标题，方便你确认打开的是哪一条。
2. 在「请输入访问密码」输入框里填密码，按回车或点「解锁」。
3. 什么都没填就点「解锁」，会直接提示「请输入访问密码」。
4. 密码不对时，输入框下方提示「访问密码错误，请重试」，可以接着试。
5. 密码对了就当场显示内容，不用手动刷新页面。

密码校验只在本次页面内有效，刷新后需要重新输入；密码不会写入地址栏，也不会存到浏览器本地。

### 分享内容类型

一条分享只属于一种类型，不同类型的页面长得不一样。下面这些区块都是「有内容才出现」。

| 类型 | 展示内容 |
| --- | --- |
| 影片 | 头图（海报、评分、标签与识别码/首映/时长/制作方/分级/语言/分辨率/文件大小/编码/字幕等元数据）、剧情简介、演员、剧照、所属系列 |
| 系列 | 头图与元数据、系列简介、作品数量、系列作品列表；无作品时提示「该系列暂无作品」 |
| 演员 | 头图（头像、别名、性别、年龄、身高、体重、生日、国籍、血型、三围、出道日期、所属公司、状态）、个人简介、图片 |
| 漫画 | 头图（作者、系列、分类、类型、季、页数、年龄分级、评分、语言、出版信息、阅读方向等）、简介、备注、创作者、角色、团队、地点、章节列表（每章标注页数） |
| 小说 | 头图（副标题、题材、状态、出版社、出版年份、语言、页数、章节数、所属系列、ISBN）、内容简介 |
| 剧集 | 头图（类型、制作公司、年份、首播、评分、时长、状态、分区）、剧情简介、演员、季集（特别篇排在最前，每季按集号/标题/首播日期三列）、类型与制作公司 |

小说分享只带章节总数，**不展示章节目录**；漫画分享带章节列表。分享页也不提供视频文件或正文的下载入口。

### 失效与异常提示

页面按状态显示整块提示面板，而不是半截内容：

| 状态 | 标题 | 说明文案 |
| --- | --- | --- |
| 加载失败或短码不存在 | 分享不存在或加载失败 | 无法获取分享内容，请检查链接是否有效，或稍后再试；面板内提供「重新加载」 |
| 创建者暂停 | 分享已暂停 | 该分享已被创建者暂停，暂时无法访问 |
| 超过有效期 | 分享已过期 | 该分享链接已超过有效期，无法访问 |
| 类型无对应展示组件 | 暂无可展示的内容 | 该分享类型暂不支持预览，请稍后再试 |

加载时会先显示灰色的占位块，不会先闪一下白页。分享被删除后短码就不存在了，再打开同样落到「分享不存在或加载失败」。

:::warning[有效期由创建者控制]
分享页不能延长有效期、不能修改密码，也不能自行解除暂停。需要这些操作时请联系分享的创建者，在其后台的分享列表里调整。
:::

### 把分享导入自己的库

分享页本身**没有**导入按钮，导入发生在接收方的后台，公开页只通过「仅查看」标签表达是否允许导入。

**允许导入时：直接导入**

1. 在接收方系统打开 **系统管理 → 备份恢复 → 分享导入**。
2. 输入分享链接或短码，分享设置了密码时同时填写访问密码。
3. 点「预览分享」，确认标题、类型与条目列表。
4. 选择导入方案：跳过已存在、覆盖更新、合并更新。
5. 点「导入分享」，页面给出成功与失败计数，失败详情最多展示前 50 条。

**不允许导入时：先申请**

1. 同样在「分享导入」里输入链接并「预览分享」。
2. 由于该分享为「仅查看」，「导入分享」按钮不可用，页面提示「该分享不允许导入」。
3. 点「申请分享」打开弹窗：目标分享为只读字段，「申请原因」必填，最多 200 字。
4. 点「提交申请」后，分享主人会在 **信息管理 → 分享 → 收件箱** 收到这条申请。
5. 分享主人在收件箱点「通过」或「拒绝」；只有「待审核」的申请才显示这两个操作。
6. 审批结果会在分享主人这一侧的站内通知（系统消息）里留痕，状态变为「已通过」或「已拒绝」。

导入完成后，接收方可以在同一页面的「链接记录」里查到这次导入的结果；申请记录也可以在这里取消尚未处理的申请。

:::note[申请与导入是两件事]
审批通过只改变申请状态并发出通知，不会自动把数据搬进接收方系统。真正的导入仍由接收方在「分享导入」里执行，导入方案也由接收方选择。
:::

## 商店

顶部菜单「商城」进入商店前台：先浏览商品列表或分类，再进商品详情选规格加入购物车，登录后结算下单，之后可在「我的订单」里查看进度、申请取消或退货退款。

### 入口与页面一览

- 商城在后台启用后，顶部菜单才会出现「商城」；未启用时菜单项隐藏，但仍可直接输入地址访问。商城未开放时，商品列表页与店铺信息页都会提示「商城尚未开放，请稍后再来」。
- 商品列表、分类页、店铺信息不登录也能看；加入购物车、结算、订单列表与订单详情需要登录，没登录会先跳到登录页。

| 页面 | 地址 | 登录要求 |
| --- | --- | --- |
| 商品列表 | `/home/store` | 匿名可看 |
| 商品分类 | `/home/store/category/{分类handle}` | 匿名可看 |
| 商品详情 | `/home/store/product/{商品handle}` | 匿名可看，加购需登录 |
| 购物车 | `/home/store/cart` | 需登录 |
| 结算 | `/home/store/checkout` | 需登录 |
| 订单结果 | `/home/store/order/{token}` | 需登录 |
| 订单列表 | `/home/store/orders` | 需登录 |
| 订单详情 | `/home/store/orders/{订单ID}` | 需登录 |
| 店铺信息 | `/home/store/info` | 匿名可看 |

### 商品列表

列表会跟着屏幕宽度换行：桌面一行 4 张、平板 3 张、手机 1 张，每页 12 个。

| 元素 | 说明 |
| --- | --- |
| 封面 | 1:1 方形图，加载失败时显示「图片加载失败」占位；不可售时封面上显示「暂不可售」 |
| 标题与金额 | 标题单行省略，副标题为空时不显示；规格金额不一致时显示区间，否则显示单一金额，具体金额与币种以页面实时返回为准 |
| 分页 | 有数据时显示分页器与总条数；列表为空时显示「暂无商品」 |

点卡片进入商品详情。分类页 `/home/store/category/{handle}` 和列表页长得一样，只是多显示分类名、分类描述和子分类标签；描述为空时用默认文案「该分类下的全部在售商品」。

#### 筛选与侧栏

桌面端右侧是商城侧栏，窄屏下搜索与分类移到列表顶部。

| 区块 | 内容 |
| --- | --- |
| 商城导航与币种 | 商品首页、我的订单、店铺信息、购物车四个按钮；下方显示当前结算币种与地区名，点击进入店铺信息页切换 |
| 搜索 | 输入框回车或点搜索按钮；关键词会同步到地址栏，这条链接复制给别人，打开就是同样的搜索结果 |
| 商品分类 | 标签云，「全部」加各级分类，点击即筛选并回到第一页 |
| 商品系列 | 有系列数据时出现，「全部系列」加各系列标签 |
| 购物车 | 未登录显示「登录后可查看购物车与下单。」与登录按钮；已登录显示前 3 行商品、数量与合计，并有「查看购物车」 |
| 店铺 | 店铺名称、描述、类型（官方自营）、币种、客服邮箱，以及固定的商城简介文案 |

### 商品详情

| 区域 | 内容 |
| --- | --- |
| 操作行与主图 | 返回商城、购物车、我的订单、店铺信息；多图时用轮播（不自动播放），无图时显示占位 |
| 销售状态 | 可售显示「有货」，不可售显示「该商品暂不可售」 |
| 规格选择 | 商品带选项时按选项分组渲染按钮；没有选项但有多个规格时直接列出规格按钮，不可售的规格置灰 |
| 数量与属性 | 数量输入范围 1–99；属性区展示商品编号、规格（全部规格标题）与库存状态（可售时显示「可售（库存以结算为准）」） |
| 操作按钮 | 「加入购物车」与「立即购买」，不可售时同时禁用 |
| 商品详情与图文 | 名称、副名称、编号、分类、币种、销售状态与规格表格（规格、SKU、金额、销售状态）；下方富文本介绍为空时显示「暂无图文介绍」，其后是固定的免责声明 |

> **SKU**：库存单位，同一个商品的不同规格各有自己的编号，结算时按它扣库存。

点「加入购物车」未登录时提示「登录后可查看购物车与下单。」并跳转登录页（登录后回到当前商品）；已登录时提示「已加入购物车」。「立即购买」加购后直接进入结算页。商品不存在或已下架时整页显示「商品不存在或已下架」并提供「返回商城」。

### 购物车

购物车绑定当前账号与结算地区，换账号或换地区会得到不同的车。

| 元素 | 说明 |
| --- | --- |
| 商品行 | 封面、标题、规格名、单价、数量（1–99，修改后立即生效）、行合计 |
| 移除 | 行内「移除」按钮，成功提示「已移除商品」；空车时显示「购物车还是空的」与「继续选购」 |
| 订单摘要 | 结算币种、小计、运费、税费、优惠（带负号）、合计，底部为进入结算页的「去结算」 |
| 优惠码 | 输入「输入优惠码」后点「使用」，成功后提示「优惠码已应用」 |
| 放弃购物车 | 二次确认「放弃当前购物车？」，确认后清空并提示「已放弃当前购物车」 |

购物车没有逐行勾选，车里所有商品一起结算。

### 结算

结算页左侧是表单，右侧是订单摘要；购物车为空时只显示空车提示与「继续选购」。

| 区块 | 字段与行为 |
| --- | --- |
| 常用地址 | 仅登录后显示。下拉列出已保存的地址（只保留与当前购物车地区兼容的地址），选中后自动回填；进入页面时默认选中默认地址 |
| 联系信息与地址 | 邮箱（必填，需包含 `@`）、电话、名、姓；详细地址、城市、国家/地区（三项必填）；邮编、省/州选填；国家选项限定在当前购物车所属地区内 |
| 配送方式 | 点「获取配送方式」先保存联系信息与地址，再读取可选配送方式与金额；没有可用方式时显示提示文案 |
| 支付方式 | 由店铺返回的支付方式单选列表；需要跳转完成的渠道额外标注「需跳转支付」；无可用渠道时提示「当前地区暂无可用支付方式」 |
| 订单摘要 | 商品行、结算币种、小计、运费、税费、优惠、合计，以及「提交订单」与「放弃购物车」 |

提交时会按顺序检查：邮箱为空或不含 `@` 提示「请填写有效邮箱」；详细地址、城市、国家任一为空提示「请填写完整的收货地址」；没选支付方式提示「请选择支付方式」；有需要配送的商品但取不到配送方式时提示「当前地区暂无可用配送方式」。

需要跳转的支付方式会离开本站进入支付页，支付完成后带 `payReturn=1` 回到结算页；扫码类支付会弹出「扫码支付」窗口，用手机扫窗口里的码付完款，回来点「我已完成支付」再确认订单。确认成功后跳到订单结果页；若返回的是订单 ID 则直接进入订单详情页。

提交时系统会自动防重复，同一笔订单多点几次「提交订单」也只会生成一笔。看到「订单正在确认中，请勿重复提交」就别再点了，稍后到订单列表看结果。

### 订单结果

`/home/store/order/{token}` 是下单后的回执页。地址里是一串随机字符，不是能被猜出来的订单号；页面打开期间还会隐藏来源地址，避免这串字符从别处漏出去。

| 区域 | 内容 |
| --- | --- |
| 结果区 | 「下单成功」、订单号，以及「继续选购」「我的订单」「订单详情」三个按钮 |
| 订单信息与明细 | 下单时间、订单状态、支付状态、履约状态、联系邮箱（脱敏）、订单金额；商品明细含封面、标题、规格、数量与行金额 |

订单不存在或 token 已失效时显示「订单不存在或链接已过期」。

### 订单列表

订单列表每页 10 条，顶部有「刷新」与「继续选购」。

| 元素 | 说明 |
| --- | --- |
| 订单头 | 订单号、下单时间、订单状态标签、支付状态标签 |
| 商品行 | 封面、标题、规格、数量、行金额，底部是订单合计；没有订单时整块显示「暂无订单」 |
| 操作 | 可支付时显示「去支付」，否则显示「查看详情」；可取消时显示「取消订单」；可退货时显示「退货退款」 |
| 取消 | 需二次确认，提交后提示「取消申请已提交，等待商家处理」，状态变为「取消申请中」 |

### 订单详情

| 区域 | 内容 |
| --- | --- |
| 提示条与状态区 | 订单携带说明时以信息条展示，存在取消申请时额外提示；随后是订单状态、支付状态、履约状态三个标签与下单时间 |
| 信息表 | 订单号、联系邮箱、下单时间、订单金额、支付状态、履约状态 |
| 物流信息 | 有履约记录时展示履约状态、承运方、发货/送达时间与物流单号；没有单号时提示「商家尚未填写物流单号」；订单内商品全部无需配送时另提示为虚拟商品 |
| 退货退款记录 | 每条记录展示状态、申请时间、商品行、原因与说明 |
| 操作区 | 订单允许取消时显示取消卡片；允许退货时显示退货退款表单，可填可退数量、退货原因、行备注与退货说明，提交后提示「退货退款申请已提交」 |

各操作区块只在订单当前状态允许时渲染，因此不同订单看到的区块不同。

### 店铺信息

店铺信息页汇总店铺的公开资料与结算规则，也是切换结算币种的入口。

| 区块 | 内容 |
| --- | --- |
| 店铺资料 | 店铺名称、描述、店铺类型（官方自营）、客服邮箱、在线下单状态（已开放 / 未开放） |
| 结算币种 | 地区单选列表，每项显示币种代码、地区名与符号；切换后立即生效，商品金额按新地区币种重新获取 |
| 结算方式 | 当前地区可用的支付方式标签，以及配送方式与结算说明文案 |
| 地区与配送范围 | 每个地区一行，显示币种与覆盖的国家/地区，当前地区带「当前」标记；无地区时提示「暂无可用地区」 |
| 售后说明 | 固定的售后文案，并提供「查看我的订单」与「继续选购」 |

:::note[金额与渠道以页面为准]
商品金额、运费、税费、优惠与支付渠道都由店铺侧返回并实时变化，本文只描述页面上的字段与操作，不展开具体金额与渠道。
:::

## 个人主页与个人中心

前台有两类与「人」相关的页面：任何人可访问的**公开主页**，以及登录后维护自己的**个人中心**。前者只展示用户在资料里勾选公开的字段，后者决定这些字段、头像、横幅与整页主题。

### 登录与账号入口

#### 顶栏

未登录时顶栏右侧只有「登录」按钮，点击进入登录页。登录后按钮换成一个头像下拉菜单：

| 菜单项 | 行为 |
| --- | --- |
| 个人中心 | 打开 `/admin/user/info` |
| 后台管理 | 打开后台工作台 |
| 开启剧透 / 关闭剧透 | 切换列表与详情中的剧透内容显示 |
| 退出登录 | 清除登录态并回到登录页 |

顶栏还有语言切换、深浅色切换、全屏按钮与快捷搜索，它们不区分登录态。

#### 登录页

| 元素 | 说明 |
| --- | --- |
| 账号 / 密码 | 占位文案为「管理员账号」「管理员密码」。后台配置了 RSA 公钥时，密码提交前会用公钥加密；没配置公钥或公钥格式不对时，则按原文提交 |
| 隐私协议与忘记密码 | 隐私协议必须勾选才能登录，未勾选时提示「请先阅读并同意隐私协议」；忘记密码打开重置弹窗，用恢复密钥重置 |
| 其他登录方式 | 只有后台开启了对应能力时，才显示「使用 Passkey 登录」与「统一登录」；统一登录会弹窗选应用，在新窗口完成第三方认证 |
| 两步验证 | 账号开启两步验证时，密码通过后再进验证码这一步，输入 6 位验证码或恢复码完成登录 |

> **RSA 公钥加密**：密码在发出前先做一层加密，让网络上截到的内容无法直接还原成密码。

:::warning[不能自助注册]
登录页底部的「注册账号」按钮当前是**禁用状态**，前台没有开放注册入口。账号来自部署时的初始化（默认管理员 `ammds`），不能在这里新注册一个。
:::

登录成功后会回到刚才想看的那个页面；如果是直接打开的登录页，就按「系统配置 → 主题外观 → 落地页」里的「打开优先进入」，决定进前台还是后台。

### 公开主页

#### 两种地址

`/user/{用户ID}` 是标准形式，`/u/{用户ID}` 是短链别名，两条地址渲染同一个页面。

两条地址都无需登录，使用公共布局（无前台顶部菜单），页面底部固定是「首页 | © AMMDS 提供技术支持」。「首页」回到站点前台首页。个人中心的「公开主页」按钮打开的就是 `/u/{用户ID}`；用户 ID 改动后旧地址立即失效。

#### 页面内容

| 元素 | 说明 |
| --- | --- |
| 头像与昵称 | 未设置头像时显示默认用户图标，未设置昵称时显示「AMMDS 用户」 |
| 用户标识 | 形如 `@用户ID` |
| 标签 | 账号状态有值时显示为绿色标签，另有固定的「AMMDS 认证用户」标签 |
| 横幅与背景 | 头图区横幅未设置时用主题渐变背景，整页底色未设置时用系统背景 |
| 基本信息 | 按用户勾选的公开字段渲染，字段为空则不出现 |
| 无内容提示 | 所有公开字段都为空时显示「该用户暂无公开信息」 |

加载中显示加载态；用户不存在或未开放主页时显示「用户不存在或不可访问」并提供「重新加载」。

:::note[能看到什么由本人决定]
邮箱、手机号、注册时间、最后登录时间与账号状态都属于可选公开字段。手机号即使公开也只展示脱敏号码；把全部字段取消勾选后，公开主页只剩头像、昵称与主题外观。
:::

| 极简线框 | 黑白瑞士排版，左侧大头像 + 信息表格 |
| 清雅海洋 | 全宽波浪头图 + 悬浮数据方块 + 横向信息流 |
| 日落暖橙 | 左窄右宽分栏，胶片颗粒与暖色渐变边框 |
| 暗夜霓虹 | 深色底霓虹描边，粘性侧栏 + 发光信息卡 |
| 纸质书卷 | 杂志开本排版，首字下沉 + 双栏正文 + 页脚版权栏 |
| 玻璃拟态 | 漂浮玻璃卡体，上下错位叠放 + 柔光光斑 |

主题保存在账号上，访客打开时按账号设置的主题渲染；主题值不合法时回退到「经典卡片」。背景图与横幅会应用到全部主题，由各主题自行决定裁切方式。

### 个人中心

从顶栏头像下拉选「个人中心」进入，页面自上而下是头部形象区、主页配置、用户信息与许可证四块。

#### 头部形象区

| 元素 | 操作 |
| --- | --- |
| 头像 | 点击头像选择图片，上传成功后立即替换 |
| 横幅 | 右上角上传按钮选择图片；已有横幅时可删除，恢复默认背景 |
| 昵称 | 展示当前昵称 |
| 角色与授权标签 | 角色显示管理员或用户；授权标签与许可证状态一致（有效 / 无效）；账号带会员标识时另显示 VIP 标签 |
| 修改密码 | 打开改密弹窗，需填写当前密码与新密码 |

#### 主页配置

这一块决定别人看到你的公开主页长什么样：

| 区域 | 说明 |
| --- | --- |
| 主页背景图 | 上传或删除；未设置时显示「未设置背景图」占位 |
| 主页横幅 Banner | 上传或删除；未设置时显示「未设置横幅」占位 |
| 公共页主题 | 12 套主题卡片，卡片带缩略图与一句话设计说明，点击即切换并保存 |

背景图与横幅是两个独立字段，与头部形象区的横幅互不影响。

#### 用户信息

信息卡展示用户 ID、昵称、邮箱、手机号、角色、状态、注册时间与最后登录时间，右上角有两个入口：

- **编辑信息**：打开编辑弹窗。
- **公开主页**：在新标签页打开 `/u/{用户ID}`；未设置用户 ID 时不可用，信息卡会提示「未设置（编辑后生成公开主页）」。

#### 编辑资料设置项说明

| 字段 | 规则 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 用户 ID | 必填，就是公开主页地址里的那一段 | 改动后旧链接失效 |
| 昵称 | 必填，最长 32 个字符 | 超长无法保存 |
| 邮箱 | 必填，需符合邮箱格式 | 格式不对无法保存 |
| 手机号 | 选填，公开主页仅展示脱敏号码 | 不填不影响使用 |
| 公开主页展示字段 | 多选：用户 ID、昵称、头像、邮箱、手机号（脱敏）、注册时间、最后登录时间、状态 | 全部取消勾选后公开主页不再展示任何资料 |

展示字段有一条默认约定：**从未配置过**时展示除手机号外的全部字段。

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 收藏与收藏库 | 各媒体详情页的收藏按钮；列表侧栏的「模式」开关 | 小说详情页显示「收藏 / 已收藏」，未登录时提示「操作失败, 请确认已登录」；切到「收藏库」后列表只返回已收藏的条目 |

## 出问题了怎么办

**分享相关**

- **链接打不开、提示「分享不存在或加载失败」**：短码抄错了，或分享已被删除；也检查是否是过期/暂停面板（面板会直接写明原因）。
- **密码一直不对**：输入框下方会提示「访问密码错误，请重试」；确认创建者给你的就是访问密码，不是别的口令。
- **刷新后又要输密码**：密码校验只在本次页面内有效，属正常设计。
- **想改有效期或解除暂停**：分享页做不到，请联系创建者在其后台的分享列表里调整。

**商店相关**

- **顶部没有「商城」菜单**：后台还没启用商城；已启用但未开放时，页面会提示「商城尚未开放，请稍后再来」。
- **加购物车跳到登录页**：加购、结算、订单都需要登录，登录后会回到原来的商品页。
- **出现「订单正在确认中，请勿重复提交」**：别反复点提交，稍后到「我的订单」确认结果；防重复机制保证不会生成两笔订单。
- **金额和之前看到的不一样**：金额、运费、税费按当前结算地区币种实时获取，去店铺信息页确认当前地区是否被切换过。

**账号与主页相关**

- **「注册账号」点不动**：前台未开放注册，账号来自部署时的初始化（默认管理员 `ammds`）。
- **旧的个人主页链接失效**：用户 ID 被改动过，用新地址（可从个人中心的「公开主页」按钮进入）。
- **忘记密码**：登录页「忘记密码」打开重置弹窗，用恢复密钥重置。
- **别人说你的主页「什么都没有」**：公开字段可能全部取消了勾选（只剩头像、昵称与主题外观），到个人中心「编辑资料」里重新勾选。
