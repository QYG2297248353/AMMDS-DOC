# 分享页

分享链接把影片、演员、系列、漫画、小说或剧集生成为一条带短码的公开地址，对方无需登录即可打开查看。分享页只做展示：内容是否可被导入由创建者决定，导入动作发生在导入方自己的系统里。

{/* truncate */}

## 链接形态

```
https://你的域名/share/{短码}
```

| 项目 | 说明 |
| --- | --- |
| 路由 | `/share/:code`，`code` 为创建时生成的分享短码 |
| 登录要求 | 不需要登录，游客可直接访问 |
| 布局 | 公共布局，不显示前台顶部菜单，也不会出现在任何菜单中 |
| 页面宽度 | 内容区最大约 1040px，桌面端居中，手机端单列 |

短码是唯一标识，链接里**不含访问密码**；分享设置了密码时，需另行把密码告知对方。

## 页面结构

| 区域 | 内容 |
| --- | --- |
| 顶部标签 | 「来自分享链接」徽标、分享类型标签（影片 / 系列 / 演员 / 漫画 / 小说 / 剧集，按类型着色）、不允许导入时的「仅查看」标签 |
| 标题 | 被分享条目的标题，超长自动换行 |
| 有效期 | 永久有效时显示「永久有效」，否则显示「有效期至 YYYY-MM-DD HH:mm」 |
| 内容区 | 按分享类型渲染的条目详情，见下一节 |
| 页脚 | 固定文案「© AMMDS 提供技术支持」 |

「仅查看」标签只有在创建者关闭了「允许他人导入」时才出现；没有该标签表示对方可以直接导入。

## 访问密码

分享设置了访问密码时，页面先显示密码面板而不是内容。

1. 面板标题为「该分享需要访问密码」，副标题是被分享条目的标题，帮助确认打开的是哪条分享。
2. 在「请输入访问密码」输入框填写密码，按回车或点「解锁」提交。
3. 密码为空时前端直接提示「请输入访问密码」，不发请求。
4. 密码错误时输入框下方提示「访问密码错误，请重试」，可以继续重试。
5. 校验通过后页面直接用返回的完整内容替换密码面板，不需要刷新。

密码校验只在本次页面内有效，刷新后需要重新输入；密码不会写入地址栏，也不会存到浏览器本地。

## 分享内容类型

同一条分享只属于一种类型，页面按类型加载对应的展示组件。以下区块都只在有数据时出现。

| 类型 | 展示内容 |
| --- | --- |
| 影片 | 头图（海报、评分、标签与识别码/首映/时长/制作方/分级/语言/分辨率/文件大小/编码/字幕等元数据）、剧情简介、演员、剧照、所属系列 |
| 系列 | 头图与元数据、系列简介、作品数量、系列作品列表；无作品时提示「该系列暂无作品」 |
| 演员 | 头图（头像、别名、性别、年龄、身高、体重、生日、国籍、血型、三围、出道日期、所属公司、状态）、个人简介、图片 |
| 漫画 | 头图（作者、系列、分类、类型、季、页数、年龄分级、评分、语言、出版信息、阅读方向等）、简介、备注、创作者、角色、团队、地点、章节列表（每章标注页数） |
| 小说 | 头图（副标题、题材、状态、出版社、出版年份、语言、页数、章节数、所属系列、ISBN）、内容简介 |
| 剧集 | 头图（类型、制作公司、年份、首播、评分、时长、状态、分区）、剧情简介、演员、季集（特别篇排在最前，每季按集号/标题/首播日期三列）、类型与制作公司 |

小说分享只带章节总数，**不展示章节目录**；漫画分享带章节列表。分享页也不提供视频文件或正文的下载入口。

## 失效与异常提示

页面按状态显示整块提示面板，而不是半截内容：

| 状态 | 标题 | 说明文案 |
| --- | --- | --- |
| 加载失败或短码不存在 | 分享不存在或加载失败 | 无法获取分享内容，请检查链接是否有效，或稍后再试；面板内提供「重新加载」 |
| 创建者暂停 | 分享已暂停 | 该分享已被创建者暂停，暂时无法访问 |
| 超过有效期 | 分享已过期 | 该分享链接已超过有效期，无法访问 |
| 类型无对应展示组件 | 暂无可展示的内容 | 该分享类型暂不支持预览，请稍后再试 |

加载中显示骨架屏，不会先闪一个空页面。分享被删除后短码不再存在，打开时同样落到「分享不存在或加载失败」。

:::warning[有效期由创建者控制]
分享页不能延长有效期、不能修改密码，也不能自行解除暂停。需要这些操作时请联系分享的创建者，在其后台的分享列表里调整。
:::

## 导入到本地库的申请流程

分享页本身**没有**导入按钮，导入发生在接收方的后台，公开页只通过「仅查看」标签表达是否允许导入。

### 允许导入时：直接导入

1. 在接收方系统打开 **系统管理 → 备份恢复 → 分享导入**。
2. 输入分享链接或短码（形如 `https://域名/share/ABC123`），分享设置了密码时同时填写访问密码。
3. 点「预览分享」，确认标题、类型与条目列表。
4. 选择导入方案：跳过已存在、覆盖更新、合并更新。
5. 点「导入分享」，页面给出成功与失败计数，失败详情最多展示前 50 条。

### 不允许导入时：先申请

1. 同样在「分享导入」里输入链接并「预览分享」。
2. 由于该分享为「仅查看」，「导入分享」按钮不可用，页面提示「该分享不允许导入」。
3. 点「申请分享」打开弹窗：目标分享为只读字段，「申请原因」必填，最多 200 字。
4. 点「提交申请」后，分享主人会在 **信息管理 → 分享 → 收件箱** 收到这条申请。
5. 分享主人在收件箱点「通过」或「拒绝」；只有「待审核」的申请才显示这两个操作。
6. 审批结果会在分享主人这一侧的站内通知（系统消息）里留痕，状态变为「已通过」或「已拒绝」。

导入完成后，接收方可以在同一页面的「链接记录」里查到这次导入的结果；申请记录也可以在这里取消尚未处理的申请。

:::note[申请与导入是两件事]
审批通过只改变申请状态并发出通知，不会自动把数据搬进接收方系统。真正的导入仍由接收方在「分享导入」里执行，导入方案也由接收方选择。
:::
