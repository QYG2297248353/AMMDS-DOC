# 小说阅读

访客在顶部菜单「小说」进入小说库：列表页挑书，详情页看书目信息与章节目录，再进阅读器逐章阅读。阅读器提供翻页与滚动两种模式、四套配色、字号与版心调节，阅读位置同时记录在服务端与浏览器本地。

{/* truncate */}

## 页面与地址

列表在 `/home/novel`，详情在 `/home/novel/details/{小说ID}`，阅读器在 `/home/novel/reader?book={小说ID}&chapter={章节ID}`。列表可直接浏览；详情与阅读器携带具体内容，未登录会跳转登录页，登录后回到原页面，且都不进入顶部菜单。

## 小说列表

列表按 2:3 封面卡片平铺，每页 16 本，底部翻页器显示总条数。

| 卡片元素 | 说明 |
| --- | --- |
| 封面 | 缺失或加载失败时统一显示「图像加载失败」占位 |
| 类型角标 | 左上角蓝色标签，取书籍的类型字段，为空时不显示 |
| 标题 | 最多两行，超出省略；开启「优先中文」后优先显示中文标题 |
| 作者 | 为空时显示「佚名」 |
| 章数与状态 | 形如「共 12 章 · 连载」，状态取完结 / 连载 / 草稿 / 待续 / 创作中 |

列表为空时显示「暂无小说」；仅在有条目时显示分页器。

## 侧栏筛选

列表右侧（窄屏下隐藏）是统一的前台媒体侧栏，影视、剧集、演员、漫画、小说五个列表页共用同一套布局。

| 区块 | 内容 |
| --- | --- |
| 搜索 | 输入框占位「书名 / 作者 / 系列」，回车或点搜索按钮后从第一页重新查询 |
| 优先 | 开关，切到「中文」时标题优先取中文名，切到「原文」时取原始标题 |
| 模式 | 开关，切到「收藏库」只检索已收藏的书，切到「全库」检索全部 |
| 搜索历史 | 最多保留 15 条，点击即再次检索；为空时提示「暂无搜索历史，快去搜索吧！」 |
| 标签 | 展示使用最多的前 20 个标签，带输入框可快捷搜索标签库；选中后按标签过滤 |

关键词、标签、模式与「优先」状态会写入浏览器本地，刷新后自动恢复上次的筛选条件。

## 详情页：书目信息

页面自上而下是标题区、基础信息卡与章节列表。基础信息卡左侧是 2:3 封面（完整显示、不裁剪），中间是书目字段，右侧是快捷操作。

| 字段 | 说明 |
| --- | --- |
| 标题 / 作者 | 标题区重复展示一次书名与「作者：xxx」 |
| 标签行 | 类型、状态、语言与「共 N 章」四个标签，字段为空时对应标签不显示 |
| 描述列表 | 作者、系列、出版社、出版年份、ISBN、总章节、页数，只展示有值的项 |
| 标签 | 书籍自带标签，青色小标签逐个列出 |
| 简介 | 长文本，按段落显示在信息卡底部 |
| 评分 | 10 分制评分换算为 5 颗心（评分 ÷ 2，支持半心），右侧橙色标签显示「N 分」 |

### 快捷操作

| 按钮 | 出现条件与行为 |
| --- | --- |
| 继续阅读 | 仅在存在阅读进度时出现，跳到上次读到的章节 |
| 从头阅读 / 阅读 | 有进度时文案为「从头阅读」，无进度时为「阅读」，始终从第一章开始 |
| 进度提示 | 有进度时在按钮下方显示「上次读到 第 N 章 · 章节标题」 |
| 收藏 / 已收藏 | 切换收藏状态，成功提示「收藏成功」或「已取消收藏」；未登录提示「操作失败, 请确认已登录」 |
| 分享 | 打开分享弹窗，以当前小说为预置内容，创建后得到 `/share/{短码}` 链接 |

### 章节目录

章节列表按「序号 + 标题 + 字数」逐行展示，每行右侧有「阅读」按钮；每页 20 章，章节更多时列表内单独分页。

- 上次读到的章节带橙色「上次读到」标签，进入详情页时会自动翻到该章节所在页。
- 无章节时显示「暂无章节」；小说不存在或加载失败时整页显示「小说不存在或加载失败」。

:::note[评论区]
详情页底部的评论区目前是前端占位实现：可以输入并提交，但评论只保留在当前页面，不会提交到服务端。
:::

## 阅读器

阅读器整屏铺满，顶部与底部控制条默认隐藏，点击屏幕中部呼出；4 秒无操作后控制条与设置面板自动收起。

| 位置 | 元素 |
| --- | --- |
| 顶部 | 返回（浏览器上一页）、书名、目录、全屏 / 退出全屏、设置 |
| 正文 | 章节标题、正文段落、章末「—— 本章完 ——」 |
| 章末 | 有下一章时显示「下一章：标题」并可点击；最后一章显示「已是最后一章」 |
| 底部 | 上一章、上一页、状态文本、下一页、下一章 |
| 底部状态 | 翻页模式为「第 x/y 章 · 第 a/b 页 · 全书百分比」；滚动模式为「第 x/y 章 · 滚动百分比 · 本章字数」 |

目录是覆盖式抽屉，标题为「目录 · 共 N 章」，逐条列出序号、标题与字数，当前章高亮，打开时自动滚动到当前章位置。切换章节时不会清空当前正文，只在顶部显示细进度条；章节加载失败时提示「章节内容加载失败, 请稍后重试」。

## 阅读设置

设置面板内所有选项即时生效，并持久化在浏览器本地（键名 `AMMDS_NOVEL_READER`），换设备不会同步。

| 设置项 | 可选项 |
| --- | --- |
| 阅读模式 | 翻页 / 滚动 |
| 主题 | 白、米黄、护眼、暗夜四个色点，点击切换阅读配色 |
| 字号 | A- 与 A+ 每次增减 2px，范围 12–34px；点击中间的「18px」按钮把字号重置为 18px |
| 行距 | 1.4 / 1.6 / 1.8 / 2.0 / 2.4 |
| 字体 | 系统默认、宋体、楷体、黑体 |
| 版心宽度 | 窄 / 适中 / 宽，对应正文最大宽度 620 / 760 / 900px |
| 页边距 | 窄 / 适中 / 宽，窄屏（视口宽度小于 640px）按比例缩小 |
| 翻页动画 | 开关，关闭后翻页无滑动过渡 |
| 首行缩进 | 开关，控制正文段落是否首行缩进两字 |
| 点击两侧翻页 | 开关，关闭后点击任意位置只呼出/收起控制条 |
| 滚轮翻页 | 开关，仅翻页模式下生效，滚动模式始终按滚动条滚动 |
| 章末自动下一章 | 开关，关闭后到达本章末页只提示「已到本章末页」 |
| 显示进度线 | 开关，开启时页面底部常显一条全书进度线 |

修改字号、行距、字体、缩进、版心或页边距后会重新分页，并以当前页首个段落为锚点保持阅读位置。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 点击屏幕左侧 32% 区域 | 上一页；本章首页时回翻到上一章末页，全书开头提示「已是全书开头」 |
| 点击屏幕右侧 32% 区域 | 下一页；本章末页时按设置进入下一章，全书末尾提示「已是全书末尾」 |
| ← / → / 空格 / PageUp / PageDown | 上一页 / 下一页 |
| ↑ / ↓ | 滚动模式下按屏滚动，翻页模式下等同上一页 / 下一页 |
| Esc | 关闭控制条、设置面板与目录 |
| 触屏左右轻扫 | 横向位移超过 40px 且明显大于纵向位移时翻页 |

选中文字时点击不触发翻页，控制条与目录、设置遮罩上的点击也不参与翻页。

## 阅读进度

| 场景 | 行为 |
| --- | --- |
| 已登录阅读 | 进度写入服务端，记录章节、章节序号、章内百分比与页码 |
| 游客阅读 | 不写服务端，只写浏览器本地缓存，换设备或清缓存后丢失 |
| 保存时机 | 翻页、滚动停止约 1.2 秒后保存；切换章节、页面隐藏或离开时立即保存 |
| 再次打开 | 同时读取服务端与本地缓存，取更新时间较新的一条 |
| 续读同章 | 恢复章内位置；地址栏显式指定了章节时从该章开头开始 |

服务端进度与详情页的「继续阅读」共用同一份数据，因此在一台设备上读过的位置，换设备登录后仍可在详情页继续。

:::tip[从详情页进入]
直接访问 `/home/novel/reader` 而不带 `book` 参数时，页面会提示「缺少小说参数, 请从小说详情页进入阅读」。请从详情页的章节目录或快捷操作进入阅读器。
:::
