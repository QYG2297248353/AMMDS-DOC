# 资讯前台

顶部菜单「资讯」打开的是 RSS 条目的前台列表页：按内容分类筛选、按关键词检索，点卡片进入详情页阅读正文、看图库、播放视频或下载资源，也可以直接跳转源站。

{/* truncate */}

## 页面与地址

| 页面 | 地址 | 未登录访问 |
| --- | --- | --- |
| 资讯列表 | `/home/information` | 可以直接浏览 |
| 资讯详情 | `/home/information/details/{资讯ID}` | 跳转登录页，登录后回到原地址 |

列表页对游客开放，详情页需要登录。列表页不进入阅读态，点卡片会**在新标签页**打开详情，避免打断列表浏览。

## 资讯列表

卡片按 16:9 横向封面平铺，桌面端一行 4 张、平板 3 张、手机 1 张。

| 卡片元素 | 说明 |
| --- | --- |
| 封面 | 缺失或加载失败时显示「图像加载失败」占位 |
| 分类角标 | 左上角标签，按分类着色：文章蓝、图像绿、视频橙、资源紫，其它为灰 |
| 标题 | 单行，超长省略；为空显示 `--` |
| 摘要 | 最多两行；为空显示 `--` |
| 来源 | 卡片左下角显示订阅源名称，超长省略；为空显示 `--` |
| 发布时间 | 卡片右下角显示订阅条目里的发布时间 |
| 快捷操作 | 「前往源站」在新标签打开原始链接；条目带种子/磁力/`.torrent` 附件时额外显示「查看原文」或「下载资源」 |

快捷操作单独占一行，点击不会触发卡片本身的跳转。列表为空时显示「暂无资讯」。

## 分类与来源

侧栏（窄屏下移到列表顶部）包含搜索、分类与搜索历史，下方另有一张固定的「资讯库」简介卡。

### 分类按钮组

分类固定为五项：全部、文章、图像、视频、资源。按钮以图标形式单行等宽铺满，鼠标悬浮显示「分类名 · 共 N 条」，数量来自后端统计。

- 只展示实际存在条目的分类，「其他」这类保底分类不会出现在按钮组里。
- 点击任一分类会回到第一页重新查询；「全部」不带分类条件。
- 切到窄屏时侧栏隐藏，同一组按钮出现在列表顶部卡片中，保证筛选始终可用。

### 搜索与历史

- 搜索框占位「资讯快搜」，支持的匹配范围是条目的标题与摘要。
- 点搜索按钮或回车才发起查询，输入过程不请求。
- 搜索历史按关键词去重后置顶，最多保留 15 条；点击历史标签再次检索，**再点同一个标签视为取消搜索**。
- 没有历史时提示「暂无搜索历史，快去搜索吧！」。

### 列表页没有的筛选

来源（订阅源）只作为卡片与详情页的展示字段，列表页**没有**按来源筛选的控件；需要缩小范围时用分类 + 关键词组合。分类、关键词与页码会写入浏览器本地，刷新后恢复上次状态。

## 分页

分页器默认每页 20 条，可切换每页条数；切换条数会回到第一页。分页器仅在总数大于 0 时显示，并显示总条数。

:::note[游客看到的分页]
未登录浏览时，服务端会把每页条数压到最多 30 条并随机取一页，同时把分页信息改写成「只有一页」，因此游客看到的总条数与页码不代表真实总量，刷新后内容片段也可能不同。登录后恢复按页正常翻页。
:::

## 资讯详情

详情页加载时先显示「正在加载资讯...」，请求结束后短暂显示「资讯加载完成」再进入内容。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 「返回列表」按钮，回到 `/home/information` |
| 标题区 | 资讯标题，下方依次是分类标签、来源标签与发布时间标签（字段为空则不显示） |
| 视频区块 | 条目带 `video/*` 附件时出现，用内嵌播放器播放该附件地址，播放器封面取 `mediaPoster`，没有则用条目封面；下方提供「前往源站」 |
| 图库 | 条目带 `image/*` 附件时出现，220×140 缩略图平铺，点击可放大预览 |
| 正文 | 条目描述按富文本渲染，表格与图片被约束在卡片宽度内 |
| 资源 | 除图片与视频外的附件逐条列出，显示附件地址、类型标签与文件大小，右侧「下载资源」在新标签打开 |
| 侧栏信息 | 来源、发布时间、分类、作者（多个作者逐个列标签） |
| 侧栏操作 | 「查看原文」在新标签打开原始链接；「返回列表」回到列表页 |

资讯不存在或已删除时整页显示「资讯不存在或已删除」。各区块只在有对应内容时渲染，因此不同分类的条目看到的区块数量不同。

:::tip[站内播放与源站播放]
视频区块播放的是条目附件里记录的地址：订阅做过离线缓存时该地址指向本地缓存，未缓存时指向源站。播放器不可用或需要原始页面时，用「前往源站」打开原链接。
:::

:::note[分类来自订阅配置]
条目归入哪个分类由 RSS 订阅的「内容分类」决定（文章 / 图像 / 视频 / 资源 / 其他）。同一条资讯可能既带正文又带图片与资源，此时详情页会同时出现多个区块。
:::

## 跳转原文的行为

| 入口 | 位置 | 打开方式 |
| --- | --- | --- |
| 前往源站 | 列表卡片、详情页视频区块 | 新标签页打开条目原始链接 |
| 查看原文 | 列表卡片（资源类）、详情页侧栏 | 新标签页打开条目原始链接 |
| 下载资源 | 列表卡片与详情页资源区块 | 新标签页打开附件地址 |

所有外链都带 `rel="noopener"`，不会把当前页面暴露给目标站点。

## 与后台的关系

前台只读取已抓取的条目，订阅的添加、抓取、离线缓存与分类都在后台维护。订阅源本身怎么配、抓取失败的排查见 [RSS 订阅与热门榜单](/docs/backend/information/rss)。
