# 浏览影片、剧集、演员与漫画小说

影视、剧集、演员、漫画、小说这五个库的页面结构很像：左边一排卡片，右边一排筛选。这一页先讲它们的共同点，再逐个说各自能看到什么、能做什么。

> **识别码 / 番号**：影片的识别编号，通常写在文件名里，例如 `SSIS-001`。卡片上以紫色小标签显示。

> **季 / 集**：剧集的分层。一部剧分成若干季，每季下面再分集。

> **磁力**：一串可以直接交给下载软件的文字，作用等同于种子文件。

## 五个库共有的东西

### 列表页长什么样

| 区域 | 内容 |
| --- | --- |
| 左侧内容区 | 卡片网格与分页 |
| 右侧筛选栏 | 搜索、中文优先、模式、搜索历史、热门标签、本库简介 |

宽屏一行 6 张卡片，窗口变窄依次降为 4、3、2、1 列；宽度不超过 1024px 时右侧筛选栏整体隐藏（漫画和小说会把它移到列表上方）。

### 筛选控件

| 控件 | 作用 | 不填 / 不改会怎样 |
| --- | --- | --- |
| 搜索框 | 输入关键词后回车或点搜索按钮 | 不填就是全部内容 |
| 中文优先 | 只影响标题显示：开启显示中文标题，关闭显示原标题 | 不影响查询结果，只影响你看到的名字 |
| 模式 | 「全局库」或「收藏库」，切换后立即重新检索 | 默认全局库，看到全部内容 |
| 搜索历史 | 最多保留 15 条，存在浏览器里，点一下就能再用一次 | 再次点击当前关键词等于取消搜索 |
| 标签 | 展示热门标签（最多 20 个），点击按标签筛选 | 再次点击取消；选中标签会清空关键词 |

:::warning[关键词和标签不能同时用]
输入关键词会清空已选标签，选择标签会清空关键词。两者不会叠加成「同时满足」的条件。
:::

### 分页与记忆

- 每页固定 20 条（小说是 16 条），分页条只显示总数，没有每页条数选择器。
- 搜索条件、模式、中文优先等会存在浏览器里，刷新后恢复。
- 影视与剧集点进详情时会把页码写进地址栏，从详情后退能回到原来那一页。
- 未登录的访客每页最多 30 条，翻到哪一页由后台随机决定，所以刷新后看到的内容可能不同——这是为了防批量抓取。

## 影视

列表地址是影视列表页，点卡片进入详情（**详情需要登录**，未登录会跳到登录页，登录后自动回到该页）。

### 卡片上有什么

- **封面**：优先高清封面；没有图或加载失败时显示「图像加载失败」。
- **悬浮标签**：发行日期、评分（10 分制），以及后台标记的「可播放」标识，有值才显示。
- **标题**：受「中文优先」控制。影视列表不会拿原名顶替：中文标题为空时，标题就留白。
- **识别码**：紫色小标签，可能有多枚。
- **演员**：青色标签，图标按角色文本包含「男 / 女」切换，判断不了时显示人形问号。

### 详情页

页面顶部是大标题与中文标题（带「译文」标签），主图优先高清背景图。

| 信息项 | 说明 |
| --- | --- |
| 识别码 | 全部识别码，以标签展示 |
| 发行日期 | 原始日期文本 |
| 时长 | 分钟数 |
| 导演 / 制作公司 / 发行公司 | 多值标签 |
| 演员 | 姓名标签，影视库里有该演员时可点进演员详情 |

信息区右侧有三枚按钮：**订阅**、**收藏**、**分享**。订阅与收藏按当前状态切换图标与配色；分享在未登录时会提示需要登录。

再往下是：

| 区块 | 内容 |
| --- | --- |
| 评分 | 5 颗星按 10 分制折算，支持半星；分数按区间着色（8 分及以上绿色、4 分及以上琥珀色、其余红色） |
| 磁力提交 | 输入磁力链接后点「提交」，为空会提示「请输入磁力链接」 |
| 扩展信息 | 三个标签页：分类、标签、扩展信息键值表 |
| 演员 | 头像 + 姓名 + 角色，横向滚动 |
| 封面图 / 背景图 / 缩略图 / 剧照 | 图墙，高清图置顶，点击可全屏预览 |
| 资源分享 | 磁力列表：名称、大小、分享日期与操作 |
| 评论区 | 只摆了个样子，详见文末说明 |

:::warning[详情页没有播放器]
影视详情只展示资料、图片与资源，**没有播放器也没有「播放」按钮**；卡片上的「可播放」只是条目标记，不代表能在这里播放。要看视频请用外部播放器。
:::

「资源分享」里每行三个操作：**推送下载**（当前版本点击只提示「敬请期待」）、**复制磁力**、**举报资源**（当前版本点击只提示「敬请期待」）。磁力表为空时显示「暂无资源分享」。

## 剧集

剧集把连续剧、番剧、综艺按「一部剧」聚合，详情页在同一页里展开全部季与集，方便看结构。

### 卡片上有什么

- **封面**：竖版，无图或加载失败显示「图像加载失败」。
- **悬浮标签**：首播年份、评分。
- **标题**：受「中文优先」控制。
- **分区**：优先显示资料里自带的分区名，没有的话按内置对照显示番剧、日剧、韩剧、国剧、欧美剧、纪录片、综艺、其他。
- **连载状态**：`Continuing` 显示「连载中」，`Ended` 显示「已完结」。
- **季集数量**：形如「3 季 · 24 集」。
- **类型**：取前三个类型，用「 / 」连接。

### 详情页

| 信息项 | 说明 |
| --- | --- |
| 首播日期 | 缺失时显示 `-` |
| 时长 | 分钟数 |
| 分区 | 中文分区名，未知的代码原样显示 |
| 数据源 | 这份资料来自哪个来源（显示来源代码），没有记录时显示 `-` |
| 季数 / 集数 | 优先数据源声明的总数，其次实际入库数 |
| 状态 | 连载中 / 已完结 / 原值 |
| 类型 / 制作公司 | 多值标签 |

同样有**订阅、收藏、分享**三枚按钮。评分与影视一致；磁力提交框只负责提交链接，提交后清空输入框，**不会在页面展示磁力列表**。

### 季与集

「季集列表」把全部季一次性渲染成可折叠面板：

1. 面板标题是季名或「第 N 季」；季号为 0 或标记为特别篇时统一显示「特别篇」。
2. 面板右侧显示「本季共 N 集」。
3. 面板内展示季海报、季首播日期与季简介。
4. 季内用表格列出集号、标题、首播日期、时长、评分、缩略图；标题优先中文名，缺失回退原名。
5. 默认展开第一个「有集」的季；没有季时显示「暂无季集数据」。

:::warning[季集表不是播放列表]
季集表只展示集号、标题、首播日期、时长、评分与缩略图，集里不包含文件信息，页面也没有播放器。文件的绑定在后台完成。
:::

图片区块有封面图、背景图、缩略图、Logo 与横幅。剧集实体没有「剧照」字段，所以没有剧照模块。

## 演员

演员库把演员档案与参演作品关联起来。

### 卡片上有什么

- **海报**：竖版，无图或加载失败显示「图像加载失败」。
- **悬浮标签**：出道日期、身高（cm）、体重（kg）。
- **姓名**：受「中文优先」控制。
- **基础标签**：性别、年龄、国籍、退役、已故、罩杯等，有值才显示。列表里的性别只分「女」和「男」两种，不细分其它情况。

### 详情页

顶部是演员姓名，有别名时在下方以「别名：A / B」展示。主卡片左侧是头像，右侧依次展示：

| 信息 | 展示方式 |
| --- | --- |
| 性别 | 男 / 女 / 人妖 / 未知性别 |
| 年龄 | 「N 岁」 |
| 退役 / 已故 | 橙色 / 红色标签 |
| 身高 / 体重 | 「N cm」「N kg」 |
| 血型 / 出生日期 / 国籍 | 标签 |
| 三围 | 「胸-腰-臀」，可追加罩杯 |
| 出道日期 / 所属公司 | 日期文本与标签列表 |
| 评分 | 5 星 + 10 分制分数 |
| 社交链接 | 按域名识别常见社交站点，其余用通用链接图标 |

同样有**订阅、收藏、分享**三枚按钮。

| 区块 | 内容 |
| --- | --- |
| 扩展信息 | 五个标签页：简介、风格、特征、标签、扩展信息（键值表） |
| 海报 | 演员图集，可预览；无图时显示「暂无海报」 |
| 作品 | 最近 20 部参演影视，按发行时间从新到旧；页面上每页显示 10 条，点标题进影视详情 |
| 资讯 | 以演员姓名作关键词检索，最多 10 条 |

:::tip[数量上限]
作品一次只取最近 20 部，资讯一次只取 10 条，两个列表都没有「加载更多」。想看更多请到影视列表或资讯页检索。
:::

:::note[「推荐演员」目前是空的]
「推荐演员」卡片还没有数据来源，所以一直显示「暂无推荐演员」。它带手型光标但没有跳转，别把它当入口。
:::

## 漫画

漫画是「封面列表 → 详情与章节 → 全屏阅读器」三段式。

### 卡片与筛选

卡片上有封面、分类、标题、作者、系列，以及最多 3 个标签。分类在非全集且季号大于 0 时显示「第 N 季」，全集则显示「全集」。搜索框会同时在标题、描述、备注、作者、绘者、出版信息和系列里找。

### 详情页

左侧是封面。右侧从上往下依次是：

1. 一排标签：分类、全集 / 第 N 季、年龄分级、页数「共 N 页」。
2. 一张一行一项的资料表：作者、系列、出版社、印刷商、出版日期、语言、格式、色彩、阅读方向、年龄分级、社区评分、备注、链接，没填的项不显示。
3. 标签、角色、团队、地点与简介。
4. 最后的评分。

右侧竖排四枚按钮：

1. **继续阅读**：仅当存在该用户的阅读进度、且进度所属章节还在章节列表里时显示。
2. **阅读 / 从头阅读**：没有进度时显示「阅读」，有进度时显示「从头阅读」，总是打开第一章。
3. **收藏 / 已收藏**：未登录时弹登录确认。
4. **分享**：未登录时弹登录确认。

章节列表每页 20 章，每章显示标题、「第 N 话 · X 页」与可选描述；续读章节会显示「读至第 N 页」；有进度时卡片右上角出现「继续阅读 第 N 页」。

### 阅读器

阅读器是全屏页面，分顶栏、阅读区、底栏与底部进度线。顶栏有返回、标题、章节下拉、上一章 / 下一章、翻页方向、全屏；底栏有翻页、页码输入、缩放、页面导航与设置。

- **翻页**：支持单页 / 双页（页面宽度至少 720px 才出双页，否则自动用单页）。点击左三分之一上一页、右三分之一下一页、中间切换工具栏。翻到本章最后一页继续翻会进入下一章。
- **滚动模式**：全部图片纵向排列，按视口顶部 35% 同步页码。
- **缩放**：0.5–5 倍，按钮每次 ±0.25，点百分比复位；双击在 1 倍与 2 倍间切换。
- **快捷键**：左右方向键翻页、空格下一页、PageUp / PageDown 翻页、Home / End 首末页、`+` / `-` 缩放、`0` 复位、`F` 全屏、`Esc` 退出全屏或切换工具栏。

### 阅读器设置项说明

右下角「设置」抽屉：

| 设置项 | 要选什么 | 不改 / 选错会怎样 |
| --- | --- | --- |
| 阅读模式 | 翻页 / 滚动 | 默认翻页；选滚动就变成纵向长图 |
| 图片适应 | 宽度 / 高度 / 原始尺寸 | 选错图片可能超出屏幕或过小 |
| 图片间距 | 0–40px | 默认不调 |
| 翻页方向 | 左到右 / 右到左 | 方向反了翻页左右会互换 |
| 单双页 | 单页 / 双页 | 屏幕太窄会强制单页 |
| 背景主题 | 纯黑 / 深灰 / 米黄 / 护眼 / 纯白 | 只影响观感 |
| 预加载 | 0–10 页 | 调大更流畅但更吃流量 |
| 滚轮缩放 | 开关 | 关闭时滚轮用于翻页 |
| 点击左右分区翻页 | 开关 | 关闭后点击只切换工具栏 |
| 触屏自动隐藏工具栏 | 开关 | 开启后移动端要轻触屏幕才出现工具栏 |

设置存在当前浏览器里，**换设备不会跟随**；「恢复默认设置」可以还原全部选项。

:::tip[设置和进度不是一回事]
阅读进度按登录账号保存，换设备登录后仍可续读；阅读设置只保存在这个浏览器里。
:::

进度按「漫画 + 章节 + 页码」记录，页码或章节变化后约 800 毫秒保存，切章、返回、离开页面时立即保存。服务器出错时至少会留下本地缓存，下次还能接着读。

## 小说

小说是「列表 → 详情与目录 → 阅读器」三段式。

### 列表

每页 16 本，卡片上有封面、左上角蓝色类型角标、标题（开启「优先中文」后优先中文名）、作者（为空显示「佚名」）、「共 12 章 · 连载」这样的章数与状态（完结 / 连载 / 草稿 / 待续 / 创作中）。

### 详情页

| 区域 | 内容 |
| --- | --- |
| 标题区 | 书名与「作者：xxx」 |
| 标签行 | 类型、状态、语言与「共 N 章」，为空不显示 |
| 描述列表 | 作者、系列、出版社、出版年份、ISBN、总章节、页数，只显示有值的项 |
| 标签 / 简介 | 青色小标签与长文本 |
| 评分 | 10 分制换算成 5 颗心，右侧显示「N 分」 |
| 快捷操作 | 继续阅读（有进度时出现）、从头阅读 / 阅读（总是从第一章）、进度提示「上次读到 第 N 章 · 章节标题」、收藏 / 已收藏、分享 |
| 章节目录 | 按「序号 + 标题 + 字数」逐行，每行右侧「阅读」；每页 20 章；上次读到的章节带橙色「上次读到」标签，进详情页会自动翻到那一页 |

收藏未登录时提示「操作失败, 请确认已登录」；分享会打开弹窗，创建后得到一条分享链接。

### 阅读器

阅读器整屏铺满，顶部与底部控制条默认隐藏，点屏幕中部呼出，4 秒无操作自动收起。

| 位置 | 元素 |
| --- | --- |
| 顶部 | 返回、书名、目录、全屏 / 退出全屏、设置 |
| 正文 | 章节标题、正文段落、章末「—— 本章完 ——」 |
| 章末 | 有下一章时显示「下一章：标题」并可点击；最后一章显示「已是最后一章」 |
| 底部 | 上一章、上一页、状态文本、下一页、下一章 |
| 底部状态 | 翻页模式为「第 x/y 章 · 第 a/b 页 · 全书百分比」；滚动模式为「第 x/y 章 · 滚动百分比 · 本章字数」 |

目录是覆盖式抽屉，标题「目录 · 共 N 章」，当前章高亮，打开时自动滚到当前章。切章不会清空当前正文，只在顶部显示细进度条。

### 阅读设置项说明

设置面板里的选项立即生效，并存在浏览器本地，换设备不会同步。

| 设置项 | 可选项 | 不改会怎样 |
| --- | --- | --- |
| 阅读模式 | 翻页 / 滚动 | 默认按上次选择 |
| 主题 | 白、米黄、护眼、暗夜 | 只影响配色 |
| 字号 | A- / A+ 每次增减 2px，范围 12–34px；点中间数字重置为 18px | 保持上次值 |
| 行距 | 1.4 / 1.6 / 1.8 / 2.0 / 2.4 | 保持上次值 |
| 字体 | 系统默认、宋体、楷体、黑体 | 保持上次值 |
| 版心宽度 | 窄 / 适中 / 宽（620 / 760 / 900px） | 保持上次值 |
| 页边距 | 窄 / 适中 / 宽，窄屏按比例缩小 | 保持上次值 |
| 翻页动画 | 开关 | 关闭后翻页没有滑动过渡 |
| 首行缩进 | 开关 | 关闭后段落不缩进 |
| 点击两侧翻页 | 开关 | 关闭后点击只呼出 / 收起控制条 |
| 滚轮翻页 | 开关，仅翻页模式生效 | 滚动模式始终按滚动条滚 |
| 章末自动下一章 | 开关 | 关闭后到章节末尾只提示「已到本章末页」 |
| 显示进度线 | 开关 | 关闭后底部不显示全书进度线 |

改字号、行距、字体、缩进、版心或页边距后会重新分页，并让你停在原来读到的那一段，不会一下跳走。

### 操作方式

| 操作 | 效果 |
| --- | --- |
| 点屏幕左侧约三分之一 | 上一页；本章首页时回翻到上一章末页 |
| 点屏幕右侧约三分之一 | 下一页；本章末页时按设置进入下一章 |
| ← / → / 空格 / PageUp / PageDown | 上一页 / 下一页 |
| ↑ / ↓ | 滚动模式按屏滚动，翻页模式等同上一页 / 下一页 |
| Esc | 关闭控制条、设置面板与目录 |
| 触屏左右轻扫 | 横向位移超过 40px 且明显大于纵向位移时翻页 |

选中文字时点击不会翻页，控制条与目录、设置遮罩上的点击也不参与翻页。

### 阅读进度

| 场景 | 行为 |
| --- | --- |
| 已登录阅读 | 进度存到服务器上，记录章节、章节序号、章内百分比与页码 |
| 访客阅读 | 只写浏览器本地缓存，换设备或清缓存后丢失 |
| 保存时机 | 翻页、滚动停止约 1.2 秒后；切换章节、页面隐藏或离开时立即保存 |
| 再次打开 | 服务器上的和浏览器里的各读一份，取较新的那条 |
| 续读同章 | 恢复到章内位置；地址栏显式指定章节时从该章开头开始 |

:::tip[从详情页进阅读器]
直接打开阅读器地址而不带书籍参数时，页面会提示「缺少小说参数, 请从小说详情页进入阅读」。请从详情页的章节目录或快捷操作进入。
:::

## 几处还没做好的地方

如实说明，免得你以为是自己的问题：

- **影视「同系列影视」**卡片始终显示「暂无同系列影视」——当前没有向这个区块填数据。
- **剧集「同系列剧集」**始终是空的——目前没有剧集系列模型。
- **评论区**只是个样子：默认显示一条「AMMDS 官方 / 敬请期待」，提交后只留在当前页面，刷新就没了，点赞与回复也没有接上后台。不要把它当社区功能用。
- **影视「推送下载」「举报资源」**当前点击只提示「敬请期待」。
- 影视详情里**没有**语言、国家 / 地区、分级、系列等字段展示，这些要到后台的媒体库核对。

## 出问题了怎么办

- **点卡片跳到登录页**：详情页需要登录，登录成功后会自动回到原来那一页。
- **列表一直是空的**：后台还没扫描入库，或者筛选条件太窄（关键词与标签不能叠加，检查一下是不是只剩一个条件）。
- **刷新后列表变了**：如果是访客，每页条数被限制、页码随机，属正常现象；登录后恢复。
- **卡片标题是空的**：影视列表不会拿原名顶替空白的中文标题；关掉「中文优先」就会显示原标题。
- **演员点进去提示「该演员暂无详情」**：这位演员只存在于影片的演员映射里，还没进演员库。
- **漫画续读按钮不见了**：服务器上没有这个账号的进度，或者进度所在的章节已经不在章节列表里。
- **换设备后阅读进度还在、但阅读设置没了**：进度按账号存在服务器上，设置只存在原来那个浏览器里，这是预期行为。
- **小说打开阅读器提示缺少参数**：请从详情页的章节目录或「阅读 / 继续阅读」按钮进入。
