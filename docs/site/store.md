# 商店前台

顶部菜单「商城」进入商店前台：先浏览商品列表或分类，再进商品详情选规格加入购物车，登录后结算下单，之后可在「我的订单」里查看进度、申请取消或退货退款。

{/* truncate */}

## 入口与页面一览

- 商城在后台启用后，顶部菜单才会出现「商城」；未启用时菜单项隐藏，但仍可直接输入地址访问。商城未开放时，商品列表页与店铺信息页都会提示「商城尚未开放，请稍后再来」。
- 商品列表、分类页、店铺信息可以匿名浏览；加入购物车、结算、订单列表与订单详情需要登录，未登录会被重定向到登录页。

| 页面 | 地址 | 登录要求 |
| --- | --- | --- |
| 商品列表 | `/home/store` | 匿名可看 |
| 商品分类 | `/home/store/category/{分类handle}` | 匿名可看 |
| 商品详情 | `/home/store/product/{商品handle}` | 匿名可看，加购需登录 |
| 购物车 | `/home/store/cart` | 需登录 |
| 结算 | `/home/store/checkout` | 需登录 |
| 订单结果 | `/home/store/order/{token}` | 需登录 |
| 订单列表 | `/home/store/orders` | 需登录 |
| 订单详情 | `/home/store/orders/{订单ID}` | 需登录 |
| 店铺信息 | `/home/store/info` | 匿名可看 |

## 商品列表

列表为响应式栅格，桌面端一行 4 张、平板 3 张、手机 1 张，每页 12 个。

| 元素 | 说明 |
| --- | --- |
| 封面 | 1:1 方形图，加载失败时显示「图片加载失败」占位；不可售时封面上显示「暂不可售」 |
| 标题与金额 | 标题单行省略，副标题为空时不显示；规格金额不一致时显示区间，否则显示单一金额，具体金额与币种以页面实时返回为准 |
| 分页 | 有数据时显示分页器与总条数；列表为空时显示「暂无商品」 |

点卡片进入商品详情。分类页 `/home/store/category/{handle}` 复用同一套侧栏与卡片，额外显示分类名、分类描述与子分类标签；描述为空时用默认文案「该分类下的全部在售商品」。

### 筛选与侧栏

桌面端右侧是商城侧栏，窄屏下搜索与分类移到列表顶部。

| 区块 | 内容 |
| --- | --- |
| 商城导航与币种 | 商品首页、我的订单、店铺信息、购物车四个按钮；下方显示当前结算币种与地区名，点击进入店铺信息页切换 |
| 搜索 | 输入框回车或点搜索按钮，关键词会写入地址栏的 `q` 参数，链接可直接分享 |
| 商品分类 | 标签云，「全部」加各级分类，点击即筛选并回到第一页 |
| 商品系列 | 有系列数据时出现，「全部系列」加各系列标签 |
| 购物车 | 未登录显示「登录后可查看购物车与下单。」与登录按钮；已登录显示前 3 行商品、数量与合计，并有「查看购物车」 |
| 店铺 | 店铺名称、描述、类型（官方自营）、币种、客服邮箱，以及固定的商城简介文案 |

## 商品详情

| 区域 | 内容 |
| --- | --- |
| 操作行与主图 | 返回商城、购物车、我的订单、店铺信息；多图时用轮播（不自动播放），无图时显示占位 |
| 销售状态 | 可售显示「有货」，不可售显示「该商品暂不可售」 |
| 规格选择 | 商品带选项时按选项分组渲染按钮；没有选项但有多个规格时直接列出规格按钮，不可售的规格置灰 |
| 数量与属性 | 数量输入范围 1–99；属性区展示商品编号、规格（全部规格标题）与库存状态（可售时显示「可售（库存以结算为准）」） |
| 操作按钮 | 「加入购物车」与「立即购买」，不可售时同时禁用 |
| 商品详情与图文 | 名称、副名称、编号、分类、币种、销售状态与规格表格（规格、SKU、金额、销售状态）；下方富文本介绍为空时显示「暂无图文介绍」，其后是固定的免责声明 |

点「加入购物车」未登录时提示「登录后可查看购物车与下单。」并跳转登录页（登录后回到当前商品）；已登录时提示「已加入购物车」。「立即购买」加购后直接进入结算页。商品不存在或已下架时整页显示「商品不存在或已下架」并提供「返回商城」。

## 购物车

购物车绑定当前账号与结算地区，换账号或换地区会得到不同的车。

| 元素 | 说明 |
| --- | --- |
| 商品行 | 封面、标题、规格名、单价、数量（1–99，修改后立即生效）、行合计 |
| 移除 | 行内「移除」按钮，成功提示「已移除商品」；空车时显示「购物车还是空的」与「继续选购」 |
| 订单摘要 | 结算币种、小计、运费、税费、优惠（带负号）、合计，底部为进入结算页的「去结算」 |
| 优惠码 | 输入「输入优惠码」后点「使用」，成功后提示「优惠码已应用」 |
| 放弃购物车 | 二次确认「放弃当前购物车？」，确认后清空并提示「已放弃当前购物车」 |

购物车没有逐行勾选，车里所有商品一起结算。

## 结算

结算页左侧是表单，右侧是订单摘要；购物车为空时只显示空车提示与「继续选购」。

| 区块 | 字段与行为 |
| --- | --- |
| 常用地址 | 仅登录后显示。下拉列出已保存的地址（只保留与当前购物车地区兼容的地址），选中后自动回填；进入页面时默认选中默认地址 |
| 联系信息与地址 | 邮箱（必填，需包含 `@`）、电话、名、姓；详细地址、城市、国家/地区（三项必填）；邮编、省/州选填；国家选项限定在当前购物车所属地区内 |
| 配送方式 | 点「获取配送方式」先保存联系信息与地址，再读取可选配送方式与金额；没有可用方式时显示提示文案 |
| 支付方式 | 由店铺返回的支付方式单选列表；需要跳转完成的渠道额外标注「需跳转支付」；无可用渠道时提示「当前地区暂无可用支付方式」 |
| 订单摘要 | 商品行、结算币种、小计、运费、税费、优惠、合计，以及「提交订单」与「放弃购物车」 |

提交时依次校验：邮箱为空或不含 `@` 提示「请填写有效邮箱」；详细地址、城市、国家任一为空提示「请填写完整的收货地址」；未选支付方式提示「请选择支付方式」；含需配送商品但取不到配送方式时提示「当前地区暂无可用配送方式」。

需要跳转的支付方式会离开本站进入支付页，支付完成后带 `payReturn=1` 回到结算页；扫码类支付会弹出「扫码支付」窗口，点「我已完成支付」后继续确认订单。确认成功后跳转到订单结果页；若返回的是订单 ID 则直接进入订单详情页。

结算使用幂等的请求标识，同一笔订单重复点「提交订单」不会生成两笔。页面出现「订单正在确认中，请勿重复提交」时不要反复重试，稍后到订单列表确认结果。

## 订单结果

`/home/store/order/{token}` 是下单后的回执页。地址使用随机 token，不是可枚举的订单 ID；页面打开期间会临时设置 `no-referrer`，避免 token 通过 Referer 外泄。

| 区域 | 内容 |
| --- | --- |
| 结果区 | 「下单成功」、订单号，以及「继续选购」「我的订单」「订单详情」三个按钮 |
| 订单信息与明细 | 下单时间、订单状态、支付状态、履约状态、联系邮箱（脱敏）、订单金额；商品明细含封面、标题、规格、数量与行金额 |

订单不存在或 token 已失效时显示「订单不存在或链接已过期」。

## 订单列表

订单列表每页 10 条，顶部有「刷新」与「继续选购」。

| 元素 | 说明 |
| --- | --- |
| 订单头 | 订单号、下单时间、订单状态标签、支付状态标签 |
| 商品行 | 封面、标题、规格、数量、行金额，底部是订单合计；没有订单时整块显示「暂无订单」 |
| 操作 | 可支付时显示「去支付」，否则显示「查看详情」；可取消时显示「取消订单」；可退货时显示「退货退款」 |
| 取消 | 需二次确认，提交后提示「取消申请已提交，等待商家处理」，状态变为「取消申请中」 |

## 订单详情

| 区域 | 内容 |
| --- | --- |
| 提示条与状态区 | 订单携带说明时以信息条展示，存在取消申请时额外提示；随后是订单状态、支付状态、履约状态三个标签与下单时间 |
| 信息表 | 订单号、联系邮箱、下单时间、订单金额、支付状态、履约状态 |
| 物流信息 | 有履约记录时展示履约状态、承运方、发货/送达时间与物流单号；没有单号时提示「商家尚未填写物流单号」；订单内商品全部无需配送时另提示为虚拟商品 |
| 退货退款记录 | 每条记录展示状态、申请时间、商品行、原因与说明 |
| 操作区 | 订单允许取消时显示取消卡片；允许退货时显示退货退款表单，可填可退数量、退货原因、行备注与退货说明，提交后提示「退货退款申请已提交」 |

各操作区块只在订单当前状态允许时渲染，因此不同订单看到的区块不同。

## 店铺信息

店铺信息页汇总店铺的公开资料与结算规则，也是切换结算币种的入口。

| 区块 | 内容 |
| --- | --- |
| 店铺资料 | 店铺名称、描述、店铺类型（官方自营）、客服邮箱、在线下单状态（已开放 / 未开放） |
| 结算币种 | 地区单选列表，每项显示币种代码、地区名与符号；切换后立即生效，商品金额按新地区币种重新获取 |
| 结算方式 | 当前地区可用的支付方式标签，以及配送方式与结算说明文案 |
| 地区与配送范围 | 每个地区一行，显示币种与覆盖的国家/地区，当前地区带「当前」标记；无地区时提示「暂无可用地区」 |
| 售后说明 | 固定的售后文案，并提供「查看我的订单」与「继续选购」 |

:::note[金额与渠道以页面为准]
商品金额、运费、税费、优惠与支付渠道都由店铺侧返回并实时变化，本文只描述页面上的字段与操作，不展开具体金额与渠道。
:::
