# 用户主页与个人中心

前台有两类与「人」相关的页面：任何人可访问的**公开主页**，以及登录后维护自己的**个人中心**。前者只展示用户在资料里勾选公开的字段，后者决定这些字段、头像、横幅与整页主题。

## 登录与账号入口

### 顶栏

未登录时顶栏右侧只有「登录」按钮，点击进入登录页。登录后按钮换成一个头像下拉菜单：

| 菜单项 | 行为 |
| --- | --- |
| 个人中心 | 打开 `/admin/user/info` |
| 后台管理 | 打开后台工作台 |
| 开启剧透 / 关闭剧透 | 切换列表与详情中的剧透内容显示 |
| 退出登录 | 清除登录态并回到登录页 |

顶栏还有语言切换、深浅色切换、全屏按钮与快捷搜索，它们不区分登录态。

### 登录页

| 元素 | 说明 |
| --- | --- |
| 账号 / 密码 | 占位文案为「管理员账号」「管理员密码」，密码提交前用 RSA 公钥加密 |
| 隐私协议与忘记密码 | 隐私协议必须勾选才能登录，未勾选时提示「请先阅读并同意隐私协议」；忘记密码打开重置弹窗，用恢复密钥重置 |
| 其他登录方式 | 只有后端开启了对应能力时才显示「使用 Passkey 登录」与「统一登录」；统一登录会弹窗选应用，在新窗口完成第三方认证 |
| 两步验证 | 账号开启两步验证时，密码校验通过后进入验证码步骤，输入 6 位验证码或恢复码完成登录 |

:::warning[不能自助注册]
登录页底部的「注册账号」按钮当前是**禁用状态**，前台没有开放注册入口。账号来自部署时的初始化（默认管理员 `ammds`），不能在这里新注册一个。
:::

登录成功后按地址栏的 `redirect` 参数回跳原页面；没有该参数时，按「系统配置 → 主题外观 → 落地页」的「打开优先进入」决定进前台还是后台。

## 公开主页

### 两种地址

`/user/{用户ID}` 是标准形式，`/u/{用户ID}` 是短链别名，两条地址渲染同一个页面。

两条地址都无需登录，使用公共布局（无前台顶部菜单），页面底部固定是「首页 | © AMMDS 提供技术支持」。「首页」回到站点前台首页。个人中心的「公开主页」按钮打开的就是 `/u/{用户ID}`；用户 ID 改动后旧地址立即失效。

### 页面内容

| 元素 | 说明 |
| --- | --- |
| 头像与昵称 | 未设置头像时显示默认用户图标，未设置昵称时显示「AMMDS 用户」 |
| 用户标识 | 形如 `@用户ID` |
| 标签 | 账号状态有值时显示为绿色标签，另有固定的「AMMDS 认证用户」标签 |
| 横幅与背景 | 头图区横幅未设置时用主题渐变背景，整页底色未设置时用系统背景 |
| 基本信息 | 按用户勾选的公开字段渲染，字段为空则不出现 |
| 无内容提示 | 所有公开字段都为空时显示「该用户暂无公开信息」 |

加载中显示加载态；用户不存在或未开放主页时显示「用户不存在或不可访问」并提供「重新加载」。

:::note[能看到什么由本人决定]
邮箱、手机号、注册时间、最后登录时间与账号状态都属于可选公开字段。手机号即使公开也只展示脱敏号码；把全部字段取消勾选后，公开主页只剩头像、昵称与主题外观。
:::

### 主页主题

公开主页有 12 套主题，每套都是独立的页面结构与排版，不是简单换色：

| 主题 | 说明 |
| --- | --- |
| 经典卡片 | 居中横幅卡片 + 双列信息栅格，默认主题 |
| 极简线框 | 黑白瑞士排版，左侧大头像 + 信息表格 |
| 清雅海洋 | 全宽波浪头图 + 悬浮数据方块 + 横向信息流 |
| 日落暖橙 | 左窄右宽分栏，胶片颗粒与暖色渐变边框 |
| 暗夜霓虹 | 深色底霓虹描边，粘性侧栏 + 发光信息卡 |
| 纸质书卷 | 杂志开本排版，首字下沉 + 双栏正文 + 页脚版权栏 |
| 玻璃拟态 | 漂浮玻璃卡体，上下错位叠放 + 柔光光斑 |
| 艺术画框 | 画布式不对称构图，倾斜画框 + 编号信息牌 |
| 时尚杂志 | 大图海报封面，全出血人像 + 底部叠字标题 |
| 赛博终端 | 终端窗口交互，打字机行号 + 扫描线监控面板 |
| 樱花物语 | 粉樱渐变圆环头像，飘落花瓣 + 柔和卡片 |
| 新粗野 | 高饱和色块硬投影，贴纸式标签 + 硬边卡片 |

主题保存在账号上，访客打开时按账号设置的主题渲染；主题值不合法时回退到「经典卡片」。背景图与横幅会应用到全部主题，由各主题自行决定裁切方式。

## 个人中心

从顶栏头像下拉选「个人中心」进入，页面自上而下是头部形象区、主页配置、用户信息与许可证四块。

### 头部形象区

| 元素 | 操作 |
| --- | --- |
| 头像 | 点击头像选择图片，上传成功后立即替换 |
| 横幅 | 右上角上传按钮选择图片；已有横幅时可删除，恢复默认背景 |
| 昵称 | 展示当前昵称 |
| 角色与授权标签 | 角色显示管理员或用户；授权标签与许可证状态一致（有效 / 无效）；账号带会员标识时另显示 VIP 标签 |
| 修改密码 | 打开改密弹窗，需填写当前密码与新密码 |

### 主页配置

这一块决定别人看到你的公开主页长什么样：

| 区域 | 说明 |
| --- | --- |
| 主页背景图 | 上传或删除；未设置时显示「未设置背景图」占位 |
| 主页横幅 Banner | 上传或删除；未设置时显示「未设置横幅」占位 |
| 公共页主题 | 12 套主题卡片，卡片带缩略图与一句话设计说明，点击即切换并保存 |

背景图与横幅是两个独立字段，与头部形象区的横幅互不影响。

### 用户信息

信息卡展示用户 ID、昵称、邮箱、手机号、角色、状态、注册时间与最后登录时间，右上角有两个入口：

- **编辑信息**：打开编辑弹窗。
- **公开主页**：在新标签页打开 `/u/{用户ID}`；未设置用户 ID 时不可用，信息卡会提示「未设置（编辑后生成公开主页）」。

### 编辑资料

| 字段 | 规则 |
| --- | --- |
| 用户 ID | 必填，就是公开主页地址里的那一段，改动后旧链接失效 |
| 昵称 | 必填，最长 32 个字符 |
| 邮箱 | 必填，需符合邮箱格式 |
| 手机号 | 选填，公开主页仅展示脱敏号码 |
| 公开主页展示字段 | 多选：用户 ID、昵称、头像、邮箱、手机号（脱敏）、注册时间、最后登录时间、状态 |

展示字段有一条默认约定：**从未配置过**时展示除手机号外的全部字段；把勾选全部取消则公开主页不再展示任何资料。

## 收藏与阅读位置

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 收藏与收藏库 | 各媒体详情页的收藏按钮；列表侧栏的「模式」开关 | 小说详情页显示「收藏 / 已收藏」，未登录时提示「操作失败, 请确认已登录」；切到「收藏库」后列表只返回已收藏的条目 |
| 小说阅读进度 | 小说详情页的「继续阅读」与进度提示 | 登录后进度存服务端，游客存浏览器本地，详见[小说阅读](/docs/site/novel) |

:::note[没有独立的「观看记录」页]
当前前台不提供单独的观看记录、播放历史或个人收藏列表页。收藏通过详情页按钮维护，并按「收藏库」模式在各媒体列表里查看；阅读位置只在小说里提供续读入口。
:::
