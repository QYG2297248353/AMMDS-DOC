# 影视列表与详情

影视库是前台默认首屏：左侧是按封面排列的影视卡片，右侧是搜索、标签与库简介；点击任意卡片进入详情页，查看元数据、演职员、图片与磁力资源。

## 列表页结构

页面地址 `/home/media`，采用两栏布局：

| 区域 | 内容 |
| --- | --- |
| 左侧内容区 | 影视卡片网格、分页 |
| 右侧侧栏 | 搜索、中文优先、模式、搜索历史、热门标签、影视库简介 |

桌面宽屏每行 6 张卡片，随窗口变窄依次降为 4、3、2、1 列；当宽度不超过 1024px 时右侧侧栏整体隐藏。

## 检索与筛选

所有筛选都在右侧侧栏完成：

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 输入关键词后回车或点搜索按钮；支持标题、简介、识别码、演员姓名 |
| 中文优先 | 只影响标题展示，不改变查询条件；开启后显示中文标题字段，关闭时显示原标题 |
| 模式 | `全局库` / `收藏库`，切换后立即按当前关键词重新检索 |
| 搜索历史 | 最多保留 15 条，存在浏览器本地，点击可复用；再次点击当前关键词即取消搜索 |
| 标签 | 展示热门标签（最多 20 个），点击按标签筛选，再次点击取消；选中标签会清空关键词 |
| 标签搜索 | 在标签模块内按名称过滤候选标签，输入有 300ms 防抖 |

页面没有年份、类型、演员、系列、评分等独立筛选控件，也没有排序下拉框。列表默认按创建时间倒序；服务端检索时按“标签优先于系列、系列优先于关键词”的顺序应用条件，但前台只暴露关键词与标签两个入口。

:::note[关键词与标签互斥]
输入关键词会清空已选标签，选择标签会清空关键词；两者不会叠加成“同时满足”的条件。
:::

## 卡片字段

每张卡片自上而下展示：

- **封面**：优先高清封面，其次普通封面；无图或加载失败时显示“图像加载失败”占位。
- **悬浮标签**：发行日期、评分（10 分制）、以及后端标记的“可播放”标识，三者有值才显示。这里的“可播放”只是条目标记，不代表详情页能直接播放。
- **标题**：受“中文优先”开关控制；开启显示中文标题字段，关闭显示原标题。影视列表没有为缺失的中文标题做回退，中文标题为空时卡片标题会留白。
- **识别码**：以紫色小标签展示，可能有多枚。
- **演员**：以青色标签展示演员姓名，标签图标按角色文本包含“男 / 女”切换，无法判断时用人形问号。

## 分页与状态记忆

- 每页固定 20 条，分页条只显示总数，没有每页条数选择器。
- 进入详情时把当前页码与每页条数写入地址栏 query；从详情后退时可恢复原页。
- 搜索模式、关键词、中文优先、标签写入 `localStorage`，刷新后恢复。
- 页码同时写入 `sessionStorage`，地址栏没有 query 时用它兜底。
- 未登录访客受服务端限制：每页最多 30 条，页码由服务端随机选取，分页信息会被重置；登录后恢复正常分页。详见[前台站点导览](/docs/site/overview)。

## 详情页入口与鉴权

详情地址为 `/home/media/details/:id`。该路由声明 `requiresAuth: true`，未登录点击卡片会先跳到登录页，登录成功后再回到详情。列表页本身不要求登录。

:::warning[详情页没有播放器]
影视详情只展示元数据、演职员、图片、磁力与评论占位，没有播放器或“播放”按钮；卡片上的“可播放”标识也不改变这一点。视频文件与媒体服务器播放请使用对应的外部客户端。
:::

## 详情页信息区

详情页顶部以大标题展示原标题，中文标题另起一行并带“译文”标签。主图是 16:9 横版，优先级为高清背景图 → 背景图首图 → 封面首图。

| 信息项 | 说明 |
| --- | --- |
| 识别码 | 全部识别码，以标签展示 |
| 发行日期 | 原始日期文本 |
| 时长 | 分钟数 + “分钟” |
| 导演 | 多值标签 |
| 制作公司 | 多值标签 |
| 发行公司 | 多值标签 |
| 演员 | 姓名标签，图标按角色性别文本切换 |

信息区右侧信息栏底部排列三枚按钮：**订阅**、**收藏**、**分享**。订阅与收藏按当前状态切换图标与配色，操作成功后重新拉取详情以刷新状态；分享未登录时会弹出“需要登录”确认框。

:::note[信息区之外的字段]
语言、国家 / 地区、分级、系列等字段没有出现在前台信息区。想核对或补全这些元数据，请到后台[影视库](/docs/backend/media/movie)查看。
:::

## 评分与磁力提交

信息区下方左侧是评分：5 颗星按 10 分制折算，支持半星；分数按区间着色（8 分及以上绿色、4 分及以上琥珀色、其余红色）。右侧是磁力提交输入框，输入磁力链接后点“提交”，为空会提示“请输入磁力链接”。

## 扩展信息与图片

| 区块 | 内容 |
| --- | --- |
| 扩展信息 | 三个标签页：分类、标签、扩展信息键值表；无内容时显示对应空态 |
| 演员 | 头像 + 姓名 + 角色，横向滚动；演员库中存在该演员时可点击进入演员详情 |
| 封面图 | 2:3 海报墙，高清图置顶 |
| 背景图 | 16:9 图墙，高清图置顶 |
| 缩略图 | 16:9 图墙，高清图置顶 |
| 剧照 | 16:9 图墙 |

图片点击后可全屏预览，多图之间可切换。演员若只存在于影视条目的演员映射中、尚未进入演员库，点击会提示“该演员暂无详情”，不会跳转。

## 资源分享

“资源分享”卡片内的“磁力列表”表格展示名称、大小、分享日期与操作：

1. **推送下载**：当前版本点击只提示“敬请期待”。
2. **复制磁力**：复制该行磁力链接，成功或失败都有提示。
3. **举报资源**：当前版本点击只提示“敬请期待”。

磁力表为空时显示“暂无资源分享”。

## 同系列影视

详情页底部保留“同系列影视”卡片，但当前代码没有向该区块填充数据，因此始终显示“暂无同系列影视”。这不是筛选失败，也不代表该影视没有系列；系列聚合请在后台维护。

## 评论区

详情页包含“评论区”，但当前实现是前端本地占位：默认展示一条“AMMDS 官方 / 敬请期待”，发表评论只把内容插入当前页面列表，刷新即丢失，点赞与回复也未接后端。不要把它当作可用的社区功能。
