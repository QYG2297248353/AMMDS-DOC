# 剧集列表与详情

剧集库把连续剧、番剧、综艺等按“剧集”聚合，列表页展示封面、分区、连载状态与季集数量；详情页在同一页内展开全部季与集，便于查看结构而不是逐集播放。

## 列表页结构

页面地址 `/home/tvshow`，结构与影视库一致：

| 区域 | 内容 |
| --- | --- |
| 左侧内容区 | 剧集卡片网格、分页 |
| 右侧侧栏 | 搜索、中文优先、模式、搜索历史、热门标签、剧集库简介 |

宽屏每行 6 张卡片，窗口变窄后依次降为 4、3、2、1 列；宽度不超过 1024px 时侧栏隐藏。

## 检索与筛选

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 按剧名关键词检索，回车或点搜索按钮提交 |
| 中文优先 | 只影响标题展示；开启后优先中文名，缺失时回退原名 |
| 模式 | `全局库` / `收藏库`，切换后立即重新检索 |
| 搜索历史 | 最多 15 条，存在浏览器本地，可点击复用 |
| 标签 | 点击按标签筛选，再次点击取消；选中标签会清空关键词 |

页面没有分区、状态、年份、数据源等筛选控件，也没有排序控件。服务端列表默认按更新时间倒序；虽然公开接口支持 `tvMediaType` 参数，但前台页面没有传这个参数。

## 卡片字段

- **封面**：2:3 竖版，无图或加载失败显示“图像加载失败”。
- **悬浮标签**：首播年份、评分（10 分制），有值才显示。
- **标题**：受“中文优先”控制。
- **分区**：优先使用接口返回的分区名称，其次按内置映射显示番剧、日剧、韩剧、国剧、欧美剧、纪录片、综艺、其他。
- **连载状态**：`Continuing` 显示“连载中”，`Ended` 显示“已完结”。
- **季集数量**：形如“3 季 · 24 集”，数据来自剧集的季数 / 集数字段。
- **类型**：取前三个类型，用“ / ”连接。

## 分页与状态记忆

每页 20 条。进入详情时把页码与每页条数写入地址栏 query；搜索条件写入 `localStorage`，刷新后恢复；页码同时写入 `sessionStorage`。分页条没有每页条数选择器。

## 详情页

详情地址为 `/home/tvshow/details/:id`，要求登录。页面结构与影视详情相近：大标题为原名，中文名带“译文”标签；主图优先高清背景图，没有背景图时回退背景图或封面首图。

### 基本信息

| 信息项 | 说明 |
| --- | --- |
| 首播日期 | 缺失时显示“-” |
| 时长 | 分钟数 + “分钟” |
| 分区 | 中文分区名，未知 code 原样显示 |
| 数据源 | 数据源代码，缺失时“-” |
| 季数 | 优先数据源声明的总季数，其次实际入库季数 |
| 集数 | 优先数据源声明的总集数，其次已入库集数 |
| 状态 | 连载中 / 已完结 / 原值 |
| 类型 | 多值标签 |
| 制作公司 | 多值标签 |

信息区右侧同样是**订阅**、**收藏**、**分享**三枚按钮，状态与影视详情一致。分享未登录时会提示先登录。

### 评分与磁力

评分按 10 分制折算成 5 星，支持半星，按分数区间着色；存在评分人数时在分数后追加“评分人数 N”。右侧磁力提交框只负责提交链接，提交成功后清空输入框，不会在页面展示磁力列表。

### 扩展信息

“扩展信息”卡片用三个标签页组织：

- **类型**：全部类型标签。
- **标签**：全部标签。
- **扩展信息**：按“识别码 · 站点”、数据源、语言、国家 / 地区、排名、已入库集数、更新时间、导演、编剧逐行展开，空值不占行。

## 季与集结构

“季集列表”把全部季一次性渲染为可折叠面板，不再使用“一次只看一季”的切换：

1. 每个面板标题为季名或“第 N 季”；季号为 0 或标记为特别篇时统一显示“特别篇”。
2. 面板右侧显示“本季共 N 集”。
3. 面板内展示季海报、季首播日期与季简介。
4. 季内用表格列出集号、标题、首播日期、时长、评分、缩略图；标题优先中文名，缺失时回退原名。
5. 默认展开第一个“有集”的季；没有季时显示“暂无季集数据”。

## 剧集文件与播放入口

前台剧集详情**不提供播放**：

- 页面没有播放器、播放按钮或“播放”链接。
- 公开详情接口只返回元数据、季与集，集内不包含文件绑定，`episodeFiles` 恒为空列表，也不返回本地路径。
- 季集表只展示集号、标题、首播日期、时长、评分与缩略图。

因此不要把“季集表”理解为播放列表；剧集文件的管理与绑定在后台完成，见[剧集库](/docs/backend/media/tvshow)。

:::warning[与影视列表的差异]
影视列表卡片可能出现“可播放”标识，但剧集详情本身没有播放能力；两者都不在前台提供视频播放器。
:::

## 图片与同系列

| 区块 | 内容 |
| --- | --- |
| 封面图 | 2:3 海报墙，高清图置顶 |
| 背景图 | 16:9 图墙，高清图置顶 |
| 缩略图 | 16:9 图墙，高清图置顶 |
| Logo | 按横版比例留白展示 |
| 横幅 | 16:9 图墙 |

剧集实体没有“剧照”字段，因此页面没有剧照模块。“同系列剧集”卡片只保留空状态：后端目前没有剧集系列 / 分组模型，前台始终显示“暂无同系列剧集”。

## 评论区

评论区与影视详情共用同一组件，当前是前端本地占位：默认一条“AMMDS 官方 / 敬请期待”，提交只写入本地列表，刷新即丢失。点赞与回复提示“敬请期待”。
