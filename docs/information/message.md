# 系统消息与官方通告

消息中心集中展示 AMMDS 运行过程中产生的通知：后台任务的结果、站点认证的状态、分享申请与导入的进展，以及官方发布的公告。每条消息都带分类与等级，便于快速判断是否需要处理。

{/* truncate */}

## 消息来源

| 分类 | code | 典型内容 |
| --- | --- | --- |
| 系统通知 | `msg_notice_system` | 订阅下载结果、站点认证成功/失败、漫画整理进度、任务异常等 |
| 官方通知 | `msg_notice_official` | 官方账号发布的公告类消息 |
| 分享通知 | `msg_notice_share` | 分享导入申请、申请审批结果、导入结果 |

:::note[站内与站外]
本页只管理站内消息记录。需要把通知发到 Telegram、Bark、WebHook 或邮箱时，在「集成应用」中配置对应通知插件，例如 [Telegram](/docs/integration/notification/telegram)。
:::

## 列表与筛选

页面顶部提供两个筛选条件与「查询」按钮：

| 筛选项 | 可选值 |
| --- | --- |
| 通知类型 | 全部、系统通知、官方通知、分享通知 |
| 阅读状态 | 全部、已读、未读 |

清空筛选项会立即按剩余条件重新查询。列表默认每页 10 条，可切换每页数量；序号按分页偏移连续计算。

列表字段：

| 字段 | 说明 |
| --- | --- |
| 序号 | 当前页内的连续编号 |
| 类型 | 通知所属分类 |
| 等级 | 信息 / 成功 / 警告 / 错误 |
| 标题 | 消息标题，缺失时显示「通知」 |
| 内容 | 消息正文摘要 |
| 时间 | 发布时间 |
| 操作 | 标记已读、删除 |

## 消息等级

| 等级 | 界面样式 | 含义 |
| --- | --- | --- |
| 信息 | 蓝色标签 | 一般性提示，无需处理 |
| 成功 | 绿色标签 | 操作已正常完成 |
| 警告 | 橙色标签 | 可能存在问题，但不影响继续使用 |
| 错误 | 红色标签 | 操作失败或出现异常，需要处理 |

未识别的等级统一显示「未知」。

## 标记已读与删除

- 点击操作列的勾选按钮把该条消息标记为已读；已读消息的按钮为禁用状态，不会重复提交。
- 点击删除按钮移除该条消息，删除后不再出现在列表中。
- 当前版本只支持逐条操作，没有「全部已读」或「批量删除」入口。

## 与其它模块的联动

消息内容来自业务动作，排查时应回到对应模块：

| 消息内容 | 相关模块 |
| --- | --- |
| 分享申请、导入结果 | [分享链接](/docs/information/share) |
| 好友申请、互通消息 | [实例互通](/docs/information/interop) |
| 订阅下载成功/失败 | 订阅检索与下载器插件 |
| 站点认证成功/失败 | 系统设置中的站点认证 |

:::tip[找不到消息]
如果确认业务动作已执行却没有任何记录，先检查筛选条件是否停在了「未读」或某个单一类型；清空筛选后再查询一次。
:::
