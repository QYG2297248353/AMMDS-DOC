# 片商与厂牌

厂牌库以厂牌为中心管理作品归属：一个厂牌有自己的资料、图像、若干条**识别码规则**，以及按规则自动收纳进来的影视与剧集。本页说明厂牌怎么建、规则怎么配、作品怎么进来和出去。

{/* truncate */}

## 页面结构

进入 **媒体管理 → 厂牌库**：

| 区域 | 内容 |
| --- | --- |
| 操作栏 | 左侧「创建厂牌」「识别码归属测试」，右侧「搜索厂牌名称或别名」 |
| 卡片区 | 每个厂牌一张卡片，点击卡片打开详情 |

搜索框输入即过滤，清空后恢复全量列表。列表按作品总数倒序排列，作品多的厂牌排在前面。

### 卡片信息

| 元素 | 说明 |
| --- | --- |
| 图像 | 鼠标悬浮显示「更换图像」，点击可直接换图 |
| 名称 | 厂牌名，右侧带星标表示已标记为「重点关注」 |
| 类型标签 | 制作商 / 发行商 / 经纪公司 / 其他 |
| 标签 | 最多展示前 2 个，其余折叠为「+N」 |
| 统计 | 「N 部影视 · N 部剧集」，有规则时追加「N 条规则」 |
| 删除 | 卡片上的删除按钮 |

:::warning[删除厂牌的影响]
删除会同时移除该厂牌的规则与排除项，但**不修改任何影视或剧集元数据**，已写入作品里的厂牌名会保留。
:::

## 创建厂牌

点「创建厂牌」后填写：

| 字段 | 说明 |
| --- | --- |
| 厂牌名称 | 必填，需与影视元数据中的制作公司名保持一致，最长 100 字符 |
| 厂牌类型 | 制作商 / 发行商 / 经纪公司 / 其他 |
| 成立年份 | 1800–2200 的整数 |
| 国家 / 地区 | 如「日本」 |
| 官网 | 以 `https://` 开头，详情页可点击跳转 |
| 别名 | 多值，输入后回车 |
| 标签 | 多值，输入后回车 |
| 描述 | 厂牌简介，最多 500 字 |
| 厂牌图像 | 弹窗右侧上传，可点击更换 |

:::tip[名称必须与元数据一致]
厂牌与作品之间按名称做软关联，所以「厂牌名称」要和影视元数据里的制作公司名完全一致，否则统计里看不到那些作品。数据源写法不同时，用「别名」兜住差异。
:::

## 别名与归属规则

厂牌的作品来源有两条路：**手动添加**与**识别码规则自动收纳**。别名用于匹配，规则用于自动判定归属。

### 识别码规则

在厂牌详情 →「识别码规则」页签维护：

| 字段 | 说明 |
| --- | --- |
| 规则类型 | 识别码前缀 / 识别码精确 / 正则表达式 |
| 匹配表达式 | 按所选类型填写，最长 200 字符 |
| 命中后写入 | 制作公司 / 发行公司 / 制作 + 发行 |
| 优先级 | -9999～9999，数值用于多条规则同时命中时排序 |
| 启用 | 关闭后该规则不参与判定 |
| 说明 | 备注规则的依据，如「该厂牌拥有 SSIS 系列发行权」 |
| 保存后 | 可勾选「立即按规则收纳作品到影视元数据」 |

「预览命中数量」可以在不落库的情况下先看这条规则会命中多少作品，再决定是否保存。

### 归属判定与收纳

1. 保存影视条目时，系统会按**已启用**的规则自动把厂牌写入制作公司 / 发行公司。
2. 也可以在厂牌详情点「立即收纳作品」（规则页签里叫「立即收纳」）手动触发一次。
3. 规则命中收纳进来的作品，会在作品卡片上标注命中的规则名，方便回溯是哪条规则带进来的。
4. 把作品移出时，系统会记录一条**排除项**，避免下次自动收纳又把它拉回来。

:::note[删除规则不回滚]
删除识别码规则只影响后续判定，已经写入影视元数据的厂牌名不会被回滚。
:::

### 识别码归属测试

顶部「识别码归属测试」与规则页签内的测试框功能相同：输入车牌号（如 `SSIS-001`），返回命中的厂牌与对应表达式；未命中时提示「未命中任何厂牌规则」。调规则时先用它验证，比直接保存再看结果快。

## 厂牌详情

点击卡片打开详情抽屉，头部包含图像、名称、类型、重点关注星标、国家、成立年份、官网、描述、标签与别名，以及三项统计：**影视数、剧集数、识别码规则数**。下方三个页签：

### 作品

- 顶部单选「全部 / 影视 / 剧集」切换媒体类型，右侧可按「标题或识别码」搜索。
- 「添加作品」弹窗中按标题或识别码搜索影视，已在厂牌中的条目标注「已在厂牌」并禁用添加。
- 作品卡片展示类型角标、标题、识别码、年份、命中来源与命中规则，操作是「查看」（跳到对应影视或剧集编辑页）与「移出」。
- 底部按页翻页。

### 识别码规则

规则表格列出表达式与说明、启用开关、编辑与删除；上方有「添加规则」「立即收纳」，右上可测试识别码归属。

### 资料

可修改厂牌类型、成立年份、国家 / 地区、官网、别名、标签、描述与「重点关注」开关，保存后卡片与统计同步更新。

:::tip[重点关注]
「重点关注」只是标记，用于在卡片上显示星标；它不会改变作品收纳逻辑。
:::
