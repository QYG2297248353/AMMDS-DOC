# 剧集库

剧集库管理的是**已入库**的剧集元数据：一部剧对应多条季与集记录，每一集可以绑定一个或多个可播放文件。本页说明如何检索、导入、查看季集结构并维护文件绑定。

{/* truncate */}

## 页面结构

进入 **媒体管理 → 剧集库**：

| 区域 | 内容 |
| --- | --- |
| 剧集检索 | 标题、识别码、演员、类型（分区）、标签、状态，右侧「搜索」「重置」 |
| 快捷操作 | 「新建剧集」「搜索剧集」，勾选后出现「删除」；右侧「来源」下拉 |
| 数据表格 | 序号、封面、剧集信息、分区、来源、季 / 集、更新时间、操作 |

顶部检索里的「类型」对应后端的**分区**（`tvMediaType`），「来源」的数据源选项由后端枚举下发，不硬编码。

### 检索字段

| 字段 | 匹配方式 |
| --- | --- |
| 标题 | 匹配剧名、原名与中文名 |
| 识别码 | TMDB / Bangumi / IMDb 等站点 ID |
| 演员 | 按演员姓名匹配 |
| 类型 | 分区，取值为后端枚举 |
| 标签 | 多值，输入后回车 |
| 状态 | 连载中 / 已完结 |
| 来源 | 数据源，选「全部」提交空值表示不过滤 |

### 列表与行操作

「季 / 集」列展示「N 季」「N 集」两行。每行右侧提供**分享**、**详情**、**编辑**、**删除**。

:::warning[删除剧集的影响]
删除会同时移除该剧的季、集、文件绑定与季映射，但**不会删除磁盘上的视频文件**。批量删除前请确认勾选范围。
:::

## 搜索剧集并导入

「搜索剧集」用于手工补录单部剧：

1. 输入剧名关键词（如 `葬送的芙莉莲`），回车检索；生成的关键词会写入本地历史搜索，最多 20 条。
2. 候选卡片展示竖版海报、年份、数据源与**匹配分**（保留三位小数）。
3. 点「导入」弹出季号输入框：
   - 留空表示导入数据源的全部季；
   - `0` 表示特别篇；
   - 填写 `1`～`99` 只导入该季。
4. 导入成功后提示「导入成功，可在剧集详情中完善元数据与季集」。

:::note[导入的合并行为]
数据源中已存在相同站点 ID 时会**并入**现有剧集，而不是新建重复条目；导入只是入库，后续季集与文件仍需在详情页维护。
:::

## 剧集详情

在列表行点「详情」进入剧集详情页。页面顶部是**重新刮削**与**编辑元数据**两个按钮，主体自上而下为：

| 区块 | 内容 |
| --- | --- |
| 头部 | 海报、标题与原标题，标签展示年份、首播日期、状态、评分、评分人数、排名、单集时长、分级、语言、分区、来源 |
| 概要 | 类型、标签、制作公司、国家/地区、导演、编剧、站点 ID 与剧情简介 |
| 演员 | 姓名与角色两列 |
| 季列表 | 季号（特别篇单独标注）、季名、首播日期、本季集数（已入库 / 总数） |
| 集列表 | SxxExx、标题、首播日期、时长、评分、类型，以及「可播放文件」列 |
| 季映射 | 本地季号、数据源、数据源条目 ID、绑定方式、集号偏移、数据源集数、备注 |

### 季与集

- 季列表的「查看集」用于把下方集列表切换到该季，集列表上方还有一排快捷按钮（「全部季」与 `S1`、`S2`……）。
- 集列表按 `S{季}E{集}` 展示，点季按钮即可筛选。
- 「本季集数」列展示 `已入库 / 总数`，两值不一致说明还有集未入库。

### 剧集文件匹配

每一集在「可播放文件」列管理文件绑定：

1. 点「添加文件」打开「按路径添加文件」弹窗，弹窗顶部会提示目标「第 N 季 第 N 集」。
2. 填写**文件绝对路径**（必填，例如 `D:\Media\剧名\Season 1\S01E01.mkv`）。
3. 分段文件填**分段序号**，`CD1` 填 `1`，`CD2` 填 `2`。
4. 绑定成功后该文件出现在文件列表，标「可用 / 不可用」与来源。
5. 「解绑」只删除绑定关系，不删除磁盘文件。

:::tip[可用性标记]
文件旁的「可用 / 不可用」来自最近一次校验结果。把文件移走或改名后重新校验才会变为不可用，解绑与重新绑定都会刷新这一状态。
:::

### 季映射

季映射用于对接「一季一个条目」的数据源（如 Bangumi）：把本地第 N 季指向数据源的某个条目，并可用集号偏移换算集号。

1. 在「绑定季映射」表单填写本地季号、数据源、数据源条目 ID。
   - 条目 ID 可以是纯数字（如 `400602`），也可以直接粘贴条目链接。
2. 「绑定方式」选 `AUTO`（自动发现）或 `MANUAL`（手工指定）。
   - `MANUAL` 的行不会被自动发现覆盖。
3. 「集号偏移」换算规则为：**数据源集号 = 本地集号 + 偏移**。
4. 点「自动发现」会按数据源重新发现并更新映射，结果提示新增 / 更新条数。

:::note[自动发现没有结果]
提示「自动发现未返回任何季映射」通常有两种原因：数据源不支持关联条目，或任务配置里的 `tv_season_auto_discover` 已关闭。
:::

### 重新刮削

详情页的「重新刮削」需要选择数据源、数据源条目 ID 与季号（`0`～`99`）。刷新会把数据并入**当前这部剧**，不会新建出第二部剧。

## 编辑剧集

列表行的「编辑」与详情页的「编辑元数据」都进入剧集编辑页，可维护：

- **基本信息**：标题、原标题、中文标题、排序标题、展示标题、状态、评分、首播日期、年份、单集时长、分级、语言、国家/地区、分区、宣传语、大纲、简介与中文简介。
- **分类信息**：类型、标签（取自剧集标签库）。
- **制作信息**：制作公司、国家/地区、导演、编剧，以及 TMDB / Bangumi / TVDB / IMDb 四类站点 ID。
- **演员**：姓名与角色可增删。
- **系列与季集**：系列归属，以及季（季号、本季集数、季名、首播日期、季简介）与集（集号、绝对集号、标题、首播日期、时长、类型、评分等）的编辑。
- **图片**：封面与背景图，支持上传、删除与排序。

保存后回到剧集列表。

## 与扫描流程的分工

本页只维护**已入库**的剧集。扫描阶段产生的「待确认剧集 / 合并 / 确认边界」在 **任务管理 → 刮削入库 → 剧集入库** 处理，参见[刮削任务](/docs/task/scrape)。影视条目的维护方式见[影视库](/docs/media/movie)。
