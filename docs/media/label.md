# 标签库

标签库是全站类型与标签的唯一来源：影视、剧集、演员、漫画、小说五类内容在编辑页里能选到的候选集，都来自这里。本页说明它的三层结构和维护方式。

{/* truncate */}

## 三层结构

| 层级 | 含义 | 数量 |
| --- | --- | --- |
| 媒体类型 | 内容的大类，固定五种 | 5 |
| 分类 | 每个媒体类型下的一组标签；系统默认分类 + 用户自建分类 | 5 + N |
| 标签 | 具体词条，带别名、颜色与权重 | 不限 |

五个系统默认分类与对应的标签类型如下：

| 卡片标题 | 媒体类型 | 标签类型 |
| --- | --- | --- |
| 影视标签 | 影视 | `tag_movie` |
| 剧集标签 | 剧集 | `tag_tv` |
| 演员标签 | 演员 | `tag_actor` |
| 漫画标签 | 漫画 | `tag_comic` |
| 小说标签 | 小说 | `tag_novel` |

用户自建分类必须挂在某个媒体类型下，因此它和系统分类共用同一套媒体类型筛选。

## 页面结构

进入 **媒体管理 → 标签库**：

| 区域 | 内容 |
| --- | --- |
| 操作栏 | 左侧「创建分类」，右侧类型筛选下拉与「搜索标签或别名」 |
| 卡片区 | 每张卡片是一个分类，一行最多 4 个 |

顶部类型筛选切换后只保留该媒体类型的卡片；搜索框按标签名或别名过滤。

### 卡片

- 卡片标题是分类名，系统分类按「媒体类型 + 标签」命名（如「影视标签」）；标题旁徽标标注「系统」或「用户」。
- 右上角显示「共 N 个」，即该分类下的标签数量。
- 用户自建分类可以删除，删除后分类下的标签会**回落到系统默认分类**，不会丢标签。
- 卡片内是标签表格：标签名（按设定颜色着色）、「引用」值，以及编辑 / 删除两个操作。

## 维护标签

### 创建分类

点「创建分类」，填名称（最多 30 字）并选择媒体类型即可。分类只用于组织标签，不参与内容检索逻辑。

### 添加与编辑标签

卡片工具条右侧点「添加」，或在标签行点编辑图标：

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填，最长 50 字。整理时作为**主名称**写入 NFO |
| 别名 | 多值，输入后回车，可填多个 |
| 颜色 | 调色板 10 个预设色，也可直接填 HEX 值（默认 `#165dff`） |

:::note[别名的作用]
不同数据源返回同一概念的写法可能不同（中英日、简繁、缩写），把差异写进「别名」，匹配时按别名识别，最终写入 NFO 时仍以主名称为准。
:::

:::warning[删除标签的边界]
删除标签只从标签库里移除词条，**不影响已保存的元数据**：影视、演员等条目里已经写入的类型与标签文本会保留，只是之后不能再从候选里选到它。
:::

## 权重与「引用」

每个标签有一个权重值，卡片表格里以「引用」列展示：

- 标签每被命中一次，权重加 1；
- 系统会定期衰减，每次最多降 10%（向下取整），且**永不低于 1**；
- 因此它是一个热度指标，可以理解成「被引用的近似次数」，不是精确的作品计数。

排序与展示用它来把常用标签排在前面，便于在编辑页快速命中。

## 检索与引用

标签库本身提供两种检索：按媒体类型筛卡片、按标签名或别名搜索。日常使用中还有一个更常见的入口——各内容编辑页的标签下拉：

| 编辑页 | 检索的标签类型 |
| --- | --- |
| 影视高级编辑 → 类型 / 标签 | 影视标签 |
| 剧集编辑 → 类型 / 标签 | 剧集标签 |
| 演员详情 → 标签 / 风格 / 特征 | 演员标签 |
| 漫画、小说编辑 | 各自的标签类型 |

这些下拉统一检索标签库（系统分类 + 用户自建分类都可见），并支持直接输入新词条：输入库里没有的值会作为新标签一起提交。

:::tip[统一维护的好处]
在任一编辑页新建的标签会回到标签库对应的分类里，下次在任何条目上都能选到；想批量整理同义词，改这里的别名单次即可覆盖所有引用方。
:::
