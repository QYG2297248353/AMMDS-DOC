# 系列库

系列库把多部作品聚合成一个可浏览的整体：一个系列有自己的名称、描述与封面，并维护成员作品的顺序与归属。本页说明如何建系列、往系列里放作品。

{/* truncate */}

## 列表与检索

进入 **媒体管理 → 系列库**：

| 区域 | 内容 |
| --- | --- |
| 系列检索 | 关键字（系列名称 / 描述）、作品识别码 |
| 快捷操作 | 「新建系列」，勾选后出现「删除」 |
| 数据表格 | 系列、操作 |

「系列」列是信息主体：左侧封面，右侧系列名称（可点击进详情）、描述与「N 部作品」标签。「操作」列提供**详情**、**分享**、**编辑**、**删除**。

检索框里的「作品识别码」用于反查系列：填一个番号即可找到包含该作品的系列。

### 新建与编辑

新建与编辑共用同一个弹窗，字段只有三项：

| 字段 | 说明 |
| --- | --- |
| 封面 | 点击或拖拽上传图片，也可删除后重传 |
| 系列名称 | 必填 |
| 系列描述 | 可选 |

:::note[封面规格]
封面上传只接受图片，大小上限 10 MB；上传后以竖版缩略图展示。
:::

## 系列详情

在列表行点「详情」或点系列名称进入详情页：

- 顶部展示系列名称与「N 部作品」，右侧是**编辑**与**分享**。
- 左侧是封面与描述等信息。
- 右侧是作品区工具条与作品表格：**添加作品**、**批量导入**、勾选后出现的**移出系列**，以及「按作品名称筛选」搜索框。
- 表格每行展示序号、作品（封面 + 标题 + 识别码 + 发行日期）与操作（查看、移出）。点「查看」跳到该影视的高级编辑页。

### 添加作品

1. 点「添加作品」打开弹窗。
2. 在「搜索媒体库作品」输入框按标题搜索影视库。
3. 勾选一个或多个作品，点「添加选中（N）」。
4. 完成后统计提示成功添加的作品数。

### 批量导入

「批量导入」按**识别码**批量放入作品，适合一次整理整个系列：

1. 在文本框中粘贴识别码，支持逗号、换行、空格、分号分隔，例如：

   ```
   SSIS-001, IPX-002
   MIDE-003
   ABP-004
   ```

2. 点「开始导入」。
3. 已在媒体库中的作品直接加入系列；不在库中的会尝试在线搜索导入。
4. 导入结果列出成功数量，失败项会给出「识别码」与「失败原因」。

:::warning[在线导入的依赖]
批量导入里「不在库中就去在线搜索」的这一步依赖已启用的元数据源。元数据源未配置或不可达时，这些识别码会以失败原因的形式返回，需要先在集成里配好数据源。参见[元数据源](/docs/integration/metadata/metatube)。
:::

### 移出系列

单条用行内的删除按钮，批量用勾选后的「移出系列」，都会二次确认。移出只解除作品与系列的关联，不删除影视条目本身。

## 与影视「系列」字段的关系

影视高级编辑页里也有「系列信息」分组，用来记录该作品所属的系列名称与系列内描述。这块信息属于**影视元数据**，与系列库中的系列实体是两处独立数据：

| 数据 | 维护位置 | 用途 |
| --- | --- | --- |
| 影视的系列字段 | 影视库 → 高级编辑 → 系列信息 | 写入单条影视的元数据与 NFO |
| 系列实体 | 系列库 → 系列详情 | 聚合作品、生成系列页与系列分享 |

因此把作品放进系列库需要显式「添加作品」或「批量导入」，不会因为影视元数据里填了系列名就自动归属。
