# 升级说明

如果你正在用 1.x 版本，打算换到 2.x，请先停下来看完这一页，再决定怎么动。**v1 和 v2 的数据并不互通**，直接换程序不会把旧资料带过去，操作不当还可能让旧数据看起来「丢了」。

:::warning[先记住三句话]
1. v1 和 v2 **不互通**，直接覆盖升级是不可以的。
2. 不建议强制升级，先评估值不值得。
3. 目前可行的办法是**从 v1 导出资料，再到 v2 导入**；更省心的做法是**装一套全新的 v2，从头来过**。
:::

## 为什么不能直接升级

v2 对数据存储和内部结构做了重新设计，v1 的数据库文件拿到 v2 里读不了，反过来也一样。这不是「升级一下就能兼容」的关系，而是两套独立的系统。

所以下面这些做法都**不行**：

- 把 v1 的 `db/`、`data/` 目录原样挂给 v2 启动。
- 用 v2 的程序文件覆盖 v1 的安装目录，指望它接着用旧数据。
- 在同一套数据目录里反复换版本启动，试图「碰运气」。

这样做的结果通常是 v2 读不懂旧数据、重新初始化一套空的，或者各种报错。影片文件本身不会丢（它们只是硬盘上的普通文件），但整理好的资料会读不出来。

## 两条可行路线

| 路线 | 适合谁 | 大概要做的事 |
| --- | --- | --- |
| 导出 → 导入 | v1 里已经整理了大量资料、条目多到不想重新刮削的人 | 在 v1 导出备份包，装好 v2 后把备份包导回去 |
| 从头来过 | 资料不多、或者想借换版机会重新整理一遍的人 | 全新安装 v2，重新做一次初始设置，让程序重新识别和刮削 |

### 路线一：导出导入

这是目前唯一能把 v1 的资料带进 v2 的方式，分三步：

1. **在 v1 里导出**。进入 v1 的备份与恢复页面，把影视、演员、漫画、小说各类资料分别导出成备份包，需要图片的话勾上「同时导出图像文件」。具体操作见[备份与恢复](./backend/system/backup-restore.md)。
2. **全新安装 v2**。不要复用 v1 的数据目录，按[先选一种安装方式](./getting-started/overview.md)正常安装，走完第一次打开的初始设置。
3. **在 v2 里导入**。进入 v2 的备份与恢复页面，把第 1 步导出的备份包逐个导入。

导入前请留意：

- 导入只搬**资料**（文字和图片），不搬系统配置、插件密钥、下载器和媒体服务器的连接设置，这些要在 v2 里重新配一遍。
- 导入完成后，建议跑一次扫描和刮削，把文件信息、任务记录这类搬不过来的内容补齐。
- v1 的备份包格式和 v2 的校验规则以[备份与恢复](./backend/system/backup-restore.md)页面为准，导入被拒绝时先用「解析预览」看具体原因。

### 路线二：从头来过（更推荐）

坦白说，对多数人这条路线**更省心**：

- 不用关心备份包格式、校验规则、图片路径这些细节。
- v2 的识别和刮削比 v1 有进步，重新跑一遍的效果通常比旧资料搬过去更好。
- 配置直接按 v2 的方式来，不用先学 v1 再学 v2。

做法很简单：装一套全新的 v2，把影片目录指过去，让程序重新扫描、识别、刮削。影片文件不用动，搬的只是「程序」不是「文件」。

如果 v1 的资料数量实在太大、重新刮削代价太高，再走路线一。

## 无论选哪条，都先备份

升级涉及换版本，动手前先把 v1 的 `db/` 和 `data/` 完整复制一份留底。这样万一导入过程出问题，旧环境随时可以退回去接着用，不会两头落空。

旧实例建议**保留到 v2 一切正常之后**再卸载，下线前记得在「个人信息 → 许可证」里停用在线许可证，把名额让给新实例，见[许可证与水印](./faq.md#许可证与水印)。

## 非 Docker 安装：装 2.0 之前先处理数据目录

Docker 的数据在挂载目录里，换镜像重建容器不受影响。但**安装包、二进制、NAS 应用包这些方式不一样**：数据目录就在程序目录旁边，卸载旧版再装新版时，数据目录可能被一并清掉。所以装 2.0 之前，建议先把数据目录**清理或备份走**：

- 走「导出导入」路线的：确认备份包都下载好了，再动旧环境。
- 走「从头来过」路线的：数据不要了，也建议先把 `db/` 和 `data/` 复制一份留底，免得反悔时两手空空。

以 Windows 安装包为例，顺序是：

1. **停止服务**：右键托盘图标，停止 AMMDS。
2. **找到数据目录**：右键托盘图标里的「查看日志」或数据目录入口，能顺藤摸瓜找到数据目录的位置。
3. **把数据目录挪走**：整个复制到程序目录之外的地方（比如另一个盘），这一步就是上面说的备份。
4. **卸载旧版**：走系统的卸载流程。
5. **安装新版**：装 2.0，按全新安装走一遍初始化。

其他安装器（NAS 应用包等）基本同理：**先停服务、把数据挪出去、再卸载**。各家卸载器的行为不一样，有的会自己把数据目录删掉，有的卸载时会问你要不要保留数据——不管哪种，都别把宝押在卸载器的提示上，提前手动挪走最稳妥。
