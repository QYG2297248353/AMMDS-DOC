# 项目简介

AMMDS 是一个**装在你自己设备上的影片资料柜**。它把你硬盘里一堆名字乱七八糟的视频，认出来是哪部片子，补上封面、简介、演员和标签，整理成一个能翻、能搜、能长期维护的媒体库。

所有资料都存在你自己的机器上，不需要注册云端账号。

:::warning[使用前提]
本软件为离线产品，数据由用户自己录入与维护。请遵守你所在地区的法律法规，不要在中国境内推广本产品；需要交流时请使用缩写 `AMMDS`。
:::

:::note[关于联网]
程序本身可以离线打开，但「自动补资料」「找资源」「推送消息」这几件事需要能访问外网。开启任一外部服务，就等于同意程序按你的设置去访问那个网站。
:::

## 它能帮你做什么

| 你遇到的麻烦 | AMMDS 怎么帮你 |
| --- | --- |
| 文件名乱，同一部片子有好几种写法 | 按编号认片子，把不同写法归到同一条记录 |
| 一张张找封面、抄简介太累 | 从资料网站自动补齐封面、简介、演员、标签 |
| 想在电视上看到整齐的海报墙 | 把整理好的资料同步给 Jellyfin、Emby 这类媒体服务器（专门负责播放影片、展示海报墙的软件） |
| 找资源、下载、入库分了好几个软件 | 搜索、订阅、推送到下载器、自动入库，一条线串起来 |
| 漫画、小说也想一起管 | 内置阅读器，记阅读进度 |
| 跑久了不知道哪里出问题 | 任务记录、运行日志、系统检查、网络检查都有现成页面，打开就能看 |

## 它不做什么

说清楚边界，比多夸几句更有用：

- **它不替你准备影片文件**。文件得你自己放在硬盘里，它只负责识别和整理。
- **它不是播放器**。想看电视上播放，还是要配 Jellyfin、Emby 这类播放器。
- **它不会把你的文件上传到别人的服务器**。资料都存在本机；只有你主动开启资料网站、通知推送等外部服务时，才会按设置访问那些网站。
- **文档只写已经做好的功能**。如果你在界面上找不到文档提到的按钮，先看看自己用的版本号对不对。

## 适合谁

**比较适合**：已经有一批影片 / 漫画文件、想长期整理、愿意花十几分钟做第一次设置的人。

**可能不适合**：只想找个播放器直接点开看、或者完全不想配置任何东西的人。第一次使用需要选安装方式、登录、告诉程序文件放在哪，这几步省不掉。

## 遇到看不懂的词

下面这些词在文档里会反复出现，都不难，看一眼就明白：

> **刮削**：程序自动去资料网站查这部片子的封面、简介、演员，并填回来。

> **番号 / 编号**：影片的识别编号，通常写在文件名里，程序靠它认片子。

> **媒体库**：整理好之后，你能翻、能搜的那一份影片清单。

> **设置项**：页面上要你填或要你打开的开关，每个都有说明。

完整的词表在[名词说明](./glossary.md)，凡是涉及填写内容的页面，也都会附一张「设置项说明」表。
