# TheTVDB

TheTVDB 主要提供剧集（含季与集）元数据，同一套检索接口也能查询影视。v4 接口全部需要先用 API 密钥登录换取 JWT，因此本插件必须配置有效密钥。

{/* truncate */}

## 打开方式

进入 **集成应用 → 元数据 → TheTVDB**。页面包含「配置信息」「连接测试」「剧集 / 影视检索」与详情面板。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `tvdb_enabled` | 启用状态 | 布尔 | `false` | 插件总开关，开启后才参与刮削 |
| `tvdb_service_url` | 服务地址 | 字符串 | `https://api4.thetvdb.com` | v4 基地址，写不写 `/v4` 都可，插件会统一归一化 |
| `tvdb_api_key` | API 密钥 | 字符串 | 空 | 必填；未配置时插件视为不可用 |
| `tvdb_pin` | 订阅 PIN (可选) | 字符串 | 空 | 仅「用户支持型」密钥需要，留空时不下发该字段 |
| `tvdb_language` | 语言 | 字符串 | `zho` | 三字母语言码，影响标题、简介与分级 |
| `tvdb_tv_search` | 剧集搜索 | 布尔 | `false` | 控制是否参与剧集检索扇出 |
| `tvdb_request_interval_ms` | 请求间隔 (毫秒) | 数字 | `1000` | 全进程共用的最小请求间隔 |

:::note[服务地址为什么没有 /v4]
插件在拼接登录与业务接口时会补 `/v4`，并对带 `/v4` 的地址做归一化。填 `https://api4.thetvdb.com` 或 `https://api4.thetvdb.com/v4` 都能工作。
:::

## 语言与限速

- 语言使用 **三字母码**：`zho` 简体中文、`eng` 英语、`jpn` 日语。填错不会报错，只会取不到对应翻译而回退原文。
- `tvdb_request_interval_ms` 约束的是同一进程内发往 TheTVDB 的请求；等待有上限（5 秒），不会无限阻塞其它线程。
- 登录得到的 JWT 由后端在内存中缓存，不写入数据库，因此没有 Token 配置项；修改密钥后重新校验即可。

## 连接测试

| 按钮 | 检查内容 |
| --- | --- |
| 测试连通性 | 请求 `POST /v4/login`，收到任意 HTTP 响应即视为网络可达 |
| 校验 API 密钥 | 用当前密钥执行登录，判断密钥是否有效 |

:::warning[两件事要分开看]
「测试连通性」通过只代表网络能到 TheTVDB；密钥无效时仍会登录失败。若密钥校验报错，请检查密钥是否复制完整、是否需要 `tvdb_pin`，以及该密钥是否已被停用。
:::

## 检索与导入

1. 选择检索类型：**剧集**或**影视**。
2. 可填写关键词、首播年份与返回条数（默认 10，服务端单页上限 50），点击「检索」。
3. 结果卡片显示封面、主语言、状态；点「查看详情」加载扩展详情，点「导入」直接入库。

详情面板按类型展示不同内容：

| 类型 | 标签页 / 内容 |
| --- | --- |
| 剧集 | 基本信息、角色与演职员、季列表、集列表 |
| 影视 | 基本信息（海报、描述、类型、制作公司、简介） |

导入剧集时可指定季号，**留空表示全季导入**：后端会逐季拉取集列表并合并，摘要中的集数是全剧集数。影视导入写入影视库，同一部影视重复导入会更新而不是新增。

:::tip[剧集搜索开关]
`tvdb_tv_search` 只影响剧集是否参与检索扇出。影视没有独立开关，只要「启用状态」打开、服务地址可用且 API 密钥有效，就会参与影视检索。
:::
