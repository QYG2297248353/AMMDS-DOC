# TheJavDB

TheJavDB 以番号为入口返回影片标题、发行信息、演员、分类与示例图，适合作为番号类影片的补充数据源。接入前不需要申请密钥，只要服务地址可达。

{/* truncate */}

## 打开方式

进入 **集成应用 → 元数据 → TheJavDB**。页面包含「配置信息」「番号检索」「连接测试」。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `thejavdb_enabled` | 启用状态 | 布尔 | `false` | 插件总开关 |
| `thejavdb_server_url` | 服务地址 | 字符串 | `https://api.thejavdb.net` | TheJavDB API 地址 |
| `thejavdb_video_search` | 影视检索 | 布尔 | `false` | 开启后才参与影片元数据检索与自动刮削 |

:::note[服务地址]
如果使用自建或镜像服务，把 `thejavdb_server_url` 改为对应地址并保存。地址需带 `http(s)://`，不要附加多余路径。
:::

## 番号检索

1. 在输入框填写车牌号，例如 `SSIS-001`。
2. 点击「检索」或按回车。
3. 命中后页面展示封面、车牌号、发行日期、时长、分类标签，以及制作公司、标签、系列、导演、演员与来源链接。
4. 有简介与示例图时会继续展示；示例图可点击进入全屏预览。

:::tip[检索测试与自动刮削是两条路径]
「番号检索」直接调用数据源，用于验证地址与数据是否正常，不受「影视检索」开关限制。但要让 TheJavDB 参与自动刮削，必须打开「影视检索」并保存。
:::

## 检索结果字段

命中后按数据源实际返回展示，缺失字段会自动省略：

| 字段 | 说明 |
| --- | --- |
| 封面 | 竖版海报，点击可全屏预览 |
| 车牌号 | 归一后的番号，如 `SSIS-001` |
| 标题 | 影片标题 |
| 发行日期 / 时长 | 发行时间与片长（分钟） |
| 分类标签 | 类型标签列表 |
| 制作公司 / 标签 / 系列 | 厂牌与所属系列信息 |
| 导演 / 演员 | 导演与演员列表 |
| 来源 | 原站详情页链接 |
| 简介 / 预览图 | 剧情简介与示例图 |

检索结果只用于核对，不会自动写库；需要入库时请在刮削任务中由识别规则触发。

## 连接测试

点击「测试连接」对 `thejavdb_server_url` 做健康检查。成功仅说明服务可达；若检索仍失败，请检查返回内容是否为空或站点是否限制了请求频率。

## 注意事项

- TheJavDB 只按番号检索，关键词需要能归一为番号；无法识别番号的文件不会命中。
- 该页面没有导入按钮，检索结果用于核对数据；自动入库发生在[刮削任务](/docs/backend/task/scrape)中。
- 与其他元数据源同时启用时，最终采用哪一条结果由刮削与识别规则决定。
