# M-Team DMM 元数据

M-Team 的 DMM 元数据能力挂在「站点资源 → M-Team」页面内。开启「元数据检索」后，M-Team 的 DMM 接口会参与在线聚合搜索、刮削识别与手动搜索测试，并支持把 DMM 结果导入影视库。

{/* truncate */}

## 打开方式

进入 **集成应用 → 站点资源 → M-Team**。除常规的「配置信息」「连接测试」外，页面底部还有「搜索测试」。M-Team 同时是 PT 站点，下载、辅种等站点能力见 [M-Team](/docs/integration/indexer/m-team)。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `m_team_enabled` | 启用状态 | 布尔 | `false` | M-Team 插件总开关 |
| `m_team_api_url` | 服务地址 | 字符串 | `https://api.m-team.io/api` | M-Team API 基地址 |
| `m_team_passkey` | 密钥 (PassKey) | 字符串 | 空 | 用于构造下载链接 |
| `m_team_token` | 存取令牌 (控制台 >>> 实验室) | 字符串 | 空 | 在站点控制台「实验室」获取 |
| `m_team_authorization` | 临时授权码 (请求头 >>> Authorization) | 字符串 | 空 | 作为请求头 `Authorization` 的值提交 |
| `m_team_account_protection` | 账户保护通知 | 布尔 | `false` | 定时检查登录状态并推送提醒 |
| `m_team_metadata_search` | 元数据检索 | 布尔 | `false` | 开启后 DMM 接口参与元数据检索；关闭时仅保留站点资源检索 |

:::warning[两个开关都要开]
只打开「启用状态」不会让 DMM 参与检索。必须同时打开「元数据检索」并保存，否则搜索测试会直接返回「请先在 M-Team 集成配置中开启「元数据检索」」。
:::

:::note[账号保护]
M-Team 长期不登录可能被站点注销，后端说明为 40 天未登录将封号处理。打开「账户保护通知」后，后台会定时检查登录状态并推送提醒，建议长期挂机的实例开启。
:::

## 连接测试

点击「测试连接」验证 M-Team API 是否可达。该测试只检查连通性，不校验 PassKey、Token 或 Authorization；搜索测试成功才说明元数据链路可用。

## 搜索测试

在「搜索测试」卡片右上角选择检索类型、输入关键词，点击「搜索」：

| 检索类型 | 检索对象 | 说明 |
| --- | --- | --- |
| DMM 元数据 | 番号或标题关键词 | 返回统一影视模型，可直接导入影视库 |
| 女优 / 企划 | 女优名或企划名 | 返回关联作品数、浏览量等信息 |
| 合集 | 合集标题关键词 | 返回合集关联作品数与类型 |
| 关键词 | 标签 / 关键词 | 返回关键词字典条目与关联数量 |

结果以表格展示「封面、ID、标题、番号、信息、操作」，顶部提示本次命中条数与耗时。点击任意一行打开「搜索测试详情」抽屉，也可以点行内的「详情」。

### DMM 元数据详情

抽屉展示封面、标题、番号、发行日期、时长、评分、DMM 详情页链接，以及制作商、厂牌、系列、导演、收录时间等字段，并单独列出女优、类型 / 关键词、简介与剧照。底部「导入影视库」按番号写入本地库。

### 女优 / 企划与合集详情

- 女优 / 企划：头像、名称、关联作品数、浏览量，可展开「资料」，并展示女优标签、主题标签与关联种子列表。
- 合集：标题、关联作品数、浏览量、类型与备注，展示女优标签、主题标签与合集种子列表。
- 两类详情中的种子列表都支持按种子绑定的 DMM 番号直接导入影视库。

### 关键词详情

关键词接口没有独立详情，抽屉直接展示检索结果中的「关键词」与「信息」字段。

:::tip[导入按钮的出现条件]
表格行内的「导入」只在检索类型为「DMM 元数据」且该行有番号时出现；其他类型请进入详情，在种子列表中按番号导入。导入成功后提示本地生成的影视编号。
:::

## 检索不到结果时

| 现象 | 检查 |
| --- | --- |
| 提示先开启「元数据检索」 | 打开开关并「保存配置」 |
| 连接测试成功但搜索为空 | 关键词是否为 DMM 支持的番号；换标题关键词重试 |
| 只有部分类型有结果 | 女优 / 企划、合集、关键词是独立接口，空结果不代表 DMM 元数据不可用 |
| 导入失败 | 该行缺少可识别番号，或 DMM 元数据中查不到对应作品 |
