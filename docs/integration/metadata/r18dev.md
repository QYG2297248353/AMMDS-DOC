# R18.dev

R18.dev 既提供在线 API，也提供可离线导入的 SQL 数据包。AMMDS 支持在线检索与本地库检索两种模式，适合在无外网或需要稳定查询的场景下使用离线数据。

{/* truncate */}

## 打开方式

进入 **集成应用 → 元数据 → R18.dev**。页面包含「配置信息」「数据统计」「数据导入」「番号检索」「连接测试」。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `r18dev_enabled` | 启用状态 | 布尔 | `false` | 插件总开关 |
| `r18dev_server_url` | 服务地址 | 字符串 | `https://r18.dev` | 在线 API 基地址 |
| `r18dev_video_search` | 影视检索 | 布尔 | `false` | 开启后才参与影视元数据检索与自动刮削 |
| `r18dev_online_search` | 在线检索 | 布尔 | `false` | 刮削时优先调用在线 API；关闭则只查本地库 |

:::note[本地库与在线数据是两套来源]
在线检索依赖 `r18dev_server_url` 可达；离线检索只查已导入的本地表。两者可以同时使用，是否优先在线由「在线检索」决定。
:::

## 数据导入

想让离线检索有数据，先导入官方数据包：

1. 点「下载页面」或「获取最新数据包」跳转 R18.dev 的 dump 页面。
2. 把 `.sql`、`.sql.gz` 或 `.sql.zip` 文件拖入上传区，或点击上传区选择文件。
3. 确认文件名与大小后点「开始导入」；上传过程可点「取消上传」。
4. 上传成功后后端在后台导入，页面提示「文件上传成功，正在后台导入数据...」。

:::warning[导入耗时与磁盘]
数据包解压与写库会占用较多 CPU、磁盘与数据库连接，建议在业务低峰执行；导入进度写入系统日志，导入期间不要重复上传同一文件。
:::

## 数据统计

「数据统计」卡片展示本地库中各表的记录数：影片、演员（女）、演员（男）、分类、系列、制作商、导演、标签、作者，并给出快照时间、导入文件名与相对上次导入的增量。点「刷新」重新统计；首次导入时没有对比数据。

## 番号检索

检索区支持两种模式：

| 模式 | 行为 |
| --- | --- |
| 在线检索 | 先调用在线 API，未命中再搜索本地数据库 |
| 离线检索 | 只搜索本地数据库，不发起外部请求 |

输入车牌号（如 `SSIS-001`）后点「检索」，结果展示封面、番号、发行日期、时长、女优、男优、导演、分类、制作商、标签、系列、作者、预告片、简介与预览图。

:::tip[页面检索与刮削开关]
页面上的「在线检索 / 离线检索」是本次请求的即时选择，不受 `r18dev_online_search` 限制；该开关决定的是自动刮削时是否优先走在线 API。要让 R18.dev 参与刮削，还需要打开「影视检索」。
:::

## 连接测试

点击「测试连接」检查 `r18dev_server_url` 是否可达。使用纯离线模式时，即使在线地址不可达，本地检索仍可工作。
