# 麻豆

麻豆（MaDou）数据源通过官方 API 分页拉取影视与演员数据，写入本地库。页面不提供关键词检索，而是以「同步」方式做整批采集。

{/* truncate */}

## 打开方式

进入 **集成应用 → 元数据 → 麻豆**。页面顶部有服务公告，下面依次是「配置信息」与「连接测试」。

:::warning[服务公告]
页面顶部显示「自 2026年4月3日 起, 我们有缘江湖再见🪁」，表示该数据源已停止对外服务。配置与采集入口仍然保留，但接口可能不再返回数据；是否继续启用请自行判断。
:::

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `madou_enabled` | 启用状态 | 布尔 | `false` | 插件总开关 |
| `madou_server_url` | 服务地址 | 字符串 | `https://api.modelmediaasia.com` | 麻豆 API 地址 |
| `madou_movie_collection` | 影视采集 | 布尔 | `false` | 允许手动触发影视同步 |
| `madou_actor_collection` | 演员采集 | 布尔 | `false` | 允许手动触发演员同步 |

:::note[采集开关只控制手动同步]
「影视采集」「演员采集」是同步任务的前置条件。只打开「启用状态」时，点击同步按钮会被拒绝并提示先启用对应采集功能。
:::

## 手动采集

「连接测试」卡片右上角有三个按钮：

| 按钮 | 行为 |
| --- | --- |
| 同步影视 | 以异步任务分页拉取影视列表并按发布时间排序入库 |
| 同步演员 | 以异步任务分页拉取演员资料入库 |
| 测试连接 | 用当前表单中的服务地址做健康检查 |

同步任务提交后立即返回「同步任务已提交」，实际采集在后台执行。同一类同步正在运行时再次点击会被拒绝，提示「同步进行中，请勿频繁操作」；后端还会用 3 小时的缓存标记兜底，避免重复触发。

:::tip[先保存再测试]
「测试连接」使用的是表单里当前填写的地址。修改地址后请先「保存配置」，再做连接测试与同步，避免测试值与实际运行值不一致。
:::

## 采集内容

- 影视同步调用 `/api/v2/videos`，按 `published_at` 排序分页拉取。
- 演员同步调用 `/api/v2/models`，分页拉取演员资料。
- 两类任务互相独立，可以只开其中一个；采集结果直接写入本地影视库与演员库，不需要再手动导入。
