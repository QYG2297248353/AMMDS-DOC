# 同步到电视上看

AMMDS 不是播放器，它只负责整理资料。想在电视上看到整齐的海报墙，就把 Jellyfin 或 Emby 接进来，让整理好的资料同步过去。

> **媒体服务器 / 播放器**：装在电视、盒子或电脑上的播放软件，例如 Jellyfin、Emby。它负责播放影片并展示海报墙。

> **API 密钥**：一串由播放软件生成的字符串，相当于一把专用钥匙。谁拿到它，谁就能按这个软件的权限读写资料。

> **绑定**：在本机影片与播放器里的影片之间建立对应关系，建立之后两边才能互相同步。

## 先选一个

Jellyfin 和 Emby 同源，配置项和能力高度相似。**两个可以同时启用**，播放统计会按各自绑定的用户分别读取后再合并。只用一个也完全够用。

| 对比 | Jellyfin | Emby |
| --- | --- | --- |
| 入口 | 集成应用 → 媒体服务器 → Jellyfin | 集成应用 → 媒体服务器 → Emby |
| 连接方式 | 用 API 密钥连上播放器 | 用 API 密钥连上播放器 |
| 默认服务地址 | `http://127.0.0.1:8096` | `http://127.0.0.1:8096` |
| 密钥获取路径 | 控制台 → API 密钥（部分版本在「高级」下） | 设置 → 高级 → API 密钥 |
| 管理入口 | 工具箱 → 媒体服务器 → 库管理 / 影视库 / 演员库 | 同上 |

## 通用三步

1. 在播放器里生成一枚 API 密钥（名称建议写 `AMMDS`，方便日后单独吊销）。
2. 回到 AMMDS 的插件页，填好服务地址与密钥，**保存**。
3. 刷新页面等系统拉取用户列表，选好「绑定用户」再保存，然后点「测试连接」。

:::tip[给它单独建一枚密钥]
不要复用管理员日常使用的密钥。单独建一枚，出问题可以只吊销这一枚。
:::

## Jellyfin

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 关闭后所有同步操作都会提示「请先启用 JellyFin 插件」 |
| 服务地址 | 默认 `http://127.0.0.1:8096`；容器部署请用宿主地址或服务名 | 装在容器里却写 `127.0.0.1`，会连到 AMMDS 自己身上 |
| API 密钥 | 在 Jellyfin 控制台新建的密钥；系统检查里属于启用后的必填项 | 为空或无效时提示「请填写正确的插件配置」 |
| 用户名 | 登录用户名，**可选** | 不填一般不影响同步 |
| 密码 | 登录密码，**可选** | 同上 |
| 绑定用户 | 播放记录归属于哪个 Jellyfin 用户，**填用户 ID，不是用户名**；多个用英文逗号分隔，建议直接从下拉列表选 | 填成 `root`、`admin` 这类用户名会出现橙色提示，媒体库列表也可能读不到；不绑定时播放记录同步仍在跑，但统计不到对应账号的数据 |
| 自动补全 | 默认关闭；开启后由定时任务在后台补全演员数据 | 依赖本地演员库已有资料或头像，本地没有的补不出来 |

### 绑定用户的顺序

1. 先填好服务地址、API 密钥并**保存**。
2. 回到配置页刷新，系统会拉取 Jellyfin 用户列表。
3. 在「绑定用户」中选择账号（管理员带红色标签，普通用户带蓝色标签），再保存。

**注意填的是用户 ID，不是用户名。** 从下拉列表里选最稳妥。手填时如果写了 `root`、`admin` 这类明显是用户名的值，输入框下方会出现橙色提示，而且很可能读不到媒体库。

### 能同步什么

| 内容 | 方向 | 说明 |
| --- | --- | --- |
| 媒体库条目 | 播放器 → AMMDS | 拉取媒体库里的影片、演员等条目，供本地绑定与展示 |
| 媒体库同步 | 双向 | 把本地影片元数据与封面写入播放器，并建立绑定关系 |
| 播放记录 | 播放器 → AMMDS | 按绑定用户拉取播放记录，用于播放统计 |
| 演员补全 | 双向 | 补全播放器里的演员数据；也可以把播放器刮削到的演员写入本地演员库 |
| 图片 | AMMDS → 播放器 | 上传媒体库或条目的主图，覆盖原有图片 |
| 媒体库扫描 | AMMDS → 播放器 | 触发单个或全部媒体库扫描 |

对应操作入口在**工具箱 → 媒体服务器 → 库管理**：「扫描所有媒体库」「补全演员信息」「同步媒体库」「同步播放记录」「刷新」。

1. 填好服务地址与 API 密钥并保存。
2. 刷新配置页，等系统拉取 Emby 用户列表。
3. 在「绑定用户」中选账号（管理员红色标签、普通用户蓝色标签）后保存。

| 内容 | 方向 | 说明 |
| --- | --- | --- |
| 媒体库条目 | 播放器 → AMMDS | 拉取媒体库的影片、演员等条目 |
| 媒体库同步 | 双向 | 写入本地影片元数据与封面，并建立影片绑定关系 |

## 两边都要知道的限制

- **全部在后台跑**：同步与补全不会当场完成，点完马上提示「正在同步…，请稍后查看日志」，进度只能看运行日志。
- **绑定会顺手写一次**：绑定影片或演员时会把本地资料和封面写进播放器，能写成最好，写不进去也不影响绑定本身。
- **不会删文件**：同步只写元数据与图片，不删除播放器上的影片文件。
- **解绑只删关系**：解除绑定只删本地的绑定记录，不影响播放器那边的数据。
- **自动补全有前提**：依赖本地演员库已有资料或头像，本地没有的数据补不出来。
- **地址别写 127.0.0.1**：容器部署时 `127.0.0.1` 指向 AMMDS 容器自身。

## 出问题了怎么办

- **提示「请填写正确的插件配置」**：服务地址写错、API 密钥无效，或播放器没启动。先点「测试连接」定位。
- **提示「请先启用 XX 插件」**：打开插件的「启用状态」并保存。
- **用户列表为空**：配置还没保存。保存后刷新配置页再试。
- **绑定用户填成了用户名**：`root`、`admin` 是用户名，不是用户 ID。回配置页从下拉列表重新选，或填对应用户 ID 再保存，否则读不到媒体库。
- **播放记录没有数据**：没绑定用户，或者该用户最近没有播放。绑定用户后重新同步。
- **同步进度看不到**：任务在后台跑，去看运行日志。
- **封面没有更新**：回写失败或原图被锁定，在播放器侧确认图片锁定状态后重试。
- **Emby 写入后界面没变**：播放器缓存没刷新，触发一次媒体库扫描或刷新元数据。
