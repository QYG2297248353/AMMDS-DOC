# Emby

Emby 是主从式架构的媒体服务器。接入 AMMDS 后，本地整理好的元数据可以写入 Emby，Emby 侧的条目、播放记录与演员资料也能回流到 AMMDS。

{/* truncate */}

## 站点定位

| 项目 | 说明 |
| --- | --- |
| 页面入口 | **集成应用 → 媒体服务器 → Emby** |
| 集成版本 | 页面顶部标注 `4.8.11.0+`，类型为「媒体服务器」 |
| 通信方式 | Emby HTTP API + API 密钥 |
| 管理入口 | **工具箱 → 媒体服务器 → 库管理 / 影视库 / 演员库** |

:::note[与 Jellyfin 的关系]
Emby 与 Jellyfin 同源，配置项与能力高度相似。两者可以同时启用，播放统计会按各自绑定的用户分别拉取后再合并。
:::

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `emby_enabled` | 启用状态 | 布尔 | `false` | 关闭后所有媒体服务器接口返回「请先启用 Emby 插件」 |
| `emby_service_url` | 服务地址 | 字符串 | `http://127.0.0.1:8096` | Emby 访问地址，容器部署请用宿主地址或服务名 |
| `emby_api_key` | API 密钥 | 字符串 | 空 | 调用 Emby 开放接口的密钥；系统检查中的必填项 |
| `emby_username` | 用户名 | 字符串 | 空 | 登录用户名，可选 |
| `emby_password` | 密码 | 字符串 | 空 | 登录密码，可选 |
| `emby_bind_user` | 绑定用户 | 下拉（多值） | 空 | 播放记录同步归属的 Emby 用户，多个以英文逗号分隔 |
| `emby_auto_complete` | 自动补全 | 布尔 | `false` | 开启后定时任务异步补全演员数据 |

## API 密钥获取路径

1. 用管理员账号登录 Emby 控制台。
2. 进入 **设置 → 高级 → API 密钥**。
3. 新建密钥并复制。
4. 粘贴到「API 密钥」，保存后点「测试连接」。

:::warning[权限与地址]
API 密钥对应的账号需要有管理媒体库的权限；「服务地址」必须是 AMMDS 能访问到的地址，不要填 Emby 容器内部的 `127.0.0.1`。
:::

## 绑定用户

1. 填好服务地址与 API 密钥并保存。
2. 刷新配置页，等系统拉取 Emby 用户列表。
3. 在「绑定用户」中选账号（管理员红色标签、普通用户蓝色标签）后保存。

播放记录同步按绑定用户执行；未绑定时同步仍会跑，但统计不到该账号的数据。

## 同步内容

| 内容 | 方向 | 说明 |
| --- | --- | --- |
| 媒体库条目 | Emby → AMMDS | 拉取媒体库的影片、演员等条目 |
| 媒体库同步 | 双向 | 写入本地影片元数据与封面，并建立影片绑定关系 |
| 播放记录 | Emby → AMMDS | 按绑定用户拉取播放记录，用于播放统计 |
| 演员补全 | 双向 | 补全 Emby 演员数据；也可把 Emby 演员刮削后写入本地演员库 |
| 图片 | AMMDS → Emby | 上传媒体库或条目的 Primary 图 |
| 媒体库扫描 | AMMDS → Emby | 触发单个或全部媒体库扫描 |

操作入口与 Jellyfin 一致，在 **工具箱 → 媒体服务器 → 库管理**。

## 限制与注意

- **异步执行**：同步、补全、刮削都在后台跑，接口只回「正在…请稍后查看日志」。
- **绑定即写入**：绑定影片或演员会把本地数据与图片回写 Emby，回写失败不影响绑定成功。
- **不删媒体文件**：同步不触碰 Emby 上的影片文件，只更新元数据与图片。
- **解绑只删本地关系**：不影响 Emby 侧已有数据。
- **自动补全依赖本地数据**：本地演员库没有的演员，补全补不出来。
- **路径与网络**：Emby 与 AMMDS 之间的连通性可用[网络与连通性](/docs/backend/dashboard/network)先做初筛，自建服务的连通性在插件页测试。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示请先启用 Emby 插件 | 启用状态为关闭 | 打开开关并保存 |
| 获取用户列表失败 | 配置未保存，或 API 密钥权限不足 | 保存后刷新，必要时重建密钥 |
| 播放记录为空 | 未绑定用户，或该用户无近期播放 | 绑定用户后重新同步 |
| 元数据写入后界面没变 | Emby 缓存未刷新 | 触发一次媒体库扫描或刷新元数据 |
| 同步卡住 | 媒体库过大，后台仍在执行 | 查看运行日志，避免重复触发 |
