# Jellyfin

Jellyfin 是开源媒体服务器。接入 AMMDS 后，媒体库条目、播放记录与演员资料可以在两边对齐：本地整理好的元数据写进 Jellyfin，Jellyfin 的播放与演员数据回流到 AMMDS。

## 站点定位

| 项目 | 说明 |
| --- | --- |
| 页面入口 | **集成应用 → 媒体服务器 → Jellyfin** |
| 集成版本 | 页面顶部标注 `10.10.3+`，类型为「媒体服务器」 |
| 通信方式 | Jellyfin HTTP API + API 密钥 |
| 管理入口 | **工具箱 → 媒体服务器 → 库管理 / 影视库 / 演员库** |

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `jellyfin_enabled` | 启用状态 | 布尔 | `false` | 关闭后所有媒体服务器接口返回「请先启用 JellyFin 插件」 |
| `jellyfin_service_url` | 服务地址 | 字符串 | `http://127.0.0.1:8096` | Jellyfin 访问地址，容器部署请用宿主地址或服务名 |
| `jellyfin_api_key` | API 密钥 | 字符串 | 空 | 调用 Jellyfin 开放接口的密钥；系统检查中的必填项 |
| `jellyfin_username` | 用户名 | 字符串 | 空 | 登录用户名，可选 |
| `jellyfin_password` | 密码 | 字符串 | 空 | 登录密码，可选 |
| `jellyfin_bind_user` | 绑定用户 | 下拉（多值） | 空 | 播放记录同步归属的 Jellyfin 用户，多个以英文逗号分隔 |
| `jellyfin_auto_complete` | 自动补全 | 布尔 | `false` | 开启后定时任务异步补全演员数据 |

## API 密钥获取路径

1. 用管理员账号登录 Jellyfin 控制台。
2. 进入 **控制台 → API 密钥**（部分版本在「高级」下）。
3. 新建密钥，名称建议写 `AMMDS`，复制生成的密钥。
4. 粘贴到「API 密钥」，保存后点「测试连接」。

:::tip[建议单独建密钥]
给 AMMDS 单独建一枚密钥，便于日后单独吊销；不要把管理员日常使用的密钥复用进来。
:::

## 绑定用户

「绑定用户」决定**播放记录算谁的**：

1. 先填好服务地址、API 密钥并**保存**。
2. 回到配置页刷新，系统会拉取 Jellyfin 用户列表。
3. 在「绑定用户」中选择账号（管理员会带红色标签，普通用户带蓝色标签），再保存。

未绑定用户时，播放记录同步仍在跑，但统计不到对应账号的数据。

## 同步内容

| 内容 | 方向 | 说明 |
| --- | --- | --- |
| 媒体库条目 | Jellyfin → AMMDS | 拉取媒体库的影片、演员等条目，供本地绑定与展示 |
| 媒体库同步 | 双向 | 把本地影片元数据与封面写入 Jellyfin，并建立本地影片与媒体服务器影片的绑定 |
| 播放记录 | Jellyfin → AMMDS | 按绑定用户拉取播放记录，用于播放统计 |
| 演员补全 | 双向 | 补全 Jellyfin 演员数据；也可把 Jellyfin 演员刮削后写入本地演员库 |
| 图片 | AMMDS → Jellyfin | 上传媒体库或条目的 Primary 图，覆盖原有图片 |
| 媒体库扫描 | AMMDS → Jellyfin | 触发单个或全部媒体库扫描 |

对应操作入口在 **工具箱 → 媒体服务器 → 库管理**：「扫描所有媒体库」「补全演员信息」「同步媒体库」「同步播放记录」「刷新」。

## 限制与注意

- **全部异步**：同步与补全在后台执行，接口立即返回「正在同步…，请稍后查看日志」，进度只能看运行日志。
- **绑定即写入**：绑定影片或演员时会把本地数据与图片回写 Jellyfin，属于尽力而为，回写失败不影响绑定结果。
- **不会删文件**：同步只写元数据与图片，不删除媒体服务器上的影片文件。
- **解绑仅删关系**：解除绑定只删本地绑定记录，不影响 Jellyfin 侧数据。
- **自动补全有前提**：依赖本地演员库已有资料或头像，本地没有的数据补不出来。
- **地址别写 127.0.0.1**：容器部署时 `127.0.0.1` 指向 AMMDS 容器自身。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示请填写正确的插件配置 | 地址错误、API 密钥无效或服务未启动 | 核对地址与密钥，先点「测试连接」 |
| 用户列表为空 | 配置尚未保存 | 保存后重新刷新配置 |
| 播放记录没有数据 | 未绑定用户，或该用户近期没播放 | 绑定用户后重新同步 |
| 同步进度看不到 | 任务在后台异步执行 | 查看运行日志 |
| 封面没有更新 | 回写失败或原图被锁定 | 在 Jellyfin 侧确认图片锁定状态后重试 |
