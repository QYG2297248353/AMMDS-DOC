# 让识别更准的小工具

这一类不直接提供影片资料，也不负责下载，但会让前面的事情跑得更顺：认得更准、搜得更快、画面能转码、字幕能自动生成。

> **转码**：把视频换成另一种格式或另一种画质，方便在更多设备上播放。

> **代理**：让本机先连到另一台服务器，再由那台服务器去访问目标网站。用于本机直接访问不到的情况。

> **索引**：一份专门给搜索用的清单。搜之前先把内容整理好，搜的时候就能很快。

> **对象存储**：一种按「桶 + 文件名」存放文件的网上空间，例如各类网盘和企业存储服务。

## 一图看懂哪个管什么

| 工具 | 解决什么问题 | 要不要自己准备服务 | 默认状态 |
| --- | --- | --- | --- |
| 高德地图 | 工作台上显示当前城市与天气 | 不用，填密钥即可（不填也能用内置额度） | 默认关闭 |
| 云存储 | 把配置加密备份到网盘或对象存储；S3 还能存图片 | 要：WebDAV 或 S3 服务地址与账号 | 默认关闭 |
| DeepSeek | 用大模型做 AI 翻译、辅助识别、Telegram 对话 | 要：服务地址与密钥 | 默认关闭 |
| FFmpeg | 视频转码、格式转换、截图、封面、读取时长 | 不用，组件缺失时自动下载 | 默认**已启用** |
| FlareSolverr | 帮 AMMDS 通过某些站点的人机验证页 | 要：自己部署该服务 | 默认关闭 |
| MeiliSearch | 让顶部搜索框能快速搜到影片、演员、漫画等 | 要：自己部署该服务 | 默认关闭 |
| 翻译服务 | 把刮削到的外文标题与简介翻成中文 | 部分通道要填密钥；内置免费通道不用 | 默认关闭 |
| VibeVoice | 把视频里的对白转成字幕文件 | 可选：本机托管（要下载模型）或连外部服务 | 默认关闭 |

## 高德地图

让工作台的天气卡片显示当前城市与天气。它按你的出口网络判断城市，也能固定到某个城市。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 不打开就不使用你填的密钥 |
| 服务地址 | 默认 `https://restapi.amap.com`；走代理或镜像时改成对应地址 | 改错会导致天气加载失败 |
| API密钥 | 在高德开放平台申请；**服务平台要选「Web 服务」** | 不填时会回退到内置额度，也能看到天气，但定位精度与用量由内置额度决定 |
| 城市代码 | 城市的数字编码，例如北京 `110000`、上海 `310000` | 不填就按出口网络定位；格式必须是 3–6 位数字，不合法时视为未填写 |

:::tip[固定城市更稳]
服务器走代理、使用 VPN 或在内网里时，按网络定位可能落到机房所在地。手动填城市代码，天气就始终对应你关心的城市。
:::

点「连接测试」只确认服务地址能连上，不检查密钥，也不会显示天气。

## 云存储

「云存储」由 WebDAV 与 S3 两个独立插件组成，用法也一样：都是加密备份，恢复时按模块挑。

| 能力 | WebDAV | S3 兼容对象存储 |
| --- | --- | --- |
| 配置加密备份 | 支持 | 支持 |
| 恢复配置 | 支持 | 支持 |
| 存放图片等业务资源 | **不支持** | 支持（需单独开启） |
| 加密口令 | 独立 | 独立，与 WebDAV 互不影响 |

:::warning[WebDAV 的定位]
WebDAV 通常额度有限，也不适合放大量图片。需要把图片等资源放到远端，请用 S3。
:::

### 备份范围

备份包只包含「配置类」数据，影片条目、图片、元数据这些大体积内容不参与备份。

| 模块 | 内容 |
| --- | --- |
| 系统配置 | 域名绑定、系统模式、磁盘监测、广告开关等 |
| 集成插件配置 | 各插件的配置 |
| 外观与主题配置 | 主题、背景、哀悼模式与落地页 |
| 个人与主页配置 | 昵称、邮箱、手机号与公共主页主题（不含头像） |
| 接口密钥 | 开放接口的访问密钥及有效期 |
| 任务与扫描规则 | 扫描任务定义、运行类型与调度规则 |
| 订阅规则 | 订阅关键词、匹配规则与自动下载策略 |
| 后台界面设置 | 后台菜单、标签栏、主题色等 |

默认勾选的模块是 `system,plugin,user,secret,task,subscribe`。

### 设置项说明（WebDAV）

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 不打开就不备份 |
| 服务地址 | 要带协议前缀，例如 `https://dav.example.com` | 为空时连接测试失败 |
| 存储目录 | 默认 `ammds-backup`；留空表示用服务根目录 | 目录不存在时连接测试会自动创建 |
| 账号 | 留空表示匿名访问 | 需要认证却留空会连不上 |
| 密码 | 登录密码，填完不会再显示出来 | 同上 |
| 允许自签名证书 | 默认关闭；自建服务用自签证书时打开 | 不开的话自签证书会校验失败 |
| 备份加密 | 默认**开启**，用 AES-256-GCM 加密备份包 | 关掉后备份包是明文 |
| 加密口令 | 用于派生密钥 | **丢失后备份无法恢复** |
| 恢复策略 | 默认「合并更新」，候选还有「本地优先」「远端优先」 | 选错会导致恢复后的值不是你想要的 |
| 备份模块 | 逗号分隔的模块代码，默认 `system,plugin,user,secret,task,subscribe` | 没勾选的模块不会进备份包 |
| 保留份数 | 默认 `5`；备份后自动清理超出的历史备份，`0` 表示不限制 | 设太小会被自动清理掉旧备份 |

### 设置项说明（S3）

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 备份与资源存储都依赖它 |
| S3 服务地址 | 例如 `https://s3.us-east-1.amazonaws.com` 或自建 MinIO 地址 | 为空连不上 |
| S3 地域 | 默认 `us-east-1` | 与存储服务不一致会签名失败 |
| S3 存储桶 | 需事先在存储服务里创建 | 不存在时连接测试失败 |
| S3 对象前缀 | 默认 `ammds-backup`，备份写入的目录前缀 | 前缀与备份目录不符时列表为空 |
| S3 Access Key / Secret Key | 访问用的两把钥匙，填完不会再显示出来 | 填错签名失败 |
| S3 路径风格寻址 | 默认**开启**；MinIO 等自建存储通常需要开启，大型公有云建议关闭 | 不匹配会连不上 |
| 允许自签名证书 | 默认关闭 | 自建存储用自签证书时要开 |
| 资源存储到 S3 | 默认关闭；开启后新上传的图片写入 S3，本地保留缓存 | 不开就不会转存；开启前已有的本地资源不会自动迁移 |
| 资源访问前缀 | 留空时图片由本系统转一手读取；填了之后直接从该地址读取，可以对接加速服务 | 填错会导致图片打不开 |
| 本地缓存 | 默认**开启**；从 S3 读过的资源在本地留副本 | 关掉后每次读取都回源，流量更多 |
| 备份加密 / 加密口令 / 恢复策略 / 备份模块 / 保留份数 | 含义与 WebDAV 一致，口令互相独立 | 同上 |

### 备份与恢复怎么做

1. 在「配置信息」里填好连接、加密与恢复策略并保存。
2. 在「模块备份管理」勾选要备份的模块，点「保存模块」。
3. 在「备份与恢复」填写可选备注，点「立即备份」。
4. 备份完成后列表刷新，能看到文件名、生成时间、大小与是否加密。
5. 需要回滚时点「恢复」，选择恢复策略并输入加密口令，确认后写入本机。

| 恢复策略 | 行为 |
| --- | --- |
| 合并更新 | 只补齐缺失项与有差异的配置 |
| 本地优先 | 只补充本地不存在的配置，保留本地已有值 |
| 远端优先 | 以备份内容覆盖本地已有配置 |

:::warning[口令丢了就恢复不了]
加密口令只用于本地派生密钥，服务端不保存明文。请单独保存口令。另外，恢复时 WebDAV 与 S3 自身的连接配置和口令都不会被覆盖，避免恢复之后没法继续备份。
:::

## DeepSeek

DeepSeek 把大模型能力接进 AMMDS，用于 AI 翻译、辅助识别，以及 Telegram 里的对话。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 关闭后余额与模型卡片不显示，调用时会直接视为未启用 |
| 服务地址 | 默认 `https://api.deepseek.com`；走中转或自建代理时改成对应地址 | 为空时提示「请先配置连接地址」，不发请求 |
| API Key | 调用时要带的钥匙 | 缺失时余额、模型与对话都不可用 |
| 推理模型 | 默认 `deepseek-v4-pro`；可以直接输入模型名，也可以在模型列表点「选用」写回 | 旧模型名会自动换成新的：`deepseek-chat` → `deepseek-v4-pro`，`deepseek-reasoner` → `deepseek-v4-flash` |
| 模型温度 | 默认 `0.7`；越大输出越随机，越小越稳定 | 一般不改 |
| 上下文长度 / 输出长度 | 默认 `1M` / `384K`，**只用于展示模型能力，不影响实际请求** | 改了也不影响实际请求 |

### 页面能做什么

| 区块 | 内容 |
| --- | --- |
| 应用信息 | 名称、Logo、官网、文档、集成版本与简介 |
| 配置信息 | 上表各项；提供「刷新配置」「保存配置」 |
| 账户余额 | 启用后出现，按币种展示总余额、赠送余额与充值余额；可用时显示绿色「账户可用」，不足时红色「余额不足」 |
| 模型列表 | 启用后出现，列出模型 ID、归属方与创建时间；点「选用」把模型写回配置，正在使用的显示「使用中」 |
| 连接测试 | 用当前服务地址发起健康检查 |

:::note[并发与失败]
按模型分别限流（同一时间能处理的请求有上限），`deepseek-v4-pro` 上限 500、`deepseek-v4-flash` 上限 2500。排不上队时最多等 30 秒，仍失败就返回「并发请求已满」。服务端返回 429 按失败处理，插件层不会自动重试。
:::

## FFmpeg

FFmpeg 是音视频处理的基础组件，负责转码、截图、封面裁剪、缩略图，以及读取视频时长与分辨率。**默认已启用**。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 默认**开启** | 关闭后不能创建新的转码 / 转换任务（已有任务不受影响） |
| 任务数量 | 默认 `2`，取值 1–5；每种任务类型各算一类 | 设太大会占满 CPU |
| 转码输出方式 | 默认「加后缀」（候选还有「统一目录」） | 选「统一目录」却没填目录会失败 |
| 转码统一输出目录 | 输出方式为「统一目录」时使用 | 同上 |
| 转码默认后缀 | 默认 `transcode`，拼在文件名后 | 一般不改 |
| 格式转换输出方式 | 默认「源目录同名输出」（候选还有「统一目录」） | 同上 |
| 格式转换统一输出目录 | 输出方式为「统一目录」时使用 | 同上 |
| 转码默认视频编码 | 默认 `libx264`，候选还有 `libx265` | 组件缺失时会报编码器不存在 |
| 转码默认预设 | 默认 `veryfast`，候选从 `ultrafast` 到 `veryslow` | 越慢越省体积，也越耗时 |
| 转码默认质量 (CRF) | 默认 `23`，建议 18–28；越小画质越高、体积越大 | 超出建议范围体积或画质会明显变化 |
| 排队等待 | 默认**开启**；超出任务数量时自动排队 | 关闭后超出的任务直接失败 |
| 任务恢复 | 默认**开启**；服务重启后自动恢复未完成任务 | 关闭后未完成任务标记失败，需手动重试 |

### 组件管理

- 组件装在本机的 `data/ffmpeg` 目录，按操作系统与处理器选择对应文件。
- 系统启动后会检查，**缺失时自动在后台下载，每分钟重试一次**；不支持 32 位系统。
- 「资源下载」卡片能看到文件名、状态、进度与路径，并提供**下载缺失组件**、**刷新状态**、**删除**。

:::note[下载中断怎么办]
状态包含未开始、下载中、已完成、失败。中断的组件删除后重新下载即可，不影响另一个组件。
:::

转码入口在**工具箱 → 视频转码**，格式转换在**工具箱 → 格式转换**。

## FlareSolverr

有些站点在返回正文前会先发一张「正在检查您的浏览器」的验证页，普通请求只能拿到这张验证页。FlareSolverr 是一个专门处理这类验证页的服务，AMMDS 可以把抓取交给它。

> **验证页 / 人机校验**：站点用来确认「你是真人浏览器而不是程序」的一张中间页面。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 关闭时不使用它，请求按原逻辑发出 |
| 服务地址 | 默认 `http://127.0.0.1:8191`，指向已运行的 FlareSolverr，要带协议与端口 | 为空时提示「请先配置连接地址」；AMMDS 与它不在同一台机器时要换成实际主机地址 |
| 同步代理配置 | 默认**开启**；把系统网络代理配置同步给它 | 装在容器里时 `127.0.0.1` 会指到自己；它所在机器能直接出网时可以关掉同步 |
| 超时时间 | 默认 `60` 秒；站点二次验证较慢时可上调到 90–120 秒 | 太大会让失败请求长时间占用连接 |

:::note[这是独立服务]
AMMDS 不下载、不托管、也不随应用启动它。你需要自己以容器或可执行文件的方式运行它，插件只保存地址并调用。
:::

### 什么时候该开、什么时候不该开

| 场景 | 是否适用 |
| --- | --- |
| 目标站点有「正在检查您的浏览器」或类似的验证页 | 适用 |
| 普通静态站点、开放接口 | 不需要，开了反而每个请求都多绕一层 |
| 需要登录、付费，或站点已封你的网络地址 | 不适用，它不能代替账号与权限 |
| 返回 401 / 403 但没有验证页 | 不适用，先查密钥与账号状态 |

点「连接测试」只验证 AMMDS 能否访问 FlareSolverr，不代表目标站点一定能通过验证。

## MeiliSearch

MeiliSearch 是全文搜索引擎。配上之后，影片、演员、漫画、小说与资讯会写进索引，前台和顶部搜索框都查这一份索引。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态 | 打开开关 | 关闭后不建索引也不检索，搜索会一直是空的 |
| 服务地址 | 默认 `http://192.168.10.24:7700` 是**示例地址**，必须改成你自己的地址；要带协议与端口 | 不改就一定会连不上 |
| API Key | 建索引和搜索都要用的钥匙；重建索引需要**可写入**的那一把 | 权限不足时重建索引报错 |
| 自动索引 | 默认**开启**；开启后定时全量重建各类型索引 | 关闭后只能手动重建，新增的影片不会自动进索引 |

### 索引管理与重建

「索引管理」按类型重建，每次都是**全量重建**：

| 选项 | 说明 |
| --- | --- |
| 全部 | 依次重建全部类型（影片、剧集、演员、漫画、小说、资讯） |
| 影片 | 影片标题、番号等内容 |
| 演员 | 演员姓名、别名等内容 |
| 漫画 | 漫画标题、作者等内容 |
| 小说 | 小说标题、作者、系列等内容 |
| 资讯 | 资讯条目 |

点「重建索引」后卡片会显示各类型写入的数量，例如 `movie=1024, actor=356`。重建是「先清空这一类型、再分批写入」，所以重建期间该类型的搜索结果可能短暂为空或不全。

:::tip[第一次用先手动重建一次]
新部署或数据大量变动后，建议先手动「全部」重建一次，之后靠自动索引维持新鲜度。开启自动索引且服务可用时，启动约 5 分钟后做首次全量重建，之后每小时一次。
:::

「搜索测试」只读取索引，不修改数据。搜不到时先确认对应类型是否已重建。

## 翻译服务

翻译服务把刮削到的外文标题、简介与标签翻成中文。有两条通道：AMMDS 内置翻译，或交给 MetaTube。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 启用状态（界面显示「启用翻译」） | 打开开关 | 关闭时翻译请求直接返回「翻译服务未启用」 |
| AI 优先 | 默认关闭；打开后先试 AI 翻译，全部失败再依次试机器翻译 | 关闭时按内置顺序走 |
| 默认翻译方式 | 默认 `ammds`（内置翻译）；另一选项是 `metatube`（交给 MetaTube） | 选了 `metatube` 但 MetaTube 侧没开翻译，就没有结果 |
| 标题 / 描述 / 标签 / 默认翻译 Prompt | 内置英文模板，可自定义；可用 `{source_lang}`、`{target_lang}`、`{content}` 三个变量 | 改错不会报错，只影响译文质量 |

:::note[只翻成简体中文]
刮削链路固定把外文内容翻成简体中文，源语言自动识别，不用在插件页单独设置目标语言。另外，刮削配置的「字段翻译」开关默认是关闭的，要打开才会有翻译。
:::

## VibeVoice

VibeVoice 把视频里的对白转成字幕文件（`.srt`）。可以本机托管，也可以连外部已有的服务。

> **语音识别**：让程序听懂视频里的说话内容，并把它写成文字。

### 设置项说明

| 设置项 | 要填什么 | 不填 / 填错会怎样 |
| --- | --- | --- |
| 接入模式 | 默认 `local`（本机托管），另一选项 `remote`（外部服务） | 选 local 时不显示服务地址、密钥与模型名 |
| 启用状态 | 打开开关 | 关闭后无法创建字幕任务，工具箱入口提示未启用 |
| 服务地址 | 默认 `http://127.0.0.1:8000`；本地模式会自动填好，远程模式需手填 | 远程模式填错会检测失败 |
| API Key | 可选；服务端没设密码时留空 | 服务端设了密码却不填会连不上 |
| 识别模型名 | 默认 `vibevoice-asr`，需与服务端加载的模型一致 | 不一致会识别失败 |
| 最多同时任务数 | 默认 `1`，取值 1–5 | 本机推理内存占用高，建议保持串行 |
| 单个任务最大线程 | 默认 `4`，作为提示信息一起发给服务 | 一般不改 |
| 单段最大分钟 | 默认 `3`，上限 60 | 单段过长时本地服务可能中断，导致字幕缺后半段 |
| 模型仓库 | 默认 `microsoft/VibeVoice-ASR-BitNet`，模型下载区使用 | 一般不改 |
| 模型文件名 | 下载完成后自动填好，空表示尚未下载 | 空则模型未就绪 |
| 启动器优先级 | 默认 `asr_infer` | 见下 |
| 字幕生成位置 | 默认 `video_dir`（与视频同源）；另一选项 `unified`（统一目录） | 选「统一目录」时字幕写到 `data/subtitles/vibevoice/` 并以任务 ID 命名 |

| 启动器 | 工作方式 | 适用 |
| --- | --- | --- |
| `asr_infer`（推荐） | 每段音频起一个独立进程做一次推理 | 默认选择，无常驻内存，速度更快 |
| `asr_stream_server` | 常驻进程提供流式服务，约 2.5 GB 常驻内存 | 只在需要避免每段重新加载模型时选用 |

### 本机模式怎么准备

1. 插件页里接入模式选「本地」。
2. 在「内置服务 → 启动器下载」下载推理程序，等状态变成已就绪。
3. 在「模型下载」确认仓库是官方仓库，点「下载模型」，等两个模型文件下载完成（合计约 1.5 GB）。
4. 点「启动服务」，状态显示「运行中」并显示端口。
5. 在「服务检测」点「检测服务」，确认已连接、已加载模型包含 `vibevoice-asr`。

### 生成字幕

入口在**工具箱 → 字幕生成**，插件未启用时页面会提示先启用。

1. 点「新建字幕任务」，选择单个视频或整个目录。
2. 选择识别语言（默认可自动检测）；需要双语时打开「双语字幕」并选目标语言。
3. 提交后任务进入队列，列表展示视频、时长、识别语言、双语、状态、进度与创建时间。

| 状态 | 可用操作 |
| --- | --- |
| 进行中 / 排队中 / 翻译中 | 取消 |
| 失败 / 已取消 | 重试 |
| 已完成 | 详情、查看、编辑、下载、翻译 |

已完成的任务还能基于当前字幕再建一条翻译任务，跳过语音识别直接翻译，生成带语言后缀的新字幕文件。

## 出问题了怎么办

- **天气一直加载失败**：服务器访问不到 `restapi.amap.com`，用连接测试确认并检查出网与代理。
- **城市定位不对**：出口网络属于机房或代理，手动填城市代码。
- **备份列表为空**：连接信息填错，或备份目录 / 前缀下确实没有备份。先做连接测试。
- **恢复提示口令错误**：用的不是备份时的口令；口令遗失则无法恢复。
- **S3 连不上但地址能访问**：地域、寻址方式或签名不匹配；自建存储试着开启路径风格寻址。
- **DeepSeek 余额为空或模型列表为空**：先用连接测试确认地址，再核对密钥；账号无权看模型列表时可直接手填模型名。
- **提示并发请求已满**：同一模型并发到上限，稍后重试或换成 `deepseek-v4-flash`。
- **转码报编码器不存在**：组件缺失或损坏，在资源下载里删除后重新下载。
- **转码任务全部失败**：关闭了排队等待且并发已满，打开排队等待后重试。
- **FlareSolverr 连接被拒绝或超时**：服务没启动、端口不对或被防火墙挡住；确认 8191 端口在监听。
- **开启 FlareSolverr 后抓取仍失败**：站点不是验证页，而是登录或封禁，按提示检查账号、密钥或更换网络出口。
- **MeiliSearch 连不上**：地址还是示例地址、端口没开，或密钥权限不足。
- **搜索没结果**：对应类型还没重建；重建一次再试。
- **提示翻译服务未启用**：打开翻译插件的「启用状态」；刮削后仍没中文则检查刮削配置的「字段翻译」。
- **VibeVoice 检测服务失败**：本机模式先点「启动服务」，远程模式核对地址与密钥。
- **字幕缺后半段**：单段过长导致推理中断，降低「单段最大分钟」或改用 `asr_infer`。
