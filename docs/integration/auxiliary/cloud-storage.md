# 云存储

「云存储」由 WebDAV 与 S3 两个独立插件组成，二者共用同一套「加密备份 + 按模块恢复」的语义，但定位不同：WebDAV 只做配置备份，S3 既能备份配置，也能把图片等业务资源转存到对象存储。

{/* truncate */}

## 能力对比

| 能力 | WebDAV | S3 兼容对象存储 |
| --- | --- | --- |
| 配置加密备份 | 支持 | 支持 |
| 恢复配置 | 支持 | 支持 |
| 图片等资源存储 | 不支持 | 支持（需单独开启） |
| 连接参数 | `webdav_` 前缀 | `s3_` 前缀 |
| 加密口令 | 独立 | 独立，与 WebDAV 互不影响 |

:::warning[WebDAV 的定位]
WebDAV 免费额度普遍有限，协议上也缺少对象存储级别的权限与成本控制，因此本插件不会把图片等资源写入 WebDAV。需要远端资源存储时请使用 S3。
:::

## 备份范围

备份包只包含「配置类」数据，元数据、图片、影片条目等大体积内容不参与备份。

| 模块 code | 名称 | 内容 |
| --- | --- | --- |
| `system` | 系统配置 | 域名绑定、系统模式、磁盘监测、广告开关等 |
| `plugin` | 集成插件配置 | Metatube、TMDB、qBittorrent、IYUU、Telegram 等插件配置 |
| `theme` | 外观与主题配置 | 主题、背景、哀悼模式与落地页 |
| `user` | 个人与主页配置 | 昵称、邮箱、手机号与公共主页主题（不含头像） |
| `secret` | 接口密钥 | 开放 API 访问密钥及有效期 |
| `task` | 任务与扫描规则 | 扫描任务定义、运行类型与调度规则 |
| `subscribe` | 订阅规则 | 订阅关键词、匹配规则与自动下载策略 |
| `admin_ui` | 后台界面设置 | 后台菜单、标签栏、主题色等 |

两个插件的「模块备份管理」各自保存选择，默认值为 `system,plugin,user,secret,task,subscribe`。

## WebDAV 配置

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `webdav_enabled` | 启用状态 | 布尔 | `false` | 备份通道开关 |
| `webdav_server_url` | 服务地址 | 文本 | 空 | 须带协议前缀，如 `https://dav.example.com` |
| `webdav_base_path` | 存储目录 | 文本 | `ammds-backup` | 远端存储目录，留空表示使用服务根目录 |
| `webdav_username` | 账号 | 文本 | 空 | 留空表示匿名访问 |
| `webdav_password` | 密码 | 文本 | 空 | 敏感字段，接口不回显明文 |
| `webdav_allow_insecure_tls` | 允许自签名证书 | 布尔 | `false` | 自建服务使用自签证书时开启 |
| `webdav_encrypt_enabled` | 备份加密 | 布尔 | `true` | 使用 AES-256-GCM 加密备份包 |
| `webdav_encrypt_password` | 加密口令 | 文本 | 空 | 用于派生密钥，丢失后备份无法恢复 |
| `webdav_restore_mode` | 恢复策略 | 单选 | `merge`（候选 `merge`、`local`、`remote`） | 合并更新 / 本地优先 / 远端优先 |
| `webdav_backup_modules` | 备份模块 | 文本 | `system,plugin,user,secret,task,subscribe` | 逗号分隔的模块 code |
| `webdav_keep_count` | 保留份数 | 数字 | `5` | 备份后自动清理超出份数的历史备份，`0` 表示不限制 |

## S3 配置

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `s3_enabled` | 启用状态 | 布尔 | `false` | 通道开关，备份与资源存储都依赖它 |
| `s3_endpoint` | S3 服务地址 | 文本 | 空 | 如 `https://s3.us-east-1.amazonaws.com` 或自建 MinIO 地址 |
| `s3_region` | S3 地域 | 文本 | `us-east-1` | 对象存储地域 |
| `s3_bucket` | S3 存储桶 | 文本 | 空 | 需事先在对象存储中创建 |
| `s3_prefix` | S3 对象前缀 | 文本 | `ammds-backup` | 备份对象写入的目录前缀 |
| `s3_access_key` | S3 Access Key | 文本 | 空 | 访问密钥 ID |
| `s3_secret_key` | S3 Secret Key | 文本 | 空 | 敏感字段，接口不回显明文 |
| `s3_path_style` | S3 路径风格寻址 | 布尔 | `true` | MinIO 等自建存储通常需要开启，AWS S3 建议关闭 |
| `s3_allow_insecure_tls` | 允许自签名证书 | 布尔 | `false` | 自建存储使用自签证书时开启 |
| `s3_storage_enabled` | 资源存储到 S3 | 布尔 | `false` | 开启后新上传图片写入 S3，本地保留缓存 |
| `s3_public_url` | 资源访问前缀 | 文本 | 空 | 留空走本系统代理读取；填写后可对接 CDN |
| `s3_local_cache` | 本地缓存 | 布尔 | `true` | 从 S3 读取过的资源在本地留存副本 |
| `s3_encrypt_enabled` | 备份加密 | 布尔 | `true` | 备份包默认加密 |
| `s3_encrypt_password` | 加密口令 | 文本 | 空 | 与 WebDAV 的口令互相独立 |
| `s3_restore_mode` | 恢复策略 | 单选 | `merge`（候选 `merge`、`local`、`remote`） | 含义与 WebDAV 一致 |
| `s3_backup_modules` | 备份模块 | 文本 | `system,plugin,user,secret,task,subscribe` | 逗号分隔的模块 code |
| `s3_keep_count` | 保留份数 | 数字 | `5` | `0` 表示不限制 |

两个插件的恢复策略都以英文逗号登记候选值，单选配置取首项生效，因此实际默认策略为「合并更新」。

## 资源存储（仅 S3）

1. 填好连接参数并保存，先通过「连接测试」。
2. 打开「资源存储到 S3」。
3. 按需填写「资源访问前缀」：留空时前端通过本系统代理读取对象；填写后直接拼接对象键，可对接 CDN。
4. 保持「本地缓存」开启可减少远端流量；关闭后每次读取都回源 S3。

规则是「新写入走 S3，读取优先本地缓存」：开启前已存在的本地资源不会被自动迁移。

## 备份与恢复

1. 在「配置信息」中填好连接、加密与恢复策略并保存。
2. 在「模块备份管理」勾选要备份的模块，点「保存模块」。
3. 在「备份与恢复」填写可选备注，点「立即备份」。
4. 备份完成后列表刷新，可查看文件名、生成时间、大小与是否加密。
5. 需要回滚时点「恢复」，选择恢复策略并输入加密口令，确认后写入本机。

| 恢复策略 | 行为 |
| --- | --- |
| 合并更新 `merge` | 仅补齐缺失项与有差异的配置 |
| 本地优先 `local` | 只补充本地不存在的配置，保留本地已有值 |
| 远端优先 `remote` | 以备份内容覆盖本地已有配置 |

备份列表还提供「预览」（应用版本、生成时间、配置项/个人配置/接口密钥数量、模块与备注）、「下载」与「删除」。恢复时 WebDAV 与 S3 自身的连接配置（地址、账号、口令、加密口令）都不会被覆盖，避免恢复后无法继续备份。

## 连接测试

| 插件 | 校验内容 |
| --- | --- |
| WebDAV | 服务地址连通性、账号写入权限，并自动创建缺失的存储目录 |
| S3 | 服务连通性与签名、存储桶列表读取、创建随机临时桶、上传/下载/删除对象，最后删除临时桶 |

S3 测试全程不触碰你配置的存储桶，不影响已有备份。测试结果按步骤展示，失败步骤会标出具体原因。

## 安全与限制

- 加密口令只用于本地派生密钥，服务端不保存明文；**口令遗失即无法恢复备份**，请单独保存。
- 备份包会离开本机存放在第三方服务器，因此默认开启加密。
- 备份的是配置，不是数据；重装后恢复配置仍需自行准备媒体文件与目录结构。
- 恢复不会还原 WebDAV / S3 的连接参数与加密口令。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 备份列表为空 | 目录/前缀下没有备份，或连接参数错误 | 先做连接测试，再确认存储目录与前缀 |
| 恢复提示口令错误 | 与备份时使用的口令不一致 | 使用备份时的口令；遗失则无法恢复 |
| S3 连接失败但地址可访问 | 区域、寻址方式或签名不匹配 | MinIO 开启路径风格寻址，并核对地域与密钥 |
| 资源仍保存在本地 | 未开启「资源存储到 S3」 | 打开开关并保存，新上传资源才会转存 |
| 备份被自动清理 | 保留份数限制 | 调大「保留份数」或设为 `0` |

完整的备份恢复入口与其它系统级操作见[备份与恢复](/docs/system/backup-restore)；系统级参数见[系统配置](/docs/system/config)。
