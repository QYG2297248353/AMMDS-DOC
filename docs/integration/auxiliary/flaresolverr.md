# FlareSolverr

FlareSolverr 是一个专门处理 Cloudflare、DDoS-GUARD 人机校验的代理服务。部分站点在返回正文前会先下发挑战页，普通 HTTP 请求只能拿到验证页面。本插件用于登记该服务的地址与超时；启用后，抓取链路遇到这类挑战页时可交由它处理，再取回真实内容。

## 适用场景

| 场景 | 是否适用 |
| --- | --- |
| 目标站点启用 Cloudflare 的「正在检查您的浏览器」 | 适用 |
| 目标站点启用 DDoS-GUARD 挑战页 | 适用 |
| 普通静态站点、开放 API | 不需要，开启反而增加一次转发开销 |
| 需要登录、付费或站点已封禁 IP | 不适用，FlareSolverr 不能代替账号与权限 |
| 接口返回 401/403 但无挑战页 | 不适用，应先检查密钥与站点账号状态 |

:::note[独立服务]
AMMDS 不下载、不托管 FlareSolverr，也不随应用启动它。你需要自行以容器或可执行文件方式运行该服务，插件只保存地址并调用它。
:::

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `flaresolverr_enabled` | 启用状态 | 布尔 | `false` | 关闭时不使用该服务，请求按原逻辑发出 |
| `flaresolverr_server_url` | 服务地址 | 文本 | `http://127.0.0.1:8191` | 指向已运行的 FlareSolverr，需带协议与端口 |
| `flaresolverr_sync_proxy` | 同步代理配置 | 布尔 | `true` | 把系统网络代理配置同步给 FlareSolverr |
| `flaresolverr_timeout` | 超时时间 | 数字 | `60` | 单位秒；请求时按该值乘以 1000 转为毫秒 |

## 部署与接入

1. 在可访问目标站点的机器上启动 FlareSolverr（默认监听 8191 端口）。
2. 在插件页填写服务地址。若 AMMDS 与 FlareSolverr 不在同一台机器，把 `127.0.0.1` 换成实际主机地址。
3. 需要走代理才能出网时，保持「同步代理配置」开启，并先在「系统配置 → 网络代理」里配好代理。
4. 点击「保存配置」，再点「连接测试」确认地址可达。
5. 确认无误后打开「启用状态」。

:::tip[超时怎么定]
挑战页通常需要数秒到数十秒。默认 60 秒适用于大多数站点；若目标站点二次验证较慢，可上调到 90–120 秒，但过大会让失败请求长时间占用连接。
:::

## 连接测试

点击「连接测试」会用当前填写的服务地址发起一次健康检查：

- 成功：显示「连接测试成功！」
- 失败：显示具体错误，常见为连接被拒绝、域名解析失败或超时
- 服务地址为空：先提示「请先配置连接地址」，不发起请求

测试只验证 AMMDS 能否访问 FlareSolverr，不代表目标站点一定能通过挑战。

## 与系统代理的关系

| 配置 | 作用 |
| --- | --- |
| 系统配置 → 网络代理 | AMMDS 自身的出网方式 |
| `flaresolverr_sync_proxy` | 是否把上面的代理参数同步给 FlareSolverr |

若 FlareSolverr 部署在另一台不受网络限制的机器上，可以关闭同步，让它直接出网，避免多绕一层代理。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 连接测试失败，提示拒绝连接 | 服务未启动或端口不对 | 在服务器上确认 8191 端口监听，并核对地址 |
| 连接测试超时 | 网络不通或服务卡死 | 检查防火墙与容器状态，必要时重启服务 |
| 开启后抓取仍失败 | 站点不是挑战页，而是登录或封禁 | 按提示检查账号、密钥或更换网络出口 |
| 开启后明显变慢 | 每个请求都经过挑战服务 | 仅在需要的站点场景下开启，或缩小使用范围 |
| 同步代理后全部超时 | FlareSolverr 无法使用该代理 | 关闭同步，让 FlareSolverr 直连；或修正代理地址 |

抓取链路的其它排查手段见[刮削任务](/docs/backend/task/scrape)与[网络与连通性](/docs/backend/dashboard/network)。
