# 高德地图

高德地图插件用高德 Web 服务接口做两件事：按 IP 识别当前城市，以及查询该城市的实况天气。配置后，**仪表盘 → 工作台** 的天气卡片会显示温度、天气现象、风向风力与省市信息。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `amap_enabled` | 启用状态 | 布尔 | `false` | 关闭时不使用你填写的 Key |
| `amap_server_url` | 服务地址 | 文本 | `https://restapi.amap.com` | 官方地址；使用代理或镜像时改成对应地址 |
| `amap_api_key` | API密钥 | 文本 | 空 | 在高德开放平台申请，未填写时天气卡片回退到内置 Key |
| `amap_city` | 城市代码 | 文本 | 空 | 填写后不再按 IP 定位，直接查询该城市 |

:::note[回退行为]
天气卡片优先使用「启用状态开启且 API Key 非空」的配置；否则回退到内置 Key。也就是说，不配置也能看到天气，但定位精度与配额由内置 Key 决定。
:::

## 获取 API 密钥

1. 打开高德开放平台，注册并登录后进入控制台。
2. 在「应用管理 → 我的应用」中创建应用。
3. 在应用中「添加 Key」，**服务平台选择「Web 服务」**。本插件由服务端直接请求 `restapi.amap.com` 的 REST 接口，不使用浏览器端 JS API。
4. 创建完成后复制 Key，填入「API密钥」并保存。

## 定位与天气流程

1. **确定城市**：填写了「城市代码」时直接使用该 adcode；未填写时先获取公网 IP，再调用高德 IP 定位接口解析出省市与 adcode。
2. **查询天气**：用 adcode 调用实况天气接口，取回温度、天气现象、风向、风力、湿度与发布时间。
3. **展示**：工作台天气卡片渲染温度、天气图标与省市；请求失败时显示「天气信息加载失败」并提供「重试」按钮。

城市代码会做格式校验：必须是 3–6 位数字且大于 0，格式不合法时视为未配置，继续按 IP 定位。

## 城市代码

| 城市 | adcode | 城市 | adcode |
| --- | --- | --- | --- |
| 北京 | `110000` | 杭州 | `330100` |
| 上海 | `310000` | 成都 | `510100` |
| 广州 | `440100` | 武汉 | `420100` |
| 深圳 | `440300` | 西安 | `610100` |

更细的行政区划编码可在高德开放平台的行政区划查询中检索；填写区县级 adcode 也能正常查询天气。

## 连接测试

点击「连接测试」会用当前「服务地址」做一次健康检查：成功显示「连接测试成功！」，失败显示错误信息。该测试只验证网络可达，不会校验 Key 是否有效，也不会返回天气数据。

:::tip[固定城市更稳定]
服务器走代理、使用 VPN 或位于 NAT 后方时，IP 定位可能落到机房所在地。此时手动填写城市代码，可让天气始终对应你关心的城市。
:::

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 天气卡片一直显示加载失败 | 服务器无法访问 `restapi.amap.com` | 检查出网与代理，用连接测试确认 |
| 城市定位错误 | 出口 IP 属于机房或代理 | 手动填写城市代码 |
| 填写 Key 后仍无数据 | Key 类型不是「Web 服务」或配额用尽 | 在高德控制台核对 Key 类型与用量 |
| 想确认改动是否生效 | 页面读取的是已保存的配置 | 保存后刷新工作台，再查看天气卡片 |

跨域与代理层面的排查可参考[网络与连通性](/docs/backend/dashboard/network)。
