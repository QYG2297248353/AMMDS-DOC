# DeepSeek AI

DeepSeek 插件把深度求索的大模型接口接入 AMMDS：填写服务地址与 API Key 后，可以在插件页查看账户余额、拉取可用模型、把选中的模型写回配置，并用连接测试确认链路可用。

{/* truncate */}

## 用途

| 场景 | 具体表现 |
| --- | --- |
| AI 翻译 | [翻译服务](/docs/integration/auxiliary/translation)支持 OpenAI 兼容通道，把服务地址指向 DeepSeek 并填写模型即可复用同一账号 |
| 智能刮削辅助 | 系统检查把本插件用途标注为「AI 翻译、智能刮削辅助」 |
| 智能对话 | Telegram Bot 的 `/deepseek` 指令开启多轮会话，20 分钟无交互自动过期 |

:::note[能力边界]
DeepSeek 不是内置元数据源，也不会直接写入影片字段；刮削中的字段翻译由「翻译服务」按所选通道执行，见[翻译服务](/docs/integration/auxiliary/translation)。
:::

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `deepseek_enabled` | 启用状态 | 布尔 | `false` | 关闭后余额与模型卡片不显示，后台调用直接判为未启用 |
| `deepseek_server_url` | 服务地址 | 文本 | `https://api.deepseek.com` | 官方地址；使用中转或自建代理时改成对应地址 |
| `deepseek_api_key` | API Key | 文本 | 空 | 调用凭证；缺失时余额、模型与对话均不可用 |
| `deepseek_server_model` | 推理模型 | 文本 | `deepseek-v4-pro` | 可直接输入模型名，也可在模型列表点「选用」写回 |
| `deepseek_model_temperature` | 模型温度 | 数字 | `0.7` | 越大输出越随机，越小越稳定 |
| `deepseek_context_length` | 上下文长度 | 文本 | `1M` | 仅用于展示模型能力，不参与请求参数 |
| `deepseek_output_length` | 输出长度 | 文本 | `384K` | 仅用于展示模型能力，不参与请求参数 |

模型名称变化较快，因此「推理模型」是自由文本项而不是固定下拉。旧模型 `deepseek-chat` 会被映射为 `deepseek-v4-pro`，`deepseek-reasoner` 映射为 `deepseek-v4-flash`。

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 应用信息 | 名称、Logo、官网、文档、集成版本与简介 |
| 配置信息 | 上表 7 项；提供「刷新配置」「保存配置」 |
| 账户余额 | 启用后出现，按币种展示总余额、赠送余额与充值余额 |
| 模型列表 | 启用后出现，列出模型 ID、归属方与创建时间 |
| 连接测试 | 用当前「服务地址」发起健康检查 |

## 账户余额

- 数据来自 DeepSeek 的余额接口，要求服务地址与 API Key 均非空。
- 账户可用时显示绿色「账户可用」，不可用时显示红色「余额不足」。
- 点击「刷新余额」重新拉取；获取失败会提示并清空卡片内容。

## 模型列表

1. 确认插件已启用并填好 API Key。
2. 在「模型列表」点击「刷新模型」拉取当前账号可用模型。
3. 找到目标模型后点「选用」，页面会把模型 ID 写回 `deepseek_server_model` 并刷新配置；正在使用的模型显示「使用中」。

刷新失败或 Key 无效时列表为空并显示空状态，不会影响已保存的模型配置。

## 并发与失败处理

| 项目 | 规则 |
| --- | --- |
| 并发控制 | 按模型分别限流，`deepseek-v4-pro` 上限 500、`deepseek-v4-flash` 上限 2500 |
| 等待策略 | 申请不到并发额度时最多等待 30 秒，仍失败则返回「并发请求已满」 |
| 超限 | 服务端返回 429 时按失败处理，由调用方提示稍后重试 |
| 重试 | 插件层不自动重试，拿到的失败信息即终态 |

## 连接测试

点击「连接测试」后，用当前填写的服务地址做一次健康检查：成功显示「连接测试成功！」，失败显示具体错误。地址为空时会先提示「请先配置连接地址」，不发起请求。

:::tip[排查顺序]
余额或模型加载失败时，先核对 API Key，再看服务器能否访问服务地址；跨境链路问题可在「系统配置 → 网络代理」中处理后，用[网络与连通性](/docs/dashboard/network)复核。
:::

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示配置不完整 | 服务地址或 API Key 为空 | 补齐后保存并刷新配置 |
| 余额为空 | Key 无效或余额接口不可达 | 先用「连接测试」确认地址，再核对 Key |
| 模型列表为空 | 账号无权访问模型列表 | 直接在「推理模型」中手动填写模型名 |
| 提示并发请求已满 | 同模型并发达到上限 | 稍后重试，或把模型换成 `deepseek-v4-flash` |
| Telegram 提示请先启用插件 | 插件开关关闭 | 打开「启用状态」并保存 |
