# MeiliSearch

MeiliSearch 是自托管的全文搜索引擎。配置服务地址与 API Key 后，AMMDS 会把影片、演员、漫画、小说与资讯写入索引，后台可重建索引、测试检索，前台与顶部搜索通过公开接口查询同一份索引。

{/* truncate */}

## 前置条件

1. 自行部署 MeiliSearch 服务并确认可从 AMMDS 服务器访问。
2. 准备具备索引读写权限的 API Key：重建索引需要创建索引并写入文档。
3. 在插件页填写地址与 Key，保存后先做连接测试。

:::warning[默认地址仅是示例]
服务地址的默认值 `http://192.168.10.24:7700` 是示例内网地址，部署后必须改成你自己的 MeiliSearch 地址，否则连接测试会失败。
:::

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `meilisearch_enabled` | 启用状态 | 布尔 | `false` | 关闭后索引与检索均不执行，公开搜索接口返回空 |
| `meilisearch_host` | 服务地址 | 文本 | `http://192.168.10.24:7700` | MeiliSearch 实例地址，需带协议与端口 |
| `meilisearch_api_key` | API Key | 文本 | 空 | 索引与检索接口鉴权；重建索引需要可写入的 Key |
| `meilisearch_auto_index` | 自动索引 | 布尔 | `true` | 开启后定时全量重建影片/演员/漫画等索引 |

## 索引管理

「索引管理」按类型重建索引，每次都是**全量重建**：

| 选项 | 说明 |
| --- | --- |
| 全部 | 依次重建全部类型（影片、剧集、演员、漫画、小说、资讯） |
| 影片 | 影片标题、番号等字段 |
| 演员 | 演员姓名、别名等字段 |
| 漫画 | 漫画标题、作者等字段 |
| 小说 | 小说标题、作者、系列等字段 |
| 资讯 | RSS 资讯条目 |

点击「重建索引」后，卡片会回显各类型写入的文档数量，例如 `movie=1024, actor=356`。重建采用「先清空该类型索引、再分片写入」的方式，因此重建期间该类型的检索结果可能短暂为空或不全，等任务结束后恢复。

页面未单列「剧集」选项，重建「全部」时会一并重建剧集索引。

:::tip[首次使用]
新部署或数据大量变动后，建议先手动「全部」重建一次，再依赖自动索引维持新鲜度。
:::

## 自动索引

- 开启「自动索引」且服务可用时，后端在启动约 5 分钟后执行首次全量重建，之后每小时一次。
- 已有任务在跑时不会重复触发；失败只记录运行日志，不阻塞其他任务。
- 关闭自动索引后，只能手动重建；新增的影片不会自动进入索引。

## 搜索测试

用于验证索引内容是否符合预期：

| 字段 | 说明 |
| --- | --- |
| 类型 | 与索引类型一致 |
| 关键词 | 必填，为空会提示先输入 |
| 结果 | 表格展示标题与文档 ID，无命中时显示「无匹配结果」 |

搜索测试只读取索引，不修改数据；搜索不到时先确认对应类型是否已重建。

## 前台检索

前台与顶部搜索调用公开接口 `/api/pub/search/meili/search`：

- 参数：`type`（默认 `all`）、`q`（必填）、`limit`（默认 10）
- 未启用插件时接口直接返回空列表，不会报错
- 返回的是命中文档的原始字段，由调用方决定展示方式

## 连接测试

点击「测试连接」调用健康检查：成功显示「连接成功，MeiliSearch 服务可用」，失败提示检查服务地址与 API Key。常见失败原因是地址写成示例地址、端口未开放或 Key 权限不足。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 连接失败 | 地址/端口错误或服务未启动 | 在服务器上用浏览器或 curl 访问同一地址验证 |
| 连接失败但地址正确 | API Key 无权限 | 换成具备索引读写权限的 Key |
| 重建索引报错 | 索引不存在且 Key 不能创建索引 | 使用可写入的管理 Key，或先在 MeiliSearch 中创建索引 |
| 搜索无结果 | 该类型尚未重建，或关键词不匹配 | 重建对应类型后重试 |
| 数据不更新 | 自动索引关闭 | 打开自动索引或手动重建 |

网络层面的连通性可结合[网络与连通性](/docs/dashboard/network)一起排查；其它插件的结构说明见[插件总览](/docs/integration/overview)。
