# VibeVoice 本地字幕识别

VibeVoice 是微软开源的语音 AI 模型。本插件通过 OpenAI 兼容的语音转写接口（`POST /v1/audio/transcriptions`）接入自部署的 VibeVoice 服务，把视频中的对白转成 SRT 字幕；既可以让 AMMDS 托管本地服务，也可以连接外部已有服务。

{/* truncate */}

## 接入模式

| 模式 | 说明 | 需要准备 |
| --- | --- | --- |
| 本地（AMMDS 托管） | 由 AMMDS 下载推理程序与 GGUF 模型，并托管识别服务（默认端口 8000，服务地址自动写入） | 启动器、模型文件 |
| 远程（外部服务） | 连接已有的 OpenAI 兼容 VibeVoice 服务，模型文件由外部服务自行管理 | 服务地址、可选 API Key、模型名 |

切换模式会改变表单可见项：本地下不显示服务地址、API Key 与识别模型名。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `vibevoice_mode` | 接入模式 | 单选 | `local` | `local` 本地托管，`remote` 远程服务 |
| `vibevoice_enabled` | 启用状态 | 布尔 | `false` | 关闭后无法创建字幕任务，工具箱入口提示未启用 |
| `vibevoice_server_url` | 服务地址 | 文本 | `http://127.0.0.1:8000` | 本地模式由内置服务自动写入，远程模式需手填 |
| `vibevoice_api_key` | API Key | 文本 | 空 | 可选；服务端未开启鉴权时留空 |
| `vibevoice_model` | 识别模型名 | 文本 | `vibevoice-asr` | 需与服务端加载的模型一致 |
| `vibevoice_max_concurrent` | 最多同时任务数 | 数字 | `1` | 取值 1–5 |
| `vibevoice_max_threads` | 单个任务最大线程 | 数字 | `4` | 作为提示参数转发给服务 |
| `vibevoice_segment_minutes` | 单段最大分钟 | 数字 | `3` | 上限 60；本地服务受推理上下文限制会自动收敛 |
| `vibevoice_hf_repo` | 模型仓库 | 文本 | `microsoft/VibeVoice-ASR-BitNet` | 模型下载区域使用，不在通用表单展示 |
| `vibevoice_hf_file` | 模型文件名 | 文本 | 空 | 下载完成后自动写入，空表示尚未下载 |
| `vibevoice_engine` | 启动器优先级 | 单选 | `asr_infer` | `asr_infer` 命令行单次推理，`asr_stream_server` 常驻服务 |
| `vibevoice_output_location` | 字幕生成位置 | 单选 | `video_dir` | `video_dir` 视频同源，`unified` 统一目录 |

## 启动器怎么选

| 启动器 | 工作方式 | 资源占用 | 适用 |
| --- | --- | --- | --- |
| `asr_infer`（推荐） | 每段音频起独立进程做一次推理，上下文 16384 | 无常驻内存，单段峰值较高 | 默认选择，速度更快（实测 RTF ≈ 1.39） |
| `asr_stream_server` | 常驻进程提供流式服务 | 约 2.5 GB 常驻内存 | 仅在需要避免每段重新加载模型时选用 |

`asr_stream_server` 的上下文较小，长音频可能因显存/内存分配失败而中断；切换启动器时页面会自动套用推荐参数（并发 1、线程 4、单段 3 分钟），仍可手动调整后保存。

## 本地模式准备

1. 打开插件页，接入模式选择「本地」。
2. 在「内置服务 → 启动器下载」下载推理程序，等待状态变为已就绪。
3. 在「模型下载」确认仓库为官方仓库，点击「下载模型」，等待 VAE 与 LM 两个 GGUF 文件下载完成（合计约 1.5 GB）。
4. 点击「启动服务」，状态显示「运行中」并回显端口。
5. 在「服务检测」点击「检测服务」，确认服务已连接、已加载模型包含 `vibevoice-asr`。

:::tip[下载失败怎么办]
启动器下载失败时，可把微软官方 VibeASR.cpp 的编译产物放入 `data/vibevoice/` 目录（如 `asr_stream_server_amd64.exe`），再刷新状态。模型下载中断会显示「已中断」，删除后重新下载即可。
:::

## 内置服务状态

| 字段 | 含义 |
| --- | --- |
| 服务状态 | 运行中 / 未运行，运行中显示监听端口 |
| 推理引擎 | 当前使用的启动器 |
| 推理程序 | 是否安装，并分别标注常驻服务、命令行工具是否就绪 |
| 模型文件 | 已就绪 / 未就绪 |
| 模型目录 | 模型实际存放路径 |

页面提供「启动服务」「停止服务」「重启服务」「刷新状态」四个操作。

## 生成字幕

入口在 **工具箱 → 字幕生成**，插件未启用时页面会直接提示先启用。

1. 点击「新建字幕任务」，选择创建方式：单个视频或目录批量。
2. 选择服务器上的视频文件或包含视频的目录。
3. 选择识别语言（默认可自动检测），需要双语时打开「双语字幕」并选择目标语言。
4. 提交后任务进入队列，列表展示视频文件、时长、识别语言、双语、状态、进度与创建时间。

任务操作随状态变化：

| 状态 | 可用操作 |
| --- | --- |
| 进行中 / 排队中 / 翻译中 | 取消 |
| 失败 / 已取消 | 重试 |
| 已完成 | 详情、查看、编辑、下载、翻译 |

任务详情会展示视频路径、分段进度、字幕片段数、识别模型、线程数与字幕文件路径；失败任务直接展示错误信息。

## 字幕文件与翻译

- **视频同源**：字幕写到视频所在目录并使用视频文件名（如 `测试视频.srt`），播放器可自动加载。
- **统一目录**：写到 `data/subtitles/vibevoice/`，以任务 ID 命名。
- 已完成的任务可基于当前字幕再建一条「翻译任务」，跳过语音识别直接翻译，生成带语言后缀的新字幕文件，同样支持查看、编辑、下载。

## 并发与分段

- 「最多同时任务数」限制并行任务，默认 1；本地推理内存峰值高，建议保持串行。
- 长视频会按「单段最大分钟」切段识别，最后合并为一条字幕；段数越多耗时越长。
- 单段时长过大时本地服务可能崩溃，页面会在切换启动器时自动收敛到推荐值。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 工具箱提示插件未启用 | 启用状态为关闭 | 打开开关并保存 |
| 检测服务失败 | 服务未启动或地址/端口不对 | 本地模式先「启动服务」，远程模式核对地址与 API Key |
| 模型文件未就绪 | 只下载了部分文件 | 在模型下载列表删除残缺文件后重新下载 |
| 任务长时间排队 | 并发已占满 | 等待前序任务完成，或调整同时任务数 |
| 字幕缺失后半段 | 单段过长导致推理中断 | 降低单段最大分钟，或改用 `asr_infer` 重试 |
