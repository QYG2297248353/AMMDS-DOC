# KamePT

KamePT（龟站）是「CosAV 次元世界」方向的 PT 站，站点基于 **NexusPHP** 架构。它没有独立的插件配置页，站点的检索能力由 **NexusPHP 插件**统一提供；另有一条独立的「站点认证」通道用于账号级认证。

## 站点定位

| 项目 | 说明 |
| --- | --- |
| 站点名称 | KamePT（龟站） |
| 站点地址 | `https://kamept.com` |
| 站点框架 | NexusPHP（与 Rousi 的 NexusPHP 站群同框架） |
| 检索入口 | **集成应用 → 站点资源 → NexusPHP** 中添加站点 |
| 认证入口 | 头像菜单 → **站点认证**，选择 KamePT |
| 站点标识 | 站点认证记录中的 ID 为 `2`，业务代码 `kame-pt`；插件里的站点条目另有独立记录 |

:::info[为什么没有单独的插件页]
NexusPHP 是一套建站程序，同一个插件可以同时管理多个基于它的站点。KamePT 作为其中一个站点条目存在，而不是单独一套插件配置。
:::

## 接入步骤

1. 打开 **集成应用 → 站点资源 → NexusPHP**，把「启用状态」打开并保存。
2. 在「NexusPHP 站点」卡片点「添加站点」。
3. 在「站点名称」下拉中选择 **KamePT (龟站)**，系统会自动带出站点地址 `https://kamept.com` 与 Logo。
4. 填写「站点令牌」（见下一节），保持「是否启用」为开启。
5. 先点「健康检查」，通过后再点「添加」。

站点保存后，卡片上可用「刷新」重新拉取列表，用「同步用户信息」同步站点账号数据。

## 集成配置项（NexusPHP 插件）

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `nexusphp_enabled` | 启用状态 | 布尔 | `false` | 关闭后所有 NexusPHP 站点（含 KamePT）不参与检索、用户同步与告警 |
| `nexusphp_search` | 检索功能 | 布尔 | `false` | 开启后站点参与订阅检索 |
| `nexusphp_sync_user` | 同步用户信息 | 布尔 | `false` | 关闭时「同步用户信息」按钮会被后端拒绝 |
| `nexusphp_notice` | 告警通知 | 布尔 | `false` | 站点异常时推送告警 |

## 站点条目字段

站点条目不是系统配置项，而是独立的数据记录，字段如下：

| 字段 | 界面名称 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `name` | 站点名称 | 是 | 展示名，选官方预设会自动填充 |
| `url` | 站点地址 | 是 | 站点首页完整地址，需含协议 |
| `logo` | 站点Logo | 否 | 仅用于界面展示 |
| `token` | 站点令牌 | 是 | 调用站点 `/api/v1` 接口的访问令牌 |
| `enable` | 是否启用 | 是 | 禁用后该站点不参与辅种与用户信息同步 |

## 获取站点令牌

1. 登录 KamePT，进入 **控制面板 → 設定首頁**。
2. 找到「访问令牌」，点创建并复制令牌。
3. 令牌权限至少需要：获取种子列表、查看种子详情、查看用户基本信息。

:::warning[权限不足的表现]
令牌权限不够时，健康检查会失败或站点添加后被标记为异常，日志中出现「权限不足」。此时回到站点重新创建令牌，不要反复重试同一枚令牌。
:::

## 连接测试

| 时机 | 方式 | 说明 |
| --- | --- | --- |
| 添加前 | 弹窗中的「健康检查」 | 校验表单后按地址与令牌请求站点，通过才允许添加 |
| 添加后 | 站点卡片的「刷新」 | 用库中已保存的地址与令牌重新检查，异常站点会保持未就绪状态 |

底层检查会访问站点的 `/api/v1/sections` 与 `/api/v1/profile`：前者校验令牌是否有读取分区与种子的权限，后者校验令牌能否读取账号信息。

## 在订阅检索中的作用

- **平台标识**：检索结果标记为 `NexusPHP`，与 Rousi、以及通过 NexusPHP 插件添加的其他站点同属一个平台。
- **检索范围**：先查站点主接口，再按站点配置的分区逐个查询并汇总；单个分区失败不影响其他分区。
- **搜索顺序**：订阅配置的默认顺序 `M-Team,NexusPHP,Rousi,Prowlarr` 中已包含 NexusPHP，KamePT 的结果随平台一同参与排序。
- **缓存**：同一关键字的结果会写入本地缓存，命中缓存时不再请求站点。

:::tip[多站点并存]
一个 NexusPHP 插件下可以同时挂 KamePT、Rousi（NexusPHP 站群）等站点，检索时会按站点逐条查询并按平台汇总。
:::

## 站点认证（可选）

站点认证与插件配置是两条独立的链路：

1. 打开右上角头像菜单，进入 **站点认证**。
2. 在站点列表中选择 **KamePT (龟站)**。
3. 填写你在站点的 **UID** 与 **PassKey**，提交认证。
4. 认证通过后，依赖认证结果的站点功能才可用；每次服务重启都需要重新认证。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 添加站点时健康检查失败 | 站点地址写错、令牌错误或权限不足 | 核对地址是否为 `https://kamept.com`，重发令牌 |
| 站点列表为空 | NexusPHP 插件未启用 | 先开启插件并保存 |
| 检索不到 KamePT 资源 | 未开启「检索功能」，或站点被禁用 | 打开检索开关，确认站点「是否启用」为开启 |
| 同步用户信息被拒绝 | 「同步用户信息」开关关闭 | 打开开关后重试 |
