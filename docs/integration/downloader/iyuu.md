# IYUU

IYUU 是基于种子特征码的交叉索引服务：拿你已经在做种的种子去比对其它站点，命中后把同一个资源「补」到那些站点继续做种。AMMDS 用它完成**自动辅种**，并用它推送辅种消息。

## 与下载器的分工

| 角色 | 承担方 |
| --- | --- |
| 判断「哪些站点有这个种子」 | IYUU |
| 实际把种子加入下载器 | qBittorrent |
| 辅种成功后继续做种 | qBittorrent |
| 订阅下载 | qBittorrent（与辅种是两个流程） |

也就是说，IYUU 只负责**找**，落地执行仍由 qBittorrent 完成。当前版本的自动辅种仅支持 qBittorrent 客户端，选 Transmission 会提示暂不支持。

## 配置项

| 配置键 | 界面名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `iyuu_enabled` | 启用状态 | 布尔 | `false` | 关闭后辅种接口与推送测试全部返回失败 |
| `iyuu_server_url` | API 服务地址 | 字符串 | `https://2025.iyuu.cn` | 辅种与用户信息接口地址 |
| `iyuu_home_url` | 服务地址 | 字符串 | `https://iyuu.cn` | 主站地址，用于页面跳转与控制台入口 |
| `iyuu_token` | 密钥 | 字符串 | 空 | IYUU 账号令牌，接口路径中的身份标识；系统检查中的必填项 |
| `iyuu_hide_image` | 隐藏图像 | 布尔 | `true` | 为 `true` 时生成的 Markdown 消息不带图片 |

:::info[页面位置]
配置页在 **集成应用 → 下载器 → IYUU**，页面顶部标注集成版本 `8.2.63+`，类型为「PT辅种」。
:::

## 获取令牌

1. 登录 IYUU 官网（`iyuu.cn`），进入用户中心。
2. 找到账号令牌并复制。
3. 回填到「密钥」并保存，随后点「测试连接」确认地址可达。

令牌与账号绑定：换账号要同步换令牌，否则辅种记录会写进旧账号名下。

## 连接测试

| 按钮 | 检查内容 |
| --- | --- |
| 测试连接 | 对「API 服务地址」做连通性探测，不校验令牌 |
| 推送测试 | 用内置测试模板向 IYUU 渠道推送一条消息，验证令牌与通知链路 |

「推送测试」会真实发一条消息，适合在配置完通知后做端到端验证。

## 辅种计划

在 **工具箱 → PT辅种 → 站点管理** 中，点「辅种计划」打开配置弹窗：

| 字段 | 说明 |
| --- | --- |
| 启用 | 是否开启自动辅种 |
| 执行周期 | Cron 表达式；留空表示不注册定时任务，只能手动执行 |
| 辅种客户端 | 选择承载辅种的下载器；当前版本仅 qBittorrent 生效 |
| 通知 | 辅种完成后是否推送通知 |

配置提交前会校验 Cron 表达式，非法表达式会被直接拒绝保存。

## 辅种流程

1. 系统按计划触发，或点「立即辅种」手动触发。
2. 启动时随机延时 30～300 秒，避免多实例同时冲击 IYUU 接口。
3. 每轮取最多 100 条「等待辅种」记录，逐条向 IYUU 查询可辅种站点。
4. 按站点要求选择添加方式：需要授权的站点先换取种子文件；需要 Cookie 的站点带上站点 Cookie；其余直接提交种子地址。
5. 每个站点的处理结果立即落库，状态为 `未辅种`、`等待辅种`、`辅种完成` 或 `辅种失败`。

:::warning[前置条件在 IYUU 侧]
自动辅种要求 IYUU 账号已开启辅种、并把辅种客户端设为 qBittorrent。这些开关在 IYUU 账号里，不在 AMMDS 里；账号侧没开，这边触发也不会有结果。
:::

## 站点与记录

| 页面 | 用途 |
| --- | --- |
| 工具箱 → PT辅种 → 站点管理 | 查看支持辅种的站点卡片、修改站点参数、**导入站点**（JSON 配置文件）、执行「立即辅种」 |
| 工具箱 → PT辅种 → 辅种记录 | 任务级记录：自动/手动、辅种结果、数量、时间与原因 |
| 工具箱 → PT辅种 → 辅种任务 | 种子级明细：状态、辅种时间、命中的站点种子、失败原因 |

记录与任务列表都支持清空，清空不可撤销。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 立即辅种返回 0 | 没有「等待辅种」记录，或 IYUU 侧未开启辅种 | 先确认账号侧开关，再核对站点配置 |
| 辅种提示暂不支持的客户端 | 辅种客户端选了 Transmission | 改为 qBittorrent |
| 大量「辅种失败」 | 站点需要 Cookie 或授权信息过期 | 在站点卡片更新对应参数后重试 |
| 推送测试收不到消息 | 令牌错误，或系统级通知开关关闭 | 核对令牌，检查通知总开关与分类 |
| 辅种成功但下载器里没有 | 保存路径在下载器主机上不存在 | 检查原种路径与下载器视角路径 |
