# 任务记录与日志

任务记录回答三个问题：这次任务跑了多久、处理了多少文件、失败在哪一步。AMMDS 把记录分成扫描日志、刮削日志与系统任务日志三类，分别对应不同的执行链路。

{/* truncate */}

## 三类记录

| 记录 | 位置 | 记录对象 |
| --- | --- | --- |
| 扫描日志 | 任务管理 → 扫描日志 | 扫描任务的每次运行 |
| 刮削日志 | 任务管理 → 刮削日志 | 刮削任务的每个批次 |
| 任务日志 | 系统 → 日志审计 → 任务日志 | 文件操作、备份、RSS、漫画/小说整理等后台任务 |

## 扫描日志

### 检索条件

| 条件 | 可选项 |
| --- | --- |
| 任务类型 | 全部 / 影视 / 剧集 |
| 任务选择 | 按任务名称筛选，可选全部 |
| 运行类型 | 手动执行、定时任务、实时监控、初始化 |
| 任务状态 | 创建、扫描中、监控中、等待扫描、扫描完成、取消扫描、扫描异常 |

点击「查询」按条件刷新，点击「重置」恢复默认条件。从任务卡片点击「记录」进入时，会自动带上该任务的 `uid` 过滤。

### 列表字段

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 本次扫描所属任务 |
| 类型 | 运行类型，对应触发来源 |
| 开始时间 | 任务开始执行的时间 |
| 任务耗时 | 有耗时时显示；扫描中无耗时显示「扫描中」，其它状态无耗时显示「扫描中断」 |
| 任务状态 | 扫描完成显示绿色圆点，其余为灰色 |
| 识别媒体数量 | 本次扫描发现的视频文件数 |
| 新增媒体数量 | 新登记入库的文件数 |
| 更新媒体数量 | 已存在并重新绑定到本次扫描的记录数 |
| 操作 | 取消；仅「扫描中」且运行类型不是「实时监控」「初始化」时可取消 |

页面底部支持分页、切换每页条数、调整表格密度与列显隐。顶部「清理日志」会清空全部扫描记录，属于不可恢复操作。

:::note[扫描日志没有单条详情]
扫描日志只记录批次级信息。要定位单个文件的识别番号、刮削状态与步骤，请到 **任务管理 → 刮削入库** 查看；单个媒体的步骤时间线在「查看步骤」中。
:::

## 刮削日志

### 检索条件

| 条件 | 可选项 |
| --- | --- |
| 任务类型 | 全部 / 影视 / 剧集 |
| 运行类型 | 手动执行、定时任务等 |
| 任务状态 | 刮削中、刮削完成、等待、取消、异常 |

### 列表字段

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 本批次任务名；多线程模式会带线程后缀 |
| 开始时间 | 批次开始时间 |
| 刮削结果 | 批次结果摘要 |
| 任务耗时 | 刮削中无耗时显示「刮削中」，其它状态无耗时显示「刮削中断」 |
| 任务状态 | 完成显示绿色，其余显示橙色 |
| 刮削媒体数量 | 本批次计划处理的媒体数 |
| 刮削成功数量 / 失败数量 | 本批次成功与失败计数 |
| 操作 | 取消；仅「刮削中」且运行类型不是实时刮削/初始化时可取消 |

「清理日志」会清理可删除的历史刮削记录。正在运行的任务不能被清理；需要停止时先点「取消」。

## 系统任务日志

文件上传/下载/复制/移动/压缩、备份导入导出、RSS 更新、漫画/小说整理等操作会写入系统任务日志：

- 支持按关键字、任务类型、状态筛选。
- 列表展示类型、标题、状态、进度、消息、开始时间与耗时。
- 点击「详情」打开抽屉，查看任务状态、进度、完成数/总数、消息、错误、开始/结束时间，以及逐行执行日志（ERROR / WARN 会高亮）。
- 仅「执行中」且后端标记可取消的任务显示「取消」。
- 执行中的任务不能删除；已结束任务可单条删除，也可用「清理」批量删除已结束日志。
- 开启「自动刷新」后每 5 秒刷新一次列表。

更完整的日志审计说明见 [运行日志](/docs/system/logs)。

## 状态对照

| 链路 | 状态 |
| --- | --- |
| 扫描任务 | 创建、扫描中、监控中、等待扫描、扫描完成、取消扫描、扫描异常、任务删除 |
| 刮削任务 | 刮削中、刮削完成、等待、取消、异常、删除 |
| 系统任务 | 执行中、已完成、失败、已取消 |

「等待」表示任务已创建但尚未获得执行机会；「异常」表示执行过程中抛出了未处理错误，需要结合日志与步骤定位。

## 失败之后怎么重试

任务记录本身不提供「重试」按钮，重试发生在对应的业务页面：

| 场景 | 重试方式 |
| --- | --- |
| 扫描失败或想重扫 | 在任务配置中再次点击「立即扫描」；扫描中的任务需先取消 |
| 单个媒体刮削失败 | 在刮削入库点击「刮削整理」，失败媒体会重新进入待办 |
| 识别番号错误 | 在刮削入库点击识别番号标签修改，再重新刮削 |
| 元数据匹配不到 | 用「绑定」手工绑定影视库记录，再刮削 |
| 图片或 NFO 缺失 | 对任务使用「查漏补缺」，只补附属文件 |
| 订阅下载失败 | 在订阅管理点「立即搜索」，或等待下一轮自动任务 |
| 文件操作失败 | 在系统任务日志查看错误，修正路径/权限后重新发起 |

:::tip[先看步骤再看日志]
刮削失败时，先在「刮削入库 → 查看步骤」定位是文件校验、番号识别、数据源检索还是图片/NFO 生成失败；步骤里的错误信息通常比批次日志更具体。
:::

## 清理建议

- 清理日志不会删除媒体记录，也不会回滚已整理的文件。
- 扫描日志清理后，历史批次无法再追溯；需要保留排查依据时先导出或截图。
- 刮削日志清理只删除允许删除的历史记录，运行中的任务不会被清理。
- 系统任务日志的「清理」只删除已结束任务，执行中的任务会保留。

扫描与刮削的触发方式分别见 [扫描任务](/docs/task/scan) 与 [刮削任务](/docs/task/scrape)；定时执行见 [定时任务](/docs/task/scheduled)。
