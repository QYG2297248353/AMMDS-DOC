# 任务配置

任务配置页把「任务」与「规则」放在同一处：上半部分是任务卡片列表，下半部分是按页签划分的规则面板。任务负责「扫描哪些目录」，规则决定「怎样识别、刮削与整理」。

{/* truncate */}

## 打开方式

进入 **任务管理 → 任务配置**。页面默认停在「任务列表」页签，其余页签都是规则配置面板。

## 任务列表

点击「点击创建扫描任务」卡片新建任务，创建字段与流程见 [扫描任务](/docs/task/scan)。每个任务卡片展示：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 卡片标题，旁带系统类型与任务类型（影视 / 剧集 / 未知）标签 |
| 媒体类型 / 剧集分区 | 影视任务显示产地分区，剧集任务显示分区 |
| 扫描目录 / 整理目录 | 源目录与目标目录 |
| 整理模式 | 原地整理、移动、复制、软连接、硬连接、查漏补缺 |
| 命名与重复规则 | 原文件名/标准化文件名；保留、大文件、小文件、新文件、旧文件、高/低分辨率 |
| 计划任务 | Cron 表达式；未启用时显示「未启用」 |

卡片操作：

| 操作 | 行为 |
| --- | --- |
| 记录 | 跳转到扫描日志，并自动按当前任务过滤 |
| 编辑 | 打开编辑弹窗；目录监控开关在编辑时不可修改 |
| 删除 | 二次确认后删除任务；扫描中的任务不允许删除 |
| 主按钮 | 按任务状态显示「立即扫描」「初始化」「监控中」或「查漏补缺」；监控中的任务不能手动扫描 |

## 规则配置分区

| 页签 | 配置分组 | 主要内容 |
| --- | --- | --- |
| 扫描规则配置 | `scanning_rule` | 视频格式、忽略目录/文件、最小体积、分段标记、字幕格式、读取 NFO，以及剧集专属扫描项 |
| 影视刮削规则 | `scrape_rule` | 刮削器、整理目录/文件名格式、NFO 字段、图片、标签、翻译、线程数等 |
| 剧集刮削规则 | `tv_scrape_rule` | 剧集刮削器、匹配阈值与权重、目录/文件名格式、季海报命名、NFO 字段等 |
| 番号补全规则 | 规则表 | 按文件名补全番号的匹配规则与模板 |
| 识别码规则 | 规则表 | 从文件名提取识别码的正则/前后缀规则，可排序、可测试 |
| CID 转换规则 | 规则表 | 把识别码转换为 CID 的模板与匹配规则 |
| 订阅规则配置 | `subscribe_config` | 中字优先、搜索顺序、下载目录 |
| 漫画整理配置 | `comic_arrange` | 整理格式、目录、目录/文件命名、章节生成、封面/封底/目录关键词 |
| 小说整理配置 | `novel_arrange` | 整理格式、目录、目录/文件命名、是否按章节生成 |

规则面板的字段类型由后端返回的 `field` 决定：字符串用输入框、数字用数字输入、布尔用开关、多值用可创建选项的下拉。修改后点击「保存配置」逐项提交；「刷新配置」会放弃未保存的修改并重新拉取。

## 扫描规则配置

影视与剧集共用同一个页签，但剧集任务读取带 `tv` 前缀的键：

| 配置项 | 影视键 | 剧集键 |
| --- | --- | --- |
| 格式限制 | `scanning_video_format` | 复用 |
| 忽略目录 | `scanning_ignore_dir` | `scanning_tv_ignore_dir` |
| 忽略文件 | `scanning_ignore_file` | `scanning_tv_ignore_file` |
| 最小视频大小 | `scanning_min_size` | `scanning_tv_min_size` |
| 视频分段标记 | `scanning_video_segmentation` | 不使用 |
| 字幕格式 | `scanning_subtitle_format` | 复用 |
| 读取本地 NFO | `scanning_read_nfo` | `scanning_tv_read_nfo` |

剧集额外的「特别篇关键词」「集号缺失默认季」「绝对编号识别」用于把文件名解析为季集结构。规则的具体作用见 [扫描任务](/docs/task/scan)。

## 影视刮削规则

| 分组 | 代表配置项 |
| --- | --- |
| 数据源 | 刮削器、本地数据优先、品牌前缀过滤 |
| 整理 | 整理目录格式、整理文件名格式 |
| 元数据 | 自动标签、自动分类标签、字段翻译、番号混合、演员刮削 |
| NFO | NFO 字段（控制生成 NFO 时写入哪些标签） |
| 图片 | 高清封面、刮削剧照、剧照目录、允许图片下载失败 |
| 字幕 | 外挂字幕搜索 |
| 性能 | 多线程执行、最大刮削线程数 |

占位符说明可以通过面板头部的「帮助」查看。字段回填与输出文件的完整说明见 [刮削任务](/docs/task/scrape)。

## 剧集刮削规则

剧集配置集中在同一个页签，包括剧集刮削器（本地、TMDB、Bangumi、TheTVDB）、自动刮削间隔、匹配阈值与权重、季映射自动发现、每季集数、目录/文件名格式、季海报命名、NFO 字段、演员刮削、字段翻译、请求间隔与线程数。

剧集按剧名与季集结构匹配，不使用番号；第一次使用建议先在「剧集刮削」页确认分组边界，再调整匹配阈值。

## 番号补全规则

用于把不完整的文件名补成可检索的番号。每条规则包含：

| 字段 | 说明 |
| --- | --- |
| 备注 | 便于识别规则用途 |
| 规则类型 | 匹配方式，决定匹配串如何解释 |
| 匹配规则 | 用于从文件名中定位片段 |
| 模板 | 生成番号的模板 |
| 番号长度 | `0` 表示自动补全，大于 0 表示补足到指定位数 |
| 自动补全 | 是否自动应用 |
| 启用状态 | 启用 / 禁用 |

规则支持新增、编辑、删除、启用/禁用；识别码规则与 CID 转换规则还支持拖拽排序，排序即优先级。

## 识别码规则与 CID 转换

「识别码规则」从文件名或路径中提取识别码，支持正则表达式、前缀、包含、后缀四种匹配方式，可设置输出模板（`{num}`、`{match}`、`{group1}` 等）、影片类型、有无码、需包含前缀、启用状态与备注。面板提供「识别测试」：输入文件名或完整路径，返回识别码、是否命中、命中规则与补全后的番号。

「CID 转换规则」在识别码正确的前提下，把识别码转换为 CID。匹配方式与识别码规则一致，输出模板支持 `{brand}`、`{num}`、`{num2}`~`{num8}`（补零）、`{match}`、`{group1}` 等占位符，并提供转换测试。

:::tip[先识别再转换]
CID 转换依赖正确的识别码。若转换结果不符合预期，先用识别码规则测试，确认识别码本身正确，再调整 CID 模板。
:::

## 订阅规则配置

| 配置项 | 说明 |
| --- | --- |
| 中字优先 | 布尔配置项；当前版本保存偏好，未参与自动下载排序 |
| 搜索顺序 | 平台关键词列表，决定订阅检索时各站点的尝试顺序，Prowlarr 始终排最后 |
| 下载目录 | 订阅提交下载时的保存路径；留空使用 qBittorrent 默认路径 |

订阅侧的状态、匹配与重试见 [订阅管理](/docs/subscribe/manage)。

## 漫画与小说整理配置

这两个页签服务于漫画/小说入库，不与影视扫描任务混用：

- 漫画：整理格式（文件夹、CBZ、CBR、CB7、PDF、EPUB）、默认整理目录、目录/文件命名规则、是否按章节生成、封面/封底/目录识别关键词。
- 小说：整理格式（EPUB、TXT）、默认整理目录、目录/文件命名规则、是否按章节生成。

命名规则支持 `${title}`、`${author}`、`${chapter}`、`${index}` 等占位符，具体以面板说明为准。

## 注意事项

- 规则是全局配置，修改后影响之后创建或执行的任务，不会回改已经入库的元数据。
- 任务级字段（目录、模式、Cron、目录监控）在任务卡片中维护，不在规则面板中。
- 目录监控与 Cron 二选一；监控任务不参与 Cron 调度。
- 想让扫描任务按计划自动执行，除填写 Cron 外，还需确认全局计划任务开关未关闭，见 [定时任务](/docs/task/scheduled)。
